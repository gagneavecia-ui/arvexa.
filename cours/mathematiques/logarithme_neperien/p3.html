Motivation

Aux deux bouts du domaine

Tu connais déjà ln au voisinage de quelques points : ln 1 = 0, ln e = 1, ln 2 ≈ 0,693. Mais un exercice de Bac D ne s'arrête jamais là : il demande ce que fait la fonction aux bornes de son domaine — près de 0 (exclu) et à l'infini. C'est l'objet des limites, et elles dictent la forme de la courbe.

La stratégie du chapitre est toujours la même : limites → dérivée → variations → tableau. Une fois ce quadrillage en place, aucune fonction contenant ln ne peut te résister.

Les questions de cette partie
  • Quelles sont les limites de ln x en 0⁺ et en +∞, et quelle asymptote en résulte ?
  • Quelles sont les variations et le signe de ln ?
  • À quelle vitesse croît ln face à x ? (croissances comparées)
  • Comment étudier complètement une fonction du type f(x) = ln(x + 2) − 2 ?
🌍 Pour aller plus loin
C'est Leonhard Euler qui, dans son Introductio in analysin infinitorum (1748), définit le logarithme comme réciproque de l'exponentielle — exactement le point de vue de ton programme. Euler aimait souligner un paradoxe amusant : ln tend vers +∞, mais si lentement qu'il faut x ≈ 10 000 pour que ln x atteigne à peine 9,2…
01
Notion 1 · limites de référence

Limites de référence et asymptote x = 0

Les deux limites de référence se justifient directement avec la réciprocité de la partie 1. Pour aller vers +∞ : prends des valeurs x = eⁿ de plus en plus grandes ; alors ln x = ln(eⁿ) = n devient aussi grand que voulu. Pour aller vers −∞ : prends des valeurs x = 1/eⁿ de plus en plus proches de 0 ; alors ln x = ln(e^(−n)) = −n devient aussi négatif que voulu.

Les deux limites à connaître par cœur
lim(x→0⁺) ln x = −∞ · lim(x→+∞) ln x = +∞
La première limite n'existe qu'à droite : 0⁺, car ln x n'existe pas pour x ≤ 0.
📗 Asymptote verticale

Quand x tend vers 0 par valeurs positives, ln x tend vers −∞ : la courbe de ln descend indéfiniment en se collant à l'axe des ordonnées. On dit que la droite d'équation x = 0 est une asymptote verticale de la courbe.

⚠️ 0⁺ et non 0

On écrit lim(x→0⁺) ln x = −∞ avec l'exposant ⁺ : la limite n'existe que par valeurs positives. Écrire lim(x→0) ln x sans le ⁺ est une maladresse signalée par les correcteurs, car ln n'existe pas à gauche de 0.

Notion 2 · variations & signe

Variations et signe de ln

La partie 2 a démontré que (ln x)' = 1/x sur ]0 ; +∞[. Comme 1/x > 0 pour tout x > 0, la fonction ln est strictement croissante sur tout son domaine. On obtient le tableau de variations complet :

x01+∞
f'(x) = 1/x‖++
f(x) = ln x−∞↗0↗+∞

Lecture du tableau : ln part de −∞ (asymptote x = 0), passe par 0 à l'abscisse 1, et monte vers +∞ — sans jamais ralentir sa montée, mais en la ralentissant (la pente 1/x diminue).

💡 Signe de ln x (à connaître par cœur)
  • Pour 0 < x < 1 : ln x < 0 (négatif).
  • Pour x = 1 : ln x = 0 (nul).
  • Pour x > 1 : ln x > 0 (positif).
📗 Conséquence — ln conserve l'ordre

Comme ln est strictement croissante, pour tous a > 0 et b > 0 : a < b ⇔ ln a < ln b. Cette équivalence est l'arme des inéquations logarithmiques (fiche, partie 4) : passer au log ne change pas le sens d'une inégalité.

Exemple : 3 < 5 et ln 3 ≈ 1,099 < 1,609 ≈ ln 5 ✓.

⚠️ Croissante ne veut pas dire rapide

ln est croissante, mais sa pente 1/x diminue : la courbe monte de moins en moins vite. Entre 1 et e, le log gagne 1 unité ; entre e et e² ≈ 7,39, il gagne encore 1 unité… mais sur un intervalle bien plus long. C'est la lenteur que quantifie la section suivante.

Notion 3 · croissances comparées

Croissances comparées : la lenteur de ln

« ln tend vers +∞ » et « ln croît lentement » ne se contredisent pas : les croissances comparées comparent deux infinis. Le verdict est sans appel : à l'infini, toute puissance de x l'emporte sur ln.

💡 Théorème — croissances comparées (admis)
  • lim(x→+∞) (ln x)/x = 0 : face à x, le logarithme est négligeable.
  • lim(x→0⁺) x · ln x = 0 : le produit d'un petit nombre et d'un « moins l'infini » finit à 0.
  • Plus généralement, pour tout entier n ≥ 1 : lim(x→+∞) (ln x)/xⁿ = 0 et lim(x→0⁺) xⁿ · ln x = 0.
Le duel ln contre x — à retenir
(ln x)/x → 0 quand x → +∞ · x ln x → 0 quand x → 0⁺
Dans les deux duels, la puissance gagne : en +∞ le facteur x écrase ln x ; en 0⁺ le facteur x écrase le −∞ du logarithme.
x101001 00010 000
ln x≈ 2,30≈ 4,61≈ 6,91≈ 9,21
(ln x)/x≈ 0,23≈ 0,046≈ 0,007≈ 0,0009

Le tableau le montre : pendant que x est multiplié par 1 000, ln x ne fait que s'ajouter quelques unités, et le rapport (ln x)/x file vers 0. C'est exactement le sens du théorème.

⚠️ Croissances comparées ≠ formes indéterminées quelconques

Ces limites traitent des formes indéterminées précises (∞/∞ et 0 × ∞). Elles ne disent rien d'une forme comme ln x − x ou ln x + x : là, il faut factoriser (voir section 06 et les exemples ci-dessous). Ne sort jamais une croissance comparée de son cadre.

04
Entraînement · limites

Limites usuelles — exemples calculés

Les limites de référence et les croissances comparées se combinent pour résoudre la plupart des questions de limite du chapitre. Voici cinq calculs types, rédigés comme en copie.

🧮 Exemple 1 — lim(x→+∞) ln(2x + 5)
1

Analyser l'intérieur. Quand x → +∞, 2x + 5 → +∞.

2

Appliquer la limite de référence. Le log d'un nombre qui tend vers +∞ tend vers +∞ : lim(x→+∞) ln(2x + 5) = +∞.

🧮 Exemple 2 — lim(x→+∞) (ln x)/(x + 1)
1

Reconnaître la forme indéterminée ∞/∞. Numérateur et dénominateur tendent tous deux vers +∞.

2

Se ramener à la croissance comparée. (ln x)/(x + 1) = (ln x)/x × x/(x + 1). Or (ln x)/x → 0 (croissance comparée) et x/(x + 1) → 1.

3

Conclure. lim(x→+∞) (ln x)/(x + 1) = 0 × 1 = 0.

🧮 Exemple 3 — lim(x→0⁺) x² ln x
1

Reconnaître la forme 0 × ∞. x² → 0 et ln x → −∞.

2

Décomposer le produit. x² ln x = x × (x ln x). Par croissances comparées, x ln x → 0 en 0⁺.

3

Conclure. lim(x→0⁺) x² ln x = 0 × 0 = 0. La puissance x² a eu le dernier mot.

🧮 Exemple 4 — lim(x→1) (ln x)/(x − 1)
1

Reconnaître la forme 0/0. En x = 1 : ln 1 = 0 et 1 − 1 = 0.

2

Penser « nombre dérivé ». La limite de (f(x) − f(a))/(x − a) quand x → a vaut f'(a). Ici f(x) = ln x, a = 1, f(1) = 0 : la limite est f'(1) = 1/1 = 1.

3

Conclure. lim(x→1) (ln x)/(x − 1) = 1 : c'est la pente de la tangente y = x − 1.

🧮 Exemple 5 — lim(x→+∞) (ln x − x), forme ∞ − ∞
1

Factoriser par x. ln x − x = x((ln x)/x − 1).

2

Évaluer les facteurs. x → +∞ et (ln x)/x − 1 → 0 − 1 = −1.

3

Conclure. lim(x→+∞) (ln x − x) = +∞ × (−1) = −∞ : à grande échelle, l'exponentielle (via x) écrase totalement le logarithme.

Notion 4 · étude complète

Étude complète : f(x) = ln(x + 2) − 2

Assemblons tous les outils dans l'exercice type du Bac D : étudier f(x) = ln(x + 2) − 2. Le plan est immuable : domaine → dérivée → limites → tableau → valeurs et signe remarquables.

🧮 Exemple travaillé complet — étude de f
1

Domaine. f existe si x + 2 > 0, soit x > −2 : domaine ]−2 ; +∞[.

2

Dérivée. Avec u(x) = x + 2 > 0 sur le domaine et u' = 1 : f'(x) = 1/(x + 2).

3

Variations. Sur ]−2 ; +∞[, x + 2 > 0 donc f'(x) > 0 : f est strictement croissante.

4

Limites. Quand x → −2⁺ : x + 2 → 0⁺ donc ln(x + 2) → −∞ et f(x) → −∞ (asymptote verticale x = −2). Quand x → +∞ : ln(x + 2) → +∞ et f(x) → +∞.

5

Zéro de f. f(x) = 0 ⇔ ln(x + 2) = 2 ⇔ x + 2 = e² ⇔ x = e² − 2, soit environ 7,389 − 2 = 5,39. La courbe coupe l'axe des abscisses en (e² − 2 ; 0).

6

Points et signe. f(−1) = ln 1 − 2 = −2 et f(0) = ln 2 − 2 ≈ 0,693 − 2 = −1,31. Comme f est croissante et s'annule en e² − 2 : f < 0 sur ]−2 ; e² − 2[, f > 0 sur ]e² − 2 ; +∞[.

x−2e² − 2+∞
f'(x) = 1/(x + 2)‖++
f(x)−∞↗0↗+∞

Remarque de structure : f est simplement la fonction ln translatée de 2 vers la gauche (l'asymptote passe de x = 0 à x = −2) et de 2 vers le bas (le zéro passe de 1 à e² − 2). Reconnaître ces translations donne un contrôle immédiat du résultat.

⚠️ L'asymptote suit l'intérieur du logarithme

L'asymptote verticale de ln(u(x)) se trouve aux bornes où u(x) → 0⁺, pas forcément en x = 0 : ici elle est en x = −2. Toujours résoudre u(x) > 0 avant d'annoncer l'asymptote.

Pour aller plus loin

La tangente en 1 : ln x ≤ x − 1

La section 2 a trouvé la tangente T : y = x − 1 au point (1 ; 0). Question de position relative : la courbe de ln est-elle au-dessus ou en dessous de T ? La réponse est un résultat majeur, démontrable en quelques lignes avec un tableau de variations.

💡 Inégalité de référence

Pour tout x > 0 : ln x ≤ x − 1, avec égalité seulement pour x = 1.

🧮 Démonstration — étude de g(x) = x − 1 − ln x
1

Poser l'écart. Soit g(x) = x − 1 − ln x sur ]0 ; +∞[ : étudier g revient à comparer la tangente et la courbe, car g est l'écart (x − 1) − ln x.

2

Dériver. g'(x) = 1 − 1/x = (x − 1)/x.

3

Signer. Sur ]0 ; +∞[, x > 0 : g' a le signe de x − 1. Négatif sur ]0 ; 1[, nul en 1, positif sur ]1 ; +∞[.

4

Tableau. g décroît sur ]0 ; 1] puis croît sur [1 ; +∞[ : elle atteint son minimum en 1, et g(1) = 1 − 1 − ln 1 = 0.

5

Conclure. Le minimum de g vaut 0, donc g(x) ≥ 0 pour tout x > 0, c'est-à-dire ln x ≤ x − 1 (∎). L'égalité n'a lieu qu'au minimum, soit x = 1.

📗 Ce que dit graphiquement cette inégalité

La courbe de ln est tout entière au-dessous de sa tangente y = x − 1, qu'elle ne touche qu'au point (1 ; 0). On dit que ln est concave : ses pentes diminuent (de 1/x, qui décroît). Cette inégalité sert aussi de croissance comparée qualitative : pour x > 0, ln x ≤ x − 1 < x, donc ln x < x toujours — le logarithme ne dépasse jamais la fonction identité.

🔍 Contrôles numériques
  • x = 0,5 : ln 0,5 ≈ −0,693 et x − 1 = −0,5. On a bien −0,693 ≤ −0,5 ✓.
  • x = 4 : ln 4 ≈ 1,386 et x − 1 = 3. On a bien 1,386 ≤ 3 ✓.
  • x = 1 : 0 = 0 — le seul point de contact ✓.

Bilan

La méthode d'étude en 5 étapes

Toute étude de fonction contenant ln suit le même chemin. Apprends l'ordre — c'est lui qui organise la rédaction et la notation.

🧠 Méthode — Étudier une fonction avec ln
(1) Domaine : résoudre u(x) > 0. (2) Dérivée : f'(x) = u'/u, en citant les conditions. (3) Limites aux bornes du domaine (référence et croissances comparées). (4) Tableau de variations (signe de f', flèches, valeurs remarquables). (5) Valeurs particulières : zéro de f (résoudre f(x) = 0 en passant à l'exponentielle), points sur les axes, signe de f.
lim(x→0⁺) ln x = −∞ · lim(x→+∞) ln x = +∞ · (ln x)/x → 0 en +∞ · x ln x → 0 en 0⁺
Le kit de limites du chapitre : deux limites de référence et deux croissances comparées, valables aussi avec des puissances de x.
  • ln est strictement croissante sur ]0 ; +∞[ : elle conserve l'ordre (a < b ⇔ ln a < ln b).
  • Asymptote verticale x = 0 : la courbe longe l'axe des ordonnées vers −∞.
  • Signe : ln x < 0 sur ]0 ; 1[, ln 1 = 0, ln x > 0 sur ]1 ; +∞[.
  • Croissances comparées : en +∞, x écrase ln x ; en 0⁺, x écrase le −∞ de ln x.
  • Inégalité de référence : ln x ≤ x − 1 pour tout x > 0 (courbe sous sa tangente en 1).
⚠️ Rédaction type pour l'examen

Chaque borne du tableau doit être justifiée : la limite en −2⁺ par celle de ln en 0⁺, le signe de f' par celui de u et de u', le zéro par un passage à l'exponentielle. Un tableau « sans explications » perd la moitié des points, même s'il est exact.

Q1 — La limite de (ln x)/x quand x tend vers +∞ est :

A) 0B) 1C) +∞D) −∞
Voir la réponse
A) 0. Croissance comparée : à l'infini, la puissance x l'emporte sur le logarithme, donc (ln x)/x → 0. Répondre +∞, c'est oublier que le dénominateur croît infiniment plus vite.

Q2 — La limite de x·ln x quand x tend vers 0⁺ est :

A) −∞B) 0C) +∞D) la limite n'existe pas
Voir la réponse
B) 0. Forme indéterminée 0 × (−∞) tranchée par la croissance comparée : x ln x → 0 en 0⁺. Le facteur x, en s'écrasant vers 0, gagne le duel contre le −∞ du logarithme.

Q3 — La fonction ln x est :

A) strictement croissante sur ]0 ; +∞[B) strictement décroissante sur ]0 ; +∞[C) croissante sur ℝ tout entierD) négative sur tout ]0 ; +∞[
Voir la réponse
A) strictement croissante sur ]0 ; +∞[. Sa dérivée 1/x est strictement positive sur ce domaine. L'option D est fausse : ln x est négatif seulement sur ]0 ; 1[, puis positif après 1.
📌 Ce qu'il faut retenir
  • [limites] lim(x→0⁺) ln x = −∞ et lim(x→+∞) ln x = +∞ — justifiées par ln(eⁿ) = n
  • [asymptote] La droite x = 0 (axe des ordonnées) est asymptote verticale à la courbe de ln
  • [variations] (ln x)' = 1/x > 0 : ln est strictement croissante sur ]0 ; +∞[, de −∞ à +∞, en passant par (1 ; 0)
  • [signe] ln x < 0 si 0 < x < 1 ; ln 1 = 0 ; ln x > 0 si x > 1
  • [ordre] ln conserve l'ordre : a < b ⇔ ln a < ln b (pour a, b > 0) — base des inéquations
  • [croissances] (ln x)/x → 0 en +∞ ; x ln x → 0 en 0⁺ ; généralisation avec xⁿ (n ≥ 1)
  • [etude] Plan d'étude : domaine (u > 0) → dérivée (u'/u) → limites → tableau → valeurs remarquables (zéro par exponentielle)
  • [etude] L'asymptote verticale de ln(u(x)) se trouve où u(x) → 0⁺ (ex. x = −2 pour ln(x + 2))
  • [tangente] Tangente en 1 : y = x − 1 ; et ln x ≤ x − 1 pour tout x > 0 (courbe sous sa tangente)
  • [methode] Toute borne de tableau doit être justifiée : limite de référence, signe de la dérivée, passage à l'exponentielle pour le zéro
