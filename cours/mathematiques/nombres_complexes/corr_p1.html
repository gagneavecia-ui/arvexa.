01
Corrigés · Thème 01 · N° 1 → 5

Forme algébrique : lire et écrire

Reconnaître Re(z) et Im(z) après (et seulement après) simplification — le réflexe n° 0 du chapitre.

✏️ Exercice 1 — Lire Re et Im (★)

Rappel : z₁ = 12 − 5i, z₂ = −(2/3)i, z₃ = √2, z₄ = −7 + i.

1

On lit chaque nombre sur la forme a + ib : z₂ = 0 + (−2/3)i ; z₃ = √2 + 0i ; z₄ = −7 + 1i.

2

Résultat : Re(z₁) = 12, Im(z₁) = −5 ; Re(z₂) = 0, Im(z₂) = −2/3 ; Re(z₃) = √2, Im(z₃) = 0 ; Re(z₄) = −7, Im(z₄) = 1.

✏️ Exercice 2 — Sommes et différences (★)
1

Rappel : a) (3 + 2i) + (5 − 7i) ; b) (4 − i) − (6 + 3i) ; c) 2(1 + i) − 3(2 − i). On regroupe réels avec réels et imaginaires avec imaginaires : a) (3 + 5) + (2 − 7)i ; b) (4 − 6) + (−1 − 3)i ; c) 2 + 2i − 6 + 3i.

2

Résultat : a) 8 − 5i ; b) −2 − 4i ; c) −4 + 5i.

✏️ Exercice 3 — Multiplications par i (★)
1

Rappel : a) i(4 + 9i) ; b) −i(6 − 5i) ; c) (1 + i)(1 − i) + 2i. On développe puis on remplace chaque i² par −1 : a) 4i + 9i² = −9 + 4i ; b) −6i + 5i² = −5 − 6i ; c) (1 − i²) + 2i = 2 + 2i.

2

Résultat : a) −9 + 4i ; b) −5 − 6i ; c) 2 + 2i.

✏️ Exercice 4 — Simplifier avant de lire (★★)

Rappel : z₁ = 3i² + 5, z₂ = i³ + i, z₃ = 2i⁴ − 1, z₄ = i⁵ − i.

1

Règle d'or : on simplifie AVANT de lire Re et Im : z₁ = −3 + 5 = 2 ; z₂ = −i + i = 0 ; z₃ = 2 − 1 = 1 ; z₄ = i − i = 0.

2

Résultat : Re(z₁) = 2, Im(z₁) = 0 ; z₂ = 0 ; z₃ = 1 ; z₄ = 0. ⚠️ Piège réussi : les quatre nombres sont des réels purs !

✏️ Exercice 5 — Retrouver a (★★)
1

Rappel : z = (2 + 3i) + (a − i) avec Re(z) = 5. On simplifie : z = (2 + a) + (3 − 1)i = (2 + a) + 2i. La condition porte sur la partie réelle : 2 + a = 5, donc a = 3.

2

Résultat : a = 3 et Im(z) = 2 — la partie imaginaire ne dépend pas de a.

Corrigés · Thème 02 · N° 6 → 10

Puissances de i

Cycle de période 4 : i, −1, −i, 1 — on réduit l'exposant avec le reste de la division euclidienne par 4.

✏️ Exercice 6 — Réduire modulo 4 (★)
1

Rappel : i²³, i⁵⁰, i⁷⁵, i¹⁰¹. On réduit chaque exposant modulo 4 : 23 = 4×5 + 3 → i³ = −i ; 50 = 4×12 + 2 → i² = −1 ; 75 = 4×18 + 3 → −i ; 101 = 4×25 + 1 → i.

2

Résultat : i²³ = −i ; i⁵⁰ = −1 ; i⁷⁵ = −i ; i¹⁰¹ = i.

✏️ Exercice 7 — Coefficient et puissance (★)
1

Rappel : (5i)², (−2i)⁴, (−i)³. On sépare coefficient et puissance de i : (5i)² = 25i² = −25 ; (−2i)⁴ = 16i⁴ = 16 ; (−i)³ = (−i)² × (−i) = (−1) × (−i) = i.

2

Résultat : −25 ; 16 ; i.

✏️ Exercice 8 — Paquets de quatre (★)
1

Rappel : i¹⁸ + i¹⁹ + i²⁰ + i²¹, puis i³² − i³⁰. Quatre puissances consécutives s'annulent (car i + i² + i³ + i⁴ = 0) : la somme vaut 0. Ensuite i³² = (i⁴)⁸ = 1 et i³⁰ = i²⁸ × i² = −1, donc 1 − (−1) = 2.

2

Résultat : 0 et 2.

✏️ Exercice 9 — Deux grandes sommes (★★)
1

Rappel : S = i + i² + … + i⁶⁰ et S' = 1 + i + … + i⁵⁰. On regroupe par paquets de 4 consécutifs, chacun nul : S contient 60 = 4×15 termes, soit 15 paquets nuls → S = 0. S' a 51 termes ; les 48 premiers (i¹ → i⁴⁸) forment 12 paquets nuls ; il reste 1 + i⁴⁹ + i⁵⁰ = 1 + i − 1 = i.

2

Résultat : S = 0 et S' = i.

✏️ Exercice 10 — Quand iⁿ est réel (★★)
1

Rappel : trouver les n, 0 ≤ n ≤ 12, avec iⁿ réel. Selon le reste de n modulo 4 : reste 0 → 1 (réel) ; reste 1 → i (non) ; reste 2 → −1 (réel) ; reste 3 → −i (non). Donc iⁿ est réel si et seulement si n est pair.

2

Résultat : n ∈ {0 ; 2 ; 4 ; 6 ; 8 ; 10 ; 12} — iⁿ = 1 quand n est multiple de 4, iⁿ = −1 sinon.

03
Corrigés · Thème 03 · N° 11 → 15

Réel pur, imaginaire pur

Réel pur ⟺ Im(z) = 0 · Imaginaire pur ⟺ Re(z) = 0 · 0 est les deux à la fois.

✏️ Exercice 11 — Classer cinq nombres (★)
1

Rappel : z₁ = √5, z₂ = √5 i, z₃ = 1 + √2 i, z₄ = i⁶, z₅ = (1 + i)(1 − i). On simplifie d'abord : i⁶ = i⁴ × i² = −1 et (1 + i)(1 − i) = 1 − i² = 2.

2

Résultat : réels purs : z₁, z₄, z₅ ; imaginaire pur : z₂ ; ni l'un ni l'autre : z₃.

✏️ Exercice 12 — Une impossibilité à prouver (★)
1

Rappel : z = (x² + 1) + (x − 2)i. z serait imaginaire pur si Re(z) = 0, c'est-à-dire x² + 1 = 0. Or x² ≥ 0 pour tout réel x, donc x² + 1 ≥ 1 > 0 : la partie réelle ne s'annule jamais.

2

Résultat : z n'est jamais imaginaire pur, quelle que soit la valeur de x.

✏️ Exercice 13 — Deux classements (★★)
1

Rappel : z = x + (x² − 9)i. a) réel pur ⟺ x² − 9 = 0 ⟺ x = 3 ou x = −3, et alors z = 3 ou z = −3. b) imaginaire pur ⟺ x = 0, et alors z = 0 + (0 − 9)i = −9i.

2

Résultat : a) x = ±3 avec z = ±3 ; b) x = 0 avec z = −9i.

✏️ Exercice 14 — Paramètre m (★★)
1

Rappel : z = (m + 1) + (m² − 1)i. a) réel pur ⟺ m² − 1 = 0 ⟺ m = 1 ou m = −1. b) imaginaire pur ⟺ m + 1 = 0 ⟺ m = −1. c) z = 0 exige les deux conditions à la fois : m = −1 convient (vérification : z = 0 + 0i = 0 ✔).

2

Résultat : réel pur : m = ±1 ; imaginaire pur : m = −1 ; z = 0 uniquement pour m = −1.

✏️ Exercice 15 — Vrai ou faux ? (★★)
1

a) FAUX — Im(z) est un réel : Im(3 + 5i) = 5, pas 5i (piège classique). b) VRAI — Re(0) = 0 et Im(0) = 0 : 0 coche les deux définitions. c) VRAI — réel pur donne Im(z) = 0, imaginaire pur donne Re(z) = 0, donc z = 0.

2

Résultat : a) Faux — b) Vrai — c) Vrai.

04
Corrigés · Thème 04 · N° 16 → 20

Premiers calculs : sommes et produits

Développer, remplacer chaque i² par −1, regrouper — et repérer le schéma précieux (a + ib)(a − ib) = a² + b².

✏️ Exercice 16 — Trois produits (★)
1

a) (1 + i)(2 + 3i) = 2 + 3i + 2i + 3i² = −1 + 5i. b) schéma (a − ib)(a + ib) : (3 − 2i)(3 + 2i) = 3² + 2² = 13. c) (2 − i)(1 + 3i) = 2 + 6i − i − 3i² = 5 + 5i.

2

Résultat : a) −1 + 5i ; b) 13 (réel !) ; c) 5 + 5i.

✏️ Exercice 17 — Un cube (★)
1

Rappel : (2 + i)³. On passe par le carré : (2 + i)² = 4 + 4i + i² = 3 + 4i, puis (3 + 4i)(2 + i) = 6 + 3i + 8i + 4i² = 2 + 11i.

2

Résultat : (2 + i)³ = 2 + 11i.

✏️ Exercice 18 — Lettres x et y (★)
1

Rappel : (x + iy)(3 + 2i). Développement : 3x + 2ix + 3iy + 2i²y = 3x − 2y + i(2x + 3y) — partie réelle 3x − 2y, partie imaginaire 2x + 3y.

2

Résultat : (x + iy)(3 + 2i) = (3x − 2y) + (2x + 3y)i.

✏️ Exercice 19 — Le pont (1 + i)² = 2i (★★)

Rappel : calculer (1 + i)⁴, puis en déduire (1 + i)⁸.

1

(1 + i)² = 1 + 2i + i² = 2i, donc (1 + i)⁴ = (2i)² = 4i² = −4.

2

Résultat : (1 + i)⁴ = −4 et (1 + i)⁸ = [(1 + i)⁴]² = (−4)² = 16.

✏️ Exercice 20 — Le schéma précieux (★★)
1

Démonstration : (a + ib)(a − ib) = a² − abi + abi − i²b² = a² + b² ✔. Application avec a = 2√2 et b = √3 : (2√2 − i√3)(2√2 + i√3) = (2√2)² + (√3)² = 8 + 3 = 11.

2

Résultat : le produit vaut 11 — un réel strictement positif, comme toujours avec ce schéma.

05
Corrigés · Thème 05 · N° 21 → 25

Identités remarquables revisitées

(a + ib)² = (a² − b²) + 2iab — développer d'abord, remplacer chaque i² ensuite.

✏️ Exercice 21 — Trois carrés (★)
1

(3 + 2i)² = 9 + 12i + 4i² = 5 + 12i ; (1 − 4i)² = 1 − 8i + 16i² = −15 − 8i ; (−2 + i)² = 4 − 4i + i² = 3 − 4i.

2

Résultat : 5 + 12i ; −15 − 8i ; 3 − 4i.

✏️ Exercice 22 — Somme de deux carrés (★)
1

Rappel : (1 + i)² + (1 − i)². Or (1 + i)² = 2i et (1 − i)² = −2i ; la somme vaut 2i − 2i = 0.

2

Résultat : 0 — la somme des deux carrés conjugués est réelle (nulle ici).

✏️ Exercice 23 — Différence de deux carrés (★★)
1

(2 + i)² = 3 + 4i et (2 − i)² = 3 − 4i, donc z = (3 + 4i) − (3 − 4i) = 8i : imaginaire pur. Vérification : (1 + 3i)² − (1 − 3i)² = (−8 + 6i) − (−8 − 6i) = 12i ✔. Raison : (a + ib)² − (a − ib)² = 4abi, toujours imaginaire pur.

2

Résultat : z = 8i — la différence de deux carrés conjugués est toujours imaginaire pure.

✏️ Exercice 24 — Retrouver un carré (★★)

Rappel : résoudre z² = 3 + 4i.

1

On cherche a, b réels avec a² − b² = 3 et 2ab = 4, soit ab = 2. Essai (a, b) = (2, 1) : ab = 2 ✔ et a² − b² = 4 − 1 = 3 ✔, donc (2 + i)² = 3 + 4i.

2

Résultat : z = 2 + i ou z = −2 − i — un carré a toujours deux solutions opposées.

✏️ Exercice 25 — Carré réel pur (★★)
1

(a + ib)² = (a² − b²) + 2abi : réel pur ⟺ 2ab = 0 ⟺ a = 0 ou b = 0. Si b = 0, z était réel et z² = a² ≥ 0 ; si a = 0, z = ib est imaginaire pur et z² = −b² ≤ 0.

2

Résultat : (a + ib)² est réel pur ⟺ a = 0 ou b = 0 — et dans le cas a = 0, le carré est un réel négatif ou nul.

Corrigés · Thème 06 · N° 26 → 30

Égalité : identification directe

a + ib = a' + ib' ⟺ a = a' ET b = b' — une équation complexe donne DEUX équations réelles.

✏️ Exercice 26 — Identification simple (★)
1

Rappel : (2x + 5) + (3y − 1)i = 11 + 8i. Identification : 2x + 5 = 11 → x = 3 et 3y − 1 = 8 → y = 3. Vérification : (2×3 + 5) + (3×3 − 1)i = 11 + 8i ✔.

2

Résultat : x = 3 et y = 3.

✏️ Exercice 27 — Deux couples (★)
1

Rappel : (x² + 3) + (2y + 1)i = 12 + 7i. identification : x² + 3 = 12 → x² = 9 → x = 3 ou x = −3 ; 2y + 1 = 7 → y = 3. L'équation en x étant du second degré, deux couples apparaissent.

2

Résultat : (x ; y) = (3 ; 3) ou (−3 ; 3).

✏️ Exercice 28 — Système symétrique (★★)
1

Rappel : (x + y) + (x − y)i = 4 + 2i. Système : x + y = 4 et x − y = 2 ; en additionnant : 2x = 6 → x = 3, puis y = 4 − 3 = 1. Vérification : (3 + 1) + (3 − 1)i = 4 + 2i ✔.

2

Résultat : x = 3 et y = 1.

✏️ Exercice 29 — Système avec fractions (★★)
1

Rappel : (2x − y) + (x + 2y)i = −1 + 5i. Système : 2x − y = −1 et x + 2y = 5. De la première : y = 2x + 1 ; report : x + 4x + 2 = 5 → 5x = 3 → x = 3/5, puis y = 6/5 + 1 = 11/5. Vérification : 2(3/5) − 11/5 = −1 ✔ et 3/5 + 22/5 = 5 ✔.

2

Résultat : x = 3/5 et y = 11/5.

✏️ Exercice 30 — Égalité à zéro (★★)
1

Rappel : (x + y) + (x − y)i = 0. Système : x + y = 0 et x − y = 0 ; en additionnant : 2x = 0 → x = 0, puis y = 0. Propriété du cours retrouvée : z = 0 ⟺ Re(z) = 0 ET Im(z) = 0.

2

Résultat : seul le couple (0 ; 0) convient.

Corrigés · Thème 07 · N° 31 → 35

Équations (α + iβ)z = γ + iδ

Le réflexe n° 1 du chapitre : poser z = x + iy, développer, identifier, résoudre le système 2 × 2, vérifier.

✏️ Exercice 31 — Première équation (★★)

Rappel : résoudre dans ℂ (2 + i)z = 7 + i.

1

On pose z = x + iy : (2 + i)(x + iy) = (2x − y) + i(x + 2y) = 7 + i. Système : 2x − y = 7 et x + 2y = 1. De la première : y = 2x − 7 ; report : x + 4x − 14 = 1 → 5x = 15 → x = 3, puis y = −1.

2

Vérification : (2 + i)(3 − i) = 6 − 2i + 3i − i² = 7 + i ✔.

3

Résultat : z = 3 − i.

✏️ Exercice 32 — Membre droit réel (★★)
1

Rappel : (1 + 2i)z = 5, c'est-à-dire 5 + 0i. (1 + 2i)(x + iy) = (x − 2y) + i(2x + y) → x − 2y = 5 et 2x + y = 0. De la seconde : y = −2x ; report : x + 4x = 5 → x = 1, puis y = −2. Vérification : (1 + 2i)(1 − 2i) = 1 + 4 = 5 ✔ (schéma a² + b²).

2

Résultat : z = 1 − 2i.

✏️ Exercice 33 — Solutions fractionnaires (★★)
1

Rappel : (3 − i)z = 10 − 5i. (3 − i)(x + iy) = (3x + y) + i(3y − x) → 3x + y = 10 et 3y − x = −5. De la première : y = 10 − 3x ; report : 30 − 9x − x = −5 → −10x = −35 → x = 7/2, puis y = 10 − 21/2 = −1/2. Vérification : (3 − i)(7/2 − i/2) = 21/2 − 3i/2 − 7i/2 + i²/2 = 10 − 5i ✔.

2

Résultat : z = 7/2 − (1/2)i.

✏️ Exercice 34 — Combinaison linéaire (★★)
1

Rappel : (2 + 3i)z = 5 + 14i. (2 + 3i)(x + iy) = (2x − 3y) + i(3x + 2y) → 2x − 3y = 5 et 3x + 2y = 14. Combinaison : 2 × (1re) donne 4x − 6y = 10 ; 3 × (2e) donne 9x + 6y = 42 ; somme : 13x = 52 → x = 4, puis 2y = 14 − 12 = 2 → y = 1. Vérification : (2 + 3i)(4 + i) = 8 + 2i + 12i − 3 = 5 + 14i ✔.

2

Résultat : z = 4 + i.

✏️ Exercice 35 — Le cas iz = γ + iδ (★★)
1

Rappel : iz = 3 − 4i. i(x + iy) = ix + i²y = −y + ix = 3 − 4i, donc −y = 3 → y = −3 et x = −4. Vérification : i(−4 − 3i) = −4i + 3 = 3 − 4i ✔.

2

Résultat : z = −4 − 3i.

Corrigés · Thème 08 · N° 36 → 40

Carrés z² = k et systèmes

L'identification complète : poser z = x + iy, développer z², identifier — et savoir lire l'issue du système.

✏️ Exercice 36 — Carré d'un imaginaire (★★)
1

Rappel : z² = −9. (x² − y²) + 2xyi = −9 + 0i → x² − y² = −9 et 2xy = 0. Si y = 0 : x² = −9 impossible dans ℝ ; donc x = 0 et −y² = −9 → y = ±3. Vérification : (3i)² = −9 ✔ et (−3i)² = −9 ✔.

2

Résultat : z = 3i ou z = −3i — deux solutions opposées, comme pour toute équation z² = k négatif.

✏️ Exercice 37 — Carré de même signe (★★)
1

Rappel : z² = 8i. x² − y² = 0 et 2xy = 8, soit xy = 4 > 0 : x et y de même signe → y = x. Alors 2x² = 8 → x = ±2 et y = x. Vérification : (2 + 2i)² = 4 + 8i − 4 = 8i ✔.

2

Résultat : z = 2 + 2i ou z = −2 − 2i.

✏️ Exercice 38 — Signes opposés (★★★)

Rappel : résoudre dans ℂ z² = −5i.

1

x² − y² = 0 et 2xy = −5, soit xy = −5/2 < 0 : x et y de signes opposés → y = −x. Alors −2x² = −5 → x² = 5/2, donc x = ±√10/2 (car √(5/2) = √10/2), et y = −x.

2

Vérification : [(√10/2)(1 − i)]² = (10/4)(1 − 2i + i²) = (5/2)(−2i) = −5i ✔.

3

Résultat : z = (√10/2)(1 − i) ou z = −(√10/2)(1 − i).

✏️ Exercice 39 — Retour aux équations (★★)
1

Rappel : (1 − i)z = 8 + 4i. (1 − i)(x + iy) = x + iy − ix − i²y = (x + y) + i(y − x) → x + y = 8 et y − x = 4. Somme : 2y = 12 → y = 6, puis x = 2. Vérification : (1 − i)(2 + 6i) = 2 + 6i − 2i + 6 = 8 + 4i ✔.

2

Résultat : z = 2 + 6i.

✏️ Exercice 40 — Système impossible (★★)
1

Rappel : x − y = 2 et 2x − 2y = 5. En multipliant la première par 2 : 2x − 2y = 4, mais la seconde exige 2x − 2y = 5 : contradiction (4 ≠ 5). Géométriquement : deux droites strictement parallèles, aucun point d'intersection.

2

Résultat : aucun couple ne convient — une équation complexe dont l'identification mène à ce système n'a aucune solution.

Corrigés · Thème 09 · N° 41 → 45

Paramètre m : classification et égalité

Quand les parties dépendent d'un réel m, chaque condition (réel pur, imaginaire pur, égalité) devient une équation en m.

✏️ Exercice 41 — Conditions linéaires (★★)
1

Rappel : z = (m − 3) + (2m + 1)i. a) réel pur ⟺ 2m + 1 = 0 ⟺ m = −1/2 (et alors z = −7/2). b) imaginaire pur ⟺ m − 3 = 0 ⟺ m = 3. c) pour m = 3 : z = 0 + 7i = 7i ✔.

2

Résultat : réel pur : m = −1/2 ; imaginaire pur : m = 3 ; z(3) = 7i.

✏️ Exercice 42 — Conditions quadratiques (★★)
1

Rappel : z = (m² − 1) + (m + 1)i. a) réel pur ⟺ m + 1 = 0 ⟺ m = −1. b) imaginaire pur ⟺ m² − 1 = 0 ⟺ m = 1 ou m = −1. c) les deux à la fois ⟺ m = −1, et alors z = 0 — 0 est le seul nombre à la fois réel pur et imaginaire pur.

2

Résultat : réel pur : m = −1 ; imaginaire pur : m = ±1 ; pour m = −1, z = 0.

✏️ Exercice 43 — Deux exigences contradictoires (★★)
1

Rappel : (2m + 1) + (3m − 2)i = 5 − i. Partie réelle : 2m + 1 = 5 → m = 2. Partie imaginaire : 3m − 2 = −1 → m = 1/3. Il faudrait m = 2 ET m = 1/3 en même temps : impossible — un seul paramètre ne peut pas satisfaire deux exigences contradictoires.

2

Résultat : aucun réel m ne convient — l'égalité est impossible pour tout m.

✏️ Exercice 44 — Factoriser pour conclure (★★★)

Rappel : z = (m² − 2m + 1) + (m² + m − 2)i.

1

Factorisations : m² − 2m + 1 = (m − 1)² et m² + m − 2 = (m + 2)(m − 1), donc z = (m − 1)² + (m + 2)(m − 1)i. b) réel pur ⟺ (m + 2)(m − 1) = 0 ⟺ m = −2 ou m = 1. c) imaginaire pur ⟺ (m − 1)² = 0 ⟺ m = 1.

2

d) Pour m = 1 : z = 0 + 0i = 0, à la fois réel pur et imaginaire pur ; pour m = −2 : z = 9 + 0i = 9, réel pur non nul.

3

Résultat : réel pur : m ∈ {−2 ; 1} ; imaginaire pur : m = 1 ; pour m = 1, z = 0.

✏️ Exercice 48 — Défi : le produit astucieux (★★★)
1

Rappel : A = (2 + i)(2 − i)(3 + i)(3 − i). On regroupe par paires conjuguées : (2 + i)(2 − i) = 2² + 1² = 5 et (3 + i)(3 − i) = 3² + 1² = 10, donc A = 5 × 10 = 50 : un entier, sans aucun développement.

2

Résultat : A = 50 — le schéma précieux (a + ib)(a − ib) = a² + b² transforme le produit en entiers.

✏️ Exercice 49 — Défi : équation à deux inconnues (★★★)
1

Rappel : (x + iy)(1 − i) = (1 + i)(2 + 3i). Droite : (1 + i)(2 + 3i) = 2 + 3i + 2i + 3i² = −1 + 5i. Gauche : (x + iy)(1 − i) = x − ix + iy − i²y = (x + y) + i(y − x). Identification : x + y = −1 et y − x = 5 ; somme : 2y = 4 → y = 2, puis x = −3. Vérification : (−3 + 2i)(1 − i) = −3 + 3i + 2i + 2 = −1 + 5i ✔.

2

Résultat : z = −3 + 2i.

✏️ Exercice 50 — Grand défi final (★★★)

Rappel : z = x + iy et w = z² + 2z.

1

a) z² = (x² − y²) + 2xyi et 2z = 2x + 2yi, donc w = (x² − y² + 2x) + i(2xy + 2y) : Re(w) = x² − y² + 2x et Im(w) = 2xy + 2y ✔.

2

b) w réel pur ⟺ Im(w) = 0 ⟺ 2xy + 2y = 0 ⟺ 2y(x + 1) = 0 ⟺ y = 0 ou x = −1.

3

Résultat : w est réel pur si et seulement si y = 0 (z réel quelconque) ou x = −1 (z = −1 + iy, la droite verticale d'abscisse −1).
