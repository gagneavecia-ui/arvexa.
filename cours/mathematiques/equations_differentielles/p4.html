Accroche

Trois équations, un seul squelette

Les parties 1 à 3 ont construit trois théorèmes, un par type d'équation. Mais au Bac, on ne te demande pas « quel théorème ? » : on te donne une équation et tu dois savoir par où commencer. Bonne nouvelle : les trois types partagent exactement le même squelette.

La structure de toutes les solutions du chapitre
y = yₚ + Ce^(ax) (C ∈ ℝ)
Une solution particulière yₚ (qui dépend du second membre) plus les solutions homogènes Ce^(ax) — dont l'exposant est toujours le coefficient a de l'équation.
Type d'équationSolution particulièreExemple
y' = ayyₚ = 0y' = 3y → y = Ce^(3x)
y' = ay + b (a ≠ 0)yₚ = −b/a (constante)y' = 2y + 4 → y = Ce^(2x) − 2
y' = ay + f(x)yₚ par identificationy' = y + e^(2x) → yₚ + Ce^x
⚠️ Deux confusions à bannir dès la première ligne

(1) Appliquer la condition initiale avant d'avoir écrit la solution générale : on calcule C après la somme yₚ + Ce^(ax), jamais avant. (2) Rendre une réponse qui contient encore C quand une condition initiale était donnée : la solution unique ne contient aucune lettre C.

01
Méthode

La méthode universelle en 4 étapes

Une seule compétence est évaluée, sous trois habillages : écrire une famille de solutions, en extraire celle qui vérifie une donnée. Les différences entre les trois types se concentrent dans une seule étape — la fabrication de yₚ — tandis que le squelette, l'ordre des 4 étapes et la vérification finale restent identiques.

1

Homogène : écrire les solutions de y' = ay, c'est-à-dire Ce^(ax) — c'est le squelette commun.

2

Particulière : trouver yₚ — la constante −b/a si le second membre est b, l'identification si c'est f(x).

3

Somme : écrire la solution générale y = yₚ + Ce^(ax), C ∈ ℝ.

4

Condition initiale : substituer, calculer C, conclure — puis vérifier en redérivant.

🧮 La méthode en action — résoudre y' = 2y + 8 avec y(0) = 5
1

Homogène : ici a = 2, donc y_h = Ce^(2x).

2

Particulière (constante) : yₚ = −b/a = −8/2 = −4.

3

Somme : y = Ce^(2x) − 4, C ∈ ℝ.

4

Condition initiale : y(0) = C·e⁰ − 4 = C − 4 ; la condition impose C − 4 = 5, donc C = 9. Solution unique : y = 9e^(2x) − 4.

5

Vérification : y' = 18e^(2x) et 2y + 8 = 18e^(2x) − 8 + 8 = 18e^(2x) : l'égalité vaut pour tout x ; et y(0) = 9 − 4 = 5 ✓

Le comportement à l'infini — une question d'argumentation fréquente

Tout se joue sur lim e^(ax), donc sur le signe de a :

  • a < 0 : lim e^(ax) = 0, donc lim y = yₚ — convergence. Le terme Ce^(ax) est le transitoire, ce qui reste (yₚ) est le régime permanent : la droite y = yₚ est asymptote à toutes les solutions.
  • a > 0 : lim e^(ax) = +∞, donc divergence (si C ≠ 0) — ne jamais annoncer de convergence.
La rédaction attendue au Bac

« Les solutions de y' = ay sont Ce^(ax) » ; « une solution particulière est … » ; « donc les solutions sont y = yₚ + Ce^(ax), C ∈ ℝ » ; substitution de la condition ; valeur de C ; solution unique ; vérification en deux lignes. Chaque étape sautée coûte, même si le résultat final est juste.

02
La constante C

La condition initiale en profondeur

Une infinité de solutions, c'est trop pour la physique : une population a une valeur de départ, un échantillon une masse initiale. Les quatre formules ci-dessous cachent une seule et même équation : yₚ(x₀) + Ce^(ax₀) = y₀. On note y₀ la valeur imposée : y(x₀) = y₀.

SituationLa constante CLa solution unique
y' = ay, y(x₀) = y₀C = y₀·e^(−ax₀)y = y₀·e^(a(x − x₀))
y' = ay + b, y(0) = y₀C = y₀ + b/ay = (y₀ + b/a)·e^(ax) − b/a
y' = ay + b, y(x₀) = y₀C = (y₀ + b/a)·e^(−ax₀)y = (y₀ + b/a)·e^(a(x−x₀)) − b/a
y' = ay + f(x), y(x₀) = y₀C = (y₀ − yₚ(x₀))·e^(−ax₀)y = yₚ + (y₀ − yₚ(x₀))·e^(a(x−x₀))
1

Démonstration (cas y' = ay + b, condition en x₀) — on part de la solution générale : y(x) = Ce^(ax) − b/a.

2

On substitue x₀ : Ce^(ax₀) − b/a = y₀, donc Ce^(ax₀) = y₀ + b/a.

3

On multiplie par e^(−ax₀) — permis car une exponentielle n'est jamais nulle : C = (y₀ + b/a)·e^(−ax₀).

4

On reporte et on simplifie : y(x) = (y₀ + b/a)·e^(a(x − x₀)) − b/a. Contrôle : y(x₀) = y₀ + b/a − b/a = y₀ ✓

La formule universelle — une seule démonstration pour les trois types
C = (y₀ − yₚ(x₀)) · e^(−ax₀)
Pour y' = ay : yₚ = 0, donc C = y₀·e^(−ax₀) ; pour y' = ay + b : yₚ = −b/a, donc C = (y₀ + b/a)·e^(−ax₀). Une formule à retenir, trois cas à lire.
🧮 Exemple 1 — condition en x₀ ≠ 0 : résoudre y' = −2y + 8 avec y(2) = 5
1

Particulière : yₚ = −8/(−2) = 4 ; solution générale : y = Ce^(−2x) + 4.

2

Substitution en 2 : y(2) = Ce^(−4) + 4 = 5, donc Ce^(−4) = 1.

3

Résolution de C : en multipliant par e⁴ : C = e⁴ = (5 − 4)·e^(−(−2)×2) — exactement la formule C = (y₀ + b/a)·e^(−ax₀) avec y₀ = 5, b/a = −4, x₀ = 2.

4

Solution unique : y = e⁴·e^(−2x) + 4 = e^(4 − 2x) + 4.

5

Vérification : y' = −2e^(4−2x) et −2y + 8 = −2e^(4−2x) ✓ ; et y(2) = e⁰ + 4 = 5 ✓

🧮 Exemple 2 — second membre variable : y' = y + e^(2x) avec y(1) = 2
1

Particulière (partie 3, μ = 2 ≠ a = 1) : yₚ = e^(2x) ; solution générale : y = Ce^x + e^(2x).

2

Substitution en 1 : y(1) = Ce + e² = 2, donc C = (2 − e²)·e^(−1) — la formule universelle avec y₀ = 2, yₚ(1) = e², x₀ = 1, a = 1.

3

Solution unique : y = (2 − e²)·e^(x − 1) + e^(2x). Vérification : y' = (2 − e²)e^(x−1) + 2e^(2x) et y + e^(2x) = (2 − e²)e^(x−1) + 2e^(2x) ✓ ; y(1) = 2 − e² + e² = 2 ✓

🧮 À toi de jouer — y' = 3y + 6 avec y(1) = 10, par la formule directe

yₚ = −6/3 = −2 ; solution générale y = Ce^(3x) − 2. Ici y₀ = 10, b/a = 2, x₀ = 1, donc C = (10 + 2)·e^(−3) = 12e^(−3). Solution unique : y = 12e^(3(x−1)) − 2. Vérification : y' = 36e^(3(x−1)) et 3y + 6 = 36e^(3(x−1)) ✓ ; y(1) = 12 − 2 = 10 ✓

Le facteur e^(−ax₀) oublié — l'erreur classique en x₀ ≠ 0

En x₀ = 0 on a le droit d'écrire y(0) = C + yₚ(0) car e⁰ = 1. Mais en x₀ ≠ 0, écrire « C = y₀ + b/a » est faux : il manque le facteur e^(−ax₀). Test minute : substitue x₀ dans ta solution unique — si tu n'obtiens pas y₀, ton C est faux. Autre glissement : oublier le signe de b/a quand a < 0 (pour y' = −2y + 8 : b/a = −4, pas 4).

03
Théorème + sécurité

Unicité de la solution et contrôle systématique

Existence et unicité — le théorème complet du chapitre

Soit a un réel, f une fonction continue, yₚ une solution particulière de y' = ay + f(x), et (x₀ ; y₀) un couple de réels donné. Il existe une seule fonction solution vérifiant y(x₀) = y₀ : c'est

y(x) = yₚ(x) + (y₀ − yₚ(x₀))·e^(a(x − x₀))

1

Démonstration de l'unicité — supposons que deux solutions y₁ et y₂ passent par (x₀ ; y₀). Posons w = y₁ − y₂ ; en soustrayant les équations membre à membre, f(x) s'élimine :

w' = (ay₁ + f(x)) − (ay₂ + f(x)) = aw

2

w est solution de l'équation homogène : w = Ce^(ax) (partie 1).

3

Or w(x₀) = y₀ − y₀ = 0, donc Ce^(ax₀) = 0 ; comme e^(ax₀) ≠ 0, C = 0 et w = 0 : y₁ = y₂ partout. ∎

Le contrôle systématique — les 4 filtres à faire passer à toute solution
  • L'équation : dériver ta solution, calculer ay + f(x), comparer — l'égalité doit valoir pour tout x ;
  • La condition initiale : substituer x₀ dans la solution unique — on doit retrouver y₀ exactement ;
  • L'exposant : l'exponentielle restante est e^(ax), avec le coefficient a de l'équation ;
  • La cohérence : si a < 0, la solution doit converger vers yₚ ; les signes doivent être plausibles (une population positive, une température qui tend vers celle de la pièce…).
🔍 L'unicité en action — trois candidats, une seule vraie solution

On résout y' = −2y + 8 avec y(0) = 5. Trois fonctions sont proposées : y₁ = e^(−2x) + 4, y₂ = 5e^(−2x), y₃ = 5e^(−2x) + 4.

1

Test de y₁ : y₁' = −2e^(−2x) et −2y₁ + 8 = −2e^(−2x) ✓ ; y₁(0) = 1 + 4 = 5 ✓ ; exposant −2 = a ✓ ; convergence vers 4 = yₚ ✓. Par unicité, c'est la solution.

2

Test de y₂ : y₂(0) = 5 ✓ mais y₂' = −10e^(−2x) tandis que −2y₂ + 8 = −10e^(−2x) + 8 ≠ y₂' : l'équation échoue (écart constant de 8). Rejetée.

3

Test de y₃ : de la forme Ce^(−2x) + 4, donc l'équation est vérifiée ✓ — mais y₃(0) = 5 + 4 = 9 ≠ 5 : la condition initiale échoue. Rejetée.

Morale : équation et condition — les deux filtres doivent passer. Conséquence graphique : deux courbes solutions du chapitre ne se croisent jamais.

Le contrôle qui ne prouve rien

Tester la solution sur deux ou trois valeurs de x ne prouve rien : deux fonctions différentes peuvent coïncider en quelques points. L'égalité y' = ay + f(x) s'établit pour tout x, par le calcul littéral. Et « vérifier » la condition initiale sur la solution générale (qui contient encore C) n'a pas de sens : le filtre s'applique à la solution unique.

04
Théorème central

La superposition démontrée

La partie 3 a annoncé le théorème de structure ; ici nous le vérifions intégralement, chaque ligne de calcul posée. Soient a un réel, f continue, yₚ une solution particulière de y' = ay + f(x) : (1) pour tout réel C, y = yₚ + Ce^(ax) est solution ; (2) toute solution s'écrit de cette forme ; (3) la seule solution vérifiant y(x₀) = y₀ s'obtient pour C = (y₀ − yₚ(x₀))·e^(−ax₀).

1

On pose y = yₚ + Ce^(ax) et on dérive terme à terme : y' = yₚ' + aCe^(ax).

2

On calcule le second membre en distribuant : ay + f(x) = a·yₚ + aCe^(ax) + f(x).

3

On compare. Par définition de yₚ, yₚ' = a·yₚ + f(x), donc :

y' = (a·yₚ + f(x)) + aCe^(ax) = ay + f(x)

Les deux membres sont égaux pour tout x : la somme est solution ✓ — le terme aCe^(ax) apparaît des deux côtés : le transitoire traverse l'équation sans laisser de trace.

4

La condition initiale fixe C : yₚ(x₀) + Ce^(ax₀) = y₀ donne C = (y₀ − yₚ(x₀))·e^(−ax₀), et par unicité aucune autre solution ne passe par (x₀ ; y₀). ∎

🧮 Superposition complète pas à pas — y' = 2y + e^x + cos x avec y(0) = 0
1

Découper le second membre : f = f₁ + f₂ avec f₁(x) = e^x et f₂(x) = cos x ; on traite chaque morceau séparément — avec le même a = 2.

2

Particulière pour f₁ : μ = 1 ≠ a = 2, on pose yₚ₁ = λ·e^x ; substitution dans y' = 2y + e^x : λe^x = 2λe^x + e^x, donc λ = −1 : yₚ₁ = −e^x.

3

Particulière pour f₂ : on pose yₚ₂ = A·cos x + B·sin x, donc yₚ₂' = −A·sin x + B·cos x. Substitution dans y' = 2y + cos x :

−A·sin x + B·cos x = 2A·cos x + 2B·sin x + cos x

4

Identification coefficient par coefficient — les cos x : B = 2A + 1 ; les sin x : −A = 2B, donc A = −2B. Report : B = −4B + 1, donc B = 1/5 et A = −2/5 :

yₚ₂ = −(2/5)·cos x + (1/5)·sin x

5

Superposer : yₚ = −e^x − (2/5)·cos x + (1/5)·sin x, puis solution générale :

y = Ce^(2x) − e^x − (2/5)·cos x + (1/5)·sin x

6

Condition initiale : y(0) = C − 1 − 2/5 + 0 = C − 7/5 = 0, donc C = 7/5 :

y = (7/5)·e^(2x) − e^x − (2/5)·cos x + (1/5)·sin x

7

Vérification : y' = (14/5)e^(2x) − e^x + (2/5)sin x + (1/5)cos x et 2y + e^x + cos x = (14/5)e^(2x) − e^x + (1/5)cos x + (2/5)sin x ✓ ; y(0) = 7/5 − 1 − 2/5 = 0 ✓

⚠️ Trois facilités interdites dans la superposition

(1) Multiplier les solutions particulières au lieu de les additionner : la structure est linéaire, pas multiplicative. (2) Changer le coefficient a d'un morceau à l'autre : les deux particulières vivent dans des équations qui ont le même a. (3) Oublier d'ajouter Ce^(ax) à la fin : sans le terme homogène, la condition initiale sera insoluble en général.

🧮 Identification degré 3, coefficient par coefficient — y' = y + x³
1

Poser (polynôme de degré 3, complet) : yₚ = Ax³ + Bx² + Cx + D, donc yₚ' = 3Ax² + 2Bx + C.

2

Substituer dans y' = y + x³ et ranger par degrés :

3Ax² + 2Bx + C = (A + 1)·x³ + Bx² + Cx + D

3

Identifier coefficient par coefficient : les x³ : 0 = A + 1, donc A = −1 ; les x² : 3A = B, donc B = −3 ; les x : 2B = C, donc C = −6 ; les constantes : C = D, donc D = −6.

4

Conclure et vérifier : yₚ = −x³ − 3x² − 6x − 6 ; yₚ' = −3x² − 6x − 6 et yₚ + x³ = −3x² − 6x − 6 ✓

5

Solution générale : y = Ce^x − x³ − 3x² − 6x − 6. Et avec y(0) = 1 : C − 6 = 1, donc C = 7, d'où y = 7e^x − x³ − 3x² − 6x − 6.

🧮 Le cas piège revisité — y' = −y + 4e^(−x)
1

Comparer les exposants : ici a = −1 et μ = −1 : μ = a — cas piège ! La forme λ·e^(−x) est bloquée (elle donnerait l'absurdité 0 = 4) ; on prend yₚ = λ·x·e^(−x) avec λ = k = 4.

2

Vérifier la formule : yₚ' = 4e^(−x) − 4x·e^(−x) (produit) et −yₚ + 4e^(−x) = −4x·e^(−x) + 4e^(−x) ✓ — les deux membres coïncident.

3

Solution générale : y = Ce^(−x) + 4x·e^(−x) = (C + 4x)·e^(−x) — un facteur polynomial qui croît linéairement, multiplié par l'exponentielle décroissante.

🧮 Trigonométrie avec fréquence β = 2 — y' = 3y + cos(2x)
1

Poser la paire (même fréquence que f) : yₚ = A·cos(2x) + B·sin(2x), donc yₚ' = −2A·sin(2x) + 2B·cos(2x).

2

Substituer dans y' = 3y + cos(2x) :

−2A·sin(2x) + 2B·cos(2x) = 3A·cos(2x) + 3B·sin(2x) + cos(2x)

3

Identifier : les cos(2x) : 2B = 3A + 1 ; les sin(2x) : −2A = 3B, donc A = −(3/2)B. Report : 2B = −(9/2)B + 1, donc B = 2/13 et A = −3/13 :

yₚ = −(3/13)·cos(2x) + (2/13)·sin(2x)

4

Vérification : yₚ' = (6/13)sin(2x) + (4/13)cos(2x) et 3yₚ + cos(2x) = (4/13)cos(2x) + (6/13)sin(2x) ✓

🧮 À toi de jouer — degré 2 avec a négatif : y' = −y + x²

On pose yₚ = Ax² + Bx + C, donc yₚ' = 2Ax + B. Substitution : 2Ax + B = (1 − A)x² − Bx − C. Identification : les x² : A = 1 ; les x : 2A = −B, donc B = −2 ; les constantes : B = −C, donc C = 2. D'où yₚ = x² − 2x + 2. Vérification : yₚ' = 2x − 2 et −yₚ + x² = 2x − 2 ✓ — solution générale : y = Ce^(−x) + x² − 2x + 2.

Trois façons de faire dérailler l'identification

(1) Choisir la forme avant de comparer μ et a : poser λ·e^(μx) alors que μ = a mène à l'absurdité 0 = k — ce n'est pas une erreur de calcul, c'est la forme qui est fausse : passer à λ·x·e^(ax). (2) Polynôme incomplet : pour y' = y + x³, poser Ax³ seul échoue — la dérivée fabrique du x² qu'il faut absorber. (3) Fréquence changée : pour f = cos(2x), chercher A·cos x + B·sin x est mort-né — les fréquences doivent coïncider.

06
Application reine

Radioactivité et demi-vie

L'application reine du chapitre — et la compétence évaluée : traduire un énoncé en français en équation différentielle, résoudre, utiliser la condition initiale, puis répondre à la question posée.

La démarche de modélisation — les 5 temps qui rapportent les points
  • Nommer l'inconnue et l'unité de temps : « soit N(t) le nombre de noyaux à l'instant t (en jours) » ;
  • Traduire chaque phrase en un terme : « la vitesse de désintégration est proportionnelle à la quantité présente » → N' = −λN (le signe −, car N diminue) ;
  • Résoudre : N(t) = Ce^(−λt) ;
  • Condition initiale : N(0) = N₀ donne C = N₀ ;
  • Répondre : valeur ou temps demandé, conclure par une phrase, avec les unités.
N' = −λN (λ > 0) ⇒ N(t) = N₀·e^(−λt)
Fonction décroissante (a = −λ < 0), qui ne s'annule jamais et tend vers 0 : il reste toujours un peu de matière.
1

Démonstration de la demi-vie — par définition, t₁/₂ est le temps au bout duquel la moitié des noyaux s'est désintégrée : N(t₁/₂) = N₀/2.

2

On remplace N par son expression et on simplifie par N₀ > 0 :

N₀·e^(−λ·t₁/₂) = N₀/2 ⇔ e^(−λ·t₁/₂) = 1/2 = e^(−ln 2)

3

On applique ln (strictement croissante, donc l'équivalence est valide) : −λ·t₁/₂ = −ln 2, d'où la formule :

La demi-vie — et sa réciproque
t₁/₂ = (ln 2)/λ ⇔ λ = (ln 2)/t₁/₂
t₁/₂ ne dépend pas de N₀ : tous les échantillons d'un même corps ont la même demi-vie.
N(t) = N₀·2^(−t/t₁/₂) ; après n demi-vies : N = N₀/2ⁿ
Réécriture démontrée : en reportant λ = (ln 2)/t₁/₂, on factorise e^(−λt) = (e^(ln 2))^(−t/t₁/₂) = 2^(−t/t₁/₂). Contrôle : N(t₁/₂) = N₀·2⁻¹ = N₀/2 ✓

Question à palier non entier : au bout de combien de temps reste-t-il 25 g ? On résout 80 × 2^(−t/5730) = 25 :

🧮 La datation au carbone 14 — un os ne contient plus que 30 % du carbone initial
1

Traduire : « 30 % du carbone initial » → N(t) = 0,3·N₀, donc e^(−λt) = 0,3, d'où t = ln(10/3)/λ.

2

Exploiter la demi-vie : 1/λ = t₁/₂/(ln 2), donc t = 5 730 × ln(10/3)/ln 2 ≈ 9 953 ans.

3

Contrôle de bon sens : 30 %, c'est moins qu'après une demi-vie (50 %) mais plus qu'après deux (25 %) — un âge entre 5 730 et 11 460 ans ✓. C'est exactement ainsi qu'on date les vestiges archéologiques.

⚠️ Les pièges de la demi-vie

(1) Inventer une « durée de vie totale » : il n'y en a pas — la décroissance est exponentielle. (2) Croire le nombre de demi-vies toujours entier : pour 0,3·N₀ il faut résoudre avec ln — le résultat n'est pas un multiple rond de t₁/₂. (3) Oublier les unités de λ : « par an » ou « par jour », en cohérence avec t. (4) Signe du modèle : N' = −λN avec λ > 0 ; écrire N' = λN décrirait une croissance.

Modélisation

Refroidissement, réservoir et croissance

Trois problèmes classiques du Bac, résolus de l'énoncé brut à la phrase finale. Le squelette est le même (y' = ay + b) ; ce qui change, c'est la traduction — et c'est elle qu'on travaille.

Phrase de l'énoncéTraduction
« la vitesse de variation est proportionnelle à la quantité »terme ay (a > 0 : croissance, a < 0 : décroissance)
« il fuit / se refroidit : x % du contenu par unité de temps »terme −c·y avec c = x/100
« on ajoute / verse d unités par unité de temps »terme constant +d
« il converge vers / se stabilise à L »L = −b/a, la valeur d'équilibre
« au bout de combien de temps atteint-il v ? »résoudre y(t) = v avec ln
Temps de passage : yₚ + (y₀ − yₚ)·e^(at) = v ⇔ t = (1/a) · ln((v − yₚ)/(y₀ − yₚ))
Le quotient doit être > 0 ; quand a < 0, cela signifie que v est compris entre yₚ et y₀. Contrôle : pour v = y₀, le quotient vaut 1 et ln 1 = 0, donc t = 0 ✓
🧮 Application 1 — la loi de refroidissement de Newton, complète

À t = 0, un liquide est à 100 °C dans une pièce maintenue à 15 °C. Après 20 minutes, il est à 60 °C.

1

Traduire : « il refroidit d'autant plus vite que l'écart avec la pièce est grand » → T' = −k(T − 15) avec k > 0, soit T' = −kT + 15k (équilibre −b/a = 15 : la température de la pièce, logique). Solution générale : T(t) = Ce^(−kt) + 15 ; T(0) = 100 donne C = 85 :

T(t) = 15 + 85·e^(−kt)

2

Exploiter T(20) = 60 :

15 + 85·e^(−20k) = 60 ⇔ e^(−20k) = 45/85 = 9/17 ⇔ k = (1/20)·ln(17/9) ≈ 0,032 min⁻¹

3

À 40 minutes : e^(−40k) = (e^(−20k))² = (9/17)² = 81/289, donc

T(40) = 15 + 85 × 81/289 ≈ 38,8 °C

4

Temps de passage à 30 °C :

15 + 85·e^(−kt) = 30 ⇔ e^(−kt) = 15/85 = 3/17 ⇔ t = 20 × ln(17/3)/ln(17/9) ≈ 54,5 min

5

Vérification et conclusion : T' = −85k·e^(−kt) et −k(T − 15) = −85k·e^(−kt) ✓ ; T(0) = 100 ✓. Le liquide refroidit de moins en moins vite vers les 15 °C de la pièce — 100 → 60 → 38,8 → 15 — et atteint 30 °C au bout d'environ 55 minutes.

🧮 Application 2 — la cuve du barrage (remplissage avec fuite)

Une cuve contient 200 litres ; une pompe y verse 25 L/min, une fuite évacue 5 % du contenu par minute.

1

Traduire : « 5 % par minute » → terme −0,05·V (proportionnel au volume) ; « 25 L/min » → terme constant +25. D'où V' = −0,05·V + 25.

2

Résoudre : Vₚ = −25/(−0,05) = 500 ; V(t) = Ce^(−0,05t) + 500 ; V(0) = 200 donne C = −300 :

V(t) = 500 − 300·e^(−0,05t)

Vérification : V' = 15e^(−0,05t) et −0,05V + 25 = 15e^(−0,05t) ✓ ; V(0) = 200 ✓

3

Limite : a = −0,05 < 0, donc V(t) → 500 : la cuve se stabilise à 500 litres — le niveau où la fuite (5 % de 500 = 25 L/min) compense exactement la pompe.

4

Temps de passage à 400 :

500 − 300·e^(−0,05t) = 400 ⇔ e^(−0,05t) = 1/3 ⇔ t = (ln 3)/0,05 = 20·ln 3 ≈ 22 min

Lecture bonus : l'écart à l'équilibre (300 L au départ) est divisé par 2 toutes les 20·ln 2 ≈ 13,9 min — la « demi-vie » du remplissage !

🧮 Application 3 — les algues du bassin (croissance avec apport constant)

Un bassin contient 5 000 algues ; la population croît de 8 % par jour (proportionnellement à sa taille) et on y introduit chaque jour 200 algues supplémentaires.

1

Traduire : « croît de 8 % par jour » → +0,08·P ; « apport constant de 200 » → +200. D'où P' = 0,08·P + 200.

2

Résoudre : Pₚ = −200/0,08 = −2 500 (négative : l'équilibre théorique est hors du domaine réel — bon signe : la croissance l'emporte) ; P(0) = 5 000 donne C = 7 500 :

P(t) = 7 500·e^(0,08t) − 2 500

Vérification : P' = 600e^(0,08t) et 0,08P + 200 = 600e^(0,08t) ✓ ; P(0) = 5 000 ✓

3

À 10 jours : P(10) = 7 500·e^(0,8) − 2 500 ≈ 14 192 algues.

4

Temps de passage à 10 000 :

7 500·e^(0,08t) − 2 500 = 10 000 ⇔ e^(0,08t) = 5/3 ⇔ t = ln(5/3)/0,08 ≈ 6,4 jours

5

Conclusion : la population double en environ 6,4 jours ; comme a = 0,08 > 0, la croissance est divergente — l'apport constant devient vite négligeable devant la croissance exponentielle.

Les erreurs de traduction — elles coûtent tout l'exercice

(1) Signe du terme proportionnel : une fuite ou un refroidissement donne −c·y. (2) Pourcentages non convertis : « 5 % par minute » → 0,05, pas 5 ni 0,5. (3) Mélanger les unités de temps : un taux « par an » avec un t « en mois » fausse tout. (4) Le signe de −b/a : pour V' = −0,05V + 25, l'équilibre vaut −25/(−0,05) = +500 ; contrôle de bon sens : un volume d'équilibre doit être positif.

Sujets type Bac et grande table de synthèse

A. Quatre sujets résolus — la chaîne complète : traduire, résoudre, condition initiale, vérifier, répondre

🧮 Sujet type Bac n° 1 — la réserve piscicole

P' = −0,05·P + 20 avec P(0) = 1 000. Particulière : yₚ = −20/(−0,05) = 400 ; solution générale P(t) = Ce^(−0,05t) + 400 ; P(0) = 1 000 donne C = 600 :

P(t) = 600·e^(−0,05t) + 400

Vérification : P' = −30e^(−0,05t) et −0,05P + 20 = −30e^(−0,05t) ✓ ; P(0) = 1 000 ✓. Limite : −0,05 < 0, donc P(t) → 400 — la réserve se stabilise à 400 individus, où la mortalité compense le réapprovisionnement. Temps de passage à 700 : e^(−0,05t) = 0,5, donc t = 20·ln 2 ≈ 13,9 ans — la « demi-vie » de l'écart à l'équilibre (600 → 300).

🧮 Sujet type Bac n° 2 — le cas piège avec condition initiale

On considère y' = y + 2e^x. 1) Vérification de yₚ = 2x·e^x : yₚ' = 2e^x + 2x·e^x et yₚ + 2e^x = 2x·e^x + 2e^x ✓ (l'exposant de f vaut 1 = a : cas piège prévisible). 2) Toutes les solutions : y = Ce^x + 2x·e^x = (C + 2x)·e^x. 3) y(0) = 3 donne C = 3 :

y = (3 + 2x)·e^x

4) Pour x ≥ 0 : 3 + 2x ≥ 3 > 0 et e^x > 0, donc y > 0 — une quantité qui reste positive, cohérent avec un modèle de population.

🧮 Sujet type Bac n° 3 — trigonométrique avec condition initiale

On considère y' = y + sin x. 1) yₚ = −(1/2)·cos x − (1/2)·sin x : yₚ' = (1/2)·sin x − (1/2)·cos x et yₚ + sin x = −(1/2)·cos x + (1/2)·sin x ✓. 2) Toutes les solutions : y = Ce^x − (1/2)·cos x − (1/2)·sin x. 3) y(0) = 1 donne C − 1/2 = 1, donc C = 3/2 :

y = (3/2)·e^x − (1/2)·cos x − (1/2)·sin x

4) Contrôle : l'équation est vérifiée pour tout x ✓, y(0) = 3/2 − 1/2 = 1 ✓, exposant 1 = a ✓. La partie oscillante ne grandit pas, mais le terme (3/2)e^x domine : la solution diverge en oscillant.

🧮 Sujet type Bac n° 4 — superposition avec condition initiale

On considère y' = 2y + x + e^x. 1) Pour f₁(x) = x : yₚ₁ = Ax + B donne A = 2Ax + 2B + x, donc 2A + 1 = 0 et 2B = A : yₚ₁ = −(1/2)·x − 1/4. Pour f₂(x) = e^x : μ = 1 ≠ a = 2, λe^x = 2λe^x + e^x donne λ = −1 : yₚ₂ = −e^x. Superposition : yₚ = −(1/2)·x − 1/4 − e^x. 2) y = Ce^(2x) − (1/2)·x − 1/4 − e^x. 3) y(0) = 1 donne C − 5/4 = 1, donc C = 9/4 :

y = (9/4)·e^(2x) − (1/2)·x − 1/4 − e^x

4) Quand x → +∞, le terme (9/4)e^(2x) domine tous les autres : la solution tend vers +∞ — attention, a > 0 : pas de convergence vers yₚ.

La carte mentale du chapitre entier

Trois équations, un seul squelette : des solutions homogènes Ce^(ax), une solution particulière (0, ou −b/a, ou fabriquée par identification avec le tableau des formes), une condition initiale qui fixe C par la formule universelle — et l'unicité qui garantit que cette solution est la seule. Le réflexe qui relie tout : vérifier en redérivant et en reportant la condition — quatre filtres qui détectent n'importe quelle erreur.

Pour y' = ay + b avec y(0) = y₀, la constante C vaut :

A) y₀ − b/aB) y₀ + b/aC) y₀·e^(−b/a)D) y₀
Voir la réponse
B. On écrit d'abord y = Ce^(ax) − b/a, puis y(0) = C − b/a = y₀, donc C = y₀ + b/a. Contrôle : a × yₚ + b = a × (−b/a) + b = 0 ✓

La solution de y' = −2y + 8 passant par (2 ; 5) est :

A) y = e^(4−2x) + 4B) y = 5e^(−2x) + 4C) y = e^(−4)·e^(−2x) + 4D) y = e^(2x) + 4
Voir la réponse
A. Solution générale y = Ce^(−2x) + 4 ; y(2) = Ce^(−4) + 4 = 5 donne C = e⁴, donc y = e⁴·e^(−2x) + 4 = e^(4−2x) + 4. Contrôle : y(2) = e⁰ + 4 = 5 ✓ (B échoue : 5e^(−4) + 4 ≠ 5)

La demi-vie d'un corps de constante radioactive λ vaut :

A) ln 2 × λB) λ/(ln 2)C) (ln 2)/λD) 1/λ
Voir la réponse
C. On résout N₀·e^(−λ·t₁/₂) = N₀/2 : e^(−λ·t₁/₂) = 1/2 = e^(−ln 2), donc t₁/₂ = (ln 2)/λ. Contrôle dimensionnel : λ est en « par an », donc t₁/₂ en années — cela élimine A et B.
📌 Ce qu'il faut retenir
  • [methode] Toutes les solutions : y = yₚ + Ce^(ax) — homogène → particulière → somme → condition initiale → vérification. La condition initiale jamais avant la solution générale.
  • [condition_c] Formule universelle : C = (y₀ − yₚ(x₀))·e^(−ax₀) ; en 0 pour y' = ay + b : C = y₀ + b/a. Contrôle : reporter x₀, retomber sur y₀.
  • [unicite] Une seule solution passe par (x₀ ; y₀) : y = yₚ(x) + (y₀ − yₚ(x₀))·e^(a(x−x₀)) — et deux courbes solutions ne se croisent jamais.
  • [controle] 4 filtres : équation (pour tout x), condition initiale, exposant = a, cohérence. Tester des valeurs ne prouve rien.
  • [superposition] f = f₁ + f₂ ⇒ yₚ = yₚ₁ + yₚ₂, avec le même a pour tous les morceaux — on additionne, jamais on multiplie.
  • [formes] yₚ : constante −b/a ; polynôme de degré n complet ; λ·e^(μx) si μ ≠ a ; λ·x·e^(ax) si μ = a (cas piège) ; la paire A·cos(βx) + B·sin(βx).
  • [radioactivite] N = N₀·e^(−λt) ; t₁/₂ = (ln 2)/λ ; N = N₀·2^(−t/t₁/₂) ; après n demi-vies : N₀/2ⁿ. Datation : t = t₁/₂·ln(N₀/N)/ln 2.
  • [modeles] Newton T' = −k(T − θ) ; réservoir V' = −cV + d : équilibre −b/a ; temps de passage t = (1/a)·ln((v − yₚ)/(y₀ − yₚ)) ; toujours conclure par une phrase avec unité.
