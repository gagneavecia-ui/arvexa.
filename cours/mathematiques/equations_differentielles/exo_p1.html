Thème 01 · Applications de cours

Solutions générales : y' = ay et y' = ay + b

Toutes les équations de cette série se résolvent sur ℝ. Le tableau du cours suffit — à condition d'identifier correctement a et b avant de l'appliquer.

Équation différentielleSolutions sur ℝ
y' = a·y (a ≠ 0)y(x) = C·e^(a·x), C ∈ ℝ
y' = a·y + b (a ≠ 0)y(x) = C·e^(a·x) − b/a, C ∈ ℝ
Réflexe — Écrivez d'abord l'équation sous la forme standard y' = a·y + b et identifiez a et b par écrit. Par exemple y' = −3y + 6 : a = −3, b = 6.
✏️ Exercice 1 — Résoudre du premier coup (★)

Résoudre sur ℝ les équations suivantes : donner la solution générale (avec C ∈ ℝ), puis vérifier en dérivant.

  1. (E₁) : y' = 2y ;
  2. (E₂) : y' = −5y ;
  3. (E₃) : y' = 3y.
✏️ Exercice 2 — Contrôle de solutions (★)

Vérifier par le calcul (dérivée à gauche, second membre à droite) que chaque fonction est solution de l'équation associée :

  1. g(x) = 5·e^(3x) et (E₁) : y' = 3y ;
  2. h(x) = −2·e^(−x) et (E₂) : y' = −y ;
  3. k(x) = 4·e^(2x) + 7 et (E₃) : y' = 2y − 14.
✏️ Exercice 3 — Avec second membre constant (★★)

Résoudre sur ℝ (on pourra commencer par chercher la solution constante −b/a, puis vérifier la solution générale en dérivant) :

  1. (E₁) : y' = −3y + 6 ;
  2. (E₂) : y' = y + 4 ;
  3. (E₃) : y' = 2y − 8.

Thème 01 · Applications de cours

Vérifications rédigées et solution unique

✏️ Exercice 4 — Vérification rédigée (★★)
  1. Vérifier que f(x) = 3·e^(−2x) + 2 est solution de (E) : y' = −2y + 4 sur ℝ.
  2. Vérifier que g(x) = (x + 1)·e^(−x) est solution de (F) : y' + y = e^(−x) sur ℝ (attention : g est un produit !).
✏️ Exercice 5 — À la lecture du graphique (★★)

Les trois courbes C₁, C₂ et C₃ ci-dessous représentent des solutions de (E) : y' = 0,5·y, toutes de la forme y(x) = k·e^(0,5x) avec k > 0.

  1. Vérifier que, pour tout réel k > 0, la fonction y(x) = k·e^(0,5x) est solution de (E).
  2. Associer chaque courbe à sa valeur de k (on lira l'ordonnée à l'origine de chacune).
  3. Le point A(0 ; 1) est sur l'une des courbes : en déduire l'unique solution de (E) vérifiant y(0) = 1, puis la vérifier par dérivation.
✏️ Exercice 6 — De la solution générale à la solution unique (★★)
  1. Résoudre (E) : y' = 4y − 8.
  2. Vérifier que h(x) = 3·e^(4x) + 2 est solution de (E).
  3. Montrer que h est exactement la solution de (E) qui vérifie la condition initiale y(0) = 5.
