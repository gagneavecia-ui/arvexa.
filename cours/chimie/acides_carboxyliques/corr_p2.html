Rendements d'estérification : suivi et optimisation

✏️ Exercice 1 — Rendement d'une estérification (★★)

Données : 0,10 mol d'acide + 0,10 mol d'éthanol, catalyseur H₂SO₄ ; il reste 0,033 mol d'acide ; M(ester) = 88 g·mol⁻¹.

1

Le catalyseur H₂SO₄ accélère la réaction sans modifier l'état d'équilibre. Le chauffage à reflux élève la température (donc la vitesse) tout en condensant les vapeurs : aucune matière ne quitte le ballon, la composition du milieu est préservée.

2

Équation : CH₃—COOH + C₂H₅—OH ⇌ CH₃—COO—C₂H₅ + H₂O. Mélange équimolaire : xₘₐₓ = 0,10 mol. À l'équilibre : n(acide restant) = 0,10 − xₑ = 0,033 mol, donc xₑ = 0,10 − 0,033 = 0,067 mol.

3

Rendement : r = xₑ/xₘₐₓ = 0,067/0,10 = 0,67 = 67 % — la valeur de cours pour un alcool primaire.

4

Masse d'ester : n(ester) = xₑ = 0,067 mol, donc m = n × M = 0,067 × 88 = 5,896 ≈ 5,9 g.

r = 67 % ; m(ester) ≈ 5,9 g

La réaction étant limitée, on ne récupère jamais les 8,8 g théoriques.

⚠️ Piège : le rendement compare xₑ à xₘₐₓ (quantités de matière), jamais des masses entre elles.
✏️ Exercice 2 — Influence de la nature de l'alcool (★★ type Bac)

Données : restes d'acide à l'équilibre : méthanol 0,033 mol ; propan-2-ol 0,045 mol ; 2-méthylpropan-2-ol 0,095 mol ; xₘₐₓ = 0,10 mol.

1

Méthanol (primaire) : xₑ = 0,10 − 0,033 = 0,067 mol → r = 0,067/0,10 = 67 %.

2

Propan-2-ol (secondaire) : xₑ = 0,10 − 0,045 = 0,055 mol → r = 0,055/0,10 = 55 %.

3

2-méthylpropan-2-ol (tertiaire) : xₑ = 0,10 − 0,095 = 0,005 mol → r = 0,005/0,10 = 5 %.

4

Classement : méthanol (67 %) > propan-2-ol (55 %) > 2-méthylpropan-2-ol (5 %). Conclusion : le rendement diminue quand le groupe alkyle lié au carbone fonctionnel de l'alcool s'encombre — un alcool primaire est le plus réactif, un tertiaire presque inerte dans l'estérification.

r = 67 % (primaire) ; 55 % (secondaire) ; 5 % (tertiaire)

Primaire > secondaire > tertiaire : à retenir pour anticiper un rendement.

⚠️ Piège : soustraire dans le bon sens : xₑ = n₀ − n(acide restant), pas l'inverse.
✏️ Exercice 3 — Suivre l'avancement par dosage (★★★ type Bac)

Données : n₀ = 0,10 mol d'acide ; prélèvement du 1/10 du milieu ; CB = 0,50 mol·L⁻¹ ; VE = 6,6 mL ; M(ester) = 88 g·mol⁻¹.

1

Dosage : CH₃—COOH + NaOH → CH₃—COO⁻Na⁺ + H₂O. Dans le prélèvement : n(acide) = CB × VE = 0,50 × 6,6×10⁻³ = 3,3×10⁻³ mol.

2

Le prélèvement représente le dixième du milieu : n(acide restant total) = 10 × 3,3×10⁻³ = 3,3×10⁻² mol = 0,033 mol.

3

Avancement : xₑ = 0,10 − 0,033 = 0,067 mol ; rendement : r = 0,067/0,10 = 67 %.

4

Masse d'ester : m = 0,067 × 88 = 5,9 g. On retrouve exactement le résultat de l'exercice 1 : deux méthodes indépendantes (reste d'acide annoncé, dosage de l'acide restant) donnent le même état final, ce qui valide les deux protocoles.

xₑ = 0,067 mol ; r = 67 % ; m ≈ 5,9 g

Le dosage de l'acide restant est LA méthode expérimentale de suivi au Bac.

⚠️ Piège : repère bien la fraction prélevée : ici 1/10, donc on multiplie par 10. Un prélèvement de 1/5 imposerait de multiplier par 5.

Savons et arômes : des esters utiles

✏️ Exercice 4 — Le savon : de l'ester au sel de sodium (★★)

Données : savon R—COO⁻Na⁺, R = chaîne de 12 à 18 carbones ; modèle : CH₃—COO—C₂H₅ + NaOH.

1

Saponification du modèle : CH₃—COO—C₂H₅ + NaOH → CH₃—COO⁻Na⁺ + C₂H₅OH. Vérification : C : 4 = 4 ✓ ; H : 8 + 1 = 9 à gauche, 3 + 6 = 9 à droite ✓ ; O : 2 + 1 = 3 de part et d'autre ✓ ; Na : 1 = 1 ✓.

2

Équation générale : R—COO—C₂H₅ + NaOH → R—COO⁻Na⁺ + C₂H₅OH. Le sel de sodium de l'acide gras est le savon.

3

Analyse du savon : la longue chaîne R est hydrophobe (elle attire les graisses) ; la tête —COO⁻Na⁺ est hydrophile (soluble dans l'eau). Le savon relie ainsi la graisse et l'eau : les gouttelettes grasses se dispersent en émulsion et partent au rinçage.

4

Différence avec l'hydrolyse simple : en milieu neutre ou acide, l'eau redonne l'acide R—COOH (réaction lente et limitée, inverse de l'estérification) ; en milieu basique, la soude donne le SEL R—COO⁻Na⁺ : la saponification est plus rapide et pratiquement totale.

R—COO—C₂H₅ + NaOH → R—COO⁻Na⁺ + C₂H₅OH

Saponification = hydrolyse en milieu basique : le savon est un sel de sodium d'acide gras.

Figure — Un savon R—COO⁻Na⁺ : une queue hydrophobe qui plonge dans la graisse, une tête hydrophile qui reste dans l'eau.
⚠️ Piège : avec la soude, le produit n'est JAMAIS l'acide R—COOH : en milieu basique on obtient le sel R—COO⁻Na⁺.
✏️ Exercice 5 — Synthèse d'un arôme : l'éthanoate de pentyle (★★★)

Données : M(acide) = 60, M(alcool) = 88, M(eau) = 18 g·mol⁻¹ ; m₁ = 12,0 g ; m₂ = 17,6 g ; r = 67 %.

1

Équation : CH₃—COOH + C₅H₁₁—OH ⇌ CH₃—COO—C₅H₁₁ + H₂O.

2

Masse molaire de l'ester C₇H₁₄O₂ : M = 7×12 + 14×1 + 2×16 = 84 + 14 + 32 = 130 g·mol⁻¹. Vérification : 60 + 88 = 148 et 130 + 18 = 148 ✓ — la conservation des masses molaires est respectée.

3

Quantités initiales : n(acide) = 12,0/60 = 0,20 mol ; n(alcool) = 17,6/88 = 0,20 mol. Mélange équimolaire et stœchiométrie 1:1 : aucun réactif limitant, xₘₐₓ = 0,20 mol.

4

Masse théorique : m_th = 0,20 × 130 = 26 g. Quantité réelle : n(ester) = 0,67 × 0,20 = 0,134 mol, d'où m = 0,134 × 130 = 17,42 ≈ 17,4 g.

5

Double vérification par conservation des masses : ester 17,4 g + eau formée 0,134 × 18 = 2,4 g + acide restant 0,066 × 60 = 4,0 g + alcool restant 0,066 × 88 = 5,8 g ≈ 29,6 g = masse initiale 12,0 + 17,6 = 29,6 g ✓.

m_th = 26 g ; masse réelle ≈ 17,4 g d'éthanoate de pentyle

Arôme de banane obtenu : le rendement limite la quantité, pas la nature du produit.

⚠️ Piège : applique le rendement à la quantité de matière (0,67 × 0,20 = 0,134 mol) PUIS convertis en masse. Multiplier directement la masse théorique par 0,67 (26 × 0,67 = 17,4 g) marche ici par coïncidence des proportions, mais le raisonnement correct passe par les moles.
✏️ Exercice 6 — Arôme d'ananas : le problème complet (★★★ type Bac)

Données : n(acide) = 0,10 mol ; n(alcool) = 0,15 mol ; M(ester) = 116, M(acide) = 88, M(alcool) = 46 g·mol⁻¹ ; r = 67 % par rapport au réactif limitant.

1

Équation : CH₃—CH₂—CH₂—COOH + C₂H₅—OH ⇌ CH₃—CH₂—CH₂—COO—C₂H₅ + H₂O. Vérification des masses molaires : 88 + 46 = 134 et 116 + 18 = 134 ✓.

2

Stœchiométrie 1:1 : 0,10 mol d'acide pour 0,15 mol d'alcool → l'acide butanoïque est le réactif limitant et xₘₐₓ = 0,10 mol (l'éthanol est en excès de 0,05 mol).

3

Ester formé : n(ester) = 0,67 × 0,10 = 0,067 mol, d'où m = 0,067 × 116 = 7,772 ≈ 7,8 g de butanoate d'éthyle (arôme d'ananas).

4

Contrôle par saponification : CH₃—CH₂—CH₂—COO—C₂H₅ + NaOH → CH₃—CH₂—CH₂—COO⁻Na⁺ + C₂H₅OH. Vérification : C : 6 = 6 ✓ ; H : 12 + 1 = 13 à gauche, 7 + 6 = 13 à droite ✓ ; O : 2 + 1 = 3 de part et d'autre ✓ ; Na : 1 = 1 ✓. Produits : butanoate de sodium (savon) et éthanol.

xₘₐₓ = 0,10 mol ; m(ester) ≈ 7,8 g

La saponification du produit confirme qu'il s'agit bien d'un ester.

⚠️ Piège : cherche TOUJOURS le réactif limitant avant d'appliquer le rendement : ici ce n'est pas l'alcool, pourtant présent en plus grande quantité.
