Accroche

Une seule équation, tout le chapitre

« Montrer que les images sont alignées », « quelle est l'image de ce cercle ? », « la composée de deux homothéties est-elle encore une homothétie ? », « que se passe-t-il si on répète la similitude ? » : chaque question du Bac exige de faire marcher z′ = az + b sur des figures entières. Et tout part d'un seul constat :

💡 La carte mentale de la partie

Une différence d'images annule le nombre b : z′(M) − z′(N) = a·(z(M) − z(N)). Ce calcul fondateur donne les distances (× |a|), les angles (+ arg(a)), donc l'alignement, les rapports, les milieux, les cercles et les triangles semblables. Posé en z = ω, il donne le centre ; écrit sous forme a = k·e^(iθ), il donne la décomposition ; substitué dans lui-même, il donne la composée ; élevé à la puissance n, il donne les itérées.

Rappels utilisés partout (parties 1 à 3) : z′ = az + b avec a ≠ 0 ; rapport k = |a| ; angle θ = arg(a) [2π] ; centre ω = b/(1 − a) si a ≠ 1 ; forme réduite z′ − ω = a·(z − ω).

01
Notion 1 · calcul_fondateur

Les propriétés conservées, démontrées

Jusqu'ici, les conservations étaient admises. Démontrons-les toutes à partir du calcul fondateur — pour S : z′ = az + b et deux points M, N d'images M′, N′ :

Calcul fondateur — la différence d'images
z′(M) − z′(N) = a·(z(M) − z(N))
Le nombre b se compense. D'où M′N′ = |a| × MN et (→MN ; →M′N′) ≡ arg(a) [2π] : toutes les distances sont multipliées par |a|, tous les vecteurs tournent du même angle arg(a).
1

Écrire les deux images :

z′(M) = a·z(M) + b

z′(N) = a·z(N) + b

2

Soustraire membre à membre — le b apparaît dans les deux lignes et se compense :

z′(M) − z′(N) = (a·z(M) + b) − (a·z(N) + b) = a·(z(M) − z(N))

3

Prendre le module (avec |a·z| = |a|·|z|) :

M′N′ = |a| × MN

4

Prendre l'argument (avec arg(a·z) ≡ arg(a) + arg(z) [2π]) :

(→MN ; →M′N′) ≡ arg(a) [2π]

Deux conséquences géométriques majeures, pour A, B, C deux à deux distincts :

Le quotient invariant :
(z′(C) − z′(A)) / (z′(B) − z′(A)) = (z(C) − z(A)) / (z(B) − z(A))
On divise deux calculs fondateurs : le facteur a se simplifie (légal car a ≠ 0). Un quotient réel reste réel → l'alignement est conservé ; un quotient de modules donne A′C′/A′B′ = AC/AB → les rapports de distances sur une même droite sont conservés. L'argument du quotient étant inchangé, les angles orientés le sont aussi.
🧮 Exemple — alignement et rapport par le calcul

Prenons S : z′ = (1 + i)·z + 2 et les points M(0), N(1 + i), P(2 + 2i) — alignés. Les images valent 2, 2 + 2i, 2 + 4i :

quotient image = (z′(P) − z′(M)) / (z′(N) − z′(M)) = 4i / 2i = 2

Un réel : M′, N′, P′ sont alignés, et M′P′/M′N′ = 2, le même rapport qu'à l'origine (MP/MN = 2√2/√2 = 2). Contrôle par k : M′N′ = |2i| = 2 = √2 × √2 = k × MN ✓

📗 Milieux et cercles — les deux autres démonstrations

Milieux : si I est le milieu de [MN], z(I) = (z(M) + z(N))/2, et on vérifie ligne à ligne que z′(I) = (z′(M) + z′(N))/2 : l'image du milieu est le milieu des images. (La similitude est affine : elle conserve les barycentres.)

Cercles : pour M sur le cercle de centre C d'affixe c et de rayon R, le calcul fondateur donne |z′(M) − c′| = |a|·|z(M) − c| = k·R où c′ = a·c + b : l'image est exactement le cercle de centre C′ (image de C) et de rayon k·R — la réciproque venant de l'antécédent z = (w − b)/a.

🧮 Exemple — image d'un cercle en deux lignes
1

Centre image (fil rouge S : z′ = (1 + i)·z + 2 − i, cercle de centre O et de rayon 2) :

z′(O) = (1 + i) × 0 + (2 − i) = 2 − i

2

Rayon image :

R′ = k × R = √2 × 2 = 2√2

3

Contrôle sur un point : le point d'affixe 2 est sur le cercle (|2 − 0| = 2) ; son image est 4 + i, et |(4 + i) − (2 − i)| = |2 + 2i| = 2√2 ✓ — c'est bien le rayon annoncé.

Erreur fréquente au Bac

Les distances sont multipliées par k, jamais « conservées » sans vérification : annoncer A′B′ = AB pour une similitude de rapport √2 est une faute lourde. Ce qui est toujours conservé : l'alignement, les angles orientés, les milieux, la circularité, les rapports de distances. Et la simplification par a dans le quotient invariant exige a ≠ 0 : écris la condition, elle justifie la ligne.

02
Notion 2 · centre_decomposition

Le centre retracé et la décomposition canonique

Le centre est le point de passage de toutes les questions riches. On le retrouve en cherchant le point qui est sa propre image :

1

Traduire l'invariance : z′ = z s'écrit a·z + b = z, soit (1 − a)·z = b.

2

Diviser si c'est légal — c'est-à-dire si a ≠ 1 :

ω = b/(1 − a)

3

Discuter si a = 1 : l'équation devient 0 × z = b — aucun point fixe si b ≠ 0 (translation), tous les points fixes si b = 0 (identité). L'unicité du centre (quand a ≠ 1) se prouve par soustraction : deux invariants z₁ ≠ z₂ donneraient (a − 1)·(z₁ − z₂) = 0, donc a = 1 — contradiction.

Le centre — unique point invariant
ω = b/(1 − a) (a ≠ 1)
Contrôle universel, valable pour tout centre : a·ω + b = ω. C'est une identité — il ne peut que réussir si le calcul est juste, et il détecte toute faute de division.
🧮 Exemple — le centre par la formule, puis le contrôle
1

Pour S : z′ = (2 + i)·z + 1 − 2i (ici a = 2 + i ≠ 1) :

ω = (1 − 2i)/(1 − (2 + i)) = (1 − 2i)/(−1 − i)

2

Multiplier par le conjugué −1 + i :

ω = ((1 − 2i) × (−1 + i)) / ((−1 − i) × (−1 + i))

ω = (1 + 3i) / 2 = 0,5 + 1,5i

3

Contrôle :

(2 + i) × (0,5 + 1,5i) + 1 − 2i = 0,5 + 1,5i ✓

Passons à la décomposition : le Chapitre 1 écrit tout complexe non nul a = k·e^(iθ) avec k = |a| et θ = arg(a). Injectée dans la forme réduite, cette écriture fait apparaître deux gestes distincts :

Décomposition canonique — les deux ordres
S = R(Ω ; θ) ∘ h(Ω ; k) = h(Ω ; k) ∘ R(Ω ; θ)
Rotation (tourner sans agrandir : module 1) et homothétie (agrandir sans tourner : réel > 0) de même centre Ω. Les deux ordres coïncident car k, réel positif, commute avec e^(iθ). Le triplet (Ω ; k ; θ) est unique — θ modulo 2π.
📗 Les cas limites rentrent dans le moule
  • θ = 0 (a réel > 0) : la rotation est l'identité → il reste l'homothétie pure.
  • k = 1 (|a| = 1, a ≠ 1) : l'homothétie est l'identité → il reste la rotation pure.
  • a réel < 0, par exemple a = −3 : a = 3·e^(iπ) → homothétie de rapport 3 puis rotation d'angle π.
  • a = 1 : pas de centre, pas de décomposition centrale — c'est une translation.
🧮 Exemple complet — décomposer z′ = (2 + 2i)·z + 1 − 3i
1

Le centre (a = 2 + 2i ≠ 1), au conjugué −1 + 2i :

ω = (1 − 3i)/(−1 − 2i) = ((1 − 3i) × (−1 + 2i))/5 = (5 + 5i)/5 = 1 + i

Contrôle : (2 + 2i)·(1 + i) + 1 − 3i = 1 + i ✓

2

Rapport et angle :

k = |2 + 2i| = 2√2

θ = arg(2 + 2i) = π/4 (parties égales et positives)

3

Contrôle de la forme exponentielle :

2√2·e^(iπ/4) = 2√2·(√2/2 + i·√2/2) = 2 + 2i ✓

4

Conclusion : S est la composée, dans un ordre indifférent, de la rotation de centre Ω d'affixe 1 + i et d'angle π/4, et de l'homothétie de même centre et de rapport 2√2.

Erreur fréquente au Bac

« Même centre » est la condition non négociable : la démonstration utilise le fait que k et e^(iθ) multiplient le même (z − ω). Avec deux centres distincts, les deux ordres ne coïncident plus. Nomme explicitement le centre des deux gestes — et vérifie qu'il est le même.

Notion 3 · composees_iterations

Le tableau des composées et les spirales

Composer, c'est enchaîner : S₂ ∘ S₁ signifie « d'abord S₁, ensuite S₂ » — on lit de droite à gauche. On substitue z′ = a₁·z + b₁ dans z″ = a₂·z′ + b₂ :

S₂ ∘ S₁ : z″ = (a₂·a₁)·z + (a₂·b₁ + b₂)
Encore une similitude directe (car a₂·a₁ ≠ 0) : les rapports se multiplient k = k₁·k₂ et les angles s'additionnent θ ≡ θ₁ + θ₂ [2π] — deux contrôles gratuits pour tout calcul de composée. Cas limite : a₂·a₁ = 1 → la composée est une translation.

h(Ω₂ ; k₂) ∘ h(Ω₁ ; k₁) — centres distinctsa = k₂·k₁, b = a₂·b₁ + b₂homothétie si k₁·k₂ ≠ 1 ; translation si k₁·k₂ = 1

R(O₂ ; θ₂) ∘ R(O₁ ; θ₁) — centres distinctsa = e^(i(θ₁+θ₂)), b = a₂·b₁ + b₂rotation si θ₁ + θ₂ ≠ 0 [2π] ; translation sinon
Translation t après S₁ (affixe b₂)a = a₁, b = b₁ + b₂mêmes rapport et angle, simple décalage
Translation t avant S₂ (affixe b₁)a = a₂, b = a₂·b₁ + b₂le décalage est multiplié par a₂
S ∘ S = S²a² et b·(a + 1)même centre que S, rapport k², angle 2θ
🧮 Exemple — le piège du produit de rapports égal à 1
1

Données : h₁ l'homothétie de centre O et de rapport 2 (z′ = 2·z) ; h₂ l'homothétie de centre le point d'affixe 3 et de rapport 1/2 (z″ = z′/2 + 3/2).

2

Composée h₂ ∘ h₁ :

z″ = (2·z)/2 + 3/2 = z + 3/2

3

Conclusion : a = 1 et b = 3/2 ≠ 0 : une translation, pas l'identité ! Le produit des rapports 2 × 1/2 = 1 a « éteint » l'agrandissement, mais les centres distincts ont laissé un glissement résiduel.

Erreur fréquente au Bac

La composition n'est pas commutative : S₁ ∘ S₂ ≠ S₂ ∘ S₁ en général — même moteur a₂·a₁ = a₁·a₂, mais pas le même décalage, donc des centres différents. Et dans b = a₂·b₁ + b₂, le facteur a₂ multiplie b₁ : écrire a₁·b₂ + b₁ révèle un enchaînement lu dans le mauvais sens.

Et si on applique la même similitude encore et encore ? On pose Mₙ₊₁ = S(Mₙ). La forme réduite, empilée n fois (récurrence d'une ligne), donne :

Les itérées Sⁿ — démontrées par récurrence
zₙ − ω = aⁿ·(z₀ − ω)
D'où, en module et argument : ΩMₙ = kⁿ × ΩM₀ et direction tournée de n·θ. Sⁿ est encore une similitude directe, de même centre Ω, de rapport kⁿ et d'angle n·θ. Cas a = 1 (translation) : zₙ = z₀ + n·b.
📗 Les trois régimes de la répétition
  • 0 < k < 1 : kⁿ → 0 — la spirale rentre vers Ω.
  • k > 1 : kⁿ → +∞ — la spirale fuit à l'infini.
  • k = 1 : distances constantes — on tourne sur le cercle de centre Ω (rotation répétée).

La suite ΩMₙ est géométrique de raison k (chapitre « Suites numériques »).

🧮 Exemple complet — une spirale rentrante

Soit S : z′ = (i/2)·z : centre O, rapport k = 1/2, angle θ = π/2. On part de z₀ = 8 :

z₁ = (i/2) × 8 = 4i

z₂ = (i/2) × 4i = 2i² = −2

z₃ = (i/2) × (−2) = −i

z₄ = (i/2) × (−i) = 1/2

z₅ = (i/2) × (1/2) = i/4

À chaque étape : quart de tour et division par 2. Contrôle de la formule : ΩM₃ = 8 × (1/2)³ = 1, et de fait |−i| = 1 ✓.

⚠️ Trois pièges des itérées

(1) Écrire ΩMₙ = n·k·ΩM₀ : non — les rapports se multiplient, d'où la puissance kⁿ. (2) La direction tourne de n·θ modulo 2π : après quatre quarts de tour, on retrouve la direction de départ. (3) La formule mesure les distances au centre Ω — depuis un autre point, rien de tel.

Notion 4 · determination

Déterminer une similitude — le système et ses variantes

Écrire z′ = az + b, c'est connaître deux nombres : il faut donc deux informations indépendantes. Toutes les variantes de l'énoncé s'organisent en un arbre de décision :

Deux couples : a = (z′(A) − z′(B)) / (z(A) − z(B)) ; b = z′(A) − a·z(A)
k et θ + un couple : a = k·e^(iθ) ; b = z′(A) − a·z(A)
Centre Ω + un couple : a = (z′(A) − ω) / (z(A) − ω) ; b = z′(A) − a·z(A)
Le quotient exige z(A) ≠ z(B) et le même ordre aux deux étages ; la variante centre exige z(A) ≠ ω. Dans tous les cas : vérifier a ≠ 0, puis contrôler sur la donnée non utilisée (le second point, le centre annoncé…). Un seul couple : insuffisant — il reste un degré de liberté, il y a une infinité de similitudes ; dis-le explicitement.
🧮 Question type Bac n°1 — déterminer et identifier (intégralement)

Énoncé. S transforme A(1) en A′(2 + i) et B(2) en B′(4 + 3i). Déterminer l'écriture complexe, puis le rapport, l'angle et le centre.

1

Poser S : z′ = az + b. Par soustraction (le b disparaît) :

a = ((2 + i) − (4 + 3i)) / (1 − 2) = (−2 − 2i)/(−1) = 2 + 2i

2

Substitution avec A :

b = z′(A) − a·z(A) = (2 + i) − (2 + 2i) × 1 = −i

S : z′ = (2 + 2i)·z − i, avec a ≠ 0.

3

Vérification sur B :

(2 + 2i) × 2 − i = 4 + 4i − i = 4 + 3i ✓

4

Rapport et angle :

k = |2 + 2i| = √(2² + 2²) = 2√2

θ = arg(2 + 2i) = π/4 (parties réelle et imaginaire égales et positives)

5

Centre (a ≠ 1), au conjugué −1 + 2i :

ω = −i/(−1 − 2i) = ((−i) × (−1 + 2i)) / ((−1 − 2i) × (−1 + 2i))

ω = (2 + i)/5 = 0,4 + 0,2i

Contrôle : (2 + 2i)·(0,4 + 0,2i) − i = 0,4 + 0,2i ✓

6

Phrase de conclusion type : S est la similitude directe de centre Ω le point d'affixe 0,4 + 0,2i, de rapport 2√2 et d'angle π/4.

🧮 Question type Bac n°2 — triangles semblables, la méthode en 3 temps

Énoncé. Soit S : z′ = (1 + i)·z + 2 et le triangle ABC avec z(A) = 1, z(B) = 3, z(C) = 1 + 2i. Les images valent z′(A) = 3 + i, z′(B) = 5 + 3i, z′(C) = 1 + 3i.

Temps 1 — déterminer la similitude sur les deux premiers sommets : a = ((3 + i) − (5 + 3i))/(1 − 3) = 1 + i et b = 2 — on retrouve l'écriture de S.

Temps 2 — vérifier le troisième sommet (obligatoire) :

(1 + i)·(1 + 2i) + 2 = 1 + 2i + i + 2i² + 2 = 1 + 3i ✓

Temps 3 — conclure : S transforme ABC en A′B′C′ : les triangles sont semblables, de rapport k = √2 et d'angle π/4. (Et l'image du cercle de centre O et de rayon 1 est le cercle de centre le point d'affixe 2 et de rayon √2.)

Erreur fréquente au Bac

(1) Conclure « similitude directe » sans annoncer a ≠ 0 : c'est la définition — une ligne, un point. (2) Sauter la vérification du troisième sommet dans « les triangles sont-ils semblables ? » : deux points déterminent la similitude, mais l'envoi du troisième doit être prouvé, pas supposé. (3) Avec un seul couple, écrire « donc S : z′ = … » est faux : les données sont insuffisantes, dis-le.

Notion 5 · reflexes_synthese

Réflexes Bac et grande table de synthèse

Les automatismes qui répondent aux questions les plus posées — le signal de l'énoncé déclenche l'action :

  • Nature demandée → a ≠ 0, puis trois tests dans l'ordre : a = 1 (translation) ; |a| = 1 (rotation) ; a réel > 0 (homothétie) ; sinon similitude générale de rapport |a| et d'angle arg(a).
  • Centre demandé → vérifier a ≠ 1, calculer ω = b/(1 − a), contrôler a·ω + b = ω.
  • Deux couples donnés → a = (z′(A) − z′(B))/(z(A) − z(B)) (même ordre !), b = z′(A) − a·z(A), vérifier sur B.
  • Composée → « d'abord S₁, ensuite S₂ » : a = a₂·a₁, b = a₂·b₁ + b₂ ; contrôler k₁·k₂ et θ₁ + θ₂.
  • Décomposition demandée → k, θ (quadrant), ω (contrôlé), puis S = R(Ω ; θ) ∘ h(Ω ; k), même centre, ordre indifférent.
  • Image d'un cercle → deux lignes : centre image a·c + b, rayon k·R.
  • Alignement / rapport de distances → calcul fondateur et quotient invariant : le facteur a se simplifie.
  • Itérées → zₙ − ω = aⁿ·(z₀ − ω) : rapport kⁿ, angle n·θ, même centre ; comparer k à 1.
  • Contrôles universels → centre invariant ; rapports multipliés, angles additionnés ; conditions écrites (a ≠ 0, a ≠ 1, z(A) ≠ z(B), même centre).

💡 Le plan de rédaction d'une question Bac complète

Acte 1 (détermination) : « posons z′ = az + b » + système ou construction de a + substitution + contrôle. Acte 2 (identification) : a ≠ 0 annoncé, nature par les trois tests, puis k = |a|, θ = arg(a) (quadrant), ω = b/(1 − a) (condition + contrôle), phrase de conclusion complète. Acte 3 (application) : images par remplacement, cercle = centre image + rayon × k, alignements par le quotient invariant. Cette architecture, répétée telle quelle, ne laisse rien au hasard.

A) l'identitéB) une rotationC) une translationD) une homothétie
Voir la réponse

S a pour rapport 1/2 et pour angle π/2. La similitude S ∘ S ∘ S a :

A) rapport 3/2 et angle 3π/2B) rapport 1/8 et angle 3π/2C) rapport 1/6 et angle π/2D) rapport 1/8 et angle π/6
