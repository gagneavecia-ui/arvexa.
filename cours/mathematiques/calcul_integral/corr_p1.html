⏱ 25 min 🧮 2 notions 📚 2 sections 🎓 Terminale D
Méthode constante — 1) Je cherche une primitive F de f. 2) Je calcule F(b) − F(a). 3) Je vérifie en dérivant F : je dois retrouver f. Sans bornes, la constante c est obligatoire ; avec des bornes, elle disparaît.

Corrigés — Primitives (exercices 1 à 3)

✏️ Exercice 1 — Primitives terme à terme (★)

Données : primitives de 3x², 5, 4x³ − 2x + 1 (sur ℝ) et 6/x (sur ]0 ; +∞[).

1

f(x) = 3x² : la formule xⁿ ↦ x^(n+1)/(n+1) avec n = 2 donne F₁(x) = x³ + c. Vérification : (x³ + c)' = 3x² ✓.

2

f(x) = 5 : une primitive est F₂(x) = 5x + c. Vérification : (5x + c)' = 5 ✓.

3

f(x) = 4x³ − 2x + 1 : linéarité, terme à terme : F₃(x) = x⁴ − x² + x + c. Vérification : (x⁴ − x² + x + c)' = 4x³ − 2x + 1 ✓.

4

f(x) = 6/x : comme (ln(x))' = 1/x, on a F₄(x) = 6·ln(x) + c. Vérification : (6·ln(x) + c)' = 6/x ✓.

F₁(x) = x³ + c
F₂(x) = 5x + c
F₃(x) = x⁴ − x² + x + c
F₄(x) = 6·ln(x) + c (sur ]0 ; +∞[)
avec c ∈ ℝ : on donne toutes les primitives, pas seulement une.
⚠️ Piège — La primitive de xⁿ est x^(n+1)/(n+1), pas n·x^(n−1) (c'est la dérivée !). Et sans bornes, la constante c ne s'oublie pas.
✏️ Exercice 2 — Exponentielles, quotients et racines (★★)

Données : primitives de e^x − 2x, 2·e^x − 3x², 1/x² et 1/√x.

1

F₁(x) = e^x − x² + c. Vérification : (e^x − x² + c)' = e^x − 2x ✓.

2

F₂(x) = 2·e^x − x³ + c. Vérification : (2·e^x − x³ + c)' = 2·e^x − 3x² ✓.

3

1/x² = x^(−2) : la formule xⁿ avec n = −2 donne F₃(x) = x^(−1)/(−1) = −1/x + c. Vérification : (−x^(−1))' = +x^(−2) = 1/x² ✓.

4

1/√x = x^(−1/2) : F₄(x) = x^(1/2)/(1/2) = 2·√x + c. Vérification : (2·x^(1/2))' = 2·(1/2)·x^(−1/2) = 1/√x ✓.

e^x − x² + c · 2·e^x − x³ + c · −1/x + c · 2·√x + c
Les deux dernières fonctions ne sont pas définies en 0 : intervalle de validité ]0 ; +∞[.
⚠️ Piège — (−1/x)' = +1/x² : le signe se retourne en dérivant. Écrire d'abord la puissance x^(−2) évite l'essentiel des erreurs.
✏️ Exercice 3 — Reconnaître u'·f(u) (★★)

Données : primitives de x·(x² + 1)³, (2x)/(x² + 1) et x·e^(x²).

1

On pose u(x) = x² + 1, donc u'(x) = 2x et x = u'/2 : f = (1/2)·u'·u³. Une primitive de u'·u³ est u⁴/4, donc F₁(x) = (1/2)·(x² + 1)⁴/4 = (x² + 1)⁴/8 + c. Vérification : ((x² + 1)⁴/8)' = (1/8)·4·(x² + 1)³·2x = x·(x² + 1)³ ✓.

2

Ici f = u'/u avec u(x) = x² + 1 et u' = 2x exactement : F₂(x) = ln(x² + 1) + c (la quantité x² + 1 est strictement positive sur ℝ). Vérification : (ln(x² + 1))' = (2x)/(x² + 1) ✓.

3

On pose u(x) = x², donc u' = 2x et f = (1/2)·u'·e^u : F₃(x) = (1/2)·e^(x²) + c. Vérification : ((1/2)·e^(x²))' = (1/2)·2x·e^(x²) = x·e^(x²) ✓.

(x² + 1)⁴/8 + c
ln(x² + 1) + c
(1/2)·e^(x²) + c
Trois formes classiques : u'·u³, u'/u, u'·e^u.
⚠️ Piège — Devant x·e^(x²), l'intégration par parties est un mur : le bon réflexe est de repérer u' = 2x. Toujours identifier le « facteur manquant » avant d'intégrer.

Corrigés — Premières intégrales (exercices 4 à 6)

✏️ Exercice 4 — Intégrales immédiates (★)

Données : calcul de ∫₁³ 2x dx, ∫₀² 3x² dx, ∫₁ᵉ (1/x) dx et ∫₀¹ e^x dx.

1

Une primitive de 2x est x² : ∫₁³ 2x dx = [x²]₁³ = 3² − 1² = 9 − 1 = 8. Vérification : (x²)' = 2x ✓.

2

Une primitive de 3x² est x³ : ∫₀² 3x² dx = [x³]₀² = 2³ − 0³ = 8.

3

∫₁ᵉ (1/x) dx = [ln(x)]₁ᵉ = ln(e) − ln(1) = 1 − 0 = 1.

4

∫₀¹ e^x dx = [e^x]₀¹ = e¹ − e⁰ = e − 1 ≈ 2,718 − 1 ≈ 1,72.

∫₁³ 2x dx = 8 · ∫₀² 3x² dx = 8 · ∫₁ᵉ (1/x) dx = 1 · ∫₀¹ e^x dx = e − 1 ≈ 1,72
Borne haute moins borne basse, dans cet ordre.
⚠️ Piège — L'ordre est F(b) − F(a) : ∫₀¹ e^x dx = e − 1, pas 1 − e. L'intégrale d'une fonction positive est positive !
✏️ Exercice 5 — Linéarité de l'intégrale (★★)

Données : calcul de ∫₀¹ (x³ + 2x) dx, ∫₁² (4x³ − 6x² + 2) dx et ∫₁² (2/x) dx.

1

Une primitive de x³ + 2x est x⁴/4 + x² (vérification : (x⁴/4 + x²)' = x³ + 2x ✓). Donc ∫₀¹ (x³ + 2x) dx = (1/4 + 1) − 0 = 5/4 = 1,25.

2

Une primitive de 4x³ − 6x² + 2 est x⁴ − 2x³ + 2x (vérification : dérivée terme à terme ✓). Donc ∫₁² (4x³ − 6x² + 2) dx = (16 − 16 + 4) − (1 − 2 + 2) = 4 − 1 = 3.

3

∫₁² (2/x) dx = 2·[ln(x)]₁² = 2·(ln(2) − ln(1)) = 2·ln(2) ≈ 2 × 0,6931 ≈ 1,39.

∫₀¹ (x³ + 2x) dx = 5/4 = 1,25
∫₁² (4x³ − 6x² + 2) dx = 3
∫₁² (2/x) dx = 2·ln(2) ≈ 1,39
La linéarité permet d'intégrer chaque terme séparément.
⚠️ Piège — Borne basse non nulle : on soustrait F(1), pas 0. Le calcul (1 − 2 + 2) = 1 de la question 2 est là pour le rappeler.
✏️ Exercice 6 — L'aire hachurée (★★)

Données : f(x) = x² sur [0 ; 2], domaine sous la courbe hachuré (voir la figure de exo_p1.html).

1

Sur [0 ; 2] : 0 ≤ x² ≤ 4, donc f(x) = x² ≥ 0 : l'intégrale de f est bien l'aire hachurée.

2

Une primitive est F(x) = x³/3 (vérification : (x³/3)' = x² ✓). Donc ∫₀² x² dx = F(2) − F(0) = 8/3 − 0 = 8/3.

3

Aire hachurée = ∫₀² x² dx = 8/3 ≈ 2,67 u.a. (car f ≥ 0 sur [0 ; 2]).

4

Valeur moyenne : m = (1/(2 − 0))·∫₀² x² dx = (1/2)·(8/3) = 8/6 = 4/3 ≈ 1,33.

∫₀² x² dx = 8/3 · aire = 8/3 ≈ 2,67 u.a. · m = 4/3 ≈ 1,33
La valeur moyenne divise l'intégrale par la longueur b − a = 2.
⚠️ Piège — La valeur moyenne divise par la longueur de l'intervalle (ici 2), pas par autre chose. Et une aire s'exprime en u.a. : jamais en cm² sans échelle donnée.
