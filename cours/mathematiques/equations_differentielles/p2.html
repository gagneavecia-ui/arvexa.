Motivation

Quand un apport constant s'invite

Imagine un réservoir d'eau d'un forage villageois : l'eau s'évapore à un rythme proportionnel au volume présent, mais une pompe ajoute en même temps un débit constant. La vitesse de variation n'est plus simplement proportionnelle au volume : un terme constant est venu s'ajouter. Mathématiquement, on obtient une équation de la forme y' = ay + b — et tu vas voir qu'elle se ramène toute entière à la partie 1.

L'idée de la partie en une phrase

Solution générale = solution particulière + solutions de l'équation homogène. Ce principe structure toute la suite du chapitre : apprends-le avec cette équation, et la partie 3 deviendra évidente.

Notion 3 · eq_y_ayb

La forme y' = ay + b et l'équation homogène

On se donne deux réels a et b avec a ≠ 0, et on cherche toutes les fonctions dérivables sur ℝ telles que, pour tout x :

📗 Définition — L'équation et son équation homogène

L'équation y' = ay + b (avec a ≠ 0 et b deux réels donnés) est dite avec second membre constant. L'équation y' = ay, obtenue en enlevant le terme b, s'appelle l'équation homogène associée (ou « équation sans second membre »).

Tu connais déjà les solutions de l'homogène : y_h(x) = C·e^(a·x). Est-ce que C·e^(a·x) résout encore y' = ay + b ? Non : en substituant, on trouve y' = a·C·e^(a·x) mais ay + b = a·C·e^(a·x) + b — il manque le b. Il faut donc ajouter quelque chose : une solution particulière de l'équation complète.

y' = ay + b = a·(y + b/a)  (valable car a ≠ 0)
Cette réécriture, anodine en apparence, contient toute la démonstration : la quantité y + b/a suit, elle, une équation homogène. On l'exploite en section 04.
02
Notion 3 · solution_particuliere

La solution particulière constante

Une solution particulière est simplement une solution de l'équation complète — n'importe laquelle, sans constante libre. Pour y' = ay + b, on la trouve en essayant le plus simple possible : une fonction constante.

1

Hypothèse : cherchons yₚ constante : yₚ(x) = c pour un certain réel c.

2

Dériver : une fonction constante a une dérivée nulle, donc yₚ' = 0.

3

Substituer dans y' = ay + b : l'équation devient 0 = a·c + b, donc a·c = −b, d'où c = −b/a (possible car a ≠ 0).

4

Vérification : pour yₚ = −b/a : yₚ' = 0 et a·(−b/a) + b = −b + b = 0 ✅ Les deux membres sont égaux : c'est bien une solution.

Solution particulière constante de y' = ay + b :  yₚ = −b/a
La droite horizontale d'ordonnée −b/a est une solution de l'équation. C'est aussi le niveau « d'équilibre » vers lequel les autres solutions convergent quand a < 0.
🧮 Mini-exemple — y' = 2y + 4

Ici a = 2 et b = 4, donc yₚ = −b/a = −4/2 = −2. Vérification : yₚ' = 0 et 2·(−2) + 4 = −4 + 4 = 0 ✅ La fonction constante y = −2 est bien une solution de y' = 2y + 4.

Erreur fréquente au Bac — le signe de −b/a

La solution particulière vaut −b/a, pas b/a ! Pour y' = 2y + 4, c'est yₚ = −2 (et non +2). Et si b est négatif, le double signe se transforme : pour y' = −3y + 6, on trouve yₚ = −6/(−3) = +2. Écris toujours le calcul 0 = a·c + b avant de conclure : deux secondes qui sauvent deux points.

Notion 4 · eq_y_ayb

La solution générale

Additionnons maintenant les deux ingrédients : la solution particulière constante yₚ = −b/a et les solutions homogènes C·e^(a·x). Le résultat est le théorème central de la partie :

📐 Théorème — Solutions de y' = ay + b (a ≠ 0)

Les solutions de y' = ay + b sont exactement les fonctions définies sur ℝ par y(x) = C·e^(a·x) − b/a, où C est un réel quelconque.

LA formule de la partie
y' = ay + b  ⇔  y(x) = C·e^(a·x) − b/a, C ∈ ℝ
Structure : solution homogène C·e^(a·x) + solution particulière −b/a. Un seul réel C libre, comme en partie 1.

Pourquoi l'addition fonctionne-t-elle ? Vérifions-le sur place, sans attendre la démonstration : si y_h résout l'homogène (y_h' = a·y_h) et si yₚ résout la complète (yₚ' = a·yₚ + b), alors la somme y = y_h + yₚ vérifie :

y' = y_h' + yₚ' = a·y_h + (a·yₚ + b) = a·(y_h + yₚ) + b = a·y + b ✅

La somme d'une solution homogène et d'une solution particulière est donc encore une solution de l'équation complète. C'est ce qu'on appelle le principe de superposition — il généralisera parfaitement en partie 3.

⚠️ L'ordre des termes

Écrire −b/a + C·e^(a·x) au lieu de C·e^(a·x) − b/a est parfaitement correct (l'addition commute). Ce qui n'est PAS correct : oublier le terme −b/a, ou l'écrire +b/a. Le correcteur cherche la constante −b/a : elle doit être visible et exacte.

Notion 4 · eq_y_ayb

Démonstration : le changement v = y + b/a

On veut montrer que toutes les solutions de y' = ay + b s'écrivent C·e^(a·x) − b/a. L'astuce : transformer l'inconnue pour retomber sur la partie 1.

💡 Démonstration complète

Soit y une solution de y' = ay + b sur ℝ (avec a ≠ 0).

1

Changement de fonction inconnue : posons v = y + b/a, c'est-à-dire y = v − b/a. La fonction v est dérivable sur ℝ comme y.

2

Dériver : v' = y' − 0 = y' (la dérivée de la constante b/a est nulle).

3

Réécrire l'équation : puisque a ≠ 0, on a ay + b = a·(y + b/a) = a·v. Donc y' = ay + b se réécrit v' = a·v : une équation homogène !

4

Résoudre (partie 1) : les solutions de v' = a·v sont v(x) = C·e^(a·x), C ∈ ℝ.

5

Revenir à y : y = v − b/a = C·e^(a·x) − b/a. Réciproquement, chaque fonction de cette forme est solution (vérification en dérivant, comme en partie 1). ∎

🧠 Technique à retenir
Le changement v = y + b/a « élimine » le second membre constant en le déplaçant dans l'inconnue. C'est un réflexe général en mathématiques : transformer un problème nouveau en un problème déjà résolu. Tu le reverras (dans l'autre sens) avec les suites auxiliaires géométriques.
⚠️ Où le a ≠ 0 est utilisé

Le réel b/a n'existe que si a ≠ 0 : c'est l'hypothèse indispensable de tout ce qui précède. (Si a = 0, l'équation devient y' = b, dont les solutions sont les fonctions affines y = b·x + C — cas à part, hors cœur du programme.)

Notion 4 · eq_y_ayb

Exemples de calculs purs

Trois calculs complets : deux résolutions, puis une résolution avec condition initiale. Le schéma est toujours le même : identifier a et b → solution particulière −b/a → solution générale → vérification.

🧮 Exemple 1 — Résoudre y' = 2y + 4
1

Identifier : a = 2, b = 4. Solution particulière constante : yₚ = −b/a = −4/2 = −2.

2

Solution générale : y(x) = C·e^(2x) − 2, C ∈ ℝ.

3

Vérification : y' = 2·C·e^(2x) ; d'autre part 2·y + 4 = 2·(C·e^(2x) − 2) + 4 = 2·C·e^(2x) − 4 + 4 = 2·C·e^(2x) ✅ Les deux membres coïncident.

🧮 Exemple 2 — Résoudre y' = −3y + 6
1

Identifier : a = −3, b = 6. Solution particulière constante : yₚ = −b/a = −6/(−3) = 2.

2

Solution générale : y(x) = C·e^(−3x) + 2, C ∈ ℝ.

3

Vérification : y' = −3·C·e^(−3x) ; d'autre part −3·y + 6 = −3·(C·e^(−3x) + 2) + 6 = −3·C·e^(−3x) − 6 + 6 = −3·C·e^(−3x) ✅

🧮 Exemple 3 — y' = 2y + 4 avec la condition initiale y(0) = 1
1

Solution générale (exemple 1) : y(x) = C·e^(2x) − 2.

2

Condition : y(0) = C·e^(2·0) − 2 = C − 2 = 1, donc C = 3.

3

Conclusion : y(x) = 3·e^(2x) − 2.

4

Double vérification : y(0) = 3·e^0 − 2 = 3 − 2 = 1 ✅ ; et y' = 6·e^(2x) tandis que 2·y + 4 = 6·e^(2x) − 4 + 4 = 6·e^(2x) ✅

⚠️ Piège de la condition initiale

Avec un second membre, la constante ne vaut pas y₀ même quand x₀ = 0 ! On a ici y(0) = C − 2, pas C : le terme −b/a participe au calcul. C'est précisément l'oubli qui coûte le plus de points dans ce type de question.

Notion 4 · eq_y_ayb

Méthode rédigée et erreurs fréquentes

🧠 Méthode à retenir — Résoudre y' = ay + b

1. Identifier les réels a et b (et vérifier a ≠ 0).
2. Solution particulière constante : yₚ = −b/a.
3. Solution générale : y(x) = C·e^(a·x) − b/a, C ∈ ℝ.
4. Si une condition initiale y(x₀) = y₀ est donnée : substituer, isoler C, puis réécrire la solution unique.
5. Vérifier en dérivant et en substituant.

Erreur fréquente au Bac — les trois classiques
  • Oublier le − b/a : écrire y = C·e^(a·x) comme réponse de y' = ay + b — c'est la solution de l'homogène, pas de la complète (substitution : il manque b).
  • Se tromper de signe : mettre +b/a au lieu de −b/a, ou rater le double signe quand b < 0 ou a < 0.
  • Se tromper d'exposant : pour y' = −3y + 6, l'exponentielle est e^(−3x) (exposant = coefficient a de y), pas e^(3x).
🔍 Contrôle express — comment le correcteur vérifie en 10 secondes

Ta réponse à y' = −3y + 6 doit vérifier trois signaux : l'exposant −3x (coefficient de y), le terme constant +2 = −b/a, et une constante C multipliant l'exponentielle. Si l'un des trois manque, la solution est fausse — d'où l'intérêt de la vérification par dérivation, qui les teste tous d'un coup.

Bilan

La recette complète

Réunissons les fils de la partie. L'équation y' = ay + b se résout en deux ingrédients : une solution particulière constante, trouvée par un calcul de trois lignes, et les solutions homogènes de la partie 1.

y' = ay + b (a ≠ 0)  ⟹  y(x) = C·e^(a·x) − b/a, C ∈ ℝ
Particulière : yₚ = −b/a (constante) · Homogène : C·e^(a·x) · Condition initiale y(x₀) = y₀ : substituer puis isoler C.
  • Équation homogène y' = ay : solutions C·e^(a·x) (partie 1).
  • Solution particulière constante : yₚ = −b/a, vérifiée par yₚ' = 0 = a·(−b/a) + b.
  • Solution générale : y(x) = C·e^(a·x) − b/a — démontrée par le changement v = y + b/a.
  • Condition initiale : la substituer dans la forme générale (attention : y(0) = C − b/a, pas C).
  • Toujours vérifier : dériver, substituer, comparer ✅
📗 Notion clé — Ce qu'il faut dire à l'examen

« Les solutions de l'équation homogène y' = ay sont C·e^(a·x). La fonction constante yₚ = −b/a est solution particulière de y' = ay + b. Donc la solution générale est y(x) = C·e^(a·x) − b/a, C ∈ ℝ. » — puis la condition initiale, puis la vérification. Cette structure rapporte tous les points de la question.

Q1 — Une solution particulière constante de y' = 3y − 6 est :

A) y = 2 B) y = −2 C) y = 6 D) y = −6
Voir la réponse
A) y = 2. yₚ = −b/a = −(−6)/3 = 2. Vérification : y' = 0 et 3·2 − 6 = 0 ✅ (Attention au double signe : b = −6, donc −b = +6.)

Q2 — La solution générale de y' = −2y + 8 est :

A) y(x) = C·e^(−2x) + 8 B) y(x) = C·e^(−2x) − 4 C) y(x) = C·e^(−2x) + 4 D) y(x) = C·e^(2x) + 4
Voir la réponse
C) y(x) = C·e^(−2x) + 4. yₚ = −b/a = −8/(−2) = 4 et l'exposant est −2x (coefficient de y). Vérification : y' = −2·C·e^(−2x) et −2·y + 8 = −2·C·e^(−2x) − 8 + 8 = −2·C·e^(−2x) ✅

Q3 — La solution de y' = 2y + 4 vérifiant y(0) = 1 est :

A) y(x) = e^(2x) − 2 B) y(x) = 3·e^(2x) − 2 C) y(x) = 3·e^(2x) + 2 D) y(x) = e^(2x) + 1
Voir la réponse
B) y(x) = 3·e^(2x) − 2. Solution générale y = C·e^(2x) − 2 ; la condition donne C − 2 = 1, donc C = 3 (et non C = 1 : le −2 compte !). Vérification : y(0) = 3 − 2 = 1 ✅ et y' = 6·e^(2x) = 2·y + 4 ✅
📌 Ce qu'il faut retenir
  • [eq_y_ayb] L'équation y' = ay + b (a ≠ 0) possède une solution particulière constante : yₚ = −b/a
  • [solution_particuliere] On la trouve en résolvant 0 = a·c + b ; vérification : yₚ' = 0 = a·(−b/a) + b ✅
  • [eq_y_ayb] Solution générale : y(x) = C·e^(a·x) − b/a, C ∈ ℝ — homogène + particulière
  • [eq_y_ayb] Démonstration : poser v = y + b/a → v' = a·v (équation homogène) → v = C·e^(a·x)
  • [eq_y_ayb] Condition initiale : substituer y(x₀) = y₀ dans la forme générale puis isoler C — attention, y(0) = C − b/a
  • [eq_y_ayb] Erreurs à bannir : oublier −b/a, erreur de signe, mauvais exposant (e^(a·x) avec a = coefficient de y)
  • [solution_particuliere] Principe de superposition : particulière + homogène = solution générale (valable aussi en partie 3)
