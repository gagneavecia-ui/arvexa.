Fonction alcool : classes et oxydation ménagée

✏️ Exercice 1 — Reconnaître et classer les alcools (★)

Données : molécules A à D de la figure (l'oxygène du —OH est en rouge).

1

Méthode : repérer le groupe —OH, puis le carbone fonctionnel qui le porte, enfin compter les atomes de carbone liés directement à lui.

2

A : CH₃—CH₂—OH → carbone fonctionnel lié à 1 seul carbone → alcool primaire (éthanol).

3

B : CH₃—CHOH—CH₃ → lié à 2 carbones → alcool secondaire (propan-2-ol).

4

C : (CH₃)₃C—OH → lié à 3 carbones → alcool tertiaire (2-méthylpropan-2-ol).

5

D : CH₃—CH₂—CH₂—OH → lié à 1 carbone → alcool primaire (propan-1-ol).

A et D : primaires · B : secondaire · C : tertiaire

Classe = nombre de carbones liés au carbone porteur du —OH.

⚠️ Piège : compter les carbones liés au carbone FONCTIONNEL, pas tous les carbones de la molécule.
✏️ Exercice 2 — Nommer les alcools (★)

Données : quatre formules semi-développées a) à d).

1

Règles : choisir la chaîne la plus longue contenant le carbone fonctionnel ; numéroter à partir de l'extrémité la plus proche du —OH ; nom = hydrocarbure parent + « -ol » + position du —OH + substituants.

2

a) CH₃—CH₂—CH₂—CH₂—OH : 4 carbones, —OH en 1 → butan-1-ol (primaire).

3

b) CH₃—CHOH—CH₃ : 3 carbones, —OH en 2 → propan-2-ol (secondaire).

4

c) (CH₃)₂CH—CH₂—OH : chaîne de 3 C portant le —OH (en 1), groupe CH₃ en 2 → 2-méthylpropan-1-ol (primaire).

5

d) CH₃—CH₂—CHOH—CH₂—CH₃ : 5 C, —OH en 3 (numérotation symétrique) → pentan-3-ol (secondaire).

a) butan-1-ol · b) propan-2-ol · c) 2-méthylpropan-1-ol · d) pentan-3-ol

Le —OH a priorité dans la numérotation de la chaîne.

⚠️ Piège : en c), la chaîne principale ne compte que 3 carbones ; le troisième CH₃ est un substituant (méthyle), pas un maillon de la chaîne.
✏️ Exercice 3 — Écrire les formules semi-développées (★★)

Données : cinq noms a) à e).

1

a) pentan-2-ol : chaîne de 5 C, —OH sur le carbone 2 → CH₃—CHOH—CH₂—CH₂—CH₃ (secondaire).

2

b) 2-méthylbutan-1-ol : chaîne de 4 C, —OH en 1, groupe CH₃ en 2 → CH₃—CH(CH₃)—CH₂—CH₂—OH (primaire).

3

c) hexan-3-ol : chaîne de 6 C, —OH en 3 → CH₃—CH₂—CHOH—CH₂—CH₂—CH₃ (secondaire).

4

d) 3-méthylbutan-2-ol : chaîne de 4 C, —OH en 2, groupe CH₃ en 3 → CH₃—CHOH—CH(CH₃)—CH₃ (secondaire).

5

e) 2-méthylbutan-2-ol : chaîne de 4 C, —OH en 2, groupe CH₃ en 2 → CH₃—C(CH₃)(OH)—CH₂—CH₃ ; le carbone fonctionnel est lié à 3 carbones → tertiaire.

a), c), d) : secondaires · b) : primaire · e) : tertiaire

Vérifier toujours le plus petit numéro possible pour le —OH.

⚠️ Piège : si le —OH n'a pas le plus petit numéro possible, la chaîne doit être renumérotée (ou lue dans l'autre sens).
✏️ Exercice 4 — Prévoir les produits d'oxydation ménagée (★★)

Données : éthanol C₂H₅OH ; propan-2-ol CH₃—CHOH—CH₃ ; 2-méthylpropan-2-ol (CH₃)₃C—OH ; oxydant doux [O].

1

Classes : éthanol → primaire (1 C lié) ; propan-2-ol → secondaire (2 C) ; 2-méthylpropan-2-ol → tertiaire (3 C).

2

Éthanol : C₂H₅OH + [O] → CH₃—CHO + H₂O (éthanal). Bilan vérifié : 2 C ; 6 H de part et d'autre ; 1 + 1 = 1 + 1 O.

3

Propan-2-ol : CH₃—CHOH—CH₃ + [O] → CH₃—CO—CH₃ + H₂O (propanone). Bilan vérifié : 3 C ; 8 H ; 2 O.

4

2-méthylpropan-2-ol : aucune réaction d'oxydation ménagée — son carbone fonctionnel ne porte aucun atome H, impossible à retirer pour créer la liaison C=O.

primaire → aldéhyde · secondaire → cétone · tertiaire → rien

Avec un excès d'oxydant, l'aldéhyde d'un primaire se poursuit en acide carboxylique.

⚠️ Piège : un alcool tertiaire résiste à l'oxydation ménagée — c'est un critère d'identification expérimentale, pas un échec de manipulation.
✏️ Exercice 5 — Retrouver l'alcool de départ (★★)

Données : quatre produits d'oxydation a) à d).

1

a) CH₃—CH₂—CH₂—CHO est un aldéhyde → alcool primaire : butan-1-ol CH₃—CH₂—CH₂—CH₂—OH ; CH₃—CH₂—CH₂—CH₂—OH + [O] → CH₃—CH₂—CH₂—CHO + H₂O.

2

b) CH₃—CO—CH₃ est une cétone (propanone) → alcool secondaire : propan-2-ol CH₃—CHOH—CH₃ ; CH₃—CHOH—CH₃ + [O] → CH₃—CO—CH₃ + H₂O.

3

c) CH₃—CO—CH₂—CH₃ est la butanone → alcool secondaire : butan-2-ol CH₃—CHOH—CH₂—CH₃ ; CH₃—CHOH—CH₂—CH₃ + [O] → CH₃—CO—CH₂—CH₃ + H₂O.

4

d) CH₃—COOH est un acide carboxylique (acide éthanoïque) → alcool primaire oxydé en deux étapes : éthanol C₂H₅OH ; C₂H₅OH + [O] → CH₃—CHO + H₂O puis CH₃—CHO + [O] → CH₃—COOH.

a) butan-1-ol · b) propan-2-ol · c) butan-2-ol · d) éthanol

Le squelette carboné du produit est celui de l'alcool : il suffit d'y remettre le —OH.

⚠️ Piège : un aldéhyde ne vient que d'un alcool primaire, une cétone que d'un secondaire ; un acide carboxylique vient d'un primaire en DEUX oxydations successives.
✏️ Exercice 6 — Choisir un alcool pour une synthèse (★★★)

Données : butanal visé CH₃—CH₂—CH₂—CHO ; alcools disponibles : butan-1-ol, butan-2-ol, 2-méthylpropan-2-ol (tous C₄H₁₀O).

1

Classes : butan-1-ol → primaire ; butan-2-ol → secondaire ; 2-méthylpropan-2-ol → tertiaire.

2

Oxydation ménagée possible pour le primaire et le secondaire ; impossible pour le tertiaire.

3

Butanal : il faut l'alcool primaire à chaîne droite → butan-1-ol : CH₃—CH₂—CH₂—CH₂—OH + [O] → CH₃—CH₂—CH₂—CHO + H₂O (bilan vérifié : 4 C ; 10 H ; 2 O).

4

Butanone : butan-2-ol : CH₃—CHOH—CH₂—CH₃ + [O] → CH₃—CO—CH₂—CH₃ + H₂O (bilan vérifié : 4 C ; 10 H ; 2 O).

5

Le 2-méthylpropan-2-ol est écarté : carbone fonctionnel sans atome H → aucune oxydation ménagée possible.

Butanal ← butan-1-ol · Butanone ← butan-2-ol · tertiaire : pas de réaction

La position du —OH décide du produit : extrémité de chaîne → aldéhyde, milieu → cétone.

⚠️ Piège : le butanal CH₃—CH₂—CH₂—CHO garde la chaîne DROITE de 4 C du butan-1-ol ; un squelette ramifié ne peut pas le donner.
