Fréquence, pulsation et équation horaire

✏️ Exercice 1 — Fréquence et pulsation d'un vibreur (★)

Données : xₘ = 2,0 cm = 0,020 m ; T = 0,50 s ; x(0) = +xₘ.

1

Fréquence : f = 1/T = 1/0,50 = 2,0 Hz.

2

Pulsation : ω = 2π/T = 2π/0,50 = 4π ≈ 12,6 rad·s⁻¹.

3

Phase : à t = 0, x(0) = xₘ·cos(φ) = xₘ, donc cos(φ) = 1 et φ = 0.

4

Équation horaire : x(t) = 2,0·cos(4π·t) cm, avec t en s.

5

Vitesse maximale : vₘ = ω·xₘ = 12,6 × 0,020 = 0,25 m·s⁻¹ (soit 25 cm·s⁻¹).

x(t) = 2,0·cos(4π·t) cm ; vₘ = 0,25 m·s⁻¹
f = 2,0 Hz ; ω ≈ 12,6 rad·s⁻¹ ; φ = 0.

⚠️ Piège : convertis xₘ en mètres avant de calculer vₘ : avec 2,0 cm tu obtiendrais 25 cm·s⁻¹ et non 0,25 m·s⁻¹.

✏️ Exercice 2 — Premier oscillogramme (★)

Données : sensibilité verticale 2 cm/div ; base de temps 5 ms/div ; courbe au maximum à t = 0.

1

Amplitude : xₘ = 3 div × 2 cm/div = 6,0 cm = 0,060 m.

2

Période : T = 4 div × 5 ms/div = 20 ms = 0,020 s.

3

Fréquence : f = 1/T = 1/0,020 = 50 Hz.

4

Pulsation : ω = 2π/T = 2π/0,020 = 100π ≈ 314 rad·s⁻¹.

5

À t = 0 la courbe est au maximum : x(0) = xₘ, donc φ = 0 et x(t) = 6,0·cos(100π·t) cm.

6

Vitesse maximale : vₘ = ω·xₘ = 314 × 0,060 = 18,8 m·s⁻¹.

x(t) = 6,0·cos(100π·t) cm ; f = 50 Hz
xₘ = 6,0 cm ; T = 20 ms ; vₘ ≈ 18,8 m·s⁻¹.

⚠️ Piège : ne confonds pas divisions et valeurs : une division ne vaut 2 cm ou 5 ms qu'après multiplication par la sensibilité. Et 20 ms = 0,020 s, pas 20 s.

Lecture graphique : amplitude, période, phase

✏️ Exercice 3 — La phase à l'origine (★★)

Données : courbe : xₘ = 2,0 cm ; T = 0,10 s ; la courbe coupe t = 0 en montant.

1

Lecture : xₘ = 2,0 cm = 0,020 m ; T = 0,10 s.

2

Fréquence et pulsation : f = 1/T = 10 Hz ; ω = 2π/T = 20π ≈ 62,8 rad·s⁻¹.

3

À t = 0 : x(0) = 0, donc xₘ·cos(φ) = 0, donc cos(φ) = 0 : φ = +π/2 ou φ = −π/2.

4

La courbe monte à l'origine : v(0) = −xₘ·ω·sin(φ) > 0, donc sin(φ) < 0, donc φ = −π/2.

5

Équation horaire : x(t) = 2,0·cos(20π·t − π/2) cm (forme équivalente : x(t) = 2,0·sin(20π·t) cm).

6

Vitesse maximale : vₘ = ω·xₘ = 62,8 × 0,020 = 1,26 ≈ 1,3 m·s⁻¹.

x(t) = 2,0·cos(20π·t − π/2) cm
f = 10 Hz ; ω ≈ 62,8 rad·s⁻¹ ; vₘ ≈ 1,3 m·s⁻¹.

⚠️ Piège : φ = +π/2 est LA faute classique : seule la vitesse initiale (courbe montante à l'origine) permet de trancher entre +π/2 et −π/2.

✏️ Exercice 4 — Accélération du point vibratoire (★★)

Données : x(t) = 5,0·cos(20π·t) cm, t en s.

1

xₘ = 5,0 cm = 0,050 m ; ω = 20π ≈ 62,8 rad·s⁻¹ ; T = 2π/ω = 0,10 s ; f = 10 Hz.

2

Vitesse : v(t) = −xₘ·ω·sin(ω·t), donc vₘ = ω·xₘ = 62,8 × 0,050 = 3,14 ≈ 3,1 m·s⁻¹.

3

Accélération : a(t) = −ω²·x(t) = −(20π)²·x(t) ≈ −3,9 × 10³·x(t), avec x en m.

4

Accélération maximale : aₘ = ω²·xₘ = 3,9 × 10³ × 0,050 = 197 ≈ 2,0 × 10² m·s⁻².

5

Pour x = +3,0 cm = 0,030 m : a = −3,9 × 10³ × 0,030 = −118 ≈ −1,2 × 10² m·s⁻².

6

a et x ont toujours des signes opposés : l'accélération, donc la force de rappel, est dirigée vers la position d'équilibre.

a = −ω²·x ; aₘ = ω²·xₘ ≈ 2,0 × 10² m·s⁻²
Quand x = +3,0 cm : a ≈ −1,2 × 10² m·s⁻².

⚠️ Piège : garde le signe « − » de a = −ω²·x et convertis x en mètres : (20π)² ≈ 3,9 × 10³.

Vitesse et accélération maximales

✏️ Exercice 5 — Vitesse : dates et valeurs (★★)

Données : x(t) = 3,0·cos(100π·t) mm, t en s.

1

ω = 100π ≈ 314 rad·s⁻¹ ; T = 2π/ω = 0,020 s = 20 ms ; f = 50 Hz.

2

xₘ = 3,0 mm = 0,0030 m ; v(t) = −xₘ·ω·sin(100π·t) ; vₘ = ω·xₘ = 314 × 0,0030 = 0,94 m·s⁻¹.

3

Premier passage en x = 0 : cos(100π·t) = 0 donne 100π·t = π/2, donc t = 1/200 = 5,0 × 10⁻³ s = 5,0 ms (soit T/4).

4

À cette date : v = −xₘ·ω·sin(π/2) = −0,94 m·s⁻¹ : la vitesse est maximale en valeur absolue et orientée vers les x négatifs.

5

À t = 0 : x = xₘ, donc a = −ω²·xₘ = −(314)² × 0,0030 = −296 ≈ −3,0 × 10² m·s⁻² : l'accélération est maximale là où la vitesse s'annule.

vₘ = 0,94 m·s⁻¹ ; aₘ ≈ 3,0 × 10² m·s⁻²
Premier passage en x = 0 à t = 5,0 ms.

⚠️ Piège : x est en mm ! Oublier de convertir 3,0 mm = 0,0030 m fausse vₘ et aₘ d'un facteur 1 000.

✏️ Exercice 6 — Oscillogramme n°2 : base de temps inconnue (★★★)

Données : sensibilité verticale 1 cm/div ; f = 50 Hz ; une période occupe 5 divisions ; maximum à t = 0.

1

Amplitude : xₘ = 2 div × 1 cm/div = 2,0 cm = 0,020 m.

2

Période : T = 1/f = 1/50 = 0,020 s = 20 ms.

3

Base de temps : la période occupe 5 divisions, donc B = T/5 = 20 ms/5 = 4 ms/div.

4

À t = 0 la courbe est au maximum, donc φ = 0 ; avec ω = 2π·f = 100π ≈ 314 rad·s⁻¹ : x(t) = 2,0·cos(100π·t) cm.

5

Vitesse maximale : vₘ = ω·xₘ = 314 × 0,020 = 6,28 ≈ 6,3 m·s⁻¹.

6

Accélération maximale : aₘ = ω²·xₘ = (314)² × 0,020 = 1 974 ≈ 2,0 × 10³ m·s⁻².

B = 4 ms/div ; x(t) = 2,0·cos(100π·t) cm
vₘ ≈ 6,3 m·s⁻¹ ; aₘ ≈ 2,0 × 10³ m·s⁻².

⚠️ Piège : B = T ÷ (nombre de divisions par période), pas l'inverse : ici 20 ms ÷ 5 div = 4 ms/div.

📌 Mémo : ω = 2π/T = 2π·f ; x(t) = xₘ·cos(ω·t + φ) ; vₘ = ω·xₘ ; a = −ω²·x ; aₘ = ω²·xₘ. À l'origine : x(0) = xₘ·cos(φ) et v(0) = −xₘ·ω·sin(φ).
