Détermination de a et b

✏️ Exercice 1 — À partir de deux points et de leurs images (★★)

Données : A(0 ; 0) → A'(0 ; −1) et B(2 ; 0) → B'(2 ; 1).

1

Comme →A'B' = a·→AB et que →AB = 2 − 0 = 2 ≠ 0, on peut diviser : a = (z_B' − z_A')/(z_B − z_A) = ((2 + i) − (−i))/2 = (2 + 2i)/2 = 1 + i.

2

b = z_A' − a·z_A = −i − (1 + i)·0 = −i : S : z' = (1 + i)z − i. Vérification sur B : (1 + i)·2 − i = 2 + 2i − i = 2 + i ✓.

3

k = |1 + i| = √2 ; θ = arg(1 + i) = π/4. Centre : ω = b/(1 − a) = (−i)/(−i) = 1 : Ω(1 ; 0).

4

z_C' = (1 + i)(1 + i) − i = (1 + 2i + i²) − i = 2i − i = i : C'(0 ; 1).

S : z' = (1 + i)z − i ; Ω(1 ; 0) ; k = √2 ; θ = π/4 ; C'(0 ; 1)
Résultats de l'exercice 1.
⚠️ Piège : un quotient complexe se traite en multipliant par le conjugué du dénominateur — ici on a évité le calcul grâce à (1 − i)(1 + i) = 2.
✏️ Exercice 2 — À partir du centre, du rapport et de l'angle (★★)

Données : centre Ω(2 ; 1), rapport 2, angle π/2 ; A(2 ; 3), B'(6 ; 5).

1

k = 2 et θ = π/2 donnent a = 2(cos(π/2) + i·sin(π/2)) = 2i. Puis b = ω(1 − a) = (2 + i)(1 − 2i) = 2 − 4i + i − 2i² = 4 − 3i : S : z' = 2iz + 4 − 3i.

2

z_A' = 2i(2 + 3i) + 4 − 3i = 4i + 6i² + 4 − 3i = −2 + i : A'(−2 ; 1).

3

→ΩA = (0 ; 2) et →ΩA' = (−4 ; 0). Produit scalaire : 0·(−4) + 2·0 = 0 : le triangle ΩAA' est rectangle en Ω. Et ΩA' = 4 = 2 × 2 = 2·ΩA : la longueur ΩA' vaut le double de ΩA, conformément au rapport k = 2 ✓.

4

z = (z' − b)/a = (6 + 5i − 4 + 3i)/(2i) = (2 + 8i)/(2i) = (1 + 4i)/i. Comme 1/i = −i : z = (1 + 4i)(−i) = −i − 4i² = 4 − i : B(4 ; −1). Vérification : 2i(4 − i) + 4 − 3i = 8i + 2 + 4 − 3i = 6 + 5i ✓.

S : z' = 2iz + 4 − 3i ; A'(−2 ; 1) ; B(4 ; −1)

Alignement et orthogonalité

✏️ Exercice 3 — Trois points alignés et leurs images (★★★)

Données : S : z' = (2 + 2i)z − 2 − 4i ; A(1 ; 1), B(2 ; 1), C(3 ; 1).

1

z = az + b donne z(1 − 2 − 2i) = −2 − 4i, soit ω = (2 + 4i)/(1 + 2i). En multipliant par 1 − 2i : (2 + 4i)(1 − 2i) = 2 − 4i + 4i − 8i² = 10 et (1 + 2i)(1 − 2i) = 5 : ω = 2, Ω(2 ; 0). Vérification : (2 + 2i)·2 − 2 − 4i = 2 ✓.

2

k = |2 + 2i| = 2√2 et θ = arg(2 + 2i) = π/4.

3

z_A' = (2 + 2i)(1 + i) − 2 − 4i = 4i − 2 − 4i = −2 : A'(−2 ; 0). z_B' = (2 + 2i)(2 + i) − 2 − 4i = 2 + 6i − 2 − 4i = 2i : B'(0 ; 2). z_C' = (2 + 2i)(3 + i) − 2 − 4i = 4 + 8i − 2 − 4i = 2 + 4i : C'(2 ; 4).

4

z_B − z_A = 1 et z_C − z_A = 2 sont réels : A, B, C sont alignés (droite d'équation y = 1). →A'B' = 2i − (−2) = 2 + 2i et →B'C' = (2 + 4i) − 2i = 2 + 2i : ces vecteurs sont égaux, donc colinéaires, et A', B', C' sont alignés.

5

Conclusion : une similitude conserve l'alignement — l'image de la droite (ABC) est la droite (A'B'C').

Ω(2 ; 0) ; k = 2√2 ; θ = π/4 ; A'(−2 ; 0), B'(0 ; 2), C'(2 ; 4)
Résultats de l'exercice 3 — →A'B' = →B'C' = 2 + 2i.
✏️ Exercice 4 — Un triangle rectangle et son image (★★★)

Données : S : z' = 2iz + 1 − 2i ; A(2 ; 0), B(3 ; 0), C(2 ; 1).

1

Pour z = 1 : 2i·1 + 1 − 2i = 1 : Ω(1 ; 0) est invariant. De plus k = |2i| = 2 et θ = arg(2i) = π/2.

2

z_A' = 2i·2 + 1 − 2i = 1 + 2i : A'(1 ; 2). z_B' = 2i·3 + 1 − 2i = 1 + 4i : B'(1 ; 4). z_C' = 2i(2 + i) + 1 − 2i = 4i − 2 + 1 − 2i = −1 + 2i : C'(−1 ; 2).

3

→AB = (1 ; 0) et →AC = (0 ; 1) : produit scalaire nul et AB = AC = 1 : ABC est rectangle isocèle en A. →A'B' = (0 ; 2) et →A'C' = (−2 ; 0) : produit scalaire nul et A'B' = A'C' = 2 : A'B'C' est rectangle isocèle en A' ✓.

4

Propriété générale : une similitude conserve l'orthogonalité et transforme un triangle rectangle en un triangle rectangle, toutes les longueurs étant multipliées par k = |a|.

Ω(1 ; 0) ; k = 2 ; θ = π/2 ; A'(1 ; 2), B'(1 ; 4), C'(−1 ; 2)
Résultats de l'exercice 4 — l'orthogonalité est conservée.

✏️ Exercice 5 — Composée de deux similitudes (★★★)

Données : S₁ : z' = iz ; S₂ : z'' = 2z' + 2 − 2i ; S = S₂ ∘ S₁ ; A(1 ; 1), B(0 ; 1), C(2 ; 1).

1

S₁ : k = 1, θ = π/2 : rotation r(O ; π/2). S₂ : k = 2, θ = 0 : homothétie de rapport 2 et de centre K d'affixe (2 − 2i)/(1 − 2) = −2 + 2i, soit K(−2 ; 2).

2

z'' = 2z' + 2 − 2i = 2(iz) + 2 − 2i = 2iz + 2 − 2i : S : z' = 2iz + 2 − 2i.

3

k = 2, θ = π/2. Centre : ω = (2 − 2i)/(1 − 2i) = (2 − 2i)(1 + 2i)/5 = (2 + 4i − 2i − 4i²)/5 = (6 + 2i)/5 = 1,2 + 0,4i : Ω(1,2 ; 0,4).

4

z_A' = 2i(1 + i) + 2 − 2i = −2 + 2i + 2 − 2i = 0 : A'(0 ; 0) = O. z_B' = 2i·i + 2 − 2i = −2 + 2 − 2i = −2i : B'(0 ; −2). z_C' = 2i(2 + i) + 2 − 2i = −2 + 4i + 2 − 2i = 2i : C'(0 ; 2).

5

B'(0 ; −2), C'(0 ; 2) et O(0 ; 0) ont tous trois une abscisse nulle : ils sont alignés sur l'axe des ordonnées ✓. En revanche →OB = (0 ; 1) et →OC = (2 ; 1) ne sont pas colinéaires : B, C, O ne sont pas alignés ✓.

6

Aucune contradiction : la propriété de conservation concerne les images des points. Or l'image de O n'est pas O mais O', avec z = 0 → 2 − 2i, soit O'(2 ; −2), qui n'appartient pas à la droite (B'C').

S : z' = 2iz + 2 − 2i ; Ω(1,2 ; 0,4) ; A'(0 ; 0), B'(0 ; −2), C'(0 ; 2)
Résultats de l'exercice 5 — B', C' et O alignés, B, C, O non alignés.
⚠️ Piège classique : « B', C', O alignés » parle du point O lui-même, pas de son image. La conservation de l'alignement s'énonce sur les trois images B', C', O'.
✏️ Exercice 6 — Sujet complet type Bac (★★★)

Données : A(1 ; 2) → A'(3 ; 3) et B(3 ; 2) → B'(5 ; 5) ; C(1 ; 0) ; (1 + i)(1 − i) = 2.

1

a = (z_B' − z_A')/(z_B − z_A) = ((5 + 5i) − (3 + 3i))/((3 + 2i) − (1 + 2i)) = (2 + 2i)/2 = 1 + i. Puis b = z_A' − a·z_A = 3 + 3i − (1 + i)(1 + 2i) = 3 + 3i − (−1 + 3i) = 4 : S : z' = (1 + i)z + 4.

2

k = |1 + i| = √2 ; θ = π/4 ; ω = 4/(1 − 1 − i) = 4/(−i) = 4i : Ω(0 ; 4).

3

z_C' = (1 + i)·1 + 4 = 5 + i : C'(5 ; 1).

4

→AB = (2 ; 0) et →AC = (0 ; −2) : produit scalaire nul, longueurs égales à 2 : ABC est rectangle isocèle en A. →A'B' = (2 ; 2) et →A'C' = (2 ; −2) : produit scalaire 4 − 4 = 0, longueurs |A'B'| = |A'C'| = 2√2 : A'B'C' est rectangle isocèle en A' ✓.

5

Réciproque : z = (z' − 4)/(1 + i) = (z' − 4)(1 − i)/((1 + i)(1 − i)) = (0,5 − 0,5i)(z' − 4) : S⁻¹ : z' = (0,5 − 0,5i)z − 2 + 2i. Son centre vaut (−2 + 2i)/(0,5 + 0,5i) = (−4 + 4i)/(1 + i) = (−4 + 4i)(1 − i)/2 = (−4 + 4i + 4i − 4i²)/2 = 8i/2 = 4i : même centre Ω(0 ; 4) que S ✓.

S : z' = (1 + i)z + 4 ; Ω(0 ; 4) ; k = √2 ; θ = π/4 ; C'(5 ; 1) ; S⁻¹ : z' = (0,5 − 0,5i)z − 2 + 2i
