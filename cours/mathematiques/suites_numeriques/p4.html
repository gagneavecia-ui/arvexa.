01
Notion 1 · bornees

Majorée, minorée, bornée

Trois mots, une seule idée : est-ce que tous les termes restent sous un plafond, au-dessus d'un plancher, ou les deux ? Le théorème central de cette partie s'énonce avec ce vocabulaire — « croissante et majorée » — et les sujets du Bac le demandent explicitement. Il faut donc savoir le définir et le démontrer.

TermeDéfinition officielleExemple
Majoréeil existe un réel M tel que, pour tout n : uₙ ≤ M (M est un majorant)1/(n + 1) ≤ 1
Minoréeil existe un réel m tel que, pour tout n : uₙ ≥ m (m est un minorant)n² ≥ 0
Bornéeà la fois minorée et majorée : m ≤ uₙ ≤ M−1 ≤ (−1)ⁿ ≤ 1
Bornée, version « valeur absolue »
(uₙ) bornée ⇔ il existe K ≥ 0 tel que |uₙ| ≤ K pour tout n
La même définition dans un autre habit : tous les termes restent à distance au plus K de 0. Preuve : de m ≤ uₙ ≤ M, pose K = max(|m| ; |M|) — et réciproquement, |uₙ| ≤ K donne −K ≤ uₙ ≤ K.
🧮 Exemple complet — La suite uₙ = n/(n + 1) est-elle bornée ?
1

On réécrit le terme général pour faire apparaître une constante :

uₙ = n/(n + 1) = ((n + 1) − 1)/(n + 1) = 1 − 1/(n + 1)

2

Comme 0 < 1/(n + 1) ≤ 1, on a −1/(n + 1) ≥ −1, d'où :

0 ≤ uₙ < 1  pour tout n

3

La suite est bornée : minorée par 0, majorée par 1. Bonus : uₙ₊₁ − uₙ = 1/((n + 1)(n + 2)) > 0 — elle est croissante. Croissante et majorée : la section 02 conclura qu'elle converge, sans même calculer sa limite.

SuiteCe qui est vraiCe qui est faux
uₙ = nminorée (par 0)pas majorée : chaque terme dépasse le précédent
uₙ = −nmajorée (par 0)pas minorée : les termes plongent indéfiniment
uₙ = (−1)ⁿbornée (−1 ≤ uₙ ≤ 1)ni croissante ni décroissante : elle oscille
📗 Prouver qu'une suite est (ma)jorée — les trois routes
  • Transformer le terme général : réécrire sous forme « constante + quotient » (n/(n + 1) = 1 − 1/(n + 1)), puis encadrer le quotient.
  • Encadrement par récurrence (partie 3) : la route reine pour les suites par récurrence — initialisation, hérédité, conclusion.
  • Comparer à une référence : 1/(n + 1) ≤ 1, 1/n ≤ 1, et 0 < qⁿ ≤ 1 si 0 < q < 1 — des majorants gratuits.
Erreur fréquente au Bac — « bornée, donc convergente »

Être bornée ne suffit jamais à conclure : (−1)ⁿ est bornée et pourtant divergente (elle oscille entre −1 et 1 sans s'accumuler nulle part). Il manque un ingrédient — la monotonie. C'est exactement le théorème de la section suivante. Et un majorant n'est pas unique : si M = 1 convient, alors 2, 100, 10⁶ aussi — la définition exige l'existence d'un majorant.

🧮 À toi de jouer — Encadrer uₙ = 5 − 1/(n + 1)

Pour tout n : 0 < 1/(n + 1) ≤ 1. On multiplie par −1 (le sens se retourne) : −1 ≤ −1/(n + 1) < 0. On ajoute 5 :

4 ≤ uₙ < 5

La suite est minorée par 4, majorée par 5, donc bornée. Contrôle : u₀ = 5 − 1 = 4, bien dans l'encadrement.

⚠️ Rédaction attendue au Bac

La définition se récite avec le « pour tout n » : « il existe un réel M tel que, pour tout n ∈ ℕ, uₙ ≤ M ». Et pour « bornée », donne les deux bornes en une seule ligne d'encadrement m ≤ uₙ ≤ M — c'est la forme que le correcteur attend.

02
Notion 2 · monotone

Le théorème de convergence monotone

Avec les gendarmes, il fallait deux suites auxiliaires qui convergent vers la même valeur. Dans une récurrence du Bac, on a rare ce luxe — mais on a presque toujours : un encadrement démontré par récurrence, et un sens de variation obtenu par le signe de uₙ₊₁ − uₙ. Le théorème de convergence monotone consomme exactement ces deux ingrédients et conclut : la suite converge. Sans jamais montrer la limite — qui reste un mystère jusqu'à la section 05.

Théorème de convergence monotone (admis)
Toute suite croissante et majorée converge.
Toute suite décroissante et minorée converge.
Le théorème est admis (pas de démonstration en Terminale) — mais ses deux hypothèses, elles, se démontrent : l'encadrement par récurrence (partie 3), la monotonie par le signe de uₙ₊₁ − uₙ (partie 1). Au Bac, ce sont ces deux démonstrations qui rapportent les points.

Pourquoi c'est plausible : imagine un escalier dont chaque marche monte, mais dont chaque nouvelle marche est plus courte que la précédente — le pied bute contre un plafond qu'il ne peut pas franchir. Les marches s'entassent contre lui, de plus en plus près : la hauteur « se stabilise ». Sans monotonie, l'argument s'effondre : une suite bornée peut zigzaguer entre plancher et plafond sans jamais se stabiliser.

La suite filée u₀ = 1 ; uₙ₊₁ = (uₙ + 3)/2 : croissante, butant contre le plafond 3 — chaque marche est plus courte que la précédente. Croissante et majorée ⇒ convergente.

🧮 Application guidée — Montrer que la suite filée converge (u₀ = 1)

Pour toute la partie, on suit la suite définie par u₀ = 1 et :

uₙ₊₁ = (uₙ + 3)/2

1

Hypothèse 1 — majorée : la récurrence de la partie 3 donne, pour tout n :

0 ≤ uₙ ≤ 3

2

Hypothèse 2 — croissante : on calcule la différence, une transformation par ligne :

uₙ₊₁ − uₙ = (uₙ + 3)/2 − uₙ = (uₙ + 3 − 2uₙ)/2 = (3 − uₙ)/2

uₙ₊₁ − uₙ = (3 − uₙ)/2 ≥ 0  car uₙ ≤ 3

3

Conclusion : la suite est croissante et majorée, donc convergente, d'après le théorème de convergence monotone. Elle converge vers une limite ℓ — dont on ne connaît pas encore la valeur. La section 05 s'en charge.

Erreur fréquente au Bac — Retire une hypothèse, et le théorème s'effondre
  • uₙ = n : croissante mais non majorée ⇒ diverge vers +∞ ;
  • uₙ = −n : décroissante mais non minorée ⇒ diverge vers −∞ ;
  • uₙ = (−1)ⁿ : bornée mais non monotone ⇒ diverge, sans limite.

« Croissante » seule ne suffit pas, « majorée » seule non plus. Énonce et démontre les deux avant de conclure.

🧮 À toi de jouer — Une décroissante minorée (w₀ = 5)

Soit wₙ₊₁ = 0,5·wₙ + 2. Encadrement par récurrence : w₀ = 5 et 4 ≤ 5 ≤ 5 (vrai) ; si 4 ≤ wₙ ≤ 5, alors 2 ≤ 0,5·wₙ ≤ 2,5, donc 4 ≤ 0,5·wₙ + 2 ≤ 4,5 ≤ 5 : héréditaire. Conclusion : 4 ≤ wₙ ≤ 5 pour tout n. Monotonie : wₙ₊₁ − wₙ = 0,5·wₙ + 2 − wₙ = (4 − wₙ)/2 ≤ 0 car wₙ ≥ 4 : décroissante. Conclusion : décroissante et minorée ⇒ convergente (premiers termes : 5 ; 4,5 ; 4,25 ; 4,125 … ils descendent vers 4 sans le franchir).

Notion 3 · limite_qn_somme

Le tableau complet de qⁿ et la somme géométrique

La partie 3 a donné le résultat sans le justifier : |q| < 1 ⇒ qⁿ → 0. Cette section le déplie : chaque cas, chaque valeur limite. Ce tableau est la référence n° 1 du chapitre : toute forme close contenant qⁿ (point fixe, somme, intérêts composés) finit par lui demander son verdict.

Raison qlim(n→+∞) qⁿCe qui se passe
0 < q < 10les termes rétrécissent et s'accumulent contre 0
−1 < q < 00signes alternés mais taille |q|ⁿ fondante
q > 1+∞les termes grossissent sans limite
q = 11suite constante : 1ⁿ = 1 pour tout n
q = 00tous les termes nuls dès le rang 1
q ≤ −1pas de limiteles signes alternent, la suite oscille sans s'accumuler
💡 Pourquoi 0 < q < 1 écrase qⁿ — l'argument du couloir

Prenons q = 0,9 et un seuil de 0,001. 1. Les puissances décroissent : 0,9^(n + 1) = 0,9 × 0,9ⁿ < 0,9ⁿ. 2. À la calculatrice : 0,9⁶⁵ ≈ 0,00106 puis 0,9⁶⁶ ≈ 0,000955 — le rang N = 66 est franchi. 3. Et pour tout n ≥ 66 : qⁿ = q⁶⁶ × q^(n − 66) ≤ q⁶⁶ < 0,001 — tous les termes restent enfermés sous le seuil. 4. Le seuil 0,001 n'a rien de sacré : les termes s'accumulent contre 0 — c'est la convergence. Pour q > 1 : chaque multiplication grossit — divergence vers +∞. Pour q ≤ −1 : les signes alternent, rien ne s'accumule — pas de limite.

🧮 Cinq destinées, une ligne chacune

1. lim (0,6)ⁿ = 0 (car 0 < 0,6 < 1) — 2. lim (1,4)ⁿ = +∞ (car 1,4 > 1) — 3. lim 1ⁿ = 1 (suite constante) — 4. lim 0ⁿ = 0 (nul dès le rang 1) — 5. (−3/2)ⁿ n'a pas de limite (car −3/2 ≤ −1 : les termes valent alternativement −(3/2)ⁿ et +(3/2)ⁿ).

🧮 Les formes closes passent au verdict

1. uₙ = 3 + 2 × (0,8)ⁿ : (0,8)ⁿ → 0, donc uₙ → 3 (la constante survit, le terme géométrique s'éteint). 2. vₙ = 5 × (0,9)ⁿ → 0. 3. wₙ = (1 + t)ⁿ avec t > 0 : raison 1 + t > 1, donc wₙ → +∞ — la croissance des intérêts composés. 4. zₙ = 4 − 2 × (0,5)ⁿ → 4 — la tontine de la section 05.

Erreur fréquente au Bac — Le piège mortel : q ≤ −1 (et sa jumelle)

Pour q ≤ −1, n'écris jamais lim (−2)ⁿ = −∞ : les termes alternent les signes (−2 ; 4 ; −8 ; 16 …) — la rédaction correcte est « la suite ((−2)ⁿ) diverge, elle n'a pas de limite ». À l'inverse, ne rejette pas trop vite une raison négative petite : (−0,5)ⁿ → 0, car |−0,5| < 1. Le tri se fait sur |q| devant 1, puis sur le signe de q.

La somme des termes d'une suite géométrique — démontrée et dépliée

1 + 2 + 4 + 8 + ⋯ + 2ⁿ : additionner terme à terme est impossible dès que n grandit. La formule remplace une addition de n + 1 termes par une seule ligne. Sa démonstration — le « coup du décalage » — est un geste universel qu'on refait ici en entier.

Somme des termes d'une suite géométrique (q ≠ 1)
S = u₀ + u₀·q + ⋯ + u₀·qⁿ = u₀ × (1 − q^(n + 1))/(1 − q)
Cas q = 1 : la formule est interdite (division par zéro) — mais tous les termes sont égaux : S = (n + 1) × u₀. Somme du rang p au rang n (p ≤ n) : S = uₚ × (1 − q^(n − p + 1))/(1 − q), qui contient n − p + 1 termes.
1

Écris la somme S, puis multiplie-la par q — la seconde ligne contient exactement les mêmes termes, décalés d'un cran :

S = u₀ + u₀·q + u₀·q² + ⋯ + u₀·qⁿ

q × S = u₀·q + u₀·q² + ⋯ + u₀·qⁿ + u₀·q^(n + 1)

2

Soustrais membre à membre — tout le milieu disparaît :

qS − S = u₀·q^(n + 1) − u₀

3

Factorise, puis divise par q − 1 (légal car q ≠ 1) :

S·(q − 1) = u₀·(q^(n + 1) − 1)

S = u₀ × (q^(n + 1) − 1)/(q − 1) = u₀ × (1 − q^(n + 1))/(1 − q)

4

Contrôle immédiat : 1 + 2 + 4 = 7 et la formule donne 1 × (1 − 2³)/(1 − 2) = (−7)/(−1) = 7.

🧮 Exemple complet — 1 + 1/2 + 1/4 + ⋯ + 1/2¹⁰
1

Identifier : u₀ = 1, q = 1/2, du rang 0 au rang 10 : 11 termes (exposant n + 1 = 11).

2

Appliquer la formule :

S = 1 × (1 − (1/2)¹¹)/(1 − 1/2) = 2 × (1 − 1/2¹¹) = 2 − 1/2¹⁰

3

Conclure : S = 2 − 1/1024 = 2047/1024 ≈ 1,999. Onze termes additionnés et on reste sous 2 — et on y restera quel que soit le nombre de termes.

📗 Le théorème inattendu — la somme partielle elle-même converge

Regarde la somme partielle Sₙ = 1 + q + q² + ⋯ + qⁿ avec 0 < q < 1. Croissante : Sₙ₊₁ = Sₙ + q^(n + 1) > Sₙ (on ajoute un terme positif). Majorée : Sₙ = (1 − q^(n + 1))/(1 − q) < 1/(1 − q). Croissante et majorée : par le théorème de convergence monotone, la somme partielle converge ! Avec q = 1/2 : Sₙ = 2 − 1/2ⁿ → 2 — elle s'accumule contre 2 sans jamais l'atteindre.

Erreur fréquente au Bac — Les trois fautes de la somme géométrique

1. L'exposant : pour une somme jusqu'à uₙ, c'est q^(n + 1) — l'exposant compte les termes (n + 1), il ne vaut jamais le dernier rang tel quel. 2. Le décompte : du rang p au rang n, il y a n − p + 1 termes — écris ce calcul sur ta copie. 3. Le cas q = 1 : formule interdite ; la somme vaut alors (n + 1) × u₀.

Notion 4 · applications

Intérêts composés, versements fixes, temps de doublement

Un capital placé, une épargne mensuelle, une population qui croît de 3 % par an : tous ces phénomènes « en pourcentage constant » sont des suites géométriques, et leurs questions d'examen demandent presque toujours l'un des trois gestes de cette partie : le terme général (où en est-on après n périodes ?), la somme (combien au total ?), ou le temps de doublement (au bout de combien de périodes ?).

Capital placé : uₙ = C × (1 + t)ⁿ
Un capital C à un taux t par période (t en décimal : 4 % = 0,04) devient uₙ après n périodes — suite géométrique de raison 1 + t. Pourquoi 1 + t ? Chaque année le capital conserve sa valeur (× 1) et gagne t fois sa valeur (× t) : au total × (1 + t).
Épargne à versements fixes — D déposé à la fin de chaque période
Tₙ = D × ((1 + t)ⁿ − 1)/t
Le total au bout de n périodes, chaque dépôt capitalisant au taux t. C'est une somme géométrique déguisée : le dépôt de fin de période k vaut D × (1 + t)^(n − k) au bout du compte.
1

D'où vient la formule ? Le total des dépôts capitalisés :

Tₙ = D·(1 + t)^(n − 1) + D·(1 + t)^(n − 2) + ⋯ + D·(1 + t) + D

2

Lue à l'envers, c'est n termes d'une suite géométrique de premier terme 1 et de raison q = 1 + t ≠ 1 :

Tₙ = D × [1 + q + ⋯ + q^(n − 1)] = D × (1 − qⁿ)/(1 − q)

3

Avec q = 1 + t, on a 1 − q = −t, d'où la formule. Contrôle : pour n = 1, T₁ = D × ((1 + t) − 1)/t = D — un seul dépôt, pas encore capitalisé.

🧮 Exemple complet — L'épargne d'Aïcha (20 000 F par an à 4 %)

Aïcha dépose 20 000 F à la fin de chaque année sur un compte à 4 % par an (intérêts composés). Combien possède-t-elle juste après le 6ᵉ dépôt ?

1

Modéliser : D = 20 000 F, t = 0,04, n = 6 périodes.

2

Calculer la puissance (une par ligne) :

1,04² = 1,0816 ; 1,04³ = 1,124864 ; 1,04⁶ ≈ 1,2653190

3

Appliquer la formule :

T₆ = 20 000 × (1,04⁶ − 1)/0,04 = 20 000 × 0,2653190/0,04

T₆ = 20 000 × 6,632976 ≈ 132 659,51 F

4

Lecture financière : elle a versé 6 × 20 000 = 120 000 F ; les intérêts capitalisés ont produit environ 12 659,51 F — c'est le salaire de la patience.

🧮 Exemple — L'arbre binaire : la croissance qui double

Chaque nœud d'un arbre de décision porte exactement 2 branches. La génération k contient 2ᵏ nœuds — suite géométrique de raison 2. Jusqu'à la génération 10 (11 générations, du rang 0 au rang 10) :

1 + 2 + 4 + ⋯ + 2¹⁰ = (1 − 2¹¹)/(1 − 2) = 2¹¹ − 1 = 2047 nœuds

Dix générations suffisent pour dépasser les deux mille nœuds — la même explosion que la légende de Sissa (partie 2).

Le temps de doublement

(1 + t)ⁿ = 2  ⇒  n = ln 2/ln(1 + t)
Méthode Bac (sûre) : essais successifs à la calculatrice, puis conclusion par encadrement. Approfondissement : la fonction ln transforme l'exposant en facteur — n × ln(1 + t) = ln 2. On arrondit toujours vers le haut : n doit être un entier qui atteint le doublement.
🧮 Exemple complet — Doublement à 3,7 % par an
1

Équation : (1,037)ⁿ = 2.

2

Essais successifs : 1,037¹⁹ ≈ 1,994 < 2 ; 1,037²⁰ ≈ 2,068 > 2.

3

Conclusion : le capital double au bout de 19 ans — la 20ᵉ année le dépasse déjà. Contrôle par le logarithme : n = ln 2/ln 1,037 ≈ 0,693/0,0363 ≈ 19,1 : cohérent.

⚠️ Le taux en décimal, la période en face

Le taux doit être écrit en décimal : 4 % donne t = 0,04, pas 4 — sinon les montants sont absurdes. Et le résultat hérite de la période du taux : un taux annuel donne des années, un taux mensuel des mois. Pour un temps de doublement, arrondis toujours vers le haut : au rang 19 le capital n'est pas encore doublé (1,994 < 2) — répondre « 18 ans » serait faux.

📗 Rédaction attendue au Bac

Toute application financière commence par une phrase de modélisation : « notons uₙ le capital (en F) après n années ; chaque année le capital est multiplié par 1,04, donc uₙ₊₁ = 1,04·uₙ : (uₙ) est géométrique de raison 1,04 et de premier terme u₀ = 20 000 ». Sans cette phrase, les calculs flottent — avec elle, chaque ligne s'appuie sur le modèle.

05
Notion 5–6 · point_fixe_heredites

Le point fixe, les hérédités délicates et la grande synthèse

Le théorème de convergence monotone dit « la suite converge » — mais pas vers quoi. Le point fixe comble le trou : si les termes s'immobilisent près de ℓ et si f est continue en ℓ, alors f laisse ℓ immobile aussi. C'est la méthode la plus demandée du Bac sur les récurrences : elle transforme une question de limite en une équation — souvent du premier degré, parfois du second.

Théorème du point fixe — pour une suite uₙ₊₁ = f(uₙ)
uₙ → ℓ et f continue en ℓ ⇒ f(ℓ) = ℓ
La limite est un point fixe de f : on la trouve en résolvant l'équation f(ℓ) = ℓ. Si l'équation a plusieurs solutions, on garde celle compatible avec l'encadrement des termes.
🧠 La méthode du point fixe — les 4 temps
  • Prouver la convergence (encadrement + monotonie + convergence monotone) — on ne cherche jamais la limite d'une suite dont l'existence de la limite n'est pas établie.
  • Écrire l'équation au point fixe : ℓ = f(ℓ).
  • Résoudre en ℓ (souvent du 1ᵉʳ ou 2ᵈ degré), une ligne par étape.
  • Filtrer : garder la solution compatible avec l'encadrement, puis conclure lim(n→+∞) uₙ = ℓ.
🧮 Exemple complet — La tontine d'Aïcha se stabilise à 4 000 F

Chaque semaine, Aïcha prélève la moitié de son solde, puis ajoute un apport fixe de 2 000 F. Solde en milliers de F : u₀ = 2 et uₙ₊₁ = 0,5·uₙ + 2. Vers quel solde se stabilise la tontine ?

1

Diagnostic : forme a·uₙ + b avec a = 0,5 et b = 2 (a ≠ 1) : suite arithmético-géométrique.

2

Point fixe, une ligne à la fois :

ℓ = 0,5·ℓ + 2

0,5·ℓ = 2

ℓ = 4

3

Suite auxiliaire — l'écart au point fixe, une transformation par ligne :

vₙ = uₙ − 4

vₙ₊₁ = uₙ₊₁ − 4 = 0,5·uₙ + 2 − 4 = 0,5·uₙ − 2

vₙ₊₁ = 0,5·(uₙ − 4) = 0,5 × vₙ

(vₙ) est géométrique de raison 0,5, avec v₀ = 2 − 4 = −2.

4

Forme explicite :

vₙ = −2 × (0,5)ⁿ

uₙ = 4 − 2 × (0,5)ⁿ

5

Contrôle : u₁ = 0,5 × 2 + 2 = 3 et la formule donne 4 − 2 × 0,5 = 3 — même accord pour u₂ = 3,5.

6

Limite et conclusion : 0 < 0,5 < 1 donc (0,5)ⁿ → 0, d'où uₙ = 4 − 2 × (0,5)ⁿ → 4. Le solde se stabilise à 4 000 F — quelle que soit la mise de départ.

Les soldes de la tontine (u₀ = 2 ; uₙ₊₁ = 0,5·uₙ + 2) montent et se collent au plafond ℓ = 4 : la forme close uₙ = 4 − 2 × (0,5)ⁿ le confirme, et (0,5)ⁿ → 0 achève la preuve.

Erreur fréquente au Bac — Deux garde-fous du point fixe

1. L'ordre : convergence d'abord, équation ensuite — résoudre f(ℓ) = ℓ ne prouve rien si la suite diverge. 2. Le filtre : quand l'équation donne plusieurs solutions, l'encadrement tranche. Exemple type : ℓ² = 2 + ℓ donne ℓ = 2 ou ℓ = −1 ; pour une suite dont tous les termes sont positifs, la limite ne peut être que 2.

Récurrence avancée — les hérédités délicates

Sur les récurrences « simples » (uₙ₊₁ = a·uₙ + b), l'hérédité est une transformation douce. Mais les sujets corsés glissent des racines carrées, des produits, des puissances — et chaque geste peut casser la logique.

📗 Les règles de sécurité d'une hérédité délicate
  • Ne jamais multiplier ou diviser une inégalité par un nombre de signe inconnu — traiter d'abord le signe.
  • Élever au carré : « a ≤ b avec 0 ≤ a et 0 ≤ b ⇒ a² ≤ b² » est légal (carrés ordonnés) ; passer d'une équation au carré (ℓ = √(2 + ℓ) devient ℓ² = 2 + ℓ) exige ℓ ≥ 0.
  • Une opération par ligne, justifiée en fin de ligne — jamais deux transformations en même temps.
  • Si la propriété réclame deux rangs (type uₙ₊₂ = uₙ₊₁ + uₙ) : initialiser deux rangs, puis démontrer « P(n) et P(n + 1) ⇒ P(n + 2) » — la double récurrence.
🧮 L'exemple royal — u₀ = 0 et uₙ₊₁ = √(2 + uₙ) : encadrement, convergence, limite
1

Objectif A — encadrement 0 ≤ uₙ < 2 par récurrence. Initialisation : u₀ = 0 et 0 ≤ 0 < 2 (vrai). Hérédité : si 0 ≤ uₙ < 2, alors 2 ≤ 2 + uₙ < 4 ; la racine carrée est croissante sur [0 ; +∞[, donc :

√2 ≤ √(2 + uₙ) < 2  c'est-à-dire  √2 ≤ uₙ₊₁ < 2

Et comme √2 > 0 : 0 ≤ uₙ₊₁ < 2 — héréditaire. Conclusion : la suite est majorée par 2.

2

Objectif B — monotonie (le geste délicat) : on compare les carrés (posés, donc positifs) :

uₙ₊₁² − uₙ² = (2 + uₙ) − uₙ² = (2 − uₙ)(1 + uₙ) > 0

car uₙ < 2 et uₙ ≥ 0. Donc uₙ₊₁² > uₙ² avec les deux termes positifs : en prenant la racine (croissante), uₙ₊₁ > uₙ — la suite est croissante.

3

Objectif C — convergence : croissante et majorée ⇒ convergente (théorème de convergence monotone), vers une limite ℓ ≥ 0.

4

Objectif C — limite par le point fixe : f(x) = √(2 + x) est continue en ℓ, donc :

ℓ = √(2 + ℓ)  donc  ℓ² = 2 + ℓ  donc  ℓ² − ℓ − 2 = 0

(ℓ − 2)(ℓ + 1) = 0 : ℓ = 2 ou ℓ = −1. Filtrage : ℓ ≥ 0 élimine −1, donc lim(n→+∞) uₙ = 2.

5

Contrôle numérique : u₁ = √2 ≈ 1,41 ; u₂ ≈ 1,85 ; u₃ ≈ 1,96 ; u₄ ≈ 1,99 — la montée bute contre 2, exactement comme l'escalier de la section 02.

Inégalité de croissance : 2ⁿ ≥ n + 1 pour tout n ∈ ℕ
Par récurrence : 2⁰ = 1 ≥ 1 (initialisation) ; si 2ⁿ ≥ n + 1, on multiplie par 2 (positif) : 2^(n + 1) ≥ 2n + 2, et 2n + 2 ≥ n + 2 car n ≥ 0 — donc 2^(n + 1) ≥ (n + 1) + 1. Le point délicat : justifier le chaînon 2n + 2 ≥ n + 2, pas le déclarer.

Et les réflexes Bac qui cochent les points de méthode :

  • Une application financière → commencer par la phrase de modélisation (« notons uₙ … (uₙ) est géométrique de raison … »).
  • « Montrer que ça converge » → deux blocs étiquetés « Hypothèse 1 : majorée » (récurrence) et « Hypothèse 2 : croissante » (signe de la différence), puis la phrase : « croissante et majorée, donc convergente d'après le théorème de convergence monotone ».
  • « Déterminer la limite » → les 4 temps du point fixe, chacun étiqueté — sauter le temps 1 est la faute la plus coûteuse du chapitre.
  • Une forme close trouvée → la vérifier sur u₀, u₁, u₂ recalculés par la récurrence : une phrase qui coûte 10 secondes et sécurise la moitié des points.
  • Une somme géométrique → écrire « il y a … termes », vérifier q ≠ 1, contrôler sur un petit cas.
  • Une hérédité délicate → chaque geste sensible porte sa justification : « (2 est positif : le sens est conservé) », « (la racine est croissante sur [0 ; +∞[) », « (les deux membres sont positifs : carrés ordonnés) ».

Q1 — Toute suite croissante et majorée est :

A) convergenteB) divergenteC) constanteD) sans limite
Voir la réponse
A) convergente — c'est le théorème de convergence monotone ; sa limite est un réel ℓ ≤ M, pas forcément égal au majorant.

Q2 — Que vaut lim(n→+∞) (−0,5)ⁿ ?

A) 0B) −0,5C) pas de limiteD) −∞
Voir la réponse
A) 0 — |−0,5| < 1 : les signes alternent mais la taille (0,5)ⁿ fond vers 0. C'est le cas |q| < 1 du tableau.

Q3 — 1 + 2 + 4 + ⋯ + 2ⁿ vaut :

A) 2^(n + 1) − 1B) 2ⁿ − 1C) (1 − 2ⁿ)/(1 − 2)D) 2^(n + 2) − 1
Voir la réponse
A) 2^(n + 1) − 1 — somme géométrique u₀ = 1, q = 2, du rang 0 au rang n : n + 1 termes, exposant n + 1. Contrôle : pour n = 2, 1 + 2 + 4 = 7 = 2³ − 1.
