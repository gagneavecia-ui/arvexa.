Réactions acide-base et titrages

✏️ Exercice 1 — Neutralisation d'un acide fort par une base forte (★★)

Données : V₁ = 10,0 mL et V₂ = 20,0 mL ; C₁ = C₂ = 0,010 mol·L⁻¹ ; pKa(H₃O⁺/H₂O) = 0 ; pKa(H₂O/OH⁻) = 14,0 ; 25 °C.

1

Équation : H₃O⁺ + OH⁻ → 2 H₂O (atomes : 4 H et 2 O de chaque côté ; charges : 0 = 0). Couples : H₃O⁺/H₂O (l'acide cède le proton) et H₂O/OH⁻ (la base capte le proton).

2

Constante : K = 10^(pKa₂ − pKa₁) = 10^(14,0 − 0) = 10^(14), valeur énorme : la réaction de neutralisation est totale.

3

pH du mélange. n(H₃O⁺) = 0,010 × 0,0100 = 1,0 × 10⁻⁴ mol ; n(OH⁻) = 0,010 × 0,0200 = 2,0 × 10⁻⁴ mol. La réaction étant totale, il reste 1,0 × 10⁻⁴ mol de OH⁻ dans V = 30,0 mL : [OH⁻] = 1,0 × 10⁻⁴/0,0300 = 3,3 × 10⁻³ mol·L⁻¹. D'où pOH = 2,5 et pH = 14,0 − 2,5 = 11,5.

4

Cas stoïchiométrique : avec V₂ = 10,0 mL, les quantités d'H₃O⁺ et de OH⁻ sont égales : tout est consommé et il ne reste que de l'eau, donc [H₃O⁺] = [OH⁻] et pH = 7,0 à 25 °C (solution neutre).

K = 10^(14) ; pH = 11,5 (base en excès) ; pH = 7,0 (mélange stoïchiométrique)
La neutralisation acide fort/base forte est totale : le pH final est dicté par le réactif en excès.
⚠️ Piège : déterminer le réactif limitant AVANT tout calcul de pH. Un excès de base donne un pH basique, un excès d'acide un pH acide, l'égalité un pH neutre.
✏️ Exercice 2 — Identifier un acide inconnu par titrage (★★★)

Données : V_a = 10,0 mL ; C_a = 0,10 mol·L⁻¹ ; c_B = 0,10 mol·L⁻¹ ; candidats : HCOOH (3,8), CH₃—COOH (4,8), H₂CO₃ (6,4).

1

Équation de titrage : HA + OH⁻ → A⁻ + H₂O (atomes et charges équilibrés). Couple 1 : HA/A⁻ ; couple 2 : H₂O/OH⁻.

2

Équivalence : le saut de pH se situe à V_E = 10,0 mL. Vérification : c_B × V_E = 0,10 × 10,0 = 1,0 × 10⁻³ mol et C_a × V_a = 0,10 × 10,0 = 1,0 × 10⁻³ mol : les quantités coïncident, la lecture est cohérente.

3

Identification. À la demi-équivalence (V = 5,0 mL), on lit pH = 3,8 sur la courbe, donc pKa = 3,8 : l'acide inconnu est l'acide méthanoïque HCOOH (les deux autres candidats donnent 4,8 et 6,4, exclus).

4

Constante du titrage : K = 10^(pKa₂ − pKa₁) = 10^(14,0 − 3,8) = 10^(10,2) = 1,6 × 10¹⁰, très supérieure à 10⁴ : la réaction de titrage est totale, le titrage est valide.

V_E = 10,0 mL ; pKa = 3,8 → acide méthanoïque HCOOH
Le pH lu à la demi-équivalence est la signature du couple titré : c'est la méthode d'identification.
⚠️ Piège : c'est à la demi-équivalence (V_E/2 = 5,0 mL) qu'on lit le pKa, pas à l'équivalence où le pH vaut environ 8,3 (présence de la base conjuguée HCOO⁻).
✏️ Exercice 3 — Mélange d'un acide faible et d'une base faible : bilan de matière (★★★)

Données : V₁ = 20,0 mL, C₁ = 0,10 mol·L⁻¹ ; V₂ = 10,0 mL, C₂ = 0,10 mol·L⁻¹ ; K = 2,5 × 10⁴ ; pKa = 4,8.

1

Quantités initiales : n₀(CH₃—COOH) = 0,10 × 0,0200 = 2,0 × 10⁻³ mol et n₀(NH₃) = 0,10 × 0,0100 = 1,0 × 10⁻³ mol.

2

Réactif limitant : K = 2,5 × 10⁴ est très supérieure à 10⁴, la réaction est donc totale et le réactif limitant est épuisé : c'est NH₃ (1,0 × 10⁻³ inférieur à 2,0 × 10⁻³ mol). État final : n(NH₃) ≈ 0 ; n(CH₃—COO⁻) ≈ n(NH₄⁺) ≈ 1,0 × 10⁻³ mol ; n(CH₃—COOH) ≈ 2,0 × 10⁻³ − 1,0 × 10⁻³ = 1,0 × 10⁻³ mol.

3

pH du mélange. Il reste 1,0 × 10⁻³ mol de CH₃—COOH et il s'est formé 1,0 × 10⁻³ mol de CH₃—COO⁻, dans le même volume : [CH₃—COOH] = [CH₃—COO⁻]. Dans Ka = [CH₃—COO⁻]·[H₃O⁺]/[CH₃—COOH], les concentrations égales se simplifient : [H₃O⁺] = Ka, donc pH = pKa = 4,8.

4

Sensibilité de l'équilibre : un ajout d'acide fort (H₃O⁺) consommerait CH₃—COO⁻, un ajout de base forte (OH⁻) consommerait CH₃—COOH : l'équilibre équimolaire serait détruit et le pH s'écarterait de 4,8. Tant qu'on n'ajoute rien de tel, ce mélange équimolaire constitue une solution tampon.

NH₃ limitant ; pH ≈ pKa = 4,8
Réaction totale + mélange final équimolaire AH/A⁻ : le pH se lit sur le pKa.
⚠️ Piège : « réaction totale » signifie qu'on raisonne avec le réactif limitant épuisé. C'est ce raisonnement qui fournit le mélange équimolaire, pas un calcul de pH direct.

Synthèse type Bac : autour du bicarbonate

✏️ Exercice 4 — Le vinaigre et le bicarbonate (★★★)

Données : pKa(CH₃—COOH/CH₃—COO⁻) = 4,8 ; pKa(H₂CO₃/HCO₃⁻) = 6,4 ; V_m = 24,5 L·mol⁻¹ ; n(CH₃—COOH) = 2,0 × 10⁻³ mol ; n(HCO₃⁻) = 1,0 × 10⁻³ mol.

1

Vérification de l'équation : CH₃—COOH + HCO₃⁻ ⇌ CH₃—COO⁻ + H₂CO₃. Atomes : 3 C, 5 H et 5 O de chaque côté ; charges : −1 = −1. Elle est équilibrée en atomes et en charges.

2

Constante : couple 1 : CH₃—COOH/CH₃—COO⁻ (4,8) ; couple 2 : H₂CO₃/HCO₃⁻ (6,4). K = 10^(6,4 − 4,8) = 10^(1,6) = 40. Le sens direct est favorisé (K supérieure à 1) mais la réaction est LIMITÉE (K inférieure à 10⁴) : elle ne détruit pas totalement les réactifs en l'absence d'autre phénomène.

3

Rôle du gaz : l'acide carbonique formé se décompose (H₂CO₃ → CO₂ + H₂O) et le CO₂ s'échappe sous forme de bulles. La disparition continuelle de H₂CO₃ empêche la réaction inverse de s'installer : le système continue d'évoluer dans le sens direct jusqu'à épuisement du réactif limitant. Le dégagement gazeux visible est la preuve de cette évolution.

4

Bilan de matière : n(HCO₃⁻) = 1,0 × 10⁻³ mol est inférieur à n(CH₃—COOH) = 2,0 × 10⁻³ mol : le bicarbonate est limitant. D'après l'équation, n(CO₂) = n(HCO₃⁻) = 1,0 × 10⁻³ mol, d'où V = n × V_m = 1,0 × 10⁻³ × 24,5 = 2,45 × 10⁻² L = 24,5 mL ≈ 25 mL de CO₂.

K = 40 (sens direct favorisé, réaction limitée) ; V(CO₂) ≈ 25 mL
Le départ du CO₂ « tire » la réaction vers l'avant : la fusée de cuisine est un couplage de deux phénomènes.
⚠️ Piège : K = 40 ne signifie pas réaction totale (seuil usuel : 10⁴). Et pour le volume de gaz, vérifier le réactif limitant avant de conclure : ici c'est HCO₃⁻, pas CH₃—COOH.
✏️ Exercice 5 — Le pH de la solution de bicarbonate (★★★)

Données : C = 0,10 mol·L⁻¹ ; pKa(H₂CO₃/HCO₃⁻) = 6,4 ; pKa(HCO₃⁻/CO₃²⁻) = 10,3 ; pKa(H₃O⁺/H₂O) = 0 ; pH mesuré 8,4.

1

Deux demi-équations : comme acide (couple HCO₃⁻/CO₃²⁻) : HCO₃⁻ ⇌ CO₃²⁻ + H⁺ ; comme base (couple H₂CO₃/HCO₃⁻) : H₂CO₃ ⇌ HCO₃⁻ + H⁺. L'ion HCO₃⁻ est bien un ampholyte.

2

Réaction entre deux ions HCO₃⁻ : 2 HCO₃⁻ ⇌ H₂CO₃ + CO₃²⁻. Couple 1 : HCO₃⁻/CO₃²⁻ (10,3) ; couple 2 : H₂CO₃/HCO₃⁻ (6,4) ; donc K = 10^(6,4 − 10,3) = 10^(−3,9) = 1,3 × 10⁻⁴.

3

Interprétation : K très inférieure à 1 : la réaction est très limitée. La solution contient donc essentiellement des ions HCO₃⁻, avec de très faibles quantités de H₂CO₃ et de CO₃²⁻ issues de cette réaction.

4

pH de l'ampholyte : pH = ½(pKa₁ + pKa₂) = ½(6,4 + 10,3) = 8,35 ≈ 8,4, en accord parfait avec le pH mesuré. Comme 8,4 est supérieur à 7, la solution est basique.

5

Contre l'acidité de l'estomac : HCO₃⁻ + H₃O⁺ → H₂CO₃ + H₂O (atomes et charges équilibrés : 0 = 0). Couple 1 : H₃O⁺/H₂O (0) ; couple 2 : H₂CO₃/HCO₃⁻ (6,4) ; K = 10^(6,4 − 0) = 10^(6,4) = 2,5 × 10⁶ : réaction totale. Le bicarbonate consomme l'excès d'ions H₃O⁺ : il neutralise l'acidité, avec dégagement de CO₂ (le fameux « rots » chimique).

K = 1,3 × 10⁻⁴ ; pH ≈ 8,4 ; K(HCO₃⁻/H₃O⁺) = 2,5 × 10⁶
Ampholyte basique : pH moyen des deux pKa ; face à un acide fort, le bicarbonate neutralise totalement.
⚠️ Piège : ne pas confondre les deux rôles de HCO₃⁻ : face à un acide il est BASE (couple H₂CO₃/HCO₃⁻), face à une base il est ACIDE (couple HCO₃⁻/CO₃²⁻). Le sens de K = 10^(pKa₂ − pKa₁) en dépend.
