Comment utiliser cette fiche

Cette partie ne raconte pas d'histoire : elle condense. Les parties 1 à 3 ont construit la fonction ; ici, tout est mis à plat pour réviser vite et bien, puis faire tourner la machine sur les questions d'examen — équations, inéquations, petits problèmes concrets. Utilise-la en trois temps :

Trois passages recommandés

  • Passage 2 (mémorisation) : cache la colonne « formule » de la grande table (section 04) et récite-la ligne par ligne.
  • Passage 3 (entraînement) : relis les 5 réflexes Bac (section 05) la veille de l'épreuve, puis passe aux exercices du chapitre.

Fondations utilisées partout : exp est définie sur tout ℝ, e⁰ = 1, e ≈ 2,718, e^x > 0 pour tout x, et exp est strictement croissante (donc bijective de ℝ sur ]0 ; +∞[). Tout le reste du chapitre découle des deux formules majeures ci-dessous :

Formule majeure n°1 — l'algèbre du chapitre
e^(a + b) = e^a · e^b
Multiplier des exponentielles revient à additionner les exposants. Elle simplifie, factorise, et fournit le carré (e^x)² = e^(2x), clé du changement de variable de la section 02.
Formule majeure n°2 — l'analyse du chapitre
(e^u)' = u'·e^u
Lue de gauche à droite, elle dérive ; lue de droite à gauche, elle intègre (u'·e^u a pour primitive e^u). Une seule formule, deux sens de lecture.

Notion 1 · reciproque_ln_exp

exp & ln réciproques, équations de référence

exp et ln se « défont » l'une l'autre : appliquer l'une puis l'autre rend le nombre de départ. C'est la définition même de fonctions réciproques — et c'est ce qui permet de résoudre les équations.

exp(ln x) = x  (x > 0)
Premier sens de la réciproque. La condition se lit sur le domaine : ln n'accepte que des nombres strictement positifs, donc ce sens exige x > 0.
ln(e^x) = x  (tout x ∈ ℝ)
Second sens : e^x est toujours positif — donc ln peut toujours le recevoir, pour n'importe quel réel x.
🧮 Contrôle rapide de la réciproque
1

Sens exp ∘ ln :

exp(ln 5) = 5

Vérification : ln 5 ≈ 1,609 puis e^(1,609) ≈ 5,000. ✅

2

Sens ln ∘ exp :

ln(e³) = 3

Vérification : e³ ≈ 20,09 puis ln 20,09 ≈ 3,000. ✅

Sur la figure, cette réciproque se voit : les deux courbes sont le reflet l'une de l'autre dans le miroir de la droite y = x. Chaque point (x ; e^x) de exp a son jumeau (e^x ; x) sur ln.

Résoudre avec la réciproque

Les équations de référence du chapitre s'obtiennent en appliquant ln ou exp des deux côtés, avec une justification d'hypothèse :

e^x = a ⇔ x = ln a  (a > 0)
On applique ln (strictement croissante) des deux côtés — à condition que a soit strictement positif.
e^x = e^b ⇔ x = b
exp est injective : des exponentielles égales ont des exposants égaux. Dans l'autre sens : ln x = b ⇔ x = e^b, toujours valable car e^b > 0.

🧮 Exemple complet — Trois équations types et un contre-exemple
1

Résoudre e^x = 8. Le second membre est positif, on applique ln :

e^x = 8 ⇔ x = ln 8

ln 8 = ln(2³) = 3 ln 2

Conclusion : S = {3 ln 2}.

2

Résoudre ln x = −2. On applique exp des deux côtés :

x = e^(−2)

x = 1 / e²

La solution est bien positive ✅ : S = {1 / e²}.

3

Résoudre e^(3x) = 5. On applique ln :

3x = ln 5 ⇔ x = (ln 5) / 3

Conclusion : S = {(ln 5) / 3}.

4

Contre-exemple : e^x = −4. Le second membre est négatif :

S = ∅

Aucun ln à poser — voir l'encadré ci-dessous.

Erreur fréquente au Bac

Résoudre e^x = −4 en écrivant x = ln(−4) : c'est doublement faux — ln n'accepte qu'un argument strictement positif, et e^x n'est jamais négatif. La bonne réponse : aucune solution, S = ∅. Avant d'appliquer ln, regarde toujours le signe du second membre.

Notion 2 · equations_exp

Changement de variable & inéquations

Quand l'équation mêle e^(2x) et e^x, elle cache un trinôme. La technique : poser X = e^x, résoudre en X, puis revenir à x — avec un contrôle de positivité obligatoire, car X = e^x > 0.

🧮 Exemple complet — Résoudre dans ℝ : e^(2x) − 3·e^x + 2 = 0
1

Repérer le carré. Le terme en e^(2x) se réécrit :

e^(2x) = (e^x)²

2

Poser la nouvelle inconnue (avec sa condition de positivité) :

X = e^x  (donc X > 0 pour tout x réel)

3

Substituer. L'équation devient :

X² − 3X + 2 = 0

4

Calculer le discriminant :

Δ = (−3)² − 4 × 1 × 2

Δ = 9 − 8 = 1

5

En déduire les racines en X :

X₁ = (3 − 1) / 2 = 1

X₂ = (3 + 1) / 2 = 2

6

Contrôler X > 0 (le piège du chapitre) : 1 > 0 ✅ et 2 > 0 ✅ — aucune racine à rejeter ici.

7

Revenir à x avec e^x = a ⇔ x = ln a :

e^x = 1 ⇔ x = 0

e^x = 2 ⇔ x = ln 2

Conclusion : S = {0 ; ln 2}.

8

Vérifier (pour x = ln 2) :

e^(2 ln 2) − 3·e^(ln 2) + 2

= 4 − 6 + 2 = 0 ✅

Erreur fréquente au Bac — garder une racine négative

Dans le changement de variable, X = e^x est strictement positif : toute racine X ≤ 0 du trinôme est toujours rejetée. Garder X = −2 et répondre x = ln(−2) annule toute la question. Écris noir sur blanc l'étape « contrôle : X > 0 » — c'est elle qui rapporte les points.

🧮 Exemple 2 — Résoudre e^(2x) − e^x − 6 = 0 (une racine rejetée)
1

On pose X = e^x (donc X > 0) ; l'équation devient :

X² − X − 6 = 0

2

Discriminant :

Δ = (−1)² − 4 × 1 × (−6)

Δ = 1 + 24 = 25

donc √Δ = 5

3

Racines :

X = (1 ± 5) / 2

soit X = 3 ou X = −2

4

Rejet obligatoire : X = −2 < 0 est impossible car X = e^x > 0. Il reste :

e^x = 3 ⇔ x = ln 3

donc S = {ln 3}.

Les inéquations — même logique

exp étant strictement croissante, passer au ln conserve l'ordre — c'est tout ce qu'il faut savoir.

e^x > a ⇔ x > ln a  (a > 0)
Le sens de l'inégalité traverse la réciproque sans se retourner, car exp (comme ln) est strictement croissante. Avec une égalité d'exponentielles : e^x ≤ e^b ⇔ x ≤ b. Seule vigilance : un coefficient négatif devant x (voir l'exemple).
🧮 Exemple 3 — Deux inéquations types
1

Cas direct :

e^x > 7 ⇔ x > ln 7

donc S = ]ln 7 ; +∞[

2

Exposant négatif :

e^(−2x) ≤ 9 ⇔ −2x ≤ ln 9

3

Diviser par −2 renverse l'inégalité :

x ≥ −(ln 9) / 2 = −ln 3  (car ln 9 = 2 ln 3)

Conclusion : S = [−ln 3 ; +∞[.

Notion 3 · applications_exp

Intérêts composés, population, temps de doublement

Tous les problèmes concrets du chapitre reposent sur le même schéma : une quantité multipliée à chaque pas de temps, que la réciproque ln transforme en équation résoluble.

N(t) = N₀·e^(kt)
N₀ est la valeur à t = 0 ; k > 0 donne une croissance, k < 0 une décroissance. Avec un taux annuel t (intérêts composés par périodes) : Cₙ = C₀ × (1 + t)ⁿ. Les calculs de doublement réunissent les deux modèles.

A. Intérêts composés — quand le capital double-t-il ?

🧮 Application 1 — 10 000 F placés à 5 % par an

Un capital de C₀ = 10 000 F est placé à 5 % par an, intérêts composés : Cₙ = C₀ × 1,05ⁿ. Au bout de combien d'années n le capital a-t-il doublé ?

1

Mettre en équation le doublement :

Cₙ ≥ 2 × C₀ ⇔ 1,05ⁿ ≥ 2

2

Appliquer ln (croissante, l'ordre est conservé) :

n × ln 1,05 ≥ ln 2

3

Diviser par ln 1,05 > 0 :

n ≥ (ln 2) / (ln 1,05) ≈ 14,2

4

Arrondir à l'entier supérieur (n est un nombre d'années) : 1,05¹⁴ ≈ 1,98 < 2 mais 1,05¹⁵ ≈ 2,08 ≥ 2. Le capital double au bout de 15 années.

B. Croissance d'une population

🧮 Application 2 — Population de 2 millions, k = 0,03 an⁻¹

Une population suit N(t) = N₀·e^(kt) avec N₀ = 2 millions et k = 0,03 an⁻¹. Que vaut N après 10 ans ?

1

Substituer les valeurs :

N(10) = 2 × e^(0,03 × 10)

N(10) = 2 × e^(0,3)

2

Calculer :

e^(0,3) ≈ 1,350

N(10) ≈ 2 × 1,350 = 2,70 millions

3

Interpréter : 2,70 / 2 = 1,35 — la population a gagné environ 35 % en 10 ans. ✅

C. Temps de doublement (et demi-vie)

t = (ln 2) / k
Temps de doublement (croissance, k > 0) : la quantité passe de N₀ à 2N₀.
t₁/₂ = (ln 2) / λ
Demi-vie (décroissance radioactive, λ > 0) : il reste N₀/2. Même calcul dans les deux cas, avec ln 2 ≈ 0,693.
🧮 Application 3 — Doublement de la population précédente
1

Mettre en équation :

N(t) = 2 × N₀ ⇔ e^(kt) = 2

2

Appliquer ln :

kt = ln 2 ⇔ t = (ln 2) / k

3

Calculer avec k = 0,03 :

t ≈ 0,693 / 0,03 ≈ 23,1 ans

Cohérent avec l'application 2 : +35 % en 10 ans, doublement vers 23 ans. ✅

4

Variante demi-vie : pour λ = 0,10 j⁻¹ :

t₁/₂ ≈ 0,693 / 0,10 ≈ 6,9 jours

Après 3 demi-vies, il reste (1/2)³ = 1/8 de la quantité initiale, soit 12,5 %.

Notion 4 · reflexes

Les 5 réflexes Bac

Face à une question sur exp, le bon réflexe est presque toujours l'un de ces cinq. Apprends-les dans l'ordre : les premiers coûtent des points entiers, les derniers raffinent la rédaction.

  • 1. Signe d'abord. Devant e^x = a : si a ≤ 0, stop — S = ∅ car e^x > 0 ; si a > 0, réponse x = ln a.
  • 2. Trinôme en e^x. Poser X = e^x, résoudre le trinôme en X, rejeter toute racine X ≤ 0, puis revenir avec x = ln X.
  • 3. Inéquation. Invoquer la stricte croissance de exp pour passer au ln sans retourner l'inégalité ; attention au renversement si l'on divise par un négatif.
  • 4. Dérivée ou primitive. (e^u)' = u'·e^u dans les deux sens : dériver en multipliant par u', intégrer en reconnaissant u' en facteur — et vérifier une primitive en la dérivant.
  • 5. Forme indéterminée. Devant ∞/∞ ou ∞ × 0 avec exp : croissances comparées (e^x / xⁿ → +∞, x·e^(−x) → 0), citées par leur nom dans la copie.
⚠️ Les trois fautes qui coûtent le plus de points

(1) Oublier le facteur u' dans (e^u)'. (2) Garder une racine X ≤ 0 du trinôme en X = e^x. (3) Écrire e^(a + b) = e^a + e^b. Relis ta copie en chassant ces trois fautes avant de rendre : c'est le gain de points le plus rapide du chapitre.

📗 Rédaction qui rapporte des points

Chaque passage au ln ou à exp doit être justifié en une ligne : « comme a > 0, on applique ln, strictement croissante » ; « comme X = e^x > 0, la racine X = −2 est rejetée » ; « d'après les croissances comparées… ». Un résultat sans justification d'hypothèse ne rapporte rien, même juste.
