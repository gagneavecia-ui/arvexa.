La loi binomiale et la loi géométrique

✏️ Exercice 1 — Le QCM du lycée Bosso (★)

Données : 5 questions indépendantes, réponse au hasard, p = 1/2 ; X = nombre de bonnes réponses.

1

On répète 5 épreuves de Bernoulli identiques et indépendantes, succès « bonne réponse » de probabilité p = 0,5 : donc X suit B(5 ; 0,5).

2

P(X = 4) = C(5 ; 4)·0,5^4·0,5 = 5/32 = 0,15625 ≈ 0,1563 ; P(X = 5) = 0,5^5 = 1/32 = 0,03125 ≈ 0,0313.

3

P(X ≥ 4) = 5/32 + 1/32 = 6/32 = 3/16 = 0,1875 : répondre au hasard donne plus de 4 bonnes réponses dans environ 18,75 % des QCM.

4

E(X) = n·p = 5×0,5 = 2,5 ; V(X) = n·p·(1 − p) = 5×0,5×0,5 = 1,25 ; σ(X) = √1,25 ≈ 1,12.

P(X ≥ 4) = 3/16 = 0,1875 · E(X) = 2,5 · V(X) = 1,25 · σ(X) ≈ 1,12
En moyenne 2,5 bonnes réponses sur 5 en répondant au hasard.
⚠️ Piège : « au moins 4 » signifie P(X = 4) + P(X = 5) — oublier P(X = 5) est l'erreur classique.
✏️ Exercice 2 — Défectueuses à la chaîne de Torodi (★★)

Données : p = 0,02, n = 10, tirages assimilés indépendants ; 0,98^10 ≈ 0,8171 et 0,98⁹ ≈ 0,8337.

1

La production est assez grande pour assimiler les 10 prélèvements à des tirages avec remise : épreuves identiques et indépendantes, succès « pain défectueux » de probabilité 0,02 → X suit B(10 ; 0,02).

2

P(X = 0) = 0,98^10 ≈ 0,8171 : environ 81,7 % des échantillons ne contiennent aucun pain défectueux.

3

P(X ≥ 1) = 1 − P(X = 0) ≈ 1 − 0,8171 = 0,1829 : environ 18,3 % des échantillons contiennent au moins un pain défectueux.

4

P(X = 1) = C(10 ; 1)·0,02·0,98⁹ = 10×0,02×0,8337 ≈ 0,1667 ; P(X ≤ 1) ≈ 0,8171 + 0,1667 = 0,9838.

5

E(X) = n·p = 10×0,02 = 0,2 : en moyenne 0,2 pain défectueux par échantillon de 10, soit 1 pain défectueux tous les 5 échantillons.

P(X = 0) ≈ 0,8171 · P(X ≥ 1) ≈ 0,1829 · P(X ≤ 1) ≈ 0,9838 · E(X) = 0,2
Presque 2 échantillons sur 10 contiennent au moins un défectueux.
⚠️ Piège : 0,98⁹ = 0,98^10/0,98, pas 0,98^10 − 0,98 ; et on n'arrondit qu'à la fin des calculs.
✏️ Exercice 3 — Le démarcheur de la Cité Anassara (★★)

Données : p = 0,25 par appel, appels indépendants ; Y = rang du premier appel qui aboutit (loi géométrique).

1

Vendre à l'appel k exige k − 1 échecs (0,75 chacun) puis un succès (0,25) : P(Y = k) = 0,75^(k−1) × 0,25.

2

P(Y = 1) = 0,25 ; P(Y = 2) = 0,75×0,25 = 0,1875 ; P(Y = 3) = 0,75²×0,25 = 0,5625×0,25 = 0,140625 ≈ 0,1406.

3

P(Y ≤ 3) = 0,25 + 0,1875 + 0,140625 = 0,578125 ≈ 0,5781 : plus d'une vente sur deux se réalise dans les trois premiers appels.

4

P(Y > 4) = 0,75⁴ = 0,31640625 ≈ 0,3164. Contrôle : 0,75² = 0,5625 et 0,5625² = 0,31640625 ✓ (quatre échecs consécutifs).

5

E(Y) = 1/p = 1/0,25 = 4 : il faut en moyenne 4 appels pour décrocher la première vente.

P(Y ≤ 3) ≈ 0,5781 · P(Y > 4) ≈ 0,3164 · E(Y) = 4
Environ 58 % des premières ventes arrivent dans les 3 premiers appels.
⚠️ Piège : par le complément, P(Y > 4) = 1 − P(Y ≤ 4) exige aussi P(Y = 4) = 0,75³×0,25 ≈ 0,1055 : la méthode directe 0,75⁴ est plus sûre.

✏️ Exercice 4 — L'urne du forgeron de Ballayara (★★★)

Données : urne 4 blanches + 6 noires = 10 boules, tirage simultané de 3 boules ; X = nombre de blanches ; C(10 ; 3) = 120 ; jeu : G = 1 000·X − 500.

1

P(X = 0) = C(6 ; 3)/120 = 20/120 = 1/6 ; P(X = 1) = C(4 ; 1)×C(6 ; 2)/120 = 4×15/120 = 60/120 = 1/2 ; P(X = 2) = C(4 ; 2)×C(6 ; 1)/120 = 6×6/120 = 36/120 = 3/10 ; P(X = 3) = C(4 ; 3)/120 = 4/120 = 1/30.

2

Somme : 1/6 + 1/2 + 3/10 + 1/30 = (5 + 15 + 9 + 1)/30 = 30/30 = 1 ✓.

3

E(X) = (0×20 + 1×60 + 2×36 + 3×4)/120 = 144/120 = 1,2. Contrôle : E(X) = n×K/N = 3×4/10 = 1,2 ✓.

4

E(X²) = (0 + 1×60 + 4×36 + 9×4)/120 = 240/120 = 2, donc V(X) = 2 − 1,2² = 2 − 1,44 = 0,56.

5

E(G) = 1 000×E(X) − 500 = 1 200 − 500 = 700 F : E(G) > 0, le jeu est favorable au joueur.

6

V(G) = 1 000²×V(X) = 1 000 000×0,56 = 560 000 F² ; σ(G) = √560 000 ≈ 748,33 F.

E(X) = 1,2 · E(G) = 700 F (favorable) · V(G) = 560 000 F² · σ(G) ≈ 748,33 F
En moyenne, le joueur gagne 700 F par partie.
⚠️ Piège : E(a·X + b) = a·E(X) + b mais V(a·X + b) = a²·V(X) : le −500 disparaît dans la variance, et V(G) s'exprime en F².
✏️ Exercice 5 — Deux parcelles d'oignons à Sagbié (★★★)

Données : parcelle A : rendement certain 800 000 F ; parcelle B : Y vaut 1 400 000 F (0,5), 600 000 F (0,3), 200 000 F (0,2).

1

Validation : 0,5 + 0,3 + 0,2 = 1 et toutes les probabilités sont positives : loi complète ✓.

2

E(Y) = 1 400 000×0,5 + 600 000×0,3 + 200 000×0,2 = 700 000 + 180 000 + 40 000 = 920 000 F, soit 920 000 − 800 000 = 120 000 F de plus que la parcelle A.

3

E(Y²) = 0,5×(1 400 000)² + 0,3×(600 000)² + 0,2×(200 000)² = 9,8×10¹¹ + 1,08×10¹¹ + 0,08×10¹¹ = 1,096×10¹².

4

V(Y) = 1,096×10¹² − (920 000)² = 1,096×10¹² − 8,464×10¹¹ = 2,496×10¹¹ F² ; σ(Y) = √(2,496×10¹¹) ≈ 499 600 F. Contrôle : 499 600² ≈ 2,496×10¹¹ ✓.

5

Décision : la parcelle B rapporte 120 000 F de plus en moyenne, mais son écart-type vaut près de 500 000 F et son pire rendement tombe à 200 000 F. Pour la sécurité : choisir A ; si le maraîcher accepte un fort risque : choisir B.

E(Y) = 920 000 F · V(Y) = 2,496×10¹¹ F² · σ(Y) ≈ 499 600 F
B est plus rentable en moyenne, mais bien plus « dispersée » que le rendement certain de A.
⚠️ Piège : deux variables d'espérances voisines peuvent avoir des écart-types très différents — l'espérance seule ne suffit jamais pour décider.
✏️ Exercice 6 — Les candidats du centre d'examen (★★★)

Données : 8 candidats indépendants, p = 0,7 ; X = nombre de réussites ; on utilisera 0,7⁶ = 0,117649 et 0,7⁷ = 0,0823543.

1

8 épreuves de Bernoulli identiques et indépendantes, succès « réussir » de probabilité 0,7 → X suit B(8 ; 0,7).

2

P(X = 8) = 0,7⁸ = 0,05764801 ≈ 0,0576. Contrôle : 0,7² = 0,49 ; 0,7⁴ = 0,2401 ; 0,2401² = 0,05764801 ✓.

3

P(X = 7) = C(8 ; 7)·0,7⁷·0,3 = 8×0,0823543×0,3 = 0,19765032 ≈ 0,1977 ; P(X = 6) = C(8 ; 6)·0,7⁶·0,3² = 28×0,117649×0,09 = 0,29647548 ≈ 0,2965.

4

P(X ≥ 6) = 0,2965 + 0,1977 + 0,0576 = 0,5518 (somme exacte : 0,55177381).

5

E(X) = 8×0,7 = 5,6 : en moyenne 5,6 réussites sur 8 ; V(X) = 8×0,7×0,3 = 1,68 ; σ(X) = √1,68 ≈ 1,30.

6

Décision : P(X ≥ 6) ≈ 0,5518 > 0,5 : le surveillant général a raison, il y a environ 55,2 % de chances qu'au moins six candidats réussissent.

P(X = 8) ≈ 0,0576 · P(X ≥ 6) ≈ 0,5518 · E(X) = 5,6 · σ(X) ≈ 1,30
L'affirmation du surveillant général est vérifiée par le calcul.
⚠️ Piège : dans P(X = 6), l'exposant de 0,3 vaut 8 − 6 = 2 : écrire 0,3 au lieu de 0,3² = 0,09 fausse tout le résultat.
