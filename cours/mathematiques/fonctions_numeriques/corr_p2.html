✏️ Exercice 1 — Asymptotes et variations de h (★★)

Données : h(x) = 1 + 2/(x − 1) sur D = ℝ ∖ {1}.

1

lim(x→±∞) 2/(x − 1) = 0 donc lim(x→±∞) h(x) = 1 : la droite y = 1 est asymptote horizontale.

2

lim(x→1⁻) 2/(x − 1) = −∞ donc lim(x→1⁻) h(x) = −∞ ; et lim(x→1⁺) h(x) = +∞ : la droite x = 1 est asymptote verticale.

3

h'(x) = −2/(x − 1)² < 0 sur D : h est strictement décroissante sur ]−∞ ; 1[ et sur ]1 ; +∞[ (double barre en 1).

4

h(x) − 1 = 2/(x − 1) : pour x > 1, h(x) − 1 > 0 (courbe au-dessus de son asymptote) ; pour x < 1, h(x) − 1 < 0 (courbe en dessous).

5

Axe des ordonnées : h(0) = 1 − 2 = −1 → point (0 ; −1). Axe des abscisses : 1 + 2/(x − 1) = 0 équivaut à x − 1 = −2, soit x = −1 → point (−1 ; 0).

asymptotes y = 1 et x = 1 · h' < 0 · points (0 ; −1) et (−1 ; 0)
Courbe au-dessus de y = 1 pour x > 1, en dessous pour x < 1.
⚠️ Piège : la position relative s'obtient en étudiant le signe de h(x) − 1, jamais celui de h(x).
✏️ Exercice 2 — Lecture graphique et asymptotes (★★)

Données : la figure de l'énoncé : courbe C de F, asymptotes en pointillés, intersection avec l'axe des abscisses en 2,5.

1

À gauche comme à droite, la courbe se colle à la droite pointillée horizontale : lim(x→−∞) F(x) = 2 et lim(x→+∞) F(x) = 2. Près de la droite verticale : lim(x→3⁻) F(x) = −∞ (la branche plonge) et lim(x→3⁺) F(x) = +∞ (la branche monte).

2

Asymptote horizontale : y = 2 ; asymptote verticale : x = 3.

3

Sur chacune des deux branches, la courbe descend de gauche à droite : F est strictement décroissante sur ]−∞ ; 3[ et sur ]3 ; +∞[.

4

La courbe coupe l'axe des abscisses en un seul point, d'abscisse 2,5 : l'équation F(x) = 0 a une unique solution x = 2,5.

5

La branche de droite est au-dessus de la droite y = 2 (sur ]3 ; +∞[) ; la branche de gauche est en dessous (sur ]−∞ ; 3[).

lim F = 2 en ±∞ · lim(x→3⁻) F = −∞ · lim(x→3⁺) F = +∞ · asymptotes x = 3 et y = 2 · F(x) = 0 ↔ x = 2,5
Toutes les réponses se lisent directement sur la figure de l'énoncé.
⚠️ Piège : en lecture graphique, une limite finie se lit sur la droite dont la courbe « se rapproche » : ici la limite vaut 2, pas 0.
✏️ Exercice 3 — Étude complète (type Bac) (★★★)

Données : f(x) = (x² − 3x)/(x − 2) sur D = ℝ ∖ {2}.

1

Décomposition : comme x² − 3x = (x − 2)(x − 1) − 2, on a f(x) = x − 1 − 2/(x − 2). Donc lim(x→+∞) f(x) = +∞ et lim(x→−∞) f(x) = −∞.

2

En 2 : le numérateur tend vers −2 < 0, le dénominateur vers 0 : lim(x→2⁻) f(x) = −2/0⁻ = +∞ et lim(x→2⁺) f(x) = −2/0⁺ = −∞ : la droite x = 2 est asymptote verticale.

3

✏️ Exercice 5 — Continuité, prolongement et TVI (★★★)

Données : φ(x) = (x² − 4)/(x − 2) pour x ≠ 2 et φ(2) = 4 ; puis ψ(x) = x³ + x − 3.

1

Pour x ≠ 2 : x² − 4 = (x − 2)(x + 2) donc φ(x) = x + 2 et lim(x→2) φ(x) = 4.

2

Comme lim(x→2) φ(x) = 4 = φ(2), la fonction φ est continue en 2 : la valeur φ(2) = 4 réalise un prolongement par continuité.

3

ψ(1) = 1 + 1 − 3 = −1 < 0 et ψ(2) = 8 + 2 − 3 = 7 > 0 ; ψ est continue sur [1 ; 2] : par le TVI, ψ(x) = 0 admet au moins une solution dans ]1 ; 2[.

4

ψ'(x) = 3x² + 1 ≥ 1 > 0 : ψ est strictement croissante sur ℝ, donc la solution α est unique dans ]1 ; 2[.

5

ψ(1,2) = 1,728 + 1,2 − 3 = −0,072 < 0 et ψ(1,3) = 2,197 + 1,3 − 3 = 0,497 > 0 : α ∈ ]1,2 ; 1,3[ (amplitude 10⁻¹).

lim(x→2) φ(x) = 4 = φ(2) : φ continue en 2 · α unique dans ]1 ; 2[ · α ∈ ]1,2 ; 1,3[
Prolongement par continuité, puis TVI avec unicité.
⚠️ Piège : pour la continuité en 2, il faut l'égalité complète lim(x→2) φ(x) = φ(2) : donner la valeur φ(2) = 4 fait partie de la réponse.
✏️ Exercice 6 — Grande synthèse (type Bac) (★★★)

Données : g(x) = (x² − 2x + 3)/(x − 1) = x − 1 + 2/(x − 1) sur D = ℝ ∖ {1}.

1

lim(x→±∞) g(x) = lim(x→±∞) (x − 1) = ±∞. En 1 : lim(x→1⁻) g(x) = −∞ et lim(x→1⁺) g(x) = +∞ : la droite x = 1 est asymptote verticale.

2

g'(x) = 1 − 2/(x − 1)² = [(x − 1)² − 2]/(x − 1)² ; (x − 1)² − 2 = 0 équivaut à x = 1 ± √2, soit environ −0,41 et 2,41.

Extremums : en posant t = x − 1, g(1 + t) = t + 2/t, donc g(1 + √2) = √2 + 2/√2 = √2 + √2 = 2√2 ≈ 2,83 (minimum local) et g(1 − √2) = −√2 − 2/√2 = −2√2 ≈ −2,83 (maximum local). Contrôle : 2/√2 = √2 ✓.

5

lim(x→±∞) [g(x) − (x − 1)] = lim(x→±∞) 2/(x − 1) = 0 : (Δ) d'équation y = x − 1 est asymptote oblique. Position : g(x) − (x − 1) = 2/(x − 1) est négatif pour x < 1 (courbe en dessous) et positif pour x > 1 (courbe au-dessus).

6

Signe : le numérateur x² − 2x + 3 = (x − 1)² + 2 > 0 pour tout x, donc g(x) a le signe de x − 1 : g < 0 sur ]−∞ ; 1[ et g > 0 sur ]1 ; +∞[.

7

Symétrie : pour t ≠ 0, g(1 + t) = t + 2/t et g(1 − t) = −t − 2/t = −(t + 2/t) = −g(1 + t), donc g(1 + t) + g(1 − t) = 0 : le point I(1 ; 0) est centre de symétrie de la courbe.

asymptotes x = 1 et y = x − 1 · extremums ∓2√2 ≈ ∓2,83 · g < 0 si x < 1, g > 0 si x > 1 · centre de symétrie I(1 ; 0)
