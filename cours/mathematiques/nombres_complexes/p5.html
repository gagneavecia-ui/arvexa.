💡 La carte mentale du chapitre

Un complexe se voit de trois façons : algébrique z = a + ib (pour additionner et développer), géométrique module + argument (pour mesurer et tourner), exponentielle z = r·e^(iθ) (pour multiplier et élever à une puissance). Chaque exercice du Bac demande simplement de choisir la bonne façade — et de la changer proprement, justifications à l'appui.

02
Réflexes

Les 8 réflexes de calcul

À chaque situation son geste automatique — la situation d'énoncé déclenche l'action :

Situation → action
  • Un quotient à simplifier : multiplier haut et bas par le conjugué du dénominateur (Partie 2).
  • Un argument à déterminer : module d'abord, puis cos θ et sin θ, puis quadrant avec les deux signes (Partie 2).
  • Une forme trigonométrique à écrire : exiger r > 0 ; facteur négatif ⇒ ajouter π à l'argument (Partie 3).
  • Une puissance de i : réduire l'exposant par le reste de la division par 4 (Partie 1).
  • Une puissance d'un complexe : passer en exponentielle, zⁿ = rⁿ·e^(i·nθ) (Partie 3).
  • cos nθ ou sin nθ à exprimer : Moivre — développer puis identifier (Partie 4).
  • Une équation az² + bz + c = 0 avec Δ < 0 : deux racines conjuguées (−b ± i·√(−Δ))/(2a) (Partie 4).
  • Une racine carrée (ou n-ième) d'un complexe : système x² − y², 2xy, x² + y² — ou formule exponentielle (Partie 4).
💡 Les réflexes géométriques
  • Distance demandée : module d'une différence d'affixes, AB = |z(B) − z(A)| ;
  • Angle en un point : argument du quotient (z(C) − z(A))/(z(B) − z(A)) ;
  • Alignement / perpendicularité : quotient réel → alignés ; quotient imaginaire pur → angle droit ;
  • Rotation / homothétie : relation centrée z' − ω = e^(iθ)·(z − ω) ou z' − ω = k·(z − ω).
03
Pièges

Les 7 erreurs à bannir

Ces sept erreurs coûtent des points à chaque épreuve — elles sont toutes réparables en une ligne :

⚠️ Erreur 1 — écrire i = √(−1)

Mathématiquement faux : les règles de la racine carrée cessent d'être vraies sur les négatifs. La formulation correcte : « i est le nombre tel que i² = −1 ». (Partie 1)

⚠️ Erreur 2 — prendre ib pour la partie imaginaire

La partie imaginaire de z = 3 + 5i est 5 (un réel), pas 5i. (Partie 1)

⚠️ Erreur 3 — confondre conjugué et opposé

z̄ = 3 − 5i mais −z = −3 − 5i : seul le signe de b change pour le conjugué, les deux pour l'opposé. (Partie 2)

⚠️ Erreur 4 — additionner les parties pour le module

|3 + 4i| = √(9 + 16) = 5, et non 7. Toujours √(a² + b²). (Partie 2)

⚠️ Erreur 5 — trancher l'argument avec le seul cosinus

Si cos θ = −1/2, deux angles conviennent (2π/3 et 4π/3) : c'est le signe du sinus qui tranche. Et toujours écrire ≡ … [2π]. (Partie 2)

⚠️ Erreur 6 — identifier sans regrouper

Avant d'identifier les parties réelle et imaginaire, il faut tout développer, remplacer les i² et regrouper : réel avec réel, i avec i. (Partie 1)

⚠️ Erreur 7 — distribuer la racine carrée

√(1 + 3) = 2, pas 1 + √3 : la racine carrée ne se distribue pas sur une somme. (Partie 3)

💡 Les quatre complexes cardinaux

1 (angle 0), i (angle π/2), −1 (angle π), −i (angle −π/2) : les racines quatrièmes de 1, aux quatre points cardinaux du cercle unité. Toute question d'argument sur les axes se règle avec eux. (Parties 3 et 4)

💡 Le quadrant en un coup d'œil
  • cos > 0, sin > 0 : premier quadrant (θ ∈ ]0 ; π/2[) ;
  • cos < 0, sin > 0 : deuxième quadrant (θ ∈ ]π/2 ; π[) ;
  • cos < 0, sin < 0 : troisième quadrant (θ ∈ ]π ; 3π/2[ ou ]−π ; −π/2[) ;
  • cos > 0, sin < 0 : quatrième quadrant (θ ∈ ]−π/2 ; 0[).
05
Fil rouge

Plan d'attaque d'un exercice type Bac

Un seul complexe, toutes les questions classiques du Bac — le fil rouge complet, à refaire sans regarder :

🧮 Le fil rouge — soit z = 1 + i√3

Partie A — Places z sous toutes ses formes.

1. Module : |z| = √(1² + (√3)²) = √(1 + 3) = 2.

2. Argument : cos θ = 1/2 et sin θ = √3/2 ; le point M(1 ; √3) est dans le premier quadrant, donc arg(z) ≡ π/3 [2π].

3. Forme trigonométrique : z = 2(cos π/3 + i·sin π/3).

4. Forme exponentielle : z = 2·e^(iπ/3).

5. Conjugué : z̄ = 1 − i√3 = 2·e^(−iπ/3) (même module, argument opposé).

Partie B — Calcule une puissance sans développer.

6. z³ = 2³·e^(i·3×π/3) = 8·e^(iπ) = −8. (Contrôle par développement direct : (1 + i√3)³ = −8 ✓)

Partie C — Exploite le module et le conjugué.

7. z·z̄ = |z|² = 4 — et par le calcul : (1 + i√3)(1 − i√3) = 1 + 3 = 4 ✓

8. z/z̄ = e^(iπ/3)·e^(iπ/3) = e^(i·2π/3) = −1/2 + i·√3/2 — un complexe de module 1 : son image est sur le cercle unité.

La trame de rédaction qui rapporte les points
  • Écrire la formule utilisée avant de l'appliquer (r = √(a² + b²), puis cos θ = a/r, sin θ = b/r) ;
  • Justifier le quadrant (signes de cos et sin) ;
  • Noter les arguments avec ≡ … [2π] ;
  • Terminer par une vérification courte (module retrouvé, somme/produit des racines, distance conservée…).

Q2. Quelle est la partie imaginaire de z = −8 + 3i ?

Q4. Donner module et argument de −4i.

Q5. Mettre z = √3 + i sous forme exponentielle.

Q6. Résoudre z² + 9 = 0.

Q7. Donner les trois racines cubiques de 1.

Q8. Le point d'affixe i subit la rotation de centre O et d'angle π/2 : quelle est son affixe d'arrivée ?

Q9. A, B, C ont pour affixes 1 ; 3 + i ; 2 + 3i. Le triangle est-il rectangle en B ?

Q10. Écrire cos 2θ en fonction de cos²θ (deux écritures).

Q11. Donner la forme de Moivre de cos 3θ.

Q12. Donner la formule de la rotation de centre Ω d'affixe ω et d'angle θ.

💡 Réponses et justifications express

R1. 2025 = 4 × 506 + 1, reste 1 : i^2025 = i. — R2. 3 — la partie imaginaire est le coefficient réel de i, jamais 3i. — R3. 2² + 1² = 5 (schéma conjugué). — R4. |−4i| = 4 ; l'image est sur l'axe des imaginaires, en bas : arg(−4i) ≡ −π/2 [2π].

R5. |√3 + i| = 2 ; cos θ = √3/2, sin θ = 1/2, premier quadrant : z = 2·e^(iπ/6). — R6. z² = −9 : z = 3i ou z = −3i (deux solutions opposées — ou formule Δ = −36, racines conjuguées). — R7. 1, j = e^(i·2π/3) = −1/2 + i·√3/2, j̄ = e^(i·4π/3) = −1/2 − i·√3/2 (triangle équilatéral sur le cercle unité). — R8. e^(iπ/2)·i = i·i = −1 : un quart de tour envoie i sur −1.

R9. q = (z(C) − z(B))/(z(A) − z(B)) = ((2 + 3i) − (3 + i))/(1 − (3 + i)) = (−1 + 2i)/(−2 − i). On multiplie par le conjugué −2 + i : numérateur (−1 + 2i)(−2 + i) = 2 − i − 4i + 2i² = −5i ; dénominateur (−2 − i)(−2 + i) = 4 + 1 = 5 ; donc q = −i, imaginaire pur : oui, rectangle en B. — R10. cos 2θ = 2cos²θ − 1 = 1 − 2sin²θ (et cos²θ − sin²θ).

07
L'outil final

Le cercle trigonométrique — le tracer sans rien mémoriser

Tous les arguments et valeurs remarquables du chapitre vivent sur un seul dessin : le cercle de centre O et de rayon 1. Un point d'angle θ y représente le complexe e^(iθ) — son abscisse est cos θ, son ordonnée est sin θ. Le voici complet :

🎯 La lecture en 10 secondes
Angle mesuré depuis l'axe horizontal, sens contraire des aiguilles d'une montre. Les 4 points cardinaux donnent 0 ; π/2 ; π ; 3π/2 — les arguments des réels purs et imaginaires purs. Les 12 autres angles se répartissent par miroirs du premier quadrant.
🛠 La méthode en 6 étapes — sans mémoriser

Étape 1 — Le squelette. Cercle + axes + 4 points cardinaux. Image : un cadran d'horloge dont l'aiguille tourne à l'envers (3 h = 0 ; 12 h = π/2 ; 9 h = π ; 6 h = 3π/2).

Étape 2 — Les deux figures magiques. Le carré de côté 1 : sa diagonale √2 donne cos π/4 = sin π/4 = √2/2. Le demi-triangle équilatéral : il donne cos π/3 = 1/2 et sin π/3 = √3/2 (et π/6 échange les deux).

Étape 3 — L'escalier des racines. Écris √0/2 ; √1/2 ; √2/2 ; √3/2 ; √4/2 : le cosinus le descend quand l'angle monte (0 → π/6 → π/4 → π/3 → π/2), le sinus le monte.

Étape 4 — Les miroirs. Les 3 autres quadrants reflètent le premier : valeurs absolues inchangées, x du signe du cosinus (+ à droite), y du signe du sinus (+ en haut).

Étape 5 — Les angles. Tout se range au dénominateur 12 : π/6 = 2π/12, π/4 = 3π/12, π/3 = 4π/12… Et les compléments : quadrant II = π − x, quadrant III = π + x, quadrant IV = 2π − x.

Étape 6 — Contrôle. Cardinaux = 0 et ±1 ; seules valeurs utilisées : 1/2, √2/2, √3/2 ; signes respectés ; angles opposés → coordonnées opposées.

✅ Ce que tu dois VRAIMENT retenir
Rien par cœur. Juste : le squelette anti-horaire, 2 figures à redessiner (carré + demi-triangle), l'escalier des racines, les miroirs, et les compléments π − x ; π + x ; 2π − x. Avec ces 5 gestes, tu reconstruis les 16 points en moins de deux minutes — la version détaillée figure par figure est dans le PDF de cette partie (section finale).
📌 Ce qu'il faut retenir
  • [partie 1] Trois façades d'un complexe : algébrique z = a + ib (sommes), module + argument (géométrie), exponentielle z = r·e^(iθ) (produits et puissances)
  • [partie 2] Conjugué z̄ = a − ib ; module |z| = √(a² + b²) ; argument : module → cos → sin → quadrant, noté ≡ … [2π]
  • [partie 3] Produit : modules ×, arguments + ; puissance zⁿ = rⁿ·e^(i·nθ) ; multiplier = tourner + agrandir

  • [partie 4] Géométrie : AB = |z(B) − z(A)| ; quotient réel → alignés, imaginaire pur → angle droit ; rotation z' − ω = e^(iθ)·(z − ω)
