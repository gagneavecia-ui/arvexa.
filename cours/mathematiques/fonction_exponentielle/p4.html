Notion 1 · reciproque_ln_exp

Résoudre e^x = a et ln x = b

Le cœur de tous les exercices du chapitre tient en deux équivalences, les deux sens de la relation réciproque :

La formule majeure du chapitre
e^x = a ⇔ x = ln a (a > 0)
Et dans l'autre sens : ln x = b ⇔ x = e^b, toujours valable car x = e^b > 0 automatiquement.
ÉquationSolutionCondition
e^x = ax = ln aa > 0
e^x = a avec a ≤ 0aucune solutioncar e^x > 0
ln x = bx = e^btoujours (x = e^b > 0)
e^(kx) = ax = ln a / kk ≠ 0 et a > 0
🧮 Exemple 1 — Résoudre e^x = 8

Un cas où ln se simplifie joliment.

1

8 > 0 : une unique solution existe, x = ln 8.

2

Comme 8 = 2³ : ln 8 = ln 2³ = 3 ln 2. Conclusion : S = {3 ln 2}.

🧮 Exemple 2 — Résoudre ln x = −2, puis e^(3x) = 5

Les deux autres sens du tableau.

1

ln x = −2 ⇔ x = e^(−2) = 1/e². La solution est bien positive ✓. Conclusion : S = {1/e²}.

2

e^(3x) = 5 ⇔ 3x = ln 5 ⇔ x = ln 5 / 3. Conclusion : S = {ln 5 / 3}.

Erreur fréquente au Bac

Résoudre e^x = −4 en écrivant x = ln(−4) : c'est doublement faux — le ln d'un nombre négatif n'existe pas, et de toute façon e^x > 0 pour tout x. La bonne réponse : aucune solution, S = ∅. Toujours vérifier le signe du second membre avant d'appliquer ln.

02
Notion 2 · equations_exp

Changement de variable & inéquations

Quand l'équation contient à la fois e^(2x) et e^x, elle devient un trinôme si l'on pose X = e^x. C'est LA technique du chapitre — avec son piège célèbre.

🧮 Exemple travaillé — Résoudre dans ℝ : e^(2x) − 3e^x + 2 = 0

L'exercice type, pas à pas, avec le contrôle de positivité.

1

Changement de variable. On remarque que e^(2x) = (e^x)². On pose X = e^x, avec X > 0 pour tout x réel.

2

Trinôme. L'équation devient X² − 3X + 2 = 0.

3

Résolution. Δ = (−3)² − 4 × 1 × 2 = 9 − 8 = 1, donc X₁ = (3 − 1)/2 = 1 et X₂ = (3 + 1)/2 = 2. (Ou factorisation : (X − 1)(X − 2) = 0.)

4

Contrôle crucial. On exige X > 0 : les deux racines conviennent (1 > 0 ✓ et 2 > 0 ✓).

5

Retour à x. e^x = 1 ⇔ x = 0 et e^x = 2 ⇔ x = ln 2. Conclusion : S = {0 ; ln 2}.

6

Vérification (pour x = ln 2) : e^(2 ln 2) − 3 · e^(ln 2) + 2 = e^(ln 4) − 6 + 2 = 4 − 6 + 2 = 0 ✓.

🧮 Exemple 2 — Résoudre e^(2x) − e^x − 6 = 0

Cette fois, une racine du trinôme doit être rejetée.

1

On pose X = e^x > 0 : l'équation devient X² − X − 6 = 0.

2

Δ = 1 + 24 = 25, donc X = (1 ± 5)/2 : X = 3 ou X = −2.

3

Rejet. X = −2 < 0 est impossible car X = e^x > 0 : cette racine est rejetée.

4

e^x = 3 ⇔ x = ln 3. Conclusion : S = {ln 3}.

Erreur fréquente au Bac — Oublier que X > 0

Dans le changement de variable, X = e^x est strictement positif : toute racine négative ou nulle du trinôme est toujours rejetée. Garder X = −2 et répondre « x = ln(−2) » est l'erreur classique qui annule toute la question. Écris noir sur blanc l'étape « contrôle : X > 0 ».

🧠 Les inéquations — même logique
exp étant strictement croissante, l'ordre est conservé : e^x > 7 ⇔ x > ln 7, donc S = ]ln 7 ; +∞[. Avec un exposant composé : e^(−2x) ≤ 9 ⇔ −2x ≤ ln 9 ⇔ x ≥ −ln 9 / 2 = −ln 3 (car ln 9 = 2 ln 3), donc S = [−ln 3 ; +∞[. Attention : diviser par −2 renverse l'inégalité !

Notion 3 · applications_exp

Intérêts composés, population, radioactivité

Trois modèles à connaître, tous bâtis sur le même schéma N(t) = N₀ · e^(kt) (k > 0 : croissance ; k < 0 : décroissance). Un seul contexte à la fois, des calculs nets.

🧮 Application 1 — Intérêts composés : quand le capital double-t-il ?

Un capital de C₀ = 10 000 F est placé à 5 % par an, intérêts composés. Après n années, Cₙ = C₀(1 + t)ⁿ = 10 000 × 1,05ⁿ. Au bout de combien d'années le capital a-t-il doublé ?

1

On cherche n tel que 1,05ⁿ ≥ 2.

2

On applique ln (croissante) : n · ln 1,05 ≥ ln 2, donc n ≥ ln 2 / ln 1,05 ≈ 14,2.

3

n est un nombre entier d'années : 1,05¹⁴ ≈ 1,98 < 2 mais 1,05¹⁵ ≈ 2,08 ≥ 2. Conclusion : le capital double au bout de 15 années.

🧮 Application 2 — Croissance d'une population

Une population suit N(t) = N₀ · e^(kt) avec N₀ = 2 millions et k = 0,03 an⁻¹. Que vaut N après 10 ans ? Calcul : N(10) = 2 · e^(0,03 × 10) = 2 · e^(0,3) ≈ 2 × 1,350 = 2,70 millions. La population a augmenté d'environ 35 % en 10 ans.

🧮 Application 3 — Décroissance radioactive et demi-vie

Une quantité radioactive suit N(t) = N₀ · e^(−λt) (λ > 0). La demi-vie t₁/₂ est le temps au bout duquel la moitié de la quantité initiale subsiste : c'est le modèle utilisé en SVT pour la datation au carbone 14.

1

Par définition : N(t₁/₂) = N₀/2, donc e^(−λ · t₁/₂) = 1/2.

2

On applique ln : −λ · t₁/₂ = ln(1/2) = −ln 2, d'où t₁/₂ = ln 2 / λ.

3

Application : pour λ = 0,10 j⁻¹, t₁/₂ = 0,693 / 0,10 ≈ 6,9 jours (car ln 2 ≈ 0,693).

4

Après 3 demi-vies, il reste (1/2)³ = 1/8 de la quantité initiale, soit 12,5 %.

N(t) = N₀ · e^(kt) (croissance) ; N(t) = N₀ · e^(−λt) (décroissance) ; t₁/₂ = ln 2 / λ
Taux t d'un capital : Cₙ = C₀(1 + t)ⁿ. Temps de doublement : n ≥ ln 2 / ln(1 + t). Demi-vie : t₁/₂ = ln 2 / λ.

Réflexes Bac

Stratégie d'examen

Face à un exercice sur exp, déroule cette liste de vérifications — dans l'ordre.

🧠 La check-list des réflexes
1. Signe d'abord. Devant e^x = a : si a ≤ 0, stop — aucune solution. 2. Changement de variable. Devant e^(2x) + e^x + … : poser X = e^x, résoudre le trinôme, puis rejeter toute racine X ≤ 0. 3. Ordre. Inéquation : invoquer la stricte croissance de exp, et faire attention au signe quand on divise. 4. Domaine. Un ln qui apparaît exige un argument strictement positif. 5. Vérification. Une primitive se vérifie en la dérivant ; une solution d'équation se vérifie en la remplaçant.
  • Limites composées : d'abord où tend u(x), ensuite e^(u) suit — et pense aux croissances comparées pour les formes indéterminées.
  • Position relative : toujours passer par une fonction auxiliaire g, sa dérivée, son minimum — jamais de « on voit sur le dessin ».
  • Rédaction : citer les théorèmes (croissances comparées, stricte croissance, signe de e^x) au lieu d'écrire « évident ».
  • Contrôle final : une solution négative pour e^x = X avec X < 0 ne peut jamais être correcte.
⚠️ Les trois fautes qui coûtent le plus de points

(1) Oublier le facteur u' dans (e^(u))'. (2) Garder une racine négative du trinôme en X = e^x. (3) Écrire e^(a + b) = e^a + e^b. Relis ta copie en cherchant ces trois pièges avant de rendre : c'est le gain de points le plus rapide du chapitre.

Q1 — L'équation e^(2x) − 5e^x + 6 = 0 admet :

A) une seule solution B) deux solutions C) aucune solution D) une infinité de solutions
Voir la réponse
B) deux solutions. Avec X = e^x : X² − 5X + 6 = (X − 2)(X − 3) = 0, donc X = 2 ou X = 3, toutes deux > 0. Retour à x : x = ln 2 ou x = ln 3. S = {ln 2 ; ln 3}.

Q2 — ln x = 3 équivaut à :

A) x = e³ B) x = ln 3 C) x = 3e D) x ≈ 20,09
Voir la réponse
A) x = e³. La réciproque donne x = e³, et comme e³ ≈ 20,085, l'option D est la même valeur mais l'égalité exacte demandée est x = e³. L'option B inverse ln et exp.

Q3 — Pour un élément radioactif, la demi-vie vérifie :

A) t₁/₂ = ln 2 / λ B) t₁/₂ = λ / ln 2 C) t₁/₂ = 2 / λ D) t₁/₂ = ln(2λ)
Voir la réponse
A) t₁/₂ = ln 2 / λ. On résout N₀ · e^(−λ · t₁/₂) = N₀/2 : en simplifiant par N₀ puis en appliquant ln, −λ · t₁/₂ = −ln 2, d'où t₁/₂ = ln 2 / λ. Application : λ = 0,10 j⁻¹ donne t₁/₂ ≈ 6,9 jours.
