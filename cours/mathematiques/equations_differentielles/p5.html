Mode d'emploi

Trois passages pour tout ancrer

Cette fiche ne raconte pas d'histoire : elle condense. Les Parties 1 à 4 ont construit les définitions et le sens ; ici, tout est mis à plat pour réviser vite et bien.

Le squelette unique du chapitre
y = yₚ + Ce^(ax)
Des solutions homogènes Ce^(ax) plus une solution particulière yₚ : trois équations (y' = ay ; y' = ay + b ; y' = ay + f(x)), un seul moule — tout le chapitre se reconstruit à partir de cette ligne.
Les trois passages recommandés
  • Passage 1 — Lire tout, une fois (20 minutes) : les formules, les réflexes, les erreurs. Objectif : voir la carte complète du chapitre — trois équations, un seul squelette.
  • Passage 2 — Cacher et restituer : couvre la colonne « Formule » de la grande table (section 01) et retrouve chaque formule à partir de son nom ; les échecs signalent exactement quoi relire (le renvoi te dit où la démonstration attend).
  • Passage 3 — La veille de l'épreuve : relis les réflexes, les erreurs et la figure finale (section 08). C'est le contenu à haute densité : 10 minutes qui valent une heure.
La règle d'or de la fiche

Une formule que tu ne sais pas re-démontrer en 2 minutes est une formule fragile. Bonne nouvelle : ce chapitre n'en a presque aucune à retenir par cœur — tout se reconstruit à partir du squelette y = yₚ + Ce^(ax), de la recherche de yₚ et de la substitution de la condition initiale. Chaque renvoi de la table pointe vers la section où la formule est obtenue.

02
Réflexes

Les 10 réflexes de calcul

À chaque situation son geste automatique — le signal de l'énoncé déclenche l'action :

Situation → action
  • « Montrer que y = … est solution » → trois lignes : (1) y' ; (2) ay + f(x) ; (3) égalité pour tout x. L'exposant doit égaler le coefficient.
  • « Résoudre y' = ay » → écrire la famille complète y = Ce^(ax), C ∈ ℝ — avec la lettre C, rien d'autre.
  • Une condition initiale apparaît → d'abord la solution générale, ensuite la substitution pour trouver C — jamais l'inverse.
  • Un doute sur une solution → re-dérive-la et compare les deux membres : la vérification en 2 lignes détecte toutes les erreurs du chapitre.
  • « Résoudre y' = ay + b » → calculer yₚ = −b/a, puis y = Ce^(ax) − b/a (particulière + homogène).
  • « Converge vers / se stabilise à » → vérifier a < 0 d'abord, puis la limite vaut −b/a ; si a > 0 : divergence.
  • Second membre variable → lire la nature de f et choisir la forme de yₚ dans le tableau avant tout calcul ; pour une exponentielle, comparer μ et a d'abord.
  • L'identification donne 0 = k → ce n'est pas une erreur de calcul : μ = a, la forme bloque — passer à λ·x·e^(ax) et recommencer.
  • f est une somme de natures différentes → superposition : une particulière par morceau (même a), puis on additionne.
  • Fin de tout exercice → les 4 filtres : équation (pour tout x), condition initiale (reporter x₀), exposant = a, cohérence (équilibre, signes, unités).
Le réflexe universel de vérification

Quel que soit l'exercice, le même contrôle final protège tout : dériver ta solution et comparer à ay + f(x) pour tout x, puis reporter la condition initiale dans la solution unique — tu dois retomber exactement sur y₀. Deux lignes, trois secondes chacune, des points sauvés à chaque fois.

03
Pièges

Les 10 erreurs à bannir

Chaque erreur, avec le faux et le vrai — elles sont toutes réparables en une ligne :

⚠️ Erreur 1 — écrire y = e^(ax) + C

Faux : C multiplie l'exponentielle : y = Ce^(ax). Et y = e^(ax) seul n'est qu'une solution, pas la famille complète.

⚠️ Erreur 2 — répondre Ce^(ax) à l'équation y' = ay + b

L'erreur n° 1 du chapitre — il manque le terme constant −b/a, qui absorbe b. Vérifie : les deux membres diffèrent de b.

⚠️ Erreur 3 — se tromper dans le signe de −b/a

Pour y' = 2y + 4, yₚ = −2 (pas +2) ; pour y' = −3y + 6, yₚ = +2 (deux moins font plus). Contrôle : a × yₚ + b doit valoir 0.

⚠️ Erreur 4 — appliquer la condition initiale avant la solution générale

On calcule C après avoir écrit y = yₚ + Ce^(ax) — sinon on confond C avec y₀ dès que yₚ ≠ 0.

⚠️ Erreur 5 — oublier le facteur e^(−ax₀) quand x₀ ≠ 0

Pour y(2) = 5 avec y' = −2y + 8, C = e⁴, pas C = 1. Contrôle : reporter x₀ dans la solution unique.

⚠️ Erreur 6 — rendre une réponse qui contient encore C

Une fois la condition initiale exploitée, la solution unique ne contient aucune lettre C.

⚠️ Erreur 7 — annoncer une convergence sans vérifier le signe de a

« Converge vers −b/a » n'est vrai que si a < 0 ; si a > 0, les solutions divergent (sauf C = 0).

⚠️ Erreur 8 — poser la forme de yₚ trop vite

λ·e^(ax) alors que μ = a donne l'absurdité 0 = k ; un polynôme incomplet casse l'identification ; une fréquence changée pour cos(βx) est morte-née.

⚠️ Erreur 9 — « vérifier » en testant des valeurs de x

Deux fonctions différentes peuvent coïncider en quelques points — l'égalité se prouve par le calcul littéral, pour tout x.

⚠️ Erreur 10 — tricher dans la traduction

Fuite ou refroidissement → terme −c·y (le signe !) ; « 5 % par minute » → 0,05 ; nommer l'unité de temps dès la première phrase.

Reconstruire sans mémoriser : cinq reconstructions de 30 secondes
  • Retrouver −b/a : pose yₚ = k (constante), dérive (yₚ' = 0), substitue : 0 = ak + b, donc k = −b/a. Rien à apprendre.
  • Retrouver C : jamais par cœur — écris y = yₚ + Ce^(ax), substitue la condition initiale, isole C : une seule équation à une inconnue.
  • Retrouver le cas piège μ = a : essaie yₚ = λ·e^(ax) — les termes en λ se compensent, il reste 0 = k (absurde). La parade : multiplier par x, la forme λ·x·e^(ax) crée le terme qui manquait.

  • Retrouver l'équilibre d'un modèle concret : cherche où la variation s'annule (fuite = apport) — c'est exactement −b/a, la solution particulière constante.
05
Fil rouge

Plan d'attaque d'un exercice type Bac

Un sujet de Bac enchaîne presque toujours : (1) une traduction de l'énoncé en équation ; (2) une résolution par les 4 étapes ; (3) une vérification ; (4) une limite avec interprétation (transitoire / régime permanent) ; (5) un temps de passage. Le fil rouge intégral — la réserve piscicole :

🧮 Le fil rouge — la réserve piscicole, en 5 questions

Q1 — Traduire. La population P(t) (en individus, t en années) décroît de 5 % par an (proportionnellement à P) ; la réserve est réapprovisionnée à raison de 20 individus par an ; P(0) = 1 000. « Décroît de 5 % par an, proportionnellement » → terme −0,05·P ; « 20 individus par an » → terme constant +20 :

P' = −0,05·P + 20 avec P(0) = 1 000

Q2 — Résoudre par les 4 étapes. Homogène : a = −0,05, donc P_h = Ce^(−0,05t). Particulière constante : yₚ = −20/(−0,05) = 400. Somme : P(t) = Ce^(−0,05t) + 400. Condition initiale : P(0) = C + 400 = 1 000, donc C = 600 :

P(t) = 600·e^(−0,05t) + 400

Q3 — Vérifier par les 4 filtres. Équation : P'(t) = −30e^(−0,05t) et −0,05P + 20 = −30e^(−0,05t) ✓. Condition : P(0) = 600 + 400 = 1 000 ✓. Exposant : e^(−0,05t) avec −0,05 = a ✓. Cohérence : a < 0 et C = 600 > 0 — la courbe est au-dessus de 400 et descend vers l'équilibre ✓.

Q4 — Limite et interprétation. Comme a = −0,05 < 0 : lim e^(−0,05t) = 0, donc lim P(t) = 400 = −b/a. Le terme 600e^(−0,05t) est le transitoire — il s'éteint ; ce qui reste, 400, est le régime permanent : quelle que soit la population de départ, la réserve se stabilise à 400 individus, valeur où la mortalité compense exactement le réapprovisionnement.

Q5 — Temps de passage à 700 individus.

600·e^(−0,05t) + 400 = 700 ⇔ e^(−0,05t) = 0,5 ⇔ t = (ln 2)/0,05 = 20·ln 2 ≈ 13,9 ans

Remarque : c'est la « demi-vie » de l'écart à l'équilibre (600 → 300) — la population atteindra 550 environ 13,9 ans plus tard.

La stratégie générale en 5 lignes

(1) Traduis chaque phrase de l'énoncé en un terme de l'équation (taux → ay, apport fixe → +b, fuite → −c·y). (2) Résous par les 4 étapes — particulière + homogène. (3) Fixe C avec la condition initiale, jamais avant. (4) Conclus par une phrase, avec les unités. (5) Contrôle : les 4 filtres, à chaque étape — pas seulement à la fin.

08
La figure finale

La famille Ce^(ax) — à refaire sans rien mémoriser

Toutes les solutions du chapitre vivent sur un seul dessin : la famille de courbes y = Ce^(ax) — et son extension Ce^(ax) − b/a pour y' = ay + b. Savoir redessiner la bonne courbe à la main, c'est emporter tout le chapitre : le rôle de a (monter ou descendre), le rôle de C (où la courbe coupe l'axe des ordonnées), la pente au départ, la destination quand x grandit.

La figure signature du chapitre
y = C·e^(at) — y(0) = C, pente en 0 = a·C
a > 0 : ça monte ; a < 0 : ça descend vers 0. C se lit en x = 0, la pente au départ vaut a·C — tout le reste se reconstruit.
🎯 LA MÉTHODE EN 5 ÉTAPES — dessiner la bonne courbe en 60 secondes
  • Étape 1 — Le squelette (15 s) : trace les axes et dessine la courbe de e^(at) : elle passe par (0 ; 1). Si a > 0 elle monte ; si a < 0 elle descend vers 0 (l'axe des x est asymptote). Le signe de a fixe toute la forme.
  • Étape 2 — Multiplier par C = étirer verticalement (10 s) : la courbe de Ce^(at) passe par (0 ; C) : même allure, juste étirée (ou retournée si C < 0). Le point de départ se lit sur l'axe des ordonnées.
  • Étape 3 — La pente en 0 vaut a·C (contrôle, 10 s) : car y' = ay, donc y'(0) = a·C. Exemple : y = 3e^(−x) part de (0 ; 3) avec la pente −3 (fortement descendante) ; y = 2e^x part de (0 ; 2) avec la pente +2. Si ta courbe part dans la mauvaise direction, c'est le signe de a ou de C qui a été mal lu.
  • Étape 4 — Condition initiale (x₀ ; y₀) : choisir la courbe (15 s) : la condition impose Ce^(ax₀) = y₀, donc C = y₀·e^(−ax₀) (et y = y₀·e^(a(x−x₀))). En pratique : place le point et choisis la courbe de la famille qui passe dedans — il n'y en a qu'une (unicité). Pour x₀ = 0, pas de calcul : C = y₀.
  • Étape 5 — Le cas y' = ay + b : la destination (10 s) : ajoute la droite horizontale y = −b/a (la valeur d'équilibre) en pointillés. Si a < 0 : toutes les courbes convergent vers cette asymptote — d'en haut si C > 0, d'en bas si C < 0. Si a > 0 : elles divergent (seule la droite d'équilibre reste stable). Le thé refroidit vers la température de la salle, le réservoir monte vers son niveau d'équilibre : c'est cette étape.
La fiche du tracé — ce que tu dois VRAIMENT retenir

Rien par cœur. Seulement : (1) le signe de a décide de monter ou descendre ; (2) C se lit en x = 0 ; (3) la pente au départ vaut a·C ; (4) une condition initiale = un point = une seule courbe (C = y₀·e^(−ax₀)) ; (5) pour y' = ay + b, la droite y = −b/a est la destination (si a < 0). Avec ces 5 gestes, tu dessines la bonne courbe en une minute — et chaque courbe retrouvée ainsi est une courbe que tu ne peux plus confondre.

🔍 Teste la méthode tout de suite

Cache les figures, prends une feuille, et dessine : (a) la solution de y' = −2y qui passe par (0 ; 3) — elle part de (0 ; 3), pente a·C = −6, et descend vers l'axe des x sans le toucher. (b) la solution de y' = −2y + 8 avec y(0) = 5 — équilibre −b/a = 4 en pointillés ; C = y₀ + b/a = 1 > 0, donc la courbe part de (0 ; 5), pente y'(0) = −2, et descend vers 4 par le haut. Contrôles : les deux courbes ne montent jamais ; aucune ne traverse son asymptote ✓

📌 Ce qu'il faut retenir
  • [fondations] y' = ay : y = Ce^(ax), C ∈ ℝ — l'exposant égale le coefficient ; C se lit en x = 0 ; deux solutions ne se croisent jamais.
  • [second_membre] y' = ay + b : y = Ce^(ax) − b/a ; condition en 0 : C = y₀ + b/a ; si a < 0, convergence vers −b/a.
  • [structure] y' = ay + f(x) : y = yₚ + Ce^(ax) — formes de yₚ : polynôme complet, λ·e^(μx) (μ ≠ a), k·x·e^(ax) (μ = a), paire cos/sin, superposition.
  • [methode] 4 étapes : homogène → particulière → somme → condition initiale ; formule universelle C = (y₀ − yₚ(x₀))·e^(−ax₀) ; unicité et 4 filtres de contrôle.
