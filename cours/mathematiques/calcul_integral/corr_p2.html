Corrigés — Intégration par parties (exercices 7 à 9)

✏️ Exercice 7 — IPP guidée (★★)

Données : G(x) = (x − 1)·e^x et H(x) = x·ln(x) − x à étudier pour en déduire deux intégrales.

1

Dérivée d'un produit, avec (u·v)' = u'·v + u·v' : G'(x) = 1·e^x + (x − 1)·e^x = (1 + x − 1)·e^x = x·e^x ✓. G est donc une primitive de x ↦ x·e^x.

2

∫₀¹ x·e^x dx = [G(x)]₀¹ = G(1) − G(0) = (0·e¹) − (−1·e⁰) = 0 + 1 = 1.

3

H'(x) = 1·ln(x) + x·(1/x) − 1 = ln(x) + 1 − 1 = ln(x) ✓ sur ]0 ; +∞[. H est une primitive de ln.

4

∫₁ᵉ ln(x) dx = [H(x)]₁ᵉ = (e·ln(e) − e) − (1·ln(1) − 1) = (e − e) − (0 − 1) = 1.

∫₀¹ x·e^x dx = 1
∫₁ᵉ ln(x) dx = 1
Deux intégrales célèbres, obtenues grâce à des primitives astucieuses.
⚠️ Piège — Ces primitives viennent d'une intégration par parties (u = x, v' = e^x, puis u = ln(x), v' = 1) : on dérive toujours le facteur qui s'appauvrit, jamais l'exponentielle en premier.
✏️ Exercice 8 — IPP à conduire seul (★★)

Données : calcul de ∫₀² x·e^x dx et ∫₁³ 2x·ln(x) dx.

1

Même primitive qu'à l'exercice 7 : ∫₀² x·e^x dx = [(x − 1)·e^x]₀² = (1·e²) − (−1·1) = e² + 1.

2

Comme e² ≈ 7,389 : ∫₀² x·e^x dx ≈ 8,39.

3

IPP avec u = ln(x) → u' = 1/x et v' = 2x → v = x² : ∫₁³ 2x·ln(x) dx = [x²·ln(x)]₁³ − ∫₁³ x²·(1/x) dx = (9·ln(3) − 0) − ∫₁³ x dx.

4

Or ∫₁³ x dx = [x²/2]₁³ = 9/2 − 1/2 = 4, donc ∫₁³ 2x·ln(x) dx = 9·ln(3) − 4 ≈ 9 × 1,0986 − 4 ≈ 9,887 − 4 ≈ 5,89. Vérification : (x²·ln(x) − x²/2)' = 2x·ln(x) + x − x = 2x·ln(x) ✓.

∫₀² x·e^x dx = e² + 1 ≈ 8,39
∫₁³ 2x·ln(x) dx = 9·ln(3) − 4 ≈ 5,89
Valeurs exactes d'abord, arrondis ensuite.
⚠️ Piège — Pour x·ln(x) : on dérive ln(x) (choix u = ln(x)) et on primitive 2x. L'autre choix fait apparaître des x²·ln(x) de plus en plus lourds.
✏️ Exercice 9 — Double intégration par parties (★★★)

Données : calcul de ∫₀¹ x²·e^x dx.

1

IPP avec u = x² → u' = 2x et v' = e^x → v = e^x : ∫₀¹ x²·e^x dx = [x²·e^x]₀¹ − ∫₀¹ 2x·e^x dx = (1·e − 0) − 2·∫₀¹ x·e^x dx = e − 2·∫₀¹ x·e^x dx.

2

L'exercice 7 a donné ∫₀¹ x·e^x dx = 1, donc ∫₀¹ x²·e^x dx = e − 2 ≈ 2,718 − 2 ≈ 0,72.

3

Vérification par dérivation : avec W(x) = (x² − 2x + 2)·e^x : W'(x) = (2x − 2)·e^x + (x² − 2x + 2)·e^x = x²·e^x ✓, et W(1) − W(0) = (1 − 2 + 2)·e − (0 − 0 + 2)·1 = e − 2 ✓.

∫₀¹ x²·e^x dx = e − 2 ≈ 0,72
La double IPP ramène à une intégrale déjà connue : inutile de tout refaire.
⚠️ Piège — Une IPP « dans le mauvais sens » (u = e^x) grossit l'intégrale au lieu de la réduire. Si x·e^x réapparaît, c'est un cadeau : réutilisez le résultat déjà démontré.

Corrigés — Aires et valeur moyenne (exercices 10 et 11)

✏️ Exercice 10 — Aire sous une parabole (★★)

Données : f(x) = 4 − x² sur [0 ; 2].

1

Sur [0 ; 2] : x² ≤ 4, donc f(x) = 4 − x² ≥ 0 : pas de découpage, l'intégrale donne directement l'aire.

2

Une primitive est F(x) = 4x − x³/3 (vérification : (4x − x³/3)' = 4 − x² ✓). Donc ∫₀² (4 − x²) dx = F(2) − F(0) = (8 − 8/3) − 0 = 24/3 − 8/3 = 16/3.

3

Aire sous la courbe = 16/3 ≈ 5,33 u.a.

4

Valeur moyenne : m = (1/(2 − 0))·(16/3) = 16/6 = 8/3 ≈ 2,67.

∫₀² (4 − x²) dx = 16/3 · aire ≈ 5,33 u.a. · m = 8/3 ≈ 2,67
On garde la fraction exacte jusqu'à l'arrondi final.
⚠️ Piège — Penser à soustraire F(0) = 0 explicitement, et à justifier le signe de f AVANT de parler d'aire : c'est une question du barème à chaque fois.
✏️ Exercice 11 — Aire entre deux courbes (★★★)

Données : f(x) = x et g(x) = x² sur [0 ; 1], domaine entre les deux courbes hachuré (voir la figure de exo_p2.html).

1

f(x) − g(x) = x − x² = x·(1 − x). Sur [0 ; 1] : x ≥ 0 et 1 − x ≥ 0, donc f(x) − g(x) ≥ 0 : la droite est au-dessus de la parabole.

2

Aire = ∫₀¹ (f(x) − g(x)) dx = [x²/2 − x³/3]₀¹ (vérification : (x²/2 − x³/3)' = x − x² ✓). Donc aire = (1/2 − 1/3) − 0 = 3/6 − 2/6 = 1/6.

3

1/6 ≈ 0,17 : l'aire hachurée vaut environ 0,17 u.a.

aire = ∫₀¹ (x − x²) dx = 1/6 ≈ 0,17 u.a.
Le signe de f − g dicte l'ordre de la différence dans l'intégrale.
⚠️ Piège — Sur [0 ; 1], f ≥ g : l'aire est ∫ (f − g). Mais pour x > 1, la parabole repasse au-dessus : il faudrait intégrer g − f. Toujours étudier le signe de f − g avant.

Corrigé — Type Bac (exercice 12)

✏️ Exercice 12 — Une exponentielle bien encadrée (★★★)

Données : f(x) = x·e^(−x) sur [0 ; +∞[, primitive proposée H(x) = −(x + 1)·e^(−x), aire totale admise égale à 1 u.a. sur [0 ; +∞[.

1

H est un produit et (e^(−x))' = −e^(−x) : H'(x) = (−1)·e^(−x) + (−(x + 1))·(−e^(−x)) = −e^(−x) + (x + 1)·e^(−x) = x·e^(−x) = f(x) ✓.

2

∫₀² f(x) dx = [H(x)]₀² = H(2) − H(0) = (−3·e^(−2)) − (−1·e⁰) = 1 − 3·e^(−2).

3

Comme e^(−2) ≈ 0,1353 : 3·e^(−2) ≈ 0,4060 et ∫₀² f(x) dx ≈ 0,5940 ≈ 0,59. Comme f ≥ 0 sur [0 ; 2], l'aire hachurée vaut environ 0,59 u.a.

4

Valeur moyenne : m = (1/(2 − 0))·0,5940 ≈ 0,297 ≈ 0,30.

5

Proportion d'aire : 0,5940/1 = 0,594, soit environ 59 % de l'aire totale se trouve sur [0 ; 2] : la queue de l'exponentielle est longue mais très fine.

∫₀² f(x) dx = 1 − 3·e^(−2) ≈ 0,59 · aire ≈ 0,59 u.a. · m ≈ 0,30 · environ 59 %
Un vrai sujet de Bac : primitive donnée à valider, intégrale, aire, valeur moyenne, interprétation.
⚠️ Piège — (e^(−x))' = −e^(−x) : dans une IPP avec v' = e^(−x), la primitive est v = −e^(−x). Ce signe oublié est l'erreur n° 1 sur ce type de sujet.
