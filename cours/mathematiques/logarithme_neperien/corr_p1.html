Calculs et simplifications

✏️ Exercice 1 — Premiers calculs ★

Énoncé : calculer ln 1 + ln e, ln(e²), ln(1/e) et e^(ln 5) + ln(e^(−2)), avec ln 1 = 0 et ln e = 1.

1
ln 1 + ln e = 0 + 1 = 1.
2
ln(e²) = 2 × ln e = 2 × 1 = 2 (propriété ln aⁿ = n·ln a avec a = e).
3
ln(1/e) = ln 1 − ln e = 0 − 1 = −1 ; autre rédaction : 1/e = e^(−1) donc ln(1/e) = −1.
4
e^(ln 5) = 5 et ln(e^(−2)) = −2, donc e^(ln 5) + ln(e^(−2)) = 5 + (−2) = 3.
ln 1 + ln e = 1 · ln(e²) = 2 · ln(1/e) = −1 · e^(ln 5) + ln(e^(−2)) = 3
Les deux valeurs de référence ln 1 = 0 et ln e = 1 font tout le travail.
⚠️ Piège : e^(ln a) n'a de sens que si a > 0, alors que ln(e^a) = a est vraie pour tout réel a.
✏️ Exercice 2 — Simplifications ★

Énoncé : simplifier A = ln 2 + ln 3, B = ln 5 − ln 20, C = 2 ln 3 + ln 2, D = ln 8 − 3 ln 2, E = ½ ln 25, F = ln 12 + ln 3 − 2 ln 2.

1
A = ln 2 + ln 3 = ln(2 × 3) = ln 6.
2
B = ln(5/20) = ln(1/4) = ln 1 − ln 4 = −ln 4 = −ln 2² = −2 ln 2.
3
C = ln 3² + ln 2 = ln 9 + ln 2 = ln(9 × 2) = ln 18.
4
D = ln 2³ − 3 ln 2 = 3 ln 2 − 3 ln 2 = 0 (car 8 = 2³).
5
E = ½ ln 25 = ln(25^(1/2)) = ln √25 = ln 5.
6
F = ln(12 × 3) − ln 2² = ln 36 − ln 4 = ln(36/4) = ln 9 = ln 3² = 2 ln 3.
A = ln 6 · B = −2 ln 2 · C = ln 18 · D = 0 · E = ln 5 · F = 2 ln 3
Toujours ramener à un seul logarithme, puis factoriser : c'est le cœur des réductions de ln.
⚠️ Piège : ln a + ln b = ln(ab), mais ln a + ln b ≠ ln(a + b) ! Le logarithme transforme les produits, pas les sommes.
✏️ Exercice 3 — Avec ln 2 ≈ 0,69 et ln 3 ≈ 1,10 ★★

Énoncé : exprimer ln 6, ln 12, ln 24 et ln(4/3) en fonction de ln 2 et ln 3, puis approcher avec ln 2 ≈ 0,69 et ln 3 ≈ 1,10.

1
ln 6 = ln(2 × 3) = ln 2 + ln 3 ≈ 0,69 + 1,10 = 1,79.
2
ln 12 = ln(4 × 3) = ln 2² + ln 3 = 2 ln 2 + ln 3 ≈ 1,38 + 1,10 = 2,48.
3
ln 24 = ln(8 × 3) = ln 2³ + ln 3 = 3 ln 2 + ln 3 ≈ 2,07 + 1,10 = 3,17.
4
ln(4/3) = ln 4 − ln 3 = 2 ln 2 − ln 3 ≈ 1,38 − 1,10 = 0,28.
ln 6 ≈ 1,79 · ln 12 ≈ 2,48 · ln 24 ≈ 3,17 · ln(4/3) ≈ 0,28
Valeurs plus précises avec ln 2 ≈ 0,693 : ln 24 ≈ 3,18 et ln(4/3) ≈ 0,29 — la précision du résultat dépend de celle des données.

Équations logarithmiques

✏️ Exercice 4 — Équations directes ★★

Énoncé : résoudre dans ℝ₊* les équations ln x = 2, ln x = −1, ln x = 0, ln x = 1/2 (question 0 : signe de ln x sur ]0 ; 1[).

Méthode
Pour tout réel a : ln x = a (avec x > 0) équivaut à x = e^a. Réponse 0 : sur ]0 ; 1[, ln x < 0 (la courbe est sous l'axe des abscisses).
1
ln x = 2 ⟺ x = e² ≈ 7,39. Vérification : ln 7,39 ≈ 2 ✓.
2
ln x = −1 ⟺ x = e^(−1) = 1/e ≈ 0,37 (cohérent : 0,37 est bien dans ]0 ; 1[ et ln y y est négatif).
3
ln x = 0 ⟺ x = e⁰ = 1 (c'est le point (1 ; 0) de la figure).
4
ln x = 1/2 ⟺ x = e^(1/2) = √e ≈ 1,65.
S₁ = {e² ≈ 7,39} · S₂ = {1/e ≈ 0,37} · S₃ = {1} · S₄ = {√e ≈ 1,65}
Chaque équation ln x = a a une unique solution x = e^a car ln est strictement croissante.
✏️ Exercice 5 — Équations avec propriétés ★★

Énoncé : résoudre ln(x + 2) = 3, 2 ln x = ln 8, ln(x² − 1) = ln 8 et (ln x)² − 3 ln x + 2 = 0, après détermination de l'ensemble d'étude.

1
Condition : x + 2 > 0 ⟺ x > −2. Alors ln(x + 2) = 3 ⟺ x + 2 = e³ ≈ 20,09, donc x = e³ − 2 ≈ 18,09. Vérification : ln(18,09 + 2) = ln(20,09) ≈ 3 ✓.
2
Condition : x > 0. Or 2 ln x = ln(x²), donc ln(x²) = ln 8 ⟺ x² = 8 ⟺ x = √8 = 2√2 ≈ 2,83 (la racine négative viole x > 0). Vérification : 2 ln(2,83) ≈ 2,08 et ln 8 ≈ 2,08 ✓.
3
Condition : x² − 1 > 0 ⟺ x < −1 ou x > 1. Alors x² − 1 = 8 ⟺ x² = 9 ⟺ x = 3 ou x = −3. Les deux conviennent : −3 < −1, et ln(9 − 1) = ln 8 ✓. Donc S = {−3 ; 3}.
4
Condition : x > 0. Posons X = ln x : l'équation devient X² − 3X + 2 = 0, de discriminant Δ = 9 − 8 = 1, d'où X = (3 + 1)/2 = 2 ou X = (3 − 1)/2 = 1. Donc x = e² ≈ 7,39 ou x = e ≈ 2,72. Vérifications : 1 − 3 + 2 = 0 ✓ et 4 − 6 + 2 = 0 ✓.
S₁ = {e³ − 2 ≈ 18,09} · S₂ = {2√2 ≈ 2,83} · S₃ = {−3 ; 3} · S₄ = {e ≈ 2,72 ; e² ≈ 7,39}
Changer de variable (X = ln x) transforme une équation du second degré en ln en une équation classique.
⚠️ Piège (équation 3) : ne rejette pas −3 trop vite ! La condition porte sur x² − 1 (qui vaut 8 > 0 pour x = −3), pas sur x lui-même : −3 est une vraie solution.
✏️ Exercice 6 — Équations de synthèse ★★★

Énoncé : résoudre ln x + ln(x − 1) = ln 6, ln(x + 2) − ln(x − 1) = ln 3 et 2 ln x = ln(x + 2), avec ensemble d'étude et vérification.

1
Conditions : x > 0 et x − 1 > 0, donc x > 1. Alors ln x + ln(x − 1) = ln[x(x − 1)] = ln 6 ⟺ x² − x − 6 = 0. Discriminant : Δ = 1 + 24 = 25, racines x = (1 + 5)/2 = 3 et x = (1 − 5)/2 = −2. Or −2 < 1 : rejeté. Vérification : ln 3 + ln 2 = ln 6 ✓. S = {3}.
2
Conditions : x + 2 > 0 et x − 1 > 0, donc x > 1. Alors ln[(x + 2)/(x − 1)] = ln 3 ⟺ (x + 2)/(x − 1) = 3 ⟺ x + 2 = 3x − 3 ⟺ 2x = 5 ⟺ x = 2,5 ✓. Vérification : ln 4,5 − ln 1,5 = ln(4,5/1,5) = ln 3 ✓. S = {2,5}.
3
Conditions : x > 0 (alors x + 2 > 2 > 0 ✓). Or 2 ln x = ln(x²), donc ln(x²) = ln(x + 2) ⟺ x² = x + 2 ⟺ x² − x − 2 = 0 ⟺ (x − 2)(x + 1) = 0 ⟺ x = 2 ou x = −1. Comme −1 < 0 : rejeté. Vérification : 2 ln 2 = ln 4 = ln(2 + 2) ✓. S = {2}.
S₁ = {3} · S₂ = {2,5} · S₃ = {2}
Schéma universel : domaine d'existence → regroupement en un seul ln → égalité des arguments → vérification.
⚠️ Piège : regrouper ln x + ln(x − 1) exige que LES DEUX facteurs soient strictement positifs ; oublier x − 1 > 0 fait apparaître la fausse solution −2.
