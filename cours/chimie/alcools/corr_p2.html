Degré alcoolique et oxydations en chaîne

✏️ Exercice 1 — Le degré alcoolique d'un rhum (★★)

Données : rhum à 45° ; ρ = 0,79 g·mL⁻¹ ; M = 46 g·mol⁻¹ ; bouteille de 70,0 cL.

1

Définition : un rhum à 45° contient 45,0 mL d'éthanol pur pour 100 mL de boisson → dans un verre de 100 mL : V = 45,0 mL.

2

Masse : m = ρ × V = 0,79 × 45,0 = 35,55 ≈ 35,6 g.

3

Quantité de matière : n = m/M = 35,55/46 = 0,77 mol.

4

Bouteille de 70,0 cL = 700 mL : V = 45,0 × 7 = 315 mL → m = 0,79 × 315 = 248,85 ≈ 249 g → n = 248,85/46 = 5,41 ≈ 5,4 mol.

5

Vérification (deuxième calcul) : la bouteille vaut 7 verres → 0,77 × 7 = 5,39 ≈ 5,4 mol ✓.

Verre : 35,6 g (0,77 mol) · bouteille : 249 g (5,4 mol)

Le degré relie un volume d'éthanol pur à un volume de boisson.

⚠️ Piège : le degré est un rapport de VOLUMES (mL d'éthanol pour 100 mL de boisson), pas un pourcentage massique.
✏️ Exercice 2 — Aldéhyde ou cétone : le test de Fehling (★★)

Données : E = CH₃—CH₂—CHO ; F = CH₃—CO—CH₃ (C₃H₆O) ; G (C₃H₈O) donne par oxydation un produit à test de Fehling positif.

1

E est le propanal (aldéhyde : groupe —CHO) ; F est la propanone (cétone : groupe C=O entre deux carbones). Même formule brute C₃H₆O, formules développées différentes → isomères.

2

E provient du propan-1-ol (primaire) : CH₃—CH₂—CH₂—OH + [O] → CH₃—CH₂—CHO + H₂O (bilan vérifié : 3 C ; 8 H ; 2 O).

3

F provient du propan-2-ol (secondaire) : CH₃—CHOH—CH₃ + [O] → CH₃—CO—CH₃ + H₂O.

4

G : son produit d'oxydation donne le précipité rouge brique de Cu₂O → c'est un aldéhyde → G est un alcool primaire → G = CH₃—CH₂—CH₂—OH (propan-1-ol) ; CH₃—CH₂—CH₂—OH + [O] → CH₃—CH₂—CHO + H₂O.

E = propanal · F = propanone · G = propan-1-ol (primaire)

Fehling positif = aldéhyde = origine primaire ; négatif = cétone possible.

⚠️ Piège : la liqueur de Fehling teste les ALDÉHYDES uniquement ; une cétone ne donne jamais le précipité rouge brique.
✏️ Exercice 3 — Dosage de l'éthanol d'un vin (★★★)

Données : vin à 12° ; V = 100 mL ; ρ = 0,79 g·mL⁻¹ ; M(éthanol) = 46 g·mol⁻¹ ; M(acide) = 60 g·mol⁻¹.

1

Chaîne d'oxydation : C₂H₅OH + [O] → CH₃—CHO + H₂O puis CH₃—CHO + [O] → CH₃—COOH → oxydation totale : C₂H₅OH + 2[O] → CH₃—COOH + H₂O (bilan vérifié : 2 C ; 6 H ; 1 + 2 = 2 + 1 O).

2

Dans 100 mL de vin à 12° : V(éthanol) = 12,0 mL → m = 0,79 × 12,0 = 9,48 g → n(éthanol) = 9,48/46 = 0,206 ≈ 0,21 mol.

3

Oxydant nécessaire : n([O]) = 2 × 0,206 = 0,41 mol.

4

Acide formé : m(acide) = 0,206 × 60 = 12,36 ≈ 12,4 g.

5

Vérification (deuxième calcul) : m(acide) = m(éthanol) × M(acide)/M(éthanol) = 9,48 × 60/46 = 9,48 × 1,30 = 12,4 g ✓.

n(éthanol) ≈ 0,21 mol · n([O]) = 0,41 mol · m(acide) ≈ 12,4 g

Deux [O] pour aller jusqu'à l'acide : une étape de plus qu'avec l'aldéhyde.

⚠️ Piège : 1 [O] mène à l'aldéhyde, 2 [O] à l'acide — compter les étapes avant d'écrire le bilan.
✏️ Exercice 4 — Identifier un alcool inconnu (★★★)

Données : A : C₄H₁₀O, M = 74 g·mol⁻¹ ; m(A) = 7,4 g ; m(B) = 7,2 g ; B à test de Fehling négatif.

1

Quantité de matière : n(A) = m/M = 7,4/74 = 0,100 mol.

2

Tout A est oxydé et l'oxydation ménagée conserve le squelette : n(B) = n(A) = 0,100 mol → M(B) = 7,2/0,100 = 72 g·mol⁻¹.

3

Cohérence : l'oxydation ménagée retire 2 H (un du —OH, un du carbone fonctionnel) et crée la liaison C=O → M(B) = 74 − 2 = 72 g·mol⁻¹ ✓, formule brute C₄H₈O.

4

Fehling négatif → B n'est pas un aldéhyde → B est une cétone → A est un alcool secondaire.

5

Identifications : B = CH₃—CO—CH₂—CH₃ (butanone) ; A = CH₃—CHOH—CH₂—CH₃ (butan-2-ol) ; équation : CH₃—CHOH—CH₂—CH₃ + [O] → CH₃—CO—CH₂—CH₃ + H₂O (bilan vérifié : 4 C ; 10 H ; 2 O).

6

Élimination des isomères : butan-1-ol et 2-méthylpropan-1-ol sont primaires (donneraient un aldéhyde, Fehling positif) ; 2-méthylpropan-2-ol est tertiaire (aucune réaction). Vérification (deuxième calcul) : m(B) = 0,100 × 72 = 7,2 g ✓.

A = butan-2-ol (secondaire) · B = butanone CH₃—CO—CH₂—CH₃

Masses + test de Fehling = identification complète de l'alcool.

⚠️ Piège : un Fehling négatif ne signifie pas « pas de réaction » : il signe une cétone, donc un alcool secondaire.
✏️ Exercice 5 — Du jus de pomme au vinaigre (★★★)

Données : 90 g de glucose (M = 180 g·mol⁻¹) ; fermentation C₆H₁₂O₆ → 2 C₂H₅OH + 2 CO₂ ; cidre de volume 1,0 L ; ρ = 0,79 g·mL⁻¹ ; M(éthanol) = 46 g·mol⁻¹ ; M(acide) = 60 g·mol⁻¹.

1

Glucose : n = 90/180 = 0,50 mol. Équation vérifiée : 6 C ; 12 H ; 6 O de part et d'autre ✓.

2

Fermentation : n(éthanol) = 2 × 0,50 = 1,0 mol → m = 1,0 × 46 = 46 g.

3

Degré alcoolique du cidre : V(éthanol) = m/ρ = 46/0,79 = 58 mL dans 1,0 L → 5,8 ≈ 6°.

4

Chaîne d'oxydation : C₂H₅OH + [O] → CH₃—CHO + H₂O puis CH₃—CHO + [O] → CH₃—COOH → bilan : C₂H₅OH + 2[O] → CH₃—COOH + H₂O → n([O]) = 2 × 1,0 = 2,0 mol.

5

Vinaigre : m(acide) = 1,0 × 60 = 60 g dans 1,0 L → 6,0 g pour 100 mL → degré acide ≈ 6,0.

6

Vérification (deuxième calcul) : chaque étape conserve la quantité de matière du squelette : n(éthanal) = n(acide) = n(éthanol) = 1,0 mol ✓.

Cidre ≈ 6° · acide éthanoïque : 60 g/L (degré acide ≈ 6,0)

Fermentation puis oxydation en chaîne : primaire → aldéhyde → acide.

⚠️ Piège : la chaîne complète consomme 2 [O] au total, et chaque étape conserve n : ici 1,0 mol d'éthanol donne 1,0 mol d'acide.
