Décodage complet et comptages

✏️ Exercice 1 — Décoder un gène ★★

Énoncé rappelé : brin transcrit T—A—C—G—G—T—A—A—T—C—C—A—G—G—C ; tableau du code génétique fourni.

1

Transcription nucléotide par nucléotide : T→A, A→U, C→G, G→C, G→C, T→A, A→U, A→U, T→A, C→G, C→G, A→U, G→C, G→C, C→G.

2

ARNm : A—U—G—C—C—A—U—U—A—G—G—U—C—C—G, soit en blocs de 3 : AUG | CCA | UUA | GGU | CCG.

3

Décodage codon par codon : AUG → Met ; CCA → Pro ; UUA → Leu ; GGU → Gly ; CCG → Pro. Peptide : Met—Pro—Leu—Gly—Pro.

4

Anticodons correspondants, complémentaires un à un : AUG ↔ UAC, CCA ↔ GGU, UUA ↔ AAU, GGU ↔ CCA, CCG ↔ GGC. Donc : UAC—GGU—AAU—CCA—GGC.

5

5 ARNt se succèdent (un par acide aminé incorporé). La transcription a lieu dans le noyau, la traduction sur les ribosomes, dans le cytoplasme.

ARNm AUG—CCA—UUA—GGU—CCG → Met—Pro—Leu—Gly—Pro · anticodons UAC—GGU—AAU—CCA—GGC
Vérification : 15 nucléotides = 5 codons ✓ ; chaque anticodon est complémentaire de son codon ✓.
✏️ Exercice 2 — De la taille du gène à la taille de la protéine ★★★

Énoncé rappelé : gène humain, brin transcrit de 603 nucléotides ; initiateur A—U—G, dernier codon = stop non traduit.

1

L'ARNm est la copie du brin transcrit : il compte 603 nucléotides. Nombre de codons : 603 ÷ 3 = 201 codons.

2

Le dernier codon (stop) n'est pas traduit : 201 − 1 = 200 acides aminés dans la protéine. Le codon initiateur AUG, lui, est bien traduit (Met).

3

Un ARNt par acide aminé incorporé : 200 ARNt se succèdent sur le ribosome.

4

Transcription dans le noyau, traduction dans le cytoplasme (sur les ribosomes). Chemin de l'information : ADN → ARNm → protéine.

603 nt → 201 codons → 200 acides aminés → 200 ARNt successifs
Vérification : 3 × 201 = 603 ✓ ; 201 − 1 = 200 ✓.
⚠️ Piège : ne compte pas 201 acides aminés : le codon stop ordonne la fin de la traduction, il ne donne aucun acide aminé.

Mutations et phénotype : la drépanocytose

✏️ Exercice 3 — La drépanocytose, une maladie d'une seule lettre ★★★

Énoncé rappelé : brin transcrit HbA C—T—C, HbS C—A—C ; position 6 de la chaîne β : Glu chez HbA, Val chez HbS ; globules rouges en faucille sous faible O₂.

1

Transcriptions : HbA, C→G, T→A, C→G → ARNm G—A—G ; HbS, C→G, A→U, C→G → ARNm G—U—G. Décodage : GAG → Glu (acide glutamique) ; GUG → Val (valine) ✓, conforme au document 1.

2

C'est une substitution : sur le brin transcrit, le nucléotide T de C—T—C est remplacé par un A, d'où C—A—C. Un seul nucléotide change, un seul codon est touché.

3

Pourquoi une maladie grave ? Glu est hydrophile et chargée, Val est hydrophobe : ce changement de propriétés modifie le repliement et la solubilité de l'hémoglobine. Sous faible O₂, les molécules de HbS s'assemblent en longues fibres à l'intérieur du globule rouge, qui se déforme en faucille, devient fragile et se fragmente : c'est l'anémie. Une seule lettre du gène change donc le phénotype entier.

4

Les individus AS (hétérozygotes) possèdent une copie normale : ils produisent assez de HbA et ne sont pas anémiques, mais ils résistent mieux au paludisme, très fréquent au Niger. Cet avantage entretient l'allèle S dans la population : la mutation n'a pas disparu, c'est un équilibre favorable aux hétérozygotes.

HbA : C—T—C → GAG → Glu · HbS : C—A—C → GUG → Val · substitution d'un seul nucléotide
Vérification : GAG = Glu ✓ ; GUG = Val ✓ ; un seul nucléotide diffère entre les deux brins ✓.
⚠️ Piège Bac : écris toujours la chaîne complète cause → effet : gène modifié → acide aminé modifié → protéine modifiée → cellule modifiée (globule rouge en faucille) → individu malade.
✏️ Exercice 4 — Quand le cadre de lecture déraille ★★★

Énoncé rappelé : ARNm normal A—U—G—C—C—U—A—G—A—G—C—U—U—A—A ; délétion du nucléotide de position 4 (C) ; ARNm muté A—U—G—C—U—A—G—A—G—C—U—U—A—A.

1

ARNm normal, blocs de 3 : AUG | CCU | AGA | GCU | UAA. Décodage : Met—Pro—Arg—Ala, puis le codon stop UAA termine la traduction. Peptide normal : Met—Pro—Arg—Ala.

2

ARNm muté, redécoupage depuis le début : AUG | CUA | GAG | CUU | A+A…. Décodage : Met—Leu—Glu—Leu, puis un fragment de 2 nucléotides qui ne forme pas un codon complet, et aucun codon stop lu. Comparaison : dès le deuxième acide aminé, tout change (Pro → Leu, Arg → Glu, Ala → Leu…).

3

C'est le décalage du cadre de lecture : la perte d'un nucléotide déplace toutes les bornes des blocs de 3 situés en aval de la délétion.

4

La protéine mutée est presque toujours non fonctionnelle parce que toute la séquence après la délétion change et que la lecture s'arrête anormalement : le repliement 3D de la protéine est bouleversé, très loin d'un simple remplacement d'un acide aminé comme dans une substitution.

Normal : Met—Pro—Arg—Ala + stop · Muté : Met—Leu—Glu—Leu… cadre de lecture décalé
Vérification : AUG = Met ✓ ; CUA = Leu ✓ ; GAG = Glu ✓ ; CUU = Leu ✓ ; 15 − 1 = 14 nucléotides, dernier bloc incomplet ✓.
⚠️ Piège : après une délétion, on ne redécoupe pas à partir du point de mutation seulement : la lecture reprend depuis l'initiateur AUG, donc tous les codons suivants sont décalés.

Problème de synthèse : le chemin de l'information

✏️ Exercice 5 — Du gène à la protéine, l'histoire complète ★★★

Énoncé rappelé : schéma de l'expression d'un gène avec 7 éléments numérotés ; légende à compléter, propriétés du code génétique, calcul sur les codons de 2 nucléotides.

1

Légende complétée : ① noyau · ② ADN (gène) · ③ ARN polymérase · ④ ARNm · ⑤ ribosome · ⑥ ARNt · ⑦ chaîne peptidique (protéine en formation).

2

La transcription se déroule dans le noyau : l'ARN polymérase copie le gène en ARNm, qui sort par les pores nucléaires. La traduction se déroule dans le cytoplasme : le ribosome lit l'ARNm codon par codon et les ARNt apportent les acides aminés. Chemin complet : ADN → ARNm → protéine.

3

Propriétés du code génétique : universel — les mêmes codons ont le même sens chez tous les êtres vivants, de la bactérie à l'homme ; redondant — plusieurs codons peuvent coder le même acide aminé, par exemple UUA et UUG codent tous deux la Leu ; non ambigu — un codon donné ne code qu'un seul acide aminé : UUA signifie toujours Leu, jamais autre chose.

4

« À trois lettres » : chaque codon comporte 3 nucléotides choisis parmi 4 bases, soit 4 × 4 × 4 = 64 combinaisons, de quoi coder les 20 acides aminés plus les codons stop. Avec des codons de 2 nucléotides : 4 × 4 = 16 combinaisons seulement, soit moins que les 20 acides aminés → impossible : le code ne peut donc pas être « à deux lettres ».

① noyau · ② ADN · ③ ARN polymérase · ④ ARNm · ⑤ ribosome · ⑥ ARNt · ⑦ peptide — 4³ = 64 codons, 4² = 16 < 20
Vérification : 64 combinaisons ≥ 20 acides aminés + 3 stops ✓ ; 16 < 20 → 2 nucléotides insuffisants ✓.
⚠️ Piège : universel ne veut pas dire redondant : l'universalité concerne tous les êtres vivants, la redondance concerne plusieurs codons pour un même acide aminé. Deux idées distinctes à ne pas mélanger dans la rédaction.
📌 À retenir de cette série
  • Décodage en 3 temps : transcription lettre par lettre, découpage en blocs de 3, tableau du code génétique codon par codon.
  • nucléotides ÷ 3 = codons ; retranche les stops pour les acides aminés (603 nt → 200 acides aminés).
  • Substitution d'un nucléotide → au plus un acide aminé changé (drépanocytose : GAG → GUG, Glu → Val) ; délétion → cadre de lecture décalé, tout change en aval.
  • Code génétique : universel, redondant, non ambigu ; 64 codons, initiateur AUG, stops UAA, UAG, UGA.
