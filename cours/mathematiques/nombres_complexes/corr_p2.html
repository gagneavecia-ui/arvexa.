Corrigés · Thème 01 · N° 1 → 5

Conjugué : calculs et propriétés

Le conjugué z̄ = a − ib : même partie réelle, partie imaginaire opposée — la réflexion par rapport à l'axe des réels.

✏️ Exercice 1 — Conjugués éclair (★)

Rappel : conjugués de z₁ = 3 + 2i, z₂ = −1 + 5i, z₃ = 4 − 7i, z₄ = −6i, z₅ = 9, z₆ = i√5.

1

La règle : conserver la partie réelle, changer le signe de la partie imaginaire — z = a + ib donne z̄ = a − ib.

2

On applique un par un : z̄₁ = 3 − 2i ; z̄₂ = −1 − 5i ; z̄₃ = 4 + 7i ; z̄₄ = 6i ; z̄₅ = 9 ; z̄₆ = −i√5.

3

Résultat : z̄₁ = 3 − 2i ; z̄₂ = −1 − 5i ; z̄₃ = 4 + 7i ; z̄₄ = 6i ; z̄₅ = 9 ; z̄₆ = −i√5. Les réels purs (comme z₅) sont leurs propres conjugués.

✏️ Exercice 2 — z + z̄ et z·z̄ (★)

Rappel : pour z = 2 + 3i puis z = 1 − 4i, calculer z + z̄ et z·z̄.

1

Pour z = 2 + 3i : z + z̄ = (2 + 3i) + (2 − 3i) = 4 et z·z̄ = (2 + 3i)(2 − 3i) = 4 − 9i² = 4 + 9 = 13.

2

Pour z = 1 − 4i : z + z̄ = 2 et z·z̄ = 1² + 4² = 17.

3

Résultat : 4 et 13 ; puis 2 et 17. Constat : z + z̄ = 2Re(z) est toujours réel, et z·z̄ = Re(z)² + Im(z)² = |z|² est un réel positif.

✏️ Exercice 3 — Conjugué d'une somme et d'un produit (★)

Rappel : w₁ = (1 + 2i) + (3 − i) et w₂ = (1 + i)(2 − i), puis leurs conjugués.

1

w₁ = (1 + 3) + (2 − 1)i = 4 + i, donc w̄₁ = 4 − i.

2

w₂ = 2 − i + 2i − i² = 3 + i, donc w̄₂ = 3 − i. Vérification du c) : (1 − i)(2 + i) = 2 + i − 2i − i² = 3 − i ✔ — le conjugué d'un produit est le produit des conjugués.

3

Résultat : w̄₁ = 4 − i et w̄₂ = 3 − i.

✏️ Exercice 4 — Caractérisation par le conjugué (★★)

Rappel : montrer z réel ⟺ z = z̄ ; z imaginaire pur ⟺ z̄ = −z ; puis classer z = (2 + i)² et w = (1 + i)².

1

a) Avec z = a + ib : z = z̄ ⟺ ib = −ib ⟺ 2b = 0 ⟺ b = 0, c'est-à-dire z réel ✔.

2

b) z̄ = −z ⟺ a − ib = −a − ib ⟺ 2a = 0 ⟺ a = 0, c'est-à-dire z imaginaire pur ✔.

3

c) z = (2 + i)² = 3 + 4i : ni réel pur (Im ≠ 0) ni imaginaire pur (Re ≠ 0). w = (1 + i)² = 2i : Re(w) = 0 donc w = −w̄ : imaginaire pur.

4

Résultat : z est ni l'un ni l'autre ; w est imaginaire pur.

z réel ⟺ z = z̄  ·  z imaginaire pur ⟺ z̄ = −z  ·  z·z̄ = |z|²
Les trois cartes d'identité du conjugué — à connaître par cœur pour cette partie et la suite.
✏️ Exercice 5 — Libérer les dénominateurs (★★)

Rappel : écrire sous forme algébrique A = (3 + 2i)/(1 − i) et B = (1 + i)/i.

1

A : on multiplie par (1 + i)/(1 + i) (le conjugué du dénominateur). Dénominateur : (1 − i)(1 + i) = 1 − i² = 2. Numérateur : (3 + 2i)(1 + i) = 3 + 3i + 2i + 2i² = 1 + 5i.

2

Donc A = (1 + 5i)/2 = 1/2 + (5/2)i = 0,5 + 2,5i.

3

B : on multiplie par (−i)/(−i). Numérateur : (1 + i)(−i) = −i − i² = 1 − i ; dénominateur : −i² = 1. Donc B = 1 − i.

4

Résultat : A = 0,5 + 2,5i et B = 1 − i. ⚠️ Piège : on multiplie par le conjugué du dénominateur — jamais de multiplication « au hasard ».

Module : calculs et lieux

Le module |z| = √(a² + b²) est la distance OM : produits et quotients se lisent directement sur les modules.

✏️ Exercice 6 — Modules au programme (★)

Rappel : |3 + 4i|, |−5 + 12i|, |1 − i|, |2i|, |−7|, |√3/2 + (1/2)i|.

1

On élève au carré, on additionne, on extrait la racine : |3 + 4i| = √(9 + 16) = √25 = 5 ; |−5 + 12i| = √(25 + 144) = √169 = 13 (le duo 5-12-13 !).

2

|1 − i| = √(1 + 1) = √2 ; |2i| = √4 = 2 ; |−7| = 7 ; |√3/2 + (1/2)i| = √(3/4 + 1/4) = √1 = 1.

3

Résultat : 5 ; 13 ; √2 ; 2 ; 7 ; 1 (en unités du repère).

✏️ Exercice 7 — Le pont z·z̄ = |z|² (★)

Rappel : z·z̄ pour z = 2 + i, z = 3 − 2i, z = (1 + i)², puis |z|.

1

(2 + i)(2 − i) = 4 + 1 = 5 → |z| = √5. (3 − 2i)(3 + 2i) = 9 + 4 = 13 → |z| = √13.

2

Pour z = (1 + i)² = 2i : z·z̄ = 2i × (−2i) = −4i² = 4 → |z| = 2.

3

Résultat : |z| = √5 ; √13 ; 2 (en unités). Le pont |z|² = z·z̄ évite toute erreur de signe.

✏️ Exercice 8 — Modules sans développer (★★)

Rappel : |(2 + i)(1 − i)| et |(3 + 4i)/(1 + i)|.

1

a) Le module d'un produit est le produit des modules : |(2 + i)(1 − i)| = |2 + i| × |1 − i| = √5 × √2 = √10.

2

b) Le module d'un quotient est le quotient des modules : |(3 + 4i)/(1 + i)| = |3 + 4i| / |1 + i| = 5/√2 = 5√2/2 ≈ 3,54 (unités).

3

Résultat : a) √10 ; b) 5√2/2 ≈ 3,54 u.

✏️ Exercice 9 — Distances et ensembles de points (★★)

Rappel : décrire |z − 2| = 3 ; |z − 1 − i| = √2 ; |z − i| = |z + 2|.

1

a) |z − 2| = |z − 2 + 0i| = 3 : distance à A(2 ; 0) égale à 3 → cercle de centre Ω₁(2 ; 0) et de rayon 3.

2

b) |z − 1 − i| = |z − (1 + i)| = √2 : cercle de centre Ω₂(1 ; 1) et de rayon √2 ≈ 1,41 u.

3

c) |z − i| = |z − (−2)| : M équidistant de A(0 ; 1) et B(−2 ; 0) → médiatrice du segment [AB].

4

Résultat : deux cercles (centres (2 ; 0) rayon 3 et (1 ; 1) rayon √2) et une médiatrice.

✏️ Exercice 10 — Un nombre sur le cercle unité (★★★)

Rappel : z = (2 + i)/(2 − i) — montrer |z| = 1, puis forme algébrique, puis vérification.

1

a) |z| = |2 + i| / |2 − i| = √5/√5 = 1 — sans même connaître z : son point image est sur le cercle unité.

2

b) On multiplie par le conjugué : z = (2 + i)² / ((2 − i)(2 + i)) = (3 + 4i)/5, soit z = 3/5 + (4/5)i = 0,6 + 0,8i.

3

c) Re(z)² + Im(z)² = (3/5)² + (4/5)² = 9/25 + 16/25 = 25/25 = 1 ✔.

4

Résultat : |z| = 1 et z = 0,6 + 0,8i — et (0,6)² + (0,8)² = 1 ✔.

Argument : angles et rotations

arg(z) = angle (→Ox ; →OM) en radians, à 2π près — multiplier par i revient à tourner d'un quart de tour.

✏️ Exercice 11 — Les quatre points cardinaux (★)

Rappel : argument de 1, i, −1, −i, 2, −3i.

1

Sur le cercle trigonométrique : 1 est à droite (angle nul), i en haut (quart de tour), −1 à gauche (demi-tour), −i en bas.

2

Les réels purs non nuls (1 et 2) ont pour argument 0 ; les imaginaires purs négatifs (−i et −3i) ont pour argument −π/2.

3

Résultat : arg(1) = 0 ; arg(i) = π/2 rad ; arg(−1) = π rad ; arg(−i) = −π/2 rad ; arg(2) = 0 ; arg(−3i) = −π/2 rad (à 2π près).

✏️ Exercice 12 — Arguments et opérations (★)

Rappel : calculer puis argumenter i × (−1), (1 + i)(1 − i), i⁵.

1

a) i × (−1) = −i → argument −π/2. Contrôle avec la règle : arg(i) + arg(−1) = π/2 + π = 3π/2 ≡ −π/2 (2π près) ✔.

2

b) (1 + i)(1 − i) = 1 − i² = 2, réel positif → argument 0. c) i⁵ = i⁴ × i = i → argument π/2.

3

Résultat : −π/2 rad ; 0 ; π/2 rad (à 2π près) — la règle arg(z·z') = arg(z) + arg(z') se vérifie partout.

✏️ Exercice 13 — Modules et arguments des classiques (★★)

Rappel : z₁ = 1 + i, z₂ = √3 + i, z₃ = 1 − i, z₄ = −1 + i.

1

z₁ : |z₁| = √2 ; cos θ = 1/√2 = √2/2 et sin θ = √2/2 → θ = π/4. z₃ : même module √2, ordonnée négative → θ = −π/4.

2

z₂ : |z₂| = √(3 + 1) = 2 ; cos θ = √3/2, sin θ = 1/2 → θ = π/6. z₄ : |z₄| = √2 ; cos θ = −√2/2, sin θ = √2/2 → θ = 3π/4.

3

Résultat : (√2 ; π/4) ; (2 ; π/6) ; (√2 ; −π/4) ; (√2 ; 3π/4) — modules en unités, arguments en radians.

✏️ Exercice 14 — Un argument au deuxième quadrant (★★★)

Rappel : z = −√3 + i — module, argument, position de M(z).

1

a) |z| = √((−√3)² + 1²) = √(3 + 1) = 2 (unités).

2

b) cos θ = −√3/2 et sin θ = 1/2 : au cercle trigonométrique, cet angle vaut θ = 5π/6 rad.

3

c) M(−√3 ; 1) : abscisse négative, ordonnée positive → deuxième quadrant. Or 5π/6 ∈ ]π/2 ; π[ : l'angle est bien entre 90° et 180° ✔ cohérent.

4

Résultat : |z| = 2 u et arg(z) = 5π/6 rad (à 2π près), M dans le deuxième quadrant.

✏️ Exercice 15 — La rotation z' = iz (★★★)

Rappel : z' = iz — nature de la transformation, images de A(1 + i) et B(2 − i), contrôles des longueurs.

1

a) |z'| = |iz| = |i| × |z| = 1 × |z| = |z| : les distances à O sont conservées.

2

b) arg(z') = arg(i) + arg(z) = π/2 + arg(z) (à 2π près) : M' est l'image de M par la rotation de centre O et d'angle π/2 (quart de tour direct).

3

c) A' : z_A' = i(1 + i) = i + i² = −1 + i ; B' : z_B' = i(2 − i) = 2i − i² = 1 + 2i.

4

Contrôles : |OA'| = |−1 + i| = √2 = |1 + i| = |OA| ✔ et |OB'| = |1 + 2i| = √5 = |2 − i| = |OB| ✔.

5

Résultat : z_A' = −1 + i et z_B' = 1 + 2i — longueurs conservées (√2 u et √5 u), angles tournés de π/2 rad.

📌 Bilan des corrections
  • Trois outils, trois usages : z̄ pour libérer les dénominateurs, |z| pour les distances, arg(z) pour les angles (en radians, à 2π près).
  • À retenir en une ligne : z·z̄ = |z|² et z' = iz est la rotation de centre O d'angle π/2.
