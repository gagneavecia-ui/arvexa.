📗 Le fil conducteur de tout le chapitre

ln et exp sont réciproques : ln(e^x) = x pour tout réel x, et e^(ln x) = x pour tout x > 0. Résoudre une équation avec ln = éliminer le ln grâce à exp. C'est tout le secret : le reste n'est que conditions d'existence et calculs soignés.

01
Formules vitales

L'essentiel en un coup d'œil

Formule vitale n° 1 — transformer les produits
ln(ab) = ln a + ln b (a > 0, b > 0)
Avec ses filles : ln(1/b) = −ln b ; ln(a/b) = ln a − ln b ; ln(aⁿ) = n ln a. Jamais pour une somme : ln(a + b) ≠ ln a + ln b.
Formule vitale n° 2 — dériver et primitiver
(ln u)' = u'/u (u > 0, dérivable) · primitive de u'/u : ln(u) + C
Cas particulier : (ln x)' = 1/x sur ]0 ; +∞[, donc ln x est une primitive de 1/x.

02
Notion 1 · équations

Équations : ln x = a, ln x = ln b

📗 Les deux équations de référence
  • Pour tout réel a : ln x = a ⇔ x = e^a. La solution est automatiquement positive (car e^a > 0), aucune condition à rejeter.
  • Pour x > 0 et b > 0 : ln x = ln b ⇔ x = b. On « enlève les ln » des deux côtés.
🧠 Méthode — résoudre une équation avec ln en 4 étapes
(1) Écrire les conditions d'existence (tout ce qui est sous un ln doit être > 0). (2) Regrouper tous les ln en un seul de chaque côté (avec ln(ab) et ln(a/b)). (3) Éliminer les ln : ln A = ln B donne A = B, ou ln A = k donne A = e^k. (4) Résoudre, rejeter les solutions hors des conditions, puis vérifier les solutions gardées et conclure avec l'ensemble S.
🧮 Exemple 1 (type Bac) — ln x + ln(x − 1) = ln 6
1

Conditions d'existence. Il faut x > 0 et x − 1 > 0, donc x > 1. Toute solution en dehors de ]1 ; +∞[ sera rejetée.

2

Regrouper. Pour x > 1 : ln x + ln(x − 1) = ln(x(x − 1)), donc l'équation devient ln(x(x − 1)) = ln 6.

3

Éliminer les ln. x(x − 1) = 6, soit x² − x − 6 = 0. Discriminant : Δ = 1 + 24 = 25, d'où √Δ = 5 et x = (1 ± 5)/2 : x = 3 ou x = −2.

4

Filtrer. −2 < 1 : rejeté (il violerait x > 1). Reste x = 3.

5

Vérifier et conclure. ln 3 + ln 2 = ln 6 ✓ (car 3 × 2 = 6). Donc S = {3}.

🧮 Exemple 2 — ln(2x + 1) = 3
1

Condition. 2x + 1 > 0 ⇔ x > −1/2.

2

Passer à l'exponentielle. ln(2x + 1) = 3 ⇔ 2x + 1 = e³ (car e^(ln A) = A et e³ > 0).

3

Isoler x. 2x = e³ − 1, donc x = (e³ − 1)/2. Valeur approchée : (20,09 − 1)/2 ≈ 9,54, qui vérifie bien x > −1/2 ✓.

4

Conclure. S = {(e³ − 1)/2}. Une solution qui garde la forme exacte e³ vaut mieux qu'un arrondi.

🚨 L'erreur éliminatoire : oublier les conditions

Dans l'exemple 1, résoudre x² − x − 6 = 0 et conclure S = {3 ; −2} sans avoir écrit (ni utilisé) la condition x > 1 fait perdre la question entière : ln(−2) et ln(−3) n'existent pas ! Les conditions d'existence d'abord, le calcul ensuite, le filtre enfin.

Notion 2 · inéquations

Inéquations : l'ordre est conservé

ln est strictement croissante : passer au logarithme (ou l'éliminer) ne change pas le sens des inégalités. C'est tout ce qu'il faut savoir.

💡 Les trois inéquations de référence
  • Pour x > 0 et b > 0 : ln x < ln b ⇔ x < b (idem avec ≤, >, ≥).
  • Pour tout réel a : ln x ≥ a ⇔ x ≥ e^a (avec x > 0, automatiquement satisfait dès que x ≥ e^a).
  • Valeurs seuils utiles : ln x > 0 ⇔ x > 1 ; ln x ≤ 0 ⇔ 0 < x ≤ 1.
🧮 Exemple 1 — ln(x − 2) > 0
1

Condition. x − 2 > 0 ⇔ x > 2.

2

Résoudre. ln(x − 2) > 0 ⇔ x − 2 > e⁰ = 1 ⇔ x > 3.

3

Fusionner. x > 3 implique x > 2 : l'ensemble des solutions est S = ]3 ; +∞[.

🧮 Exemple 2 — ln x ≤ ln 5
1

Condition. x > 0 (et 5 > 0 est acquis).

2

Résoudre. Comme ln est croissante : ln x ≤ ln 5 ⇔ x ≤ 5.

3

Fusionner. Il faut à la fois 0 < x et x ≤ 5 : S = ]0 ; 5]. Le 0 est exclu : ln 0 n'existe pas.

🧮 Exemple 3 — ln(x + 1) < 2
1

Condition. x + 1 > 0 ⇔ x > −1.

2

Résoudre. ln(x + 1) < 2 ⇔ x + 1 < e² ⇔ x < e² − 2 (soit environ 5,39).

3

Fusionner. S = ]−1 ; e² − 2[ : les deux bornes sont ouvertes, l'une par la condition, l'autre par l'inégalité stricte.

⚠️ Deux ensembles à joindre, pas un seul

La réponse d'une inéquation logarithmique est presque toujours l'intersection de la condition d'existence et de la solution « sans ln ». Écrire S = ]−∞ ; e² − 2[ pour l'exemple 3 en oubliant x > −1 est l'erreur la plus fréquente du chapitre.

Notion 3 · changement de variable

Changement de variable & croissances comparées

Quand ln x apparaît plusieurs fois, dont une fois au carré, l'équation est un trinôme déguisé. On pose X = ln x, on résout en X, puis on revient à x par x = e^X.

🧮 Exemple travaillé (type Bac) — 2(ln x)² − 3 ln x + 1 = 0
1

Condition. ln x exige x > 0. On pose X = ln x : l'inconnue intermédiaire X est un réel quelconque, et x = e^X sera positif automatiquement.

2

Réécrire l'équation. Elle devient 2X² − 3X + 1 = 0, un trinôme classique.

3

Résoudre en X. Δ = 9 − 8 = 1, donc √Δ = 1 et X = (3 ± 1)/4 : X = 1/2 ou X = 1.

4

Revenir à x. X = 1 donne ln x = 1, soit x = e¹ = e ; X = 1/2 donne ln x = 1/2, soit x = e^(1/2) = √e (environ 1,65).

5

Conclure. Les deux solutions sont positives : S = {√e ; e}, soit environ {1,65 ; 2,72}.

6

Vérifier une solution. Pour x = e : 2(ln e)² − 3 ln e + 1 = 2 − 3 + 1 = 0 ✓. Pour x = √e : 2(1/2)² − 3(1/2) + 1 = 1/2 − 3/2 + 1 = 0 ✓.

⚠️ (ln x)² et ln(x²) : ne jamais mélanger

(ln x)² est le carré du logarithme (c'est lui qui donne le trinôme ci-dessus) ; ln(x²) = 2 ln x est le logarithme du carré. Les deux expressions n'ont ni le même sens ni le même domaine : (ln x)² vit sur ]0 ; +∞[, ln(x²) sur ℝ*.

Seconde arme de la section : les croissances comparées, qui répondent à la question piège « peut-on avoir x < ln x ? ». Réponse : jamais (pour x > 0). En effet ln x ≤ x − 1 (partie 3), donc ln x < x pour tout x > 0. Vérification numérique :

📗 Hiérarchie des croissances (à retenir telle quelle)

À l'infini : exp écrase les puissances, qui écrasent ln. Conséquences chiffrées : (ln x)/x → 0 et x ln x → 0 en 0⁺ ; et pour tout x > 0 : ln x ≤ x − 1 < x. Le logarithme ne « rattrape » jamais x, quelle que soit la taille de x.

Notion 4 · applications & examen

Applications concrètes & réflexes Bac

📈 Le temps de doublement

Une grandeur qui croît de façon exponentielle s'écrit N(t) = N₀ e^(kt) avec k > 0. Le temps de doublement t_d est la durée au bout de laquelle N(t_d) = 2N₀ :

1

Écrire l'équation du doublement. N₀ e^(k t_d) = 2N₀, donc e^(k t_d) = 2.

2

Passer au ln. k t_d = ln 2, donc t_d = ln 2/k.

3

Application numérique. Avec k = 0,07 par an (croissance de 7 % par an) : t_d = 0,693/0,07 ≈ 9,9 ans. On retrouve la « règle des 70 » des économistes : 70/7 = 10 ans environ.

🧪 Le pH et le logarithme décimal

Le logarithme décimal se déduit du népérien par log x = ln x/ln 10 (avec ln 10 ≈ 2,303). En chimie, pH = −log a où a est la concentration d'ions hydrogène : une eau neutre a a = 10⁻⁷, d'où pH = −log 10⁻⁷ = 7. Chaque unité de pH divise la concentration par 10 : c'est une échelle logarithmique.

🔊 Les décibels

L'intensité sonore se mesure aussi en échelle log : L = 10 log(I/I₀) avec I₀ = 10⁻¹² W·m⁻² (seuil d'audition). Pour I = 10⁻⁶ W·m⁻² : I/I₀ = 10⁶, donc L = 10 × 6 = 60 dB (conversation courante). Multiplier l'intensité par 10 ajoute 10 dB seulement — encore la propriété ln(10x) = ln 10 + ln x en action.

💡 Les 5 réflexes Bac
  • Réflexe 1 — Domaine d'abord : écrire toutes les conditions (> 0) avant la moindre manipulation.
  • Réflexe 2 — Un seul ln par côté : regrouper avec ln(ab) = ln a + ln b et ln(a/b) = ln a − ln b.
  • Réflexe 3 — Exp pour éliminer : ln A = ln B ⇔ A = B et ln A = k ⇔ A = e^k.
  • Réflexe 4 — Filtrer les solutions : rejeter toute solution hors du domaine, et l'expliquer en une phrase.
  • Réflexe 5 — Contrôler : réinjecter la solution (e^(ln x) = x) ou vérifier à la calculatrice avec des valeurs approchées.
🚨 Les 6 erreurs interdites (vérifie ta copie)
  • Écrire ln(a + b) = ln a + ln b : faux, le log ne transforme que les produits.
  • Conclure ln x = 0 ⇒ x = 0 : faux, la solution est x = 1 (et ln 0 n'existe pas).
  • Oublier de rejeter une solution hors du domaine (ex. garder x = −2 quand il faut x > 1).
  • Confondre (ln x)² et ln(x²) = 2 ln x.
  • Écrire ln 1 = 1 : faux, ln 1 = 0 (c'est ln e qui vaut 1).
  • Dériver ou primitiver ln(u) sans vérifier u > 0.
🌍 Pour aller plus loin
Le ln 2 ≈ 0,693 qui a servi au temps de doublement est aussi le rapport de fréquences d'une octave en musique : monter d'une octave, c'est multiplier la fréquence par 2, c'est-à-dire ajouter ln 2 au logarithme. Échelles musicales, pH, décibels, séismes (échelle de Richter) : les sciences adorent mesurer en logarithmes, parce que l'œil et l'oreille humaines eux-mêmes perçoivent les rapports, pas les écarts.
