Pour démontrer une propriété P(n) pour tout n : 1) initialisation : vérifier P(0) ou P(1) ; 2) hérédité : supposer P(n) vraie pour un entier n quelconque et démontrer P(n + 1) ; 3) conclusion : la propriété est vraie pour tout n. Récurrence et limites

✏️ Exercice 1 — Récurrence : une formule de somme (★★)
Rappel des données

On démontre : 1 + 2 + 3 + … + n = n(n + 1)/2 pour tout n ≥ 1.

1

Vérifications. Pour n = 1 : membre de gauche 1, membre de droite 1×2/2 = 1 ✓. Pour n = 5 : 1+2+3+4+5 = 15 et 5×6/2 = 15 ✓.

2

Initialisation. Pour n = 1, on vient de vérifier 1 = 1×2/2 : la formule est vraie au rang 1.

3

Hérédité. Supposons la formule vraie pour un entier n ≥ 1 : 1 + 2 + … + n = n(n + 1)/2. Alors 1 + 2 + … + n + (n + 1) = n(n + 1)/2 + (n + 1) = (n + 1)×[n/2 + 1] = (n + 1)×(n + 2)/2. C'est exactement la formule au rang n + 1 : elle est héréditaire.

4

Conclusion. La formule est vraie au rang 1 et héréditaire : elle est donc vraie pour tout n ≥ 1.

5

Application. 1 + 2 + … + 100 = 100×101/2 = 50×101 = 5 050.

1 + 2 + … + n = n(n + 1)/2  ·  1 + 2 + … + 100 = 5 050

Résultats de l'exercice 1.

Piège. Dans l'hérédité, ne remplace pas n par n + 1 partout : on garde l'hypothèse au rang n et on en déduit le rang n + 1.
✏️ Exercice 2 — Récurrence : divisibilité (★★★)
Rappel des données

aₙ = 8ⁿ − 3ⁿ pour tout n ∈ ℕ ; on démontre que 5 divise aₙ pour tout n.

1

Vérifications. n = 0 : 8⁰ − 3⁰ = 1 − 1 = 0 = 5×0 ✓. n = 2 : 64 − 9 = 55 = 5×11 ✓.

2

Initialisation. Pour n = 0, 5 divise 0 : la propriété est vraie au rang 0.

3

Hérédité. Supposons que 5 divise 8ⁿ − 3ⁿ pour un entier n. Alors : 8ⁿ⁺¹ − 3ⁿ⁺¹ = 8×8ⁿ − 3×3ⁿ = 8×8ⁿ − 8×3ⁿ + 8×3ⁿ − 3×3ⁿ = 8×(8ⁿ − 3ⁿ) + 5×3ⁿ. Le premier terme est un multiple de 5 (hypothèse de récurrence), le second aussi (5×3ⁿ) : la somme est un multiple de 5. La propriété est héréditaire.

4

Conclusion. Vraie au rang 0 et héréditaire : 5 divise 8ⁿ − 3ⁿ pour tout n ∈ ℕ.

5

Déduction pour 10. 8ⁿ⁺¹ + 2×3ⁿ = 8×(8ⁿ − 3ⁿ) + 10×3ⁿ : le premier terme est divisible par 5 (question précédente), le second par 10. De plus 8×(8ⁿ − 3ⁿ) est pair (produit par 8) et 10×3ⁿ est pair : la somme est paire et multiple de 5, donc divisible par 10. Vérification : n = 2 : 8³ + 2×9 = 512 + 18 = 530 = 10×53 ✓.

8ⁿ⁺¹ − 3ⁿ⁺¹ = 8×(8ⁿ − 3ⁿ) + 5×3ⁿ  ·  5 divise 8ⁿ − 3ⁿ pour tout n

Résultat clé de l'exercice 2.

Piège. L'astuce « ajouter et retrancher 8×3ⁿ » est le cœur de l'hérédité : sans elle, impossible de faire apparaître l'hypothèse de récurrence 8ⁿ − 3ⁿ.
✏️ Exercice 3 — Limites et théorème des gendarmes (★★)
Rappel des données

a) uₙ = 0,9ⁿ ; b) uₙ = (3n + 2)/(n + 1) ; c) vₙ = (−1)ⁿ/n² avec −1/n² ≤ vₙ ≤ 1/n² ; d) wₙ = 3 + 6×0,5ⁿ.

1

a) −1 < 0,9 < 1 : une suite géométrique de raison comprise entre −1 et 1 converge vers 0. Donc lim uₙ = 0.

2

b) uₙ = (3 + 2/n)/(1 + 1/n) ; or 2/n et 1/n tendent vers 0, donc le numérateur tend vers 3 et le dénominateur vers 1 : lim uₙ = 3/1 = 3.

3

c) Pour tout n ≥ 1 : −1/n² ≤ vₙ ≤ 1/n². Les deux suites encadrantes convergent vers 0 (car 1/n² → 0). Par le théorème des gendarmes, lim vₙ = 0 : la suite converge, même si elle change de signe à chaque rang.

4

d) 0,5ⁿ tend vers 0 car |0,5| < 1, donc lim wₙ = 3 + 6×0 = 3. Sur la figure, les points se rapprochent de la droite horizontale pointillée : c'est la droite y = 3, asymptote à la courbe représentative de la suite.

lim 0,9ⁿ = 0  ·  lim (3n + 2)/(n + 1) = 3  ·  lim vₙ = 0  ·  lim wₙ = 3

Résultats de l'exercice 3.

Piège. (−1)ⁿ n'a pas de limite, mais la division par n² écrase tout : c'est exactement le rôle du théorème des gendarmes de conclure sans calculer (−1)ⁿ.

Suites arithmético-géométriques, type Bac

✏️ Exercice 4 — À la découverte des suites arithmético-géométriques (★★)
Rappel des données

u₀ = 4 et uₙ₊₁ = 3uₙ − 4 pour tout n ∈ ℕ ; suite auxiliaire vₙ = uₙ − 2.

1

Premiers termes. u₁ = 3×4 − 4 = 8 ; u₂ = 3×8 − 4 = 20 ; u₃ = 3×20 − 4 = 56.

2

Ni l'une ni l'autre. Écarts : u₁ − u₀ = 4, u₂ − u₁ = 12, u₃ − u₂ = 36 → non constants, pas arithmétique. Rapports : 8/4 = 2, 20/8 = 2,5, 56/20 = 2,8 → non constants, pas géométrique.

3

La suite auxiliaire. Pour tout n : vₙ₊₁ = uₙ₊₁ − 2 = 3uₙ − 4 − 2 = 3uₙ − 6 = 3×(uₙ − 2) = 3vₙ. Donc (vₙ) est géométrique de raison q = 3, avec v₀ = u₀ − 2 = 2.

4

Termes généraux. vₙ = v₀×3ⁿ = 2×3ⁿ, puis uₙ = vₙ + 2 = 2×3ⁿ + 2.

5

Valeur de u₆. u₆ = 2×3⁶ + 2 = 2×729 + 2 = 1 458 + 2 = 1 460. Contrôle par la récurrence : u₄ = 3×56 − 4 = 164, u₅ = 3×164 − 4 = 488, u₆ = 3×488 − 4 = 1 460 ✓.

vₙ = 2×3ⁿ  ·  uₙ = 2×3ⁿ + 2  ·  u₆ = 1 460

Résultats de l'exercice 4.

Méthode. Le 2 de la suite auxiliaire est la solution de x = 3x − 4 (point fixe). Pour uₙ₊₁ = a·uₙ + b, on pose vₙ = uₙ − x où x = b/(1 − a).
✏️ Exercice 5 — Type Bac : le stock d'engrais de la coopérative (★★★)
Rappel des données

u₀ = 1 000 sacs et uₙ₊₁ = 0,8uₙ + 400 ; suite auxiliaire vₙ = 2 000 − uₙ.

1

Premiers termes. u₁ = 0,8×1 000 + 400 = 1 200 ; u₂ = 0,8×1 200 + 400 = 1 360 ; u₃ = 0,8×1 360 + 400 = 1 488 (sacs).

2

Récurrence : uₙ ≤ 2 000. Initialisation : u₀ = 1 000 ≤ 2 000 ✓. Hérédité : supposons uₙ ≤ 2 000 pour un entier n ; alors 0,8uₙ ≤ 1 600, donc 0,8uₙ + 400 ≤ 2 000, c'est-à-dire uₙ₊₁ ≤ 2 000 ✓. Conclusion : pour tout n ∈ ℕ, uₙ ≤ 2 000.

3

La suite auxiliaire. vₙ₊₁ = 2 000 − uₙ₊₁ = 2 000 − 0,8uₙ − 400 = 1 600 − 0,8uₙ = 0,8×(2 000 − uₙ) = 0,8vₙ : (vₙ) est géométrique de raison q = 0,8, avec v₀ = 2 000 − 1 000 = 1 000. Donc vₙ = 1 000×0,8ⁿ.

4

Terme général de uₙ. vₙ = 2 000 − uₙ donne uₙ = 2 000 − vₙ = 2 000 − 1 000×0,8ⁿ. Contrôle : u₃ = 2 000 − 1 000×0,512 = 1 488 ✓.

5

Limite et interprétation. |0,8| < 1 donc 0,8ⁿ → 0, et lim uₙ = 2 000 − 0 = 2 000. Le stock tend vers 2 000 sacs : à long terme il se stabilise autour de cette valeur ; la droite y = 2 000 est asymptote horizontale à la courbe représentative.

6

Sens de variation. uₙ₊₁ − uₙ = 0,8uₙ + 400 − uₙ = 400 − 0,2uₙ = 0,2×(2 000 − uₙ) = 0,2vₙ. Or vₙ = 1 000×0,8ⁿ > 0 pour tout n, donc uₙ₊₁ − uₙ > 0 : la suite (uₙ) est strictement croissante, en cohérence avec u₀ = 1 000 qui monte vers 2 000.

vₙ = 1 000×0,8ⁿ  ·  uₙ = 2 000 − 1 000×0,8ⁿ  ·  lim uₙ = 2 000

Résultats de l'exercice 5 : le stock se stabilise à 2 000 sacs.

Piège. Ici la suite auxiliaire est 2 000 − uₙ (et non uₙ − 2 000) : c'est le choix qui rend v₀ = 1 000 > 0 et les calculs de signe limpides. Les deux conviennent si la raison est cohérente.
✏️ Exercice 6 — Synthèse : sommes et limite (★★★)
Rappel des données

uₙ = 2×3ⁿ + 2 pour tout n ∈ ℕ ; 3⁸ = 6 561.

1

Premier et dernier termes. u₀ = 2×3⁰ + 2 = 2 + 2 = 4 ; u₇ = 2×3⁷ + 2 = 2×2 187 + 2 = 4 374 + 2 = 4 376.

2

Sens de variation. uₙ₊₁ − uₙ = (2×3ⁿ⁺¹ + 2) − (2×3ⁿ + 2) = 2×3ⁿ⁺¹ − 2×3ⁿ = 2×3ⁿ×(3 − 1) = 4×3ⁿ. Comme 4×3ⁿ > 0 pour tout n, la suite est strictement croissante.

3

Somme des 8 premiers termes. On sépare les deux morceaux : S = 2×(1 + 3 + 9 + … + 3⁷) + 2×8. La somme géométrique vaut (3⁸ − 1)/(3 − 1) = 6 560/2 = 3 280. Donc S = 2×3 280 + 16 = 6 560 + 16 = 6 576. Contrôle en additionnant les termes : 4 + 8 + 20 + 56 + 164 + 488 + 1 460 + 4 376 = 6 576 ✓.

4

Convergence. 3 > 1 donc 3ⁿ → +∞, et uₙ = 2×3ⁿ + 2 → +∞ : la suite (uₙ) diverge, elle n'a pas de limite finie.

S = u₀ + u₁ + … + u₇ = 6 576  ·  lim uₙ = +∞

Résultats de l'exercice 6.

Piège. La somme 1 + 3 + … + 3⁷ compte 8 termes, d'où la formule (3⁸ − 1)/(3 − 1) avec l'exposant 8 — et non 7 — au numérateur.
