📘 Partie 02 · Expression des gènes

Code génétique et Traduction

L'ARNm est écrit dans une langue à 4 lettres ; les protéines sont écrites dans une langue à 20 mots. Pour passer de l'une à l'autre, la cellule possède un dictionnaire — le code génétique — et une usine — le ribosome. Cette partie déroule 4 notions : le codon, le code génétique et ses propriétés, l'ARN de transfert et son anticodon, et la traduction pas à pas.

Motivation

Faire dialoguer deux langues

Imagine un message écrit en hébreu et un lecteur qui ne comprend que le haoussa. Pour que le message passe, il faut un dictionnaire et un interprète. Dans la cellule, c'est exactement la situation : l'ARNm, sorti du noyau à la fin de la partie 1, est écrit dans l'alphabet à 4 lettres A — U — G — C. Or ce que le cytoplasme doit fabriquer, c'est une protéine, c'est-à-dire une suite d'acides aminés — et il n'existe que 20 acides aminés différents.

Comment une suite de lettres A, U, G, C devient-elle une suite de méthionine, d'alanine, de tryptophane ? C'est le problème du code génétique (les mots de la langue ADN) et de la traduction (la fabrication de la protéine). Deux questions vont nous guider :

  • Comment regrouper les 4 lettres de l'ARNm pour former des « mots » assez nombreux pour désigner 20 acides aminés ?
  • Quelle machine lit ces mots et quel outil assemble les acides aminés dans le bon ordre ?
La grande idée de la partie

Les mots de l'ARNm sont des triplets de nucléotides appelés codons. Chaque codon désigne un acide aminé précis — ou un signal d'arrêt. Des transporteurs, les ARNt, apportent au ribosome les acides aminés correspondants, et la chaîne protéique s'édifie : c'est la traduction.

01
Notion 1 · codon

Le codon : mot de trois lettres

Commençons par un petit calcul, très apprécié des examinateurs. Avec des mots d'une lettre, on ne forme que 4 mots (A, U, G, C) — insuffisant pour 20 acides aminés. Avec des mots de deux lettres : 4² = 16 combinaisons — encore insuffisant. Avec des mots de trois lettres : 4³ = 64 combinaisons — largement suffisant. La nature a choisi cette dernière solution :

Définition officielle — codon

Un codon est un triplet de nucléotides de l'ARN messager qui désigne un acide aminé précis (ou un signal de début ou de fin de lecture). Comme il y a 4 sortes de nucléotides, on obtient 4³ = 64 codons possibles.

1 codon = 3 nucléotides de l'ARNm · nombre de codons possibles : 4³ = 64
Exemple : dans l'ARNm AUG GCU UGG, on lit trois codons — AUG, puis GCU, puis UGG. La lecture se fait depuis le codon de départ, par groupes de trois, sans chevauchement.
⚠️ Piège — le décalage d'une lettre

Si l'on commence la lecture au mauvais endroit, tous les triplets changent ! Dans AUG GCU UGG UGA, une lecture décalée d'une lettre donnerait UGG, CUU, GGU… n'importe quoi. La lecture démarre toujours au même codon et avance de trois en trois. C'est ce qu'on appelle le cadre de lecture.

Vérifie toi-même sur l'ARNm de la partie 1 : AUG GCU UGG UGA se découpe en quatre codons bien alignés, comme des wagons d'un même train. Chacun de ces wagons va recevoir sa traduction dans la section suivante.

02
Notion 2 · code_genetique

64 codons, 20 acides aminés

Le dictionnaire qui relie les 64 codons aux 20 acides aminés s'appelle le code génétique. Il est entièrement déterminé : face à un codon donné, il n'y a qu'une seule réponse possible.

Définition officielle — code génétique

Le code génétique est le système de correspondance entre les codons de l'ARNm et les acides aminés qu'ils désignent. Il comprend 4³ = 64 codons : 61 codons codent les 20 acides aminés, 1 codon start (AUG = méthionine) initie la traduction, et 3 codons stop (UAA, UAG, UGA) y mettent fin.

Trois familles de codons à ne jamais mélanger :

FamilleCodonsRôle
Codon startAUGinitie la lecture de l'ARNm ; code aussi la méthionine (premier acide aminé du polypeptide)
Codons stopUAA · UAG · UGAterminent la traduction ; ne codent aucun acide aminé
Codons des acides aminésles 60 autres (plus AUG)chacun désigne un acide aminé précis, parmi les 20
Erreur fréquente — les codons stop

Écrire « le codon stop ajoute le dernier acide aminé » est une erreur condamnée au Bac : les codons stop ne codent aucun acide aminé. Aucun ARNt ne les reconnaît — ils font simplement sortir le polypeptide terminé de la machine (section 5). Et ne confonds pas : UGA est un stop, mais UGG code le tryptophane — deux triplets très proches, deux sorts très différents !

Exemple — la correspondance en action

Le codon GCU désigne l'alanine ; le codon UGG désigne le tryptophane. Le même codon désigne toujours le même acide aminé, aujourd'hui comme demain, chez le zébu comme chez le niébé : le code génétique est une table fixe, inscrite dans tout le vivant (section 3).

03
Notion 2 · code_genetique

Les trois propriétés du code

Le code génétique possède trois propriétés que les épreuves adorent demander. Tu dois savoir les nommer, les définir et donner un exemple de chacune :

1
Le code est dégénéré (ou redondant)

plusieurs codons différents peuvent désigner le même acide aminé : les codons GCU, GCC, GCA et GCG codent tous les quatre l'alanine ; la leucine est même codée par 6 codons. C'est la redondance qui explique le compte : 61 codons « utiles » pour seulement 20 acides aminés.

2
Le code est non ambigu

un codon donné désigne un seul acide aminé, toujours le même : GCU vaut alanine, point. La flèche « codon → acide aminé » n'a qu'une seule réponse ; c'est « acide aminé → codon » qui peut en avoir plusieurs.

3
Le code est universel

le même codon désigne le même acide aminé chez tous les êtres vivants : bactérie, mil, zébu, homme. Un gène humain lu par une bactérie produit la protéine humaine attendue.

⚠️ Piège — dégénéré ≠ ambigu

Beaucoup d'élèves inversent les deux mots. Retiens le sens des flèches : plusieurs codons → un seul AA = code dégénéré ; un codon → un seul AA, jamais deux = code non ambigu. Si tu écris « le code est ambigu », tu affirmes qu'un codon donne deux acides aminés différents — c'est faux et lourdement sanctionné.

Application — l'insuline d'origine bactérienne

L'universalité du code a changé la médecine : le gène humain de l'insuline a été introduit dans des bactéries, qui le transcrivent puis le traduisent en véritable insuline humaine — car bactéries et humains lisent le code de la même façon. Des millions de personnes diabétiques, au Niger comme ailleurs, s'injectent ainsi une insuline produite par des bactéries. Même argument pour l'hormone de croissance et plusieurs vaccins.

Notion 3 · arn_transfert

L'ARNt, traducteur à double face

Reste à résoudre une énigme pratique : les codons parlent la langue des nucléotides, les acides aminés ne la parlent pas. Qui fait le lien ? Une famille d'ARN un peu spéciale, les ARN de transfert (ARNt), véritables interprètes bilingues : ils savent à la fois lire un codon et porter un acide aminé.

Définition officielle — ARN de transfert

Un ARN de transfert (ARNt) est une petite molécule d'ARN, repliée en forme de trèfle, qui porte à l'une de ses extrémités un acide aminé bien précis et qui possède, à l'autre extrémité, un anticodon : triplet complémentaire du codon de l'ARNm correspondant. Chaque ARNt joue le rôle d'un adaptateur entre codon et acide aminé.

Anticodon : triplet de nucléotides porté par l'ARNt, complémentaire du codon de l'ARNm (A↔U, G↔C).
ARNt : ARN de transfert ; porte un acide aminé d'un côté, un anticodon de l'autre — un ARNt par famille de codons.
Liaison peptidique : liaison qui unit deux acides aminés voisins le long de la chaîne ; elle se forme sur le ribosome pendant l'élongation.

Voici comment fonctionne l'appariement codon–anticodon. Face au codon GCU de l'ARNm, l'ARNt porte l'anticodon CGA (complémentaire : G↔C, C↔G, U↔A) et l'acide aminé alanine qu'il transporte vient s'ajouter à la chaîne. L'anticodon « sonde » le codon, l'acide aminé est livré, et le traducteur repart chercher une nouvelle cargaison.

Erreur fréquente — codon et anticodon confondus

Le codon est sur l'ARNm ; l'anticodon est sur l'ARNt — et il est complémentaire du codon, jamais identique ! Face à AUG, l'anticodon est UAC (et non AUG). Ce mélange des rôles est l'erreur la plus fréquente des copies de Terminale D : écris systématiquement à côté de qui est quoi.

05
Notion 4 · traduction

Le mécanisme : initiation, élongation, terminaison

Tout est en place : le message (ARNm), le dictionnaire (code génétique), les interprètes (ARNt) et l'usine (ribosome, organe du cytoplasme fait de deux sous-unités qui enserrent l'ARNm). La traduction peut commencer :

Définition officielle — traduction

La traduction est la synthèse, dans le cytoplasme, d'un polypeptide par lecture de l'ARNm codon par codon, sur le ribosome, grâce aux ARNt qui apportent les acides aminés correspondants. Elle s'achève à la rencontre d'un codon stop, où le polypeptide est libéré.

1
Initiation — la machine se met en place

le ribosome se fixe sur l'ARNm au niveau du codon start AUG. Le premier ARNt, porteur de méthionine, s'installe : son anticodon UAC s'apparie au codon de départ.

2
Élongation — la chaîne s'allonge codon par codon

le ribosome avance de codon en codon ; à chaque étape, un nouvel ARNt s'apparie par son anticodon et dépose son acide aminé, qu'une liaison peptidique soude au précédent. Les ARNt « vides » repartent dans le cytoplasme se recharger. Le polypeptide, suspendu au ribosome, s'allonge dans l'ordre exact des codons.

3
Terminaison — le polypeptide est libéré

le ribosome atteint un codon stop (UAA, UAG ou UGA) : aucun ARNt ne peut s'y apparier, la lecture s'arrête, le polypeptide est libéré, et l'ARNm et le ribosome se séparent. L'ARNm peut encore servir à plusieurs traductions.

⚠️ Piège — l'ordre vient de l'ARNm

L'ordre des acides aminés du polypeptide est imposé par l'ordre des codons de l'ARNm, donc par l'ordre des nucléotides du gène : c'est la colinéarité. Les ARNt ne décident de rien : ils obéissent à la complémentarité codon–anticodon. Le ribosome, lui, ne choisit pas la séquence — il ne fait que mettre les partenaires en contact.

Fiche méthode

Lire un code génétique fourni

Au Bac, le code génétique complet n'est pas à apprendre par cœur : un extrait (mini-tableau) est fourni dans l'énoncé. Ton travail consiste à le lire sans erreur. Entraînons-nous sur l'ARNm obtenu en partie 1 :

🎓 Exemple complet résolu — de l'ARNm au polypeptide

Données : ARNm AUG GCU UGG UGA (5′ → 3′). Extrait du code génétique fourni : AUG = méthionine (codon start) · GCU = alanine · UGG = tryptophane · UGA = codon stop.

Étape 1 — Découper en codons : AUG / GCU / UGG / UGA — quatre triplets alignés depuis le codon start.

Étape 2 — Traduire chaque codon grâce au tableau : AUG → méthionine · GCU → alanine · UGG → tryptophane · UGA → stop (aucun acide aminé).

Étape 3 — Rédiger la réponse : la traduction démarre au codon start AUG et s'arrête au codon stop UGA ; le polypeptide synthétisé est méthionine — alanine — tryptophane.

Bonus — les anticodons : les ARNt correspondants portaient les anticodons UAC, CGA et ACC — complémentaires, lettre par lettre, des codons AUG, GCU et UGG.

1
Repérer le codon start

la lecture commence à AUG — jamais avant, jamais une lettre plus loin.

2
Traduire codon par codon

en lisant le tableau fourni uniquement : ne tente jamais un codon de mémoire, la table fournie fait foi.

3
S'arrêter au codon stop

le stop ne fait pas partie du polypeptide : on ne l'écrit pas dans la liste des acides aminés, on l'annonce comme signal de fin.

4
Relier par des tirets et nommer

« méthionine — alanine — tryptophane » : c'est le polypeptide, futur protéine une fois repliée (partie 3).

⚠️ Vérification éclair

Avant de rendre : mes codons font-ils tous 3 lettres ? Ai-je écrit des U (et pas des T) ? Mon polypeptide commence-t-il par la méthionine et s'arrête-t-il au stop ? Mes anticodons sont-ils complémentaires (et non identiques) des codons ?

Q1 — Un codon est un triplet de nucléotides porté par :

A) l'ADN B) l'ARN messager C) l'ARN de transfert D) le ribosome
Voir la réponse
B) l'ARN messager. Le codon est sur l'ARNm. Le triplet porté par l'ARNt s'appelle l'anticodon — la confusion codon/anticodon est l'erreur n°1 du chapitre.

Q2 — Le codon AUG joue le rôle de :

A) codon stop, il ne code rien B) codon start ; il code la méthionine C) codon start ; il code le tryptophane D) anticodon du premier ARNt
Voir la réponse
B) codon start ; il code la méthionine. AUG initie la lecture et désigne en même temps la méthionine, premier acide aminé de tout polypeptide. (Tryptophane = UGG ; les stops sont UAA, UAG, UGA.)

Q3 — Un ARNt porte l'anticodon ACC. Face à quel codon s'apparie-t-il, et quel acide aminé transporte-t-il si le tableau donne UGG = tryptophane ?

A) codon ACC — tryptophane B) codon UGG — tryptophane C) codon UGG — alanine D) codon TGG — tryptophane
Voir la réponse
B) codon UGG — tryptophane. L'anticodon est complémentaire du codon : A↔U, C↔G, C↔G, donc ACC s'apparie à UGG. Et l'ARNt transporte toujours l'acide aminé codé par ce codon. (D est piégé : pas de T dans l'ARN !)
📌 Ce qu'il faut retenir
  • [codon] Un codon = 3 nucléotides de l'ARNm ; 4 bases → 4³ = 64 codons possibles, lus par triplets depuis le codon start, sans chevauchement
  • [code_genetique] Le code génétique est la correspondance codon → acide aminé : 61 codons codent les 20 acides aminés, AUG (méthionine) est le codon start, UAA/UAG/UGA sont les 3 codons stop (aucun acide aminé)
  • [code_genetique] Trois propriétés : dégénéré (plusieurs codons → même AA), non ambigu (un codon → un seul AA), universel (même code chez tous les êtres vivants)
  • [arn_transfert] L'ARNt porte d'un côté un acide aminé précis, de l'autre un anticodon complémentaire du codon : c'est l'adaptateur entre les deux langues
  • [arn_transfert] Anticodon = sur l'ARNt, complémentaire du codon (AUG → anticodon UAC) — ne pas confondre les deux triplets
  • [traduction] La traduction est la synthèse d'un polypeptide dans le cytoplasme, sur le ribosome, par lecture codon par codon de l'ARNm grâce aux ARNt
  • [traduction] Trois étapes : initiation (AUG, ARNt-méthionine), élongation (appariement codon-anticodon, liaison peptidique), terminaison (codon stop, polypeptide libéré)
  • [traduction] L'ordre des acides aminés reflète l'ordre des codons de l'ARNm, donc des nucléotides du gène : c'est la colinéarité
