Primitives : remonter de la dérivée à la fonction

Dans toute cette série, les fonctions sont définies sur des intervalles de ℝ. Rappel : F est une primitive de f sur un intervalle I lorsque F'(x) = f(x) pour tout x de I. Le tableau regroupe les primitives usuelles du cours.

Réflexe — Avant de chercher une primitive, observez f : une somme se primitive terme à terme (linéarité) ; un produit comme x·e^(x²) cache souvent une forme u'·f(u).
✏️ Exercice 1 — Primitives terme à terme (★)

Pour chaque fonction f, donner une primitive F (avec sa constante c), puis vérifier en dérivant que F'(x) = f(x) :

  1. f(x) = 3x² sur ℝ ;
  2. f(x) = 5 sur ℝ ;
  3. f(x) = 4x³ − 2x + 1 sur ℝ ;
  4. f(x) = 6/x sur ]0 ; +∞[.
✏️ Exercice 2 — Exponentielles, quotients et racines (★)

Même consigne : une primitive, puis contrôle systématique par dérivation.

  1. f(x) = e^x − 2x sur ℝ ;
  2. f(x) = 2·e^x − 3x² sur ℝ ;
  3. f(x) = 1/x² sur ]0 ; +∞[ ;
  4. f(x) = 1/√x sur ]0 ; +∞[.
✏️ Exercice 3 — Reconnaître u'·f(u) (★★)

Les fonctions suivantes ne figurent pas au tableau, mais chacune s'écrit (au facteur multiplicatif près) sous la forme u'·f(u). Pour chacune : poser u, calculer u', corriger le facteur manquant, puis donner une primitive.

  1. f(x) = x·(x² + 1)³ ;
  2. f(x) = (2x)/(x² + 1) ;
  3. f(x) = x·e^(x²).

Thème 01 · Applications de cours

Premières intégrales : bornes, aire et valeur moyenne

∫ₐᵇ f(x) dx = F(b) − F(a)
f continue sur [a ; b], F une primitive de f. Si f ≥ 0, l'intégrale mesure l'aire sous la courbe, en unités d'aire (u.a.). Valeur moyenne de f sur [a ; b] : m = (1/(b − a))·∫ₐᵇ f(x) dx.
✏️ Exercice 4 — Intégrales immédiates (★)

Calculer à l'aide d'une primitive (valeur exacte, sauf indication) :

  1. ∫₁³ 2x dx ;
  2. ∫₀² 3x² dx ;
  3. ∫₁ᵉ (1/x) dx ;
  4. ∫₀¹ e^x dx (arrondi à 10⁻²).
✏️ Exercice 5 — Linéarité de l'intégrale (★★)

Rappel : ∫ₐᵇ (u + v) = ∫ₐᵇ u + ∫ₐᵇ v et ∫ₐᵇ k·u = k·∫ₐᵇ u. Calculer :

  1. ∫₀¹ (x³ + 2x) dx ;
  2. ∫₁² (4x³ − 6x² + 2) dx ;
  3. ∫₁² (2/x) dx (valeur exacte avec ln, puis arrondi à 10⁻²).
✏️ Exercice 6 — L'aire hachurée (★★)

La figure représente la courbe C de f(x) = x² sur [0 ; 2] ; le domaine situé sous la courbe est hachuré.

  1. Vérifier que f ≥ 0 sur [0 ; 2] (donc que l'intégrale est bien une aire).
  2. Donner une primitive F de f, puis calculer ∫₀² x² dx (valeur exacte fractionnaire).
  3. En déduire l'aire du domaine hachuré, en unités d'aire.
  4. Calculer la valeur moyenne de f sur [0 ; 2] (arrondie à 10⁻²).
