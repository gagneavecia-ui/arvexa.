Titrage acide-base et solutions tampon

✏️ Exercice 1 — Équation de titrage et équivalence (★)

Données : V(acide) = 20,0 mL ; C(base) = 1,0 × 10⁻² mol·L⁻¹ ; Vₑ = 10,0 mL.

1

Équation de titrage : CH₃—COOH + OH⁻ → CH₃—COO⁻ + H₂O. Bilan vérifié : 2 C ; 4 + 1 = 3 + 2 H ; 2 + 1 = 2 + 1 O ; charges : −1 des deux côtés.

2

Définition : à l'équivalence, les réactifs ont été mélangés dans les proportions stœchiométriques de l'équation, soit ici n(acide) = n(base) : aucun n'est en excès. Le saut de pH (ou le virage de l'indicateur) le signale.

3

On en déduit : C(acide) × V(acide) = C(base) × Vₑ, soit C(acide) = C(base) × Vₑ / V(acide) (les volumes en mL se simplifient).

4

Application numérique : C(acide) = (1,0 × 10⁻² × 10,0) / 20,0 = 5,0 × 10⁻³ mol·L⁻¹.

5

Quantité initiale : n(acide) = C(acide) × V(acide) = 5,0 × 10⁻³ × 20,0 × 10⁻³ = 1,0 × 10⁻⁴ mol.

6

Vérification (deuxième calcul) : n(acide) = n(base versée) = C(base) × Vₑ = 1,0 × 10⁻² × 10,0 × 10⁻³ = 1,0 × 10⁻⁴ mol ✓ (même valeur).

C(acide) = 5,0 × 10⁻³ mol·L⁻¹ · n(acide) = 1,0 × 10⁻⁴ mol

À l'équivalence : n(acide) = n(base), soit C(acide) × V(acide) = C(base) × Vₑ.

⚠️ Piège : Vₑ = 10,0 mL est le volume de SOUDE versé, à ne pas confondre avec V(acide) = 20,0 mL ; et tout volume en mL doit être converti en L (× 10⁻³) dès qu'il rencontre une concentration en mol·L⁻¹.
✏️ Exercice 2 — Le pH à la demi-équivalence (★)

Données : Vₑ = 10,0 mL ; à la demi-équivalence, pH = 4,8.

1

Volume à la demi-équivalence : V = Vₑ/2 = 10,0/2 = 5,0 mL de soude versée.

2

À ce moment, la moitié de l'acide a réagi : n(CH₃—COO⁻) formée = n(CH₃—COOH) restante, donc [CH₃—COO⁻]/[CH₃—COOH] = 1.

3

Henderson : pH = pKa + log ([CH₃—COO⁻]/[CH₃—COOH]) = pKa + log (1) = pKa + 0 → à la demi-équivalence, pH = pKa.

4

Conclusion : pKa = 4,8 ; la demi-équivalence est la méthode expérimentale de mesure d'un pKa.

5

Constante d'acidité : Ka = 1,6 × 10⁻⁵ mol·L⁻¹. Vérification (deuxième calcul) : à la demi-équivalence [CH₃—COO⁻] = [CH₃—COOH] donc Ka = [H₃O⁺], et pH = −log [H₃O⁺] donne [H₃O⁺] = 1,6 × 10⁻⁵ mol·L⁻¹ ✓.

pH = pKa = 4,8 · Ka = 1,6 × 10⁻⁵ mol·L⁻¹

À la demi-équivalence, pH = pKa : c'est LA relation à retenir.

⚠️ Piège : la demi-équivalence correspond à Vₑ/2 = 5,0 mL versés ; ce n'est pas le pH d'équivalence (8,5) et ce n'est pas pH = 7.
✏️ Exercice 3 — Préparer un tampon de pH = 4,8 (★★)

Données : V₁ = V₂ = 50,0 mL ; C₁ = C₂ = 0,10 mol·L⁻¹ ; pKa = 4,8.

1

Quantités introduites : n(CH₃—COOH) = 0,10 × 50,0 × 10⁻³ = 5,0 × 10⁻³ mol et de même n(CH₃—COO⁻) = 5,0 × 10⁻³ mol.

2

Dans le mélange (V = 100,0 mL) : [CH₃—COOH] = [CH₃—COO⁻] = 0,050 mol·L⁻¹ → rapport = 1.

3

Henderson : pH = 4,8 + log (1) = 4,8 + 0 = 4,8.

4

Vérification (deuxième calcul) : le rapport vaut n(base)/n(acide) = 5,0/5,0 = 1 → pH = pKa + 0 = 4,8 ✓ ; la solution est exactement au centre de la zone tampon [3,8 ; 5,8] → pouvoir tampon maximal.

pH = 4,8 = pKa

Mélange équimolaire d'un acide et de sa base conjuguée = tampon optimal.

⚠️ Piège : la dilution divise les deux concentrations par 2 mais ne change pas leur rapport — le pH d'un tampon ne dépend pas de sa dilution.
✏️ Exercice 4 — Henderson à l'envers (★★)

Données : couple NH₄⁺/NH₃ ; pKa = 9,2 ; [NH₃]/[NH₄⁺] = 0,25.

1

Pour ce couple : l'acide est NH₄⁺ (donc AH) et la base conjuguée est NH₃ (donc A⁻) → pH = 9,2 + log ([NH₃]/[NH₄⁺]).

2

Calcul : log (0,25) = log (1/4) = −0,60 → pH = 9,2 − 0,60 = 8,6.

3

Pour pH = 9,8 : log ([NH₃]/[NH₄⁺]) = 9,8 − 9,2 = 0,6 → le rapport cherché est le nombre dont le logarithme vaut 0,6, soit [NH₃]/[NH₄⁺] = 4,0.

4

Vérification (deuxième calcul) : pH = 9,2 + log (4,0) = 9,2 + 0,60 = 9,8 ✓.

pH = 8,6 · pour pH = 9,8 : [NH₃]/[NH₄⁺] = 4,0

Henderson se lit dans les deux sens : du rapport vers le pH, ou du pH vers le rapport.

⚠️ Piège : Henderson s'écrit toujours pH = pKa + log ([base conjuguée]/[acide]) ; si l'on inversait le rapport ici, on trouverait 9,8 au lieu de 8,6.
✏️ Exercice 5 — La zone tampon pKa ± 1 (★★)

Données : pKa = 4,8 ; r = [CH₃—COO⁻]/[CH₃—COOH] variable.

1

Pour r = 10 : pH = 4,8 + log (10) = 4,8 + 1,0 = 5,8.

2

Pour r = 0,10 : pH = 4,8 + log (0,10) = 4,8 − 1,0 = 3,8.

3

Le tampon est efficace tant que 0,10 ≤ r ≤ 10, c'est-à-dire 3,8 ≤ pH ≤ 5,8 : la zone tampon vaut pKa ± 1.

4

Pouvoir tampon maximal pour r = 1 (pH = pKa = 4,8) : autant d'acide que de base conjuguée, donc un ajout modéré d'ions H₃O⁺ ou d'ions OH⁻ est absorbé dans les deux sens sans changement notable de pH.

5

Vérification (deuxième calcul) : pour r = 1, pH = 4,8 + log (1) = 4,8 ✓ (centre de la zone [3,8 ; 5,8]).

Zone tampon : [3,8 ; 5,8] = [pKa − 1 ; pKa + 1]

La solution « résiste » tant que le rapport reste entre 0,10 et 10.

⚠️ Piège : la zone tampon est centrée sur le pKa du COUPLE, pas sur le pH qu'on viserait dans une expérience.
✏️ Exercice 6 — Choisir l'indicateur coloré (★★★)

Données : pH = 8,5 à l'équivalence ; saut de pH de 5,8 à 10,5 ; zones de virage : hélianthine 3,1 → 4,4, BBT 6,0 → 7,6, phénolphtaléine 8,2 → 10,0.

1

Rôle de l'indicateur : changer de couleur quand le pH traverse sa zone de virage ; on le choisit pour que le virage coïncide avec l'équivalence, ce qui repère Vₑ à l'œil.

2

Condition 1 — zone de virage incluse dans le saut [5,8 ; 10,5] : le BBT (6,0 → 7,6) convient, la phénolphtaléine (8,2 → 10,0) convient ; l'hélianthine (3,1 → 4,4) est en dehors : exclue.

3

Condition 2 — contenir le pH d'équivalence 8,5 : seule la phénolphtaléine (8,2 → 10,0) le contient → on choisit la phénolphtaléine.

4

Couleurs : avant l'équivalence (pH < 8,2) la solution est incolore ; juste après, elle devient rose ; le premier rose persistant annonce Vₑ.

5

Avec l'hélianthine, le virage (jaune dès pH 4,4) se produirait vers V ≈ 6 mL, bien avant Vₑ = 10,0 mL : erreur d'environ 40 % sur la concentration.

Indicateur choisi : phénolphtaléine (incolore → rose)

Zone de virage 8,2 → 10,0, contenant le pH d'équivalence 8,5.

⚠️ Piège : « zone de virage dans le saut de pH » est nécessaire mais pas suffisant : il faut aussi que le pH d'équivalence soit dans la zone de virage.
