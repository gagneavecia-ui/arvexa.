Corrigés 1 à 3 : mesures et équilibres

✏️ Exercice 1 — La balance de Cotton (★★)

Données : l = 0,10 m ; I = 2,0 A ; Δm = 10,0 g = 0,0100 kg ; g = 9,8 N·kg⁻¹ ; une seule spire.

1

Sans courant, m₀ équilibre le cadre. Quand le courant circule, →F pousse EF vers le haut : le plateau devient trop léger → il faut AJOUTER Δm pour compenser, d'où Δm·g = F.

2

F = Δm·g = 0,0100 × 9,8 = 0,098 N.

3

Comme EF ⊥ B : F = I·l·B → B = F/(I·l) = Δm·g/(I·l) = 0,098/(2,0 × 0,10) = 0,098/0,20 = 0,49 T.

4

Les deux côtés verticaux sont parcourus par des courants opposés dans le même champ → forces opposées qui se compensent ; le côté supérieur est hors du champ (F = 0). Seul EF compte.

B = Δm·g/(I·l) = 0,49 T
La balance de Cotton « pèse » le champ magnétique grâce à la force de Laplace.
⚠️ Piège : convertir Δm = 10,0 g = 0,0100 kg ; si →F poussait vers le bas, il faudrait RETIRER des masses au lieu d'en ajouter.
✏️ Exercice 2 — Rail de Laplace et poulie (★★)

Données : l = 0,15 m ; m = 30 g = 0,030 kg ; B = 0,40 T rentrant ; g = 9,8 N·kg⁻¹.

1

Tension du fil (masse suspendue en équilibre) : T = m·g = 0,030 × 9,8 = 0,294 N.

2

La tige est en équilibre : la force de Laplace compense la tension → F = T = 0,294 N, dirigée vers la poulie.

3

F = I·l·B → I = F/(l·B) = 0,294/(0,15 × 0,40) = 0,294/0,060 = 4,9 A.

4

Sens : →F doit pointer vers la poulie (vers la droite) et →B est rentrant ; la règle des trois doigts donne un courant de A vers B (du rail supérieur vers le rail inférieur sur la figure).

I = 4,9 A, de A vers B
L'équilibre exige F = T : l'intensité du courant ajuste la tension que la tige peut retenir.
⚠️ Piège : la tige a une masse négligeable, seul le poids suspendu compte ; et toujours déterminer le sens de →F AVANT de donner le sens de I.
✏️ Exercice 3 — Trouver B sur rails inclinés (★★)

Données : α = 30° ; m = 50 g = 0,050 kg ; l = 0,25 m ; I = 1,0 A ; g = 9,8 N·kg⁻¹ ; B ⊥ plan.

1

Composante du poids : m·g·sin α = 0,050 × 9,8 × 0,5 = 0,245 N.

2

Équilibre : I·l·B = m·g·sin α → B = m·g·sin α/(I·l) = 0,245/(1,0 × 0,25) = 0,98 T.

3

Le sens du courant reste celui qui donne →F montante : courant entrant ⊗ (même raisonnement qu'à l'exercice 5 de la partie 01).

4

Si B = 0,50 T : F = 1,0 × 0,25 × 0,50 = 0,125 N < 0,245 N → équilibre impossible : la tige glisse vers le bas.

B = 0,98 T
À B = 0,50 T la force F = 0,125 N est deux fois trop faible pour retenir la tige.
⚠️ Piège : champ plus faible → force plus faible → la tige glisse ; toujours comparer F et m·g·sin α avant de conclure.

✏️ Exercice 4 — Tige avec frottements (★★★)

Données : m = 200 g = 0,200 kg ; l = 0,10 m ; B = 0,50 T ; μ = 0,25 ; g = 9,8 N·kg⁻¹.

1

Frottement : f = μ·m·g = 0,25 × 0,200 × 9,8 = 0,49 N.

2

La tige démarre si F > f : I·l·B > μ·m·g → I_min = 0,49/(0,10 × 0,50) = 0,49/0,050 = 9,8 A.

3

Avec I = 12 A : F = 12 × 0,10 × 0,50 = 0,60 N ; la 2ᵉ loi de Newton donne a = (F − f)/m = (0,60 − 0,49)/0,200 = 0,55 m·s⁻².

4

Avec I = 5,0 A : F = 5,0 × 0,10 × 0,50 = 0,25 N < 0,49 N → non, la tige reste immobile.

I_min = 9,8 A ; a = 0,55 m·s⁻² pour I = 12 A
Tant que F ≤ f, rien ne bouge ; au-delà, l'accélération est proportionnelle à F − f.
⚠️ Piège : tant que F ≤ f, la tige ne bouge pas ; ensuite, utiliser (F − f) dans la 2ᵉ loi de Newton, et non F seule.
✏️ Exercice 5 — Rails inclinés et poulie : le problème complet (★★★)

Données : α = 30° ; l = 0,20 m ; m = 50 g = 0,050 kg ; m₀ = 20 g = 0,020 kg ; B = 0,50 T ⊥ plan ; g = 9,8 N·kg⁻¹.

1

Tension : T = m₀·g = 0,020 × 9,8 = 0,196 N. Composante du poids : m·g·sin α = 0,050 × 9,8 × 0,5 = 0,245 N.

2

Le poids l'emporte (0,245 > 0,196) : sans force de Laplace, la tige descend. →F doit donc pointer vers le HAUT de la pente : F = 0,245 − 0,196 = 0,049 N.

3

I = F/(l·B) = 0,049/(0,20 × 0,50) = 0,049/0,10 = 0,49 A, dans le sens qui donne →F montante (courant entrant ⊗).

4

Avec m₁ = 100 g : T = 0,98 N > 0,245 N : la masse l'emporte → →F doit pointer vers le BAS de la pente : F = 0,98 − 0,245 = 0,735 N → I = 0,735/0,10 = 7,35 A, sens INVERSÉ.

I = 0,49 A (m₀ = 20 g) ; I = 7,35 A, sens inversé (m₀ = 100 g)
Changer la masse suspendue change à la fois l'intensité ET le sens du courant d'équilibre.
⚠️ Piège : comparer D'ABORD T et m·g·sin α pour connaître le sens nécessaire de →F ; le sens du courant s'en déduit en dernier.
