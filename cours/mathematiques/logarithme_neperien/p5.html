💡 La carte mentale du chapitre en trois gestes

Transformer : ln change les produits en sommes, les quotients en différences, les puissances en facteurs (Partie 1). Éliminer : pour sortir de ln, on passe à l'exponentielle — ln x = a ⇔ x = e^a — ou on retire deux logs égaux, ln étant strictement croissante (Partie 3). Étudier : domaine u > 0, dérivée u'/u, limites, tableau (Parties 2 à 4). Chaque question du Bac en active un, deux ou trois.

02
Réflexes

Les 10 réflexes de calcul

À chaque signal de l'énoncé son geste automatique :

Situation → action
  • Un ln apparaît → avant tout : vérifier que l'argument est strictement positif et écrire le domaine (P2 §8).
  • « Simplifier » une somme/différence de logs → regrouper en produit ou quotient, sortir les puissances ; un calcul réussi finit souvent sur ln 1 = 0 (P1 §5–8).
  • « En fonction de ln 2, ln 3… » → décomposer en facteurs premiers : 150 = 2 × 3 × 5² (P1 §8).
  • Des exponentielles qui cachent un log (e^(1 + ln 5), e^(2 ln 3)) → reconstituer un log complet dans l'exposant, puis réciprocité : e^(ln 9) = 9 (P1 §3).
  • Dériver ln(…) → domaine, écrire u et u', conclure u'/u sur le domaine — jamais 1/u sans le u' (P2 §5).
  • Le ln est à côté (x · ln x, (ln x)/x, (ln x)²) → produit, quotient ou carré : les trois résultats par cœur (P2 §6).
  • Une primitive à trouver → le dénominateur est u ; comparer le numérateur à u', corriger le facteur k, vérifier u > 0, redériver pour contrôler (P2 §7, P4 §5).
  • Une limite avec ln → diagnostiquer la forme : référence (0⁺, +∞), croissance comparée (∞/∞, 0 × ∞), factoriser (∞ − ∞), nombre dérivé (0/0 en un point fini) (P3 §5–6).
  • Une équation avec ln → domaine, regrouper en un seul ln par membre, exponentielle ou injectivité, filtrer les solutions hors domaine ; un (ln x)² → poser t = ln x (P3 §9, P4 §2).
  • Une inéquation avec ln → retirer les logs en gardant le sens (ln croissante), puis intersecter avec le domaine — deux ensembles à joindre (P4 §3).
💡 Le réflexe universel de vérification

(1) Domaine respecté ? (2) Redériver une primitive ou réinjecter une solution. (3) Ordre de grandeur avec les valeurs mentales ln 2 ≈ 0,693 ; ln 3 ≈ 1,099 ; ln 10 ≈ 2,303 — un « ln 12 » qui donne 2,5, oui ; 25, non. Trois secondes chacune, des points sauvés à chaque fois.

03
Pièges

Les 10 erreurs à bannir

Chacune coûte des points à chaque épreuve — et se répare en une ligne :

⚠️ Erreur 1 — écrire ln 0 = 0

Faux : ln 0 n'existe pas ; c'est ln 1 = 0 qui est vrai (et ln e = 1). (P1 §4)

⚠️ Erreur 2 — écrire ln(a + b) = ln a + ln b

Faux : ln 2 ≈ 0,693 alors que ln 1 + ln 1 = 0. Le log ne traite que produits, quotients, puissances. (P1 §7)

⚠️ Erreur 3 — écrire ln(a/b) = (ln a)/(ln b)

Faux : ln(8/2) = ln 4 ≈ 1,386 mais (ln 8)/(ln 2) = 3. La formule juste est une différence : ln a − ln b. (P1 §6)

⚠️ Erreur 4 — écrire (ln(x² + 1))' = 1/(x² + 1)

Faux : il faut u' au numérateur — 2x/(x² + 1). Et (ln u)' = u'/u ne s'écrit jamais hors du domaine u > 0. (P2 §5)

⚠️ Erreur 5 — dériver ou primitiver ln(u) sans vérifier u > 0

« f(x) = ln(4 − x²) donc f'(x) = −2x/(4 − x²) sur ℝ » est doublement faux : la formule ne vaut que sur ]−2 ; 2[, et en dehors, f n'existe même pas. (P2 §8)

⚠️ Erreur 6 — écrire lim ln x en 0 sans le +

La limite n'existe qu'à droite : écrire 0⁺ — de même lim ln(x + 2) en −2⁺. Omettre le + est une maladresse signalée par les correcteurs. (P3 §3)

⚠️ Erreur 7 — sortir une croissance comparée de son cadre

« x · ln x → 0 en +∞ » est faux (elle vaut +∞ !) — la limite 0 est valable en 0⁺ ; et (ln x)/x → 0 en +∞ seulement. Écris toujours le point limite. (P4 §1)

⚠️ Erreur 8 — garder une solution hors du domaine

Conclure S = {3 ; −2} pour ln x + ln(x − 1) = ln 6 sans le filtre x > 1 fait perdre la question — ln(−2) n'existe pas. Conditions d'abord, calcul ensuite, filtre enfin. (P4 §2)

⚠️ Erreur 9 — confondre (ln x)² et ln(x²)

Le carré du log contre le log du carré : ln(x²) = 2 · ln x si x > 0, mais (ln x)² n'a aucune formule de simplification — et les domaines diffèrent (ℝ* contre ]0 ; +∞[). (P4 §2)

⚠️ Erreur 10 — conclure « ln x = 0 ⇒ x = 0 » (ou confondre ln et log)

La solution de ln x = 0 est x = 1. Et dans les applications, le pH et les décibels utilisent le log décimal : ln x ≠ log x. (P3 §9, P4 §6)

💡 Reconstruire sans mémoriser : la définition fait tout le travail
  • Les pivots : ln 1 = 0 et ln e = 1 ne s'apprennent pas — ln x est l'exposant à mettre sur e pour obtenir x. Pour 1 : l'exposant est 0 ; pour e : c'est 1 ; pour eⁿ : c'est n.

05
Fil rouge

Plan d'attaque d'un exercice type Bac

Un exercice de logarithme au Bac enchaîne presque toujours : domaine → dérivée et tableau → limites avec croissances comparées → équation ou inégalité → parfois primitive ou application. Voici le fil rouge intégral sur f(x) = x · ln x — la fonction vedette du chapitre, à refaire sans regarder.

🧮 Le fil rouge — f(x) = x · ln x

Q1 — Domaine et dérivée. f existe si x > 0. Dérivée (produit) : f'(x) = 1 × ln x + x × (1/x) = ln x + 1. (Réflexes 1 et 6)

Q2 — Limites. En 0⁺ : forme 0 × (−∞) tranchée par la croissance comparée démontrée (substitution x = 1/t) : x · ln x → 0. En +∞ : f → +∞. (Réflexe 8)

Q3 — Tableau. f'(x) > 0 ⇔ ln x > −1 ⇔ x > 1/e : f décroît sur ]0 ; 1/e], croît ensuite, minimum f(1/e) = (1/e) × (−1) = −1/e. (Réflexe 5)

Q4 — Inégalité. Le minimum vaut −1/e : donc x · ln x ≥ −1/e pour tout x > 0, égalité seulement en 1/e. (Un extremum devient une inégalité globale)

Q5 — Équation sans solution exacte. x · ln x = 1 : sur [1/e ; +∞[, f est continue et strictement croissante de −1/e vers +∞ — une unique solution α. À la calculatrice : f(1,76) ≈ 0,995 < 1 < f(1,77) ≈ 1,011, donc α ∈ ]1,76 ; 1,77[. (Existence + unicité + encadrement)

Q6 — Primitive et intégrale. Une primitive de (2 ln x + 3)/x : décomposer en 2 · (ln x)/x + 3 · (1/x), d'où H(x) = (ln x)² + 3 ln x (contrôle : H' = (2 ln x + 3)/x ✔). Et ∫₂⁵ (2x)/(x² + 1) dx = ln 26 − ln 5 = ln(26/5) = ln 5,2 ≈ 1,65. (Réflexe 7)

Q7 — Le trinôme déguisé. (ln x)² − 3 ln x + 2 = 0 : poser t = ln x, trinôme t² − 3t + 2 = 0, t = 1 ou 2, retour S = {e ; e²}. (Réflexe 9)

Q8 — L'application. N(t) = N₀ · e^(0,2t) : seuil e^(0,2T) = 2, donc T = ln 2/0,2 ≈ 3,47 h (contrôle : e^(0,693) ≈ 2 ✔). (La formule T = ln 2/k, à savoir refaire)

La trame de rédaction qui rapporte les points
  • Écrire le domaine en première ligne de presque chaque question ;
  • Citer la formule et ses conditions (« comme a > 0 et b > 0, ln(ab) = ln a + ln b ») ;
  • Justifier chaque passage à l'exponentielle ou chaque retrait de logs (ln strictement croissante) ;
  • Terminer par un contrôle : redériver une primitive, réinjecter une solution, ordre de grandeur.

08
L'outil final

La courbe de ln — la refaire en 60 secondes sans rien mémoriser

Toutes les grandes idées du chapitre vivent sur un seul dessin : le domaine ]0 ; +∞[ et son asymptote x = 0, les pivots ln 1 = 0 et ln e = 1, la tangente y = x − 1 et l'inégalité ln x ≤ x − 1, la croissance et la concavité (les pentes 1/x qui diminuent), la lenteur vers +∞ — et le jumelage avec l'exponentielle par la symétrie d'axe y = x.

La figure signature du chapitre : asymptote verticale x = 0, tangente y = x − 1 (pente 1 au point (1 ; 0)), courbe concave qui passe par (e ; 1) et monte de plus en plus lentement.
🎯 Comment lire cette figure

À gauche de l'axe des ordonnées : la courbe n'existe pas (domaine ]0 ; +∞[) ; à droite, elle plonge vers −∞ en se collant à l'asymptote x = 0. Les points pivots : (1 ; 0) car ln 1 = 0, (e ; 1) car ln e = 1 — et gratuitement (e² ; 2) et (1/e ; −1). La tangente y = x − 1 touche la courbe en (1 ; 0) avec la pente 1 (triangle 1 × 1), et la courbe reste tout entière sous elle : ln x ≤ x − 1. Elle reste aussi sous la diagonale y = x : ln x < x toujours.

🛠 LA MÉTHODE EN 6 ÉTAPES — redresser la courbe en 60 secondes

Étape 1 — Le squelette et le domaine (10 s). Trace les axes, hachure légèrement tout le demi-plan gauche (ln n'y existe pas), marque l'asymptote verticale x = 0 : la courbe va s'y coller en plongeant. Pourquoi ? ln x existe seulement pour x > 0 — et ln x → −∞ quand x → 0⁺.

Étape 2 — Les deux points magiques (10 s). Place (1 ; 0) et (e ; 1) — car ln 1 = 0 et ln e = 1 : ce ne sont pas des valeurs à retenir, ce sont la définition lue en deux endroits (ln x est l'exposant à mettre sur e). Ajoute si tu veux (e² ; 2) et (1/e ; −1), même mécanique.

Étape 3 — La tangente en 1 (10 s). Trace la droite y = x − 1 : elle passe par (1 ; 0) et (0 ; −1), avec la pente 1 (la dérivée 1/x vaut 1 en x = 1). Et le sens : la courbe est toujours sous cette tangente — ln x ≤ x − 1, égalité seulement au contact en 1. Justification express : l'écart g(x) = x − 1 − ln x a pour dérivée (x − 1)/x, minimum g(1) = 0 : l'écart ne descend jamais sous 0.

Étape 4 — Le sens de la courbe (10 s). Croissante (dérivée 1/x > 0) et concave : les pentes 1/x diminuent, la courbe tourne vers le bas — elle monte de moins en moins vite (entre 1 et e elle gagne une unité, entre e et e² ≈ 7,39 encore une, mais sur bien plus de terrain).

Étape 5 — Le tracé (15 s). Un seul geste : descendre depuis le haut de l'asymptote en frôlant l'axe, traverser l'axe des abscisses en (1 ; 0) avec la pente 1, passer par (e ; 1) en s'infléchissant déjà vers le bas, puis monter lentement vers +∞ — de plus en plus plate, sans jamais devenir horizontale ni reprendre de la pente.

Étape 6 — Le contrôle (5 s). Quatre vérifications : (1) sous la tangente : ln x ≤ x − 1 ✔ ; (2) sous la diagonale : ln x < x ✔ ; (3) négative avant 1, positive après ✔ ; (4) passage par les pivots (eⁿ ; n) ✔. Un seul point cloche ? Relis l'étape 2.

Le bonus gratuit : ln et exp se défont l'une l'autre, donc leurs courbes sont symétriques par rapport à la bissectrice y = x — (1 ; 0) ↔ (0 ; 1), (e ; 1) ↔ (1 ; e).
💡 Ce que tu dois VRAIMENT retenir

Rien par cœur. Juste : (1) le squelette et son domaine ]0 ; +∞[ avec l'asymptote x = 0 ; (2) deux points magiques — (1 ; 0) et (e ; 1), lus sur la définition ; (3) la tangente y = x − 1 de pente 1, courbe dessous ; (4) croissante et concave (les pentes 1/x diminuent) ; (5) le contrôle ln x < x. Avec ces 5 gestes, tu redresses la courbe en 60 secondes — et le miroir y = x te donne exp gratuitement. La version commentée pas à pas est dans le PDF de cette partie (section finale).

Puis vérifie : ta courbe doit passer par (e² ; 2), rester sous la droite y = x − 1 partout sauf en (1 ; 0), et ne jamais couper la diagonale. Si les trois contrôles passent, tu n'as rien mémorisé — tu as reconstruit. C'est beaucoup plus solide.

📌 Ce qu'il faut retenir
  • [partie 1] ln x est l'exposant à mettre sur e : ln 1 = 0, ln e = 1 ; ln(ab) = ln a + ln b, ln(a/b) = ln a − ln b, ln(aⁿ) = n · ln a — jamais pour une somme
  • [partie 2] (ln x)' = 1/x et (ln u)' = u'/u (u > 0) ; primitives : 1/x → ln x + C, u'/u → ln(u) + C ; le domaine u > 0 avant tout
  • [partie 3] ln croissante de −∞ (en 0⁺) à +∞, asymptote x = 0, signe lu par rapport à 1 ; ordre conservé ; ln x ≤ x − 1 puis ln x < x
  • [partie 4] Croissances comparées démontrées : (ln x)/x → 0 en +∞, x · ln x → 0 en 0⁺ ; équations : regrouper puis e^k ou injectivité ; t = ln x pour les (ln x)² ; T = ln 2/k, log x = ln x/ln 10
  • [fiche] Le trio de gestes : transformer (P1), éliminer (exponentielle + ordre conservé), étudier (domaine, u'/u, tableau)
  • [figure] La courbe de ln se reconstruit sans rien mémoriser : domaine + asymptote, deux points magiques, tangente pente 1 dessous, croissante-concave, contrôle ln x < x — et exp en miroir par y = x
