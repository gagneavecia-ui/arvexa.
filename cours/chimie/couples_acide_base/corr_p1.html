Écrire et classer les couples acide/base

✏️ Exercice 1 — Écrire des couples acide/base (★)
1

Couples organiques et ammonium : CH₃—COOH ⇌ CH₃—COO⁻ + H⁺ (acide : CH₃—COOH, base : CH₃—COO⁻) ; NH₄⁺ ⇌ NH₃ + H⁺ (acide : NH₄⁺, base : NH₃). Dans chaque cas, la base conjuguée gagne un atome H de moins et une charge de moins que l'acide.

2

Couples de l'eau : H₃O⁺ ⇌ H₂O + H⁺ (acide : H₃O⁺, base : H₂O) et H₂O ⇌ OH⁻ + H⁺ (acide : H₂O, base : OH⁻). L'eau apparaît dans deux couples : elle est ampholyte.

3

Couples du carbone : H₂CO₃ ⇌ HCO₃⁻ + H⁺ (acide : H₂CO₃, base : HCO₃⁻) et HCO₃⁻ ⇌ CO₃²⁻ + H⁺ (acide : HCO₃⁻, base : CO₃²⁻). Chaque demi-équation est équilibrée en atomes et en charges.

4

Bilan : l'ion HCO₃⁻ est base dans le couple H₂CO₃/HCO₃⁻ et acide dans le couple HCO₃⁻/CO₃²⁻ : c'est un ampholyte (comme l'eau).

HCO₃⁻ : base du couple H₂CO₃/HCO₃⁻, acide du couple HCO₃⁻/CO₃²⁻
Un ampholyte possède deux couples : il peut céder ou capter un proton.
⚠️ Piège : dans la demi-équation, la charge de la base est celle de l'acide diminuée de 1 (ex : HCO₃⁻ donne CO₃²⁻). Vérifier toujours les charges !
✏️ Exercice 2 — Acides et bases dans une réaction (★)
1

Première réaction : CH₃—COOH + H₂O ⇌ CH₃—COO⁻ + H₃O⁺. Couple 1 : CH₃—COOH/CH₃—COO⁻ (l'acide CH₃—COOH cède le proton, base formée CH₃—COO⁻) ; couple 2 : H₃O⁺/H₂O (la base H₂O capte le proton, acide formé H₃O⁺).

2

Deuxième réaction : NH₃ + H₂O ⇌ NH₄⁺ + OH⁻. Couple 1 : NH₄⁺/NH₃ (la base NH₃ capte le proton, acide formé NH₄⁺) ; couple 2 : H₂O/OH⁻ (l'acide H₂O cède le proton, base formée OH⁻).

3

Rôle de l'eau : l'eau est base (elle capte H⁺) dans la première réaction et acide (elle cède H⁺) dans la seconde. Cette double personnalité s'appelle l'ampholytie de l'eau.

Deux couples par réaction acide-base, toujours
Repérer les deux couples avant tout calcul : c'est la première étape de tout exercice.
✏️ Exercice 3 — L'échelle des pKa (★★)
1

Placement : pKa(H₂CO₃/HCO₃⁻) = 6,4 : le couple se place entre 4,8 et 9,2, un peu après le 6 de l'échelle, à l'emplacement du point d'interrogation.

2

Extrêmes : l'acide le plus fort est celui de plus petit pKa : H₃O⁺ (pKa = 0). La base la plus forte est la base conjuguée de l'acide le plus faible : OH⁻, base du couple H₂O/OH⁻ (pKa = 14,0).

3

Classements. Acides, du plus fort au plus faible : HCOOH, puis CH₃—COOH, puis H₂CO₃, puis NH₄⁺, puis HCO₃⁻, puis H₂O. Leurs bases conjuguées, de la plus faible à la plus forte, s'échangent dans l'ordre inverse : HCOO⁻, CH₃—COO⁻, HCO₃⁻, NH₃, CO₃²⁻, OH⁻.

4

Non : plus un acide est fort, plus sa base conjuguée est faible. Exemple : H₃O⁺, acide très fort (pKa = 0), a pour base conjuguée H₂O, base très faible.

pKa petit → acide fort, base conjuguée faible
L'échelle des pKa se lit dans les deux sens : acides à gauche, bases fortes à droite.
⚠️ Piège : ne pas confondre « l'acide le plus fort » (plus petit pKa) et « la base la plus forte » (associée au plus GRAND pKa) : ce sont les deux extrémités opposées de l'échelle.

Prévoir le sens d'une réaction entre deux couples

✏️ Exercice 4 — La réaction de l'acide éthanoïque avec l'ammoniac (★★)

Données : pKa₁ = 4,8 ; pKa₂ = 9,2 ; réaction CH₃—COOH + NH₃ ⇌ CH₃—COO⁻ + NH₄⁺.

1

Couples : couple 1 CH₃—COOH/CH₃—COO⁻ (l'acide CH₃—COOH cède le proton) et couple 2 NH₄⁺/NH₃ (la base NH₃ capte le proton, acide formé NH₄⁺).

2

Démonstration. Ka₁ = [CH₃—COO⁻]·[H₃O⁺]/[CH₃—COOH] donne [CH₃—COO⁻]/[CH₃—COOH] = Ka₁/[H₃O⁺] ; et Ka₂ = [NH₃]·[H₃O⁺]/[NH₄⁺] donne [NH₄⁺]/[NH₃] = [H₃O⁺]/Ka₂. En multipliant : K = [CH₃—COO⁻]·[NH₄⁺]/([CH₃—COOH]·[NH₃]) = Ka₁/Ka₂ = 10^(−pKa₁)/10^(−pKa₂) = 10^(pKa₂ − pKa₁).

3

Application numérique : K = 10^(9,2 − 4,8) = 10^(4,4) = 2,5 × 10⁴. Comme K est très supérieure à 10⁴, la réaction est totale dans le sens direct (sens 1) : l'acide éthanoïque cède son proton à l'ammoniac.

K = 10^(pKa₂ − pKa₁) = 2,5 × 10⁴ → sens direct
L'acide le plus fort (pKa 4,8) réagit avec la base la plus forte (pKa 9,2) : réaction spontanée et totale.
⚠️ Piège : inverser les pKa donne 10^(−4,4), absurde pour une réaction entre un acide plus fort et une base plus forte. Toujours repérer QUI cède et QUI capte le proton avant d'appliquer la formule.
✏️ Exercice 5 — Quatre réactions, quatre constantes (★★)
1

Réaction a : HCOOH + NH₃ ⇌ HCOO⁻ + NH₄⁺. Couple 1 : HCOOH/HCOO⁻ (3,8) ; couple 2 : NH₄⁺/NH₃ (9,2). K = 10^(9,2 − 3,8) = 10^(5,4) = 2,5 × 10⁵ : très supérieure à 10⁴, réaction TOTALE dans le sens direct.

2

Réaction b : CH₃—COOH + HCO₃⁻ ⇌ CH₃—COO⁻ + H₂CO₃. Couple 1 : CH₃—COOH/CH₃—COO⁻ (4,8) ; couple 2 : H₂CO₃/HCO₃⁻ (6,4). K = 10^(6,4 − 4,8) = 10^(1,6) = 4,0 × 10¹ = 40 : supérieure à 1, le sens direct est favorisé, mais très inférieure à 10⁴ : réaction LIMITÉE.

3

Réaction c : NH₄⁺ + CH₃—COO⁻ ⇌ NH₃ + CH₃—COOH. Couple 1 : NH₄⁺/NH₃ (9,2) ; couple 2 : CH₃—COOH/CH₃—COO⁻ (4,8). K = 10^(4,8 − 9,2) = 10^(−4,4) = 4,0 × 10⁻⁵ : très petite, réaction quasi NULLE dans ce sens (c'est la réaction inverse de l'exercice 4, totale dans l'autre sens).

4

Réaction d (autoprotolyse) : 2 H₂O ⇌ H₃O⁺ + OH⁻. Couple 1 : H₂O/OH⁻ (14,0, l'eau acide cède le proton) ; couple 2 : H₃O⁺/H₂O (0, l'eau base capte le proton). K = 10^(0 − 14,0) = 10^(−14,0) = 1,0 × 10⁻¹⁴ = Ke : on retrouve la constante d'autoprotolyse, réaction extrêmement limitée.

5

Classement final : a (2,5 × 10⁵, totale), puis b (40, limitée mais favorisée), puis c (4,0 × 10⁻⁵, quasi nulle), puis d (1,0 × 10⁻¹⁴, négligeable). Plus l'écart entre les deux pKa est grand en faveur du couple 2, plus la réaction est totale.

K(a) = 2,5 × 10⁵ ; K(b) = 40 ; K(c) = 4,0 × 10⁻⁵ ; K(d) = 1,0 × 10⁻¹⁴
Grand écart de pKa favorable → réaction totale ; petit écart → limitée ; écart négatif → sens indirect.
⚠️ Piège : pour l'autoprotolyse, le couple 1 est H₂O/OH⁻ (pKa 14,0) et le couple 2 est H₃O⁺/H₂O (pKa 0). Les inverser donnerait 10^(14), le contraire de la réalité !
✏️ Exercice 6 — L'ion hydrogénocarbonate, un ampholyte (★★★)

Données : pKa(H₂CO₃/HCO₃⁻) = 6,4 ; pKa(HCO₃⁻/CO₃²⁻) = 10,3 ; pH mesuré 8,4.

1

Double comportement : comme acide (couple HCO₃⁻/CO₃²⁻) : HCO₃⁻ ⇌ CO₃²⁻ + H⁺ ; comme base (couple H₂CO₃/HCO₃⁻) : H₂CO₃ ⇌ HCO₃⁻ + H⁺. L'ion HCO₃⁻ peut donc céder ou capter un proton : c'est un ampholyte.

2

Réaction entre deux ions HCO₃⁻ : 2 HCO₃⁻ ⇌ H₂CO₃ + CO₃²⁻ (atomes : 2 C, 2 H, 6 O de chaque côté ; charges : −2 = −2). Couple 1 : HCO₃⁻/CO₃²⁻ (10,3) ; couple 2 : H₂CO₃/HCO₃⁻ (6,4) ; d'où K = 10^(6,4 − 10,3) = 10^(−3,9) = 1,3 × 10⁻⁴.

3

Conclusion : K est très inférieure à 1 : la réaction est très limitée. La quasi-totalité du carbone dissous reste sous forme d'ions HCO₃⁻, espèce majoritaire.

4

pH de l'ampholyte : pH = ½(pKa₁ + pKa₂) = ½(6,4 + 10,3) = ½ × 16,7 = 8,35 ≈ 8,4. On retrouve exactement le pH mesuré : la solution de bicarbonate est basique (pH supérieur à 7).

K = 1,3 × 10⁻⁴ ; pH = ½(6,4 + 10,3) ≈ 8,4
Le pH d'un ampholyte est la moyenne des deux pKa de ses couples.
⚠️ Piège : dans K = 10^(pKa₂ − pKa₁), le couple 1 est celui où HCO₃⁻ est ACIDE (10,3) et le couple 2 celui où il est BASE (6,4). L'ordre compte : 10^(−3,9) et non 10^(3,9).
