L'angle optimal et les portées comparées

Deux questions de cours déguisées : le maximum de la portée et la propriété des angles complémentaires. Les formules D(α) et H(α) font tout le travail, à condition de bien distinguer sin 2α et sin²α.

✏️ Exercice 1 — L'angle optimal du footballeur (★★)

Données : v₀ = 20 m·s⁻¹ ; g = 9,8 m·s⁻² ; sin 60° = 0,866 ; sin 90° = 1,00.

1

À v₀ fixée, D(α) = v₀²·sin 2α/g est maximale quand sin 2α = 1, c'est-à-dire pour 2α = 90°, soit α = 45°.

2

Portée maximale : D_max = v₀²/g = 400/9,8 = 40,8 ≈ 41 m.

3

Portée à 30° : D(30°) = 400×0,866/9,8 = 346,4/9,8 = 35,3 m.

4

Perte relative : (D_max − D)/D_max = (40,8 − 35,3)/40,8 = 5,5/40,8 = 0,135 → environ 13 %.

5

✅ Vérification : D(30°)/D_max = sin 60° = 0,866, donc D(30°) = 0,866×40,8 = 35,3 m ✓ (deux chemins, même valeur).

D_max = 40,8 m pour α = 45° ; D(30°) = 35,3 m (perte de 13 %)

Le 45° est l'angle magne des portées maximales, à condition de retomber au niveau du départ.

⚠️ Piège : le maximum correspond à sin 2α = 1 (α = 45°), pas à α = 90° — un tir vertical retombe au pied du tireur !
✏️ Exercice 2 — Trajectoire tendue ou trajectoire haute ? (★★)

Données : v₀ = 18 m·s⁻¹ ; sin 25° = 0,423 ; cos 25° = 0,906 ; sin 50° = sin 130° = 0,766.

1

Portée du tir tendu : D(25°) = 324×0,766/9,8 = 248,2/9,8 = 25,3 m.

2

Portée du tir haut : D(65°) = 324×sin 130°/9,8 = 324×0,766/9,8 = 25,3 m → égalité vérifiée ✓ : 25° et 65° sont complémentaires et sin 2(90° − α) = sin 2α.

3

Flèches : H(25°) = 324×0,423²/19,6 = 324×0,179/19,6 = 58,0/19,6 = 3,0 m ; H(65°) = 324×0,906²/19,6 = 324×0,821/19,6 = 266,0/19,6 = 13,6 m.

4

✅ Vérification du rapport : H(65°)/H(25°) = 0,821/0,179 = 4,6, soit (0,906/0,423)² = 4,6 ✓ (rapport des sinus carrés).

5

Durées de vol : t(25°) = 2×18×0,423/9,8 = 15,2/9,8 = 1,6 s ; t(65°) = 2×18×0,906/9,8 = 32,6/9,8 = 3,3 s. À mi-portée, chaque tir culmine à sa flèche : 3,0 m, insuffisant ; 13,6 m, l'obstacle de 5,0 m est largement franchi → choisir α = 65°.

D = 25,3 m pour les deux tirs ; H = 3,0 m (25°) et 13,6 m (65°)

Seul le tir haut franchit l'obstacle de 5,0 m.

⚠️ Méthode : même portée ne veut pas dire même trajectoire — le tir haut met deux fois plus de temps mais passe les obstacles.

Dossiers complets : pierre et mur

Départ surélevé pour la pierre, mur en travers du tir pour le ballon : les formules toutes faites cessent de s'appliquer, les équations horaires reprennent la main.

✏️ Exercice 3 — Dossier complet : le lancer de pierre (★★★)

Données : v₀ = 13 m·s⁻¹ ; α = 35° ; z₀ = 2,0 m ; cos 35° = 0,819 ; sin 35° = 0,574 ; √95,5 = 9,77 ; √206,5 = 14,4.

1

Composantes initiales : vₓ = 13×0,819 = 10,6 m·s⁻¹ ; v′₀ = 13×0,574 = 7,46 ≈ 7,5 m·s⁻¹.

2

Équations horaires : x(t) = 10,6·t ; z(t) = −4,9·t² + 7,5·t + 2,0 (attention, z₀ = 2,0 m).

3

Flèche au-dessus du départ : H = v₀²·sin²α/(2g) = 169×0,574²/19,6 = 169×0,329/19,6 = 55,6/19,6 = 2,8 m → z_max = 2,0 + 2,8 = 4,8 m au-dessus du sol.

4

✅ Vérification : tₛ = 7,5/9,8 = 0,77 s puis z(0,77) = −4,9×0,77² + 7,5×0,77 + 2,0 = −2,91 + 5,78 + 2,0 = 4,87 ≈ 4,8 m ✓.

5

Impact au sol : −4,9·t² + 7,5·t + 2,0 = 0 → Δ = 7,5² + 4×4,9×2,0 = 56,25 + 39,2 = 95,45 ≈ 95,5 ; √Δ = 9,77 ; t = (7,5 + 9,77)/9,8 = 17,27/9,8 = 1,76 s (racine positive).

6

Portée : D = vₓ·t = 10,6×1,76 = 18,7 m.

7

Vitesse d'impact : v′ = −9,8×1,76 + 7,5 = −17,2 + 7,5 = −9,7 m·s⁻¹ ; v = √(10,6² + 9,7²) = √(112,4 + 94,1) = √206,5 = 14,4 ≈ 14 m·s⁻¹, avec tan θ = 9,7/10,6 = 0,92 → θ ≈ 42° sous l'horizontale.

8

✅ Vérification énergétique : v = √(v₀² + 2·g·z₀) = √(169 + 39,2) = √208,2 = 14,4 m·s⁻¹ ✓ (écart minime dû aux arrondis).

z_max = 4,8 m ; impact à t = 1,76 s ; D = 18,7 m ; v ≈ 14 m·s⁻¹

La pierre frappe le sol 1,76 s après le lancer, à 18,7 m du promontoire.

⚠️ Attention : ici z₀ = 2,0 m, la formule D = v₀²·sin 2α/g est INVALIDE — seule la résolution du trinôme donne la bonne portée !
✏️ Exercice 4 — Dossier complet : le tir arrêté par le mur (★★★)

Données : v₀ = 11 m·s⁻¹ ; α = 40° ; d = 10 m ; mur de 2,5 m ; cos 40° = 0,766 ; sin 40° = 0,643 ; sin 80° = 0,985 ; cos 20° = 0,94 ; sin 20° = 0,342.

1

Composantes : vₓ = 11×0,766 = 8,43 ≈ 8,4 m·s⁻¹ ; v′₀ = 11×0,643 = 7,07 ≈ 7,1 m·s⁻¹ → x(t) = 8,4·t ; z(t) = −4,9·t² + 7,1·t.

2

Date d'arrivée au mur : t_m = d/vₓ = 10/8,4 = 1,19 s.

3

Hauteur d'impact : z(1,19) = −4,9×1,19² + 7,1×1,19 = −4,9×1,416 + 8,45 = −6,94 + 8,45 = 1,5 m.

4

Comme 1,5 m est inférieur à 2,5 m, le ballon frappe le mur en dessous de son sommet → le tir est arrêté.

5

✅ Vérification : sans mur, la portée vaudrait D = 121×sin 80°/9,8 = 119,2/9,8 = 12,2 m, supérieure à 10 m → le ballon vole bien jusqu'au mur ✓.

6

Tir tendu α = 20° : vₓ = 11×0,94 = 10,3 m·s⁻¹ ; v′₀ = 11×0,342 = 3,8 m·s⁻¹ ; le sol est atteint pour t_sol = 2·v′₀/g = 7,5/9,8 = 0,77 s → x_sol = 10,3×0,77 = 7,9 m, inférieur à 10 m : le ballon rebondit avant le mur.

impact sur le mur à 1,5 m de haut (tir arrêté) ; à 20° : rebond à 7,9 m du tireur

Un tir trop tendu meurt avant le mur : l'angle compte autant que la vitesse.

⚠️ Piège : si le calcul donne z négatif, le ballon toucherait le sol AVANT le mur — c'est un tir manqué.

Cascade et tableau de synthèse

La cascade réutilise les formules du tir à même altitude ; le tableau final récapitule les trois formules du chapitre sur trois angles différents.

✏️ Exercice 5 — Dossier complet : le saut de la moto (★★★)

Données : v₀ = 14 m·s⁻¹ ; α = 20° ; cos 20° = 0,94 ; sin 20° = 0,342 ; sin 40° = 0,643 ; √197,2 = 14,0.

1

Durée du saut : t_vol = 2·v₀·sin α/g = 2×14×0,342/9,8 = 9,58/9,8 = 0,98 s.

2

Longueur du saut : D = v₀²·sin 2α/g = 196×0,643/9,8 = 126,0/9,8 = 12,9 m.

3

✅ Vérification : vₓ = 14×0,94 = 13,2 m·s⁻¹ puis D = vₓ·t_vol = 13,2×0,98 = 12,9 m ✓ (deux chemins, même valeur).

4

Flèche : H = v₀²·sin²α/(2g) = 196×0,342²/19,6 = 196×0,117/19,6 = 22,9/19,6 = 1,2 m.

5

Atterrissage : v′ = v′₀ − g·t_vol = 4,79 − 9,58 = −4,8 m·s⁻¹ = −v′₀ et vₓ = 13,2 m·s⁻¹ → v = √(13,2² + 4,8²) = √(174,2 + 23,0) = √197,2 = 14,0 ≈ 14 m·s⁻¹ = v₀, inclinée de 20° sous l'horizontale.

6

✅ Vérification par la symétrie : départ et arrivée à même altitude → trajectoire symétrique, la vitesse d'arrivée a la même norme que v₀ et l'angle opposé ✓.

t_vol = 0,98 s ; D = 12,9 m ; H = 1,2 m ; atterrissage à 14 m·s⁻¹, 20° sous l'horizontale

La moto reprend au matelas exactement la vitesse qu'elle avait à la rampe.

⚠️ Piège : « même vitesse à l'arrivée » n'est vrai que si l'arrivée est à la même altitude que le départ.
✏️ Exercice 6 — Tableau de synthèse des trois tirs (★★★)

Données : v₀ = 16 m·s⁻¹ ; sin 15° = 0,259 ; sin 45° = 0,707 ; sin 75° = 0,966 ; sin 30° = sin 150° = 0,50 ; sin 90° = 1,00.

1

Portées : D(15°) = 256×0,50/9,8 = 128/9,8 = 13,1 m ; D(45°) = 256×1,00/9,8 = 26,1 m ; D(75°) = 256×sin 150°/9,8 = 256×0,50/9,8 = 13,1 m.

2

✅ Vérification : 15° et 75° sont complémentaires → même portée ✓ ; la plus grande portée est bien celle de 45°.

3

Flèches : H(15°) = 256×0,259²/19,6 = 256×0,0671/19,6 = 17,2/19,6 = 0,88 m ; H(45°) = 256×0,707²/19,6 = 256×0,50/19,6 = 128/19,6 = 6,5 m ; H(75°) = 256×0,966²/19,6 = 256×0,933/19,6 = 238,9/19,6 = 12,2 m.

4

✅ Vérification : pour α = 45°, on a toujours H = D/4 = 26,1/4 = 6,5 m ✓ (propriété générale du tir à 45°).

5

Durées : t(15°) = 2×16×0,259/9,8 = 8,29/9,8 = 0,85 s ; t(45°) = 2×16×0,707/9,8 = 22,6/9,8 = 2,3 s ; t(75°) = 2×16×0,966/9,8 = 30,9/9,8 = 3,2 s.

6

Tableau complété ci-dessous ; conclusions : portée maximale pour α = 45°, angles complémentaires de même portée, flèche et durée de vol croissantes avec α.

7

Lecture du tableau : multiplier α par 5 (de 15° à 75°) multiplie la flèche par 14 environ et la durée par presque 4, mais laisse la portée inchangée pour les angles complémentaires.

D max = 26,1 m à 45° ; H : 0,88 m → 6,5 m → 12,2 m ; t : 0,85 s → 2,3 s → 3,2 s

La portée « passe par un maximum » à 45°, la flèche croît régulièrement avec α.
