01
Définition

Le conjugué : définition

À tout nombre complexe z = a + ib, on associe son conjugué, noté z̄ (lire « z barre ») : on change uniquement le signe de la partie imaginaire, la partie réelle reste inchangée.

Définition du conjugué
z = a + ib  ⟹  z̄ = a − ib
On change le signe de la partie imaginaire, point final.
Exemples de base

z = 3 + 4i → z̄ = 3 − 4i

z = −2 + 5i → z̄ = −2 − 5i

z = i → z̄ = −i

z = 7 → z̄ = 7 (un réel est son propre conjugué !)

Erreur classique

Le conjugué de −2 + 5i est −2 − 5i, et non 2 − 5i. On ne change que le signe de la partie imaginaire : la partie réelle −2 reste telle quelle. C'est l'erreur n°1 sur ce chapitre !

Propriété immédiate : le double conjugué

(z̄)̄ = z
Conjuguer deux fois redonne le nombre de départ : on a changé deux fois le signe de la partie imaginaire.

Le conjugué agit donc comme un miroir : passer deux fois dans le miroir restitue l'original. C'est ce qui fait de la conjugaison une opération « réversible », sans aucune perte d'information.

Pourquoi le conjugué est-il si utile ?

Parce qu'il fabrique des réels à partir de complexes. Le produit z · z̄ est toujours un réel positif (section 5), ce qui permet de faire disparaître les i d'un dénominateur — exactement comme on multiplie par la « quantité conjuguée » pour lever la gêne d'un radical comme (√2 − 1) au dénominateur d'une fraction.

Un peu d'histoire

Le mot conjugué vient du latin conjugare : « unir, marier ensemble ». Les deux nombres z et z̄ sont « mariés » par l'axe des réels, qui joue le rôle de miroir. La notation avec la barre supérieure s'est imposée au XIXe siècle avec Cauchy. Attention : en physique (mécanique quantique, ondes), on écrit souvent z* (étoile) au lieu de z̄ — c'est exactement la même chose.

02
Géométrie

Interprétation géométrique

Si z = a + ib a pour image M(a, b), alors z̄ = a − ib a pour image M'(a, −b). On passe de M à M' en conservant l'abscisse et en changeant le signe de l'ordonnée…

La clé de la partie

M' est le symétrique de M par rapport à l'axe des réels (l'axe horizontal). Le conjugué, c'est une réflexion d'axe (O, réels) — le miroir horizontal du plan complexe.

Conséquences immédiates

  • |z̄| = |z| — une réflexion conserve les distances, donc le module est inchangé.
  • arg(z̄) = −arg(z) (modulo 2π) — l'angle « se reflète » sous l'axe.
  • Un réel est sur le miroir : son conjugué est lui-même (z̄ = z).
  • Un imaginaire pur est « au-dessus ou en dessous » du miroir : son conjugué est son opposé (z̄ = −z).

En forme exponentielle (Partie 2) : si z = r·e^(iθ), alors z̄ = r·e^(−iθ) — même module, argument opposé. En particulier (e^(iθ))̄ = e^(−iθ).

Les quatre associés de z

Autour d'un complexe z gravitent trois compagnons : z̄, −z et −z̄. Leur position dans le plan résume toutes les symétries du chapitre :

✏️ À toi de jouer

Soit z = −1 + i√3. Sans calculer de cosinus, donner module et argument de z̄ sachant que |z| = 2 et arg(z) = 2π/3.

Voir la solution

z̄ = |z| · e^(−i·arg(z)) = 2 · e^(−i·2π/3)

Donc |z̄| = 2 (inchangé) et arg(z̄) = −2π/3 (opposé).

Vérification : z̄ = −1 − i√3 est bien dans le quadrant 3, où l'argument principal est dans ]−π, −π/2[ : −2π/3 y figure ✔

03
Propriétés

Propriétés algébriques

La conjugaison est compatible avec toutes les opérations : elle se « distribue » sur les sommes, produits, quotients et puissances. C'est ce qui la rend si maniable en calcul.

Le tableau des propriétés

conj(z + z') = z̄ + z̄'
Le conjugué d'une somme est la somme des conjugués.
conj(z · z') = z̄ · z̄'
Le conjugué d'un produit est le produit des conjugués.
conj(z / z') = z̄ / z̄'
Le conjugué d'un quotient est le quotient des conjugués (z' ≠ 0).
conj(zⁿ) = (z̄)ⁿ
Cas particulier du produit, pour tout entier n.
Conséquence élégante

Pour toute expression obtenue à partir de z, z' par des opérations algébriques : conjuguer l'expression revient à conjuguer chaque complexe qui la compose. Exemple :

conj(z² + 3z + 1) = (z̄)² + 3z̄ + 1

On conjugue « de l'intérieur », sans tout redévelopper. Gain de temps énorme en exercice.

Démonstration : conjugué d'un produit

Démonstration pas à pas

Posons z = a + ib et z' = c + id.

D'une part : z·z' = (ac − bd) + i(ad + bc) (Partie 1), donc :

conj(z·z') = (ac − bd) − i(ad + bc)

D'autre part : z̄ · z̄' = (a − ib)(c − id) = ac − iad − ibc + i²bd = (ac − bd) − i(ad + bc)

Les deux expressions sont identiques. ∎

Application directe : conjugué d'une expression

Exemple guidé

Calculer conj( (1 + i)(2 − i) ) de deux manières.

Méthode 1 — Calculer puis conjuguer :

(1 + i)(2 − i) = 2 − i + 2i − i² = 3 + i, donc le conjugué est 3 − i.

Méthode 2 — Conjuguer puis calculer :

(1 − i)(2 + i) = 2 + i − 2i − i² = 3 − i ✔

Les deux méthodes donnent le même résultat — comme promis par la propriété du produit !

Exemple avec un quotient

Le conjugué de z = (1 + 2i)/(3 − i) est z̄ = (1 − 2i)/(3 + i) — on conjugue numérateur et dénominateur, sans se fatiguer à simplifier d'abord.

Ce qui ne marche PAS comme tu l'espères

La conjugaison ne commute pas avec le module au sens où : |z̄|² = |z|² oui, mais attention à ne pas confondre (z̄)² (le conjugué élevé au carré) avec (z²)̄… qui sont en fait égaux ((z²)̄ = (z̄)²) ! Le vrai piège est ailleurs : ne jamais écrire conj(z + |z|) = z̄ + |z̄| de tête sans réflexion — ici ça marche (|z̄| = |z|), mais la règle « on conjugue tout à l'intérieur » ne s'applique qu'aux opérations algébriques, pas aux fonctions quelconques.

04
Caractérisations

Caractérisations du réel et de l'imaginaire pur

Le conjugué fournit des tests algébriques redoutables pour savoir si un complexe est réel ou imaginaire pur — sans même connaître ses parties réelle et imaginaire. Ces caractérisations sont massivement utilisées dans les exercices du style « montrer que… ».

Test du réel
z ∈ ℝ ⟺ z̄ = z
Démonstration

Posons z = a + ib. Alors :

z̄ = z ⟺ a − ib = a + ib ⟺ −2ib = 0 ⟺ b = 0 ⟺ z ∈ ℝ ∎

Test de l'imaginaire pur
z ∈ iℝ ⟺ z̄ = −z
Démonstration

z̄ = −z ⟺ a − ib = −a − ib ⟺ 2a = 0 ⟺ a = 0 ⟺ z ∈ iℝ ∎

Géométriquement : z̄ = −z signifie que M et son reflet M' sont aussi symétriques par rapport à O — possible uniquement si M est sur l'axe vertical.

Extraire Re(z) et Im(z) avec le conjugué

Deux formules élégantes qui découlent d'un simple calcul :

z + z̄ = 2·Re(z)   (réel)
a + ib + a − ib = 2a. La somme d'un complexe et de son conjugué est toujours un réel.
z − z̄ = 2i·Im(z)   (imaginaire pur)
a + ib − (a − ib) = 2ib. La différence est toujours un imaginaire pur.
Re(z) = (z + z̄)/2   ·   Im(z) = (z − z̄)/(2i)
Formules d'extraction : elles marchent même quand z est une grosse expression non simplifiée !
Exemple d'application

Soit z = (1 + i)². Sans développer directement, montrons que z est imaginaire pur :

z̄ = ((1 + i)²)̄ = ((1 + i)̄)² = (1 − i)² = 1 − 2i + i² = −2i

Or z = (1 + i)² = 2i, donc z̄ = −z → z est imaginaire pur ✔ (en effet z = 2i).

✏️ À toi de jouer

Montrer que A = (2 + i)(3 − i) + (2 − i)(3 + i) est un réel, puis le calculer.

Voir la solution

Les deux termes sont conjugués l'un de l'autre (on conjugue chaque facteur) : le second vaut (2 + i)(3 − i)̄… plus précisément si B = (2 + i)(3 − i) alors le second terme est B̄.

Or B + B̄ = 2·Re(B) est toujours réel ✔

Calcul : B = 6 − 2i + 3i − i² = 7 + i, donc A = B + B̄ = (7 + i) + (7 − i) = 14.

Boucle avec la Partie 2

Appliquons z + z̄ = 2Re(z) au complexe z = e^(iθ) : on obtient e^(iθ) + e^(−iθ) = 2cos θ, c'est-à-dire cos θ = (e^(iθ) + e^(−iθ))/2 — la formule d'Euler inverse vue en Partie 2 ! Les propriétés du conjugué expliquent les formules trigonométriques.

05
Module

Conjugué et module

C'est ici que le conjugué révèle sa puissance : multiplié par lui-même, il fabricque le carré du module. Cette propriété est le moteur de tous les calculs d'inverses et de quotients.

La formule clé
z · z̄ = |z|²
Le produit d'un complexe par son conjugué est un réel positif
Démonstration

Posons z = a + ib :

z · z̄ = (a + ib)(a − ib) = a² − (ib)² = a² − i²b² = a² + b²

Or |z|² = (√(a² + b²))² = a² + b². Donc z·z̄ = |z|² ∎

Exemples numériques

(3 + 2i)(3 − 2i) = 9 + 4 = 13 = |3 + 2i|²

(1 + i)(1 − i) = 2 = |1 + i|² — on retrouve le calcul de la Partie 1 !

i · (−i) = −i² = 1 = |i|²

Piège majeur : |z|² ≠ z²

z·z̄ (réel positif) et z² (complexe quelconque) sont radicalement différents ! Exemple avec z = 1 + i :

|z|² = z·z̄ = 2 (réel)  mais  z² = 2i (imaginaire pur !)

Seuls les réels et les imaginaires purs créent des confusions possibles. Écris toujours z̄ explicitement avant de simplifier.

La formule de l'inverse

En divisant la formule clé par |z|² (pour z ≠ 0), on obtient l'outil le plus pratique du chapitre :

Formule de l'inverse
1/z = z̄ / |z|²
Multiplier par le conjugué divise le module au carré — le i disparaît du dénominateur
🎓 Application immédiate

Calculer 1/(1 + i) — retrouvons le résultat de la Partie 1 en 3 lignes :

1/(1 + i) = (1 − i)/((1 + i)(1 − i)) = (1 − i)/2

Le conjugué remplace toute la méthode d'identification : plus rapide, moins d'erreurs. La méthode d'identification reste utile pour comprendre pourquoi ça marche ; le conjugué sert à calculer efficacement.

Autres exemples d'inverses

1/(3 + 4i) = (3 − 4i)/25  (car |3 + 4i|² = 25)

1/i = (−i)/|i|² = −i  (résultat à connaître !)

1/(2i) = (−2i)/4 = −i/2

Une équation qui cache un cercle

Interprétation géométrique

Résoudre z · z̄ = 9.

Grâce à la formule clé : z·z̄ = |z|², donc l'équation devient |z|² = 9, soit |z| = 3.

Conclusion : l'ensemble des solutions est le cercle de centre O et de rayon 3 — tous les points à distance 3 de l'origine. Une équation avec conjugué peut cacher un objet géométrique !

En physique

Le produit z·z̄ = |z|² est partout en sciences : en mécanique quantique, la densité de probabilité vaut ψ·ψ̄ = |ψ|² ; en électricité, la puissance moyenne d'un circuit se calcule avec le conjugué du courant ; en traitement du signal, l'énergie d'un signal est la somme de ses |z|². Quand un physicien écrit une « norme au carré », il écrit un complexe fois son conjugué.

06
Applications

Applications classiques

Voici les quatre applications incontournables du conjugué en Terminale. Ce sont des automatismes à acquérir absolument avant la partie sur les équations.

Application 1 — Calculer un inverse

Méthode complète

Exemple : calculer 1/(2 − i).

1. Multiplier haut et bas par le conjugué du dénominateur :

1/(2 − i) = (2 + i)/((2 − i)(2 + i))

2. Le dénominateur devient un réel : (2 − i)(2 + i) = 4 + 1 = 5

3. Résultat : 1/(2 − i) = (2 + i)/5

Vérification : (2 − i) × (2 + i)/5 = 5/5 = 1 ✔

Application 2 — Simplifier un quotient

Méthode complète

Exemple : écrire Z = (3 + i)/(1 − i) sous forme algébrique.

1. Multiplier par le conjugué du dénominateur (1 + i) :

Z = (3 + i)(1 + i) / ((1 − i)(1 + i))

2. Développer le numérateur : 3 + 3i + i + i² = 2 + 4i

3. Dénominateur : 1 + 1 = 2

4. Résultat : Z = (2 + 4i)/2 = 1 + 2i

Vérification : (1 − i)(1 + 2i) = 1 + 2i − i − 2i² = 3 + i ✔

Application 3 — Résoudre une équation contenant z et z̄

Méthode complète

Exemple : résoudre z + 2z̄ = 3 + i.

1. Poser z = x + iy avec x, y réels (donc z̄ = x − iy) :

(x + iy) + 2(x − iy) = 3x − iy

2. Identifier avec 3 + i (méthode de la Partie 1) :

3x = 3 et −y = 1

3. Résoudre : x = 1 et y = −1

✅ Solution : z = 1 − i

Vérification : (1 − i) + 2(1 + i) = 1 − i + 2 + 2i = 3 + i ✔

Pourquoi poser z = x + iy ?

Dès qu'une équation mélange z et z̄, on ne peut plus manipuler z comme une inconnue classique (car z̄ dépend de z). La solution : se ramener à deux réels x et y indépendants, puis identifier. C'est le grand retour de la méthode d'identification.

Application 4 — Montrer qu'un nombre est réel

Méthode complète

Exemple : montrer que A = (2 + i)/(2 − i) + (2 − i)/(2 + i) est réel.

1. Remarquer la structure : le second terme est le conjugué du premier (on conjugue chaque facteur) :

A = B + B̄ avec B = (2 + i)/(2 − i)

2. Utiliser la propriété : B + B̄ = 2·Re(B) est toujours un réel ✔

3. Calculer sa valeur (pour être complet) :

B = (2 + i)²/((2 − i)(2 + i)) = (4 + 4i + i²)/5 = (3 + 4i)/5

A = (3 + 4i)/5 + (3 − 4i)/5 = 6/5 — un réel, comme annoncé 🎯

Le réflexe « conjugué » en résumé
  • i au dénominateur ? → multiplier par le conjugué
  • « Montrer que c'est réel » ? → chercher une structure B + B̄ ou conjuguer l'expression entière et comparer
  • Équation avec z et z̄ ? → poser z = x + iy et identifier
  • Module au carré qui traîne ? → penser à |z|² = z·z̄
07
Méthodologie

Fiches méthodes

Trois procédés à automatiser. Le jour du contrôle, ils doivent venir sans réfléchir.

📋 Méthode 1 — Calculer 1/z avec le conjugué

1
Identifier z = a + ib et son conjugué z̄ = a − ib

attention : seule la partie imaginaire change de signe

2
Appliquer la formule

1/z = z̄/(z·z̄) = z̄/|z|² — calculer a² + b²

3
Écrire la forme algébrique et vérifier

le produit z × (1/z) doit valoir 1

Application

1/(3 + 4i) = (3 − 4i)/(9 + 16) = (3 − 4i)/25

Vérification : (3 + 4i)(3 − 4i)/25 = 25/25 = 1 ✔

📋 Méthode 2 — Simplifier un quotient (a + ib)/(c + id)

1
Multiplier numérateur et dénominateur par le conjugué du dénominateur

c'est-à-dire par c − id

2
Calculer le dénominateur : c² + d² (réel !)

(c + id)(c − id) = c² + d²

3
Développer le numérateur et séparer réel/imaginaire

puis simplifier par le dénominateur

4
Vérifier par produit croisé

(c + id) × résultat = a + ib

Application

Z = (2 + 3i)/(1 − 4i) : on multiplie par (1 + 4i)

Numérateur : (2 + 3i)(1 + 4i) = 2 + 8i + 3i + 12i² = −10 + 11i

Dénominateur : 1 + 16 = 17

Résultat : Z = (−10 + 11i)/17

Vérification : (−10 + 11i)(1 − 4i)/17 = (−10 + 40i + 11i + 44)/17 = (34 + 51i)/17 = 2 + 3i ✔

📋 Méthode 3 — Résoudre une équation contenant z et z̄

1
Poser z = x + iy avec x, y réels

donc z̄ = x − iy

2
Substituer et développer

l'équation devient A(x, y) + i·B(x, y) = c + id

3
Identifier parties réelles et imaginaires

système de deux équations en x, y

4
Résoudre, conclure z = x + iy, et vérifier dans l'équation d'origine

la vérification est obligatoire : elle valide tout le raisonnement

Application

2z + z̄ = 5 − 3i : en posant z = x + iy :

2(x + iy) + (x − iy) = 3x + iy

Identification : 3x = 5 et y = −3

Solution : z = 5/3 − 3i

Vérification : 2(5/3 − 3i) + (5/3 + 3i) = 10/3 + 5/3 − 3i = 5 − 3i ✔

08
Entraînement

Exercices d'entraînement

🎯 QCM — Teste tes réflexes

Q1 — Le conjugué de z = −2 + 5i est :

A) 2 − 5i B) −2 − 5i C) 2 + 5i D) −5 + 2i
Voir la réponse
B) −2 − 5i. On change uniquement le signe de la partie imaginaire. La réponse A est le piège classique (elle change aussi la partie réelle !)

Q2 — z̄ = z si et seulement si :

A) z = 0 B) z est réel C) z est imaginaire pur D) |z| = 1
Voir la réponse
B) z est réel. z̄ = z ⟺ Im(z) = 0 ⟺ z ∈ ℝ. (Pour un imaginaire pur, on aurait z̄ = −z.)

Q3 — Pour tout complexe z, le produit z · z̄ est :

A) égal à z² B) égal à |z|² C) égal à 2·Re(z) D) toujours nul
Voir la réponse
B) |z|². C'est la formule clé de la section 5. Attention : 2·Re(z) correspond à z + z̄, et z² est généralement un vrai complexe !

Q4 — 1/i est égal à :

A) i B) 1 C) −i D) −1
Voir la réponse
C) −i. 1/i = ī/|i|² = −i/1 = −i. Vérification : i × (−i) = −i² = 1 ✔

Q5 — Le conjugué de e^(iπ/3) est :

A) e^(iπ/3) B) e^(i2π/3) C) e^(−iπ/3) D) −e^(iπ/3)
Voir la réponse
C) e^(−iπ/3). Comme z̄ = r·e^(−iθ), conjuguer un complexe de module 1 change l'argument en son opposé. Géométriquement : réflexion par rapport à l'axe des réels.

💪 Exercices d'application

Exercice 1 — Conjugués directs

Donner le conjugué de : z₁ = 3 + 4i, z₂ = −i, z₃ = √2, z₄ = 2i − 1

Voir la solution

z̄₁ = 3 − 4i

z̄₂ = i (le conjugué de −i est i !)

z̄₃ = √2 (réel : inchangé)

z₄ = −1 + 2i donc z̄₄ = −1 − 2i (attention à réécrire sous la forme canonique d'abord !)

Exercice 2 — Inverse

Calculer 1/(2 − i) et 1/(2i).

Voir la solution

1/(2 − i) = (2 + i)/((2 − i)(2 + i)) = (2 + i)/5

1/(2i) = (−2i)/((2i)(−2i)) = (−2i)/4 = −i/2

Vérifications : (2 − i)(2 + i)/5 = 5/5 = 1 ✔ et 2i × (−i/2) = −2i²/2 = 1 ✔

Exercice 3 — Quotient

Écrire sous forme algébrique : Z = (3 + i)/(1 − i)

Voir la solution

On multiplie par (1 + i)/(1 + i) :

Z = (3 + i)(1 + i)/((1 − i)(1 + i)) = (3 + 3i + i + i²)/2 = (2 + 4i)/2

Résultat : Z = 1 + 2i

Vérification : (1 − i)(1 + 2i) = 1 + 2i − i − 2i² = 3 + i ✔

Exercice 4 — Équation avec z et z̄

Résoudre dans ℂ : z + 3z̄ = 4 + 2i

Voir la solution

On pose z = x + iy : (x + iy) + 3(x − iy) = 4x − 2iy

Identification : 4x = 4 et −2y = 2, donc x = 1 et y = −1

Solution : z = 1 − i

Vérification : (1 − i) + 3(1 + i) = 1 − i + 3 + 3i = 4 + 2i ✔

Exercice 5 — Montrer qu'un nombre est réel (défi ★)

Montrer que A = (1 + i)/(1 − i) + (1 − i)/(1 + i) est un réel, puis calculer sa valeur.

Voir la solution

Le second terme est le conjugué du premier : A = B + B̄ avec B = (1 + i)/(1 − i), donc A = 2·Re(B) est réel ✔

Calcul de B : B = (1 + i)²/((1 − i)(1 + i)) = (2i)/2 = i

Donc B = i et B̄ = −i, d'où A = i + (−i) = 0.

A = 0, qui est bien un réel 🎯 (Et au passage : B = i est imaginaire pur — joli contre-exemple à ne pas confondre avec A !)

Exercice 6 — Équation inattendue (défi ★★)

Résoudre dans ℂ : z = iz̄. Que représente l'ensemble des solutions dans le plan complexe ?

Voir la solution

On pose z = x + iy : l'équation devient x + iy = i(x − iy) = ix + y

Identification : x = y et y = x — c'est la même équation ! Tout couple (x, x) convient.

Solutions : z = x + ix = x(1 + i) pour tout x ∈ ℝ

Vérification (avec x = 2) : z = 2 + 2i, iz̄ = i(2 − 2i) = 2i + 2 = 2 + 2i ✔

Interprétation géométrique : les solutions forment la première bissectrice (la droite y = x), c'est-à-dire l'ensemble des points équidistants des deux axes. Une équation de conjugaison peut définir une droite entière, pas seulement un nombre !

📌 Ce qu'il faut retenir
  • Le conjugué de z = a + ib est z̄ = a − ib : seule la partie imaginaire change de signe
  • (z̄)̄ = z — conjuguer deux fois ne change rien
  • Géométriquement, z̄ est le symétrique de z par rapport à l'axe des réels : |z̄| = |z| et arg(z̄) = −arg(z)
  • La conjugaison respecte toutes les opérations : conj(z + z') = z̄ + z̄', conj(z·z') = z̄·z̄', conj(z/z') = z̄/z̄', conj(zⁿ) = (z̄)ⁿ
  • z ∈ ℝ ⟺ z̄ = z  ·  z ∈ iℝ ⟺ z̄ = −z
  • z + z̄ = 2Re(z) et z − z̄ = 2i·Im(z)
  • Formule clé : z · z̄ = |z|² (un réel positif) — mais |z|² ≠ z² !
  • Formule de l'inverse : 1/z = z̄/|z|² — pour simplifier un quotient, multiplier par le conjugué du dénominateur
  • Équation avec z et z̄ ? → poser z = x + iy et identifier
  • z·z̄ = k (k > 0) est le cercle de centre O et de rayon √k
  • On n'écrit jamais √(−1) : on dit « i est le nombre tel que i² = −1 »
