📘 Partie 03 · Équations différentielles

L’équation y' = ay + f(x)

Et si le second membre devenait variable ? Un prélèvement qui évolue avec le temps, une charge proportionnelle à x², un effet périodique : voici l’équation y' = ay + f(x), avec f donnée. La stratégie tient en une phrase : une solution particulière, plus C·e^(ax). Cette partie apprend à fabriquer la solution particulière par identification — pour un polynôme, une exponentielle, un sinus ou un cosinus — puis à conclure avec la condition initiale.

Motivation

Quand le second membre varie

En Partie 2, le second membre était constant : un versement fixe, une température ambiante fixe. Mais la réalité est souvent plus riche : un projet dont les coûts augmentent avec le temps (f(x) = x ou x²), une campagne de vaccination dont l’intensité décroît exponentiellement (f(x) = e^(−x)), une activité qui oscille avec les saisons (f(x) = sin x). L’équation devient y' = ay + f(x).

Bonne nouvelle : la recette générale ne change pas. On garde les solutions homogènes C·e^(ax) de la Partie 1, on cherche une seule solution particulière de l’équation complète, on additionne, puis la condition initiale fixe C. La seule vraie question nouvelle est : comment deviner la bonne forme de solution particulière ? Réponse : on la devine au sens fort du terme — on la pose avec des coefficients inconnus, et l’équation les révèle. C’est l’identification.

Les trois formes à connaître du programme
  • f est un polynôme de degré ≤ 2 → on pose y_p polynôme de même degré.
  • f(x) = e^(kx) avec k ≠ a → on pose y_p = A·e^(kx).
  • f est un mélange (somme) → principe de superposition : traiter chaque morceau, puis additionner.
01
Notion 1 · principe

Le principe : particulière + C·e^(ax)

💡 THÉORÈME — Structure des solutions de y' = ay + f(x)

Soient a un réel non nul et f une fonction continue sur ℝ. Si y_p est une solution particulière de y' = ay + f(x), alors les solutions sur ℝ sont exactement :

y(x) = y_p(x) + C·e^(ax)  où  C ∈ ℝ

c’est-à-dire : solution particulière + solutions de l’équation homogène y' = ay.

Justification du « dans ce sens » (exigible par le calcul) : si y_p et y sont solutions de y' = ay + f(x), alors leur différence z = y − y_p vérifie z' = y' − y_p' = (a·y + f) − (a·y_p + f) = a·(y − y_p) = a·z : la différence résout l’équation homogène, donc z = C·e^(ax) (Partie 1), d’où y = y_p + C·e^(ax).

🔍 Vérification directe — la somme fonctionne

Posons y = y_p + C·e^(ax) où y_p' = a·y_p + f. Alors y' = y_p' + C·a·e^(ax) = a·y_p + f + a·C·e^(ax) = a·(y_p + C·e^(ax)) + f = a·y + f : la somme est bien solution de l’équation complète, pour toute valeur de C. ✅

y' = ay + f(x) ⇔ y = y_p + C·e^(ax)
Le plan de bataille : (1) solutions homogènes C·e^(ax) — connues ; (2) une solution particulière y_p — à fabriquer ; (3) somme ; (4) condition initiale pour C.
⚠️ Une particulière suffit — et on ne la cherche pas « au hasard »

Il faut une seule solution particulière, n’importe laquelle : les autres sont absorbées par le terme C·e^(ax). Et pour la fabriquer, on ne tâtonne pas : on pose une forme dépendant de f (même nature que f), avec des coefficients inconnus à déterminer. C’est l’objet des sections suivantes.

02
Notion 2 · identification polynôme

f polynôme — la méthode d’identification

Quand f est un polynôme de degré ≤ 2, une solution particulière existe parmi les polynômes de même degré. On la pose donc avec des coefficients inconnus, on injecte dans l’équation, et on identifie les coefficients de chaque puissance de x.

🧠 Méthode — Identification avec un polynôme
(1) Poser la forme : f(x) = c (constante) → y_p = A ; f(x) = px + q → y_p = Ax + B ; f(x) = px² + qx + r → y_p = Ax² + Bx + D (on évite la lettre C, réservée à la constante de la solution générale). (2) Dériver y_p. (3) Remplacer dans l’équation et développer. (4) Identifier les coefficients de x², de x et la constante, membre à membre. (5) Résoudre le petit système obtenu.
🧮 Premier exemple — résoudre y' = y + x

Ici a = 1 et f(x) = x (degré 1). Cherchons y_p = Ax + B : alors y_p' = A, et l’équation y_p' = y_p + x s’écrit A = (Ax + B) + x = (A + 1)x + B.

1

Identifier en x. Coefficient de x : à gauche 0, à droite A + 1. Donc 0 = A + 1, soit A = −1.

2

Identifier la constante. Constante : à gauche A, à droite B. Donc A = B, soit B = −1.

3

Solution particulière. y_p = −x − 1. Contrôle : y_p' = −1 et y_p + x = −x − 1 + x = −1 ✓.

4

Solutions générales. y(x) = C·e^x − x − 1, C ∈ ℝ. Contrôle global : y' = C·e^x − 1 et y + x = C·e^x − x − 1 + x = C·e^x − 1 ✓.

⚠️ Poser la forme complète, pas le strict minimum

Pour f(x) = x², pose y_p = Ax² + Bx + D et pas Ax² : en dérivant, un x apparaît, et l’équation en fabrique aussi — il faut de la place pour tous les degrés, jusqu’à la constante. Omettre un degré rend l’identification impossible (ou fausse).

03
Notion 2 · exemple complet

Exemple complet : y’ = 2y + x²

C’est LE calcul modèle de la partie : seconde membre polynôme de degré 2, coefficient a = 2. Refais-le toi-même après lecture, sans regarder.

🧮 Exemple travaillé — résoudre y' = 2y + x²
1

Poser la forme. f(x) = x² : on pose y_p = Ax² + Bx + D, donc y_p' = 2Ax + B.

2

Injecter dans l’équation. On veut y_p' = 2y_p + x², c’est-à-dire 2Ax + B = 2(Ax² + Bx + D) + x² = (2A + 1)x² + 2B·x + 2D.

3

Identifier les coefficients. En x² : 0 = 2A + 1, donc A = −1/2. En x : 2A = 2B, donc B = A = −1/2. En constante : B = 2D, donc D = B/2 = −1/4.

4

Solution particulière. y_p = −x²/2 − x/2 − 1/4. Contrôle obligatoire : y_p' = −x − 1/2, et 2y_p + x² = −x² − x − 1/2 + x² = −x − 1/2 ✓ — les deux membres coïncident.

5

Solutions générales. y(x) = C·e^(2x) − x²/2 − x/2 − 1/4, C ∈ ℝ. Contrôle global : y' = 2C·e^(2x) − x − 1/2 et 2y + x² = 2C·e^(2x) − x² − x − 1/2 + x² = 2C·e^(2x) − x − 1/2 ✓.

Erreur fréquente au Bac

S’arrêter avant le contrôle. L’identification produit des coefficients (A = −1/2, B = −1/2, D = −1/4) obtenus en quatre petits calculs : une erreur de signe n’importe où se voit immédiatement au contrôle final, puisque y_p' doit redonner exactement 2y_p + x². Ce contrôle de la section 03, étape 4, prend trois lignes et sécurise tout l’exercice.

📗 À retenir sur l’identification

L’identification transforme une équation différentielle en petit système linéaire : autant d’équations que de coefficients inconnus (un par puissance de x). Écris les membres dans le même ordre de puissances des deux côtés avant d’identifier : c’est là que se cachent 90 % des erreurs.

Notion 3 · identification exponentielle

f exponentielle e^(kx) avec k ≠ a

Quand f(x) = e^(kx) avec k ≠ a, la solution particulière est de la même famille : y_p = A·e^(kx). L’exponentielle e^(kx) se factorise dans l’équation, et il reste un petit calcul sur A.

🧠 Méthode — Identification avec e^(kx), k ≠ a
(1) Poser y_p = A·e^(kx), donc y_p' = kA·e^(kx). (2) Injecter : kA·e^(kx) = aA·e^(kx) + e^(kx). (3) Factoriser e^(kx) (jamais nul) et simplifier : kA = aA + 1. (4) En déduire A = 1/(k − a), puis écrire les solutions générales y = A·e^(kx) + C·e^(ax).
🧮 Exemple 1 — résoudre y' = y + e^(2x)
1

Poser. Ici a = 1 et k = 2 ≠ 1 ✓ : on pose y_p = A·e^(2x), donc y_p' = 2A·e^(2x).

2

Injecter. 2A·e^(2x) = A·e^(2x) + e^(2x). En simplifiant par e^(2x) : 2A = A + 1, donc A = 1.

3

Solution particulière. y_p = e^(2x). Contrôle : y_p' = 2e^(2x) et y_p + e^(2x) = 2e^(2x) ✓.

4

Solutions générales. y(x) = C·e^x + e^(2x), C ∈ ℝ. Contrôle : y' = C·e^x + 2e^(2x) et y + e^(2x) = C·e^x + 2e^(2x) ✓.

🧮 Exemple 2 — résoudre y' = 3y + e^(−x)

Ici a = 3 et k = −1 ≠ 3 ✓. On pose y_p = A·e^(−x), donc y_p' = −A·e^(−x). L’équation donne −A·e^(−x) = 3A·e^(−x) + e^(−x), d’où −A = 3A + 1, soit −4A = 1 et A = −1/4. Solution particulière : y_p = −e^(−x)/4. Contrôle : y_p' = e^(−x)/4 et 3y_p + e^(−x) = −3e^(−x)/4 + e^(−x) = e^(−x)/4 ✓. Solutions générales : y(x) = C·e^(3x) − e^(−x)/4, C ∈ ℝ.

Erreur fréquente au Bac — le cas interdit k = a

La méthode exige k ≠ a : si k = a, poser A·e^(kx) mène à kA = kA + 1, c’est-à-dire 0 = 1 — absurde, donc aucune solution particulière de cette forme n’existe (la bonne forme, hors programme, fait intervenir x·e^(kx)). Vérifie k ≠ a avant de poser quoi que ce soit, et dis-le sur ta copie.

05
Notion 4 · identification trigo

f trigonométrique — sinus et cosinus

Quand f(x) = sin x ou cos x, il faut poser une solution particulière qui contient les deux : y_p = A·sin x + B·cos x. La raison : dériver un sinus donne un cosinus (et réciproquement), donc les deux familles se mélangent à chaque dérivation — impossible de les séparer.

🧮 Exemple travaillé — résoudre y' = y + cos x
1

Poser. y_p = A·sin x + B·cos x, donc y_p' = A·cos x − B·sin x.

2

Injecter. On veut y_p' = y_p + cos x, c’est-à-dire A·cos x − B·sin x = A·sin x + B·cos x + cos x.

3

Identifier. En cos x : A = B + 1. En sin x : −B = A. En remplaçant : −B = B + 1, donc B = −1/2, puis A = 1/2.

4

Solution particulière. y_p = (1/2)·sin x − (1/2)·cos x. Contrôle : y_p' = (1/2)·cos x + (1/2)·sin x et y_p + cos x = (1/2)·sin x + (1/2)·cos x ✓.

5

Solutions générales. y(x) = C·e^x + (1/2)·sin x − (1/2)·cos x, C ∈ ℝ.

⚠️ Deux inconnues, deux identifications

Avec le sinus et le cosinus, il y a toujours deux coefficients (A et B) et toujours deux identifications (une en sin x, une en cos x). N’essaye pas de poser y_p = A·sin x seul pour f(x) = sin x : la dérivée fait apparaître un cosinus, et l’identification bloque.

Notion 4 · superposition

Superposition — quand f se décompose

💡 Principe de superposition

Si f = f₁ + f₂ et si y₁ est solution particulière de y' = ay + f₁(x) tandis que y₂ est solution particulière de y' = ay + f₂(x), alors y_p = y₁ + y₂ est solution particulière de y' = ay + f₁(x) + f₂(x).

Preuve rapide : (y₁ + y₂)' = (a·y₁ + f₁) + (a·y₂ + f₂) = a·(y₁ + y₂) + f₁ + f₂. ✅ On traite chaque morceau avec sa méthode, puis on additionne.

🧮 Exemple travaillé — résoudre y' = 2y + x + e^(x)
1

Décomposer. f(x) = x + e^(x) = f₁(x) + f₂(x) avec f₁(x) = x (polynôme) et f₂(x) = e^(x) (exponentielle, k = 1 ≠ a = 2 ✓).

2

Morceau polynomial. Pour y' = 2y + x : pose y₁ = Ax + B, y₁' = A. L’équation donne A = 2Ax + 2B + x = (2A + 1)x + 2B ; identification : 0 = 2A + 1 et A = 2B, donc A = −1/2, B = −1/4. D’où y₁ = −x/2 − 1/4. Contrôle : y₁' = −1/2 et 2y₁ + x = −x − 1/2 + x = −1/2 ✓.

3

Morceau exponentiel. Pour y' = 2y + e^(x) : pose y₂ = A·e^(x), y₂' = A·e^(x). L’équation donne A = 2A + 1, donc A = −1. D’où y₂ = −e^(x). Contrôle : y₂' = −e^(x) et 2y₂ + e^(x) = −2e^(x) + e^(x) = −e^(x) ✓.

4

Solution particulière totale. y_p = y₁ + y₂ = −x/2 − 1/4 − e^(x). Contrôle : y_p' = −1/2 − e^(x) et 2y_p + x + e^(x) = −x − 1/2 − 2e^(x) + x + e^(x) = −1/2 − e^(x) ✓.

5

Solutions générales. y(x) = C·e^(2x) − x/2 − 1/4 − e^(x), C ∈ ℝ.

Le principe de superposition n’est pas un gadget : c’est lui qui permet de traiter des seconds membres riches comme x² + e^(2x) ou 3x + cos x sans jamais poser une forme monstrueuse d’un coup. Décompose, résous chaque morceau, additionne, contrôle l’ensemble.

07
Examen · bilan

Exemple type Bac avec condition initiale & bilan

🧮 Exemple type Bac — y' = 2y + x² avec y(0) = 1
1

Solutions générales. Travail déjà fait (section 03) : y(x) = C·e^(2x) − x²/2 − x/2 − 1/4, avec la solution particulière polynomiale contrôlée.

2

Condition initiale. En x = 0 : y(0) = C·e^(0) − 0 − 0 − 1/4 = C − 1/4. On veut y(0) = 1, donc C − 1/4 = 1, soit C = 5/4.

3

Conclusion. L’unique solution est y(x) = (5/4)·e^(2x) − x²/2 − x/2 − 1/4.

4

Vérification complète. Condition : y(0) = 5/4 − 1/4 = 1 ✓. Équation : y' = (5/2)·e^(2x) − x − 1/2 et 2y + x² = (5/2)·e^(2x) − x² − x − 1/2 + x² = (5/2)·e^(2x) − x − 1/2 ✓. Les deux exigences sont satisfaites.

La recette universelle de la partie
y = y_p + C·e^(ax)  ·  avec y_p posée « comme f » puis identifiée
Polynôme → Ax² + Bx + D · exponentielle e^(kx), k ≠ a → A·e^(kx) · sin/cos → A·sin x + B·cos x · somme → superposition.
  • Solutions de y' = ay + f(x) : une particulière + C·e^(ax) — la différence de deux solutions est toujours solution de y' = ay.
  • Identification : poser la forme, dériver, injecter, identifier coefficient par coefficient, résoudre.
  • Hypothèses à citer : a ≠ 0 ; pour l’exponentielle, k ≠ a vérifié avant de poser A·e^(kx).
  • Condition initiale en dernier : écrire y(0) avec la solution générale complète (particulière comprise !), puis en tirer C.
  • Contrôles : redériver y_p seule, puis la solution finale complète avec sa condition initiale.
⚠️ Rédaction type pour l’examen

Quatre blocs attendus : la forme posée (« on cherche une solution particulière de la forme… »), le calcul d’identification complet, la solution générale écrite avec C ∈ ℝ, puis la détermination de C par la condition initiale. Le tout couronné par la vérification. Un bloc manquant = des points perdus, même avec le bon résultat.

Q1 — La solution générale de y' = y + x est :

A) y = C·e^x − x − 1B) y = C·e^x + x + 1C) y = C·e^x − xD) y = C·e^(2x) − x − 1
Voir la réponse
A) y = C·e^x − x − 1. On pose y_p = Ax + B : l’identification donne 0 = A + 1 et A = B, donc y_p = −x − 1, plus l’homogène C·e^x. Contrôle : y' = C·e^x − 1 et y + x = C·e^x − x − 1 + x = C·e^x − 1 ✓.

Q2 — Pour chercher une solution particulière de y' = y + e^(2x), on pose :

A) y_p = A·e^(2x)B) y_p = A·x·e^(2x)C) y_p = A·e^xD) y_p = Ax + B
Voir la réponse
A) y_p = A·e^(2x). Le second membre est e^(2x) avec k = 2 ≠ a = 1 : on pose la même forme. L’identification donne 2A = A + 1, soit A = 1 et y_p = e^(2x). La forme B (avec un x en facteur) ne sert que dans le cas interdit k = a, hors programme.

Q3 — Pour y' = 2y + x², la solution particulière polynomiale est :

A) y_p = −x²/2 − x/2 − 1/4B) y_p = x²/2 + x/2 + 1/4C) y_p = −x²/2D) y_p = −x²/4
Voir la réponse
A) y_p = −x²/2 − x/2 − 1/4. L’identification (0 = 2A + 1 ; 2A = 2B ; B = 2D) donne A = B = −1/2 et D = −1/4. Contrôle : y_p' = −x − 1/2 et 2y_p + x² = −x² − x − 1/2 + x² = −x − 1/2 ✓. Les options C et D omettent des degrés : l’identification ne peut alors pas aboutir.
📌 Ce qu’il faut retenir
  • [principe] Solutions de y' = ay + f(x) : y = y_p + C·e^(ax) — une solution particulière plus l’homogène ; la différence de deux solutions résout y' = ay
  • [polynome] f polynôme de degré ≤ 2 → poser y_p polynôme complet de même degré (Ax² + Bx + D) et identifier coefficient par coefficient
  • [exponentielle] f(x) = e^(kx) avec k ≠ a (à vérifier !) → poser y_p = A·e^(kx) ; l’identification donne A = 1/(k − a)
  • [trigo] f(x) = sin x ou cos x → poser y_p = A·sin x + B·cos x (les deux !) et identifier en sin x et en cos x
  • [superposition] Si f = f₁ + f₂ : particulière de chaque morceau, puis y_p = y₁ + y₂ — contrôler la somme finale
  • [methode] Ordre imposé : homogène → particulière (identification) → somme → condition initiale en dernier → vérification par redérivation
