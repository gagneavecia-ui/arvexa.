✏️ Exercice 1 — Quatre calculs express (★)

Données : 1) v = 340 m·s⁻¹, f = 500 Hz ; 2) 500 Hz et 504 Hz ; 3) L = 1,20 m, 4 fuseaux, v = 24 m·s⁻¹ ; 4) δ = 2,5λ.

1

λ = v/f = 340/500 = 0,68 m.

2

f_b = |504 − 500| = 4 Hz.

3

λ = 2L/n = 2 × 1,20/4 = 0,60 m ; puis f = v/λ = 24/0,60 = 40 Hz.

4

δ = 2,5λ = (2 + ½)·λ : la condition destructive est vérifiée → interférence DESTRUCTIVE.

λ = 0,68 m ; f_b = 4 Hz ; λ = 0,60 m ; f = 40 Hz
δ = 2,5λ → interférence destructive.

⚠️ Piège : deux formules pour λ selon le contexte : λ = v/f pour une onde progressive, λ = 2L/n pour une corde de Melde. Choisis selon les données.

✏️ Exercice 2 — Contrôler l'accord d'un piano (★★)

Données : f₁ = 435 Hz ; 3 battements par seconde ; les battements diminuent quand on tend la corde.

1

f_b = 3 Hz (3 maxima d'intensité par seconde).

2

|f₂ − 435| = 3 donne deux hypothèses : f₂ = 435 − 3 = 432 Hz ou f₂ = 435 + 3 = 438 Hz.

3

Tendre la corde augmente f₂. Si f₂ = 438 Hz, f_b = |f₂ − 435| AUGMENTerait ; or f_b diminue : f₂ se rapproche de 435 Hz par valeurs inférieures, donc f₂ = 432 Hz.

4

Période des battements : T_b = 1/f_b = 1/3 ≈ 0,33 s.

f₂ = 432 Hz ; T_b ≈ 0,33 s
Le test (tendre → battements ↓) tranche entre 432 et 438 Hz.

⚠️ Piège : sans l'expérience du test, les deux hypothèses seraient également valables : c'est le SENS de variation des battements qui décide.

✏️ Exercice 3 — Deux haut-parleurs synchrones (★★)

Données : f = 1 000 Hz ; v = 340 m·s⁻¹ ; M : 1,87 m et 1,19 m ; N : 1,36 m et 0,85 m ; M′ : δ = 0,34 m.

1

Longueur d'onde : λ = v/f = 340/1 000 = 0,34 m.

2

En M : δ = |1,87 − 1,19| = 0,68 m ; δ/λ = 0,68/0,34 = 2 : δ = 2λ → interférence CONSTRUCTIVE, le signal est amplifié (amplitude maximale).

3

En N : δ = |1,36 − 0,85| = 0,51 m ; δ/λ = 0,51/0,34 = 1,5 : δ = (1 + ½)·λ → interférence DESTRUCTIVE, le signal est annulé.

4

En M′ : δ = 0,34 m = 1λ = k·λ avec k = 1 → interférence CONSTRUCTIVE : signal amplifié.

λ = 0,34 m ; M : constructif ; N : destructif ; M′ : constructif
Rapports δ/λ = 2 ; 1,5 ; 1.

⚠️ Piège : calcule δ/λ et regarde si tu tombes sur un entier (constructif) ou un demi-entier (destructif) ; arrondis le plus tard possible.

✏️ Exercice 4 — Corde de Melde : étude complète (★★★)

Données : L = 1,20 m ; n = 4 fuseaux à f = 60 Hz ; puis f′ = 75 Hz.

1

λ = 2L/n = 2 × 1,20/4 = 0,60 m ; v = λ·f = 0,60 × 60 = 36 m·s⁻¹.

2

Distance entre deux nœuds consécutifs : d = λ/2 = 0,15 m ; nœuds : n + 1 = 5 ; ventres : 4.

3

Un régime stationnaire impose L = n·λ/2 avec λ = v/f_n : f_n = n·v/(2L) = n × 36/2,40 = 15·n Hz : 15 ; 30 ; 45 ; 60 ; 75 Hz.

4

75 Hz = 15 × 5 → n = 5 fuseaux ; λ′ = 2L/5 = 2,40/5 = 0,48 m ; vérification : v = λ′·f′ = 0,48 × 75 = 36 m·s⁻¹ ✓.

λ = 0,60 m ; v = 36 m·s⁻¹ ; f_n = 15·n Hz
À 75 Hz : 5 fuseaux, λ′ = 0,48 m.

⚠️ Piège : la célérité v est fixée par la corde (tension, masse linéique) : elle ne change PAS quand f change ; seule λ et le nombre de fuseaux s'adaptent.

✏️ Exercice 5 — Lecture d'une figure : trois fuseaux (★★★)

Données : figure : 3 fuseaux ; L = 0,60 m ; f = 90 Hz ; puis f′ = 120 Hz et L = 1,20 m.

1

λ = 2L/n = 2 × 0,60/3 = 0,40 m ; v = λ·f = 0,40 × 90 = 36 m·s⁻¹.

2

À f′ = 120 Hz (v inchangée) : λ′ = v/f′ = 36/120 = 0,30 m ; n′ = 2L/λ′ = 1,20/0,30 = 4 fuseaux.

3

Corde de longueur 1,20 m à 90 Hz : λ reste 0,40 m (v et f inchangées), donc n″ = 2 × 1,20/0,40 = 6 fuseaux.

4

Non : v = λ·f est fixée par le milieu (tension, masse linéique de la corde) ; changer f change λ, mais pas v.

λ = 0,40 m ; v = 36 m·s⁻¹ ; n′ = 4 ; n″ = 6
λ′ = 0,30 m à 120 Hz ; λ inchangée quand L change.

⚠️ Piège : ne modifie pas v quand f change : c'est LE piège de l'exercice ; ici v = 36 m·s⁻¹ dans toutes les questions, seule λ et le nombre de fuseaux varient.

📌 Mémo : battements : f_b = |f₂ − f₁| ; interférences : δ = |S₂M − S₁M| ; Melde : L = n·λ/2, f_n = n·v/(2L), distance entre nœuds λ/2.
