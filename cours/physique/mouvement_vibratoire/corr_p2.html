✏️ Exercice 1 — Quatre calculs express (★)

Données : 1) ω = 100π rad·s⁻¹ ; 2)-3) xₘ = 4,0 cm et f = 25 Hz ; 4) xₘ = 2,5 cm et T = 5,0 ms.

1

T = 2π/ω = 2π/100π = 0,020 s ; f = 1/T = 50 Hz.

2

ω = 2π·f = 50π ≈ 157 rad·s⁻¹ ; vₘ = ω·xₘ = 157 × 0,040 = 6,28 ≈ 6,3 m·s⁻¹.

3

aₘ = ω²·xₘ = (157)² × 0,040 = 987 ≈ 9,9 × 10² m·s⁻².

4

T = 5,0 ms = 0,0050 s : ω = 2π/T = 2π/0,0050 = 1 257 ≈ 1,3 × 10³ rad·s⁻¹ ; f = 1/T = 200 Hz.

1) T = 0,020 s, f = 50 Hz ; 4) ω ≈ 1,3 × 10³ rad·s⁻¹
vₘ ≈ 6,3 m·s⁻¹ ; aₘ ≈ 9,9 × 10² m·s⁻².

⚠️ Piège : T = 5,0 ms = 0,0050 s : convertis toujours en secondes avant de diviser 2π par T.

✏️ Exercice 2 — Étude complète d'un vibreur (★★)

Données : T = 0,20 s ; xₘ = 5,0 cm = 0,050 m ; lâché sans vitesse initiale depuis x = +xₘ.

1

f = 1/T = 5,0 Hz ; ω = 2π/T = 10π ≈ 31,4 rad·s⁻¹.

2

À t = 0 : x(0) = xₘ donne cos(φ) = 1, donc φ = 0 ; x(t) = 5,0·cos(10π·t) cm.

3

Valeurs utiles : vₘ = ω·xₘ = 31,4 × 0,050 = 1,57 m·s⁻¹ ; aₘ = ω²·xₘ = 987 × 0,050 = 49,3 m·s⁻². D'où le tableau :

4

Pour x = −2,0 cm = −0,020 m : a = −ω²·x = −987 × (−0,020) = +19,7 ≈ +20 m·s⁻².

5

Bilan : vₘ = 1,6 m·s⁻¹ et aₘ = 49 m·s⁻².

x(t) = 5,0·cos(10π·t) cm ; vₘ ≈ 1,6 m·s⁻¹ ; aₘ ≈ 49 m·s⁻²
v est maximale en x = 0 ; a est maximale en x = ±xₘ.

⚠️ Piège : ne remplis pas le tableau au hasard : x et v s'échangent (extremum ↔ zéro) et a = −ω²·x change de signe avec x.

✏️ Exercice 3 — Mesure de fréquence à l'oscilloscope (★★)

Données : 0,5 V/div ; 2 ms/div ; u = 100·x (u en V, x en m) ; u(0) = 0, courbe montante.

1

T = 5 div × 2 ms/div = 10 ms = 0,010 s ; f = 1/T = 100 Hz.

2

Amplitude de la tension : uₘ = 4 div × 0,5 V/div = 2,0 V.

3

u(0) = 0 et courbe montante → φ = −π/2 ; avec ω = 2π·f = 628 rad·s⁻¹ : u(t) = 2,0·cos(628·t − π/2) V.

4

Le capteur impose x = u/100, donc xₘ = uₘ/100 = 2,0/100 = 0,020 m = 2,0 cm.

5

Vitesse maximale : vₘ = ω·xₘ = 628 × 0,020 = 12,6 m·s⁻¹.

f = 100 Hz ; uₘ = 2,0 V ; xₘ = 2,0 cm ; vₘ ≈ 12,6 m·s⁻¹
u(t) = 2,0·cos(628·t − π/2) V.

⚠️ Piège : pour ω, utilise ω = 2π·f avec f = 100 Hz, ou convertis T en secondes : 2π/10 (au lieu de 2π/0,010) donnerait un résultat 1 000 fois trop petit.

✏️ Exercice 4 — Problème type Bac : la lame vibrante (★★★)

Données : 1 cm/div ; 2,5 ms/div ; à t = 0 la courbe descend.

1

xₘ = 3 div × 1 cm/div = 3,0 cm = 0,030 m ; T = 4 div × 2,5 ms/div = 10 ms = 0,010 s ; f = 100 Hz.

2

Pulsation : ω = 2π·f = 200π ≈ 628 rad·s⁻¹.

3

x(0) = 0 → φ = ±π/2 ; la courbe descend → v(0) < 0 → −xₘ·ω·sin(φ) < 0 → sin(φ) > 0 → φ = +π/2.

4

Équation horaire : x(t) = 3,0·cos(200π·t + π/2) cm, avec t en s.

5

vₘ = ω·xₘ = 628 × 0,030 = 18,8 ≈ 19 m·s⁻¹ ; aₘ = ω²·xₘ = (628)² × 0,030 = 11 844 ≈ 1,2 × 10⁴ m·s⁻².

6

x = +xₘ exige cos(ω·t + π/2) = 1, donc ω·t = 3π/2 pour le premier retour : t₁ = 3T/4 = 7,5 ms.

x(t) = 3,0·cos(200π·t + π/2) cm ; t₁ = 7,5 ms
vₘ ≈ 19 m·s⁻¹ ; aₘ ≈ 1,2 × 10⁴ m·s⁻².

⚠️ Piège : ici φ = +π/2 (courbe descendante) : c'est l'opposé de l'exercice 3 de la partie 01. Vérifie toujours le sens de la courbe à t = 0.

✏️ Exercice 5 — Deux vibreurs comparés (★★★)

Données : A : T = 20 ms, xₘ = 3,0 cm ; B : x(t) = 2,0·cos(200π·t) cm.

1

f(A) = 1/T = 50 Hz ; pour B : ω = 200π rad·s⁻¹, donc f(B) = ω/2π = 100 Hz : B vibre deux fois plus vite.

2

ω(A) = 2π/T = 100π ≈ 314 rad·s⁻¹ ; vₘ(A) = 314 × 0,030 = 9,4 m·s⁻¹ ; vₘ(B) = 628 × 0,020 = 12,6 m·s⁻¹ : B possède la plus grande vitesse maximale.

3

aₘ(A) = (314)² × 0,030 = 2 961 ≈ 3,0 × 10³ m·s⁻² ; aₘ(B) = (628)² × 0,020 = 7 896 ≈ 7,9 × 10³ m·s⁻².

4

Pour B : x = 0 exige cos(200π·t) = 0 ; la vitesse v = −xₘ·ω·sin(200π·t) doit être positive, donc sin(200π·t) < 0 : on garde 200π·t = 3π/2, soit t = 3T/4 = 7,5 ms.

f(A) = 50 Hz ; f(B) = 100 Hz ; vₘ(B) ≈ 12,6 m·s⁻¹
aₘ(A) ≈ 3,0 × 10³ m·s⁻² ; aₘ(B) ≈ 7,9 × 10³ m·s⁻² ; t = 7,5 ms.

⚠️ Piège : une vitesse positive en x = 0 exige ω·t = 3π/2 (et non π/2) : à π/2 le point passe en descendant, avec une vitesse négative.

📌 Mémo : lecture d'un écran : valeur = nombre de divisions × sensibilité ; T = divisions × base de temps. Phase à l'origine : courbe au maximum → φ = 0 ; coupe en montant → φ = −π/2 ; coupe en descendant → φ = +π/2.
