✏️ Exercice 1 — Dosage pH-métrique d’un acide chlorhydrique ★★★

Données : V₁ = 20,0 mL d’acide (C₁ inconnue) ; C₂ = 0,020 mol·L⁻¹ de soude (burette) ; courbe pH = f(V) de l’énoncé ; Kₑ = 1,0 × 10⁻¹⁴ à 25 °C.

1

Équation : H₃O⁺ + OH⁻ → 2 H₂O ; équilibre : H : 4 = 4 ; O : 2 = 2 ; charges : (+1) + (−1) = 0 et 0 ✅.

2

Lecture : à V = 0, la courbe part de pH = 2,0 ; acide fort → pH = −log C₁, donc C₁ ≈ 10⁻²,⁰ = 1,0 × 10⁻² mol·L⁻¹ (première estimation).

3

Le saut de pH est symétrique autour de pH = 7,0 ; son milieu, le point E, se projette sur l’axe des volumes à Vₑ = 10,0 mL.

4

À l’équivalence : n(OH⁻)versé = n(H₃O⁺)initial, soit C₂Vₑ = C₁V₁ → C₁ = C₂ × Vₑ / V₁ = 0,020 × 10,0 ÷ 20,0 = 0,20 ÷ 20,0 = 0,010 mol·L⁻¹.

5

2ᵉ méthode (question 2) : l’estimation par le pH initial donnait 1,0 × 10⁻² mol·L⁻¹ = 0,010 mol·L⁻¹ : les deux méthodes concordent ✅.

6

À l’équivalence : ni H₃O⁺ ni OH⁻ en excès, ions Na⁺ et Cl⁻ spectateurs → solution neutre, pH = 7,0 à 25 °C : c’était prévisible pour un dosage acide fort / base forte.

Vₑ = 10,0 mL · C₁ = 0,010 mol·L⁻¹ · pH(E) = 7,0
Le pH initial lu sur la courbe valide le résultat du calcul d’équivalence.
⚠️ Piège : Vₑ se lit sur l’axe des volumes (10,0 mL) ; « pH = 7 » est l’ORDONNÉE du milieu du saut, pas son abscisse.
✏️ Exercice 2 — Titrage inverse : une soude de concentration inconnue ★★★

Données : V₁ = 25,0 mL de soude (bécher, C₁ inconnue) ; C₂ = 0,020 mol·L⁻¹ d’acide (burette) ; Vₑ = 15,0 mL ; log 1,2 ≈ 0,08 ; Kₑ = 1,0 × 10⁻¹⁴ (25 °C).

1

Équation : H₃O⁺ + OH⁻ → 2 H₂O.

2

Ici la solution titrante (burette) est l’ACIDE : à l’équivalence, n(H₃O⁺)versé = n(OH⁻)initial, soit C₂Vₑ = C₁V₁.

3

1ʳᵉ méthode : C₁ = C₂ × Vₑ / V₁ = 0,020 × 15,0 ÷ 25,0 = 0,30 ÷ 25,0 = 0,012 mol·L⁻¹.

4

2ᵉ méthode : n(H₃O⁺)versé = 0,020 × 15,0 × 10⁻³ = 3,0 × 10⁻⁴ mol ; puis C₁ = n / V₁ = 3,0 × 10⁻⁴ ÷ 25,0 × 10⁻³ = 0,012 mol·L⁻¹ : identique ✅.

5

pH initial : [OH⁻] = C₁ = 1,2 × 10⁻² mol·L⁻¹ → pH = 14 + log(1,2 × 10⁻²) = 14 − 2,00 + 0,08 = 12,08 ≈ 12,1.

6

Contrôle du pH initial : pOH = −log(1,2 × 10⁻²) = 2,00 − 0,08 = 1,92 → pH = 14 − 1,92 = 12,08 ✅ identique.

7

À l’équivalence : pH = 7,0 dans les deux sens du dosage ; à 25 °C, l’équivalence d’un couple acide fort / base forte est toujours neutre.

C₁ = 0,012 mol·L⁻¹ · pH initial ≈ 12,1 · pH(E) = 7,0
La relation d’équivalence s’écrit avec la solution titrante du côté versé, quelle que soit sa nature.
⚠️ Piège : indices inversés ! L’inconnue est dans le BÉCHER : C₂Vₑ = C₁V₁ ; écrire C₁ = C₂ × V₁ / Vₑ donnerait 0,033 mol·L⁻¹, valeur fausse.

✏️ Exercice 3 — Contrôle qualité d’un déboucheur de canalisation ★★★

Données : dilution F = 100 (10,0 mL → 1000,0 mL) ; pH(diluée) = 12,0 ; Kₑ = 1,0 × 10⁻¹⁴ (25 °C).

1

Sécurité : soude très concentrée et corrosive → gants et lunettes obligatoires. Protocole : prélever 10,0 mL de déboucheur à la pipette jaugée, verser dans la fiole jaugée de 1000,0 mL, rincer la pipette dans la fiole, compléter au trait de jauge avec de l’eau distillée, puis homogénéiser.

2

pH = 12,0 → [H₃O⁺] = 10⁻¹²,⁰ = 1,0 × 10⁻¹² mol·L⁻¹ ; puis [OH⁻] = Kₑ / [H₃O⁺] = 1,0 × 10⁻¹⁴ ÷ 1,0 × 10⁻¹² = 1,0 × 10⁻² mol·L⁻¹.

3

2ᵉ méthode (contrôle) : [H₃O⁺] × [OH⁻] = 10⁻¹² × 10⁻² = 10⁻¹⁴ = Kₑ ✅.

4

1ʳᵉ méthode : la dilution divise les concentrations par F, donc C = F × [OH⁻]diluée = 100 × 1,0 × 10⁻² = 1,0 mol·L⁻¹.

5

2ᵉ méthode : C × 10,0 = 1,0 × 10⁻² × 1000,0 → C = 1,0 × 10⁻² × 1000,0 ÷ 10,0 = 1,0 mol·L⁻¹ : identique ✅.

6

pH du commercial : [OH⁻] = 1,0 mol·L⁻¹ → pH = 14 + log(1,0) = 14,00 ; contrôle : [H₃O⁺] = 1,0 × 10⁻¹⁴ mol·L⁻¹ → pH = 14,00 ✅. Mesure directe impossible : pH = 14,00, hors plage utile, et l’électrode serait attaquée.

7

Équation : NaOH → Na⁺ + OH⁻ ; Na : 1 = 1 ; O : 1 = 1 ; H : 1 = 1 ; charges : 0 = (+1) + (−1) ✅.

8

Cohérence : C = 1,0 mol·L⁻¹ (pH 14,00) : produit très basique, capable de décomposer les graisses → usage de déboucheur plausible.

[OH⁻]diluée = 1,0 × 10⁻² mol·L⁻¹ · C = 1,0 mol·L⁻¹ · pH(commercial) = 14,00
La solution commerciale est 100 fois plus concentrée que la solution diluée.
⚠️ Piège : la dilution DIVISE les concentrations par F : c’est le commercial qui est 100 fois plus concentré que la diluée, pas l’inverse.
✏️ Exercice 4 — Quatre solutions à classer ★★★

Données : S₁ : HCl, 1,0 × 10⁻³ mol·L⁻¹ ; S₂ : NaOH, 1,0 × 10⁻³ mol·L⁻¹ ; S₃ : HCl, 5,0 × 10⁻⁴ mol·L⁻¹ ; S₄ : NaOH, 2,0 × 10⁻² mol·L⁻¹ ; log 2 ≈ 0,30 ; log 5 ≈ 0,70 ; Kₑ = 1,0 × 10⁻¹⁴ (25 °C).

1

pH(S₁) = −log(1,0 × 10⁻³) = 3,00 ; contrôle : 10⁻³,⁰⁰ = 1,0 × 10⁻³ mol·L⁻¹ ✅.

2

pH(S₂) = 14 + log(1,0 × 10⁻³) = 11,00 ; contrôle : [H₃O⁺] = 1,0 × 10⁻¹¹ mol·L⁻¹ → pH = 11,00 ✅.

3

pH(S₃) = −log(5,0 × 10⁻⁴) = 4,00 − 0,70 = 3,30 ; contrôle : [OH⁻] = 1,0 × 10⁻¹⁴ ÷ 5,0 × 10⁻⁴ = 2,0 × 10⁻¹¹ mol·L⁻¹ → pH = 14 − 11 + 0,30 = 3,30 ✅.

4

pH(S₄) = 14 + log(2,0 × 10⁻²) = 14 − 2,00 + 0,30 = 12,30 ; contrôle : [H₃O⁺] = 1,0 × 10⁻¹⁴ ÷ 2,0 × 10⁻² = 5,0 × 10⁻¹³ mol·L⁻¹ → pH = 13,00 − 0,70 = 12,30 ✅.

5

Classement : S₁ (3,00) < S₃ (3,30) < S₂ (11,00) < S₄ (12,30) ; pour chaque solution, [H₃O⁺]·[OH⁻] = 1,0 × 10⁻¹⁴ ✅.

6

Plus proche de 7,0 : S₃, avec un écart de 7,00 − 3,30 = 3,70, devant S₂ (écart 11,00 − 7,00 = 4,00).

7

Mélange 10,0 mL de S₁ et 10,0 mL de S₂ : n(H₃O⁺) = 1,0 × 10⁻³ × 10,0 × 10⁻³ = 1,0 × 10⁻⁵ mol et n(OH⁻) = 1,0 × 10⁻⁵ mol : quantités égales → réaction totale H₃O⁺ + OH⁻ → 2 H₂O, aucun excès → solution neutre, pH = 7,0.

pH : S₁ 3,00 · S₂ 11,00 · S₃ 3,30 · S₄ 12,30 · mélange S₁ + S₂ : pH = 7,0
Chaque pH est contrôlé par une seconde méthode avant le classement.
⚠️ Piège : log(5,0 × 10⁻⁴) = 0,70 − 4,00 = −3,30 (et non 4,00 − 0,70) : le logarithme d’un nombre plus petit que 1 est négatif.
✏️ Exercice 5 — Dossier complet : de la dilution au dosage ★★★

Données : C₀ = 0,50 mol·L⁻¹ ; 10,0 mL → 100,0 mL (S₂) ; V₁ = 20,0 mL de soude ; Vₑ = 16,0 mL ; log 2 ≈ 0,30 ; log 2,5 ≈ 0,40 ; log 4 ≈ 0,60 ; log 5 ≈ 0,70 ; Kₑ = 1,0 × 10⁻¹⁴ (25 °C).

1

F = 100,0 ÷ 10,0 = 10.

2

1ʳᵉ méthode : C₂ = C₀ / F = 0,50 ÷ 10 = 0,050 mol·L⁻¹ ; 2ᵉ méthode : C₂ = C₀ × 10,0 ÷ 100,0 = 0,050 mol·L⁻¹ ✅ identique.

3

pH(S₂) = −log(5,0 × 10⁻²) = 2,00 − 0,70 = 1,30 ; contrôle : [OH⁻] = 1,0 × 10⁻¹⁴ ÷ 5,0 × 10⁻² = 2,0 × 10⁻¹³ mol·L⁻¹ → pOH = 13,00 − 0,30 = 12,70 → pH = 14 − 12,70 = 1,30 ✅.

4

Équation de dosage : H₃O⁺ + OH⁻ → 2 H₂O.

5

1ʳᵉ méthode : C₁ = C₂ × Vₑ / V₁ = 0,050 × 16,0 ÷ 20,0 = 0,80 ÷ 20,0 = 0,040 mol·L⁻¹ ; 2ᵉ méthode : n(H₃O⁺)versé = 0,050 × 16,0 × 10⁻³ = 8,0 × 10⁻⁴ mol puis C₁ = 8,0 × 10⁻⁴ ÷ 20,0 × 10⁻³ = 0,040 mol·L⁻¹ ✅ identique.

6

pH initial de la soude : [OH⁻] = C₁ = 4,0 × 10⁻² mol·L⁻¹ → pH = 14 + log(4,0 × 10⁻²) = 14 − 2,00 + 0,60 = 12,60 ; contrôle : [H₃O⁺] = 1,0 × 10⁻¹⁴ ÷ 4,0 × 10⁻² = 2,5 × 10⁻¹³ mol·L⁻¹ → pH = 13,00 − 0,40 = 12,60 ✅.

7

À l’équivalence : pH = 7,0 à 25 °C (dosage acide fort / base forte).

F = 10 · C₂ = 0,050 mol·L⁻¹ · C₁ = 0,040 mol·L⁻¹ · pH(soude) = 12,60 · pH(E) = 7,0
Le dossier enchaîne dilution, formule de la base forte et relation d’équivalence sans rupture de cohérence.
⚠️ Piège : C₀ = 0,50 mol·L⁻¹ mais C₂ = 0,050 mol·L⁻¹ : un seul zéro de différence, et toute la suite du dosage est faussée.
📌 À retenir pour le Bac
  • Vₑ se lit au milieu du saut de pH ; à 25 °C, pH = 7,0 à l’équivalence d’un dosage acide fort / base forte.
  • Équivalence : n(dosé) = n(versé), soit C₁V₁ = C₂Vₑ — vérifier qui est dans la burette.
  • Chaque résultat se contrôle deux fois : formule du cours, puis Kₑ, pH initial ou retour arrière.
  • Acide fort : pH = −log C ; base forte : pH = 14 + log C ; unité mol·L⁻¹ partout.
