La méthode complète en 4 étapes

Toute question du type « déterminer la solution qui vérifie y(x₀) = y₀ » se traite avec la même procédure, quel que soit le type d'équation :

1

Forme générale : résoudre l'équation différentielle — la solution contient une constante C (selon le type : C·e^(a·x), C·e^(a·x) − b/a ou yₚ(x) + C·e^(a·x)).

2

Condition : écrire la condition initiale y(x₀) = y₀ telle quelle, sans la réinterpréter.

3

Constante C : substituer x₀ dans la forme générale, obtenir une équation en C, la résoudre.

4

Solution unique : remplacer C par sa valeur et énoncer la solution — puis la vérifier (condition initiale ET équation, en dérivant).

Forme générale → Condition y(x₀) = y₀ → Constante C → Solution unique
Le théorème d'existence-unicité garantit que cette procédure donne exactement une réponse : ni échec, ni doublon. Dans le cas y' = ay avec x₀ = 0, on a directement C = y₀.
🧮 Exemple éclair — y' = 2y avec y(0) = 5
1

Forme générale : y(x) = C·e^(2x) (partie 1, avec a = 2).

2

Condition : y(0) = 5.

3

y(0) = C·e^0 = C = 5, donc C = 5.

4

Solution unique : y(x) = 5·e^(2x). Vérification : y(0) = 5·e^0 = 5 ✅ et y' = 10·e^(2x) = 2·(5·e^(2x)) = 2·y ✅

Tableau de synthèse des 3 types d'équations

Le tableau à connaître par cœur — ou mieux, à savoir reconstruire en comprenant d'où vient chaque ligne :

ÉquationSolution générale (C ∈ ℝ)Clé de résolution
y' = ay (a ≠ 0) y(x) = C·e^(a·x) directe (partie 1) ; C = y₀ si y(0) = y₀
y' = ay + b (a ≠ 0) y(x) = C·e^(a·x) − b/a particulière constante yₚ = −b/a (partie 2)
y' = ay + f(x) y(x) = yₚ(x) + C·e^(a·x) yₚ par identification (partie 3)
  • Les trois solutions contiennent une seule constante libre C multipliant e^(a·x).
  • Le second membre n'apparaît jamais multiplié par C : il est entièrement absorbé par la solution particulière.
  • Les deux premières lignes sont des cas particuliers de la troisième (f = 0, puis f = b).
  • Dans tous les cas, la condition initiale se traite après l'écriture de la forme générale.
⚠️ Auto-test en 30 secondes

Sans regarder le tableau : quelle est la solution générale de y' = 4y − 3 ? Réponse attendue : y(x) = C·e^(4x) + 3/4 (car yₚ = −b/a = 3/4). Si tu as écrit −3/4 ou oublié le terme constant, retourne à la partie 2, section 02.

Radioactivité, demi-vie et croissance bactérienne

Application 1 — La désintégration radioactive. Un échantillon radioactif contient N(t) noyaux instables à l'instant t. Chaque noyau se désintègre indépendamment des autres : la vitesse de disparition est proportionnelle au nombre de noyaux présents. Le modèle s'écrit N'(t) = −λ·N(t), où λ > 0 est la constante radioactive (propre à chaque élément). C'est l'équation y' = ay avec a = −λ < 0, donc :

N(t) = N₀·e^(−λ·t), où N₀ = N(0) est le nombre initial de noyaux. Vérification : N'(t) = N₀·(−λ)·e^(−λ·t) = −λ·N(t) ✅

📗 Définition — Demi-vie t½

La demi-vie, notée t½, est la durée au bout de laquelle la moitié des noyaux initialement présents s'est désintégrée : N(t½) = N₀/2. Elle caractérise l'élément radioactif — comme en SVT, où tu l'as rencontrée pour la datation et la radioactivité.

🧮 Calcul de la demi-vie
1

Équation : N(t½) = N₀/2 devient, avec N(t) = N₀·e^(−λ·t) : N₀·e^(−λ·t½) = N₀/2.

2

Simplifier (division par N₀ > 0) : e^(−λ·t½) = 1/2.

3

Passer au logarithme : −λ·t½ = ln(1/2) = −ln 2, d'où t½ = (ln 2)/λ.

4

Vérification : N((ln 2)/λ) = N₀·e^(−λ·(ln 2)/λ) = N₀·e^(−ln 2) = N₀·(1/2) = N₀/2 ✅

Le duo à connaître (maths + SVT)
N(t) = N₀·e^(−λ·t)  ·  t½ = (ln 2)/λ
Lien SVT : la décroissance exponentielle par demi-vies est le même modèle mathématique que la radioactivité (datation au carbone 14, demi-vie ≈ 5 730 ans) et rythme les divisions du cycle cellulaire — une division, une division des effectifs par 2.

Application 2 — Croissance d'une population bactérienne. Dans un milieu favorable, chaque bactérie se divise indépendamment : la vitesse de croissance est proportionnelle à l'effectif. Le modèle s'écrit N'(t) = k·N(t) avec k > 0, d'où N(t) = N₀·e^(k·t) (vérification identique à celle ci-dessus, au signe près). On définit le temps de doublement τ par N(τ) = 2·N₀ :

N₀·e^(k·τ) = 2·N₀ ⟹ e^(k·τ) = 2 ⟹ k·τ = ln 2 ⟹ τ = (ln 2)/k.

Temps de doublement : τ = (ln 2)/k  ·  Exemple : k = 0,04 par heure ⟹ τ ≈ 17,3 h
Même formule que la demi-vie, au signe près : k > 0 pour une croissance, −λ < 0 pour une décroissance. Le logarithme népérien de 2 est LA constante des phénomènes exponentiels.

Exercice type Bac corrigé

📝 Énoncé — Population et prélèvements

Soit P la fonction, définie et dérivable sur [0 ; +∞), qui à l'instant t (en années) associe l'effectif, en milliers d'individus, d'une population d'un bassin du fleuve Niger. On admet que P vérifie : P'(t) = 0,05·P(t) − 20 et P(0) = 1000.

1. Résoudre l'équation différentielle y' = 0,05·y − 20. 2. En déduire l'expression de P(t). 3. Vérifier que P convient. 4. Déterminer lim (t→+∞) P(t) et interpréter. 5. Au bout de combien d'années l'effectif atteint-il 2000 milliers d'individus ?

1

Résolution (partie 2) : a = 0,05 ≠ 0 et b = −20. Solution particulière constante : yₚ = −b/a = 20/0,05 = 400. Solution générale : y(t) = C·e^(0,05t) + 400, C ∈ ℝ.

2

Condition initiale : P(0) = C·e^0 + 400 = C + 400 = 1000, donc C = 600. D'où P(t) = 600·e^(0,05t) + 400.

3

Vérification : P'(t) = 600·0,05·e^(0,05t) = 30·e^(0,05t) ; d'autre part 0,05·P(t) − 20 = 0,05·(600·e^(0,05t) + 400) − 20 = 30·e^(0,05t) + 20 − 20 = 30·e^(0,05t) ✅ Et P(0) = 600 + 400 = 1000 ✅

4

Limite : comme 0,05 > 0, lim (t→+∞) e^(0,05t) = +∞, donc lim (t→+∞) P(t) = +∞. Interprétation : la population croît sans borne — la croissance exponentielle (5 % par an, environ) l'emporte sur le prélèvement fixe de 20 ; le niveau 400 n'est pas un équilibre atteint, c'est un simple décalage.

5

Instant cherché : 600·e^(0,05t) + 400 = 2000 ⟹ e^(0,05t) = 1600/600 = 8/3 ⟹ 0,05t = ln(8/3) ⟹ t = 20·ln(8/3) ≈ 19,6. L'effectif de 2000 milliers d'individus est atteint au bout d'environ 19,6 années (donc durant la 20ᵉ année).

⚠️ Ce que le correcteur attend à chaque question

Q1 : la forme générale avec C et le terme +400 (ou −b/a bien signé). Q2 : le calcul de C visible (C + 400 = 1000). Q3 : la dérivation ET la substitution — deux lignes. Q4 : la limite justifiée par 0,05 > 0 puis une phrase d'interprétation. Q5 : le passage au logarithme avec le résultat exact 20·ln(8/3) avant la valeur approchée. Chaque maillon manquant coûte des points.

Réflexes Bac et erreurs à éviter

🧠 Le réflexe n° 1 — Vérifier en dérivant et substituant
Face à une question « vérifier que la fonction g définie par g(x) = … est solution de … », ne cherche jamais à résoudre : dérive g, calcule le second membre (a·g + b ou a·g + f(x)), compare. Si les deux expressions coïncident, g est solution. Cette technique rapporte des points même sans savoir résoudre l'équation — et elle sert aussi à contrôler ta propre résolution en fin de question. Deux lignes, zéro risque.
Erreur fréquente au Bac — les quatre péchés capitaux
  • La constante oubliée : écrire y = e^(a·x) comme solution générale. Sans C, ce n'est qu'une solution parmi une infinité — la question « résoudre » est perdue d'avance.
  • L'identification bâclée : identifier seulement le coefficient de x et oublier la constante (ou l'inverse) quand f est affine. Les DEUX coefficients doivent être exploités.
  • Le signe de −b/a : poser yₚ = b/a, ou rater le double signe quand a ou b est négatif. Écrire 0 = a·c + b avant de conclure.
  • La condition initiale sur la mauvaise forme : substituer y(x₀) = y₀ dans une forme générale déjà fausse, ou oublier que y(0) = C − b/a (et non C) quand il y a un second membre.
  • Lire le type d'équation : second membre absent, constant, ou fonction ? → choisir la ligne du tableau de synthèse.
  • Écrire la forme générale avec C avant toute condition initiale.
  • Traiter la condition : substituer, isoler C, réécrire la solution unique.
  • Vérifier : condition initiale ✅ puis équation par dérivation ✅ — si l'une des deux échoue, chercher l'erreur avant d'aller plus loin.
  • Justifier les valeurs approchées : donner d'abord la valeur exacte (20·ln(8/3)), puis l'arrondi (≈ 19,6).
