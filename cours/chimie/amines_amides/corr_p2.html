Obtention et hydrolyse d'un amide

✏️ Exercice 1 — Synthèse de l'éthanamide (★★)

Données : m = 12,0 g d'acide éthanoïque (M = 60 g·mol⁻¹) ; M(éthanamide) = 59 g·mol⁻¹ ; étape 2 : chauffage du sel.

1

Étape 1 — formation du sel : CH₃—COOH + NH₃ → CH₃—COO⁻ + NH₄⁺. Le sel est l'éthanoate d'ammonium. Neutralité : (−1) + (+1) = 0 ✓ ; atomes : C 2 = 2 ✓, H 4 + 3 = 7 à gauche et 3 + 4 = 7 à droite ✓, N 1 = 1 ✓, O 2 = 2 ✓.

2

Étape 2 — déshydratation à chaud (Δ) : CH₃—COO⁻ + NH₄⁺ → CH₃—CO—NH₂ + H₂O. C'est à cette étape que se crée la liaison amide C—N annotée sur la figure de l'énoncé.

3

Vérification de l'étape 2 : neutralité 0 = 0 ✓ ; atomes : C 2 = 2 ✓ ; H 3 + 4 = 7 à gauche et 5 + 2 = 7 à droite ✓ ; O 2 = 2 ✓ ; N 1 = 1 ✓. L'eau formée provient du H de NH₄⁺ et de l'OH du carboxylate.

4

Masse théorique : n(acide) = 12,0/60 = 0,20 mol, donc n_th(amide) = 0,20 mol et m_th = 0,20 × 59 = 11,8 g.

m_th(éthanamide) = 11,8 g

Deux étapes : sel d'ammonium puis déshydratation à chaud.

⚠️ Piège : l'étape 2 libère bien UNE eau : sans chauffage, le sel reste sel d'ammonium et l'amide ne se forme pas.
✏️ Exercice 2 — Rendement de la synthèse (★★ type Bac)

Données : n₀ = 0,20 mol d'acide, ammoniac en excès ; recueilli n = 0,13 mol d'éthanamide (M = 59 g·mol⁻¹).

1

L'ammoniac étant en excès, l'avancement maximal est fixé par l'acide : xₘₐₓ = n₀ = 0,20 mol.

2

Rendement : r = n(obtenu)/n(théorique) = 0,13/0,20 = 0,65 = 65 %.

3

Masse obtenue : m = n × M = 0,13 × 59 = 7,67 ≈ 7,7 g d'éthanamide.

4

Comparaison : 65 % est du même ordre que le 67 % d'une estérification. La déshydratation à chaud chasse l'eau du milieu, ce qui pousse la transformation vers l'amide ; le rendement peut encore être amélioré en éliminant l'eau au fur et à mesure.

r = 65 % ; m ≈ 7,7 g d'éthanamide

Le chauffage et l'évaporation de l'eau déplacent la synthèse vers l'amide.

⚠️ Piège : le rendement se calcule toujours en quantité de matière (n(obtenu)/n(théorique)), jamais en comparant des volumes ou des masses brutes.
✏️ Exercice 3 — Hydrolyse totale d'un amide (★★★ type Bac)

Données : n₀ = 0,10 mol d'éthanamide ; prélèvement du 1/10 ; CB = 0,50 mol·L⁻¹ ; VE = 20,0 mL ; M(acide) = 60 g·mol⁻¹.

1

Équation d'hydrolyse : CH₃—CO—NH₂ + H₂O → CH₃—COOH + NH₃. Vérification : C 2 = 2 ✓ ; H 5 + 2 = 7 et 4 + 3 = 7 ✓ ; O 2 = 2 ✓ ; N 1 = 1 ✓.

2

Dosage : n(acide) = CB × VE = 0,50 × 20,0×10⁻³ = 0,010 mol dans le prélèvement. Le prélèvement étant le dixième du milieu : n(acide total) = 10 × 0,010 = 0,10 mol.

3

Comparaison : n(acide formé) = 0,10 mol = n₀ : tout l'éthanamide a réagi, l'hydrolyse est totale. Contraste avec l'estérification : celle-ci est limitée par l'équilibre ⇌ (rendement au plus 67 % pour un alcool primaire), tandis que l'hydrolyse d'un amide, lente, va ici à son terme à chaud.

4

Masse d'acide éthanoïque obtenue : m = n × M = 0,10 × 60 = 6,0 g.

n(acide) = 0,10 mol : hydrolyse totale ; m = 6,0 g

Le dosage de l'acide formé prouve la complétude de la réaction.

⚠️ Piège : ne recopie pas « rendement 67 % » par habitude : ce chiffre appartient à l'estérification ; ici l'hydrolyse de l'amide est totale.

Polymères polyamides : le nylon 6,6

✏️ Exercice 4 — La polycondensation : écriture du bilan (★★)

Données : HOOC—(CH₂)₄—COOH (M = 146 g·mol⁻¹) ; H₂N—(CH₂)₆—NH₂ (M = 116 g·mol⁻¹) ; motif —OC—(CH₂)₄—CO—NH—(CH₂)₆—NH—.

1

Équation : n HOOC—(CH₂)₄—COOH + n H₂N—(CH₂)₆—NH₂ → —[—OC—(CH₂)₄—CO—NH—(CH₂)₆—NH—]ₙ— + 2n H₂O. Chaque liaison amide créée libère une eau ; il s'en forme deux par motif.

2

Vérification pour n = 1 : gauche = C₁₂H₂₆N₂O₄ (acide C₆H₁₀O₄ + diamine C₆H₁₆N₂) ; droite = motif C₁₂H₂₂N₂O₂ + 2 H₂O = C₁₂H₂₆N₂O₄ ✓ : C 12 = 12, H 26 = 26, N 2 = 2, O 4 = 4.

3

Masse molaire du motif, voie 1 (réactifs) : M = 146 + 116 − 2×18 = 262 − 36 = 226 g·mol⁻¹. Voie 2 (formule brute) : C₁₂H₂₂N₂O₂ → M = 144 + 22 + 28 + 32 = 226 g·mol⁻¹ ✓ : les deux voies coïncident.

4

Les motifs sont soudés par des liaisons amide —CO—NH— ; la réaction est une polycondensation : assemblage de monomères avec élimination d'une petite molécule, ici l'eau.

M(motif) = 226 g·mol⁻¹ ; + 2n H₂O libérées

Deux liaisons amide par motif : deux eaux par motif, toujours.

Figure — Le motif du nylon 6,6 répété n fois : les traits épais marquent les liaisons amide —CO—NH— qui soudent les monomères.
⚠️ Piège : pour n motifs, il se libère 2n eaux (deux liaisons amide créées par motif), pas n.
✏️ Exercice 5 — Préparer un échantillon de nylon (★★★ type Bac)

Données : m₁ = 14,6 g d'acide adipique (M = 146 g·mol⁻¹) ; m₂ = 11,6 g de diamine (M = 116 g·mol⁻¹) ; M(motif) = 226 g·mol⁻¹ ; Nₐ = 6,02×10²³ mol⁻¹.

1

Quantités de matière : n₁ = 14,6/146 = 0,10 mol d'acide et n₂ = 11,6/116 = 0,10 mol de diamine. La stœchiométrie est 1:1 et les quantités sont égales : aucun réactif limitant, on formera 0,10 mol de motifs.

2

Eau libérée : 2n = 2 × 0,10 = 0,20 mol, soit m(eau) = 0,20 × 18 = 3,6 g.

3

Masse de nylon, voie 1 (conservation) : m = 14,6 + 11,6 − 3,6 = 22,6 g. Voie 2 (motifs) : m = n(motifs) × M(motif) = 0,10 × 226 = 22,6 g ✓ : les deux méthodes coïncident.

4

Nombre de motifs : N = n × Nₐ = 0,10 × 6,02×10²³ = 6,02×10²² motifs.

m(eau) = 3,6 g ; m(nylon) = 22,6 g ; 6,02×10²² motifs

La conservation des masses valide le bilan de polycondensation.

⚠️ Piège : si les deux méthodes de calcul de m(nylon) divergent, ne moyenne pas : cherche l'erreur (oubli des 2n eaux le plus souvent).
✏️ Exercice 6 — Ester ou amide ? Le match des dérivés d'acide (★★★ type Bac)

Données : CH₃—COOH ; C₂H₅—OH ; NH₃.

1

Ester : CH₃—COOH + C₂H₅—OH ⇌ CH₃—COO—C₂H₅ + H₂O (lente, limitée, catalysée par H₂SO₄). Amide : CH₃—COOH + NH₃ → CH₃—COO⁻ + NH₄⁺ puis, à chaud : CH₃—COO⁻ + NH₄⁺ → CH₃—CO—NH₂ + H₂O.

2

Hydrolyses : ester CH₃—COO—C₂H₅ + H₂O ⇌ CH₃—COOH + C₂H₅—OH (limitée, inverse de l'estérification) ; amide CH₃—CO—NH₂ + H₂O → CH₃—COOH + NH₃ (lente mais totale à chaud).

3

Comparaison : l'estérification est un équilibre limité (rendement au plus 67 % pour un alcool primaire) dont l'eau est un produit, accéléré par H₂SO₄ ; l'obtention d'un amide passe par le sel d'ammonium et se poursuit à chaud avec élimination de l'eau. À l'hydrolyse, l'ester reste dans l'équilibre, l'amide est coupé totalement.

4

Polyamide industriel : le nylon 6,6, obtenu par polycondensation de l'acide adipique et de l'hexaméthylènediamine. Usages : textile (bas, tissus), cordes et brosses.

Ester ⇌ équilibre limité ; amide → déshydratation à chaud, hydrolyse totale

Même point de départ (l'acide), deux comportements très différents.

⚠️ Piège : dans les deux familles, l'hydrolyse redonne l'acide : ce qui change, c'est le second produit (alcool ou ammoniac) et la limite de la réaction.
