📗 Le fil conducteur de tout le chapitre

ln et exp sont réciproques : chacun défait le travail de l'autre, sur les bons domaines. Résoudre une équation avec ln, c'est éliminer le ln grâce à exp. Le reste n'est que conditions d'existence et calculs soignés.

01
Formules vitales

L'essentiel en un coup d'œil

Formule vitale n° 1 — transformer les produits
ln(ab) = ln a + ln b   (a > 0, b > 0)
Avec ses conséquences : ln(1/b) = −ln b ; ln(a/b) = ln a − ln b ; ln(aⁿ) = n·ln a. Jamais pour une somme : ln(a + b) ≠ ln a + ln b.
Formule vitale n° 2 — dériver et primitiver
(ln u)' = u'/u   (u > 0)
u'/u → ln(u) + C
Cas particulier : (ln x)' = 1/x sur ]0 ; +∞[, donc ln x est une primitive de 1/x.
Formule vitale n° 3 — résoudre les équations
ln x = a ⇔ x = e^a
ln x = ln b ⇔ x = b
La solution de la première est automatiquement positive (car e^a > 0) ; la seconde « enlève les ln » des deux côtés, avec x > 0 et b > 0.
ln x ≤ x − 1  (tout x > 0, égalité en x = 1)
L'inégalité de référence (partie 3) : conséquence immédiate ln x < x — le logarithme ne rattrape jamais la fonction identité.
⚠️ Chaque formule traîne sa condition

Une formule de cette section utilisée sans sa condition est une demi-formule : elle rapporte peu et coûte cher. Écris « car a > 0 et b > 0 » à chaque application — le correcteur cherche ces mentions.

02
Notion 1 · équations

Équations : ln x = a, ln x = ln b

📗 Les deux équations de référence
  • Pour tout réel a : ln x = a ⇔ x = e^a. La solution est automatiquement positive : aucune condition à rejeter.
  • Pour x > 0 et b > 0 : ln x = ln b ⇔ x = b. On « enlève les ln » des deux côtés.
🧠 Méthode — résoudre une équation avec ln en 4 étapes
  • (1) Écrire les conditions d'existence sur leur propre ligne (tout ce qui est sous un ln doit être > 0), avant toute manipulation.
  • (2) Regrouper tous les ln en un seul de chaque côté (propriétés du produit et du quotient).
  • (3) Éliminer les ln : ln A = ln B donne A = B, ou ln A = k donne A = e^k.
  • (4) Résoudre, rejeter les solutions hors des conditions, puis vérifier et conclure avec l'ensemble S.
🧮 Exemple 1 (type Bac) — ln x + ln(x − 1) = ln 6

Conditions d'existence, écrites avant la résolution :

x > 0 et x − 1 > 0, c'est-à-dire x > 1

Toute solution en dehors de ]1 ; +∞[ sera rejetée. La résolution, une transformation par étape :

1

Regrouper. Pour x > 1 :

ln x + ln(x − 1) = ln(x(x − 1))

L'équation devient ln(x(x − 1)) = ln 6.

2

Éliminer les ln.

x(x − 1) = 6

x² − x − 6 = 0

3

Résoudre le trinôme.

Δ = 1 + 24 = 25

x = (1 ± 5)/2 : donc x = 3 ou x = −2.

4

Filtrer, vérifier, conclure. −2 viole la condition x > 1 : rejeté. Reste x = 3, et en effet ln 3 + ln 2 = ln 6 ✓ (car 3 × 2 = 6). Donc S = {3}.

🧮 Exemple 2 — ln(2x + 1) = 3

Condition d'existence, écrite avant la résolution :

2x + 1 > 0 ⇔ x > −1/2

1

Passer à l'exponentielle.

ln(2x + 1) = 3 ⇔ 2x + 1 = e³

2

Isoler, une étape par ligne.

2x = e³ − 1

x = (e³ − 1)/2

3

Conclure. S = {(e³ − 1)/2}, soit environ 9,54, qui vérifie bien x > −1/2 ✓ — la forme exacte avec e³ vaut mieux qu'un arrondi.

🚨 L'erreur éliminatoire : oublier les conditions

Dans l'exemple 1, résoudre le trinôme et conclure S = {3 ; −2} sans avoir écrit (ni utilisé) la condition x > 1 fait perdre la question entière : ln(−2) et ln(−3) n'existent pas ! Les conditions d'existence d'abord, le calcul ensuite, le filtre enfin.

03
Notion 2 · inéquations

Inéquations : l'ordre est conservé

ln est strictement croissante : passer au logarithme (ou l'éliminer) ne change pas le sens des inégalités. C'est tout ce qu'il faut savoir — le reste est du filtrage de domaine.

💡 Les trois inéquations de référence
  • Pour x > 0 et b > 0 : ln x < ln b ⇔ x < b (idem avec ≤, >, ≥).
  • Pour tout réel a : ln x ≥ a ⇔ x ≥ e^a — et x > 0 est alors automatiquement vérifié.
  • Seuils utiles : ln x > 0 ⇔ x > 1 ; ln x ≤ 0 ⇔ 0 < x ≤ 1.
🧮 Exemple 1 — ln(x − 2) > 0

Condition d'existence, écrite avant la résolution :

x − 2 > 0 ⇔ x > 2

1

Résoudre sans le ln.

ln(x − 2) > 0 ⇔ x − 2 > e⁰ = 1

x − 2 > 1 ⇔ x > 3

2

Fusionner avec la condition. x > 3 implique x > 2 : S = ]3 ; +∞[.

🧮 Exemple 2 — ln x ≤ ln 5

Condition d'existence, écrite avant la résolution :

x > 0 (et 5 > 0 est acquis)

1

Résoudre sans le ln. Ordre conservé :

ln x ≤ ln 5 ⇔ x ≤ 5

2

Fusionner avec la condition. S = ]0 ; 5] — le 0 est exclu car ln 0 n'existe pas.

🧮 Exemple 3 — ln(x + 1) < 2

Condition d'existence, écrite avant la résolution :

x + 1 > 0 ⇔ x > −1

1

Résoudre sans le ln, une équivalence par ligne.

ln(x + 1) < 2 ⇔ x + 1 < e²

x + 1 < e² ⇔ x < e² − 2 (environ 5,39)

2

Fusionner avec la condition. S = ]−1 ; e² − 2[.

⚠️ Deux ensembles à joindre, pas un seul

La réponse d'une inéquation logarithmique est presque toujours l'intersection de la condition d'existence et de la solution « sans ln ». Écrire S = ]−∞ ; e² − 2[ pour l'exemple 3 en oubliant x > −1 est l'erreur la plus fréquente du chapitre.

Notion 3 · changement de variable

Changement de variable & croissances comparées

Quand ln x apparaît plusieurs fois, dont une fois au carré, l'équation est un trinôme déguisé. On pose l'inconnue intermédiaire X = ln x, on résout en X, puis on revient à x.

X = ln x  ⇔  x = e^X   (x > 0, X ∈ ℝ)
Le retour à x passe par l'exponentielle : la solution x est positive automatiquement, quel que soit le signe de X.
🧮 Exemple travaillé (type Bac) — 2(ln x)² − 3 ln x + 1 = 0

Condition d'existence, écrite avant la résolution :

x > 0 — on pose alors X = ln x, avec X réel quelconque

1

Réécrire l'équation. Elle devient un trinôme classique :

2X² − 3X + 1 = 0

2

Résoudre en X.

Δ = 9 − 8 = 1

X = (3 ± 1)/4 : donc X = 1/2 ou X = 1.

3

Revenir à x, une valeur par ligne.

X = 1 donne x = e¹ = e

X = 1/2 donne x = e^(1/2) = √e (environ 1,65)

4

Conclure et vérifier. S = {√e ; e}. Contrôles : pour x = e, 2 − 3 + 1 = 0 ✓ ; pour x = √e, 2 × (1/2)² − 3 × (1/2) + 1 = 0 ✓.

⚠️ (ln x)² et ln(x²) : ne jamais mélanger

(ln x)² est le carré du logarithme (c'est lui qui donne le trinôme ci-dessus) ; ln(x²) = 2·ln x est le logarithme du carré. Les deux expressions n'ont ni le même sens ni le même domaine : ]0 ; +∞[ pour l'une, ℝ* pour l'autre.

Seconde arme de la section : les croissances comparées, qui répondent à la question piège « peut-on avoir x < ln x ? ». Réponse : jamais (pour x > 0), car ln x ≤ x − 1 entraîne ln x < x. Vérification numérique :

x0,51e ≈ 2,7210
ln x≈ −0,6901≈ 2,30
x0,51≈ 2,7210
ln x < x ?ouiouiouioui
📗 Hiérarchie des croissances (à retenir telle quelle)

À l'infini : exp écrase les puissances, qui écrasent ln. Conséquences chiffrées : le quotient de ln x par x tend vers 0 en +∞, le produit x · ln x tend vers 0 en 0⁺, et pour tout x > 0 : ln x ≤ x − 1 < x. Le logarithme ne « rattrape » jamais x.

05
Notion 4 · applications & examen

Applications concrètes & réflexes Bac

📈 Le temps de doublement

Une grandeur qui croît de façon exponentielle s'écrit N(t) = N₀ e^(k·t) avec k > 0. Le temps de doublement T est la durée au bout de laquelle la grandeur vaut le double de son départ :

1

Écrire l'équation du doublement.

N₀ e^(k·T) = 2N₀

e^(k·T) = 2

2

Prendre le log et isoler.

k·T = ln 2

T = (ln 2)/k

3

Application. Avec k = 0,07 par an : T = 0,693/0,07 ≈ 9,9 ans — on retrouve la « règle des 70 » des économistes (70/7 = 10 ans).

🧪 Le pH et le logarithme décimal

Le logarithme décimal se déduit du népérien par log x = ln x / ln 10 (avec ln 10 ≈ 2,303). En chimie, le pH vaut l'opposé du log de la concentration a en ions hydrogène :

1

Eau neutre. Sa concentration vaut a = 10⁻⁷, donc log(10⁻⁷) = −7.

2

Conclure. pH = −log a = 7 : chaque unité de pH divise la concentration par 10 — une échelle logarithmique.

🔊 Les décibels

L'intensité sonore se mesure aussi en échelle log : L = 10 · log(I/I₀) avec I₀ = 10⁻¹² W·m⁻² (seuil d'audition).

1

Calculer le rapport. Pour I = 10⁻⁶ :

I/I₀ = 10⁻⁶/10⁻¹² = 10⁶

2

Conclure, une multiplication par ligne.

L = 10 × log(10⁶)

L = 10 × 6 = 60 dB

(conversation courante). Multiplier l'intensité par 10 ajoute 10 dB seulement — la propriété du produit en action.

💡 Les 5 réflexes Bac
  • Réflexe 1 — Domaine d'abord : écrire toutes les conditions (> 0) avant la moindre manipulation.
  • Réflexe 2 — Un seul ln par côté : regrouper avec les propriétés du produit et du quotient.
  • Réflexe 3 — Exp pour éliminer : ln A = ln B ⇔ A = B et ln A = k ⇔ A = e^k.
  • Réflexe 4 — Filtrer les solutions : rejeter toute solution hors du domaine, et l'expliquer en une phrase.
  • Réflexe 5 — Contrôler : réinjecter la solution, ou vérifier à la calculatrice avec des valeurs approchées.
🚨 Les 6 erreurs interdites (vérifie ta copie)
  • Écrire ln(a + b) = ln a + ln b : faux, le log ne transforme que les produits.
  • Conclure ln x = 0 ⇒ x = 0 : faux, la solution est x = 1 (et ln 0 n'existe pas).
  • Garder une solution hors du domaine (exemple : garder x = −2 quand il faut x > 1).
  • Confondre (ln x)² et ln(x²) = 2·ln x.
  • Écrire ln 1 = 1 : faux, ln 1 = 0 (c'est ln e qui vaut 1).
  • Dériver ou primitiver ln(u) sans vérifier u > 0.

💡 La carte mentale du chapitre

Une question avec ln se traite de trois façons : simplifier (propriétés algébriques du produit, du quotient, de la puissance), éliminer le ln (exponentielle pour les équations, ordre conservé pour les inéquations), étudier (domaine, dérivée u'/u, limites, tableau). Chaque exercice du Bac demande simplement de choisir le bon outil — et de citer ses conditions.
