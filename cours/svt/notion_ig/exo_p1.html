QCM, vrai/faux et vocabulaire de l'IG

✏️ Exercice 1 — Vrai ou faux ? (★)

Pour chacune des cinq affirmations suivantes, indique si elle est VRAIE ou FAUSSE, puis justifie ta réponse par une phrase exacte du cours.

  • 1) L'information génétique est portée par les protéines contenues dans le noyau.
  • 2) Un gène est une portion d'ADN qui commande un caractère héréditaire.
  • 3) Les chromosomes sont des structures filamenteuses situées dans le cytoplasme.
  • 4) Le code génétique est universel : il est le même chez tous les êtres vivants.
  • 5) Un caractère acquis au cours de la vie, comme un muscle développé par l'entraînement, se transmet aux descendants.
✏️ Exercice 2 — QCM (★)

Pour chaque question, une seule réponse est correcte. Recopie le numéro de la question et la lettre de la réponse choisie.

Q1. Chez les êtres vivants, l'information génétique est localisée :

  • a) uniquement dans les mitochondries ;
  • b) dans l'ADN des chromosomes du noyau ;
  • c) dans les protéines du cytoplasme ;
  • d) dans la membrane de la cellule.

Q2. Un chromosome est constitué principalement :

  • a) d'ADN et de protéines ;
  • b) de glucides et de lipides ;
  • c) d'ARN uniquement ;
  • d) d'eau et de sels minéraux.

Q3. Le nombre de chromosomes d'une cellule humaine ordinaire (cellule somatique) est :

  • a) 23 ;
  • b) 32 ;
  • c) 46 ;
  • d) 64.

Q4. Deux individus de la même espèce peuvent avoir les yeux bleus ou les yeux bruns bien qu'ils possèdent les mêmes gènes. Pourquoi ?

  • a) ils n'ont pas les mêmes gènes ;
  • b) les versions (allèles) de certains gènes diffèrent ;
  • c) leur information génétique n'est pas portée par l'ADN ;
  • d) le code génétique est différent d'un individu à l'autre.
✏️ Exercice 3 — Associe les termes et les définitions (★★)

Associe chaque terme (1 à 5) à sa définition (A à E). Réponds sous la forme : 1 → … ; 2 → … ; 3 → … ; 4 → … ; 5 → … .

Termes

  • 1. Gène
  • 2. Allèle
  • 3. Information génétique
  • 4. Chromosome
  • 5. Universalité du code

Définitions

  • A. Message contenu dans l'ADN, qui détermine les caractères héréditaires d'un être vivant.
  • B. Portion d'ADN qui commande un caractère héréditaire.
  • C. Version différente d'un même gène.
  • D. Structure filamenteuse du noyau, constituée d'ADN et de protéines, qui porte les gènes.
  • E. Fait que le code de lecture de l'ADN est identique chez tous les êtres vivants.

✏️ Exercice 5 — L'expérience de Griffith (1928) (★★)

Document. Griffith travaille sur deux souches de pneumocoques (bactéries) : la souche S (colonies lisses, munies d'une capsule, virulentes) et la souche R (colonies rugueuses, sans capsule, non virulentes). Il injecte à des souris les quatre lots suivants et note le sort de chaque souris.

LotContenu injecté à la sourisSort de la souris
1Souche S vivanteMort
2Souche R vivanteSurvit
3Souche S tuée par la chaleurSurvit
4Souche R vivante + souche S tuée par la chaleurMort

1) Compare les résultats des lots 1 et 2. Que peut-on conclure sur les deux souches de bactéries ?
2) Le lot 3 montre que les bactéries S tuées par la chaleur ne peuvent pas, seules, tuer la souris. Que se passe-t-il pourtant au lot 4, alors qu'aucune bactérie S vivante n'a été injectée ?
3) Formule l'hypothèse de Griffith en nommant le « principe transformant ».

✏️ Exercice 6 — L'expérience d'Avery (1944) (★★★)

Document. Avery reprend l'expérience de Griffith. Il prépare un extrait de bactéries S tuées (contenant leurs protéines, leur ARN et leur ADN), puis le mélange avec des bactéries R vivantes dans trois tubes. Dans chaque tube, une enzyme détruit un seul type de molécule de l'extrait.

TubeContenu du tubeTransformation des bactéries R en bactéries S
1Extrait de S tuées + enzyme qui détruit les protéines (protéase)Oui : bactéries S obtenues
2Extrait de S tuées + enzyme qui détruit l'ARN (ARNase)Oui : bactéries S obtenues
3Extrait de S tuées + enzyme qui détruit l'ADN (ADNase)Non : aucune bactérie S obtenue

1) Compare les résultats des trois tubes.
2) À quelle condition la transformation des bactéries R en bactéries S a-t-elle lieu ?
3) Déduis-en quelle molécule constitue le principe transformant, donc le support de l'information génétique.
4) Rédige une phrase de conclusion complète, comme attendue au Bac.
