Corrigés — Solutions générales (exercices 1 à 3)

✏️ Exercice 1 — Résoudre du premier coup (★)

Données : résoudre y' = 2y, y' = −5y et y' = 3y sur ℝ.

1

(E₁) : y' = 2y : solutions y(x) = C·e^(2x), C ∈ ℝ. Vérification : y'(x) = 2C·e^(2x) = 2·y(x) ✓.

2

(E₂) : y' = −5y : y(x) = C·e^(−5x). Vérification : y'(x) = −5·C·e^(−5x) = −5·y(x) ✓.

3

(E₃) : y' = 3y : y(x) = C·e^(3x). Vérification : y'(x) = 3·C·e^(3x) = 3·y(x) ✓.

(E₁) : y = C·e^(2x)
(E₂) : y = C·e^(−5x)
(E₃) : y = C·e^(3x), avec C ∈ ℝ
Le coefficient a se retrouve tel quel dans l'exposant.
⚠️ Piège — y' = −5y donne e^(−5x), pas e^(5x). Et la constante C est indispensable : une équation du premier ordre a une famille de solutions, pas une seule.
✏️ Exercice 2 — Contrôle de solutions (★)

Données : g(x) = 5·e^(3x), h(x) = −2·e^(−x), k(x) = 4·e^(2x) + 7 à tester sur trois équations.

1

g'(x) = 5·3·e^(3x) = 15·e^(3x) et 3·g(x) = 3·5·e^(3x) = 15·e^(3x) : donc g' = 3·g ✓, g est solution de (E₁).

2

h'(x) = −2·(−e^(−x)) = 2·e^(−x) (car (e^(−x))' = −e^(−x)) et −h(x) = 2·e^(−x) : donc h' = −h ✓, h est solution de (E₂).

3

k'(x) = 8·e^(2x) et 2·k(x) − 14 = 8·e^(2x) + 14 − 14 = 8·e^(2x) : donc k' = 2·k − 14 ✓, k est solution de (E₃).

Les trois fonctions sont bien solutions de leurs équations respectives.
Méthode : dériver le membre de gauche, calculer le membre de droite, comparer.
⚠️ Piège — Rédigez les deux membres séparément (g'(x) = … puis 3·g(x) = …) avant de conclure : un « on voit que » ne rapporte aucun point.
✏️ Exercice 3 — Avec second membre constant (★★)

Données : résoudre y' = −3y + 6, y' = y + 4 et y' = 2y − 8 sur ℝ.

1

y' = −3y + 6 : forme y' = a·y + b avec a = −3, b = 6 : solution constante −b/a = −6/(−3) = 2. Solution générale : y(x) = C·e^(−3x) + 2. Vérification : y'(x) = −3C·e^(−3x) et −3·y(x) + 6 = −3C·e^(−3x) − 6 + 6 = y'(x) ✓.

2

y' = y + 4 : a = 1, b = 4, solution constante −4 : y(x) = C·e^x − 4. Vérification : y'(x) = C·e^x et y(x) + 4 = C·e^x ✓.

3

y' = 2y − 8 : a = 2, b = −8, solution constante −(−8)/2 = 4 : y(x) = C·e^(2x) + 4. Vérification : y'(x) = 2C·e^(2x) et 2·y(x) − 8 = 2C·e^(2x) + 8 − 8 = y'(x) ✓.

y = C·e^(−3x) + 2
y = C·e^x − 4
y = C·e^(2x) + 4, avec C ∈ ℝ
La solution constante −b/a sert de « point d'ancrage ».
⚠️ Piège — Le calcul −b/a avec a = −3 : −6/(−3) = +2. Faites les signes par écrit, pas de tête.

Corrigés — Vérifications et solution unique (exercices 4 à 6)

✏️ Exercice 4 — Vérification rédigée (★★)

Données : f(x) = 3·e^(−2x) + 2 à tester sur y' = −2y + 4 ; g(x) = (x + 1)·e^(−x) à tester sur y' + y = e^(−x).

1

f'(x) = 3·(−2)·e^(−2x) = −6·e^(−2x). Membre de droite : −2·f(x) + 4 = −6·e^(−2x) − 4 + 4 = −6·e^(−2x). Les deux membres coïncident ✓ : f est solution de (E).

2

g est un produit : g'(x) = 1·e^(−x) + (x + 1)·(−e^(−x)) = (1 − x − 1)·e^(−x) = −x·e^(−x). Alors g'(x) + g(x) = −x·e^(−x) + (x + 1)·e^(−x) = e^(−x) ✓ : g est solution de (F).

f et g sont solutions de leurs équations.
Pour g, la dérivée d'un produit était incontournable.
⚠️ Piège — Dans g' + g, tout doit se simplifier sauf e^(−x) : si un terme en x survit, une dérivée a été mal menée.
✏️ Exercice 5 — À la lecture du graphique (★★)

Données : trois solutions de (E) : y' = 0,5·y, de la forme y(x) = k·e^(0,5x), k > 0 (figure de exo_p1.html).

1

y'(x) = k·0,5·e^(0,5x) = 0,5·k·e^(0,5x) et 0,5·y(x) = 0,5·k·e^(0,5x) : donc y' = 0,5·y ✓ pour tout k. Toutes ces fonctions sont solutions de (E).

2

On a y(0) = k·e⁰ = k : la constante se lit sur l'axe des ordonnées, en x = 0. Courbe du haut C₁ part de 2 : k = 2 ; C₂ part de 1 : k = 1 ; C₃ part de 0,5 : k = 0,5.

3

La condition y(0) = 1 impose k = 1 : l'unique solution est y(x) = e^(0,5x), celle qui porte le point A(0 ; 1). Vérification : y'(x) = 0,5·e^(0,5x) = 0,5·y(x) ✓ et y(0) = 1 ✓.

y(x) = e^(0,5x) (cas k = 1)
La condition initiale y(0) = 1 sélectionne une seule courbe.
⚠️ Piège — Ne pas confondre les courbes (C₁, C₂…) et la constante k. Et k se lit en x = 0, nulle part ailleurs.
✏️ Exercice 6 — De la solution générale à la solution unique (★★)

Données : (E) : y' = 4y − 8 et h(x) = 3·e^(4x) + 2.

1

a = 4, b = −8 : solution constante −b/a = 8/4 = 2. Solution générale : y(x) = C·e^(4x) + 2, C ∈ ℝ. Vérification : y'(x) = 4C·e^(4x) et 4·y(x) − 8 = 4C·e^(4x) + 8 − 8 = y'(x) ✓.

2

h(x) = 3·e^(4x) + 2 correspond à C = 3 : c'est bien une solution. Contrôle direct : h'(x) = 12·e^(4x) et 4·h(x) − 8 = 12·e^(4x) + 8 − 8 = 12·e^(4x) ✓.

3

h(0) = 3·e⁰ + 2 = 3 + 2 = 5 : h vérifie y(0) = 5. Comme toutes les solutions de (E) sont de la forme C·e^(4x) + 2, une seule passe par cette valeur en 0 : h est l'unique solution vérifiant la condition initiale.

y = C·e^(4x) + 2 · solution unique : h(x) = 3·e^(4x) + 2
En x = 0 : C = y(0) − 2 directement.
⚠️ Piège — e⁰ = 1, toujours. Beaucoup laissent un « e⁰ » traîner dans la copie : remplacez-le avant de conclure.
