Calculs, simplifications et équations e^x = a

✏️ Exercice 1 — Premières valeurs ★

Énoncé : calculer e⁰, e^(−1), e^(ln 5), ln(e²) et e^(ln 2 + ln 3), avec e ≈ 2,72.

1
e⁰ = 1 (tout nombre non nul élevé à la puissance 0 vaut 1).
2
e^(−1) = 1/e ≈ 1/2,72 ≈ 0,37.
3
e^(ln 5) = 5 (ln et exp sont réciproques, pour a > 0 : e^(ln a) = a).
4
ln(e²) = 2, valable pour tout réel a : ln(e^a) = a.
5
e^(ln 2 + ln 3) = e^(ln(2 × 3)) = e^(ln 6) = 6.
e⁰ = 1 · e^(−1) = 1/e ≈ 0,37 · e^(ln 5) = 5 · ln(e²) = 2 · e^(ln 2 + ln 3) = 6
ln et exp sont réciproques : elles annulent mutuellement leurs effets, dans le bon ordre de validité.
✏️ Exercice 2 — Simplifications ★

Énoncé : simplifier e² × e³, e⁵/e², (e²)³, e^(2x) × e^(−x), e^(x+1)/e^x et (e^x)².

1
e² × e³ = e^(2 + 3) = e⁵.
2
e⁵/e² = e^(5 − 2) = e³.
3
(e²)³ = e^(2 × 3) = e⁶.
4
e^(2x) × e^(−x) = e^(2x − x) = e^x.
5
e^(x+1)/e^x = e^(x + 1 − x) = e.
6
(e^x)² = e^(x × 2) = e^(2x).
e⁵ · e³ · e⁶ · e^x · e · e^(2x)
Les puissances de e s'ajoutent dans un produit, se soustraient dans un quotient, se multiplient dans une puissance de puissance.
⚠️ Piège : e² × e³ = e⁵ mais e² + e³ ≠ e⁵ ! Les règles des puissances concernent les produits et quotients, jamais les sommes.
✏️ Exercice 3 — Équations e^x = a ★★

Énoncé : question 0 (pourquoi e^x = −2 est impossible), puis résoudre e^x = 5, e^x = 0,5, e^x = −2, e^(2x) = 7 et e^x = 1 (données : ln 2 ≈ 0,69, ln 5 ≈ 1,61, ln 7 ≈ 1,95).

Réponse 0 + méthode
La courbe de exp reste strictement au-dessus de son asymptote y = 0 : e^x > 0 pour tout x ∈ ℝ, donc e^x = −2 n'a aucune solution. Pour tout a > 0 : e^x = a ⟺ x = ln a (unique solution, exp étant strictement croissante).
1
e^x = 5 ⟺ x = ln 5 ≈ 1,61. Vérification : e^1,61 ≈ 5,0 ✓.
2
e^x = 0,5 ⟺ x = ln 0,5 = −ln 2 ≈ −0,69. Vérification : e^(−0,69) ≈ 0,50 ✓.
3
e^x = −2 : aucune solution, car e^x > 0 strictement pour tout réel x. S = ∅.
4
e^(2x) = 7 ⟺ 2x = ln 7 ⟺ x = (ln 7)/2 ≈ 1,95/2 ≈ 0,97. Vérification : e^(2 × 0,97) = e^1,94 ≈ 6,96 ≈ 7 ✓.
5
e^x = 1 ⟺ x = ln 1 = 0 (c'est le point (0 ; 1) de la figure).
S₁ = {ln 5 ≈ 1,61} · S₂ = {−ln 2 ≈ −0,69} · S₃ = ∅ · S₄ = {(ln 7)/2 ≈ 0,97} · S₅ = {0}
Bilan : e^x = a a une unique solution x = ln a si a > 0, et aucune solution si a ≤ 0.

Équations composées et inéquations

✏️ Exercice 4 — Équations composées ★★

Énoncé : résoudre e^(2x) = e^(x + 3), e^x × e^(x + 1) = e² et e^(2x) − 3e^x + 2 = 0.

1
e^(2x) = e^(x + 3) ⟺ 2x = x + 3 (croissance stricte de exp) ⟺ x = 3. Vérification : e⁶ = e^(3 + 3) ✓. S = {3}.
2
e^x × e^(x + 1) = e^(x + x + 1) = e^(2x + 1), donc e^(2x + 1) = e² ⟺ 2x + 1 = 2 ⟺ x = 0,5. Vérification : e^0,5 × e^1,5 = e² ✓. S = {0,5}.
3
Posons X = e^x, avec X > 0 ; comme e^(2x) = (e^x)² = X², l'équation devient X² − 3X + 2 = 0. Discriminant : Δ = 9 − 8 = 1, d'où X = (3 + 1)/2 = 2 ou X = (3 − 1)/2 = 1.
4
Retour à x : e^x = 1 ⟺ x = 0 ; e^x = 2 ⟺ x = ln 2 ≈ 0,69. Vérifications : e⁰ = 1 donne 1 − 3 + 2 = 0 ✓ ; e^(2 ln 2) = 4 donne 4 − 6 + 2 = 0 ✓. S = {0 ; ln 2 ≈ 0,69}.
S₁ = {3} · S₂ = {0,5} · S₃ = {0 ; ln 2 ≈ 0,69}
Le changement de variable X = e^x (strictement positif) ramène l'équation à un trinôme classique.
⚠️ Piège : dans le changement de variable, X = e^x impose X > 0 — ici les deux racines 1 et 2 sont positives, donc toutes deux exploitables ; sinon, on rejetterait les racines négatives.
✏️ Exercice 5 — Inéquations exponentielles ★★

Énoncé : résoudre e^x ≤ 3, e^(x − 1) > 2 et 2e^x − e^(2x) ≥ 0 (données : ln 2 ≈ 0,69, ln 3 ≈ 1,10).

1
exp étant strictement croissante : e^x ≤ 3 ⟺ x ≤ ln 3 ≈ 1,10. D'où S = ]−∞ ; ln 3].
2
e^(x − 1) > 2 ⟺ x − 1 > ln 2 (ln est croissante) ⟺ x > 1 + ln 2 ≈ 1,69. D'où S = ]1 + ln 2 ; +∞[.
3
On factorise : 2e^x − e^(2x) = e^x(2 − e^x). Comme e^x > 0 pour tout x, l'inéquation équivaut à 2 − e^x ≥ 0, soit e^x ≤ 2, soit x ≤ ln 2 ≈ 0,69. D'où S = ]−∞ ; ln 2].
4
Contrôles : pour x = 0 : 2 × 1 − 1 = 1 ≥ 0 ✓ (0 est bien dans S) ; pour x = 1 : 2e − e² ≈ 5,44 − 7,39 < 0 ✓ (1 est bien hors de S, car 1 > 0,69).
S₁ = ]−∞ ; ln 3] · S₂ = ]1 + ln 2 ; +∞[ · S₃ = ]−∞ ; ln 2]
Passer au ln des deux côtés est licite car ln est croissante ET exp est strictement positive : aucun sens d'inégalité ne change.
✏️ Exercice 6 — Identités remarquables ★★★

Énoncé : développer et réduire A = (e^x + e^(−x))², B = (e^x − e^(−x))² et C = (e^x + e^(−x))(e^x − e^(−x)).

1
A = (e^x)² + 2 × e^x × e^(−x) + (e^(−x))² = e^(2x) + 2e⁰ + e^(−2x) = e^(2x) + 2 + e^(−2x), car e^x × e^(−x) = e^(x − x) = e⁰ = 1.
2
B = (e^x)² − 2 × e^x × e^(−x) + (e^(−x))² = e^(2x) − 2 + e^(−2x).
3
C = (e^x)² − (e^(−x))² = e^(2x) − e^(−2x) (identité (a + b)(a − b) = a² − b²).
4
Contrôle de cohérence : A − B = (e^(2x) + 2 + e^(−2x)) − (e^(2x) − 2 + e^(−2x)) = 4 ✓, et A × B = C² (produit de deux carrés) — les trois résultats se tiennent.
A = e^(2x) + 2 + e^(−2x) · B = e^(2x) − 2 + e^(−2x) · C = e^(2x) − e^(−2x)
Ces trois expressions reviennent sans cesse : dans les modèles de tension électrique, de chaînes de suspension et de tables financières.
⚠️ Piège : c'est le produit e^x × e^(−x) = e⁰ = 1 qui fait naître les constantes +2 et −2 ; et n'oublie pas : (e^x)² = e^(2x), la puissance porte sur l'exposant x, pas sur e.
