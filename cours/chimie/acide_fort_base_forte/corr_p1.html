pH des acides forts et des bases fortes

✏️ Exercice 1 — Le pH d’un acide fort ★

Données : HCl ; C = 0,010 mol·L⁻¹ ; Kₑ = 1,0 × 10⁻¹⁴ à 25 °C.

1

Équation : HCl + H₂O → H₃O⁺ + Cl⁻. Équilibre : H : 1 + 2 = 3 à gauche et 3 à droite ; O : 1 = 1 ; Cl : 1 = 1 ; charges : 0 à gauche et (+1) + (−1) = 0 à droite ✅.

2

HCl est un acide fort : la dissociation est totale, donc chaque mole de HCl donne une mole de H₃O⁺ : [H₃O⁺] = C = 0,010 mol·L⁻¹ = 1,0 × 10⁻² mol·L⁻¹.

3

pH = −log C = −log(1,0 × 10⁻²) = 2,00.

4

2ᵉ méthode (contrôle par retour arrière) : 10⁻²,⁰⁰ = 1,0 × 10⁻² mol·L⁻¹ = C ✅ ; et C ≥ 1,0 × 10⁻⁶ mol·L⁻¹ : la formule pH = −log C est bien applicable.

pH = 2,00
Un acide fort à 0,010 mol·L⁻¹ a toujours un pH de 2,00 à 25 °C.
⚠️ Piège : le pH est un LOGARITHME sans unité ; écrire pH = 0,010 ou confondre 0,010 avec 1,0 × 10⁻² sont les fautes classiques.
✏️ Exercice 2 — Le pH d’une base forte ★

Données : NaOH ; C = 0,0010 mol·L⁻¹ = 1,0 × 10⁻³ mol·L⁻¹ ; Kₑ = 1,0 × 10⁻¹⁴ à 25 °C.

1

Équation : NaOH → Na⁺ + OH⁻. Équilibre : Na : 1 = 1 ; O : 1 = 1 ; H : 1 = 1 ; charges : 0 à gauche et (+1) + (−1) = 0 à droite ✅.

2

NaOH est une base forte : dissolution totale, donc [OH⁻] = C = 1,0 × 10⁻³ mol·L⁻¹.

3

pH = 14 + log C = 14 + (−3,00) = 11,00.

4

2ᵉ méthode : [H₃O⁺] = Kₑ / [OH⁻] = 1,0 × 10⁻¹⁴ ÷ 1,0 × 10⁻³ = 1,0 × 10⁻¹¹ mol·L⁻¹, donc pH = −log(1,0 × 10⁻¹¹) = 11,00 : identique ✅.

pH = 11,00
Les deux méthodes (formule de la base forte et passage par Kₑ) concordent.
⚠️ Piège : pour une base forte le pH est SUPÉRIEUR à 7 ; écrire pH = −log C = 3,00 est l’erreur classique (3,00 serait le pOH).
✏️ Exercice 3 — Remonter du pH à la concentration ★★

Données : A : HCl, pH = 3,00 ; B : NaOH, pH = 12,00 ; Kₑ = 1,0 × 10⁻¹⁴ à 25 °C.

1

A, 1ʳᵉ méthode : [H₃O⁺] = 10⁻ᵖᴴ = 10⁻³,⁰⁰ = 1,0 × 10⁻³ mol·L⁻¹ ; acide fort → C = [H₃O⁺] = 1,0 × 10⁻³ mol·L⁻¹.

2

A, 2ᵉ méthode (contrôle) : pH = −log(1,0 × 10⁻³) = 3,00 ✅.

3

B, 1ʳᵉ méthode : pH = 14 + log C → log C = pH − 14 = 12,00 − 14 = −2,00 → C = 10⁻²,⁰⁰ = 1,0 × 10⁻² mol·L⁻¹.

4

B, 2ᵉ méthode : [H₃O⁺] = 10⁻¹²,⁰⁰ = 1,0 × 10⁻¹² mol·L⁻¹ ; [OH⁻] = Kₑ / [H₃O⁺] = 1,0 × 10⁻¹⁴ ÷ 1,0 × 10⁻¹² = 1,0 × 10⁻² mol·L⁻¹ = C ✅ identique.

C(A) = 1,0 × 10⁻³ mol·L⁻¹ · C(B) = 1,0 × 10⁻² mol·L⁻¹
Pour l’acide fort C = [H₃O⁺] ; pour la base forte C = [OH⁻].
⚠️ Piège : pour une base forte, C = [OH⁻] et NON C = [H₃O⁺] ; en cas de doute, repasser par Kₑ.

Titrage et mélanges

✏️ Exercice 4 — Le montage de titrage ★★

Données : V₁ = 20,0 mL d’acide (bécher) ; C₂ = 0,10 mol·L⁻¹ de soude (burette) ; Vₑ = 12,0 mL ; 25 °C.

1

① burette graduée contenant la solution de soude ; ② pH-mètre ; ③ bécher contenant l’acide chlorhydrique et le barreau aimanté.

2

Équation de dosage : H₃O⁺ + OH⁻ → 2 H₂O. Équilibre : H : 3 + 1 = 4 à gauche et 2 × 2 = 4 à droite ; O : 1 + 1 = 2 et 2 = 2 ; charges : (+1) + (−1) = 0 et 0 ✅.

3

Équivalence : on a versé exactement la quantité d’ions OH⁻ nécessaire pour neutraliser tout le H₃O⁺ initialement présent : n(OH⁻)versé = n(H₃O⁺)initial.

4

1ʳᵉ méthode : C₁V₁ = C₂Vₑ → C₁ = C₂ × Vₑ / V₁ = 0,10 × 12,0 ÷ 20,0 = 1,2 ÷ 20,0 = 0,060 mol·L⁻¹.

5

2ᵉ méthode : n(OH⁻)versé = C₂ × Vₑ = 0,10 × 12,0 × 10⁻³ = 1,2 × 10⁻³ mol ; puis C₁ = n / V₁ = 1,2 × 10⁻³ ÷ 20,0 × 10⁻³ = 0,060 mol·L⁻¹ : identique ✅.

6

À l’équivalence : ni H₃O⁺ ni OH⁻ en excès, les ions Na⁺ et Cl⁻ sont spectateurs → solution neutre, pH = 7,0 à 25 °C.

C₁ = 0,060 mol·L⁻¹ · pH(équivalence) = 7,0
Les deux méthodes (relation directe et quantités de matière) donnent 0,060 mol·L⁻¹.
⚠️ Piège : Vₑ (12,0 mL) se place avec C₂ au numérateur et V₁ (20,0 mL) au dénominateur ; l’inversion donnerait 0,17 mol·L⁻¹, valeur fausse.
✏️ Exercice 5 — Préparer une solution titrante par dilution ★★

Données : C₁ = 0,10 mol·L⁻¹ ; C₂ = 0,010 mol·L⁻¹ ; V₂ = 250,0 mL.

1

1ʳᵉ méthode : C₁V₁ = C₂V₂ → V₁ = C₂ × V₂ / C₁ = 0,010 × 250,0 ÷ 0,10 = 2,50 ÷ 0,10 = 25,0 mL.

2

2ᵉ méthode : F = C₁ / C₂ = 0,10 ÷ 0,010 = 10 → V₁ = V₂ / F = 250,0 ÷ 10 = 25,0 mL : identique ✅.

3

pH₁ = −log(0,10) = −log(1,0 × 10⁻¹) = 1,00 ; pH₂ = −log(0,010) = −log(1,0 × 10⁻²) = 2,00.

4

Vérification : F = 10 → le pH de l’acide dilué augmente d’une unité : pH₂ − pH₁ = 2,00 − 1,00 = 1,00 ✅ cohérent.

V₁ = 25,0 mL · pH₁ = 1,00 · pH₂ = 2,00
On prélève les 25,0 mL à la pipette jaugée avant de compléter la fiole de 250,0 mL.
⚠️ Piège : ne pas confondre l’indice 1 (solution mère) et l’indice 2 (solution fille) dans C₁V₁ = C₂V₂ ; et le prélèvement se fait à la pipette jaugée de 25,0 mL.
✏️ Exercice 6 — Mélange acide + base : qui gagne ? ★★★

Données : V₁ = 10,0 mL de HCl à C₁ = 0,020 mol·L⁻¹ ; V₂ = 30,0 mL de NaOH à C₂ = 0,010 mol·L⁻¹ ; réaction totale H₃O⁺ + OH⁻ → 2 H₂O ; log 2,5 ≈ 0,40 ; log 4 ≈ 0,60 ; Kₑ = 1,0 × 10⁻¹⁴ (25 °C).

1

n(H₃O⁺) = C₁ × V₁ = 0,020 × 10,0 × 10⁻³ = 2,0 × 10⁻⁴ mol.

2

n(OH⁻) = C₂ × V₂ = 0,010 × 30,0 × 10⁻³ = 3,0 × 10⁻⁴ mol.

3

Comme 2,0 × 10⁻⁴ < 3,0 × 10⁻⁴ mol, le réactif limitant est H₃O⁺ ; il reste n(OH⁻)excès = 3,0 × 10⁻⁴ − 2,0 × 10⁻⁴ = 1,0 × 10⁻⁴ mol.

4

Volume total : 10,0 + 30,0 = 40,0 mL = 0,0400 L ; donc [OH⁻] = 1,0 × 10⁻⁴ ÷ 0,0400 = 2,5 × 10⁻³ mol·L⁻¹.

5

1ʳᵉ méthode : pH = 14 + log [OH⁻] = 14 + log(2,5 × 10⁻³) = 14 − 3,00 + 0,40 = 11,40.

6

2ᵉ méthode : [H₃O⁺] = Kₑ / [OH⁻] = 1,0 × 10⁻¹⁴ ÷ 2,5 × 10⁻³ = 4,0 × 10⁻¹² mol·L⁻¹ → pH = −log(4,0 × 10⁻¹²) = 12,00 − 0,60 = 11,40 : identique ✅.

n(OH⁻)excès = 1,0 × 10⁻⁴ mol · [OH⁻] = 2,5 × 10⁻³ mol·L⁻¹ · pH = 11,40
La base l’emporte : le mélange est basique.
⚠️ Piège : on ne mélange pas des concentrations ; on calcule les QUANTITÉS de matière, on soustrait, puis on divise par le volume TOTAL (40,0 mL, ni 30,0 ni 10,0).
📌 À retenir avant la partie 02
  • Dissociation totale : [H₃O⁺] = C (acide fort) et [OH⁻] = C (base forte).
  • pH = −log C pour l’acide fort (si C ≥ 1,0 × 10⁻⁶ mol·L⁻¹) ; pH = 14 + log C pour la base forte.
  • Équivalence du titrage : n(H₃O⁺)initial = n(OH⁻)versé, soit C₁V₁ = C₂Vₑ, et pH = 7,0 à 25 °C.
  • Contrôle universel : Kₑ = [H₃O⁺]·[OH⁻] = 1,0 × 10⁻¹⁴ à 25 °C.
