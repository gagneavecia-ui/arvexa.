Univers et équiprobabilité

✏️ Exercice 1 — Lancé d'un dé équilibré (★)

Données : dé équilibré à 6 faces ; A pair, B multiple de 3, C ≥ 5.

1

Ω = {1 ; 2 ; 3 ; 4 ; 5 ; 6}, A = {2 ; 4 ; 6}, B = {3 ; 6}, C = {5 ; 6}. Donc P(A) = 3/6 = 0,5, P(B) = 2/6 = 1/3 ≈ 0,333, P(C) = 2/6 = 1/3 ≈ 0,333.

2

A ∩ B = {6} donc P(A ∩ B) = 1/6 ≈ 0,167 ; A ∪ B = {2 ; 3 ; 4 ; 6} donc P(A ∪ B) = 4/6 = 2/3 ≈ 0,667. Contrôle par la formule : 0,5 + 0,333 − 0,167 = 0,667 ✓.

3

Par dénombrement : B ∪ C = {3 ; 5 ; 6} et P(B ∪ C) = 3/6 = 0,5. Par la formule : B ∩ C = {6}, donc 2/6 + 2/6 − 1/6 = 3/6 = 0,5 ✓.

4

P(A̅) = 1 − P(A) = 1 − 0,5 = 0,5 : il y a une chance sur deux d'obtenir un nombre impair.

P(A) = 0,5 ; P(B) = P(C) = 1/3 ≈ 0,333 ; P(A ∪ B) = 2/3 ≈ 0,667 ; P(B ∪ C) = 0,5
Résultats de l'exercice 1 — chaque valeur contrôlée deux fois.
✏️ Exercice 2 — Tirage d'une carte (★)

Données : jeu de 32 cartes ; A cœur, B as.

1

Il y a 8 cœurs et 4 as : P(A) = 8/32 = 0,25 et P(B) = 4/32 = 0,125.

2

A ∩ B : « la carte est l'as de cœur » (une seule carte) : P(A ∩ B) = 1/32 ≈ 0,031.

3

Par la formule : P(A ∪ B) = 0,25 + 0,125 − 0,031 = 0,344. Par dénombrement : 7 cœurs non as, 3 as non cœur et l'as de cœur, soit 11 cartes : 11/32 ≈ 0,344 ✓.

4

« Ni cœur ni as » est l'événement A̅ ∩ B̅ : P(A̅ ∩ B̅) = 1 − 0,344 = 0,656. Contrôle : il reste 32 − 11 = 21 cartes, et 21/32 ≈ 0,656 ✓.

P(A) = 0,25 ; P(B) = 0,125 ; P(A ∩ B) ≈ 0,031 ; P(A ∪ B) ≈ 0,344 ; P(A̅ ∩ B̅) ≈ 0,656
Résultats de l'exercice 2 — 0,344 + 0,656 = 1.

Union, intersection, contraire

✏️ Exercice 3 — La tontine du quartier Yantala (★★)

Données : 12 membres ; 7 femmes ; 8 à Niamey dont 5 femmes.

1

P(F) = 7/12 ≈ 0,583 ; P(N) = 8/12 ≈ 0,667 ; P(F ∩ N) = 5/12 ≈ 0,417.

2

P(F ∪ N) = 7/12 + 8/12 − 5/12 = 10/12 = 5/6 ≈ 0,833. Contrôle par effectifs : femmes hors Niamey 2, femmes à Niamey 5, hommes à Niamey 3, soit 10 membres : 10/12 ≈ 0,833 ✓.

3

P(F̅ ∩ N̅) = 1 − 0,833 = 0,167. Ce sont les hommes n'habitant pas Niamey : 12 − 10 = 2 membres, et 2/12 ≈ 0,167 ✓.

4

La fiche est remise : les deux tirages sont indépendants et de même loi, donc P(F₁ ∩ F₂) = P(F₁) × P(F₂) = (7/12)² = 49/144 ≈ 0,340.

P(F ∪ N) = 5/6 ≈ 0,833 ; P(F̅ ∩ N̅) = 1/6 ≈ 0,167 ; P(deux femmes) = 49/144 ≈ 0,340
Résultats de l'exercice 3 — 0,583 + 0,667 − 0,417 = 0,833.
✏️ Exercice 4 — Urne avec remise (★★)

Données : urne de 10 boules (6 blanches, 4 noires) ; deux tirages successifs avec remise.

1

P(B₁) = 6/10 = 0,60 et P(N₁) = 4/10 = 0,40. Contrôle : 0,60 + 0,40 = 1 ✓.

2

Avec remise, la composition de l'urne ne change pas : B₂ ne dépend pas de B₁, donc B₁ et B₂ sont indépendants et P(B₁ ∩ B₂) = 0,60 × 0,60 = 0,36.

3

« Au moins une noire » est le contraire de « deux blanches » : 1 − 0,36 = 0,64. Contrôle direct : P(B₁ ∩ N₂) = 0,24, P(N₁ ∩ B₂) = 0,24, P(N₁ ∩ N₂) = 0,16, et 0,24 + 0,24 + 0,16 = 0,64 ✓.

4

« Exactement une blanche » : P(B₁ ∩ N₂) + P(N₁ ∩ B₂) = 0,24 + 0,24 = 0,48. Contrôle global : 0,36 + 0,48 + 0,16 = 1 ✓.

P(B₁ ∩ B₂) = 0,36 ; P(au moins une noire) = 0,64 ; P(exactement une blanche) = 0,48
Résultats de l'exercice 4 — 0,36 + 0,48 + 0,16 = 1.
⚠️ Piège : avec remise, l'indépendance autorise le produit P(B₁) × P(B₂) ; sans remise, il faut passer par des probabilités conditionnelles.
✏️ Exercice 5 — Mobilité urbaine à Niamey (★★)

Données : 200 habitants ; 80 taxi, 70 moto, 30 les deux.

1

P(T) = 80/200 = 0,40 ; P(M) = 70/200 = 0,35 ; P(T ∩ M) = 30/200 = 0,15.

2

Par la formule : P(T ∪ M) = 0,40 + 0,35 − 0,15 = 0,60. Par dénombrement : taxi seul 50, les deux 30, moto seul 40, soit 120 habitants : 120/200 = 0,60 ✓.

3

P(T̅ ∩ M̅) = 1 − 0,60 = 0,40. Contrôle : 200 − 120 = 80 habitants n'utilisent ni taxi ni moto : 80/200 = 0,40 ✓.

4

« Exactement un des deux » : (50 + 40)/200 = 90/200 = 0,45. Contrôle global : 0,15 + 0,45 + 0,40 = 1 ✓.

P(T) = 0,40 ; P(M) = 0,35 ; P(T ∩ M) = 0,15 ; P(T ∪ M) = 0,60 ; P(T̅ ∩ M̅) = 0,40 ; P(exactement un) = 0,45
Résultats de l'exercice 5 — 0,15 + 0,45 + 0,40 = 1.

Variable aléatoire

✏️ Exercice 6 — Un jeu de dé payant (★★★)

Données : dé équilibré ; gain 500 F si 6, gain 200 F si 4 ou 5, perte de 100 F si 1, 2 ou 3.

1

X prend les valeurs 500 (issue 6), 200 (issues 4 et 5) et −100 (issues 1, 2, 3). D'où la loi : P(X = 500) = 1/6 ≈ 0,167, P(X = 200) = 2/6 = 1/3 ≈ 0,333, P(X = −100) = 3/6 = 0,5.

2

Somme : 0,167 + 0,333 + 0,5 = 1 ✓ (valeur exacte : 1/6 + 2/6 + 3/6 = 1).

3

E(X) = 500 × 1/6 + 200 × 1/3 + (−100) × 0,5 = 500/6 + 400/6 − 300/6 = 600/6 = 100. L'espérance vaut E(X) = 100 F : en moyenne, le joueur gagne 100 F par partie, le jeu lui est favorable.

4

E(X²) = 250000/6 + 2 × 40000/6 + 3 × 10000/6 = 360000/6 = 60000. Donc V(X) = 60000 − 100² = 50000 F² et σ(X) = √(50000) = 100√5 ≈ 223,61 F.

Valeur xᵢ de X (en F)−100200500
P(X = xᵢ)0,51/3 ≈ 0,3331/6 ≈ 0,167
E(X) = 100 F ; V(X) = 50000 F² ; σ(X) = 100√5 ≈ 223,61 F
Résultats de l'exercice 6 — le jeu est favorable au joueur.
⚠️ Piège : V(X) = E(X²) − E(X)² ; ne pas oublier d'élever l'espérance au carré avant de soustraire, et donner la variance en F².
