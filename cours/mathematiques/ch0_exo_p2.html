Calcul de modules

1

z = 3 + 4i

|z| = 5

On applique directement la formule |z| = √(a² + b²) avec a = 3 et b = 4.

|z| = √(3² + 4²) = √(9 + 16) = √25 = 5

Le triplet (3, 4, 5) est un triplet pythagoricien classique : à retenir par cœur.

Partie 2 · Section 1 — Module d'un complexe
2

z = -5 + 12i

|z| = 13

|z| = √((-5)² + 12²) = √(25 + 144) = √169 = 13

Le triplet (5, 12, 13) est aussi un triplet pythagoricien. Attention aux carrés des négatifs : (-5)² = 25, pas -25.

Partie 2 · Section 1 — Module d'un complexe
3

z = 1 - i

|z| = √2

|z| = √(1² + (-1)²) = √(1 + 1) = √2

On garde √2 sous cette forme. Ne pas confondre √(1 + 1) et 1 + 1 : la somme est sous la racine.

Partie 2 · Section 1 — Module d'un complexe
4

z = -2i

|z| = 2

Ici a = 0 et b = -2. Donc |z| = √(0² + (-2)²) = √4 = 2.

Pour un imaginaire pur z = ib, le module vaut |b|. Ici |z| = |-2| = 2.

Partie 2 · Section 1 — Cas particuliers
5

z = √3 + i

|z| = 2

|z| = √((√3)² + 1²) = √(3 + 1) = √4 = 2

Bien élever √3 au carré : (√3)² = 3, et non √3.

Corrections 6 à 10

Arguments

6

z = 1

arg(z) = 0

Le point image de z = 1 est (1, 0), sur l'axe des réels positifs. L'angle avec cet axe est nul.

Partie 2 · Section 2 — Arguments remarquables
7

z = i

arg(z) = π/2

Le point image est (0, 1), sur l'axe des imaginaires positifs. L'angle avec l'axe des réels est π/2 (angle droit dans le sens direct).

Partie 2 · Section 2 — Arguments remarquables
8

z = -1

arg(z) = π

Le point image est (-1, 0), sur l'axe des réels négatifs. L'angle est π (angle plat dans le sens direct).

On pourrait aussi écrire arg(z) = -π, car π ≡ -π (mod 2π). Par convention, on prend l'argument principal dans ]-π, π], donc ici π.

Partie 2 · Section 2 — Argument principal
9

z = 1 + i

arg(z) = π/4

Module : |z| = √2. Donc cos θ = 1/√2 = √2/2 et sin θ = 1/√2 = √2/2.

L'unique angle dans ]-π, π] ayant ces deux valeurs est π/4 (45°).

Partie 2 · Section 2 — Calcul de l'argument
10

z = √3 + i

arg(z) = π/6

Module : |z| = 2. Donc cos θ = √3/2 et sin θ = 1/2.

L'angle correspondant est π/6 (30°).

Ne pas confondre π/6 (cos = √3/2) et π/3 (cos = 1/2). Le cosinus et le sinus sont inversés entre ces deux angles.

Formes trigonométrique et exponentielle

11

z = 1 + i

z = √2(cos(π/4) + i sin(π/4)) = √2·e^(iπ/4)

Module : r = √2. Argument : θ = π/4.

On remplace dans les deux formes demandées.

Partie 2 · Sections 3 et 4
12

z = -1 + i√3

z = 2(cos(2π/3) + i sin(2π/3)) = 2·e^(i·2π/3)

Module : r = √(1 + 3) = 2.

Cos et sin : cos θ = -1/2 et sin θ = √3/2, donc θ = 2π/3.

Point délicat : cos θ = -1/2 (négatif) signifie que l'angle est dans le demi-plan gauche, donc dans ]π/2, π] ou [-π, -π/2[. Ici, sin θ > 0 impose θ ∈ ]0, π[, donc θ = 2π/3.

13

z = 2i

z = 2(cos(π/2) + i sin(π/2)) = 2·e^(iπ/2)

Module 2, argument π/2 (z est sur l'axe des imaginaires positifs).

Partie 2 · Sections 3 et 4
14

z = -3

z = 3(cos π + i sin π) = 3·e^(iπ)

Module 3, argument π (z est sur l'axe des réels négatifs).

On garde le module positif r = 3, et c'est l'argument π qui porte le signe négatif.

Corrections 15 à 19

Propriétés et calculs

15

|(1 + i)(2 - 2i)|

= 4

On utilise la propriété |z · z'| = |z| · |z'|.

|1 + i| = √2 et |2 - 2i| = √(4 + 4) = √8 = 2√2.

Donc |(1 + i)(2 - 2i)| = √2 × 2√2 = 2 × 2 = 4.

Beaucoup plus rapide que de développer puis calculer le module du résultat !

Partie 2 · Section 5 — Propriétés des modules
16

arg((1 + i)(2i))

= 3π/4

Propriété : arg(z · z') = arg(z) + arg(z').

arg(1 + i) = π/4 et arg(2i) = π/2.

Donc arg((1 + i)(2i)) = π/4 + π/2 = π/4 + 2π/4 = 3π/4.

Partie 2 · Section 5 — Propriétés des arguments
17

(1 + i)⁶

= -8i

1. Forme exponentielle : 1 + i = √2 · e^(iπ/4)

2. Élever à la puissance : (1 + i)⁶ = (√2)⁶ · e^(i·6π/4) = 8 · e^(i·3π/2)

3. Identifier : e^(i·3π/2) = -i

4. Résultat : (1 + i)⁶ = 8 · (-i) = -8i

Partie 2 · Section 5 — Formule de Moivre
18

e^(iπ/3) · e^(iπ/6)

= i

On additionne les exposants : e^(iπ/3) · e^(iπ/6) = e^(i(π/3 + π/6))

π/3 + π/6 = 2π/6 + π/6 = 3π/6 = π/2

Donc le produit vaut e^(iπ/2) = i.

Partie 2 · Section 4 — Forme exponentielle
19

(√3 + i)⁴

= -8 + 8i√3

1. Forme exponentielle : module 2, argument π/6. Donc √3 + i = 2·e^(iπ/6).

2. Élever à la puissance 4 : (√3 + i)⁴ = 2⁴ · e^(i·4π/6) = 16 · e^(i·2π/3)

3. Retour forme algébrique : e^(i·2π/3) = cos(2π/3) + i sin(2π/3) = -1/2 + i·√3/2

4. Résultat : 16 · (-1/2 + i·√3/2) = -8 + 8i√3

Correction 20

Synthèse

20

Forme algébrique de z = 2·e^(i·2π/3)

z = -1 + i√3

On utilise la formule d'Euler : e^(iθ) = cos θ + i sin θ.

e^(i·2π/3) = cos(2π/3) + i sin(2π/3) = -1/2 + i·√3/2

En multipliant par 2 : z = 2(-1/2 + i·√3/2) = -1 + i√3.

Vérification : |-1 + i√3| = √(1 + 3) = 2, et arg(-1 + i√3) = 2π/3. On retrouve bien module 2 et argument 2π/3.
