Limites, continuité et valeurs intermédiaires

✏️ Exercice 1 — Limites de référence (★)

Données : f(x) = 2x³ − x + 4 et g(x) = (3x − 1)/(x + 2).

1

D_g = ℝ ∖ {−2} : le dénominateur x + 2 doit être non nul.

2

Le terme dominant de f est 2x³ : lim(x→+∞) f(x) = +∞ et lim(x→−∞) f(x) = −∞.

3

En ±∞, g(x) se comporte comme 3x/x = 3 : lim(x→±∞) g(x) = 3 ; la droite y = 3 est asymptote horizontale.

4

En −2 : le numérateur tend vers 3×(−2) − 1 = −7 < 0, le dénominateur vers 0 : lim(x→−2⁺) g(x) = −7/0⁺ = −∞ et lim(x→−2⁻) g(x) = −7/0⁻ = +∞ ; la droite x = −2 est asymptote verticale.

lim f = +∞ (x→+∞) et −∞ (x→−∞) · lim g = 3 en ±∞ · asymptotes x = −2 et y = 3
Limites de référence à connaître par cœur.
⚠️ Piège : près de l'asymptote verticale, regarde toujours le signe du numérateur ET celui du dénominateur : ici −7/0⁺ = −∞ mais −7/0⁻ = +∞.
✏️ Exercice 2 — Formes indéterminées et comparaison (★★)

Données : quatre limites à justifier, dont une par le théorème de comparaison.

1

x² − 4 = (x − 2)(x + 2), donc pour x ≠ 2 : (x² − 4)/(x − 2) = x + 2 et lim(x→2) (x² − 4)/(x − 2) = 4.

2

(2x² + x)/(x² + 3) = [x²(2 + 1/x)]/[x²(1 + 3/x²)] ; comme 1/x → 0 et 3/x² → 0 : lim(x→+∞) (2x² + x)/(x² + 3) = 2/1 = 2.

3

(x³ + 2)/(2x² + 1) = x·(1 + 2/x³)/(2 + 1/x²) : le facteur (1 + 2/x³)/(2 + 1/x²) tend vers 1/2 et x tend vers −∞, donc lim(x→−∞) (x³ + 2)/(2x² + 1) = −∞.

4

Pour x > 0 : 3/x > 0 donc h(x) = x² + 3/x ≥ x² ; or lim(x→+∞) x² = +∞ : par le théorème de comparaison, lim(x→+∞) h(x) = +∞.

4 · 2 · −∞ · +∞ (par comparaison)
Les quatre limites de l'exercice 2, toutes justifiées.
⚠️ Piège : « 0/0 » ou « ∞/∞ » ne sont pas des réponses : ce sont des formes indéterminées qu'il faut lever par une factorisation.
✏️ Exercice 3 — Continuité et TVI (★★★)

Données : f(x) = x³ + 3x − 1 sur [0 ; 1] ; on cherche l'unique zéro α et son encadrement.

1

f est polynomiale : continue sur ℝ, donc sur [0 ; 1] ; de plus f'(x) = 3x² + 3 = 3(x² + 1) > 0 pour tout x : f est strictement croissante.

2

f(0) = −1 < 0 et f(1) = 1 + 3 − 1 = 3 > 0 : 0 ∈ ]−1 ; 3[. Par le TVI, f(x) = 0 admet au moins une solution dans ]0 ; 1[ ; comme f est strictement croissante, elle est unique.

3

f(0,3) = 0,027 + 0,9 − 1 = −0,073 < 0 ; f(0,4) = 0,064 + 1,2 − 1 = 0,264 > 0 : donc α ∈ ]0,3 ; 0,4[ (amplitude 10⁻¹).

4

f(0,32) = 0,032768 + 0,96 − 1 = −0,007232 < 0 ; f(0,33) = 0,035937 + 0,99 − 1 = 0,025937 > 0 : donc α ∈ ]0,32 ; 0,33[ (amplitude 10⁻²).

α unique dans ]0 ; 1[ · α ∈ ]0,32 ; 0,33[
Le zéro de f vaut environ 0,32 à 10⁻² près.
⚠️ Piège : le TVI seul donne l'existence de α ; c'est la stricte monotonie de f qui garantit son unicité — les deux arguments doivent figurer sur la copie.

Dérivation et tableaux de variations

✏️ Exercice 4 — Dérivée et variations d'un polynôme (★)

Données : f(x) = x³ − 3x² + 2 sur ℝ.

1

f'(x) = 3x² − 6x = 3x(x − 2).

2

Signe (règle des signes d'un produit) : pour x < 0, 3x < 0 et x − 2 < 0 donc f'(x) > 0 ; pour 0 < x < 2, f'(x) < 0 ; pour x > 2, f'(x) > 0.

3

f est croissante sur ]−∞ ; 0], décroissante sur [0 ; 2], croissante sur [2 ; +∞[ ; f(0) = 2 est un maximum local, f(2) = 8 − 12 + 2 = −2 est un minimum local.

4

Terme dominant x³ : lim(x→+∞) f(x) = +∞ et lim(x→−∞) f(x) = −∞.

f'(x) = 3x(x − 2) · max local f(0) = 2 · min local f(2) = −2 · lim f = ±∞
Tableau de variations : ↗ jusqu'à 2, ↘ jusqu'à −2, ↗ ensuite.
⚠️ Piège : toujours factoriser f'(x) avant d'étudier son signe — 3x² − 6x seul ne permet pas de conclure.
✏️ Exercice 5 — La fonction homographique (★★)

Données : f(x) = (2x − 1)/(x + 1) sur D = ℝ ∖ {−1}.

1

Formule du quotient (u/v)' avec u = 2x − 1, v = x + 1 : f'(x) = [2(x + 1) − (2x − 1)]/(x + 1)² = (2x + 2 − 2x + 1)/(x + 1)² = 3/(x + 1)².

2

(x + 1)² > 0 pour x ≠ −1 et 3 > 0 : donc f'(x) > 0 sur D et f est strictement croissante sur ]−∞ ; −1[ et sur ]−1 ; +∞[.

3

lim(x→±∞) f(x) = lim(x→±∞) 2x/x = 2 : asymptote horizontale y = 2. En −1, le numérateur tend vers −3 < 0 : lim(x→−1⁻) f(x) = +∞ et lim(x→−1⁺) f(x) = −∞ : asymptote verticale x = −1.

4

f(x) = 0 équivaut à 2x − 1 = 0, soit x = 1/2 : la courbe coupe l'axe des abscisses en (1/2 ; 0).

5

f(x) = 2 équivaut à 2x − 1 = 2x + 2, c'est-à-dire −1 = 2 : impossible. La courbe ne coupe jamais son asymptote horizontale.

f'(x) = 3/(x + 1)² > 0 · asymptotes x = −1 et y = 2 · f(x) = 0 ↔ x = 1/2 · f(x) = 2 impossible
Fonction croissante sur chacun des deux intervalles de définition.
⚠️ Piège : « croissante sur ]−∞ ; −1[ et sur ]−1 ; +∞[ » ne signifie pas croissante sur D tout entier : la double barre en −1 est obligatoire dans le tableau.
✏️ Exercice 6 — Somme d'une fonction affine et d'un inverse (★★)

Données : f(x) = (x² + 1)/x sur D = ℝ*.

1

Pour x ≠ 0 : (x² + 1)/x = x²/x + 1/x = x + 1/x ✓.

2

f'(x) = 1 − 1/x² = (x² − 1)/x².

3

Comme x² > 0 sur ℝ*, f'(x) a le signe de x² − 1 : f' > 0 si x < −1 ou x > 1 ; f' < 0 si −1 < x < 0 ou 0 < x < 1.

4

f croissante sur ]−∞ ; −1], décroissante sur [−1 ; 0[ et ]0 ; 1], croissante sur [1 ; +∞[, avec double barre en 0 — voir le tableau complété ci-dessous.

5

lim(x→0⁺) f(x) = +∞ et lim(x→0⁻) f(x) = −∞ : la droite x = 0 (axe des ordonnées) est asymptote verticale. Extremums locaux : f(−1) = −1 − 1 = −2 (maximum local) et f(1) = 1 + 1 = 2 (minimum local).

f'(x) = (x² − 1)/x² · max local −2 en −1 · min local 2 en 1 · x = 0 asymptote verticale
La courbe descend de −2 vers −∞ puis redescend de +∞ vers 2.
⚠️ Piège : un « minimum local » (2) peut être plus grand qu'un « maximum local » (−2) : ces extremums sont locaux, chacun vit sur sa propre branche.
