Ajustement affine

✏️ Exercice 1 — Pluie et rendement du mil : le nuage et son point moyen (★★)
Rappel des données

Pluviométries 300 ; 350 ; 400 ; 450 ; 500 (mm) ; rendements 640 ; 780 ; 950 ; 1 080 ; 1 250 (kg/ha).

1

Nuage. Avec l'origine (300 ; 600), les cinq points se placent à partir de leurs écarts : par exemple (350 ; 780) est à 50 mm (2 cm) à droite et 180 kg/ha (1,8 cm) au-dessus de l'origine choisie. Les points montent régulièrement de gauche à droite.

2

Allure. Les points sont presque alignés le long d'une droite croissante : un ajustement affine est justifié (plus il pleut, meilleur est le rendement).

3

Abscisse du point moyen. x̄ = (300 + 350 + 400 + 450 + 500)/5 = 2 000/5 = 400 mm.

4

Ordonnée du point moyen. ȳ = (640 + 780 + 950 + 1 080 + 1 250)/5 = 4 700/5 = 940 kg/ha. Donc G(400 ; 940) : sur le dessin, G apparaît bien au centre du nuage.

G(400 ; 940)

Point moyen du nuage pluie / rendement (exercice 1).

Piège. Le point moyen se calcule sur toutes les valeurs : diviser par 5 (nombre de points), et vérifier que G est visuellement au centre du nuage, jamais sur un bord.
✏️ Exercice 2 — Production maraîchère : la droite de Mayer (★★)
Rappel des données

Années 1 à 6 ; productions 12 ; 15 ; 18 ; 24 ; 27 ; 30 (t).

1

Points moyens des deux moitiés. G₁ (années 1 à 3) : x₁ = (1 + 2 + 3)/3 = 2, y₁ = (12 + 15 + 18)/3 = 45/3 = 15, donc G₁(2 ; 15). G₂ (années 4 à 6) : x₂ = (4 + 5 + 6)/3 = 5, y₂ = (24 + 27 + 30)/3 = 81/3 = 27, donc G₂(5 ; 27).

2

Coefficient directeur. a = (27 − 15)/(5 − 2) = 12/3 = 4 : la production augmente en moyenne de 4 t par an.

3

Équation de D. Avec G₁(2 ; 15) : 15 = 4×2 + b, donc b = 15 − 8 = 7. La droite de Mayer est D : y = 4x + 7. Contrôle avec G₂ : 4×5 + 7 = 27 ✓.

4

Le point moyen est sur D. x̄ = (1 + 2 + 3 + 4 + 5 + 6)/6 = 21/6 = 3,5 et ȳ = (12 + 15 + 18 + 24 + 27 + 30)/6 = 126/6 = 21, donc G(3,5 ; 21). Or 4×3,5 + 7 = 14 + 7 = 21 : G ∈ D ✓.

5

Prévision année 8. y = 4×8 + 7 = 39 : on estime la production de l'année 8 à 39 t.

G₁(2 ; 15), G₂(5 ; 27)  ·  D : y = 4x + 7  ·  année 8 : 39 t

Résultats de l'exercice 2.

Piège. La droite de Mayer passe par G₁ et G₂, et comme les deux groupes ont la même taille, elle passe aussi par G : ce triple passage est un excellent contrôle de tes calculs.
✏️ Exercice 3 — Adhérents d'une coopérative : la droite de régression (★★★)
Rappel des données

Années 0 à 4 ; adhérents 50 ; 62 ; 75 ; 85 ; 103.

1

Moyennes. x̄ = (0 + 1 + 2 + 3 + 4)/5 = 2 ; ȳ = (50 + 62 + 75 + 85 + 103)/5 = 375/5 = 75 adhérents. D'où les écarts yᵢ − ȳ : −25 ; −13 ; 0 ; 10 ; 28.

2

Produits et carrés. (xᵢ − x̄)(yᵢ − ȳ) = (−2)(−25) + (−1)(−13) + 0×0 + 1×10 + 2×28 = 50 + 13 + 0 + 10 + 56 = 129 ; Σ(xᵢ − x̄)² = 4 + 1 + 0 + 1 + 4 = 10.

3

Coefficient directeur. a = 129/10 = 12,9 : la coopérative gagne en moyenne 12,9 adhérents par an.

4

Ordonnée à l'origine. b = ȳ − a×x̄ = 75 − 12,9×2 = 75 − 25,8 = 49,2. La droite de régression est D : y = 12,9x + 49,2.

5

Prévision 2027 (x = 6). y = 12,9×6 + 49,2 = 77,4 + 49,2 = 126,6 : on estime à environ 127 adhérents en 2027.

6

Qualité du modèle. Pour x = 4, le modèle donne 12,9×4 + 49,2 = 51,6 + 49,2 = 100,8 contre 103 réels : un écart de 2,2 adhérents seulement (environ 2 %) — le modèle est satisfaisant sur la période observée.

a = 12,9  ·  b = 49,2  ·  D : y = 12,9x + 49,2  ·  2027 : environ 127 adhérents

Résultats de l'exercice 3.

Piège. Ne pas confondre les deux formules : a se calcule avec les écarts produits, b se récupère ensuite avec b = ȳ − a×x̄, jamais l'inverse.

Synthèse type Bac

✏️ Exercice 4 — Type Bac : rendements du riz en périmètre irrigué (★★★)
Rappel des données

Années 1 à 8 ; rendements 22 ; 25 ; 27 ; 30 ; 34 ; 35 ; 39 ; 40 (qx/ha).

1

Nuage. Les huit points montent régulièrement, presque en ligne droite : un ajustement affine par la droite de Mayer est justifié.

2

Points moyens. G₁ (années 1 à 4) : x₁ = (1 + 2 + 3 + 4)/4 = 2,5, y₁ = (22 + 25 + 27 + 30)/4 = 104/4 = 26, donc G₁(2,5 ; 26). G₂ (années 5 à 8) : x₂ = (5 + 6 + 7 + 8)/4 = 6,5, y₂ = (34 + 35 + 39 + 40)/4 = 148/4 = 37, donc G₂(6,5 ; 37).

3

Équation de D. a = (37 − 26)/(6,5 − 2,5) = 11/4 = 2,75 ; puis b = 26 − 2,75×2,5 = 26 − 6,875 = 19,125. Donc D : y = 2,75x + 19,125. Contrôle avec G₂ : 2,75×6,5 + 19,125 = 17,875 + 19,125 = 37 ✓.

4

Le point moyen est sur D. x̄ = (1 + … + 8)/8 = 36/8 = 4,5 ; ȳ = (22 + 25 + 27 + 30 + 34 + 35 + 39 + 40)/8 = 252/8 = 31,5. Or 2,75×4,5 + 19,125 = 12,375 + 19,125 = 31,5 : G(4,5 ; 31,5) ∈ D ✓.

5

Prévision année 10. y = 2,75×10 + 19,125 = 27,5 + 19,125 = 46,625 : on estime le rendement à environ 46,6 qx/ha.

6

Esprit critique. L'année 10 est à 2 ans au-delà du dernier point observé (8) : la tendance linéaire peut être ralentie par la fatigue des sols, le manque d'eau ou le coût des intrants. La prévision est une indication, pas une certitude — il faut la surveiller avec de nouvelles données.

G₁(2,5 ; 26), G₂(6,5 ; 37)  ·  D : y = 2,75x + 19,125  ·  année 10 : ≈ 46,6 qx/ha

Résultats de l'exercice 4.

Piège. Avec 8 points coupés en 4 + 4, les abscisses de G₁ et G₂ sont décimales (2,5 et 6,5) : garde les valeurs exactes jusqu'au bout, n'arrondis qu'à la fin.
✏️ Exercice 5 — Lecture d'un graphique : trouver la droite (★★)
Rappel des données

Droite D tracée sur le nuage ; elle passe par les points cerclés A (sur l'axe des ordonnées) et B (d'abscisse 8).

1

Lecture de A. A est sur l'axe vertical, à la hauteur de la graduation 20 : A(0 ; 20). Son ordonnée est l'ordonnée à l'origine de D, donc b = 20.

2

Lecture de B. B se trouve à l'intersection du quadrillage x = 8 et y = 60 : B(8 ; 60).

3

Coefficient directeur. a = (60 − 20)/(8 − 0) = 40/8 = 5.

4

Équation de D. D : y = 5x + 20. Contrôle : les 7 points du nuage sont tous à moins de 1 unité de la droite (par exemple x = 4 donne 5×4 + 20 = 40, et le point correspondant est exactement en (4 ; 40)) ✓.

5

Prévision pour x = 9. y = 5×9 + 20 = 45 + 20 = 65 : on estime y ≈ 65.

6

Et pour x = 12 ? Les données observées vont seulement de x = 0 à x = 10 environ : x = 12 est hors de la zone observée, l'extrapolation n'est pas fiable. On peut la proposer à titre d'hypothèse, mais en signalant qu'aucune donnée ne l'appuie.

A(0 ; 20), B(8 ; 60)  ·  D : y = 5x + 20  ·  x = 9 : y ≈ 65

Résultats de l'exercice 5.

Piège. Pour lire le coefficient directeur, prends deux points situés sur la droite (ici les points cerclés), pas des points du nuage qui, eux, s'en écartent un peu.
✏️ Exercice 6 — Synthèse : résumé complet d'une série (★★★)
Rappel des données

10 valeurs (kg/ha) : 850 ; 900 ; 950 ; 950 ; 1 000 ; 1 000 ; 1 050 ; 1 100 ; 1 150 ; 1 250 ; Σxᵢ² = 10 535 000.

1

Moyenne. Σxᵢ = 850 + 900 + 950 + 950 + 1 000 + 1 000 + 1 050 + 1 100 + 1 150 + 1 250 = 10 200, donc x̄ = 10 200/10 = 1 020 kg/ha.

2

Médiane. N = 10 pair : la médiane est la moyenne des 5ᵉ et 6ᵉ valeurs de la série ordonnée : Me = (1 000 + 1 000)/2 = 1 000 kg/ha.

3

Quartiles. Il faut au moins 0,25×10 = 2,5 valeurs, donc au moins 3 valeurs pour Q₁ : la 3ᵉ valeur est 950, donc Q₁ = 950 kg/ha. De même, au moins 0,75×10 = 7,5, donc au moins 8 valeurs pour Q₃ : la 8ᵉ valeur est 1 100, donc Q₃ = 1 100 kg/ha. Écart interquartile : 1 100 − 950 = 150 kg/ha.

4

Variance. Avec la formule V = Σxᵢ²/N − x̄² : V = 10 535 000/10 − 1 020² = 1 053 500 − 1 040 400 = 13 100 (kg/ha)².

5

Écart-type. σ = √13 100 ≈ 114,5 kg/ha (car 114,5² = 13 110,25, très proche de 13 100).

6

Comparaison des deux villages. Même moyenne 1 020 kg/ha, mais σ = 60 kg/ha dans le village voisin contre 114,5 kg/ha ici : plus l'écart-type est petit, plus la série est regroupée autour de la moyenne. Les rendements sont donc plus réguliers dans le village voisin.

x̄ = 1 020 kg/ha  ·  Me = 1 000 kg/ha  ·  Q₁ = 950, Q₃ = 1 100  ·  σ ≈ 114,5 kg/ha

Résumé complet de la série (exercice 6).

Piège. La formule V = Σxᵢ²/N − x̄² exige de soustraire x̄² après la division : 1 053 500 − 1 040 400, et non (1 053 500 − 1 040 400)/10.
