Courbes de titrage, tampons et indicateurs

✏️ Exercice 1 — Exploiter une courbe de titrage (★★)

Données : V(acide) = 10,0 mL ; C(base) = 2,0 × 10⁻² mol·L⁻¹ ; courbe avec point E (inflexion) et repère à V = 5,0 mL.

1

Une réaction de titrage doit être rapide et totale : c'est le cas de CH₃—COOH + OH⁻ → CH₃—COO⁻ + H₂O (réaction acide-base, quasi instantanée, non inversée).

2

Méthode des tangentes : les tangentes aux deux branches se coupent au-dessus du point d'inflexion E ; la verticale issue de E donne Vₑ = 10,0 mL (lecture sur l'axe des volumes).

3

Demi-équivalence : V = Vₑ/2 = 5,0 mL (droite en pointillés) ; on lit pH = 4,8. Or à la demi-équivalence [CH₃—COO⁻] = [CH₃—COOH], donc pH = pKa = 4,8.

4

Concentration : C(acide) = C(base) × Vₑ / V(acide) = (2,0 × 10⁻² × 10,0) / 10,0 = 2,0 × 10⁻² mol·L⁻¹.

5

Vérification (deuxième calcul) : n(acide) = 2,0 × 10⁻² × 10,0 × 10⁻³ = 2,0 × 10⁻⁴ mol et n(base) = C(base) × Vₑ = 2,0 × 10⁻² × 10,0 × 10⁻³ = 2,0 × 10⁻⁴ mol ✓.

6

Bande bleue : le pH y varie peu, de 3,8 à 5,8, soit pKa ± 1 ; Henderson donne alors 0,10 ≤ [CH₃—COO⁻]/[CH₃—COOH] ≤ 10 : acide et base conjuguée coexistent en quantités comparables → zone tampon.

Vₑ = 10,0 mL · pKa = 4,8 · C(acide) = 2,0 × 10⁻² mol·L⁻¹

Vₑ se lit à l'inflexion, le pKa à Vₑ/2 : ne jamais les confondre.

⚠️ Piège : lire le pH d'équivalence (8,5) n'est PAS lire le pKa ; le pKa se lit à Vₑ/2 = 5,0 mL.
✏️ Exercice 2 — Deux titrages, deux indicateurs (★★)

Données : A : acide fort, pH d'équivalence = 7,0 ; B : acide éthanoïque, pH d'équivalence = 8,5 ; C(acide) = C(base) = 1,0 × 10⁻² mol·L⁻¹ ; V(acide) = 20,0 mL.

1

Titrage A (acide fort + base forte) : à l'équivalence, la solution ne contient que de l'eau et du chlorure de sodium (neutre) → pH = 7,0.

2

Titrage B (acide faible + base forte) : à l'équivalence, il reste des ions CH₃—COO⁻, base conjuguée qui capte partiellement les ions H₃O⁺ → pH = 8,5 > 7.

3

Indicateur de A : le pH d'équivalence 7,0 appartient à la zone du BBT (6,0 → 7,6) → BBT, jaune → bleu.

4

Indicateur de B : 8,5 appartient à la zone de la phénolphtaléine (8,2 → 10,0) → phénolphtaléine, incolore → rose (l'hélianthine est hors sujet dans les deux cas).

5

Volumes équivalents : Vₑ = C(acide) × V(acide) / C(base) = (1,0 × 10⁻² × 20,0) / (1,0 × 10⁻²) = 20,0 mL, identique pour A et B.

A : BBT · B : phénolphtaléine · Vₑ = 20,0 mL (deux cas)

Le choix de l'indicateur dépend du pH d'équivalence, pas de Vₑ.

⚠️ Piège : le pH d'équivalence d'un acide FAIBLE n'est pas 7 ; c'est lui qui commande le choix de l'indicateur.
✏️ Exercice 3 — Le pouvoir tampon (★★)

Données : S = 50,0 mL d'acide éthanoïque 0,20 mol·L⁻¹ + 50,0 mL d'éthanoate de sodium 0,20 mol·L⁻¹ ; ajout de 1,0 mL de HCl 0,10 mol·L⁻¹ ; pKa = 4,8.

1

Quantités initiales : n(CH₃—COOH) = n(CH₃—COO⁻) = 0,20 × 50,0 × 10⁻³ = 10,0 × 10⁻³ mol → rapport = 1 → pH = 4,8 + log (1) = 4,8.

2

Réaction avec l'acide ajouté : CH₃—COO⁻ + H₃O⁺ → CH₃—COOH + H₂O (totale ; bilan vérifié : 2 C ; 3 + 3 = 4 + 2 H ; 2 + 1 = 2 + 1 O ; charges −1 + 1 = 0).

3

Ions H₃O⁺ ajoutés : n = 0,10 × 1,0 × 10⁻³ = 1,0 × 10⁻⁴ mol = 0,10 mmol → n(CH₃—COO⁻) = 9,9 mmol et n(CH₃—COOH) = 10,1 mmol.

4

Nouveau pH : pH = 4,8 + log (9,9/10,1) = 4,8 + log (0,980) = 4,8 − 0,01 = 4,79 ≈ 4,8.

5

Dans 100,0 mL d'eau pure : [H₃O⁺] = 0,10 mmol / 101,0 mL = 9,9 × 10⁻⁴ mol·L⁻¹ → pH = 3,0.

6

Vérification (deuxième calcul) et conclusion : 9,9/10,1 = 0,980, dont le logarithme vaut environ −0,01 ✓ ; le pH varie de 0,01 unité dans le tampon contre 4,0 unités dans l'eau (de 7,0 à 3,0) → S est un bon tampon.

pH : 4,8 → 4,79 ≈ 4,8 (au lieu de 3,0 dans l'eau pure)

Acide et base conjuguée en quantités voisines = pouvoir tampon.

⚠️ Piège : dans Henderson, le rapport [base]/[acide] fait disparaître le volume total — inutile de le calculer pour ce pH.
✏️ Exercice 4 — Le tampon du sang (★★★)

Données : couple H₂CO₃/HCO₃⁻ ; pKa = 6,4 ; pH du sang = 7,4 ; acidose si pH < 7,35.

1

Henderson : pH = 6,4 + log ([HCO₃⁻]/[H₂CO₃]) → 7,4 = 6,4 + log r → log r = 1,0 → r = 10.

2

Zone tampon : [6,4 − 1 ; 6,4 + 1] = [5,4 ; 7,4] ; le pH du sang (7,4) est dans la zone, à la borne haute.

3

Excès d'acide : HCO₃⁻ + H₃O⁺ → H₂CO₃ + H₂O ; excès de base : H₂CO₃ + OH⁻ → HCO₃⁻ + H₂O (bilans vérifiés : atomes et charges équilibrés).

4

Effort musculaire : les ions H₃O⁺ libérés par l'acide lactique sont consommés par les ions HCO₃⁻ (première équation) → le pH reste voisin de 7,4 tant que les réserves de HCO₃⁻ suffisent ; sinon, acidose.

5

Vérification (deuxième calcul) : pH = 6,4 + log (10) = 6,4 + 1,0 = 7,4 ✓.

[HCO₃⁻]/[H₂CO₃] = 10 · zone tampon [5,4 ; 7,4]

Le tampon sanguin absorbe les excès d'acide ou de base dans les deux sens.

⚠️ Piège : ici la base conjuguée (au numérateur du log) est HCO₃⁻, pas H₂CO₃.
✏️ Exercice 5 — Contrôle d'un vinaigre (★★★)

Données : V = 5,0 mL ; C(base) = 1,0 mol·L⁻¹ ; Vₑ = 6,0 mL ; pH = 4,8 à la demi-équivalence ; M(CH₃—COOH) = 60 g·mol⁻¹ ; ρ = 1,0 g·mL⁻¹.

1

Équation : CH₃—COOH + OH⁻ → CH₃—COO⁻ + H₂O.

2

Concentration : C(vinaigre) = C(base) × Vₑ / V = (1,0 × 6,0) / 5,0 = 1,2 mol·L⁻¹.

3

Dans l'échantillon : n(CH₃—COOH) = 1,2 × 5,0 × 10⁻³ = 6,0 × 10⁻³ mol → m = 6,0 × 10⁻³ × 60 = 0,36 g dans 5,0 mL.

4

Par litre : 0,36 × (1000 / 5,0) = 72 g·L⁻¹ ; avec ρ = 1,0 g·mL⁻¹, 1 L pèse 1000 g → 72 g d'acide pour 1000 g de vinaigre, soit 7,2 g pour 100 g → degré acide = 7,2.

5

Demi-équivalence : V = Vₑ/2 = 3,0 mL → pH = pKa = 4,8 : l'acide du vinaigre est bien l'acide éthanoïque.

6

Titrage colorimétrique : à l'équivalence, la solution contient des ions éthanoate (pH basique, > 7) → phénolphtaléine (8,2 → 10,0). Vérification (deuxième calcul) du degré : 0,36 g/5,0 mL = 7,2 g/100 mL, et 100 mL pèsent 100 g → 7,2 g/100 g ✓.

C(vinaigre) = 1,2 mol·L⁻¹ · degré acide = 7,2 · pKa = 4,8

Un vinaigre commercial classique : le titrage confirme l'étiquette.

⚠️ Piège : le degré acide est rapporté à 100 g de vinaigre ; ici ρ = 1,0 g·mL⁻¹ fait coïncider 100 mL et 100 g, mais il faut le justifier.
✏️ Exercice 6 — Fabriquer un tampon de pH = 5,3 (★★★)

Données : S₁ acide éthanoïque 0,10 mol·L⁻¹ ; S₂ éthanoate de sodium 0,10 mol·L⁻¹ ; pKa = 4,8 ; volume final 100,0 mL ; pH visé = 5,3.

1

Henderson : 5,3 = 4,8 + log r → log r = 0,5 → r = 3,2 (nombre dont le logarithme vaut 0,5).

2

Concentrations égales : r = (C × V₂) / (C × V₁) = V₂/V₁ → V₂ = 3,2 × V₁.

3

Volume total : V₁ + V₂ = 100,0 → 4,2 × V₁ = 100,0 → V₁ = 23,8 mL (S₁) et V₂ = 76,2 mL (S₂).

4

Vérification (deuxième calcul) : r = 76,2/23,8 = 3,2 → pH = 4,8 + log (3,2) = 4,8 + 0,5 = 5,3 ✓.

5

Avec S₁ et S₂ à 0,20 mol·L⁻¹ : le rapport V₂/V₁ et donc [base]/[acide] sont inchangés → pH inchangé (5,3) ; les quantités tampon sont doublées → pouvoir tampon accru.

V(S₁) = 23,8 mL · V(S₂) = 76,2 mL · pH = 5,3

La richesse du tampon dépend des concentrations, son pH du seul rapport.

⚠️ Piège : r = [base conjuguée]/[acide] = V(éthanoate)/V(acide) uniquement parce que les deux solutions ont la même concentration.
