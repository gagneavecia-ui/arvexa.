Voici le corrigé pas à pas des 6 exercices de Synthèse type Bac (exo_p2.html), avec les mêmes numéros et les mêmes valeurs. La démarche : construire l'arbre et le compléter, multiplier le long des branches, additionner les branches qui mènent au même événement, puis inverser avec P_A(B) = P(A ∩ B)/P(A). Chaque feuille d'arbre est contrôlée : les sommes valent 1.

✅ 6 corrigés 📊 ★★ → ★★★ ⏱ 45 min 🎓 Terminale D
Méthode permanente : le long d'un chemin, on multiplie les probabilités (P(A ∩ B) = P(A) × P_A(B)) ; pour un événement atteint par plusieurs chemins, on additionne (probabilités totales) ; et P_A(B) = P(A ∩ B)/P(A). Pour la loi binomiale : P(X = k) = C(n ; k) × pᵏ × qⁿ⁻ᵏ avec q = 1 − p, et E(X) = np.

Probabilités conditionnelles

✏️ Exercice 1 — Tableau croisé d'un lycée (★★)

Données : 300 élèves, 180 garçons, 120 filles ; 210 étudient les mathématiques, dont 120 garçons.

1

Tableau complété : garçons 120 et 60 (car 180 − 120 = 60) ; filles 90 (car 210 − 120 = 90) et 30 ; totaux 210, 90, 300. Contrôles : 60 + 30 = 90 et 210 + 90 = 300 ✓.

2

P(G) = 180/300 = 0,60 et P(M) = 210/300 = 0,70.

3

Par les effectifs : P_G(M) = 120/180 = 2/3 ≈ 0,667. Par la formule : P(G ∩ M) = 120/300 = 0,40, donc P_G(M) = 0,40/0,60 = 2/3 ≈ 0,667 ✓. Et P_F(M) = 90/120 = 0,75 = 0,30/0,40 ✓.

4

P(G) × P(M) = 0,60 × 0,70 = 0,42 alors que P(G ∩ M) = 0,40 : les valeurs diffèrent, donc G et M ne sont pas indépendants. Autre lecture : P_G(M) = 0,667 ≠ 0,70 = P(M) ✓.

P(G) = 0,60 ; P(M) = 0,70 ; P_G(M) = 2/3 ≈ 0,667 ; P_F(M) = 0,75 ; G et M non indépendants
Résultats de l'exercice 1.
✏️ Exercice 2 — Contrôle des pièces d'une usine (★★)

Données : ligne A : 60 % des pièces, 3 % défectueuses ; ligne B : 40 % des pièces, 5 % défectueuses.

1

Arbre complété : premier niveau P(A) = 0,6 et P(B) = 0,4 ; second niveau P_A(D) = 0,03, P_A(C) = 0,97, P_B(D) = 0,05, P_B(C) = 0,95. Contrôles : 0,03 + 0,97 = 1 et 0,05 + 0,95 = 1 ✓.

2

Le long des branches : P(A ∩ D) = 0,6 × 0,03 = 0,018 et P(B ∩ D) = 0,4 × 0,05 = 0,02. Donc P(D) = 0,018 + 0,02 = 0,038.

3

Première méthode : P(C) = P(A ∩ C) + P(B ∩ C) = 0,6 × 0,97 + 0,4 × 0,95 = 0,582 + 0,38 = 0,962. Seconde méthode : P(C) = 1 − P(D) = 1 − 0,038 = 0,962 ✓. Contrôle des quatre feuilles : 0,018 + 0,582 + 0,02 + 0,38 = 1 ✓.

4

P_D(A) = P(A ∩ D)/P(D) = 0,018/0,038 = 9/19 ≈ 0,474 : parmi les pièces défectueuses, moins de la moitié provient de la ligne A, alors que cette ligne produit 60 % des pièces — un résultat contre-intuitif à retenir.

P(D) = 0,038 ; P(C) = 0,962 ; P_D(A) = 9/19 ≈ 0,474
Résultats de l'exercice 2 — les quatre feuilles de l'arbre somment à 1.
⚠️ Piège : P_D(A) et P_A(D) sont différentes : la barre se lit « sachant que », et l'ordre des événements change tout.

Arbres, tirages et indépendance

✏️ Exercice 3 — Tirages successifs sans remise (★★)

Données : urne de 8 boules (5 rouges, 3 vertes) ; deux tirages successifs sans remise.

1

Branches : P(R₁) = 5/8 = 0,625, P(V₁) = 3/8 = 0,375 ; puis P_{R₁}(R₂) = 4/7 ≈ 0,571, P_{R₁}(V₂) = 3/7 ≈ 0,429, P_{V₁}(R₂) = 5/7 ≈ 0,714, P_{V₁}(V₂) = 2/7 ≈ 0,286. Contrôles : 0,571 + 0,429 = 1 et 0,714 + 0,286 = 1 ✓.

2

P(R₁ ∩ R₂) = 5/8 × 4/7 = 20/56 = 5/14 ≈ 0,357 et P(V₁ ∩ V₂) = 3/8 × 2/7 = 6/56 = 3/28 ≈ 0,107. De même P(R₁ ∩ V₂) = P(V₁ ∩ R₂) = 15/56 ≈ 0,268. Somme des quatre feuilles : 0,357 + 0,268 + 0,268 + 0,107 = 1 ✓.

3

« Deux couleurs différentes » : P(R₁ ∩ V₂) + P(V₁ ∩ R₂) = 15/56 + 15/56 = 30/56 = 15/28 ≈ 0,536. Contrôle par le complément : 1 − 0,357 − 0,107 = 0,536 ✓.

4

Probabilités totales : P(V₂) = P(R₁ ∩ V₂) + P(V₁ ∩ V₂) = 15/56 + 6/56 = 21/56 = 3/8 = 0,375. On remarque que P(V₂) = P(V₁) = 0,375 : sans information sur le premier tirage, la composition moyenne de l'urne au second tirage reste 5 rouges et 3 vertes.

P(R₁ ∩ R₂) = 5/14 ≈ 0,357 ; P(2 couleurs différentes) = 15/28 ≈ 0,536 ; P(V₂) = 3/8 = 0,375
Résultats de l'exercice 3.
⚠️ Piège : sans remise, le dénominateur passe de 8 à 7 au second tirage ; les branches du second niveau changent selon la couleur tirée en premier.
✏️ Exercice 4 — Devoirs d'Ali et de Bintou (★★★)

Données : P(A) = 0,7, P(B) = 0,6, travaux indépendants.

1

Par indépendance : P(A ∩ B) = 0,7 × 0,6 = 0,42 et P(A̅ ∩ B̅) = 0,3 × 0,4 = 0,12.

2

« Au moins un réussit » est le contraire de « aucun ne réussit » : P = 1 − 0,12 = 0,88. Contrôle : P(A ∩ B̅) = 0,7 × 0,4 = 0,28 et P(A̅ ∩ B) = 0,3 × 0,6 = 0,18, donc 0,42 + 0,28 + 0,18 = 0,88 ✓.

3

« Un seul réussit » : P(A ∩ B̅) + P(A̅ ∩ B) = 0,28 + 0,18 = 0,46. Contrôle global des quatre issues : 0,42 + 0,28 + 0,18 + 0,12 = 1 ✓.

4

P_B(A) = P(A ∩ B)/P(B) = 0,42/0,6 = 0,7 = P(A) : savoir Bintou réussie ne change pas la probabilité de réussite d'Ali, ce qui traduit bien l'indépendance de A et B.

P(A ∩ B) = 0,42 ; P(au moins un) = 0,88 ; P(un seul) = 0,46 ; P_B(A) = 0,7 = P(A)
Résultats de l'exercice 4 — 0,42 + 0,28 + 0,18 + 0,12 = 1.

Loi binomiale et synthèse

✏️ Exercice 5 — QCM répondu au hasard (★★★)

Données : 5 questions indépendantes, 4 réponses dont une exacte ; X nombre de bonnes réponses.

1

On répète 5 fois, de façon identique et indépendante, une épreuve de Bernoulli de succès « réponse exacte » de probabilité p = 1/4 = 0,25 : X suit la loi binomiale B(5 ; 0,25), avec q = 0,75.

2

P(X = 0) = 0,75⁵ ≈ 0,237 ; P(X = 1) = 5 × 0,25 × 0,75⁴ ≈ 0,396 ; P(X = 2) = 10 × 0,25² × 0,75³ ≈ 0,264. Somme partielle : 0,237 + 0,396 + 0,264 = 0,897.

3

Par somme directe : P(X = 3) = 10 × 0,25³ × 0,75² ≈ 0,088, P(X = 4) = 5 × 0,25⁴ × 0,75 ≈ 0,015, P(X = 5) = 0,25⁵ ≈ 0,001, donc P(X ≥ 3) = 0,088 + 0,015 + 0,001 = 0,104. Contrôle : 0,897 + 0,104 = 1,001 ≈ 1, l'écart vient des arrondis à trois décimales ✓.

4

E(X) = np = 5 × 0,25 = 1,25 : en répondant au hasard, l'élève obtient en moyenne 1,25 bonne réponse sur 5.

X ∼ B(5 ; 0,25) ; P(X ≥ 3) = 0,104 ; E(X) = 1,25
Résultats de l'exercice 5.
✏️ Exercice 6 — Le commerçant du marché Wadata (★★★)

Données : taxi 0,6 (retard 0,1), moto 0,4 (retard 0,25) ; 5 matins indépendants ; X nombre de retards.

1

Arbre : T (0,6) puis retard 0,1 / ponctuel 0,9 ; M (0,4) puis retard 0,25 / ponctuel 0,75. Feuilles : P(T ∩ R) = 0,06, P(T ∩ R̅) = 0,54, P(M ∩ R) = 0,10, P(M ∩ R̅) = 0,30, et 0,06 + 0,54 + 0,10 + 0,30 = 1 ✓. Donc P(R) = 0,06 + 0,10 = 0,16.

2

P_R(T) = P(T ∩ R)/P(R) = 0,06/0,16 = 0,375 : sachant qu'il est en retard, le retard vient trois fois sur huit du taxi.

3

On répète 5 matins de façon identique et indépendante une épreuve de Bernoulli de succès « retard » de probabilité P(R) = 0,16 : X suit la loi binomiale B(5 ; 0,16), avec q = 0,84.

4

P(X = 0) = q⁵ = 0,84⁵ ≈ 0,418 (car 0,84² = 0,7056, 0,84³ ≈ 0,5927, 0,84⁴ ≈ 0,4979, 0,84⁵ ≈ 0,4182). Donc P(X ≥ 1) = 1 − P(X = 0) = 1 − 0,418 = 0,582 ✓ (0,418 + 0,582 = 1). Et E(X) = np = 5 × 0,16 = 0,8 : en moyenne 0,8 matin de retard par semaine.

P(R) = 0,16 ; P_R(T) = 0,375 ; X ∼ B(5 ; 0,16) ; P(X = 0) ≈ 0,418 ; P(X ≥ 1) ≈ 0,582 ; E(X) = 0,8
Résultats de l'exercice 6 — sujet de synthèse complet.
⚠️ Piège : pour P(X ≥ 1), passer par le complément 1 − P(X = 0), beaucoup plus rapide que sommer cinq termes.
