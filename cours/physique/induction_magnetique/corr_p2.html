Dispositifs d'induction : cadre, bobine, alternateur

✏️ Exercice 1 — Cadre qui pénètre dans un champ (★★)

Données : a = 5,0 cm ; v = 0,50 m·s⁻¹ ; L = 10 cm ; B = 0,80 T vers le lecteur.

1

Surface : S = a² = (5,0×10⁻²)² = 2,5×10⁻³ m² ; durée de pénétration : t = L/v = 0,10/0,50 = 0,20 s.

2

Variation de flux : le cadre passe de Φ₁ = 0 à Φ₂ = B·S = 0,80×2,5×10⁻³ = 2,0×10⁻³ Wb, donc ΔΦ = 2,0×10⁻³ Wb.

3

F.é.m. moyenne : e = |ΔΦ/Δt| = 2,0×10⁻³/0,20 = 1,0×10⁻² V = 10 mV.

4

Loi de Lenz : le flux sortant augmente → le courant induit crée un champ induit ENTRANT dans le cadre → vu par le lecteur, le courant induit est horaire.

t = 0,20 s ; e = 10 mV ; courant induit horaire (vu par le lecteur)

Le cadre qui entre dans le champ se comporte comme un générateur.

⚠️ Piège : une fois le cadre ENTIÈREMENT dans la zone de champ, le flux ne varie plus → e = 0. Il n'y a courant induit qu'à l'entrée et à la sortie.

✏️ Exercice 2 — Un aimant tombe dans une bobine (★★)

Données : aimant lâché pôle Nord vers le bas au-dessus d'une bobine reliée à un galvanomètre.

1

Approche : le flux sortant par la face supérieure augmente → cette face devient un pôle N qui repousse l'aimant qui arrive : le courant induit freine légèrement la chute.

2

Éloignement : le flux diminue → la face supérieure devient un pôle S qui attire l'aimant qui part → freinage encore, et la déviation du galvanomètre change de sens.

3

À la sortie, l'aimant est tombé plus longtemps : sa vitesse est plus grande → le flux varie plus vite → e = |ΔΦ/Δt| est plus grande → i plus grande → déviation plus ample.

4

Bilan énergétique : une partie de l'énergie mécanique de l'aimant est convertie en énergie électrique dans la bobine (le galvanomètre dévie), puis dissipée par effet Joule.

La bobine convertit de l'énergie mécanique en énergie électrique, dissipée ensuite en chaleur

Le sens du courant imposé par Lenz garantit la conservation de l'énergie.

⚠️ Piège : sans la loi de Lenz (opposition), l'énergie apparaîtrait de nulle part. Le courant induit s'oppose TOUJOURS à la cause : approche repoussée, éloignement attiré.

✏️ Exercice 3 — Tension induite d'un alternateur (★★★)

Données : S = 10 cm × 20 cm = 2,0×10⁻² m² ; B = 0,50 T ; ω = 100 rad·s⁻¹ ; R = 2,0 Ω ; sin(π/4) ≈ 0,71 ; π ≈ 3,14.

1

Vérification : Φₘₐₓ = B·S = 0,50×2,0×10⁻² = 1,0×10⁻² Wb ✓.

2

F.é.m. maximale : eₘₐₓ = ω·Φₘₐₓ = 100×1,0×10⁻² = 1,0 V ; d'où e(t) = 1,0×sin(100t) (e en V, t en s).

3

À t = T/8 : ωt = (2π/T)×(T/8) = π/4, donc e = 1,0×0,71 = 0,71 V.

4

Intensités : iₘₐₓ = eₘₐₓ/R = 1,0/2,0 = 0,50 A ; i(T/8) = 0,71/2,0 = 0,355 ≈ 0,36 A.

5

Fréquence : f = ω/2π = 100/6,28 ≈ 16 Hz.

eₘₐₓ = 1,0 V ; e(T/8) ≈ 0,71 V ; iₘₐₓ = 0,50 A ; f ≈ 16 Hz

La tension induite est sinusoïdale de même fréquence que la rotation.

⚠️ Piège : e(T/8) n'est pas la moitié de eₘₐₓ ! Le sinus n'est pas une fonction linéaire : on calcule toujours sin(ωt) avant de multiplier.

Dynamo, courants induits et synthèse

✏️ Exercice 4 — Dynamo de vélo : étude complète (★★★)

Données : N = 240 ; S = 2,0×10⁻³ m² ; B = 0,20 T ; n = 10 tr·s⁻¹ ; π ≈ 3,14.

1

Vitesse angulaire : ω = 2πn = 2×3,14×10 = 62,8 rad·s⁻¹ ; fréquence de la tension : f = n = 10 Hz.

2

Flux maximal par spire : Φₘₐₓ = B·S = 0,20×2,0×10⁻³ = 4,0×10⁻⁴ Wb.

3

F.é.m. maximale : eₘₐₓ = N·Φₘₐₓ·ω = 240×4,0×10⁻⁴×62,8 = 6,0 V (240×4,0×10⁻⁴ = 9,6×10⁻² Wb ; ×62,8 ≈ 6,03 V) : la lampe 6,0 V est parfaitement adaptée.

4

À n = 20 tr·s⁻¹, ω = 125,6 rad·s⁻¹ est double, donc eₘₐₓ = 2×6,0 = 12 V : eₘₐₓ est proportionnelle à ω (eₘₐₓ = N·B·S·ω).

ω = 62,8 rad·s⁻¹ ; eₘₐₓ ≈ 6,0 V puis ≈ 12 V à vitesse doublée

Rouler plus vite augmente à la fois la fréquence et l'amplitude de la tension.

⚠️ Piège : la tension induite est ALTERNATIVE : la lampe reçoit une tension qui oscille entre −6,0 V et +6,0 V. Le filament éclaire malgré le changement de sens du courant.

✏️ Exercice 5 — Chute freinée dans un tube de cuivre (★★)

Données : aimant lâché dans un tube de cuivre, puis dans un tube de plastique identique.

1

Oui : quand l'aimant passe devant une section du tube, le flux à travers cette section varie fortement → des courants induits fermés apparaissent dans la masse métallique : ce sont les courants de Foucault.

2

Loi de Lenz : ces courants s'opposent à la cause qui les crée, c'est-à-dire à la chute → ils exercent sur l'aimant une force orientée vers le haut → la chute est ralentie.

3

Le plastique est isolant : aucun courant induit ne peut s'y fermer → aucune force de freinage → chute libre identique à celle dans l'air.

4

Bilan : l'énergie mécanique perdue par l'aimant est convertie en énergie électrique des courants de Foucault, puis en énergie thermique : le tube de cuivre peut légèrement s'échauffer.

Cuivre conducteur → courants de Foucault → chute freinée ; plastique isolant → chute libre

Application directe de la loi de Lenz et de la conservation de l'énergie.

⚠️ Piège : le freinage nécessite une VARIATION de flux. Un aimant immobile dans le tube ne subit aucune force : c'est le mouvement qui crée les courants.

✏️ Exercice 6 — Bobine plate dans un champ variable (★★★)

Données : N = 200 ; S = 40 cm² = 4,0×10⁻³ m² ; R = 2,0 Ω ; B croît de 0,10 T à 0,50 T en 0,40 s.

1

Flux par spire : Φ₁ = 0,10×4,0×10⁻³ = 4,0×10⁻⁴ Wb ; Φ₂ = 0,50×4,0×10⁻³ = 2,0×10⁻³ Wb.

2

Variation totale : ΔΦ = N·(Φ₂ − Φ₁) = 200×(2,0×10⁻³ − 4,0×10⁻⁴) = 200×1,6×10⁻³ = 0,32 Wb.

3

F.é.m. moyenne : e = |ΔΦ/Δt| = 0,32/0,40 = 0,80 V ; intensité : i = e/R = 0,80/2,0 = 0,40 A.

4

Charge transportée : Q = i·Δt = 0,40×0,40 = 0,16 C.

5

Loi de Lenz : le flux à travers la bobine augmente → le courant induit crée un champ induit de sens OPPOSÉ à →B (remarque : Q = N·S·ΔB/R = 0,32/2,0 = 0,16 C ne dépend pas de la durée !).

ΔΦ = 0,32 Wb ; e = 0,80 V ; i = 0,40 A ; Q = 0,16 C

Le champ induit s'oppose à l'augmentation du flux.

⚠️ Piège : multiplier par N AVANT de diviser par Δt. Si l'on oublie les 200 spires, la f.é.m. est 200 fois trop petite (4,0 mV au lieu de 0,80 V).
