Utiliser cette fiche

Cette fiche ne remplace pas les parties 1 à 3 : elle les compresse sous forme d'outils mobilisables en quelques secondes. Utilise-la ainsi : relis-la entièrement la veille d'un devoir, puis, après le devoir, retourne à l'outil correspondant à chaque question manquée.

Le kit minimal — quatre formules qui répondent à presque tout
z' = az + b  (a ≠ 0)
ω = b/(1 − a)
k = |a|
θ = arg(a)
Écriture complexe, centre, rapport, angle : avec ces quatre objets tu identifies, calcules et vérifies toute similitude directe (si a = 1 : translation, aucun centre). 01
Outil 1 · methode_bac

Déterminer une similitude (2 points → 2 images)

Énoncé type : « Soit S la similitude directe qui transforme A en A' et B en B'. Déterminer son écriture complexe. » On pose S : z' = az + b et on résout un système 2×2 en a et b.

🧠 La méthode en une ligne

On écrit le système :

a·z_A + b = z'_A  et  a·z_B + b = z'_B

Par soustraction, b disparaît :

a = (z'_A − z'_B)/(z_A − z_B)

b = z'_A − a·z_A

Toujours finir par la vérification sur le second point.

🧮 Exemple type Bac — A(1) ↦ A'(2 + i) et B(2) ↦ B'(4 + 3i)
1

Système, ligne par ligne :

a + b = 2 + i

2·a + b = 4 + 3i

2

Soustraction (ligne 2 − ligne 1) :

a·(2 − 1) = (4 + 3i) − (2 + i)

a = 2 + 2i

3

Report :

b = (2 + i) − (2 + 2i) × 1 = −i

D'où S : z' = (2 + 2i)·z − i.

4

Vérification sur B :

(2 + 2i) × 2 − i = 4 + 4i − i = 4 + 3i ✓

5

Éléments caractéristiques :

k = |2 + 2i| = 2√2

θ = arg(2 + 2i) = π/4

Centre, ligne par ligne :

1 − a = 1 − (2 + 2i) = −1 − 2i

ω = −i/(1 − 2 − 2i) = −i/(−1 − 2i)

ω = ((−i) × (−1 + 2i))/((−1 − 2i) × (−1 + 2i))

ω = (−i)·(−1 + 2i)/5

ω = (2 + i)/5 = 0,4 + 0,2i

⚠️ Variantes d'énoncé

Si l'énoncé donne le rapport ET l'angle en plus d'un couple (A, A') : construire a = k·e^(iθ) puis b = z'_A − a·z_A. Si l'énoncé donne seulement un couple (A, A') : signaler que l'information est insuffisante — il manque une condition sur a ou un second couple.

02
Outil 2 · invariants

Le point invariant et le centre

Le point invariant est le point qui vérifie z = a·z + b : c'est le centre de la similitude (dès que a ≠ 1). Trois usages au Bac : le trouver, le vérifier, ou l'utiliser pour identifier une transformation.

z = a·z + b
z = b/(1 − a)  (a ≠ 1)
Unique point invariant = centre Ω. Si a = 1 : translation, aucun point invariant (sauf identité si b = 0). Toujours vérifier a ≠ 1 avant de diviser.
🧮 Exemple éclair

S : z' = 2·z + 3 : centre, ligne par ligne :

ω = 3/(1 − 2) = 3/(−1)

ω = −3

Vérification : 2 × (−3) + 3 = −3 ✓. Avec la forme réduite z' + 3 = 2·(z + 3), on identifie d'un coup d'œil : homothétie de centre Ω(−3) et de rapport 2.

📗 Le réflexe de vérification universel

Après tout calcul de centre ou d'écriture, reporte l'affixe trouvée dans la formule : si a·ω + b ≠ ω, il y a une erreur de calcul. Ce contrôle de dix secondes sauve plusieurs points à chaque devoir.

Outil 3 · geometrie

Images de figures et triangles semblables

Construire l'image d'une figure : comme une similitude conserve l'alignement, il suffit de calculer les images des points de repère (sommets, centres) puis de tracer. L'image d'un triangle de sommets A, B, C est le triangle A'B'C' ; l'image d'un cercle de centre C et de rayon r est le cercle de centre C' et de rayon k × r.

cercle de centre C, rayon r ⇒ cercle de centre C' (image de C), rayon k × r
Un seul point de repère suffit pour le cercle : son centre. L'image du rayon est k × r car la similitude multiplie toutes les distances par k.
🧮 Exemple — image du triangle A(1), B(3), C(1 + 2i) par S : z' = (1 + i)·z + 2
1

z'_A = (1 + i) × 1 + 2 = 3 + i

→ A'(3 + i).

2

z'_B = (1 + i) × 3 + 2 = 3 + 3i + 2

= 5 + 3i

→ B'(5 + 3i).

3

z'_C = (1 + i)·(1 + 2i) + 2 = 1 + 2i + i + 2i² + 2

= 1 + 3i

→ C'(1 + 3i).

4

On trace le triangle A'B'C' : c'est l'image de ABC, agrandi d'un facteur k = √2 et tourné de π/4 autour du centre Ω(2i). Contrôle du centre, ligne par ligne :

1 − a = 1 − (1 + i) = −i

ω = 2/(1 − (1 + i)) = 2/(−i)

ω = 2i

Montrer que deux triangles sont semblables : exhiber une similitude qui envoie l'un sur l'autre. Méthode : déterminer S à partir des deux premiers sommets, puis vérifier qu'elle envoie le troisième sur le troisième.

🧮 Exemple — A'B'C' (ci-dessus) est-il semblable à ABC ?
1

Déterminer S à partir de A et B, ligne par ligne :

a = (z'_A − z'_B)/(z_A − z_B)

a = ((3 + i) − (5 + 3i))/(1 − 3)

a = (−2 − 2i)/(−2) = 1 + i

puis b = z'_A − a·z_A, soit b = 3 + i − (1 + i) = 2.

2

Vérifier le troisième sommet :

(1 + i)·(1 + 2i) + 2 = 1 + 2i + i − 2 + 2

= 1 + 3i = z'_C ✓

— S envoie bien C sur C'.

3

Conclure : la similitude directe z' = (1 + i)·z + 2 (a = 1 + i ≠ 0) transforme ABC en A'B'C' : les triangles sont semblables, de rapport √2 et d'angle π/4.

⚠️ La vérification du 3e sommet est obligatoire

Deux points et leurs images déterminent toujours une similitude — mais rien ne prouve qu'elle envoie le troisième sommet au bon endroit ! Sans l'étape de vérification, la conclusion « semblables » est infondée : c'est exactement ce que le correcteur attend de toi.

Outil 4 · synthese

Tableau des écritures complexes

Le tableau à connaître par cœur : il relie chaque transformation du programme à son écriture complexe et à ses éléments caractéristiques (pour un centre Ω d'affixe ω).

Les deux clés de lecture du tableau
k = |a|
θ = arg(a) (à 2π près)
De n'importe quelle écriture z' = az + b : le module de a donne le rapport, l'argument de a donne l'angle. Tout le reste du tableau se déduit de ces deux lectures.
TransformationÉcriture complexeCoefficient akθ
Translation de vecteur d'affixe bz' = z + b110
Rotation de centre Ω, d'angle θz' = e^(iθ)·(z − ω) + ωe^(iθ)1θ
Symétrie centrale de centre Ωz' = −z + 2ω−11π
Homothétie de centre Ω, de rapport kz' = k·(z − ω) + ωk (réel > 0)k0
Similitude directe de centre Ω, de rapport k, d'angle θz' = az + b avec a = k·e^(iθ)a|a|arg(a)

Lecture utile du tableau : la symétrie centrale est la rotation d'angle π (d'où a = −1 : z' = −(z − ω) + ω = −z + 2ω) ; l'homothétie est la similitude d'angle nul ; la rotation est la similitude de rapport 1. Toutes sont des cas particuliers de z' = az + b.

📗 Comment utiliser ce tableau à l'examen

Énoncé du type « montrer que l'application z' = … est une rotation (une homothétie, une symétrie centrale…) » : on calcule la forme réduite z' − ω = a·(z − ω), puis on lit a dans la colonne « coefficient » du tableau pour nommer la transformation. C'est la démarche attendue, rédigée dans cet ordre.

Outil 5 · reflexes

Réflexes Bac et erreurs à éviter

La différence entre une copie moyenne et une bonne copie tient souvent à des réflexes. Voici les cinq réflexes du chapitre, puis les erreurs que les correcteurs voient chaque année.

🧠 Les 5 réflexes du jour J
1. « Nature de la transformation ? » → calculer |a| et arg(a), passer par la forme réduite.
2. « Déterminer la similitude ? » → deux informations : soit rapport + angle + un couple, soit deux couples (système).
3. « Image d'une figure ? » → images des points de repère, puis tracer (cercle : centre + rayon × k).
4. « Semblables ? » → exhiber S et vérifier le 3ᵉ point.
5. Toujours vérifier : centre invariant, second point correct, division par le conjugué bien menée.
Erreur n°1 — oublier a ≠ 0

z' = 0·z + b n'est pas une similitude : tout le plan s'écrase sur un point. Devant toute écriture z' = az + b, la phrase d'ouverture attendue est : « comme a ≠ 0, c'est l'écriture complexe d'une similitude directe de rapport |a| et d'angle arg(a) ».

Erreur n°2 — confondre rapport et angle

Le rapport est k = |a| : un module, toujours positif. L'angle est θ = arg(a) : un argument, défini modulo 2π. Écrire « rapport −3 » ou prendre l'argument pour un module (ex. : pour a = √3 + i, répondre rapport √3 au lieu de 2) sont des fautes classiques.

Erreur n°3 — le centre mal calculé

Trois variantes du même accident : utiliser b/(a − 1) au lieu de b/(1 − a) (signe) ; utiliser b/(1 + a) ; ou oublier de multiplier par le conjugué du dénominateur lors de la division de complexes. Contrôle systématique : a·ω + b = ω.

⚠️ Erreur n°4 — chercher un centre quand a = 1

Pour une translation (a = 1), la formule b/(1 − a) divise par zéro : il n'y a pas de centre. Si la composée de deux similitudes donne a₂·a₁ = 1, conclure directement « translation de vecteur d'affixe a₂·b₁ + b₂ » sans chercher plus loin.
