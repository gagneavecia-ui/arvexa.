Notion 1 · chaine

La chaîne complète de l'étude statistique

Un sujet de statistiques du Bac demande presque toujours la même chaîne — la connaître, c'est savoir où l'on va avant de calculer :

💡 La carte d'identité du chapitre

nuage → point moyen G → variances et covariance → droite D : y = a·x + b → coefficient r → jugement → prévision. Maîtrise cette chaîne et tu couvres l'essentiel de l'épreuve. Un seul tableau de calcul sert à tout : colonnes xᵢ², yᵢ², xᵢ·yᵢ, totaux en bas.

IndicateurFormuleCe qu'il mesure / quand l'utiliser
Modevaleur du plus grand nᵢ (ou classe modale)la valeur la plus fréquente ; seul indicateur possible pour un caractère qualitatif
Médiane Merang (N + 1)/2 si N impair ; demi-somme des rangs N/2 et N/2 + 1 si N pairpartage la série ordonnée en deux moitiés ; insensible aux valeurs extrêmes

L'ordre des calculs, en six gestes — dans cet ordre, toujours :

1

Tracer le nuage des points Mᵢ(xᵢ ; yᵢ) et juger son allure : allongé autour d'une droite → ajustement linéaire envisagé (sinon, le dire et s'abstenir).

2

Calculer le point moyen : x̄ = (Σ xᵢ) / n, ȳ = (Σ yᵢ) / n, d'où G(x̄ ; ȳ).

3

Remplir le tableau de calcul puis calculer V(x), V(y) et cov(x ; y).

4

Pente : a = cov(x ; y) / V(x) — le signe de a est celui de la covariance.

5

Ordonnée : b = ȳ − a·x̄, écrire D : y = a·x + b, et contrôler que G appartient à D.

6

Juger : r = cov(x ; y) / (σₓ·σᵧ) ; si |r| ≥ 0,9, l'ajustement est justifié → prévision.

✅ Les sept contrôles réflexes — cinq secondes chacun
  • Effectifs : Σ nᵢ = N ; fréquences : Σ fᵢ = 1 ;
  • Moyenne : Σ nᵢ·(xᵢ − x̄) = 0 exactement (idem pour y) — un résultat non nul = moyenne fausse ;
  • Droite : a·x̄ + b = ȳ — le point moyen G appartient toujours à D (démontré en section 02) ;
  • Corrélation : −1 ≤ r ≤ 1 — un r dehors signale une erreur de calcul ;
  • Signes : r et a de même signe, comme cov(x ; y) ;
  • Unités : t/ha, kg/ha, mm, FCFA — annoncées dans la conclusion ;
  • Arrondis : valeurs exactes (fractions, racines) pendant les calculs, arrondi seulement à la fin.
Erreur fréquente — mélanger les colonnes xᵢ² et xᵢ·yᵢ

La variance utilise la colonne xᵢ², la covariance la colonne xᵢ·yᵢ : deux colonnes distinctes, jamais interchangeables. Et Σ xᵢ·yᵢ (produits terme à terme) n'est ni Σ xᵢ², ni (Σ xᵢ)·(Σ yᵢ) — sur le fil rouge sorgho : 352, et non 30 × 50 = 1 500. Deuxième variante du piège : oublier b = ȳ − a·x̄ et écrire D : y = a·x seul — b peut être négatif (l'étude de la section 05 donnera b = −345).

Notion 2 · demonstration

La démonstration des moindres carrés

Depuis la Partie 2, tu appliques la formule de la pente. D'où vient-elle ? De l'exigence : chercher la droite qui rend minimale la somme des carrés des écarts verticaux. On pose S(a ; b) = Σ (yᵢ − a·xᵢ − b)² : c'est un trinôme en b (à a fixé), puis un trinôme en a — et un trinôme q(u) = α·u² + β·u + γ avec α > 0 atteint son minimum quand sa dérivée q'(u) = 2α·u + β s'annule.

1

Développer S. Avec (u + v + w)² = u² + v² + w² + 2uv + 2uw + 2vw :

S = Σ yᵢ² + a²·Σ xᵢ² + n·b² − 2a·Σ xᵢ·yᵢ − 2b·Σ yᵢ + 2ab·Σ xᵢ

(b² apparaît n fois, d'où n·b².)

2

Dériver par rapport à b (à a fixé) et annuler — trinôme en b de coefficient dominant n > 0 :

n·b = Σ yᵢ − a·Σ xᵢ

b = (Σ yᵢ) / n − a·(Σ xᵢ) / n = ȳ − a·x̄

3

Dériver par rapport à a (à b fixé) et annuler — coefficient dominant Σ xᵢ² > 0 :

a·Σ xᵢ² + b·Σ xᵢ = Σ xᵢ·yᵢ

4

Résoudre le système 2 × 2 par substitution : avec Σ xᵢ = n·x̄, on obtient a·n·V(x) = n·cov(x ; y), d'où la formule — dès que V(x) > 0 (les xᵢ non tous égaux) :

Droite des moindres carrés (droite de régression de y en x)
a = cov(x ; y) / V(x)
b = ȳ − a·x̄
Elle minimise S(a ; b) = Σ (yᵢ − a·xᵢ − b)² : aucun autre couple (a ; b) ne fait mieux. Condition : V(x) > 0.
a·Σ xᵢ² + b·Σ xᵢ = Σ xᵢ·yᵢ
a·Σ xᵢ + n·b = Σ yᵢ
Les deux « équations normales » : la droite solution les vérifie exactement — c'est le test qui prouve que ton (a ; b) est le bon.
🧮 Vérification des équations normales — fil rouge sorgho
1

Données : Σ xᵢ = 30, Σ yᵢ = 50, Σ xᵢ² = 220, Σ xᵢ·yᵢ = 352, n = 5, droite a = 1,3, b = 2,2.

2

Équation (1) :

1,3 × 30 + 5 × 2,2 = 39 + 11 = 50 = Σ yᵢ ✓

3

Équation (2) :

1,3 × 220 + 2,2 × 30 = 286 + 66 = 352 = Σ xᵢ·yᵢ ✓

Le couple (1,3 ; 2,2) résout le système : deux données, deux contrôles exacts, zéro doute.

⚠️ Deux pièges de rédaction

(1) « La dérivée s'annule » ne prouve un minimum que si le coefficient dominant est positif (n > 0, Σ xᵢ² > 0) — cite-le, c'est la ligne qui rapporte les points. (2) Oublier la condition V(x) > 0 : si tous les xᵢ sont égaux, le nuage est une colonne verticale et la droite de régression n'existe pas.

Notion 3 · point_g

Toute droite de régression passe par G

La première équation normale donne b = ȳ − a·x̄, quelle que soit la pente a. En reportant dans l'équation de la droite :

La preuve en deux lignes — et sa conséquence
a·x̄ + b = a·x̄ + (ȳ − a·x̄) = ȳ
donc G(x̄ ; ȳ) ∈ D — pour toute pente a
C'est le contrôle n°1 du chapitre : si ton couple (a ; b) ne vérifie pas G ∈ D, l'erreur est certaine — retrouve-la avant de prédire quoi que ce soit. La même preuve vaut pour la droite de Mayer (G est le barycentre de G₁ et G₂).
y − ȳ = a·(x − x̄)
La « forme centrée » : droite de pente a passant par G, sans jamais calculer b. Pratique pour prédire en gardant G sous les yeux — et pour limiter les erreurs d'arrondi.
🧮 Prédire sans calculer b — données du mil
1

Données du mil (section 05) : x̄ = 420, ȳ = 900, pente a = 83/28. La droite s'écrit y − 900 = (83/28)·(x − 420).

2

Prévision pour x = 480 mm, une étape par ligne :

y = 900 + (83/28) × (480 − 420)

y = 900 + (83/28) × 60 ≈ 1 077,9

On retrouve la valeur de la section 05 (≈ 1 078 kg/ha) — sans avoir jamais calculé b.

Σ (yᵢ − a·xᵢ − b) = 0
Le « cadeau caché » : la somme des résidus (écarts verticaux des points à la droite) est exactement nulle. La droite de régression équilibre le nuage, au sens du centre de gravité — et c'est un contrôle de calcul gratuit.
⚠️ G ∈ D ne prouve pas que la droite est bonne !

La preuve vaut pour toute pente : une droite arbitraire de pente 7 avec b = ȳ − 7·x̄ passe aussi par G. Donc : (1) G ∈ D est un contrôle de calcul, pas un certificat de qualité — la qualité se juge avec r ; (2) si tu calcules b à partir d'un a arrondi, le contrôle G ∈ D reste vrai et cache l'erreur d'arrondi. Le vrai rempart : garder les fractions exactes jusqu'au bout.

Notion 4 · cov_r

Covariance en profondeur et coefficient r

La covariance mesure comment x et y s'écartent ensemble de leurs moyennes : elle multiplie les écarts — positif × positif ou négatif × négatif donne positif (la liaison « pousse dans le même sens »), positif × négatif donne négatif.

cov(x ; y) = (Σ nᵢ·xᵢ·yᵢ) / N − x̄·ȳ = (1/N)·Σ nᵢ·(xᵢ − x̄)·(yᵢ − ȳ)
Deux écritures équivalentes (« moyenne des produits moins produit des moyennes », ou écriture centrée). Propriétés : cov(x ; x) = V(x) ; cov(x ; α·y + β) = α·cov(x ; y) — changer l'unité de y multiplie la pente dans le même rapport ; et cov(x ; y) = 0 ne signifie PAS « aucune liaison » (parabole parfaite : cov = 0, liaison courbe intacte).
Le coefficient de corrélation linéaire
r = cov(x ; y) / (σₓ·σᵧ) = cov(x ; y) / (√(V(x))·√(V(y)))
Nombre sans unité, toujours entre −1 et 1 : r = ±1 si le nuage est exactement aligné (croissant pour +1, décroissant pour −1). Il ne manque jamais qu'une seule quantité nouvelle pour le calculer : V(y) = (Σ yᵢ²) / n − ȳ².
🧮 Le calcul complet de r — données du mil
1

Deja connu (section 05) : cov(x ; y) = 16 600, V(x) = 5 600, V(y) = 50 400. Les écart-types, arrondis seulement ici :

σₓ = √5 600 ≈ 74,83 ; σᵧ = √50 400 ≈ 224,50

2

Le produit, gardé exact :

σₓ·σᵧ = √(5 600 × 50 400) = √282 240 000 = 16 800

3

Le quotient :

r = 16 600 / 16 800 = 83/84 ≈ 0,99

4

Contrôle en or : σᵧ / σₓ = √(50 400 / 5 600) = √9 = 3, donc la formule a = r·(σᵧ / σₓ) prédit a = 3 × 83/84 = 83/28 — exactement la pente de la section 05 ✓.

Valeur de |r|ForceConclusion pratique
0,9 ≤ |r| ≤ 1très fortenuage presque aligné : ajustement justifié, prédictions fiables
0,7 ≤ |r| < 0,9fortetendance nette mais points dispersés : prudence sur les prédictions
0,5 ≤ |r| < 0,7modéréeliaison réelle mais faible : la droite ne résume qu'une partie du phénomène
|r| < 0,5faibleaucun ajustement linéaire sérieux : ne pas prédire avec la droite
Erreur fréquente — trois confusions sur r

(1) Écrire « r = 0,98 t/ha » : r est un quotient de produits d'écart-types, les unités se simplifient — c'est un nombre pur. (2) Arrondir les écart-types avant le quotient : garder les racines jusqu'à la fin. (3) Croire qu'un r ≈ 0 prouve « aucune relation » : des points parfaitement posés sur une parabole ont r ≈ 0 alors que la liaison est parfaite… mais courbe ! Et un r fort ne prouve jamais une cause : corrélation ≠ causalité.

🔍 Petite histoire des sciences
C'est en étudiant la taille des parents et celle de leurs enfants que Francis Galton remarque, vers 1886, que les enfants de parents très grands sont en moyenne un peu moins grands qu'eux : il nomme ce phénomène « régression vers la moyenne ». Le mot régression est depuis resté collé à la droite des moindres carrés.

Notion 5 · courbe

Quand le nuage se courbe : changer de variable

La droite est le seul modèle du programme… mais on peut changer ce qu'on met dedans. Si le nuage s'incurve, on pose z = f(y) : si cette fois les points (xᵢ ; zᵢ) sont presque alignés, on les ajuste par les moindres carrés, puis on revient à y en inversant f. Le détecteur rapide : différences yᵢ₊₁ − yᵢ à peu près constantes → droite ; différences croissant régulièrement → parabole, pose z = √y ; rapports yᵢ₊₁ / yᵢ voisins d'une constante → exponentiel, pose z = ln y.

TransformationModèle obtenuQuand l'utiliser
z = ln yy = e^b · e^(a·x)croissance multiplicative : les rapports yᵢ₊₁ / yᵢ sont voisins d'une constante ; y se multiplie quand x s'additionne
z = √yy = (a·x + b)²croissance parabolique : les différences yᵢ₊₁ − yᵢ croissent régulièrement ; données « carrés »
🧮 Exemple complet — z = √y sur la pépinière

Hauteur y (en cm) d'un plant de cacaoyer selon le nombre x de semaines : x = 1 ; 2 ; 3 ; 4 ; 5 et y = 4 ; 9 ; 16 ; 25 ; 36. Prévision pour x = 6.

1

Diagnostic. Les différences valent 5 ; 7 ; 9 ; 11 : elles augmentent de 2 à chaque pas — croissance parabolique. Le modèle linéaire direct donne y = 8x − 6 (avec r ≈ 0,99 trompeusement élevé !) mais ses résidus alternent +, −, +, − : le nuage ondule systématiquement autour de la droite.

2

Transformer. Les yᵢ sont des carrés parfaits :

zᵢ = √yᵢ = 2 ; 3 ; 4 ; 5 ; 6

Les différences des zᵢ valent toutes 1 : droite en vue.

3

Ajuster (x ; z). z̄ = 4, Σ xᵢ·zᵢ = 70, V(x) = 2 :

cov(x ; z) = 70/5 − 3 × 4 = 2

a = 2/2 = 1 ; b = 4 − 1 × 3 = 1 : soit z = x + 1 (r = 1 : alignement parfait).

4

Revenir à y. √y = x + 1 donne, en élevant au carré :

y = (x + 1)²

Vérification : (1 + 1)² = 4, (2 + 1)² = 9, …, (5 + 1)² = 36 ✓

5

Prédire. Pour x = 6 semaines : y = (6 + 1)² = 49 cm. Le linéaire aurait donné 8 × 6 − 6 = 42 cm : 7 cm d'écart (14 %) — voilà ce que le mauvais modèle coûtait.

⚠️ Deux façons de rater le retour

(1) Répondre en z : à la question « quelle hauteur pour x = 6 semaines ? », répondre « z = 7 » est faux — on revient toujours : y = 7² = 49 cm. (2) Ajuster dans le mauvais sens : on pose z = f(y) et on ajuste z en fonction de x — jamais l'inverse (même piège que la régression de x en y, section 06).

Notion 6 · etude_mil

Étude complète — pluviométrie et rendement du mil

Voici l'enchaînement intégral, du tableau brut à la prévision commentée : c'est le gabarit de la question 3 de tout sujet de statistiques. Six années consécutives (2019–2024) près de Niamey — pluviométrie annuelle xᵢ (mm) et rendement moyen du mil yᵢ (kg/ha).

Si on arrondit a ≈ 2,96 avant de calculer b :

b = 900 − 2,96 × 420 = −343,2 au lieu de −345,

et la prévision devient ≈ 1 075,8 au lieu de ≈ 1 077,9. Et le contrôle G ∈ D ne détectera pas l'erreur (b calculé à partir d'un a arrondi garde le passage par G). Règle d'or : valeurs exactes (fractions, racines) jusqu'au dernier résultat, arrondi seulement à la fin.

Notion 7 · deux_regressions

Deux régressions, réflexes Bac et grande synthèse

La droite y = a·x + b minimise les écarts verticaux : elle explique y par x. Certains énoncés demandent l'inverse — estimer x connaissant y — et alors il faut minimiser les écarts horizontaux : on échange les rôles, et le résultat n'est pas « la droite inverse ».

a' = cov(x ; y) / V(y) ; b' = x̄ − a'·ȳ (droite x = a'·y + b')
a × a' = r²
Les deux droites passent par G ; leur produit de pentes vaut r². Elles ne coïncident que si |r| = 1 (nuage exactement aligné). Sur le fil rouge sorgho : a' = 10,4 / 14 ≈ 0,74, b' ≈ −1,43, et a × a' ≈ 0,966 = r² ✓ — alors que « l'inverse de D » donne 0,77·y − 1,69 : ce n'est pas la même droite.

Les automatismes qui séparent la copie à 10 de la copie à 16 :

  • Un seul tableau de calcul (xᵢ², yᵢ², xᵢ·yᵢ et leurs sommes) : il sert à V(x), V(y) et cov.
  • Calculer x̄, ȳ et G avant toute autre chose — moyennes colonne par colonne.
  • Garder les valeurs exactes (fractions, racines) jusqu'au résultat final ; arrondir à la fin.
  • Contrôler G ∈ D : a·x̄ + b = ȳ — systématique, souvent demandé explicitement.
  • Vérifier −1 ≤ r ≤ 1 et le même signe pour r et a ; conclure avec la grille |r| vs 0,9.
  • Sens de la régression : prédire y → a = cov / V(x) ; estimer x → a' = cov / V(y). Ne jamais inverser.
  • Nuage courbe → différences croissantes : z = √y ; rapports constants : z = ln y — puis revenir à y.
  • Interpolation dedans = légitime ; extrapolation dehors = à signaler ; l'unité de la réponse annoncée.

Q1 — La droite des moindres carrés passe :

A) par l'origineB) par le point moyen GC) par le premier point du nuageD) par aucun point particulier
Voir la réponse
B. Toute droite de régression passe par G(x̄ ; ȳ) — preuve : b = ȳ − a·x̄ donne a·x̄ + b = ȳ, pour toute pente. C'est un contrôle de calcul, pas un certificat de qualité (le juge, c'est r).

Q2 — Avec cov(x ; y) = 16 600 et V(x) = 5 600, la pente vaut :

A) 83/28 ≈ 2,96B) 0,34C) 29,6D) 8,3
Voir la réponse
A. a = cov(x ; y) / V(x) = 16 600 / 5 600 = 83/28 ≈ 2,96. C'est l'étude du mil : on garde la fraction exacte pour calculer b = 900 − (83/28) × 420 = −345.

Q3 — Pour estimer x connaissant y, on utilise :

A) l'inverse de D : y = a·x + bB) la droite de régression de x en yC) la médiane de la sérieD) c'est impossible
Voir la réponse
B. a' = cov(x ; y) / V(y) et b' = x̄ − a'·ȳ : on échange les rôles. L'inverse de D n'est pas la droite de régression de x en y — elles ne coïncident que si |r| = 1 (alors a × a' = r² = 1).

📌 Ce qu'il faut retenir
  • [chaine] nuage → G → variances et covariance → D → r → jugement → prévision ; 7 contrôles réflexes (Σ nᵢ = N ; G ∈ D ; −1 ≤ r ≤ 1 ; signes ; unités ; arrondis)
  • [demonstration] Minimiser S(a ; b) = Σ (yᵢ − a·xᵢ − b)² : dériver selon b puis a, résoudre le système —
    a = cov(x ; y) / V(x) ; b = ȳ − a·x̄ (si V(x) > 0)
  • [point_g] Toute droite de régression passe par G ; forme centrée y − ȳ = a·(x − x̄) ; somme des résidus nulle
  • [cov_r] cov(x ; x) = V(x) ; cov(x ; α·y + β) = α·cov(x ; y) ;
    r = cov / (σₓ·σᵧ) sans unité, −1 ≤ r ≤ 1 ; |r| ≥ 0,9 justifie l'ajustement
  • [courbe] différences croissantes → z = √y, modèle y = (a·x + b)² ; rapports constants → z = ln y, modèle y = e^b·e^(a·x) ; toujours revenir à y
  • [etude_mil] G(420 ; 900) ; D : y = (83/28)·x − 345 ; r = 83/84 ≈ 0,99 ; prévision ≈ 1 078 kg/ha à 480 mm (interpolation), 1 730 à 700 mm (extrapolation risquée) ; a ≈ 2,96 kg/ha par mm
  • [deux_regressions] Estimer x connaissant y : a' = cov / V(y), b' = x̄ − a'·ȳ ; a × a' = r² ; coïncidence ssi |r| = 1 — jamais l'inverse de D
  • [reflexes] Valeurs exactes jusqu'au bout, un seul tableau, contrôles systématiques, conclusion en contexte avec l'unité
