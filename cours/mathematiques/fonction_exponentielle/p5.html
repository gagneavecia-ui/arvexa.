02
Réflexes

Les 10 réflexes de calcul

À chaque situation son geste automatique — le signal de l'énoncé déclenche l'action :

Situation → action
  • Produit ou quotient d'exponentielles → tout ramener aux exposants : multiplier ⇒ additionner, diviser ⇒ soustraire, puissance ⇒ multiplier ; objectif : une seule exponentielle. (P1)
  • Somme d'exponentielles à étudier → factoriser par la plus petite : e^(2x) − 3e^x = e^x(e^x − 3). (P1)
  • Exposant qui n'est pas x tout seul → (e^u)' = u'·e^u : dériver l'exposant d'abord, vérifier u' comme facteur. (P2)
  • Produit avec exp à dériver → (uv)' : deux termes, puis factorisation par e^x ; le signe se lit sur le facteur restant. (P2)
  • e^(2x) et e^x dans la même équation → poser X = e^x (X > 0), trinôme, filtrer, revenir par x = ln X. (P4)
  • e^x = a ou e^x > a → filtre du signe d'abord : a ≤ 0 → ∅ (ou ℝ pour >) sans calcul ; a > 0 → ln. (P3–P4)
  • Division par un négatif dans une inéquation → le sens se retourne ; le vérifier deux fois. (P4)
  • Limite « +∞/+∞ » ou « ∞ × 0 » → nommer l'outil : « d'après les croissances comparées… ». (P3–P4)
  • Primitive avec exponentielle → comparer le facteur à u' : exacte → e^u + c ; proportionnelle → λe^u + c ; affine → (1/k)e^(kx+b) + c ; x devant e^(ax) → (x/a − 1/a²)e^(ax). (P2–P4)
  • Problème concret → écrire N(t) = N₀e^(kt), traduire la question, simplifier par N₀, appliquer ln, conclure avec l'unité. (P4)
💡 Le réflexe universel de vérification

Trois contrôles de trois secondes, quel que soit le calcul : signe (e^(quoi que ce soit) > 0 — un résultat négatif est faux, une racine X ≤ 0 est rejetée), substitution (remettre la solution dans l'équation de départ), dérivation (toute primitive se vérifie en dérivant).

Pièges

Les 10 erreurs à bannir

Ces dix erreurs coûtent des points à chaque épreuve — chacune se corrige en une ligne :

⚠️ Les 10 erreurs, avec le faux et le vrai
  • Écrire e^(a+b) = e^a + e^b : l'exponentielle ne distribue pas sur la somme — e + e ≈ 5,44 mais e² ≈ 7,39. Une somme se factorise, elle ne se simplifie pas. (P1)
  • Confondre e^(−a) et −e^a : e^(−1) ≈ 0,368 est positif (un inverse) ; −e ≈ −2,718 est négatif (un opposé). (P1)
  • Oublier le facteur u' : (e^(3x))' = 3e^(3x), jamais e^(3x) tout seul — l'erreur la plus sanctionnée du chapitre. (P2)
  • Mélanger (2e^x)' et (e^(2x))' : le premier vaut 2e^x (facteur qui traverse), le second 2e^(2x) (le 2 est dans l'exposant). (P2)
  • Primitive de e^(3x) : écrire e^(3x) : faux — trois fois trop en dérivant. La bonne : (1/3)e^(3x). (P2)
  • Écrire e^x → −∞ en −∞ : e^x > 0 toujours, la limite est 0 ; e^x = 0 n'a aucune solution. (P3)
  • Garder une racine X ≤ 0 : après X = e^x, toute racine ≤ 0 est rejetée — « X = −2 donc x = ln(−2) » est doublement faux. (P4)
  • Sauter le filtre du second membre : e^x = −4 → S = ∅ avant tout calcul ; e^x > −1 → S = ℝ. Pas de ln sur un négatif. (P3–P4)
  • Diviser par (e^x − 3) : illégal — ce facteur peut s'annuler (c'est la solution !). On divise par e^x seul, ou on factorise. (P4)
  • Confondre l'abscisse et la valeur d'un extremum : x·e^x atteint son minimum en x = −1, et il vaut −1/e ≈ −0,37 (pas −e). (P4)

05
Fil rouge

Plan d'attaque d'un exercice type Bac

Le Bac enchaîne presque toujours : dérivée à factoriser → signe et tableau → limites (avec une indétermination à lever) → zéros et tangente. Voici le fil rouge intégral sur la fonction vedette f(x) = (2x + 1)·e^x — à refaire en cachant les solutions.

🧮 Le fil rouge — étudier f(x) = (2x + 1)·e^x

1. Dérivée factorisée. Produit de u(x) = 2x + 1 et v(x) = e^x, deux termes :

f'(x) = 2·e^x + (2x+1)·e^x = (2x + 3)·e^x

2. Signe et tableau. e^x > 0 toujours : le signe de f' est celui de (2x + 3), nul en x = −3/2. Minimum f(−3/2) = −2e^(−3/2) ≈ −0,45 :

x : −∞ → −3/2 → +∞ ; f' : − 0 + ; f : 0 ↘ −0,45 ↗ +∞

3. Limites, outil nommé. En −∞ : forme « −∞ × 0 » — on décompose f(x) = 2x·e^x + e^x, et d'après les croissances comparées, x·e^x → 0 et e^x → 0 : f → 0 (asymptote y = 0). En +∞ : produit de deux +∞, pas d'indétermination : f → +∞.

4. Zéro et signe. f(x) = 0 ⇔ 2x + 1 = 0 ⇔ x = −1/2 (car e^x ≠ 0) : f < 0 avant — la courbe passe sous son asymptote avant de remonter.

5. Tangente en A(0 ; 1). f(0) = 1 et f'(0) = 3 :

y = 3(x − 0) + 1 = 3x + 1

Contrôles : redévelopper f' pour retrouver les deux termes ; substituer x = −1/2 dans f ; la tangente passe bien par (0 ; 1).

La stratégie générale en 5 lignes
  • Range : simplifie ou factorise l'expression avant tout.
  • Dérive avec la bonne règle et factorise par l'exponentielle.
  • Lis le signe : l'exponentielle disparaît (> 0), le facteur restant décide.
  • Termine par le tableau et les limites nommées.
  • Contrôle : signe global, substitution, cohérence du dessin. Toujours.

08
L'outil final

La figure du chapitre — la courbe de exp, à refaire sans rien mémoriser

Toutes les questions du chapitre passent par le même dessin : le signe (e^x > 0 : jamais sous l'axe), les variations (dérivée e^x > 0 : croissante), les limites (asymptote y = 0 en −∞, explosion en +∞), la position relative (e^x ≥ x + 1 : toujours au-dessus de sa tangente) et le miroir avec la courbe de ln. La voici complète :

📐 La méthode en 6 étapes — 60 secondes, sans mémoriser
  1. Le squelette (20 s). Deux axes ; la fonction vit sur tout ℝ ; trace l'asymptote horizontale y = 0 côté gauche — la courbe s'y collera sans jamais la toucher, car e^x > 0.
  2. Les deux points magiques (15 s). Place A(0 ; 1) — car e^0 = 1 — et B(1 ; e ≈ 2,72) — car e^1 = e. Deux points, et la silhouette est fixée.
  3. La tangente en 0 (15 s). Trace y = x + 1 : elle passe par A avec une pente de 1 (car (e^x)' vaut 1 en 0). Contrôle capital : la courbe est TOUJOURS au-dessus — e^x ≥ x + 1, égalité seulement en 0.
  4. Le sens (10 s). Strictement croissante (dérivée e^x > 0) et convexe : tourne vers le haut, de plus en plus raide — en chaque point, la pente vaut la hauteur.
  5. Le tracé (30 s). Depuis la gauche collée à l'asymptote, frôler y = x + 1 en A, passer par B, puis décoller vers +∞ (déjà plus haut que 7 en x = 2).
  6. Le contrôle (10 s). Jamais sous l'axe ; A et B sur la courbe ; tangente frôlée sans être coupée ; et pliée le long de la droite y = x, elle coïncide avec la courbe de ln — chaque point (t ; e^t) a son miroir (e^t ; t).
✅ Ce que tu dois VRAIMENT retenir

Rien par cœur. Cinq gestes : l'asymptote y = 0 à gauche ; deux points — (0 ; 1) et (1 ; e) ; la tangente y = x + 1, courbe toujours au-dessus ; croissante et convexe, pente = hauteur ; le contrôle final par la symétrie avec ln le long de y = x. Avec ces cinq gestes, tu redresses la courbe en moins d'une minute — et chaque contrôle raté te dit quel geste revoir.

📌 Ce qu'il faut retenir
  • [fondations] Réciproque : ln(e^x) = x (tout x), e^(ln x) = x (x > 0) ; e^x > 0 toujours ; e^(a+b) = e^a × e^b — jamais e^a + e^b
  • [calcul] Produit → additionner les exposants ; quotient → soustraire ; puissance → multiplier ; somme → factoriser par la plus petite exponentielle
  • [dérivées] (e^x)' = e^x ; (e^u)' = u'·e^u — le facteur u' est l'erreur n°1 ; (u·e^x)' = (u' + u)·e^x
  • [primitives] u'·e^u → e^u + c ; e^(kx+b) → (1/k)e^(kx+b) + c ; x·e^(ax) → (x/a − 1/a²)·e^(ax) — vérifier en dérivant
  • [limites] e^x → 0 en −∞ (jamais −∞), +∞ en +∞ ; croissances comparées : e^x/xⁿ → +∞, xⁿ·e^(−x) → 0 — toujours nommer l'outil
  • [équations] Filtre du signe d'abord : a ≤ 0 → ∅ ou ℝ ; sinon ln ; X = e^x avec X > 0 : rejeter toute racine ≤ 0 ; division par e^x légale, par (e^x − a) interdite
  • [études] Le duel : e^x/x → +∞ (min e en 1) ; x·e^x : min −1/e en −1 ; x²·e^x : zéro double en 0 ; e^x ≥ x + 1
  • [applications] N(t) = N₀·e^(kt) ; doublement ln 2/k ; demi-vie ln 2/λ ; intérêts composés C₀(1 + t)ⁿ ou C₀·e^(rt)
  • [figure] La courbe de exp : asymptote y = 0, deux points (0 ; 1) et (1 ; e), tangente y = x + 1, croissante et convexe, miroir de ln par y = x
