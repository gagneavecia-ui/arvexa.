Lancers de ballon et jet d'eau

Les trois lancers de la série sont ici menés de bout en bout, avec à chaque fois une vérification du résultat par un second chemin.

x(t) = v₀·cos α·t ; z(t) = −½·g·t² + v₀·sin α·t + z₀ ; H = v₀²·sin²α/(2g) ; D = v₀²·sin 2α/g

Les quatre formules du chapitre — H et D supposent départ et arrivée à la même altitude (z₀ = 0).

✏️ Exercice 1 — Le lancer de ballon (★)

Données : v₀ = 10 m·s⁻¹ ; α = 30° ; z₀ = 0 ; g = 9,8 m·s⁻² ; cos 30° = 0,866 ; sin 30° = 0,50.

1

Composantes initiales : vₓ = v₀·cos α = 10 × 0,866 = 8,66 ≈ 8,7 m·s⁻¹ (constante) ; v′₀ = v₀·sin α = 10 × 0,50 = 5,0 m·s⁻¹.

2

Chute libre : aₓ = 0 et accélération verticale −g. En intégrant deux fois (vitesse horizontale initiale vₓ, verticale v′₀) : x(t) = 8,7·t et z(t) = −4,9·t² + 5,0·t (z₀ = 0).

3

Trajectoire : on exprime t = x/8,7 puis on remplace dans z(t) : z = −4,9·(x/8,7)² + 5,0·(x/8,7) = −(4,9/75,7)·x² + 0,575·x, soit z = −0,065·x² + 0,58·x (x et z en m).

4

✅ Vérification de la trajectoire : son sommet est en x = 0,575/(2×0,065) = 4,4 m, où z = −0,065×4,4² + 0,575×4,4 = −1,26 + 2,53 = 1,27 m — on retrouve la flèche du calcul suivant (1,28 m) : cohérent.

5

Flèche : H = v₀²·sin²α/(2g) = 10²×0,50²/19,6 = 25/19,6 = 1,28 ≈ 1,3 m.

6

Portée : D = v₀²·sin 2α/g = 100×0,866/9,8 = 86,6/9,8 = 8,8 m. ✅ Vérification : t_D = 2·v₀·sin α/g = 10/9,8 = 1,02 s, puis x(1,02) = 8,66×1,02 = 8,8 m ✓.

D ≈ 8,8 m ; H ≈ 1,3 m

Le ballon retombe au sol après 1,02 s de vol.

⚠️ Piège : H et D ne sont valables que si départ et arrivée ont la même altitude (z₀ = 0) ; sinon, il faut résoudre un trinôme (voir le dossier de la pierre, corrigés partie 02).
✏️ Exercice 2 — Le jet d'eau du jardinier (★★)

Données : v₀ = 15 m·s⁻¹ ; α = 60° ; cos 60° = 0,50 ; sin 60° = 0,866.

1

Composantes : vₓ = 15×0,50 = 7,5 m·s⁻¹ ; v′₀ = 15×0,866 = 13,0 m·s⁻¹. D'où x(t) = 7,5·t et z(t) = −4,9·t² + 13,0·t.

2

Sommet : la composante verticale v′ = v′₀ − g·t s'annule pour tₛ = 13,0/9,8 = 1,33 s.

3

Flèche : H = z(tₛ) = −4,9×1,33² + 13,0×1,33 = −8,67 + 17,29 = 8,6 m.

4

✅ Vérification par la formule : H = v₀²·sin²α/(2g) = 225×0,75/19,6 = 168,75/19,6 = 8,6 m ✓ (deux chemins, même valeur).

5

Durée totale du jet : t_D = 2·tₛ = 2,65 s (ou 2·v₀·sin α/g = 26,0/9,8 = 2,65 s).

6

Portée : D = vₓ·t_D = 7,5×2,65 = 19,9 m. ✅ Vérification : D = v₀²·sin 2α/g = 225×sin 120°/9,8 = 194,9/9,8 = 19,9 m ✓.

tₛ = 1,33 s ; H = 8,6 m ; D = 19,9 m

Le jet retombe au sol après 2,65 s, loin devant la plante des 8,0 m : le jet la dépasse largement.

⚠️ Piège : ne pas confondre sin²α (ici 0,75) et sin 2α (ici sin 120° = 0,866) !
✏️ Exercice 3 — Deux angles pour une même portée (★★)

Données : v₀ = 12 m·s⁻¹ ; α₁ = 30° ; α₂ = 60° ; sin 60° = sin 120° = 0,866 ; sin²30° = 0,25 ; sin²60° = 0,75.

1

Portée du premier tir : D₁ = v₀²·sin 2α₁/g = 144×0,866/9,8 = 124,7/9,8 = 12,7 m.

2

Portée du second : D₂ = 144×sin 120°/9,8 = 144×0,866/9,8 = 12,7 m → D₁ = D₂ : les angles complémentaires donnent la même portée car sin 2(90° − α) = sin 2α.

3

Flèches : H₁ = 144×0,25/19,6 = 36/19,6 = 1,8 m ; H₂ = 144×0,75/19,6 = 108/19,6 = 5,5 m.

4

Rapport : H₂/H₁ = 0,75/0,25 = 3 → le tir à 60° culmine trois fois plus haut que le tir à 30°.

5

À mi-portée, chaque ballon culmine à sa flèche : H₁ = 1,8 m, inférieure à 2,0 m → ballon tendu bloqué ; H₂ = 5,5 m, supérieure à 2,0 m → c'est le tir à 60° qui passe.

D₁ = D₂ = 12,7 m ; H₁ = 1,8 m ; H₂ = 5,5 m

Même portée, trajectoires très différentes.

⚠️ Méthode : pour comparer deux angles, calcule toujours séparément sin 2α (portée) et sin²α (flèche).

Chutes verticales et lancer horizontal

Ici la vitesse initiale est verticale, nulle ou horizontale : les équations se simplifient mais la vigilance reste de mise, surtout sur les racines carrées et les signes.

✏️ Exercice 4 — La bille lâchée du toit (★)

Données : h = 20 m ; v₀ = 0 ; g = 9,8 m·s⁻² ; √4,08 = 2,02 ; √392 = 19,8.

1

Lâchée sans vitesse : z(t) = z₀ − ½·g·t² = 20 − 4,9·t² (z en m, t en s) ; mouvement rectiligne vertical accéléré.

2

Le sol est atteint quand z = 0 : 4,9·t² = 20 → t_c = √(20/4,9) = √4,08 = 2,02 ≈ 2,0 s.

3

Vitesse d'impact : v = √(2·g·h) = √(2×9,8×20) = √392 = 19,8 ≈ 20 m·s⁻¹, dirigée vers le bas.

4

✅ Vérification : v = g·t_c = 9,8×2,02 = 19,8 m·s⁻¹ ✓ (deux chemins, même valeur).

t_c = 2,0 s ; v = 19,8 m·s⁻¹ ≈ 20 m·s⁻¹

Vingt mètres de chute libre durent à peine deux secondes.

⚠️ Piège : la durée vient de t_c = √(2h/g) — ne pas oublier la racine carrée !
✏️ Exercice 5 — Balle lancée verticalement (★)

Données : z₀ = 1,5 m ; v₀ = 5,0 m·s⁻¹ ; g = 9,8 m·s⁻² ; √54,4 = 7,38.

1

Équations : v(t) = v₀ − g·t = 5,0 − 9,8·t (m·s⁻¹) ; z(t) = z₀ + v₀·t − ½·g·t² = 1,5 + 5,0·t − 4,9·t² (m).

2

Sommet : v = 0 → tₛ = 5,0/9,8 = 0,51 s ; z_max = z₀ + v₀²/(2g) = 1,5 + 25/19,6 = 1,5 + 1,28 = 2,78 ≈ 2,8 m.

3

✅ Vérification : z(0,51) = 1,5 + 5,0×0,51 − 4,9×0,51² = 1,5 + 2,55 − 1,27 = 2,78 m ✓.

4

Retour au sol : 1,5 + 5,0·t − 4,9·t² = 0 → Δ = 5,0² + 4×4,9×1,5 = 25 + 29,4 = 54,4 ; √Δ = 7,38 ; t = (5,0 + 7,38)/9,8 = 1,26 ≈ 1,3 s (racine positive).

5

Vitesse d'impact : v = 5,0 − 9,8×1,26 = −7,4 m·s⁻¹ → la balle frappe le sol à 7,4 m·s⁻¹ vers le bas (le signe − traduit la descente).

6

✅ Vérification énergétique : v² = v₀² − 2·g·(0 − z₀) = 25 + 29,4 = 54,4 → |v| = 7,4 m·s⁻¹ ✓.

z_max = 2,8 m ; retour au sol à t = 1,3 s ; v = −7,4 m·s⁻¹

La hauteur maximale dépasse le point de lancement de 1,28 m seulement.

⚠️ Piège : deux racines pour le trinôme — ne garder que t positif ; et ne pas oublier z₀ = 1,5 m dans z(t).
✏️ Exercice 6 — La bille qui quitte la table (★★)

Données : h = 1,25 m ; v₀ = 4,0 m·s⁻¹ ; √0,255 = 0,505 ; √40,5 = 6,4.

1

Horizontalement, aucune force (air négligé) : aₓ = 0 → vₓ = v₀ = 4,0 m·s⁻¹ reste constante ; x(t) = 4,0·t.

2

Verticalement : z(t) = h − ½·g·t² = 1,25 − 4,9·t². Le sol est atteint pour t_c = √(2h/g) = √(2,50/9,8) = √0,255 = 0,51 s : la durée de chute ne dépend pas de v₀ !

3

Distance horizontale : x_a = v₀·t_c = 4,0×0,505 = 2,0 m.

4

Vitesse d'arrivée : composante verticale v′ = −g·t_c = −9,8×0,505 = −4,95 ≈ −5,0 m·s⁻¹ ; norme v = √(v₀² + v′²) = √(16,0 + 24,5) = √40,5 = 6,4 m·s⁻¹.

5

Direction : tan θ = |v′|/v₀ = 4,95/4,0 = 1,24 → θ = 51° sous l'horizontale.

6

✅ Vérification énergétique : v = √(v₀² + 2·g·h) = √(16,0 + 24,5) = 6,4 m·s⁻¹ ✓ (même valeur).

t_c = 0,51 s ; x_a = 2,0 m ; v = 6,4 m·s⁻¹ à 51° sous l'horizontale

Un lancer horizontal, c'est une chute libre qui avance.

⚠️ Piège : lancer plus fort ne raccourcit pas la chute — la durée ne dépend que de h !
