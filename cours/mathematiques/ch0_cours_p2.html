01
Définition

Le module d'un nombre complexe

Dans le plan complexe, un nombre $z = a + ib$ est représenté par un point $M(a, b)$. On peut naturellement mesurer la distance entre l'origine $O$ et ce point $M$. Cette distance s'appelle le module de $z$.

Définition du module
$$|z| = \sqrt{a^2 + b^2}$$
Le module de $z = a + ib$ est la distance $OM$ dans le plan complexe

Le module se note $|z|$ (comme la valeur absolue) ou parfois $r$. C'est toujours un réel positif ou nul. Contrairement aux apparences, ce n'est pas un complexe.

Interprétation géométrique

Le module $|z|$ est la longueur du segment $OM$ dans le plan complexe. C'est l'analogue de la valeur absolue $|x|$ sur la droite réelle, qui mesure la distance entre $x$ et $0$.

📐 La formule des distances (cruciale !)

Plus généralement, la distance entre deux points $A$ et $B$ du plan complexe s'obtient par le module de la différence des affixes :

$$AB = |z_B - z_A|$$

C'est LA formule qui relie complexes et géométrie. On la réutilisera constamment dans les parties géométriques.

Exemple de calcul de distance

$A(2 + i)$ et $B(-1 + 2i)$. Calculer $AB$ :

$$AB = |z_B - z_A| = |(-1 + 2i) - (2 + i)| = |-3 + i|$$

$$AB = \sqrt{(-3)^2 + 1^2} = \sqrt{10}$$

Propriétés immédiates

  • $|z| \geq 0$ pour tout complexe $z$ — un module est toujours positif ou nul.
  • $|z| = 0 \iff z = 0$ — seul le complexe nul a un module nul.
  • $|z| = |-z|$ — l'opposé a le même module.
  • $|z| = |\bar{z}|$ — le conjugué a le même module (démontré en partie 3).
  • Si $z$ est réel, alors $|z|$ est la valeur absolue classique.

Module de quelques cas simples

  • Réel pur : $z = a$, alors $|z| = |a|$ (valeur absolue classique).
  • Imaginaire pur : $z = ib$, alors $|z| = |b|$.
  • Cas général : $z = a + ib$, on applique la formule $|z| = \sqrt{a^2 + b^2}$.
💡 Astuce : les triplets pythagoriciens

Certains modules reviennent tout le temps en exercice. Apprends-les par cœur :

  • $|3 + 4i| = 5$ (triplet 3-4-5)
  • $|6 + 8i| = 10$, $|9 + 12i| = 15$ (multiples du 3-4-5)
  • $|5 + 12i| = 13$ (triplet 5-12-13)
  • $|1 + i| = \sqrt{2}$, $|1 + i\sqrt{3}| = 2$, $|\sqrt{3} + i| = 2$ (angles remarquables)
Exemples de calcul

$z = 3 + 4i$ : $|z| = \sqrt{3^2 + 4^2} = \sqrt{9 + 16} = \sqrt{25} = 5$

$z = -5$ : $|z| = \sqrt{(-5)^2 + 0^2} = \sqrt{25} = 5$

$z = 2i$ : $|z| = \sqrt{0^2 + 2^2} = \sqrt{4} = 2$

$z = 1 - i$ : $|z| = \sqrt{1^2 + (-1)^2} = \sqrt{2}$

✏️ À toi de jouer

Calculer $|5 - 12i|$, puis la distance entre $A(1 + i)$ et $B(4 - 2i)$.

Voir la solution

$|5 - 12i| = \sqrt{25 + 144} = \sqrt{169} = 13$ (triplet 5-12-13)

$AB = |(4 - 2i) - (1 + i)| = |3 - 3i| = \sqrt{9 + 9} = \sqrt{18} = 3\sqrt{2}$

Attention

Le module n'est pas la somme des modules des parties. Par exemple, pour $z = 3 + 4i$, on a $|z| = 5$, et non $3 + 4 = 7$. Il faut bien élever au carré, additionner, puis prendre la racine.

L'inégalité triangulaire

$$|z + z'| \leq |z| + |z'|$$
Le module de la somme est inférieur ou égal à la somme des modules.

Interprétation géométrique : dans un triangle, un côté est toujours plus court que la somme des deux autres. Le chemin $O \to A \to (A+B)$ est plus long (ou aussi long) que le chemin direct $O \to (A+B)$.

Exemple

Avec $z = 1 + i$ et $z' = 1 - i$ :

$|z + z'| = |2| = 2$ et $|z| + |z'| = \sqrt{2} + \sqrt{2} = 2\sqrt{2} \approx 2{,}83$

On a bien $2 \leq 2\sqrt{2}$. L'égalité n'a lieu que si $z$ et $z'$ ont le même argument (points alignés du même côté de $O$).

En physique

Un signal sinusoïdal s'écrit $z = A \cdot e^{i\varphi}$ : le module $A$ est l'amplitude du signal, l'argument $\varphi$ est la phase. C'est pourquoi on dit qu'un complexe code « une force et une direction » — exactement comme un vecteur.

02
Définition

L'argument d'un nombre complexe

Le module mesure la distance. Mais il manque une information : dans quelle direction se trouve le point $M$ ? C'est le rôle de l'argument : l'angle que fait le vecteur $OM$ avec l'axe des réels.

Définition de l'argument
$$\theta = \arg(z)$$
Angle orienté entre l'axe des réels positifs et le vecteur $OM$

L'argument se mesure en radians, dans le sens direct (sens inverse des aiguilles d'une montre). Il est défini modulo $2\pi$ : si $\theta$ est un argument de $z$, alors $\theta + 2k\pi$ est aussi un argument de $z$, pour tout entier $k$.

Argument principal

Pour éviter l'ambiguïté, on choisit souvent l'argument principal, noté $\operatorname{Arg}(z)$ (avec majuscule), qui est l'unique argument appartenant à l'intervalle $]-\pi, \pi]$. C'est celui qu'on affiche par convention.

Comment calculer l'argument ?

Pour $z = a + ib \neq 0$, on utilise les relations suivantes, qui découlent directement de la trigonométrie dans le triangle rectangle :

$$\cos\theta = \frac{a}{|z|}$$
Le cosinus de l'argument est la partie réelle divisée par le module.
$$\sin\theta = \frac{b}{|z|}$$
Le sinus de l'argument est la partie imaginaire divisée par le module.

Connaissant $\cos\theta$ et $\sin\theta$, on identifie l'angle $\theta$ à l'aide des valeurs remarquables du cercle trigonométrique.

💡 Méthode : vérifier le quadrant d'abord

Avant de chercher $\theta$, regarde les signes de $a$ et $b$ pour savoir dans quel quadrant se trouve le point :

  • $a > 0$ et $b > 0$ → $\theta \in \left]0, \dfrac{\pi}{2}\right[$ (Q1)
  • $a < 0$ et $b > 0$ → $\theta \in \left]\dfrac{\pi}{2}, \pi\right[$ (Q2)
  • $a < 0$ et $b < 0$ → $\theta \in \left]-\pi, -\dfrac{\pi}{2}\right[$ (Q3)
  • $a > 0$ et $b < 0$ → $\theta \in \left]-\dfrac{\pi}{2}, 0\right[$ (Q4)

Cette vérification élimine la moitié des candidats et évite 90 % des erreurs d'argument !

Angles de référence à connaître

Trois angles reviennent systématiquement dans les exercices :

$\dfrac{\pi}{6}$
$\cos = \dfrac{\sqrt{3}}{2}$
$\sin = \dfrac{1}{2}$
$\tan = \dfrac{\sqrt{3}}{3}$
$\dfrac{\pi}{4}$
$\cos = \dfrac{\sqrt{2}}{2}$
$\sin = \dfrac{\sqrt{2}}{2}$
$\tan = 1$
$\dfrac{\pi}{3}$
$\cos = \dfrac{1}{2}$
$\sin = \dfrac{\sqrt{3}}{2}$
$\tan = \sqrt{3}$

Pour les autres quadrants, on utilise les symétries du cercle trigonométrique : $\pi - \theta$ (symétrie par l'axe des imaginaires), $-\theta$ (symétrie par l'axe des réels), $\pi + \theta$ (symétrie par l'origine).

Arguments remarquables

$0$
$\arg(1) = 0$
réels positifs
$\dfrac{\pi}{2}$
$\arg(i) = \dfrac{\pi}{2}$
imaginaires purs positifs
$\pi$
$\arg(-1) = \pi$
réels négatifs
$-\dfrac{\pi}{2}$
$\arg(-i) = -\dfrac{\pi}{2}$
imaginaires purs négatifs
Exemple guidé

Calculer le module et l'argument de $z = 1 + i$.

Étape 1 — Module : $|z| = \sqrt{1^2 + 1^2} = \sqrt{2}$

Étape 2 — Cos et sin : $\cos\theta = \dfrac{1}{\sqrt{2}} = \dfrac{\sqrt{2}}{2}$ et $\sin\theta = \dfrac{1}{\sqrt{2}} = \dfrac{\sqrt{2}}{2}$

Étape 3 — Identification : l'angle dont le cosinus et le sinus valent $\dfrac{\sqrt{2}}{2}$ est $\dfrac{\pi}{4}$.

Conclusion : $|z| = \sqrt{2}$ et $\arg(z) = \dfrac{\pi}{4}$.

Exemple avec vérification du quadrant

Calculer le module et l'argument de $z = -1 - i$.

Étape 1 — Module : $|z| = \sqrt{(-1)^2 + (-1)^2} = \sqrt{2}$

Étape 2 — Quadrant : $a = -1 < 0$ et $b = -1 < 0$ → quadrant 3, donc $\theta \in \left]-\pi, -\dfrac{\pi}{2}\right[$.

Étape 3 — Cos et sin : $\cos\theta = -\dfrac{\sqrt{2}}{2}$ et $\sin\theta = -\dfrac{\sqrt{2}}{2}$

Étape 4 — Identification : le seul angle du quadrant 3 qui convient est $\theta = -\dfrac{3\pi}{4}$ (et non $\dfrac{\pi}{4}$ !).

Conclusion : $|z| = \sqrt{2}$ et $\arg(z) = -\dfrac{3\pi}{4}$.

✏️ À toi de jouer

Déterminer l'argument principal de $z = -1 + i$.

Voir la solution

$|z| = \sqrt{2}$ · $a = -1 < 0$, $b = 1 > 0$ → quadrant 2, donc $\theta \in \left]\dfrac{\pi}{2}, \pi\right[$.

$\cos\theta = -\dfrac{\sqrt{2}}{2}$ et $\sin\theta = \dfrac{\sqrt{2}}{2}$ → $\theta = \dfrac{3\pi}{4}$ ✅

Attention

L'argument n'est pas défini pour $z = 0$ : le point $O$ n'a pas de direction privilégiée. On dit souvent que $\arg(0)$ est indéterminé.

Piège de la calculatrice

Si tu utilises $\tan\theta = \dfrac{b}{a}$ (ou la fonction arctan), la calculatrice donne toujours un angle dans $\left]-\dfrac{\pi}{2}, \dfrac{\pi}{2}\right[$ — elle ne connaît pas le quadrant. Exemple : pour $z = -1 - i$, $\arctan(1) = \dfrac{\pi}{4}$, mais la bonne réponse est $-\dfrac{3\pi}{4}$. Toujours corriger avec le quadrant !

03
Écriture

Forme trigonométrique

Connaissant le module $r = |z|$ et un argument $\theta = \arg(z)$, on peut réécrire $z$ sous une nouvelle forme, dite trigonométrique.

Forme trigonométrique
$$z = r(\cos\theta + i\sin\theta)$$
avec $r = |z| > 0$ et $\theta = \arg(z)$

Cette écriture met en évidence les deux informations géométriques : $r$ (la distance) et $\theta$ (l'angle). Elle est équivalente à la forme algébrique $z = a + ib$, avec les relations $a = r\cos\theta$ et $b = r\sin\theta$.

Unicité de la forme trigonométrique

Avec les conventions $r > 0$ et $\theta \in ]-\pi, \pi]$, la forme trigonométrique est unique. C'est ce qui permet de comparer deux complexes en comparant leurs modules et leurs arguments : $r(\cos\theta + i\sin\theta) = r'(\cos\theta' + i\sin\theta')$ ⟺ $r = r'$ et $\theta = \theta'$ (modulo $2\pi$).

Piège : le module doit être positif

Dans une forme trigonométrique, $r$ est toujours positif. Une écriture comme $-2\left(\cos\dfrac{\pi}{3} + i\sin\dfrac{\pi}{3}\right)$ n'est pas une forme trigonométrique ! On la corrige : le signe « $-$ » vaut une rotation d'un demi-tour, donc :

$$-2\left(\cos\dfrac{\pi}{3} + i\sin\dfrac{\pi}{3}\right) = 2\left(\cos\left(\dfrac{\pi}{3} + \pi\right) + i\sin\left(\dfrac{\pi}{3} + \pi\right)\right) = 2\left(\cos\dfrac{4\pi}{3} + i\sin\dfrac{4\pi}{3}\right)$$

De même, un facteur $i$ devant vaut une rotation de $\dfrac{\pi}{2}$ : $2i(\cos\theta + i\sin\theta) = 2\left(\cos\left(\theta + \dfrac{\pi}{2}\right) + i\sin\left(\theta + \dfrac{\pi}{2}\right)\right)$.

Passer de la forme algébrique à la forme trigonométrique

1
Calculer le module

$r = \sqrt{a^2 + b^2}$

2
Factoriser par $r$

$z = r\left(\dfrac{a}{r} + i \cdot \dfrac{b}{r}\right)$

3
Identifier $\cos\theta$ et $\sin\theta$

$\cos\theta = \dfrac{a}{r}$ et $\sin\theta = \dfrac{b}{r}$

4
Déterminer $\theta$

À l'aide des valeurs remarquables et de la vérification du quadrant.

🎓 Exemple complet

Écrire $z = 1 + i$ sous forme trigonométrique.

Étape 1 : $r = |z| = \sqrt{1^2 + 1^2} = \sqrt{2}$

Étape 2 : $z = \sqrt{2}\left(\dfrac{1}{\sqrt{2}} + i \cdot \dfrac{1}{\sqrt{2}}\right) = \sqrt{2}\left(\dfrac{\sqrt{2}}{2} + i\dfrac{\sqrt{2}}{2}\right)$

Étape 3 : On identifie $\cos\theta = \dfrac{\sqrt{2}}{2}$ et $\sin\theta = \dfrac{\sqrt{2}}{2}$, donc $\theta = \dfrac{\pi}{4}$.

Résultat : $z = \sqrt{2}\left(\cos\dfrac{\pi}{4} + i\sin\dfrac{\pi}{4}\right)$

Deuxième exemple

Écrire $z = -1 + i\sqrt{3}$ sous forme trigonométrique.

Étape 1 : $r = \sqrt{(-1)^2 + (\sqrt{3})^2} = \sqrt{1 + 3} = \sqrt{4} = 2$

Étape 2 : $z = 2\left(-\dfrac{1}{2} + i\dfrac{\sqrt{3}}{2}\right)$

Étape 3 : On identifie $\cos\theta = -\dfrac{1}{2}$ et $\sin\theta = \dfrac{\sqrt{3}}{2}$, donc $\theta = \dfrac{2\pi}{3}$.

Résultat : $z = 2\left(\cos\dfrac{2\pi}{3} + i\sin\dfrac{2\pi}{3}\right)$

Troisième exemple (quadrant 4)

Écrire $z = 1 - i\sqrt{3}$ sous forme trigonométrique.

Étape 1 : $r = \sqrt{1 + 3} = 2$

Étape 2 — Quadrant : $a = 1 > 0$, $b = -\sqrt{3} < 0$ → quadrant 4, donc $\theta \in \left]-\dfrac{\pi}{2}, 0\right[$.

Étape 3 : $\cos\theta = \dfrac{1}{2}$ et $\sin\theta = -\dfrac{\sqrt{3}}{2}$ → $\theta = -\dfrac{\pi}{3}$.

Résultat : $z = 2\left(\cos\left(-\dfrac{\pi}{3}\right) + i\sin\left(-\dfrac{\pi}{3}\right)\right)$

✏️ À toi de jouer

Écrire $z = 2 - 2i$ sous forme trigonométrique.

Voir la solution

$r = \sqrt{4 + 4} = 2\sqrt{2}$ · Quadrant 4 ($a > 0$, $b < 0$).

$\cos\theta = \dfrac{2}{2\sqrt{2}} = \dfrac{\sqrt{2}}{2}$ et $\sin\theta = -\dfrac{\sqrt{2}}{2}$ → $\theta = -\dfrac{\pi}{4}$

Résultat : $z = 2\sqrt{2}\left(\cos\left(-\dfrac{\pi}{4}\right) + i\sin\left(-\dfrac{\pi}{4}\right)\right)$ ✅

04
Écriture

Forme exponentielle

Il existe une troisième forme, encore plus compacte : la forme exponentielle. Elle repose sur la formule d'Euler, qui relie l'exponentielle complexe aux fonctions trigonométriques.

Formule d'Euler
$$e^{i\theta} = \cos\theta + i\sin\theta$$
pour tout réel $\theta$

En combinant cette formule avec l'écriture trigonométrique $z = r(\cos\theta + i\sin\theta)$, on obtient la forme exponentielle :

$$z = r \cdot e^{i\theta}$$
avec $r = |z|$ et $\theta = \arg(z)$

Le cercle des exponentielles

Les nombres $e^{i\theta}$ sont exactement les complexes de module 1 : ils forment le cercle trigonométrique. Retour sur ce cercle avec notre nouvelle notation :

Valeurs remarquables

  • $e^{i \cdot 0} = 1$
  • $e^{i\pi/6} = \dfrac{\sqrt{3}}{2} + \dfrac{1}{2}i$
  • $e^{i\pi/4} = \dfrac{\sqrt{2}}{2} + i\dfrac{\sqrt{2}}{2}$
  • $e^{i\pi/3} = \dfrac{1}{2} + i\dfrac{\sqrt{3}}{2}$
  • $e^{i\pi/2} = i$
  • $e^{i\pi} = -1$
  • $e^{-i\pi/2} = -i$
  • $e^{2i\pi} = 1$
💡 Réflexe à automatiser

$e^{2i\pi} = 1$ signifie qu'on peut ajouter ou retrancher $2\pi$ à un exposant sans changer la valeur : $e^{i \cdot 9\pi/2} = e^{i(9\pi/2 - 4\pi)} = e^{i\pi/2} = i$. C'est l'analogue de la période 4 des puissances de $i$ vu en Partie 1 !

L'identité d'Euler

En prenant $\theta = \pi$ dans la formule d'Euler, on obtient $e^{i\pi} = -1$, soit l'identité célèbre :

$$e^{i\pi} + 1 = 0$$

Cette formule relie cinq constantes fondamentales des mathématiques : $e$, $i$, $\pi$, $1$ et $0$. Elle a été élue « plus belle formule des mathématiques ».

Exemples d'écriture

Reprenons $z = 1 + i$ : module $\sqrt{2}$, argument $\dfrac{\pi}{4}$.

Forme trigonométrique : $z = \sqrt{2}\left(\cos\dfrac{\pi}{4} + i\sin\dfrac{\pi}{4}\right)$

Forme exponentielle : $z = \sqrt{2} \cdot e^{i\pi/4}$

Autre exemple : $z = -1$ a pour module $1$ et argument $\pi$, donc $z = e^{i\pi}$.

✏️ À toi de jouer

Écrire $z = -3i$ sous forme exponentielle.

Voir la solution

$r = |-3i| = 3$ · Imaginaire pur négatif → $\theta = -\dfrac{\pi}{2}$

Résultat : $z = 3e^{-i\pi/2}$ ✅ (On peut aussi écrire $3e^{i \cdot 3\pi/2}$ — même nombre.)

Un peu d'histoire

La formule $e^{i\theta} = \cos\theta + i\sin\theta$ apparaît chez Euler en 1748 dans son Introductio in analysin infinitorum. La représentation géométrique des complexes, elle, est l'œuvre de l'arpenteur norvégien Wessel (1797) et du mathématicien suisse Argand (1806) — avant que Gauss ne la popularise. Trois pays, trois professions… et une seule révolution mathématique !

05
Propriétés

Propriétés des modules et arguments

Les formes trigonométrique et exponentielle rendent les multiplications et divisions beaucoup plus simples. C'est leur grand avantage.

Modules

$$|z \cdot z'| = |z| \cdot |z'|$$
Le module d'un produit est le produit des modules.
$$\left|\dfrac{z}{z'}\right| = \dfrac{|z|}{|z'|}$$
Le module d'un quotient est le quotient des modules ($z' \neq 0$).
$$|z^n| = |z|^n$$
Pour tout entier $n$.
$$\left|\dfrac{1}{z}\right| = \dfrac{1}{|z|}$$
Cas particulier du quotient : le module de l'inverse est l'inverse du module.

Arguments

$$\arg(z \cdot z') = \arg(z) + \arg(z')$$
Modulo $2\pi$.
$$\arg\left(\dfrac{z}{z'}\right) = \arg(z) - \arg(z')$$
Modulo $2\pi$ ($z' \neq 0$).
$$\arg(z^n) = n \cdot \arg(z)$$
Modulo $2\pi$, pour tout entier $n$.
$$\arg\left(\dfrac{1}{z}\right) = -\arg(z)$$
L'inverse « revient en arrière » sur le cercle.
Pourquoi ces règles ?

En écriture exponentielle, une multiplication devient une addition dans l'exposant : $r e^{i\theta} \times r' e^{i\theta'} = (r r') e^{i(\theta + \theta')}$. Les modules se multiplient et les arguments s'additionnent. C'est toute la puissance de cette écriture.

🔄 Interprétation géométrique : rotation et dilatation

Multiplier par $r e^{i\theta}$ revient à :

  • agrandir les distances par un facteur $r$ (dilatation de centre $O$)
  • tourner d'un angle $\theta$ autour de l'origine (rotation)

Cas particuliers à connaître : multiplier par $e^{i\pi/2} = i$ = quart de tour ; multiplier par $e^{i\pi} = -1$ = demi-tour (symétrie centrale) ; multiplier par $e^{-i\pi/2} = -i$ = quart de tour horaire. On exploitera ces idées en géométrie (parties 9 et 10).

Exemple avec un produit

Calculer module et argument de $(\sqrt{3} + i)(1 + i)$ sans développer :

Modules : $|\sqrt{3} + i| = 2$ et $|1 + i| = \sqrt{2}$, donc le produit a pour module $2\sqrt{2}$.

Arguments : $\dfrac{\pi}{6} + \dfrac{\pi}{4} = \dfrac{5\pi}{12}$.

Conclusion : $(\sqrt{3} + i)(1 + i) = 2\sqrt{2} \cdot e^{i \cdot 5\pi/12}$ — calcul fait sans aucune multiplication !

Exemple avec un quotient

Simplifier $\dfrac{1 + i}{1 - i}$ :

Modules : $\dfrac{\sqrt{2}}{\sqrt{2}} = 1$ — le résultat est sur le cercle de rayon 1.

Arguments : $\dfrac{\pi}{4} - \left(-\dfrac{\pi}{4}\right) = \dfrac{\pi}{2}$.

Conclusion : $\dfrac{1 + i}{1 - i} = 1 \cdot e^{i\pi/2} = i$.

Vérification : $\dfrac{(1 + i)^2}{(1 - i)(1 + i)} = \dfrac{2i}{2} = i$ ✔

Formule de Moivre

Une conséquence directe des propriétés d'argument :

Formule de Moivre
$$(\cos\theta + i\sin\theta)^n = \cos(n\theta) + i\sin(n\theta)$$
pour tout entier $n$ et tout réel $\theta$

Sous forme exponentielle, cette formule devient triviale : $(e^{i\theta})^n = e^{in\theta}$. C'est cette simplicité qui fait la force de l'écriture exponentielle.

Application immédiate : retrouver $\cos(2\theta)$

On applique Moivre avec $n = 2$ et on développe le carré :

$(\cos\theta + i\sin\theta)^2 = \cos^2\theta + 2i\sin\theta\cos\theta + i^2\sin^2\theta$

$= (\cos^2\theta - \sin^2\theta) + i(2\sin\theta\cos\theta)$

Or c'est aussi $\cos(2\theta) + i\sin(2\theta)$. En identifiant les parties réelles et imaginaires (méthode de la Partie 1 !) :

$\cos(2\theta) = \cos^2\theta - \sin^2\theta$   et   $\sin(2\theta) = 2\sin\theta\cos\theta$

On retrouve les formules trigonométriques de duplication — retrouvées par simple calcul complexe !

Application

Calculer $(1 + i)^8$.

Étape 1 — Forme exponentielle : $1 + i = \sqrt{2} \cdot e^{i\pi/4}$

Étape 2 — Puissance : $(1 + i)^8 = (\sqrt{2})^8 \cdot e^{i \cdot 8\pi/4} = 16 \cdot e^{i \cdot 2\pi}$

Étape 3 — Or $e^{i \cdot 2\pi} = 1$, donc $(1 + i)^8 = 16$.

06
Applications

Applications classiques

Voici les quatre applications les plus fréquentes des formes trigonométriques et exponentielles en Terminale.

Application 1 — Écrire un complexe sous forme exponentielle

Méthode complète

Exemple : écrire $z = -\sqrt{3} + i$ sous forme exponentielle.

1. Module : $r = \sqrt{(-\sqrt{3})^2 + 1^2} = \sqrt{3 + 1} = 2$

2. Cos et sin : $\cos\theta = -\dfrac{\sqrt{3}}{2}$ et $\sin\theta = \dfrac{1}{2}$

3. Identification : ces valeurs correspondent à $\theta = \dfrac{5\pi}{6}$.

4. Résultat : $z = 2 \cdot e^{i \cdot 5\pi/6}$

Application 2 — Calculer une puissance élevée

Méthode complète

Exemple : calculer $(1 + i)^{10}$.

1. Forme exponentielle : $1 + i = \sqrt{2} \cdot e^{i\pi/4}$

2. Élever à la puissance : $(1 + i)^{10} = (\sqrt{2})^{10} \cdot e^{i \cdot 10\pi/4}$

3. Simplifier : $(\sqrt{2})^{10} = 2^5 = 32$, et $\dfrac{10\pi}{4} = \dfrac{5\pi}{2}$.

4. Réduire l'angle modulo $2\pi$ : $\dfrac{5\pi}{2} = 2\pi + \dfrac{\pi}{2}$, donc $e^{i \cdot 5\pi/2} = e^{i\pi/2} = i$.

5. Résultat : $(1 + i)^{10} = 32i$

Application 3 — Simplifier un produit ou un quotient

Méthode complète

Exemple : écrire $Z = \dfrac{2e^{i\pi/3}}{4e^{i\pi/6}}$ sous forme algébrique.

1. Modules : $\dfrac{2}{4} = \dfrac{1}{2}$

2. Arguments : $\dfrac{\pi}{3} - \dfrac{\pi}{6} = \dfrac{\pi}{6}$, donc $Z = \dfrac{1}{2}e^{i\pi/6}$

3. Retour à la forme algébrique : $Z = \dfrac{1}{2}\left(\cos\dfrac{\pi}{6} + i\sin\dfrac{\pi}{6}\right) = \dfrac{1}{2}\left(\dfrac{\sqrt{3}}{2} + \dfrac{i}{2}\right)$

4. Résultat : $Z = \dfrac{\sqrt{3}}{4} + \dfrac{1}{4}i$

Application 4 — Linéariser une puissance de $\cos$ ou $\sin$

Les formules d'Euler permettent d'exprimer les puissances de $\cos\theta$ et $\sin\theta$ en sommes de cosinus et sinus de multiples angles. Cette technique, appelée linéarisation, sera détaillée dans la Partie 8. Retenons simplement les formules de base :

$$\cos\theta = \dfrac{e^{i\theta} + e^{-i\theta}}{2}$$
Formule d'Euler inverse pour le cosinus.
$$\sin\theta = \dfrac{e^{i\theta} - e^{-i\theta}}{2i}$$
Formule d'Euler inverse pour le sinus.
À retenir

La forme exponentielle transforme les multiplications en additions d'arguments et les puissances en multiplications d'arguments. C'est l'outil de calcul par excellence dès que les exposants deviennent grands.

Erreur classique : ne pas réduire l'angle final

Après un calcul de puissance, l'argument obtenu dépasse souvent $\pi$ : $e^{i \cdot 10\pi/4}$ n'est pas une réponse « finie ». Toujours ramener l'angle dans $]-\pi, \pi]$ (ou dans $[0, 2\pi[$ selon la consigne) avant de conclure. Un angle comme $\dfrac{5\pi}{2}$ doit devenir $\dfrac{\pi}{2}$.

07
Méthodologie

Fiches méthodes

Trois procédés à automatiser. Le jour du contrôle, ils doivent venir sans réfléchir.

📋 Méthode 1 — Trouver module ET argument d'un complexe

1
Calculer le module

$r = \sqrt{a^2 + b^2}$ — repérer un triplet pythagoricien si possible

2
Déterminer le quadrant

signes de $a$ et $b$ → intervalle possible pour $\theta$

3
Calculer $\cos\theta$ et $\sin\theta$

$\cos\theta = \dfrac{a}{r}$, $\sin\theta = \dfrac{b}{r}$, puis reconnaître un angle remarquable

4
Vérifier que $\theta$ est bien dans le bon quadrant

sinon, ajuster avec les symétries du cercle ($\pi - \theta$, $-\theta$, $\theta - \pi$)

📋 Méthode 2 — Passer de la forme algébrique à la forme exponentielle

1
Appliquer la Méthode 1

trouver $r$ et $\theta$

2
Conclure directement

$z = r \cdot e^{i\theta}$ — en gardant $\theta$ comme argument principal

3
Contre-vérification

$r\cos\theta = a$ et $r\sin\theta = b$ — 20 secondes qui garantissent zéro erreur

Application

$z = -5 + 5i$ : $r = 5\sqrt{2}$, quadrant 2, $\cos\theta = -\dfrac{\sqrt{2}}{2}$, $\sin\theta = \dfrac{\sqrt{2}}{2}$ → $\theta = \dfrac{3\pi}{4}$

Résultat : $z = 5\sqrt{2} \cdot e^{i \cdot 3\pi/4}$

Contre-vérification : $5\sqrt{2} \times \left(-\dfrac{\sqrt{2}}{2}\right) = -5$ ✔ et $5\sqrt{2} \times \dfrac{\sqrt{2}}{2} = 5$ ✔

📋 Méthode 3 — Calculer une puissance élevée $z^n$

1
Mettre $z$ sous forme exponentielle

$z = r \cdot e^{i\theta}$

2
Utiliser $(e^{i\theta})^n = e^{in\theta}$

$z^n = r^n \cdot e^{in\theta}$ — calculer $r^n$ séparément

3
Réduire $n\theta$ modulo $2\pi$

retirer autant de $2\pi$ que nécessaire pour revenir dans $]-\pi, \pi]$

4
Revenir à la forme algébrique si demandé

$r^n(\cos(n\theta) + i\sin(n\theta))$

Application

$(1 - i)^{12}$ : $1 - i = \sqrt{2} \cdot e^{-i\pi/4}$

$(1 - i)^{12} = (\sqrt{2})^{12} \cdot e^{-i \cdot 3\pi} = 2^6 \cdot e^{-i \cdot 3\pi}$

Or $-3\pi + 4\pi = \pi$, donc $e^{-i \cdot 3\pi} = e^{i\pi} = -1$

Résultat : $(1 - i)^{12} = -64$ 🎯

Entraînement

Exercices d'entraînement

🎯 QCM — Teste tes réflexes

Q1 — Le module de $z = -3 + 4i$ est :

A) 3 B) 5 C) 7 D) −5
Voir la réponse
B) 5. $|-3 + 4i| = \sqrt{9 + 16} = \sqrt{25} = 5$. Les signes ne comptent pas : ils sont élevés au carré. (Un module n'est jamais négatif → D éliminé !)

Q2 — L'argument principal de $z = -2i$ est :

A) π/2 B) −π/2 C) π D) 0
Voir la réponse
B) −π/2. Imaginaire pur négatif : le point est « en dessous » de l'origine, sur l'axe vertical. L'argument principal est $-\dfrac{\pi}{2}$.

Q3 — $e^{i\pi/6} \times e^{i\pi/3}$ est égal à :

A) e^(iπ/18) B) e^(iπ/2) = i C) e^(iπ/9) D) 1
Voir la réponse
B) i. Les arguments s'additionnent : $\dfrac{\pi}{6} + \dfrac{\pi}{3} = \dfrac{\pi}{6} + \dfrac{2\pi}{6} = \dfrac{3\pi}{6} = \dfrac{\pi}{2}$. Donc le produit vaut $e^{i\pi/2} = i$.

Q4 — Le module et l'argument principal de $z = -1 - i\sqrt{3}$ sont :

A) 2 et −2π/3 B) 2 et 4π/3 C) 4 et 2π/3 D) 2 et π/3
Voir la réponse
A) 2 et −2π/3. $r = \sqrt{1 + 3} = 2$. Point en quadrant 3 ($a < 0$, $b < 0$), donc argument principal dans $\left]-\pi, -\dfrac{\pi}{2}\right[$. $\cos\theta = -\dfrac{1}{2}$ et $\sin\theta = -\dfrac{\sqrt{3}}{2}$ → $\theta = -\dfrac{2\pi}{3}$. ($\dfrac{4\pi}{3}$ est un argument correct mais pas l'argument principal !)

Q5 — Si $|z| = 2$, alors $|z^5|$ est égal à :

A) 10 B) 16 C) 32 D) On ne peut pas savoir
Voir la réponse
C) 32. $|z^5| = |z|^5 = 2^5 = 32$. Peu importe l'argument de $z$ !

💪 Exercices d'application

Exercice 1 — Modules

Calculer : $|6 + 8i|$, $|1 - i|$, $|-5i|$ et $|\sqrt{3} - i|$

Voir la solution

$|6 + 8i| = \sqrt{36 + 64} = \sqrt{100} = 10$ (double du 3-4-5)

$|1 - i| = \sqrt{1 + 1} = \sqrt{2}$

$|-5i| = 5$ (imaginaire pur : module = $|-5|$)

$|\sqrt{3} - i| = \sqrt{3 + 1} = 2$

Exercice 2 — Arguments avec quadrant

Déterminer l'argument principal de $z = -\sqrt{3} - i$.

Voir la solution

$r = \sqrt{3 + 1} = 2$

$a = -\sqrt{3} < 0$, $b = -1 < 0$ → quadrant 3, $\theta \in \left]-\pi, -\dfrac{\pi}{2}\right[$

$\cos\theta = -\dfrac{\sqrt{3}}{2}$ et $\sin\theta = -\dfrac{1}{2}$ → $\theta = -\dfrac{5\pi}{6}$ ✅

Exercice 3 — Forme exponentielle

Écrire $z = -5 + 5i$ sous forme exponentielle.

Voir la solution

$r = \sqrt{25 + 25} = 5\sqrt{2}$

$\cos\theta = -\dfrac{5}{5\sqrt{2}} = -\dfrac{\sqrt{2}}{2}$, $\sin\theta = \dfrac{5}{5\sqrt{2}} = \dfrac{\sqrt{2}}{2}$ → quadrant 2 → $\theta = \dfrac{3\pi}{4}$

Résultat : $z = 5\sqrt{2} \cdot e^{i \cdot 3\pi/4}$

Exercice 4 — Puissance élevée

Calculer $(1 - i)^{12}$.

Voir la solution

$1 - i = \sqrt{2} \cdot e^{-i\pi/4}$

$(1 - i)^{12} = (\sqrt{2})^{12} \cdot e^{-i \cdot 12\pi/4} = 2^6 \cdot e^{-i \cdot 3\pi} = 64 \cdot e^{-i \cdot 3\pi}$

$-3\pi + 4\pi = \pi$, donc $e^{-i \cdot 3\pi} = e^{i\pi} = -1$

Résultat : $(1 - i)^{12} = -64$

Vérification rapide : $(1 - i)^2 = -2i$, $(1 - i)^4 = -4$, $(1 - i)^8 = 16$, $(1 - i)^{12} = (1 - i)^8 \times (1 - i)^4 = 16 \times (-4) = -64$ ✔

Exercice 5 — Produit et quotient (défi ★)

Simplifier $Z = \dfrac{(1 + i)^6}{(1 - i)^2}$ en utilisant module et argument.

Voir la solution

$1 + i = \sqrt{2} \cdot e^{i\pi/4}$, donc $(1 + i)^6 = (\sqrt{2})^6 \cdot e^{i \cdot 6\pi/4} = 8 \cdot e^{i \cdot 3\pi/2} = 8 \cdot e^{-i\pi/2}$

$(1 - i)^2 = (\sqrt{2} \cdot e^{-i\pi/4})^2 = 2 \cdot e^{-i\pi/2} = -2i$

Modules : $\dfrac{8}{2} = 4$ · Arguments : $-\dfrac{\pi}{2} - \left(-\dfrac{\pi}{2}\right) = 0$

Résultat : $Z = 4 \cdot e^{i \cdot 0} = 4$ ✅

Vérification : $(1 + i)^6 = -8i$ et $\dfrac{-8i}{-2i} = 4$ ✔

Exercice 6 — Géométrie (défi ★★)

Soit $A(3 + i)$ et $B(1 - 2i)$. Calculer la distance $AB$ et l'affixe du milieu $I$ du segment $[AB]$.

Voir la solution

Distance : $AB = |z_B - z_A| = |(1 - 2i) - (3 + i)| = |-2 - 3i| = \sqrt{4 + 9} = \sqrt{13}$

Milieu : $z_I = \dfrac{z_A + z_B}{2} = \dfrac{(3 + i) + (1 - 2i)}{2} = \dfrac{4 - i}{2} = 2 - \dfrac{i}{2}$

📌 Ce qu'il faut retenir
  • Le module $|z| = \sqrt{a^2 + b^2}$ mesure la distance $OM$ dans le plan complexe.
  • Distance entre deux points : $AB = |z_B - z_A|$
  • L'argument $\theta = \arg(z)$ est l'angle orienté entre l'axe des réels et le vecteur $OM$ — toujours vérifier le quadrant !
  • Forme trigonométrique : $z = r(\cos\theta + i\sin\theta)$ avec $r > 0$
  • Formule d'Euler : $e^{i\theta} = \cos\theta + i\sin\theta$ ; les $e^{i\theta}$ parcourent le cercle de rayon 1
  • Forme exponentielle : $z = r \cdot e^{i\theta}$
  • $|z \cdot z'| = |z| \cdot |z'|$ et $\arg(z \cdot z') = \arg(z) + \arg(z')$ (modulo $2\pi$)
  • Multiplier par $r \cdot e^{i\theta}$ = dilatation de facteur $r$ + rotation d'angle $\theta$
  • Formule de Moivre : $(\cos\theta + i\sin\theta)^n = \cos(n\theta) + i\sin(n\theta)$
  • Après un calcul de puissance, toujours réduire l'angle modulo $2\pi$
  • Inégalité triangulaire : $|z + z'| \leq |z| + |z'|$
  • Applications : forme exponentielle, puissances élevées, quotients, linéarisation.
