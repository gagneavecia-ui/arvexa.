01
Bloc 1 · bornees

Majorée, minorée, bornée

Trois mots de vocabulaire, une seule idée : est-ce que tous les termes de la suite restent sous un plafond, au-dessus d'un plancher, ou les deux ?

📗 Définitions officielles
  • (uₙ) est majorée s'il existe un réel M tel que, pour tout n : uₙ ≤ M (M est un majorant).
  • (uₙ) est minorée s'il existe un réel m tel que, pour tout n : uₙ ≥ m (m est un minorant).
  • (uₙ) est bornée si elle est minorée et majorée : il existe m et M tels que, pour tout n : m ≤ uₙ ≤ M.
🧮 Exemples — les trois situations

Bornée : uₙ = 1/(n + 1) vérifie 0 < uₙ ≤ 1 pour tout n (le plus grand terme est u₀ = 1, et les termes restent positifs) : minorée par 0, majorée par 1.

Minorée seulement : uₙ = n² vérifie uₙ ≥ 0, mais aucun nombre ne dépasse tous les termes (ils grandissent sans fin) : minorée, non majorée.

Bornée mais agitée : uₙ = (−1)ⁿ vérifie −1 ≤ uₙ ≤ 1 : bornée ! Pourtant, on sait (partie 3) qu'elle est divergente.

Erreur fréquente au Bac — « bornée donc convergente »

Être bornée ne suffit jamais à conclure à la convergence : (−1)ⁿ est bornée et divergente. Il faut un ingrédient supplémentaire — la monotonie — c'est exactement le théorème du bloc suivant.

02
Bloc 2 · monotone_converge

Croissante + majorée = convergente

Voici le théorème qui permet de conclure à la convergence sans connaître la limite — l'entrée officielle du programme, à énoncer avec ses hypothèses au complet.

Toute suite croissante et majorée converge. Toute suite décroissante et minorée converge.
Théorème admis (on ne le démontre pas en Terminale). Les deux hypothèses sont indispensables : croissante seule (uₙ = n diverge) ou majorée seule ((−1)ⁿ diverge) ne suffisent pas.
🧮 Application complète — u₀ = 1 et uₙ₊₁ = (uₙ + 3)/2

Montrons que la suite de la partie 3 converge, puis calculerons sa limite au bloc suivant.

1

Bornée : on a démontré par récurrence (partie 3) que 0 ≤ uₙ ≤ 3 pour tout n. La suite est donc majorée par 3 (et minorée par 0).

2

Croissante : uₙ₊₁ − uₙ = (uₙ + 3)/2 − uₙ = (uₙ + 3 − 2uₙ)/2 = (3 − uₙ)/2. Or uₙ ≤ 3, donc 3 − uₙ ≥ 0 et uₙ₊₁ − uₙ ≥ 0 : la suite est croissante.

3

Conclusion : croissante et majorée, la suite (uₙ) converge vers une limite ℓ — dont on ne connaît pas encore la valeur… mais le bloc suivant s'en charge.

🧠 Méthode à retenir
Pour une suite définie par uₙ₊₁ = f(uₙ), le trio gagnant est : (1) encadrement par récurrence (partie 3), (2) monotonie par le signe de uₙ₊₁ − uₙ (partie 1), (3) convergence par le théorème ci-dessus. La limite elle-même attendra le point fixe.
03
Bloc 3 · point_fixe

La méthode du point fixe

Une suite (uₙ) définie par uₙ₊₁ = f(uₙ) converge vers ℓ : que vaut ℓ ? L'idée est d'une simplicité désarmante — si les termes s'immobilisent en ℓ, alors f doit laisser ℓ immobile aussi.

Si lim(n→+∞) uₙ = ℓ et si f est continue en ℓ, alors f(ℓ) = ℓ.
La limite ℓ est un point fixe de f : on la trouve en résolvant l'équation f(ℓ) = ℓ. Si plusieurs solutions, on garde celle compatible avec l'encadrement des termes.
🧠 Méthode en 4 étapes
  • 1. Prouver la convergence (théorème du bloc 2, ou forme explicite) — on ne cherche jamais une limite dont l'existence n'est pas établie.
  • 2. Écrire f(ℓ) = ℓ en remplaçant dans la relation de récurrence.
  • 3. Résoudre l'équation en ℓ (souvent du 1ᵉʳ ou 2ᵈ degré).
  • 4. Choisir la solution compatible avec l'encadrement des termes (signe, minorant, majorant).
🧮 Exemple résolu 1 — la limite de la suite du bloc 2

u₀ = 1, uₙ₊₁ = (uₙ + 3)/2 = f(uₙ) avec f(x) = (x + 3)/2, suite convergente (bloc 2).

1

Équation au point fixe : ℓ = (ℓ + 3)/2, soit 2ℓ = ℓ + 3, soit ℓ = 3.

2

Conclusion : lim(n→+∞) uₙ = 3. Tout se tient : la récurrence avait prouvé 0 ≤ uₙ ≤ 3, le théorème avait prouvé la convergence, et le point fixe livre la valeur — exactement la « porte de 3 » observée en partie 3.

🧮 Exemple résolu 2 — avec une racine carrée

u₀ = 0, uₙ₊₁ = √(2uₙ + 3). Les premiers termes : u₁ = √3 ≈ 1,73 ; u₂ = √(2 × 1,73 + 3) = √6,46 ≈ 2,54 ; u₃ ≈ 2,84 ; u₄ ≈ 2,95. La suite, croissante et majorée par 3 (on le démontre par récurrence, comme en partie 3), converge. Que vaut sa limite ?

1

Point fixe : ℓ = √(2ℓ + 3). Les deux membres sont positifs, on peut élever au carré : ℓ² = 2ℓ + 3, soit ℓ² − 2ℓ − 3 = 0.

2

Résoudre : ℓ² − 2ℓ − 3 = (ℓ − 3)(ℓ + 1), donc ℓ = 3 ou ℓ = −1.

3

Choisir la bonne solution : u₀ = 0 et chaque terme est une racine carrée, donc uₙ ≥ 0 pour tout n. Par passage à la limite, ℓ ≥ 0 : la solution −1 est rejetée.

4

Conclusion : lim(n→+∞) uₙ = 3 — cohérent avec les termes calculés (2,84 ; 2,95… s'approchent bien de 3).

⚠️ Deux garde-fous

(1) Ordre des étapes : d'abord la convergence (bloc 2), ensuite seulement l'équation — résoudre f(ℓ) = ℓ ne prouve rien si la suite diverge. (2) Filtre final : quand l'équation donne plusieurs solutions, c'est l'encadrement des termes (récurrence de la partie 3) qui tranche.

Bloc 4 · synthese

Tableau de synthèse du chapitre

Voici le condensé de tout le chapitre : les trois grandes familles de suites, côte à côte. À connaître par cœur — colonne par colonne.

ArithmétiqueGéométriqueArithmético-géométrique
Définition uₙ₊₁ = uₙ + r uₙ₊₁ = q × uₙ (u₀ ≠ 0) uₙ₊₁ = a × uₙ + b (a ≠ 1)
Terme général uₙ = u₀ + n × r = u₁ + (n − 1) × r uₙ = u₀ × qⁿ = u₁ × q^(n − 1) uₙ = ℓ + (u₀ − ℓ) × aⁿ avec ℓ = b/(1 − a)
Somme des n premiers termes u₁ + ⋯ + uₙ = n × (u₁ + uₙ)/2 u₁ + ⋯ + uₙ = u₁ × (1 − qⁿ)/(1 − q) (q ≠ 1) — (hors programme)
Limite en +∞ +∞ si r > 0 ; −∞ si r < 0 ; constante si r = 0 0 si |q| < 1 ; ±∞ si q > 1 (signe de u₀) ; pas de limite si q ≤ −1 ℓ si |a| < 1 ; diverge en général si |a| > 1
La clé de tout le chapitre
Reconnaître le type de suite → écrire uₙ en fonction de n → passer à la limite
Les trois formes explicites à connaître : u₀ + n × r · u₀ × qⁿ · ℓ + (u₀ − ℓ) × aⁿ. Avec uₙ en fonction de n, les limites deviennent des substitutions.
🧠 Reconnaître le type en deux gestes
Calcule uₙ₊₁ − uₙ : constant ⇒ arithmétique (raison = cette constante). Sinon, si les termes sont non nuls, calcule uₙ₊₁/uₙ : constant ⇒ géométrique (raison = ce rapport). Sinon, si l'écriture est a × uₙ + b ⇒ arithmético-géométrique (point fixe). Ne jamais « foncer » dans une formule avant ce diagnostic.

Bloc 5 · reflexes

Réflexes Bac et erreurs à éviter

Un sujet sur les suites se lit comme une check-list. Voici l'ordre d'attaque qui rapporte des points, puis la liste des pièges qui en coûtent.

  • Reconnaître le type de suite AVANT de foncer : uₙ₊₁ − uₙ constant ? uₙ₊₁/uₙ constant ? ou a × uₙ + b ? Le diagnostic dicte la méthode.
  • Chercher l'expression de uₙ en fonction de n : c'est la clé des limites, des encadrements et des questions de rang (« à partir de quel n a-t-on uₙ > 1 000 ? » se résout avec la forme explicite, jamais terme par terme).
  • Rédiger une récurrence en trois temps nommés : Initialisation, Hérédité (avec hypothèse « pour un entier n fixé » et démonstration complète), Conclusion.
  • Vérifier chaque formule explicite sur u₀, u₁, u₂ : si n = 0 ne redonne pas u₀, il y a une erreur d'exposant ou de signe.
  • Conclure proprement sur une convergence : encadrement (récurrence) + monotonie (signe de uₙ₊₁ − uₙ) + théorème, puis limite par point fixe — dans cet ordre.
Les 6 erreurs qui coûtent le plus de points
  • Conclure l'hérédité sans la démontrer (« c'est évident ») : 0 point sur la récurrence.
  • Confondre uₙ et n : uₙ est le terme (un nombre), n est le rang (un entier) — « uₙ → +∞ » ne signifie pas « n → +∞ ».
  • Croire que « bornée » suffit à converger : (−1)ⁿ est bornée et divergente — il faut la monotonie.
  • Écrire une limite pour (−1)ⁿ ou qⁿ avec q ≤ −1 : ces suites divergent sans limite (elles oscillent).
  • Appliquer la formule de la somme géométrique avec q = 1 : division par 0 — dans ce cas Sₙ = n × u₁.
  • Oublier le point fixe dans uₙ = ℓ + (u₀ − ℓ) × aⁿ, ou prendre une solution impossible de f(ℓ) = ℓ sans vérifier l'encadrement.

Q1 — Une suite croissante et majorée par 5 est :

A) divergente B) convergente C) constante égale à 5 D) décroissante à partir d'un certain rang
Voir la réponse
B) convergente. C'est exactement le théorème de convergence monotone : croissante et majorée ⇒ convergence (vers une limite ≤ 5, dont la valeur demande un autre outil — le point fixe).

Q2 — La suite définie par uₙ₊₁ = √(2uₙ + 3) converge. Sa limite ℓ vérifie :

A) ℓ = 2ℓ + 3 B) ℓ² = 2ℓ + 3 C) ℓ = √3 D) ℓ² = 3
Voir la réponse
B) ℓ² = 2ℓ + 3. Point fixe : ℓ = √(2ℓ + 3) donne, après élévation au carré, ℓ² = 2ℓ + 3, soit ℓ² − 2ℓ − 3 = 0 : ℓ = 3 ou ℓ = −1. La suite étant positive, la limite est ℓ = 3.
📌 Ce qu'il faut retenir
  • [bornees] Majorée : uₙ ≤ M pour tout n ; minorée : uₙ ≥ m ; bornée : m ≤ uₙ ≤ M (les deux)
  • [bornees] Exemples : 1/(n + 1) bornée (0 < uₙ ≤ 1) ; n² minorée non majorée ; (−1)ⁿ bornée mais divergente
  • [monotone_converge] Théorème (admis) : toute suite croissante et majorée converge ; toute suite décroissante et minorée converge — les deux hypothèses sont indispensables
  • [monotone_converge] Recette : encadrement par récurrence + monotonie par signe de uₙ₊₁ − uₙ + théorème ⇒ convergence
  • [point_fixe] Si uₙ₊₁ = f(uₙ) converge vers ℓ et f est continue, alors f(ℓ) = ℓ : résoudre l'équation, puis filtrer par l'encadrement
  • [point_fixe] (uₙ + 3)/2 → ℓ = 3 ; √(2uₙ + 3) → ℓ² − 2ℓ − 3 = 0 → ℓ = 3 (le −1 est rejeté, suite positive)
  • [synthese] Arithmétique : uₙ = u₀ + n × r ; somme n × (u₁ + uₙ)/2 ; limite ±∞ selon le signe de r
  • [synthese] Géométrique : uₙ = u₀ × qⁿ ; somme u₁(1 − qⁿ)/(1 − q) ; limite 0 si |q| < 1, ±∞ si q > 1, rien si q ≤ −1
  • [synthese] Arithmético-géométrique : point fixe ℓ = b/(1 − a) ; uₙ = ℓ + (u₀ − ℓ) × aⁿ ; limite ℓ si |a| < 1
  • [reflexes] Diagnostic AVANT calcul, forme explicite = clé des limites, récurrence en 3 temps nommés, contrôle systématique sur u₀, u₁, u₂
