📘 Partie 02 · Calcul intégral

Primitives composées & définition de l'intégrale

Le tableau usuel a ses limites : que faire de x·√(x² + 1) ou de e^x/(1 + e^x) ? Cette partie installe d'abord les trois formes composées de référence — u'·uⁿ, u'/u et u'·e^u — et t'entraîne à reconnaître le couple (u, u') dans une expression. Puis vient l'objet central du chapitre : la définition de l'intégrale ∫ₐᵇ f(x) dx par le théorème fondamental de l'analyse, avec les premiers calculs complets.

00
Motivation

Des formes qui se reconnaissent

Avec la Partie 1, tu sais primitiver x³, √x, cos x… mais un exercice d'examen te proposera plutôt des produits et des quotients : 2x·(x² + 1)³, cos x·sin⁴x, e^x/(1 + e^x). Inutile de paniquer : ces expressions ont une structure, et cette structure se reconnaît comme on reconnaît un visage.

L'idée maîtresse : quand on dérive une fonction composée, un facteur u' apparaît tout seul dans le résultat. En lisant ces dérivées à l'envers, on obtient des primitives de produits contenant u'. C'est le premier thème de cette partie. Le second est la récompense : munis de nos primitives, nous pourrons enfin définir et calculer ∫ₐᵇ f(x) dx — l'intégrale — grâce au théorème fondamental de l'analyse.

Les questions de cette partie
  • Quelles formes composées faut-il reconnaître par cœur ? (u'·uⁿ, u'/u, u'·e^u)
  • Comment repérer le couple (u, u') dans une expression donnée ?
  • Qu'est-ce que ∫ₐᵇ f(x) dx et que signifient les bornes ? (Notion 3)
  • Comment calculer une intégrale avec F(b) − F(a), vite et sans faute ?
🌍 Pour aller plus loin
Le symbole ∫ est un S étiré : Leibniz l'a choisi en 1675 d'après le mot latin summa (« somme »), car une intégrale additionne des contributions infiniment petites. La notation dx rappelle la petite variation de la variable — tu verras en Partie 4 que l'intégrale mesure bien une aire.
01
Notion 1 · formes de référence

Les trois formes composées de référence

Rappel de Partie 3 (dérivation) : (uⁿ)' = n·u'·u^(n − 1), (ln u)' = u'/u et (e^u)' = u'·e^u. Lisons ces trois égalités de droite à gauche : elles nous disent quelles expressions admettent des primitives toutes faites.

Forme de f(x)Primitive F(x)Condition
u'(x)·[u(x)]ⁿu^(n+1)/(n+1)n ≠ −1
u'(x)/u(x)ln(u(x))u(x) > 0 sur l'intervalle
u'(x)·e^(u(x))e^(u(x))aucune (u quelconque)
💡 Pourquoi ça marche — les dérivées composées lues à l'envers
  • (u^(n+1))' = (n + 1)·u'·uⁿ, donc en divisant par (n + 1) : une primitive de u'·uⁿ est u^(n+1)/(n+1).
  • (ln u)' = u'/u : une primitive de u'/u est ln(u) — à condition que u > 0 pour que ln(u) existe.
  • (e^u)' = u'·e^u : une primitive de u'·e^u est e^u.

Dans les trois cas, le signe de réussite est le même : le facteur u' doit être déjà présent dans f (à un facteur constant près).

⚠️ Le cas n = −1 réapparaît… en mieux

Prends la première forme avec n = −1 : u'·u⁻¹ = u'/u. Le cas « interdit » du tableau usuel devient justement la deuxième forme, de primitive ln(u). Vérifie simplement que u > 0 sur tout l'intervalle — sinon ln(u) n'existe pas.

02
Notion 2 · reconnaissance

Reconnaître la forme — la chasse au couple (u, u')

🧠 Méthode — reconnaître une forme composée
(1) Chercher « ce qui est à l'intérieur » : une puissance, une racine, un logarithme, un exposant… c'est le candidat u. (2) Calculer u' et vérifier qu'il apparaît (ou presque) comme facteur de f. (3) Réécrire f sous la forme k·u'·uⁿ, k·u'/u ou k·u'·e^u (le facteur constant k est autorisé). (4) Appliquer la formule, multiplier par k, puis vérifier en dérivant.
🔍 Entraînement à l'œil — trouver le couple (u, u')
  • f(x) = 2x·(x² + 1)³ : le facteur 2x est la dérivée de x² + 1. Forme u'·u³ avec u = x² + 1 ⇒ primitive (x² + 1)⁴/4.
  • f(x) = e^x/(1 + e^x) : le numérateur e^x est la dérivée du dénominateur 1 + e^x. Forme u'/u ⇒ primitive ln(1 + e^x).
  • f(x) = cos x·sin⁴x : cos x est la dérivée de sin x. Forme u'·u⁴ avec u = sin x ⇒ primitive sin⁵x/5.
  • f(x) = (ln x)/x : 1/x est la dérivée de ln x. Forme u'·u¹ avec u = ln x ⇒ primitive (ln x)²/2.
🚨 Erreur fréquente — oublier le facteur constant

Pour f(x) = x·√(x² + 1), la dérivée de u = x² + 1 est 2x, pas x : il faut réécrire f = (1/2)·2x·√(x² + 1) et n'oublier ni le 1/2 ni le facteur (n + 1) au moment de primitiver. Le contrôle par la dérivée attrape cette erreur à tous les coups.

03
Entraînement

Exemples complets de primitives composées

🧮 Exemple 1 — x·√(x² + 1) : la forme u'·uⁿ avec facteur 1/2

Cherchons les primitives de f(x) = x·√(x² + 1) sur ℝ.

1

Choisir u. L'intérieur est u(x) = x² + 1, donc u'(x) = 2x.

2

Réécrire. x = (1/2)·2x, donc f(x) = (1/2)·u'(x)·√(u(x)) = (1/2)·u'(x)·[u(x)]^(1/2) : forme u'·uⁿ avec n = 1/2.

3

Primitiver. F(x) = (1/2)·u^(3/2)/(3/2) = (1/2)·(2/3)·u^(3/2) = (1/3)·(x² + 1)^(3/2) + C.

4

Vérifier. F'(x) = (1/3)·(3/2)·(x² + 1)^(1/2)·2x = x·√(x² + 1) = f(x) ✓.

🧮 Exemple 2 — e^x/(1 + e^x) : la forme u'/u

Cherchons les primitives de f(x) = e^x/(1 + e^x) sur ℝ.

1

Choisir u. Dénominateur : u(x) = 1 + e^x, donc u'(x) = e^x — exactement le numérateur.

2

Vérifier la condition. u(x) = 1 + e^x ≥ 1 > 0 pour tout x : la forme u'/u est autorisée.

3

Primitiver. F(x) = ln(1 + e^x) + C.

4

Vérifier. F'(x) = e^x/(1 + e^x) = f(x) ✓.

🧮 Exemple 3 — cos x·sin⁴x : la forme u'·uⁿ trigonométrique

Cherchons les primitives de f(x) = cos x·sin⁴x sur ℝ.

1

Choisir u. u(x) = sin x, donc u'(x) = cos x : le facteur est déjà là, sans coefficient à ajuster.

2

Réécrire. f(x) = u'(x)·[u(x)]⁴ : forme u'·uⁿ avec n = 4.

3

Primitiver. F(x) = sin⁵x/5 + C.

4

Vérifier. F'(x) = (5·sin⁴x·cos x)/5 = cos x·sin⁴x = f(x) ✓.

🧮 Exemple 4 — 2x/(x² + 1) : la forme u'/u polynomiale

Cherchons les primitives de f(x) = 2x/(x² + 1) sur ℝ.

1

Choisir u. u(x) = x² + 1, donc u'(x) = 2x : le numérateur, pile.

2

Vérifier la condition. u(x) = x² + 1 ≥ 1 > 0 sur ℝ ✓.

3

Primitiver. F(x) = ln(x² + 1) + C.

4

Vérifier. F'(x) = 2x/(x² + 1) = f(x) ✓.

04
Notion 3 · l'intégrale

Définition de l'intégrale — le théorème fondamental

Voilà le théorème du chapitre : il relie le calcul des primitives (Partie 1) au calcul de cumuls et d'aires (Parties 3 et 4). On note ∫ₐᵇ f(x) dx l'intégrale de f entre les bornes a (en indice) et b (en exposant). Les bornes s'écrivent en Unicode quand elles sont simples : ∫₀¹, ∫₁³, ∫₋₁², ∫₁ᵉ, ∫ₐᵇ — et entre parenthèses sinon : ∫₀^(π/2), ∫₁^(+∞).

📗 Définition — Intégrale d'une fonction continue

Soit f une fonction continue sur un intervalle [a ; b]. Pour toute primitive F de f sur [a ; b], on définit l'intégrale de f entre a et b par : ∫ₐᵇ f(x) dx = F(b) − F(a).

Théorème fondamental de l'analyse
∫ₐᵇ f(x) dx = F(b) − F(a)
f continue sur [a ; b], F une primitive de f sur [a ; b]. On note aussi [F(x)]ₐᵇ = F(b) − F(a).

Peu importe la primitive choisie. Si l'on prend F + C au lieu de F, alors (F + C)(b) − (F + C)(a) = F(b) + C − F(a) − C = F(b) − F(a) : la constante disparaît dans la soustraction. C'est pour cela qu'ici on n'écrit jamais + C.

⚠️ Les hypothèses du théorème fondamental

Le théorème exige que f soit continue sur l'intervalle entre les bornes — c'est automatique pour les fonctions usuelles sur leur domaine (polynômes sur ℝ, 1/x sur ]0 ; +∞[, √x sur [0 ; +∞[…). Pense aussi à vérifier le domaine : on ne calcule pas ∫₋₁¹ (dx/x), car 1/x n'est pas continue sur [−1 ; 1].

05
Méthode

Calculer une intégrale : la méthode

🧠 Méthode — calculer ∫ₐᵇ f(x) dx
(1) Vérifier que f est continue entre a et b. (2) Trouver une primitive F de f (tableau de la Partie 1, formes composées ci-dessus) — sans écrire + C. (3) Écrire [F(x)]ₐᵇ avant de substituer. (4) Calculer F(b) − F(a) en prenant soin des signes, et simplifier. (5) Contrôler : si f ≥ 0 et a ≤ b, le résultat doit être positif (Partie 3).
[F(x)]ₐᵇ = F(b) − F(a)
La notation crochet : on remplace x par la borne du haut b, puis par la borne du bas a, et on soustrait — toujours dans cet ordre.
🚨 Erreur fréquente — inverser les bornes dans le crochet

Écrire [x³]₁² = 1 − 8 = −7 au lieu de 8 − 1 = 7 : c'est la faute la plus fréquente du chapitre. Réflexe : borne du haut d'abord (celle de l'exposant), borne du bas ensuite, puis soustraction. Et si les bornes sont données dans l'ordre décroissant, garde le signe − (Partie 3).

Notion 4 · premiers calculs

Premiers calculs — exemples guidés

🧮 Exemple 1 — un polynôme : ∫₀¹ (3x² + 2x) dx
1

Continuité. 3x² + 2x est polynomiale : continue sur [0 ; 1] ✓.

2

Primitive. F(x) = x³ + x² (car 3x² ↦ 3·x³/3 = x³ et 2x ↦ 2·x²/2 = x²).

3

Crochet. [x³ + x²]₀¹ = (1³ + 1²) − (0³ + 0²) = (1 + 1) − 0.

4

Conclure. ∫₀¹ (3x² + 2x) dx = 2. Contrôle : 3x² + 2x ≥ 0 sur [0 ; 1] et le résultat est bien positif ✓.

🧮 Exemple 2 — avec le logarithme : ∫₁ᵉ dx/x
1

Continuité. 1/x est continue sur [1 ; e] (car 1 ≥ 1 > 0) ✓.

2

Primitive. F(x) = ln x sur ]0 ; +∞[.

3

Crochet. [ln x]₁ᵉ = ln e − ln 1 = 1 − 0.

4

Conclure. ∫₁ᵉ dx/x = 1 : entre 1 et e ≈ 2,718, l'aire sous y = 1/x vaut exactement 1 unité d'aire.

🧮 Exemple 3 — avec le cosinus : ∫₀^(π/2) cos x dx
1

Continuité. cos x est continue sur [0 ; π/2] ✓.

2

Primitive. F(x) = sin x.

3

Crochet. [sin x]₀^(π/2) = sin(π/2) − sin(0) = 1 − 0.

4

Conclure. ∫₀^(π/2) cos x dx = 1. La borne π/2 ne s'écrivant pas en exposant Unicode, on la met entre parenthèses : ∫₀^(π/2).

🧮 Exemple 4 — bornes négatives : ∫₋₁² x dx
1

Primitive. F(x) = x²/2, continue partout ; les bornes s'écrivent ∫₋₁² (indice −1, exposant 2).

2

Crochet. [x²/2]₋₁² = 2²/2 − (−1)²/2 = 2 − 0,5.

3

Conclure. ∫₋₁² x dx = 3/2.

4

Remarque. f(x) = x est négative sur [−1 ; 0] et positive sur [0 ; 2] : l'intégrale additionne les aires avec leur signe. L'aire réelle du domaine se calculera en Partie 4, en découpant au point 0.

⚠️ La variable est muette

∫₀¹ x² dx = ∫₀¹ t² dt = 1/3 : la lettre placée dans f(x) dx n'a pas d'existence propre — seul compte l'intervalle entre les bornes. En revanche, ne mélange pas les lettres dans un même calcul : choisis x ou t et garde-la.

07
Bilan

La boîte à outils

La formule de la partie à connaître par cœur
∫ₐᵇ f(x) dx = F(b) − F(a) = [F(x)]ₐᵇ
f continue sur [a ; b] et F primitive de f. Toute primitive convient (la constante disparaît) : on n'écrit jamais + C dans un calcul d'intégrale.
  • Trois formes composées à reconnaître : u'·uⁿ ↦ u^(n+1)/(n+1) (n ≠ −1), u'/u ↦ ln(u) (u > 0), u'·e^u ↦ e^u.
  • Le signal : un facteur u' (à un coefficient près) collé à une fonction de u — puissance, logarithme ou exponentielle.
  • Notation : ∫ₐᵇ f(x) dx — a en indice, b en exposant ; [F(x)]ₐᵇ = F(b) − F(a).
  • Méthode de calcul : continuité → primitive → crochet → soustraction → contrôle du signe.
  • La variable x est muette : ∫₀¹ f(x) dx = ∫₀¹ f(t) dt.
⚠️ Rédaction type pour l'examen

Un calcul d'intégrale bien noté passe toujours par la ligne ∫₀¹ (3x² + 2x) dx = [x³ + x²]₀¹ : primitive entre crochets avec les bornes, et seulement après la substitution. Une réponse donnée directement, sans crochet, est quasiment toujours mal évaluée — même juste.

Q1 — Une primitive de f(x) = 2x·(x² + 1)² est :

A) (x² + 1)³/3B) 2(x² + 1)³C) (x² + 1)³D) 6x·(x² + 1)
Voir la réponse
A) (x² + 1)³/3. Forme u'·u² avec u = x² + 1 et u' = 2x : primitive u³/3. Vérification : ((x² + 1)³/3)' = 3(x² + 1)²·2x/3 = 2x·(x² + 1)² ✓.

Q2 — ∫₀¹ (2x + 1) dx est égal à :

A) 1B) 2C) 3/2D) 1/2
Voir la réponse
B) 2. ∫₀¹ (2x + 1) dx = [x² + x]₀¹ = (1 + 1) − (0 + 0) = 2. Contrôle : 2x + 1 ≥ 1 > 0 sur [0 ; 1], le résultat est bien positif.

Q3 — ∫₁ᵉ dx/x est égal à :

A) e − 1B) 1C) eD) 0
Voir la réponse
B) 1. ∫₁ᵉ dx/x = [ln x]₁ᵉ = ln e − ln 1 = 1 − 0 = 1. L'option A (« e − 1 ») serait le résultat de ∫₀¹ e^x dx — ne pas confondre les deux calculs classiques.
📌 Ce qu'il faut retenir
  • [formes_composees] u'·uⁿ ↦ u^(n+1)/(n+1) (n ≠ −1) ; u'/u ↦ ln(u) avec u > 0 ; u'·e^u ↦ e^u — les dérivées composées lues à l'envers
  • [formes_composees] Le cas n = −1 de u'·uⁿ est exactement u'/u ↦ ln(u)
  • [reconnaissance] Chercher « l'intérieur » u, vérifier que u' apparaît en facteur (à un coefficient près), réécrire, appliquer, vérifier en dérivant
  • [integrale_def] f continue sur [a ; b], F primitive de f : ∫ₐᵇ f(x) dx = F(b) − F(a) — théorème fondamental de l'analyse
  • [integrale_def] Notation : a en indice, b en exposant ; [F(x)]ₐᵇ = F(b) − F(a) ; pas de + C (elle disparaît dans la soustraction)
  • [calcul] Méthode : continuité → primitive → crochet → F(b) − F(a) → contrôle du signe
  • [calcul] Calculs de référence : ∫₀¹ (3x² + 2x) dx = 2 ; ∫₁ᵉ dx/x = 1 ; ∫₀^(π/2) cos x dx = 1 ; ∫₋₁² x dx = 3/2
  • [calcul] La variable est muette : ∫₀¹ f(x) dx = ∫₀¹ f(t) dt — et si f ≥ 0 avec a ≤ b, l'intégrale est ≥ 0
