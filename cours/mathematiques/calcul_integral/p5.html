02
Réflexes

Les 10 réflexes de calcul

À chaque situation son geste automatique — la situation d'énoncé déclenche l'action :

Situation → action
  • « Calculer ∫ₐᵇ f » → trouver une primitive F, écrire le crochet [F(x)]ₐᵇ, puis substituer F(b) − F(a) (P2 §6).
  • « Montrer que F est une primitive » → dériver F, comparer à f, conclure en citant l'intervalle (P1 §3).
  • Racine ou puissance de trinôme → repérer le bloc u, calculer u', vérifier sa présence, compenser le coefficient (P2 §3).
  • Fraction « numérateur ≈ dérivée du dénominateur » → u'/u → ln(u), mais vérifier u > 0 avant d'écrire (P2 §3).
  • Produit polynôme × e^x, cos, sin → intégration par parties : dériver le polynôme, intégrer le reste (P4 §2-3).
  • Le logarithme seul → écrire ln x = 1 × ln x : u = ln x, v' = 1 (P4 §3).
  • « Calculer l'aire » → étudier le signe de f d'abord : f ≥ 0 → aire = ∫ ; f ≤ 0 → aire = −∫ ; signe quelconque → découper aux zéros (P2 §7 ; P3 §8).
  • « Aire entre deux courbes » → résoudre f = g, étudier le signe de f − g, intégrer haut − bas sur chaque tranche (P4 §5).
  • Contrôler un résultat → encadrement m·(b − a) ≤ ∫ ≤ M·(b − a), et μ = ∫/(b − a) reste entre m et M (P3 §7, §9).
  • Bornes écrites « à l'envers » → retourner avec le signe « − » avant d'appliquer toute autre propriété (P3 §6).
🔍 Le réflexe universel de vérification

Quel que soit le calcul, il existe un contrôle qui ne rate jamais : dériver la primitive candidate — on doit retrouver exactement f (chaque terme, chaque signe). Complète avec le contrôle d'ordre : une intégrale de fonction positive est positive, et une intégrale reste coincée entre les deux rectangles m·(b − a) et M·(b − a). Trois secondes par question, des points sauvés à chaque fois.

03
Pièges

Les 10 erreurs à bannir

Ces dix erreurs coûtent des points à chaque épreuve — le faux et le vrai, en une ligne chacune :

⚠️ Erreur 1 — oublier le « + c »

Les primitives de f sont F(x) = G(x) + c : c'est la condition initiale qui choisit c. Répondre x² seul à « une primitive de 2x » manque la famille complète. (P1 §5-6)

⚠️ Erreur 2 — confondre primitive et dérivée

x² est une primitive de 2x, pas l'inverse. Sens de lecture unique : on dérive le candidat F, on doit retrouver f. (P1 §3)

⚠️ Erreur 3 — écrire sin x → cos x

Faux : c'est −cos x. Le signe de cette ligne piège à chaque Bac — contrôle : dérive cos x, tu obtiens −sin x. (P1 §7)

⚠️ Erreur 4 — écrire √x → (3/2)·x·√x

Faux : on divise par le nouvel exposant, donc (2/3)·x·√x. Même piège avec 1/√x → 2√x (diviser par 1/2 = multiplier par 2). (P1 §7)

⚠️ Erreur 5 — écrire ln(u) sans vérifier u > 0

La forme u'/u → ln(u) exige que le bloc u soit strictement positif sur l'intervalle — sinon la primitive s'écrit ln|u| avec un contrôle du signe. (P2 §3)

⚠️ Erreur 6 — substituer F(a) − F(b)

Faux : borne haute MOINS borne basse. L'ordre inversé change le signe du résultat et coûte toute la question, même si la primitive est juste. Écris d'abord le crochet, ensuite substitue. (P2 §6)

⚠️ Erreur 7 — confondre aire et intégrale quand f change de signe

∫₀² (x² − 1) dx = 2/3 mais l'aire vaut 2/3 + 4/3 = 2 u.a. : on découpe aux zéros et on additionne les AIRES, pas les intégrales (qui se compensent). (P2 §7 ; P3 §8)

⚠️ Erreur 8 — distribuer l'intégrale sur un produit

∫ f·g dx ≠ ∫ f dx × ∫ g dx — il n'existe aucune règle pour « l'intégrale d'un produit » : pour cela, l'intégration par parties existe. (P3 §3)

⚠️ Erreur 9 — inverser la positivité

∫ₐᵇ f ≥ 0 ne prouve PAS que f ≥ 0 : contre-exemple x³ sur [−1 ; 1], intégrale nulle alors que f prend des valeurs négatives. Le sens de lecture va du signe de f vers le signe de l'intégrale. (P3 §5)

⚠️ Erreur 10 — bâcler la deuxième passe d'IPP

Oublier le facteur 2 de u' = 2x, ou le signe « − » devant la nouvelle intégrale (et v = −cos x quand v' = sin x) fausse tout. Remède : écrire les quatre fonctions u, u', v, v' à chaque passe. (P4 §2, §4)

🔍 Reconstruire sans mémoriser — 4 gestes
  • La règle des puissances : augmenter l'exposant de 1, puis diviser par le nouvel exposant. Le « 2/3 » de √x s'impose — et se contrôle en dérivant ((2/3) × (3/2) = 1).
  • La chaîne trigonométrique : dériver fait avancer d'une case dans le cycle cos → −sin → −cos → sin → cos ; primitiver fait reculer d'une case.
  • Deviner puis vérifier : pour ln x, on devine x·ln x − x et on dérive : ln x + 1 − 1 = ln x ✓. C'est la vérification qui décide, jamais l'impression.
  • Le bloc u : « quel bloc se répète ? où est u' ? » — puis appliquer la règle de xⁿ au bloc.
05
Fil rouge

Plan d'attaque d'un exercice type Bac

Un exercice d'intégration au Bac enchaîne presque toujours : (1) une étude de fonction (elle fixe les signes) ; (2) un calcul d'intégrale (forme composée ou IPP) ; (3) une aire (justifier le signe, conclure en u.a.) ; (4) une valeur moyenne (diviser par la largeur). Un seul sujet guide toutes les questions :

🧮 Le fil rouge — soit f(x) = x·ln x sur ]0 ; +∞[

Q1 — L'étude qui fixe les signes. Dérivée d'un produit :

f'(x) = 1 × ln x + x × 1/x = ln x + 1

Signe : ln x + 1 > 0 ⇔ x > 1/e. f décroît sur ]0 ; 1/e], croît ensuite, minimum f(1/e) = −1/e ≈ −0,37 ; et f(1) = 0, f(e) = e. (Réflexe 2 ; P1 §7-8)

Q2 — L'intégration par parties. Le cas logarithme prime : on dérive ln x, on intègre x. Posons u(x) = ln x (donc u' = 1/x) et v'(x) = x (donc v = x²/2) :

∫₁^e x·ln x dx = [x²·ln x/2]₁^e − ∫₁^e x/2 dx

= e²/2 − (e² − 1)/4 = (e² + 1)/4

Contrôle : 0 ≤ 2,10 ≤ (e² − 1)/2 ≈ 3,19 ✓ (Réflexe 6 ; P4 §2-3)

Q3 — La valeur moyenne. Largeur b − a = e − 1 :

μ = 1/(e − 1) × (e² + 1)/4 = (e² + 1)/(4(e − 1)) ≈ 1,22

Contrôle : f ≥ 0 sur [1 ; e] et f ≤ e, donc 0 ≤ 1,22 ≤ e ≈ 2,72 ✓ (P3 §9 ; Réflexe 9)

Q4 — L'aire. Sur [1 ; e], f(x) = x·ln x ≥ 0 (produit de deux positifs) : l'aire est l'intégrale.

A = ∫₁^e f(x) dx = (e² + 1)/4 ≈ 2,10 u.a.

Le fil du sujet : une seule intégrale, trois exploitations. (Réflexe 7 ; P2 §7)

La stratégie générale en 5 lignes
  • Étudie la fonction : dérivée, variations — c'est elle qui fixe les signes.
  • Calcule l'intégrale avec la bonne technique (tableau, forme composée, IPP) — en nommant l'outil.
  • Justifie le signe ou l'ordre des courbes avant d'écrire une intégrale d'aire.
  • Conclus chaque question par une phrase : valeur, unité, interprétation.
  • Contrôle : encadrement, valeur moyenne entre min et max, ou dérivation de la primitive. Toujours.

L'outil final

La figure du chapitre : l'aire sous la courbe — la refaire sans rien mémoriser

Tout le chapitre vit dans un seul dessin : une courbe, deux bornes, une zone hachurée entre la courbe et l'axe. La définition ∫ₐᵇ f = F(b) − F(a) y prend son sens, la valeur moyenne y devient visible, et chaque technique — signe de f, découpage aux zéros, encadrement — y trouve sa place. La voici :

🎯 La méthode en 5 étapes — poser n'importe quel calcul d'aire en 60 secondes
  • Étape 1 — Dessiner la courbe, repérer a et b, hachurer. Trace y = f(x) sur [a ; b], marque les bornes, hachure la zone entre courbe et axe. La figure décide de tout : signe, découpage, bornes. Jamais d'intégrale d'aire sans dessin.
  • Étape 2 — Le signe de f tranche entre aire et intégrale. f ≥ 0 sur [a ; b] : aire = ∫ₐᵇ f = F(b) − F(a) en u.a. f ≤ 0 : l'intégrale est négative, aire = −∫ₐᵇ f. Signe quelconque : résoudre f(x) = 0, découper aux zéros (Chasles), calculer chaque aire avec la bonne règle et additionner les AIRES — jamais les intégrales brutes.
  • Étape 3 — Retrouver la primitive : remonter depuis f, puis vérifier. La question n'est pas « quelle est la primitive de f ? » mais « de quoi f est-elle la dérivée ? ». On remonte (règle des puissances, chaîne trigo, bloc u), puis contrôle obligatoire : on redérive F, on doit retomber exactement sur f. Jamais de tableau à mémoriser aveuglément : chaque ligne se retrouve et se prouve.
  • Étape 4 — Le contrôle rapide (3 secondes). Si m ≤ f ≤ M sur [a ; b], l'intégrale reste coincée entre les deux rectangles : m·(b − a) ≤ ∫ₐᵇ f ≤ M·(b − a) (et si f ≥ 0 : simplement 0 ≤ ∫ₐᵇ f ≤ M·(b − a)). Si ton calcul sort de l'encadrement, il est faux.
  • Étape 5 — La valeur moyenne : le rectangle de même aire. μ = aire/(b − a) = 1/(b − a) × ∫ₐᵇ f : le rectangle de hauteur μ posé sur [a ; b] a exactement la même aire que le domaine, avec toujours m ≤ μ ≤ M. La bosse qui dépasse comble exactement le creux.
✅ Ce que tu dois VRAIMENT retenir

Rien par cœur. Juste : (1) le dessin d'abord (courbe, bornes, hachures) ; (2) la lecture du signe (f ≥ 0 : aire = ∫ ; f ≤ 0 : aire = −∫ ; signe quelconque : découper aux zéros) ; (3) la remontée « de quoi f est-elle la dérivée ? » suivie du contrôle F' = f ; (4) l'encadrement entre les rectangles m·(b − a) et M·(b − a) ; (5) la moyenne μ = aire/(b − a) et son rectangle. Avec ces 5 gestes, tu poses n'importe quel calcul d'aire en une minute.

🧮 Teste la méthode tout de suite — aire sous f(x) = √x entre 0 et 4

Étape 1. La courbe monte, la zone est hachurée au-dessus de l'axe entre x = 0 et x = 4.

Étape 2. f ≥ 0 sur [0 ; 4], donc aire = ∫₀⁴ √x dx.

Étape 3. De quoi √x est-elle la dérivée ? De (2/3)·x·√x — contrôle : ((2/3)·x^(3/2))' = √x ✓. D'où :

[(2/3)·x^(3/2)]₀⁴ = (2/3) × 8 = 16/3

Étape 4. Encadrement : f croît de 0 à 2, donc 0 ≤ 16/3 ≈ 5,33 ≤ 2 × 4 = 8 ✓

Étape 5. μ = (16/3)/4 = 4/3 : le rectangle de hauteur 4/3 sur [0 ; 4] a la même aire. ✓ Une minute, cinq gestes, zéro mémorisation.

📌 Ce qu'il faut retenir
  • [partie 1] F primitive de f ⇔ F' = f ; f continue ⇒ des primitives existent ; famille F + c ; tableau des primitives (xⁿ, 1/x, 1/x², √x, e^x, cos, sin) — toujours vérifier en dérivant
  • [partie 2] Formes composées u'·uⁿ, u'/u (u > 0), u'·e^u : repérer le bloc u et compenser ; ∫ₐᵇ f(x) dx = F(b) − F(a) — borne haute moins borne basse
  • [partie 3] Linéarité, Chasles, positivité (réciproque fausse), croissance, bornes inversées ; encadrement m·(b − a) ≤ ∫ ≤ M·(b − a) ; μ = 1/(b − a) × ∫, avec m ≤ μ ≤ M
