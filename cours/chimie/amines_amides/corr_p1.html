Nomenclature et classes d'amines

✏️ Exercice 1 — Nommer les amines (★)

Données : structures a à e de l'énoncé ; règle : alcane − « ane » + « -X-amine ».

1

a) CH₃—NH₂ : méthanamine. b) CH₃—CH₂—NH₂ : éthanamine.

2

c) CH₃—CH₂—CH₂—NH₂ : propan-1-amine (le groupe —NH₂ est sur le carbone 1). d) CH₃—CH(NH₂)—CH₃ : propan-2-amine (groupe sur le carbone 2).

3

e) CH₃—NH—CH₃ : l'azote porte deux groupes méthyle, donc N-méthylméthanamine. Formules demandées : butan-1-amine CH₃—CH₂—CH₂—CH₂—NH₂ ; N-méthyléthanamine CH₃—CH₂—NH—CH₃.

a) méthanamine ; b) éthanamine ; c) propan-1-amine ; d) propan-2-amine ; e) N-méthylméthanamine

La position du groupe —NH₂ sur la chaîne fait partie du nom.

⚠️ Piège : propan-1-amine et propan-2-amine sont deux composés différents ; et le préfixe « N- » signale un substitut porté par l'azote, pas par la chaîne.
✏️ Exercice 2 — Classes d'amines : lire la figure (★)

Données : figure de l'éthanamine ; H = 1, C = 12, N = 14 g·mol⁻¹.

1

Sur la figure, l'azote est lié à un seul atome de carbone (celui du groupe éthyle) : l'éthanamine est une amine primaire.

2

Classement : CH₃—NH₂ (N lié à 1 carbone) → primaire ; CH₃—NH—CH₃ (N lié à 2 carbones) → secondaire ; CH₃—N(CH₃)—CH₃ (N lié à 3 carbones) → tertiaire.

3

Masses molaires : CH₃—NH₂ = CH₅N → M = 12 + 5 + 14 = 31 g·mol⁻¹ ; CH₃—CH₂—NH₂ = C₂H₇N → M = 24 + 7 + 14 = 45 g·mol⁻¹.

Éthanamine : amine primaire ; M = 31 g·mol⁻¹ et 45 g·mol⁻¹

Primaire : 1 alkyle sur N ; secondaire : 2 ; tertiaire : 3.

⚠️ Piège : la classe se lit sur l'azote (nombre de carbones directement liés), pas sur la longueur de la chaîne : ne pas confondre avec les classes d'alcools.

Basicité, sels d'ammonium et découverte des amides

✏️ Exercice 3 — Une base en solution aqueuse (★★)

Données : éthanamine dissoute dans l'eau ; ajout d'acide chlorhydrique.

1

Réaction avec l'eau : CH₃—CH₂—NH₂ + H₂O ⇌ CH₃—CH₂—NH₃⁺ + OH⁻. L'ion organique formé est l'ion éthylammonium ; la double flèche signale un équilibre limité.

2

Oui : la solution contient des ions (CH₃—CH₂—NH₃⁺ et OH⁻) porteurs de charges électriques, donc elle conduit le courant.

3

L'acide apporte des ions H₃O⁺ qui consomment les ions OH⁻ et fixent un proton sur l'amine : l'équilibre se déplace dans le sens direct, l'amine est transformée en ion éthylammonium (sel d'ammonium soluble).

CH₃—CH₂—NH₂ + H₂O ⇌ CH₃—CH₂—NH₃⁺ + OH⁻

Vérification des charges : côté droit (+1) + (−1) = 0, comme à gauche ✓.

Figure — L'équilibre de basicité : l'azote bleu de l'amine fixe un proton et devient ion ammonium.
⚠️ Piège : l'équilibre est limité : la solution reste peu concentrée en OH⁻ — l'amine est une base faible, comme l'ammoniac.
✏️ Exercice 4 — Les amines réagissent avec les acides (★★)

Données : éthanamine ; HCl ; acide éthanoïque CH₃—COOH.

1

Avec l'acide chlorhydrique : CH₃—CH₂—NH₂ + HCl → CH₃—CH₂—NH₃⁺ + Cl⁻. Le sel obtenu est le chlorure d'éthylammonium. Neutralité : (+1) + (−1) = 0, comme à gauche ✓.

2

Avec l'acide éthanoïque : CH₃—CH₂—NH₂ + CH₃—COOH → CH₃—CH₂—NH₃⁺ + CH₃—COO⁻. Le sel obtenu est l'éthanoate d'éthylammonium. Neutralité : (+1) + (−1) = 0 ✓ ; atomes : C 4 = 4 ✓, H 12 = 12 ✓, N 1 = 1 ✓, O 2 = 2 ✓.

3

Comparaison : NH₃ + HCl → NH₄⁺ + Cl⁻. L'amine est une molécule d'ammoniac où un H est remplacé par un groupe alkyle R ; elle fixe un proton de la même façon et forme un « ammonium substitué » R—NH₃⁺.

R—NH₂ + HA → R—NH₃⁺ + A⁻

Chlorure d'éthylammonium et éthanoate d'éthylammonium : deux sels d'ammonium substitués.

⚠️ Piège : vérifie toujours que la somme des charges du membre de droite redonne celle de gauche : c'est le contrôle le plus rapide d'une équation ionique.
✏️ Exercice 5 — Compter les molécules d'une amine (★★)

Données : m = 3,65 g de butan-1-amine C₄H₁₁N ; Nₐ = 6,02×10²³ mol⁻¹.

1

La chaîne butyle porte 9 H, plus les 2 H du groupe —NH₂ : formule brute C₄H₁₁N. D'où M = 4×12 + 11×1 + 14 = 48 + 11 + 14 = 73 g·mol⁻¹.

2

Quantité de matière : n = m/M = 3,65/73 = 0,050 mol.

3

Nombre de molécules : N = n × Nₐ = 0,050 × 6,02×10²³ = 3,01×10²² molécules.

M = 73 g·mol⁻¹ ; n = 0,050 mol ; N = 3,01×10²² molécules

Chaîne d'abord, hydrogènes de l'azote ensuite : 9 + 2 = 11 H.

⚠️ Piège : ne compte que 9 hydrogènes : il manque alors les 2 H du groupe —NH₂ et la masse molaire est fausse.
✏️ Exercice 6 — Découvrir les amides : l'éthanamide (★★★)

Données : CH₃—CO—NH₂ ; hydrolyse à chaud : produits = acide éthanoïque + ammoniac.

1

Le groupe amide est l'ensemble —CO—NH₂ : un carbonyle lié directement à un azote. Formule générale : R—CO—NH₂, avec ici R = CH₃.

2

Formule brute : C₂H₅NO (3 H sur CH₃, 2 H sur NH₂). Masse molaire : M = 2×12 + 5×1 + 14 + 16 = 24 + 5 + 14 + 16 = 59 g·mol⁻¹.

3

Hydrolyse : CH₃—CO—NH₂ + H₂O → CH₃—COOH + NH₃. Vérification atome par atome : C : 2 = 2 ✓ ; H : 5 + 2 = 7 à gauche, 4 + 3 = 7 à droite ✓ ; O : 1 + 1 = 2 de part et d'autre ✓ ; N : 1 = 1 ✓.

4

Point commun avec l'hydrolyse d'un ester : c'est une réaction lente qui nécessite le chauffage (on coupe la molécule avec l'eau). Différence : conduite à chaud en milieu acide ou basique, l'hydrolyse d'un amide est totale, alors que celle d'un ester reste limitée par l'équilibre d'estérification.

CH₃—CO—NH₂ + H₂O → CH₃—COOH + NH₃

L'eau casse la liaison amide : l'acide et l'ammoniac se reforment.

⚠️ Piège : ne confonds pas l'amide R—CO—NH₂ (azote lié au carbone) et le sel d'ammonium R—COO⁻NH₄⁺ (azote lié à des hydrogènes) : ce sont deux composés très différents.
