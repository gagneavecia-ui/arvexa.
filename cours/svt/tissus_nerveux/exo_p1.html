✏️ Exercice 1 — Vrai ou Faux : le neurone (★)

Pour chaque affirmation, écris V (vrai) ou F (faux). Pour chaque « F », tu réécriras l'affirmation corrigée en une phrase.

  • a) Les dendrites conduisent le message nerveux vers le corps cellulaire.
  • b) L'axone conduit le message du corps cellulaire vers les boutons terminaux.
  • c) Les gaines de myéline sont des expansions des dendrites.
  • d) Le corps cellulaire contient le noyau.
  • e) Un nerf est formé d'un seul axone très long.
  • f) Les boutons terminaux permettent la communication avec la cellule suivante, au niveau d'une synapse.
  • g) Les cellules gliales produisent la gaine de myéline autour de certains axones.
  • h) Tous les neurones ont exactement la même forme.

✏️ Exercice 4 — Le nerf et les cellules gliales (★★)

Données : en microscopie optique, une coupe transversale d'un nerf montre de nombreux paquets de fibres nerveuses, regroupés et entourés d'enveloppes de tissu conjonctif. Chaque fibre est un axone, souvent entouré d'une gaine isolante.

  1. Comment nomme-t-on les « paquets de fibres » observés dans le nerf ?
  2. De quoi est constituée une fibre nerveuse d'un nerf ?
  3. Cite trois rôles des cellules gliales dans le tissu nerveux.
  4. Le nerf sciatique est dit mixte : explique pourquoi, en précisant les deux sens de circulation des messages qu'il contient.

✏️ Exercice 6 — Remets l'arc réflexe en ordre (★★★)

Situation : en cuisinant, tu touches une casserole brûlante : tu retires la main immédiatement, avant même d'avoir « compris » ce qui se passait. Les cinq étapes de la réponse sont données en désordre :

  • A. le neurone moteur conduit la commande jusqu'à la main ;
  • B. le récepteur cutané de la main détecte la chaleur ;
  • C. le muscle de la main (effecteur) se contracte : tu retires la main ;
  • D. dans la moelle épinière, le message passe au neurone moteur ;
  • E. le neurone sensitif conduit le message jusqu'à la moelle épinière.
  1. Remets ces étapes dans l'ordre chronologique (lettres séparées par des flèches →).
  2. Comment nomme-t-on le trajet ainsi parcouru par le message nerveux ?
  3. À quels niveaux le message traverse-t-il des synapses ?
  4. Le retrait de la main aurait-il lieu si le message n'atteignait pas le cerveau ? Justifie ta réponse.
