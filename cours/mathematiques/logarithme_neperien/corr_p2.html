✏️ Exercice 1 — Cinq dérivées ★★

Énoncé : dériver f(x) = x ln x, g(x) = ln(2x + 1), h(x) = x² ln x, k(x) = (ln x)/x et m(x) = ln(x² + 1), avec domaines.

1
f = u × v avec u = x, v = ln x : f' = u'v + uv' = 1 × ln x + x × (1/x) = ln x + 1, sur ℝ₊*.
2
Condition : 2x + 1 > 0 ⟺ x > −0,5. Avec (ln u)' = u'/u : g'(x) = 2/(2x + 1), sur ]−0,5 ; +∞[.
3
h' = u'v + uv' = 2x ln x + x² × (1/x) = 2x ln x + x = x(2 ln x + 1), sur ℝ₊*.
4
k = u/v avec u = ln x, v = x : k'(x) = (1 × x − ln x × 1)/x² = (1 − ln x)/x², sur ℝ₊*.
5
x² + 1 > 0 pour tout x : m'(x) = 2x/(x² + 1), sur ℝ.
f' = ln x + 1 · g' = 2/(2x + 1) · h' = x(2 ln x + 1) · k' = (1 − ln x)/x² · m' = 2x/(x² + 1)
Domaine d'abord, formule ensuite : g n'existe que pour x > −0,5, les autres partout où ln existe.
✏️ Exercice 2 — Étude complète de f(x) = x ln x − x ★★

Énoncé : limites, démonstration de f'(x) = ln x, tableau de variations et équation f(x) = 0 pour f(x) = x ln x − x sur ℝ₊*.

1
En 0⁺ : x ln x → 0 (croissance comparée) et x → 0, donc f(x) → 0 (par valeurs négatives). En +∞ : x ln x → +∞ et x → +∞, donc f(x) → +∞.
2
f' = u'v + uv' avec u = x, v = ln x : f'(x) = 1 × ln x + x × (1/x) = ln x + 1 − 1 = ln x.
3
Sur ]0 ; 1[, ln x < 0 donc f' < 0 ; sur ]1 ; +∞[, f' > 0 ; f'(1) = 0. Donc f décroît puis croît : minimum f(1) = 1 × 0 − 1 = −1.
4
f(x) = 0 ⟺ x ln x = x ⟺ x(ln x − 1) = 0 ; comme x > 0, il reste ln x = 1 ⟺ x = e. Contrôle : f(e) = e × 1 − e = 0 ✓.
x01+∞
f'(x)∥−0+∥
f(x)∥↘−1↗+∞

Limite en 0⁺ : f(x) → 0 par valeurs négatives. La courbe part donc de l'origine (sans l'atteindre), plonge jusqu'à −1 en x = 1, puis remonte en coupant l'axe en x = e ≈ 2,72.

Minimum : f(1) = −1 · f(x) = 0 ⟺ x = e
Le minimum est négatif : f est strictement négative sur ]0 ; e[ et strictement positive sur ]e ; +∞[.
✏️ Exercice 3 — Tangente et inégalité de référence ★★★

Énoncé : étudier f(x) = x − ln x (limites, variations), tangente en x = 1, puis démontrer ln x ≤ x − 1 pour tout x > 0.

1
En 0⁺ : x → 0 et ln x → −∞, donc f(x) = x − ln x → +∞. En +∞ : la croissance comparée donne (ln x)/x → 0, donc f(x) = x(1 − (ln x)/x) → +∞.
2
f'(x) = 1 − 1/x = (x − 1)/x pour x > 0 ; x étant positif, f' a le signe de x − 1 : négatif sur ]0 ; 1[, nul en 1, positif après.
3
Minimum : f(1) = 1 − 0 = 1. Tableau : f décroît de +∞ à 1 sur ]0 ; 1], puis croît de 1 à +∞.
4
Tangente en 1 : y = f(1) + f'(1)(x − 1) = 1 + 0 × (x − 1) = 1. Elle est horizontale — cohérent avec un minimum en ce point.
5
Pour tout x > 0 : f(x) ≥ f(1) = 1, c'est-à-dire x − ln x ≥ 1, donc ln x ≤ x − 1. L'égalité f(x) = 1 n'a lieu qu'en x = 1 (minimum unique), d'où l'égalité seulement pour x = 1.
Inégalité de référence (à connaître) : pour tout x > 0, ln x ≤ x − 1, avec égalité seulement en x = 1 — la droite y = x − 1 est tangente à la courbe de ln au point (1 ; 0) et la domine.
Minimum : f(1) = 1 · Tangente en 1 : y = 1 · ln x ≤ x − 1
Comme 1 > 0, on en déduit aussi x − ln x > 0 : la fonction f est toujours strictement positive.

✏️ Exercice 4 — Inéquations logarithmiques ★★

Énoncé : résoudre ln x ≤ 1, ln(x − 2) > 0, ln(2x) < ln(x + 3) et ln(x²) ≤ 2 (x ∈ ℝ*).

1
Domaine ℝ₊*. La stricte croissance de ln donne : ln x ≤ 1 ⟺ ln x ≤ ln e ⟺ x ≤ e ≈ 2,72. D'où S = ]0 ; e].
2
Domaine : x > 2. Alors ln(x − 2) > 0 = ln 1 ⟺ x − 2 > 1 ⟺ x > 3. D'où S = ]3 ; +∞[.
3
Domaine : x > 0 (il contient x > −3). La croissance de ln donne ln(2x) < ln(x + 3) ⟺ 2x < x + 3 ⟺ x < 3. D'où S = ]0 ; 3[.
4
Ici x ∈ ℝ* et ln(x²) existe pour tout x ≠ 0 (car x² > 0). On a ln(x²) ≤ 2 ⟺ x² ≤ e² ⟺ −e ≤ x ≤ e, avec x ≠ 0. D'où S = [−e ; 0[ ∪ ]0 ; e], soit environ [−2,72 ; 0[ ∪ ]0 ; 2,72].
S₁ = ]0 ; e] · S₂ = ]3 ; +∞[ · S₃ = ]0 ; 3[ · S₄ = [−e ; 0[ ∪ ]0 ; e]
Toute inéquation logarithmique se ramène à ln A ≤ ln B puis A ≤ B, à condition que A et B soient strictement positifs.
⚠️ Piège (équation 4) : ln x n'existe que si x > 0, mais ln(x²) existe aussi pour x < 0 ! D'où des solutions négatives, ici [−e ; 0[.
✏️ Exercice 5 — Limites et croissances comparées ★★★

Énoncé : calculer lim(x→+∞) (x − ln x), lim(x→0⁺) (x ln x), lim(x→+∞) (ln x)/x et lim(x→0⁺) (ln x)/x.

1
Forme +∞ − ∞ indéterminée : on factorise, x − ln x = x(1 − (ln x)/x) ; or (ln x)/x → 0 (croissance comparée), donc le facteur tend vers 1 et x → +∞ : la limite est +∞.
2
Limite de référence : lim(x→0⁺) x ln x = 0 (l'exponentielle de référence l'emporte ; ici le produit d'un petit facteur par un grand tend vers 0). On peut l'écrire x ln x = ln(x^x), mais la référence du cours suffit.
3
Croissance comparée : lim(x→+∞) (ln x)/x = 0 — la droite y = 0 est asymptote horizontale à la courbe de (ln x)/x en +∞.
4
En 0⁺ : ln x → −∞ et 1/x → +∞, donc (ln x)/x → −∞ (produit de deux limites infinies de signes opposés, pas d'indétermination ici).
Croissances comparées de ln (à connaître, n entier ≥ 1) : lim(x→+∞) (ln x)/xⁿ = 0 et lim(x→0⁺) xⁿ ln x = 0 : en fin de compte, ln grandit plus lentement que toute puissance de x.
x − ln x → +∞ · x ln x → 0 · (ln x)/x → 0 · (ln x)/x → −∞ en 0⁺
Les deux premières limites utilisent les croissances comparées ; les factorisations lèvent les formes indéterminées.
✏️ Exercice 6 — Problème type Bac ★★★

Énoncé : pour f(x) = x − 2 + ln x sur ℝ₊* : limites, variations, unicité de la solution α de f(x) = 0, encadrement de α, puis solutions de x − 2 + ln x ≥ 0.

1
En 0⁺ : x → 0 et ln x → −∞, donc f(x) → −∞. En +∞ : x → +∞ et ln x → +∞, donc f(x) → +∞.
2
f'(x) = 1 + 1/x = (x + 1)/x pour x > 0 ; x + 1 > 0 et x > 0, donc f'(x) > 0 : f est strictement croissante sur ℝ₊*.
3
Or f(1) = 1 − 2 + 0 = −1 < 0 et f(2) = 0 + ln 2 ≈ 0,69 > 0. f est continue et strictement croissante sur [1 ; 2] : d'après le théorème des valeurs intermédiaires (version stricte), l'équation f(x) = 0 admet une unique solution α dans ]1 ; 2[, donc dans ℝ₊*.
4
Avec ln 1,5 ≈ 0,41 : f(1,5) = 1,5 − 2 + 0,41 = −0,09 < 0 ; avec ln 1,6 ≈ 0,47 : f(1,6) = 1,6 − 2 + 0,47 = 0,07 > 0. Comme f est croissante : 1,5 < α < 1,6 (encadrement d'amplitude 10^(−1)).
5
f est strictement croissante et f(α) = 0 : donc f(x) ≥ 0 ⟺ x ≥ α. L'ensemble des solutions de x − 2 + ln x ≥ 0 est [α ; +∞[ avec α ≈ 1,56.
f croissante, f(1) = −1, f(2) ≈ 0,69 · 1,5 < α < 1,6 · S = [α ; +∞[
Le signe de f(x) se lit directement sur le tableau : négative avant α, positive après — c'est le lien étude ↔ inéquation.
⚠️ Piège : citer le théorème des valeurs intermédiaires sans justifier la stricte monotonie (question 2) fait perdre la moitié des points de la question 3.
