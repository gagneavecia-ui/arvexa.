✏️ Exercice 1 — Cinq dérivées ★★

Énoncé : dériver f(x) = x e^x, g(x) = e^(2x + 1), h(x) = (e^x)/x, k(x) = x² e^(−x) et m(x) = (2x + 1)e^x.

1
f = u × v avec u = x, v = e^x : f' = u'v + uv' = 1 × e^x + x × e^x = (x + 1)e^x.
2
Avec (e^u)' = u' e^u et u(x) = 2x + 1 : g'(x) = 2 × e^(2x + 1) = 2e^(2x + 1).
3
h = u/v avec u = e^x, v = x : h'(x) = (x e^x − e^x)/x² = e^x(x − 1)/x², pour x ≠ 0.
4
k' = u'v + uv' = 2x e^(−x) + x² × (−e^(−x)) = x e^(−x)(2 − x) (on factorise par x e^(−x)).
5
m' = 2e^x + (2x + 1)e^x = (2x + 3)e^x.
f' = (x + 1)e^x · g' = 2e^(2x + 1) · h' = e^x(x − 1)/x² · k' = x e^(−x)(2 − x) · m' = (2x + 3)e^x
Factoriser la dérivée (par e^x, x e^(−x)…) rend l'étude du signe presque immédiate.
✏️ Exercice 2 — Étude complète de f(x) = (x + 1)e^x ★★

Énoncé : limites et asymptote en −∞, limite en +∞, démonstration de f'(x) = (x + 2)e^x, tableau de variations, puis zéro de f.

1
En −∞ : f(x) = x e^x + e^x avec x e^x → 0 (croissance comparée) et e^x → 0, donc f(x) → 0 (par valeurs négatives). La droite y = 0, c'est-à-dire l'axe des abscisses, est asymptote horizontale en −∞.
2
En +∞ : x + 1 → +∞ et e^x → +∞, donc f(x) → +∞.
3
f' = u'v + uv' = 1 × e^x + (x + 1)e^x = (x + 2)e^x. Comme e^x > 0, f'(x) a le signe de x + 2 : négatif sur ]−∞ ; −2[, nul en −2, positif sur ]−2 ; +∞[.
4
f décroît puis croît : minimum f(−2) = (−2 + 1)e^(−2) = −e^(−2) ≈ −0,14 (car e^(−2) ≈ 0,135).
5
f(−1) = 0 × e^(−1) = 0 et f(0) = 1 × e⁰ = 1 : la courbe coupe l'axe des abscisses au point (−1 ; 0) et passe par (0 ; 1).

Asymptote : y = 0 en −∞ · Minimum : f(−2) = −e^(−2) ≈ −0,14 · f(−1) = 0
La courbe descend de l'asymptote y = 0, plonge jusqu'à −0,14 en x = −2, remonte et traverse l'axe en x = −1.
✏️ Exercice 3 — Croissance comparée : e^x contre x ★★★

Énoncé : étudier g(x) = e^x − x − 1, en déduire e^x ≥ x + 1, l'interpréter comme une tangente, puis calculer lim(x→−∞) (e^x − x).

1
g'(x) = e^x − 1. Or e^x < 1 pour x < 0, e^x = 1 pour x = 0, e^x > 1 pour x > 0 : g décroît sur ]−∞ ; 0] et croît sur [0 ; +∞[.
2
Minimum : g(0) = e⁰ − 0 − 1 = 0. Donc g(x) ≥ 0 pour tout x ∈ ℝ, c'est-à-dire e^x ≥ x + 1, avec égalité seulement en x = 0 (minimum unique).
3
Interprétation : la tangente à la courbe de e^x au point (0 ; 1) a pour équation y = e⁰ + e⁰ × x = x + 1 ; l'inégalité e^x ≥ x + 1 dit que la courbe reste au-dessus de cette tangente en (0 ; 1) — c'est le signe d'une fonction convexe.
4
Comme x + 1 > x pour tout x, on a a fortiori e^x > x : l'exponentielle domine la droite y = x (comparer sur la figure).
5
En −∞ : pour x < 0, e^x > 0 donc e^x − x > −x ; comme −x → +∞, on obtient lim(x→−∞) e^x − x = +∞.
Croissance comparée de référence (à connaître) : pour tout x ∈ ℝ, e^x ≥ x + 1, avec égalité seulement en x = 0 — la courbe de exp est au-dessus de sa tangente y = x + 1 au point (0 ; 1).
Minimum : g(0) = 0 · e^x ≥ x + 1 ≥ x · e^x − x → +∞ en −∞
C'est l'inégalité mère du chapitre : elle fournit toutes les comparaisons entre exp et les fonctions affines.

✏️ Exercice 4 — Limites et croissances comparées ★★

Énoncé : calculer lim(x→+∞) (e^x)/x, lim(x→−∞) (x e^x), lim(x→+∞) (e^x − x) et lim(x→−∞) (x² e^x).

1
Croissance comparée : lim(x→+∞) (e^x)/x = +∞ — l'exponentielle l'emporte sur toute puissance de x.
2
Croissance comparée en −∞ : lim(x→−∞) x e^x = 0 — la décroissance rapide de e^x écrase la croissance de x.
3
e^x − x = e^x(1 − x e^(−x)) ; en +∞, x e^(−x) → 0 (croissance comparée, question 2 en changeant x en −x), donc le facteur tend vers 1 tandis que e^x → +∞ : la limite est +∞.
4
De même lim(x→−∞) x² e^x = 0 : même à l'infini négatif, e^x tend vers 0 plus vite que x² ne tend vers l'infini.
Bilan des croissances comparées (n entier ≥ 1) : lim(x→+∞) (e^x)/xⁿ = +∞ · lim(x→−∞) xⁿ e^x = 0 · lim(x→+∞) (ln x)/xⁿ = 0 · lim(x→0⁺) xⁿ ln x = 0.
(e^x)/x → +∞ · x e^x → 0 · e^x − x → +∞ · x² e^x → 0
Message unique du chapitre : en bout de course, e^x gagne contre tout polynôme, et ln perd contre tout polynôme.
✏️ Exercice 5 — Intérêts composés et suite géométrique ★★★

Énoncé : u₀ = 50 000 F CFA, uₙ₊₁ = 1,04 × uₙ ; montrer que (uₙ) est géométrique, exprimer uₙ, calculer u₅, puis trouver l'année où le capital dépasse 100 000 F CFA (ln 2 ≈ 0,69, ln 1,04 ≈ 0,039).

1
Pour tout n : uₙ₊₁ = 1,04 × uₙ — chaque terme s'obtient en multipliant le précédent par une constante : (uₙ) est géométrique de raison q = 1,04 et de premier terme u₀ = 50 000. Or 1,04 = 1 + 4/100 : multiplier par 1,04 ajoute 4 % du capital (les intérêts de l'année).
2
Formule d'une suite géométrique : uₙ = u₀ × qⁿ = 50 000 × 1,04ⁿ (F CFA).
3
1,04⁵ ≈ 1,2167, donc u₅ = 50 000 × 1,2167 ≈ 60 833 F CFA. Contrôle année par année dans le tableau ci-dessous ✓.
4
uₙ ≥ 100 000 ⟺ 1,04ⁿ ≥ 2. Comme ln est croissante et 1,04ⁿ > 0 : n ln 1,04 ≥ ln 2 ⟺ n ≥ ln 2/ln 1,04 ≈ 0,69/0,039 ≈ 17,7. Le premier entier convenable est n = 18.
5
Contrôle : u₁₇ = 50 000 × 1,04¹⁷ ≈ 97 395 F CFA < 100 000 et u₁₈ = 50 000 × 1,04¹⁸ ≈ 101 291 F CFA ≥ 100 000 : le capital dépasse 100 000 F CFA la 18ᵉ année.

✏️ Exercice 6 — Problème type Bac ★★★

Énoncé : pour f(x) = (x + 1)e^(−x) sur ℝ : limites et asymptote, démonstration de f'(x) = −x e^(−x), tableau de variations, tangente en 0, zéro et signe de f.

1
En +∞ : f(x) = x e^(−x) + e^(−x) avec x e^(−x) → 0 (croissance comparée) et e^(−x) → 0, donc f(x) → 0 (par valeurs positives). La droite y = 0 est asymptote horizontale en +∞.
2
En −∞ : x + 1 → −∞ et e^(−x) → +∞, donc f(x) → −∞.
3
f' = u'v + uv' avec u = x + 1, v = e^(−x) et v' = −e^(−x) : f'(x) = e^(−x) + (x + 1)(−e^(−x)) = e^(−x)(1 − x − 1) = −x e^(−x).
4
Comme e^(−x) > 0, f' a le signe de −x : positif sur ]−∞ ; 0[, nul en 0, négatif sur ]0 ; +∞[. f croît puis décroît : maximum f(0) = 1 × e⁰ = 1.
5
Tangente en 0 : f'(0) = 0 et f(0) = 1, donc y = 1 — tangente horizontale au sommet.
6
f(x) = 0 ⟺ x + 1 = 0 (car e^(−x) ≠ 0) ⟺ x = −1. Signe : f(x) < 0 pour x < −1, f(−1) = 0, f(x) > 0 pour x > −1.

Asymptote : y = 0 en +∞ · Maximum : f(0) = 1 · Tangente en 0 : y = 1 · f(x) = 0 ⟺ x = −1
Le signe de −x commande tout : croissante avant 0, décroissante après — d'où le maximum 1.
⚠️ Piège : la dérivée de e^(−x) est −e^(−x) (facteur u' = −1) ; oublier ce signe inverse tout le tableau de variations.
