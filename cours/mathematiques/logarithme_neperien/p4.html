Accroche

La technique reine : figer un duel dans une fonction

« ln x tend vers +∞ » et « ln x croît lentement » ne se contredisent pas : ce sont deux infinis qui se disputent la même courbe. Une calculatrice laisse croire au hasard ; la démonstration, elle, remplace le duel par un objet figé : une fonction auxiliaire — l'écart x − ln x pour les inégalités, le quotient (ln x)/x pour les limites, la substitution x = 1/t pour changer de point limite.

📗 Le fil conducteur de toute la partie

La démarche est toujours la même : former l'écart ou le quotient, l'étudier (dérivée, tableau de variations), puis lire la conclusion sur son tableau. Trois gestes démontrés ici une fois pour toutes, réutilisables dans tous les chapitres de Terminale D — suites, exponentielle, intégrales.

Le trio de croissances — démontré dans cette partie
ln x ≤ x − 1 < x  (x > 0)
(ln x)/x → 0 en +∞  ·  x · ln x → 0 en 0⁺
À l'infini, toute puissance de x l'emporte sur ln. La partie 3 avait admis ces limites : ici, chacune reçoit sa démonstration.
01
Notion 1 · croissances

Croissances comparées : les démonstrations complètes

Démonstration n° 1 — ln x < x pour tout x > 0

L'auxiliaire est l'écart u(x) = x − ln x sur ]0 ; +∞[ : si u est toujours positive, le duel est plié.

1

Dérivée (même dénominateur x) :

u'(x) = 1 − 1/x = (x − 1)/x

2

Signe. Sur le domaine, x > 0 : u' a le signe de x − 1, négatif avant 1, positif après.

3

Tableau. u décroît puis croît : minimum en x = 1, et u(1) = 1 − ln 1 = 1.

4

Conclusion. Le minimum vaut 1 > 0 : x − ln x > 0 pour tout x > 0, c'est-à-dire ln x < x. ✔

ln x ≤ x − 1  (égalité seulement en x = 1)  ⇒  ln x < x
La version ln x < x est la forme « tout terrain », valable sans exception, qui sert dans les comparaisons rapides.

Démonstration n° 2 — (ln x)/x → 0 en +∞ : le pincement

1

Appliquer ln x ≤ y − 1 à y = √x (inégalité de référence, partie 3) :

ln √x ≤ √x − 1 ≤ √x

2

Sortir la racine du log (ln √x = (1/2) · ln x) et multiplier par 2 :

ln x ≤ 2√x

3

Diviser par x > 0 — les deux gendarmes se resserrent :

0 ≤ (ln x)/x ≤ 2√x/x = 2/√x

Quand x → +∞, 2/√x → 0 : par pincement, (ln x)/x → 0. ✔

🧮 Vérifier le majorant sur des valeurs

Pour x = 4 : ln 4 ≈ 1,386 et 2√4 = 4 ✔. Pour x = 100 : ln 100 ≈ 4,61 et 2√100 = 20 ✔. Pour x = 10 000 : ln 10 000 ≈ 9,21 et 2√10 000 = 200 ✔. Le majorant est lâche mais il tend vers 0 après division par x : c'est tout ce qu'il faut. La « lenteur » de ln est une conséquence de sa concavité — et pour tout entier n ≥ 1, la généralisation suit : (ln x)/xⁿ = (ln x)/x × 1/x^(n−1) → 0 × 0 = 0 (le cas 0⁺ se ramène au même par x = 1/t).

Démonstration n° 3 — x · ln x → 0 en 0⁺ : la substitution

1

Poser t = 1/x. Quand x → 0⁺, t → +∞, et ln x = ln(1/t) = −ln t (l'inverse change le signe).

2

Réécrire le produit :

x · ln x = (1/t) × (−ln t) = −(ln t)/t

3

Conclure avec la démonstration n° 2 : (ln t)/t → 0 quand t → +∞, donc x · ln x → 0 en 0⁺. ✔ Le produit est négatif sur ]0 ; 1[ et tend vers 0 par valeurs négatives.

🚨 Ne pas sortir une croissance comparée de son cadre

(ln x)/x → 0 est valable en +∞ ; x · ln x → 0 est valable en 0⁺. Les échanger est une faute classique : « x · ln x → 0 en +∞ » est faux (en +∞, x · ln x → +∞ !). Avant d'invoquer une croissance comparée, écris le point limite : c'est la moitié de la réponse.

Notion 2 · equations

Équations avec ln approfondies

Trois familles font la différence au Bac : les équations à regrouper (plusieurs ln), les trinômes déguisés (changement de variable t = ln x) et les équations produit. Le fil conducteur ne change jamais.

Les équivalences de travail — avec leurs conditions
ln A = ln B ⇔ A = B
ln A = k ⇔ A = e^k
Valables pour A, B > 0 sur le domaine. La première est l'injectivité de ln (strictement croissante) ; la seconde est la définition même. Les conditions A > 0, B > 0 ne sont pas décoratives : ce sont elles qui rejettent les fausses solutions.
🧠 Méthode — équation avec ln en 5 étapes
  • (1) Domaine : écrire toutes les conditions (> 0 sous chaque ln) sur leur propre ligne, avant tout calcul.
  • (2) Regrouper : ramener chaque membre à un seul ln (propriétés du produit et du quotient).
  • (3) Éliminer : ln A = ln B ⇔ A = B ; ou changer de variable t = ln x si un carré traîne.
  • (4) Résoudre l'équation restante (souvent un trinôme).
  • (5) Filtrer : rejeter toute solution hors du domaine, vérifier les autres, conclure S = {…}.
🧮 Exemple 1 (type Bac) — ln x + ln(x − 1) = ln 6

Domaine : x > 0 et x − 1 > 0, c'est-à-dire x > 1. Toute solution hors de ]1 ; +∞[ sera rejetée.

1

Regrouper. Pour x > 1, les deux arguments sont positifs :

ln x + ln(x − 1) = ln(x(x − 1))

L'équation devient ln(x(x − 1)) = ln 6.

2

Éliminer les ln (injectivité) :

x(x − 1) = 6 ⇔ x² − x − 6 = 0

3

Trinôme. Δ = 1 + 24 = 25 :

x = (1 + 5)/2 = 3  ou  x = (1 − 5)/2 = −2

4

Filtrer et vérifier. −2 < 1 : rejeté (ln(−2) et ln(−3) n'existent pas). Reste x = 3, et en effet ln 3 + ln 2 = ln 6 car 3 × 2 = 6 ✔. Conclusion : S = {3}.

Le changement de variable t = ln x

L'équation (ln x)² − 3 ln x + 2 = 0 semble du second degré en x — elle est du second degré en ln x. Le changement de variable est légitime car ln est une bijection de ]0 ; +∞[ sur ℝ : à chaque réel t correspond exactement un x > 0, à savoir x = e^t. Rien ne se perd, rien ne se crée.

🧮 Exemple 3 (type Bac) — (ln x)² − 3 ln x + 2 = 0
1

Domaine : x > 0. On pose t = ln x, t réel quelconque.

2

Réécrire : l'équation devient le trinôme t² − 3t + 2 = 0.

3

Résoudre en t. Δ = 9 − 8 = 1 : t = (3 ± 1)/2, donc t = 1 ou t = 2.

4

Revenir à x via x = e^t, une valeur par ligne :

t = 1 donne x = e  ;  t = 2 donne x = e²

5

Conclure et vérifier. S = {e ; e²} ; contrôles : pour x = e, 1 − 3 + 2 = 0 ✔ ; pour x = e², 4 − 6 + 2 = 0 ✔.

🧮 Exemple 4 — (ln x)² = ln(x²) : le piège du carré démêlé

Domaine x > 0 : dans ce domaine, ln(x²) = 2 ln x (puissance licite). Tout à gauche puis factoriser :

(ln x)² − 2 ln x = 0 ⇔ ln x · (ln x − 2) = 0

Donc ln x = 0 ⇔ x = 1 ou ln x = 2 ⇔ x = e² : S = {1 ; e²} ✔. Le carré du log n'est pas le log du carré — cette équation démasque la confusion.

🚨 Garder une solution hors du domaine : la faute éliminatoire

Dans l'exemple 1, conclure S = {3 ; −2} sans avoir écrit le domaine x > 1 fait perdre la question entière. Grille de sécurité : conditions d'existence d'abord (ligne séparée), calcul ensuite, filtre et vérification enfin. Une phrase de rejet vaut des points : « −2 est rejeté car il viole x > 1 ».

Notion 3 · inequations

Inéquations avec ln approfondies

Même stratégie que pour les équations, avec un atout : ln est strictement croissante, donc éliminer les logarithmes conserve le sens des inégalités. Le travail de fond reste le filtre du domaine — et, sur les trinômes, un tableau de signes soigné.

ln x < ln b ⇔ 0 < x < b  (x > 0, b > 0)
ln x ≥ a ⇔ x ≥ e^a  (solution automatiquement positive)
ln x > 0 ⇔ x > 1
Les trois inéquations de référence, à décliner avec ≤, >, ≥. La première conserve l'ordre et le domaine ; la seconde donne une solution toujours positive ; la troisième est le seuil x = 1 du signe de ln.
🧮 Exemple 1 (type Bac) — (ln x)² ≤ 3 ln x
1

Domaine : x > 0.

2

Tout à gauche et factoriser :

(ln x)² − 3 ln x ≤ 0 ⇔ ln x · (ln x − 3) ≤ 0

3

Tableau de signes en posant t = ln x. Le produit t(t − 3) est négatif entre ses racines 0 et 3 :

0 ≤ ln x ≤ 3

4

Revenir à x (ordre conservé, car e^0 = 1 et e^3) : 1 ≤ x ≤ e³, donc S = [1 ; e³]. Contrôles : x = 1 donne 0 ≤ 0 ✔ (inclus) ; x = e⁴ donne 16 ≤ 12 ? Non — exclu, cohérent.

🧮 Exemple 2 — domaine des deux côtés : ln(5 − 2x) ≥ ln(x + 4)

Domaine : x < 5/2 et x > −4, soit ]−4 ; 5/2[. On retire les ln (ordre conservé) :

5 − 2x ≥ x + 4 ⇔ 1 ≥ 3x ⇔ x ≤ 1/3

Intersecter : 1/3 ≈ 0,33 appartient au domaine : S = ]−4 ; 1/3]. Contrôles : x = 0 donne ln 5 ≥ ln 4 ✔ ; x = 2 donne ln 1 = 0 < ln 6 — exclu, cohérent.

🧮 Exemple 3 — une impossibilité démontrée en une ligne : ln x ≥ x

Aucun calcul de domaine nécessaire : la démonstration n° 1 donne ln x < x pour tout x > 0. Donc l'inéquation ln x ≥ x n'a aucune solution : S = ∅. Une inéquation logarithmique peut se conclure par une croissance comparée — une phrase suffit, à condition de citer le théorème démontré.

⚠️ Deux ensembles à joindre, pas un seul

La réponse d'une inéquation logarithmique est presque toujours l'intersection du domaine et de la solution « sans ln ». Pour l'exemple 2, conclure S = ]−∞ ; 1/3] en oubliant −4 < x < 5/2 est faux : sur ]−∞ ; −4[, les deux logarithmes n'existent pas. Écris deux lignes — la solution sans ln, le domaine — puis une ligne d'intersection.

Notion 4 · etudes

Études complètes : f(x) = x ln x et g(x) = ln(x² + 1)

Les deux fonctions vedettes des sujets de Bac : la première est la forme produit du duel des croissances comparées, la seconde la forme composée la plus classique. Toutes deux suivent le plan immuable : domaine → dérivée → limites → tableau → valeurs particulières.

A. Étude complète de f(x) = x · ln x

1

Domaine. f existe si x > 0 : domaine ]0 ; +∞[.

2

Dérivée (produit, u = x et v = ln x) :

f'(x) = 1 × ln x + x × (1/x) = ln x + 1

3

Signe de f'. ln x + 1 > 0 ⇔ ln x > −1 ⇔ x > e^(−1) = 1/e : négative sur ]0 ; 1/e[, nulle en 1/e, positive ensuite.

4

Limites. En +∞ : f → +∞. En 0⁺ : croissance comparée démontrée en section 01 — x · ln x → 0.

5

Extremum et signe. f(1/e) = (1/e) × ln(1/e) = −1/e : minimum. Zéro en x = 1 (car ln 1 = 0) : f < 0 sur ]0 ; 1[, f > 0 ensuite. Corollaire : x · ln x ≥ −1/e pour tout x > 0.

x01/e ≈ 0,37+∞
f'(x) = ln x + 1‖−0+
f(x)0↘−1/e↗+∞
La courbe part de l'origine (limite 0 en 0⁺), plonge jusqu'au minimum (1/e ; −1/e), puis remonte — elle coupe l'axe en (1 ; 0).
🧮 Application — résoudre x · ln x = 1

Cette équation mêle l'inconnue et son logarithme : aucun outil des équations ne l'isole. Mais l'étude dit tout : sur [1/e ; +∞[, f est continue et strictement croissante de −1/e vers +∞, elle prend la valeur 1 une seule fois (unicité garantie par la stricte monotonie). Sur ]0 ; 1/e], f ≤ 0 < 1 : rien. À la calculatrice : f(1,76) ≈ 0,995 < 1 et f(1,77) ≈ 1,011 > 1. Conclusion : l'équation a une unique solution α, avec α ∈ ]1,76 ; 1,77[. Existence, unicité, encadrement : trois points de rédaction.

📗 Bonus — la tangente en 1, et une jolie symétrie de situation

f(1) = 0 et f'(1) = ln 1 + 1 = 1 : la tangente en (1 ; 0) est y = x − 1 — exactement la tangente de ln en 1 ! Mais position relative opposée : l'écart d(x) = x ln x − (x − 1) a pour dérivée ln x, minimum d(1) = 0, donc d ≥ 0 : la courbe de x ln x est au-dessus de sa tangente, alors que celle de ln était en dessous. Les deux fonctions encadrent la droite y = x − 1 de part et d'autre.

B. Étude complète de g(x) = ln(x² + 1)

1

Domaine. x² + 1 ≥ 1 > 0 pour tout réel : domaine ℝ — une ligne suffit, dite en une fois.

2

Parité. g(−x) = ln((−x)² + 1) = g(x) : g est paire — courbe symétrique par rapport à l'axe des ordonnées. On étudie sur [0 ; +∞[ et on lit la suite en miroir.

3

Dérivée (u = x² + 1, u' = 2x, formule (ln u)' = u'/u) :

g'(x) = 2x/(x² + 1)

4

Signe. x² + 1 > 0 toujours : g' a le signe de 2x — négative sur ]−∞ ; 0[, nulle en 0, positive ensuite : minimum en 0, et g(0) = ln 1 = 0.

5

Limites, zéro, signe. En ±∞ : x² + 1 → +∞ donc g → +∞. g(x) = 0 ⇔ x² + 1 = 1 ⇔ x = 0 : g ≥ 0 sur ℝ, nulle seulement en 0 — la courbe vit au-dessus de l'axe, qu'elle touche avec une tangente horizontale.

Fonction paire : minimum 0 à l'origine, croissance « logarithmique » des deux côtés — g(1) = ln 2 ≈ 0,69 ; g(2) = ln 5 ≈ 1,61 ; g(3) = ln 10 ≈ 2,30.
🚨 Écrire g'(x) = 1/(x² + 1) : la dérivée « oubliée »

Confondre [ln(x² + 1)]' avec 1/(x² + 1) est l'erreur de dérivation n° 1 sur cette fonction : il faut la formule (ln u)' = u'/u avec le u' : g' = 2x/(x² + 1). Réflexe de vérification : dérive ta réponse — la dérivée de 1/(x² + 1) donne −2x/(x² + 1)², qui n'a ni le bon signe ni la bonne forme : l'erreur se démasque en dix secondes.

Notion 5 · primitives

Primitives u'/u en profondeur

La forme u'/u est la « caméléone » des intégrales : x/(x² + 1), (ln x)/x, 1/(x · ln x), e^x/(e^x + 1)… sont la même forme avec des u différents. Savoir la démasquer, c'est transformer une intégrale-effrayante en une primitive en une ligne.

Le socle — formules et conditions
∫ u'/u dx = ln(u) + C   (u > 0 sur l'intervalle)
∫ k · u'/u dx = k · ln(u) + C
Le facteur k (constant) sort de l'intégrale sans dommage ; la condition u > 0 sur tout l'intervalle fait partie de la réponse. Contrôle universel : redériver la primitive doit redonner exactement l'intégrande.
🧠 Reconnaître et primitiver u'/u — les 5 gestes
  • (1) Repérer le dénominateur : c'est le candidat u ;
  • (2) Calculer u' et comparer au numérateur : proportionnels ?
  • (3) Corriger le facteur : si le numérateur vaut k · u', la primitive est k · ln(u) ;
  • (4) Vérifier u > 0 sur l'intervalle donné (discriminant, minimum, évidence) ;
  • (5) Redériver ta réponse pour contrôler — toujours.
🧮 Exemple 1 — quand u est elle-même un logarithme : (ln x)/x
1

Poser u. u(x) = ln x ; alors u'(x) = 1/x : le numérateur est exactement u'.

2

Reconnaître : f(x) = (ln x)/x = u'/u — la forme parfaite.

3

Primitiver :

F(x) = (ln x)²/2

4

Contrôler : F'(x) = (1/2) × 2 ln x × (1/x) = (ln x)/x = f(x) ✔ — la dérivée d'un carré, chaîne (v²)' = 2v'v avec v = ln x.

🧮 Exemple 2 — le classique des classiques : 1/(x · ln x)
1

Poser u. u(x) = ln x, u'(x) = 1/x, et f(x) = 1/(x · ln x) = u'/u.

2

Le domaine, crucial. Il faut u(x) = ln x > 0, c'est-à-dire x > 1 : la primitive n'existe que sur ]1 ; +∞[.

3

Conclure : F(x) = ln(ln x) + C sur ]1 ; +∞[. Contrôle : [ln(v)]' = v'/v avec v = ln x donne F'(x) = (1/x)/ln x = 1/(x · ln x) ✔.

🧮 Exemple 3 — facteur constant : (4x + 2)/(x² + x + 1)

On pose u(x) = x² + x + 1, donc u'(x) = 2x + 1 : le numérateur 4x + 2 = 2(2x + 1) = 2u', donc f = 2 · u'/u. Et Δ = 1 − 4 = −3 < 0 avec a = 1 > 0 : u est toujours positif (minimum u(−1/2) = 3/4 > 0) — la primitive vaut sur ℝ tout entier :

F(x) = 2 · ln(x² + x + 1)

Contrôle : F'(x) = 2(2x + 1)/(x² + x + 1) = (4x + 2)/(x² + x + 1) ✔.

🧮 Exemple 4 — l'intégrale définie évaluée de bout en bout

Calculer I = ∫₂⁵ (2x)/(x² + 1) dx :

1

Reconnaître. u(x) = x² + 1, u' = 2x : l'intégrande est u'/u, avec u ≥ 5 > 0 sur [2 ; 5].

2

Une primitive : F(x) = ln(x² + 1).

3

Évaluer (théorème fondamental : F(b) − F(a)) :

I = F(5) − F(2) = ln 26 − ln 5 = ln(26/5) = ln 5,2 ≈ 1,65

🚨 L'intervalle fait partie de la réponse

Répondre « une primitive de 1/(x · ln x) est ln(ln x) » sans l'intervalle est une réponse incomplète — et fausse si on la croit valable sur ]0 ; +∞[ : pour 0 < x < 1, ln x < 0 et ln(ln x) n'existe pas. De même, ln(x² − 4) n'est primitive de rien sur ℝ (où x² − 4 change de signe). Grille : forme → facteur → signe de u sur l'intervalle → formule + intervalle → contrôle par dérivation.

Notion 6 · applications & examen

Applications, réflexes Bac et grande table de synthèse

Dès qu'une grandeur croît ou décroît exponentiellement, retrouver la durée ou le facteur demande de sortir l'exposant — c'est-à-dire d'appliquer ln. La chaîne est toujours la même : équation du seuil, division par N₀, application de ln, isolement.

N(t) = N₀ · e^(k·t)  ⇒  T = ln 2 / k ≈ 0,693/k
log x = ln x / ln 10  (ln 10 ≈ 2,303)  ;  log(10ⁿ) = n
T est indépendante de N₀. Le seuil « multiplier par a » donne T = ln a / k. Le log décimal « compte les puissances de 10 » : pH = −log a ; décibels = 10 · log(I/I₀).
🧮 Le temps de doublement, démontré puis appliqué
1

Équation du seuil. Le temps T tel que N(T) = 2N₀ :

N₀ · e^(k·T) = 2N₀ ⇔ e^(k·T) = 2

2

Appliquer ln des deux côtés (fonction croissante : équivalence) :

k·T = ln 2

3

Isoler : T = ln 2 / k. La même formule vaut pour la décroissance (demi-vie, dépréciation) : le seuil e^(−kT) = 1/2 donne −kT = −ln 2.

4

Application. Capital à 7 % continu (k = 0,07) : T = 0,693/0,07 ≈ 9,9 ans — la « règle des 70 » des économistes (70/7 = 10). Bactéries à k = 0,2/h : T = 0,693/0,2 ≈ 3,47 h. ✔

🧮 Le pH — le logarithme décimal en chimie

Le pH d'une solution de concentration a en ions hydrogène vaut pH = −log a. Eau neutre : a = 10⁻⁷, donc log(10⁻⁷) = −7 et pH = 7 ✔. Lecture inverse : un pH de 4 correspond à a = 10⁻⁴ — chaque unité de pH divise la concentration par 10 : une échelle logarithmique.

🧮 Les décibels — mesurer le son en échelle log
1

Formule : L = 10 · log(I/I₀) avec I₀ = 10⁻¹² W·m⁻² (seuil d'audition).

2

Conversation courante (I = 10⁻⁶) : le rapport vaut 10⁻⁶/10⁻¹² = 10⁶, donc

L = 10 × log(10⁶) = 10 × 6 = 60 dB

3

Lire l'échelle : multiplier l'intensité par 10 ajoute log 10 = 1, soit +10 dB seulement. Une échelle log aplatit les grands facteurs : la propriété ln(ab) = ln a + ln b transforme les multiplications en additions.

⚠️ Confondre ln et log dans les applications

Calculer le pH d'une eau neutre avec le logarithme népérien donnerait −ln(10⁻⁷) = 7 · ln 10 ≈ 16,1 : absurde (le pH va de 0 à 14). Réflexe : dès que la grandeur s'écrit en puissances de 10, c'est log ; dès qu'elle s'écrit en e^(k·t), c'est ln — et log x = ln x / ln 10 fait le pont.

Les réflexes transversaux de toute la partie

💡 Le réflexe transversal
  • Le domaine d'abord : conditions > 0, écrites avant tout, ligne séparée.
  • Le retour par l'exponentielle : x = e^t pour sortir du ln (et l'ordre conservé pour les inéquations).
  • La vérification finale : réinjecter la solution, redériver la primitive, citer la croissance comparée utilisée.
  • Le bon outil par forme : écart pour les inégalités globales, quotient pour les limites, substitution x = 1/t pour changer de point limite.

💡 La carte mentale de la partie

Tout part d'un duel : ln contre la puissance. L'écart x − ln x donne l'inégalité ln x < x ; le quotient (ln x)/x, pincé entre 0 et 2/√x, donne la limite 0 en +∞ ; la substitution x = 1/t la transporte en 0⁺ pour x · ln x. Ces objets figés servent ensuite partout : x ln x et (ln x)/x deviennent des études complètes (extremums en 1/e et e), les équations deviennent des trinômes en t = ln x, les primitives u'/u s'ouvrent jusqu'à ln(ln x), et les applications ne font que résoudre e^(kT) = seuil en appliquant ln.

Q1. Que vaut lim (ln x)/x⁵ quand x → +∞ ?

A) 0B) +∞C) 1D) 5
Voir la réponse

A) (ln x)/x⁵ = (ln x)/x × 1/x⁴ → 0 × 0 = 0 — croissance comparée généralisée (n = 5), démontrée en section 01.

Q2. L'équation (ln x)² − 3 ln x + 2 = 0 a pour solutions :

A) S = {e ; e²}B) S = {1 ; 2}C) S = {e}D) S = {2 ; 4}
Voir la réponse

A) Poser t = ln x : t² − 3t + 2 = (t − 1)(t − 2) = 0, donc t = 1 ou t = 2, et le retour par x = e^t donne x = e et x = e² (tous deux dans le domaine x > 0).

Q3. Le minimum de f(x) = x · ln x sur ]0 ; +∞[ vaut :

A) 0B) −1/eC) 1/eD) −e
Voir la réponse

B) f' = ln x + 1 s'annule en x = 1/e et f(1/e) = (1/e) × ln(1/e) = (1/e) × (−1) = −1/e — étude complète en section 04.

📌 Ce qu'il faut retenir
  • [croissances] Pour tout x > 0 : ln x ≤ x − 1 < x ; en +∞, (ln x)/x → 0 (pincement par 2/√x) ; en 0⁺, x · ln x → 0 (substitution x = 1/t)
  • [croissances] Trois gestes : écart pour les inégalités, quotient pour les limites, substitution pour changer de point limite — et toujours écrire le point limite concerné
  • [equations] ln A = ln B ⇔ A = B et ln A = k ⇔ A = e^k : domaine d'abord, regrouper, éliminer, filtrer, vérifier
  • [equations] Trinôme déguisé : poser t = ln x, résoudre en t, revenir par x = e^t — (ln x)² − 3 ln x + 2 = 0 donne S = {e ; e²}
  • [inequations] Ordre conservé (ln croissante), puis intersection avec le domaine — exemple : (ln x)² ≤ 3 ln x donne S = [1 ; e³]
  • [etudes] x · ln x : min −1/e en 1/e, zéro en 1, limite 0 en 0⁺ ; ln(x² + 1) : paire, min 0 en 0, g' = 2x/(x² + 1)
  • [primitives] ∫ u'/u = ln(u) + C (u > 0) ; (ln x)/x → (ln x)²/2 ; 1/(x · ln x) → ln(ln x) sur ]1 ; +∞[ ; redériver pour contrôler
  • [applications] T = ln 2 / k (doublement, demi-vie) ; log x = ln x / ln 10 ; pH = −log a ; dB = 10 · log(I/I₀) — une échelle log transforme les rapports en pas
