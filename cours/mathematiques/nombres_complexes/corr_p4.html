Géométrie du plan complexe

Traductions automatiques : AB = |z_B − z_A|, milieu I : z_I = (z_A + z_B)/2, angle en A : arg((z_C − z_A)/(z_B − z_A)).

✏️ Exercice 1 — Distances et milieu (★)

Rappel : z_A = 1 + 2i, z_B = 3 + 4i — AB, affixe du milieu I, puis OI.

1

a) z_B − z_A = (3 + 4i) − (1 + 2i) = 2 + 2i, donc AB = |2 + 2i| = √(4 + 4) = 2√2 (u).

2

b) z_I = (z_A + z_B)/2 = (4 + 6i)/2 = 2 + 3i.

3

c) OI = |2 + 3i| = √(4 + 9) = √13 (u).

4

Résultat : AB = 2√2 u ; z_I = 2 + 3i ; OI = √13 u.

✏️ Exercice 2 — Alignement : le test du quotient (★★)

Rappel : z_A = 1 + i, z_B = 3 + 3i, z_C = −2 − 2i — quotient et position de A sur [BC].

1

z_B − z_A = 2 + 2i et z_C − z_A = −3 − 3i = −3(1 + i).

2

Donc (z_C − z_A)/(z_B − z_A) = −3(1 + i)/(2(1 + i)) = −3/2 : un réel → les vecteurs →AB et →AC sont colinéaires → A, B, C alignés.

3

Le réel −3/2 est strictement négatif : →AC et →AB sont de sens contraires, donc A se trouve entre B et C : A ∈ [BC].

4

Résultat : A, B, C alignés, et A appartient au segment [BC].

✏️ Exercice 3 — Rectangle isocèle en B (★★)

Rappel : z_A = 1 + i, z_B = 3 + i, z_C = 3 + 3i — trois longueurs, puis nature du triangle.

1

z_B − z_A = 2 → AB = 2 ; z_C − z_B = 2i → BC = 2 ; z_C − z_A = 2 + 2i → AC = 2√2 (u).

2

AB = BC : le triangle est isocèle en B. Et AB² + BC² = 4 + 4 = 8 = (2√2)² = AC² : réciproque de Pythagore → rectangle en B.

3

Contrôle par les arguments : arg((z_C − z_B)/(z_B − z_A)) = arg(2i/2) = arg(i) = π/2 rad — angle droit en B ✔.

4

Résultat : AB = BC = 2 u, AC = 2√2 u — ABC est rectangle isocèle en B.

✏️ Exercice 4 — Rotation de centre Ω (★★)

Rappel : rotation z' = a + e^(iπ/2)(z − a) avec a = 1 + i ; image de B(3 + i).

1

a) Pour z = a : z' = a + e^(iπ/2)(a − a) = a — le centre est bien invariant ✔.

2

b) z − a = (3 + i) − (1 + i) = 2, donc z' = (1 + i) + i × 2 = 1 + 3i.

3

c) ΩB' = |1 + 3i − (1 + i)| = |2i| = 2 et ΩB = |2| = 2 ✔ — une rotation conserve les longueurs.

4

Résultat : z_B' = 1 + 3i et ΩB' = ΩB = 2 u.

AB = |z_B − z_A|  ·  z' = a + e^(iθ)(z − a) : rotation de centre a et d'angle θ
Les deux formules à retenir pour toute la géométrie du plan complexe.
✏️ Exercice 5 — Trois ensembles de points (★★★)

Rappel : décrire |z| = 3 ; |z − 1| = 2 ; |z − 2| = |z + 2i|.

1

a) OM = 3 : cercle de centre O et de rayon 3 (u).

2

b) AM = 2 avec A(1 ; 0) : cercle de centre A(1 ; 0) et de rayon 2 (u).

3

c) On élève au carré avec z = x + iy : (x − 2)² + y² = x² + (y + 2)². Développement : x² − 4x + 4 + y² = x² + y² + 4y + 4, donc −4x = 4y, soit y = −x.

4

M est équidistant de A(2 ; 0) et B(0 ; −2) : c'est la médiatrice de [AB], droite d'équation y = −x.

5

Résultat : deux cercles (O rayon 3 ; A(1 ; 0) rayon 2) et la médiatrice y = −x.

Corrigés · Thème 02 · N° 6 → 9

Racines et équations du second degré

Trois méthodes : identification pour la racine carrée, discriminant Δ pour le second degré, angles pour les racines cubiques.

✏️ Exercice 6 — Racines carrées de 5 + 12i (★★)

Rappel : z² = 5 + 12i avec z = x + iy — résoudre puis vérifier.

1

z² = (x² − y²) + 2xyi = 5 + 12i donne x² − y² = 5 et 2xy = 12. Le pont des modules ajoute : x² + y² = |5 + 12i| = √(25 + 144) = 13.

2

En sommant et soustrayant : 2x² = 18 → x = ±3 et 2y² = 8 → y = ±2. Comme xy = 6 > 0, x et y ont le même signe.

3

Vérification : (3 + 2i)² = 9 + 12i + 4i² = 5 + 12i ✔ et (−3 − 2i)² = (3 + 2i)² ✔.

4

Résultat : z = 3 + 2i ou z = −3 − 2i — deux racines opposées, comme toujours pour z² = k.

✏️ Exercice 7 — Second degré : z² − 2z + 5 = 0 (★★)

Rappel : résoudre z² − 2z + 5 = 0, puis vérifier une solution.

1

Δ = b² − 4ac = (−2)² − 4 × 1 × 5 = 4 − 20 = −16 < 0 : pas de racine réelle, mais deux racines complexes conjuguées.

2

√Δ = 4i, donc z = (2 ± 4i)/2 = 1 ± 2i.

3

Vérification avec z = 1 + 2i : (1 + 2i)² − 2(1 + 2i) + 5 = (−3 + 4i) + (−2 − 4i) + 5 = 0 ✔.

4

Résultat : z₁ = 1 + 2i et z₂ = 1 − 2i — racines conjuguées, comme l'impose a, b, c réels.

✏️ Exercice 8 — Les racines cubiques de l'unité (★★★)

Rappel : z² + z + 1 = 0, puis ω = (−1 + i√3)/2, ω³ et 1 + ω + ω².

1

a) Δ = 1 − 4 = −3, donc z = (−1 ± i√3)/2.

2

b) |ω|² = 1/4 + 3/4 = 1 → |ω| = 1 ; cos θ = −1/2 et sin θ = √3/2 → θ = 2π/3 : ω = e^(i2π/3). Alors ω³ = e^(i2π) = 1 ✔.

3

c) ω² = e^(i4π/3) = −1/2 − i√3/2, donc 1 + ω + ω² = (1 − 1/2 − 1/2) + i(√3/2 − √3/2) = 0 ✔.

4

Résultat : ω = e^(i2π/3), ω³ = 1 et 1 + ω + ω² = 0 — les trois racines cubiques de 1 sont 1, ω, ω².

✏️ Exercice 9 — Trois racines pour z³ = i (★★★)

Rappel : z³ = i — résoudre par les angles, vérifier −i et la somme des solutions.

1

a) i = e^(iπ/2) (module 1, argument π/2). Les solutions sont z_k = e^(i(π/6 + 2kπ/3)) pour k = 0, 1, 2.

2

Calculs : z₀ = e^(iπ/6) = √3/2 + (1/2)i ; z₁ = e^(i5π/6) = −√3/2 + (1/2)i ; z₂ = e^(i3π/2) = −i.

3

b) Contrôle : (−i)³ = (−i)² × (−i) = (−1)(−i) = i ✔ — et son argument 3 × (−π/2) = −3π/2 ≡ π/2 (2π près) ✔.

4

c) Somme : (√3/2 − √3/2 + 0) + i(1/2 + 1/2 − 1) = 0 ✔ — somme nulle, fidèle à l'absence de terme en z² dans z³ − i = 0.

5

Résultat : z ∈ {√3/2 + (1/2)i ; −√3/2 + (1/2)i ; −i} — trois racines, sommant à 0.

Synthèse type Bac

Les trois problèmes, rédigés comme en épreuve : chaque affirmation est prouvée, chaque longueur recalculée.

✏️ Exercice 10 — Problème : les triangles OAB et ABC (★★★)

Rappel : z_A = 2, z_B = 2i ; C image de B par la rotation de centre A d'angle π/2 ; nature des triangles.

1

a) OA = |2| = 2 et OB = |2i| = 2 : OA = OB (isocèle en O). Et arg((z_B − z_O)/(z_A − z_O)) = arg(2i/2) = arg(i) = π/2 rad : angle droit en O → OAB rectangle isocèle en O.

2

b) Rotation de centre A : z_C = z_A + e^(iπ/2)(z_B − z_A) = 2 + i(2i − 2) = 2 + 2i² − 2i = 2 − 2 − 2i = −2i ✔.

3

c) AB = |2i − 2| = √(4 + 4) = 2√2 ; AC = |−2i − 2| = √(4 + 4) = 2√2 ; BC = |−2i − 2i| = |−4i| = 4 (u).

4

Alors AB² + AC² = 8 + 8 = 16 = BC² : rectangle en B ? Non — la somme porte sur les côtés d'extrémité commune A → rectangle en A, et AB = AC → isocèle en A.

5

Résultat : OAB rectangle isocèle en O ; z_C = −2i ; ABC rectangle isocèle en A (AB = AC = 2√2 u, BC = 4 u).

✏️ Exercice 11 — L'angle triple par De Moivre (★★★)

Rappel : développer (cos θ + i sin θ)³, en déduire cos 3θ et sin 3θ.

1

a) Avec c = cos θ, s = sin θ : (c + is)³ = c³ + 3ic²s + 3c(i²s²) + i³s³ = (c³ − 3cs²) + i(3c²s − s³).

2

b) De Moivre : ce nombre vaut cos 3θ + i sin 3θ. Identification : cos 3θ = c³ − 3cs² et sin 3θ = 3c²s − s³.

3

Avec s² = 1 − c² : cos 3θ = c³ − 3c(1 − c²) = 4c³ − 3c. Avec c² = 1 − s² : sin 3θ = 3s(1 − s²) − s³ = 3s − 4s³.

4

Résultat : cos 3θ = 4cos³θ − 3cos θ et sin 3θ = 3 sin θ − 4 sin³θ.

cos 3θ = 4cos³θ − 3cos θ  ·  sin 3θ = 3 sin θ − 4 sin³θ
L'angle triple : De Moivre plus une identification, c'est tout.
✏️ Exercice 12 — Problème : z² − 4z + 8 = 0 sous toutes les formes (★★★)

Rappel : résoudre z² − 4z + 8 = 0, passer en forme exponentielle, puis somme et produit des solutions.

1

a) Δ = 16 − 32 = −16 < 0, donc √Δ = 4i et z = (4 ± 4i)/2 = 2 ± 2i.

2

b) Pour 2 + 2i : module √(4 + 4) = 2√2, argument π/4 (cos = sin = 1/√2) → z₁ = 2√2 e^(iπ/4) ; et z₂ = 2√2 e^(−iπ/4).

3

c) Somme : (2 + 2i) + (2 − 2i) = 4. Produit : (2 + 2i)(2 − 2i) = 4 + 4 = 8.

4

Contrôle avec les coefficients : −b/a = 4 ✔ et c/a = 8 ✔.

5

Résultat : z = 2 ± 2i, soit 2√2 e^(±iπ/4) — somme 4 = −b/a, produit 8 = c/a.
