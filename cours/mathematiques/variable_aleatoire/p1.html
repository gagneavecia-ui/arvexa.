📘 Partie 01 · Variable aléatoire

Définition & loi de probabilité

Tu lances deux dés : combien vaudra la somme ? Personne ne peut le prédire… et pourtant on peut calculer des probabilités exactes sur ce nombre. Toute l'idée de la variable aléatoire est là : traduire chaque résultat du hasard en un nombre, puis décrire avec une loi de probabilité comment ce nombre se répartit. Cette partie couvre 3 notions : la définition d'une variable aléatoire X et de ses événements, la loi de probabilité présentée en tableau avec la vérification Σpᵢ = 1, et la fonction de répartition F(x).

Motivation

Traduire le hasard en nombres

Le hasard est partout : le score d'un jeu de ludo, le nombre de piles obtenus en lançant une pièce, le billet gagnant d'une tombola de tontine, ou encore le nombre de pièces défectueuses dans un lot de quatre prélevées à la sortie d'un atelier de Niamey pour le contrôle qualité. Dans tous ces exemples, ce qui se produit n'est pas un nombre : c'est un résultat (« pile », « le couple (2 ; 5) », « ce sachet-ci »). Or pour calculer, comparer, décider — combien de lots accepter, quel billet « vaut » quoi — il faut des nombres.

L'outil qui fait le pont s'appelle une variable aléatoire : une fonction qui attribue à chaque résultat du hasard une valeur numérique. Une fois ce nombre construit, on décrit comment ses valeurs se répartissent grâce à une loi de probabilité, que l'on présente dans un tableau — l'objet central de cette partie. La partie 2 en tirera l'espérance (le gain moyen), la partie 3 la variance (le risque).

Les objectifs de cette partie
  • Définir une variable aléatoire X comme une application de l'univers Ω vers ℝ, et écrire les événements associés.
  • Construire et vérifier une loi de probabilité : tableau des valeurs xᵢ et des probabilités pᵢ, avec le contrôle Σpᵢ = 1.
  • Décrire brièvement la fonction de répartition F(x).
🌍 Petite histoire des sciences
En 1654, le français Blaise Pascal correspond avec Pierre de Fermat au sujet du « problème des partis » : comment partager équitablement l'enjeu d'un jeu de dés interrompu avant la fin ? En modélisant chaque partie par des nombres et des probabilités, les deux savants posent les bases du calcul des probabilités. Les variables aléatoires, elles, porteront la théorie au niveau suivant : elles permettent de calculer des moyennes et des risques — exactement ce que font aujourd'hui les assurances, les loteries et les plans de contrôle qualité.

Notion 1 · variable_aleatoire

Définir une variable aléatoire

Voici la définition officielle, celle qu'il faut savoir restituer mot pour mot à l'examen.

📗 Définition officielle — Variable aléatoire

Soit Ω l'univers d'une expérience aléatoire (l'ensemble de toutes les issues possibles). Une variable aléatoire est une application X de Ω vers l'ensemble ℝ des nombres réels : à chaque issue ω de Ω, elle associe un unique nombre réel noté X(ω). Les nombres x₁ ; x₂ ; … ; xₙ pris par X sont ses valeurs possibles.

La définition à graver dans ta mémoire
X : Ω → ℝ
Une variable aléatoire N'EST PAS un nombre : c'est une fonction qui attribue un nombre à chaque issue du hasard.

Trois exemples à bien visualiser, chacun avec son univers et ses valeurs :

  • Somme de deux dés : Ω est l'ensemble des 36 couples (d₁ ; d₂) de faces ; l'image du couple (1 ; 3) est 1 + 3 = 4. Les valeurs possibles vont de 2 à 12.
  • Deux lancers d'une pièce : Ω = {PP ; PF ; FP ; FF} ; l'image de PF est 1 (un seul pile). Les valeurs possibles sont 0 ; 1 ; 2.
  • Tombola de tontine : Ω est l'ensemble des 20 billets ; l'image du billet gagnant du grand lot est 5000 (en francs). Les valeurs possibles sont 0 ; 1000 ; 5000.
🧮 Exemple — Déterminer les valeurs possibles d'une variable
1

On lance deux fois une pièce équilibrée et on note N le nombre de piles obtenus. L'univers est Ω = {PP ; PF ; FP ; FF}.

2

On calcule les images : N(PP) = 2 ; N(PF) = N(FP) = 1 ; N(FF) = 0.

3

Conclusion : les valeurs possibles de N sont 0 ; 1 ; 2. Plusieurs issues différentes peuvent avoir la même image (PF et FP).

🎲
Univers Ω
l'ensemble de toutes les issues de l'expérience
🔍
Issue ω
un résultat élémentaire, image X(ω) = un réel
📊
Valeurs possibles
x₁ ; x₂ ; … ; xₙ : les nombres pris par X
⚠️
Plusieurs issues → une valeur
X regroupe les issues en « paniers » numérotés
Erreur fréquente au Bac

Écrire « X = 2 » tout seul comme si X était un nombre est un abus de langage sanctionné : X est une fonction. On écrit correctement : « X prend la valeur 2 », ou encore « l'événement (X = 2) ». De même, ne confonds pas l'issue ω = PF avec la valeur N(PF) = 1 : l'une est un résultat du hasard, l'autre un nombre.

Notion 1 · variable_aleatoire

Les événements (X = k) et (X ≤ k)

Définir X ne suffit pas : il faut savoir poser les événements qui la concernent, car c'est sur eux qu'on calcule les probabilités. Tout se passe comme si X découpait Ω en tranches numérotées par ses valeurs.

📗 Définition officielle — Événements liés à X

Pour tout réel k :

(X = k) est l'événement « X prend la valeur k », c'est-à-dire l'ensemble des issues ω de Ω telles que X(ω) = k. Sa probabilité se note P(X = k).

(X ≤ k) est l'événement « X prend une valeur inférieure ou égale à k » ; on définit de même (X ≥ k), (X > k), (X < k).

P(X ≤ k) + P(X > k) = 1
Les événements (X ≤ k) et (X > k) sont contraires : toute issue donne à X une valeur qui est soit ≤ k, soit > k, jamais les deux. Même idée avec (X ≥ k) et (X < k).
🧮 Exemple complet — Traduire des événements avec deux dés

On lance deux dés équilibrés et X désigne la somme des faces. Voici trois traductions, issue par issue :

1

L'événement (X = 5) : on liste les couples de somme 5 — {(1 ; 4) ; (2 ; 3) ; (3 ; 2) ; (4 ; 1)} — soit 4 issues sur 36, donc P(X = 5) = 4/36 = 1/9.

2

L'événement (X ≥ 11) : les couples de somme 11 ou 12 — {(5 ; 6) ; (6 ; 5) ; (6 ; 6)} — soit 3 issues, donc P(X ≥ 11) = 3/36 = 1/12.

3

L'événement (X ≤ 3) : les couples de somme 2 ou 3 — {(1 ; 1) ; (1 ; 2) ; (2 ; 1)} — soit 3 issues, donc P(X ≤ 3) = 3/36 = 1/12.

4

Vérification par l'événement contraire : P(X ≤ 3) + P(X > 3) = 3/36 + 33/36 = 1. Tout est cohérent.

Erreur fréquente au Bac

La somme de deux dés prend 11 valeurs (de 2 à 12), mais P(X = 7) ≠ 1/11 ! Les valeurs d'une variable aléatoire ne sont pas équiprobables en général : la somme 7 sort sur 6 issues sur 36, la somme 2 sur une seule. On ne divise jamais « par le nombre de valeurs » : on compte les issues de Ω qui réalisent l'événement.

Notion 2 · loi_probabilite

La loi de probabilité et son tableau

Connaître la loi de X, c'est connaître la liste complète de ses valeurs possibles avec la probabilité de chacune. C'est la « carte d'identité » de la variable : tout le reste (espérance, variance, lois usuelles) se calcule à partir d'elle.

📗 Définition officielle — Loi de probabilité

La loi de probabilité d'une variable aléatoire X prenant les valeurs x₁ ; x₂ ; … ; xₙ est la donnée des probabilités pᵢ = P(X = xᵢ) pour chaque i. On la présente dans un tableau : les valeurs xᵢ sur une ligne, les probabilités pᵢ sur l'autre.

La condition que TOUTE loi doit vérifier
p₁ + p₂ + … + pₙ = Σ pᵢ = 1
Les événements (X = x₁), (X = x₂), … forment une partition de Ω : exactement un d'eux se réalise. Donc la somme des pᵢ vaut P(Ω) = 1.

Premier exemple, le plus simple qui soit : un dé équilibré. On note Y le score obtenu ; chaque face a la même probabilité 1/6 :

Valeur xᵢ123456
Probabilité pᵢ1/61/61/61/61/61/6
✅ Vérification systématique — à faire CHAQUE FOIS

Σpᵢ = 1/6 + 1/6 + 1/6 + 1/6 + 1/6 + 1/6 = 6/6 = 1 ✓ — la loi est cohérente. Cette vérification vaut des points de méthode : prends le réflexe de l'écrire sous chaque tableau de loi.

Quand toutes les probabilités sont égales, on dit que la loi est uniforme. Mais le cas général est plus intéressant : que faire quand une probabilité manque dans le tableau ? On utilise Σpᵢ = 1, comme dans l'exemple suivant.

🧮 Exemple — Retrouver la probabilité manquante d'un dé truqué

Un dé pipé donne la loi suivante, où P(Y = 6) est restée en blanc :

Valeur xᵢ123456
Probabilité pᵢ0,140,140,140,140,14?
1

On additionne les probabilités connues : 0,14 × 5 = 0,70.

2

La somme totale doit valoir 1, donc : P(Y = 6) = 1 − 0,70 = 0,30.

3

Vérification : 0,70 + 0,30 = 1 ✓ — la loi est complète. (Le dé favorise clairement le 6.)

p₃ = 1 − (p₁ + p₂)  ·  plus généralement : p manquante = 1 − Σ p connues
Méthode d'examen : quand un tableau de loi contient une case vide, la compléter par 1 moins la somme des probabilités déjà connues.

Notion 2 · loi_probabilite

Exemple complet : la somme de deux dés

Voici l'exemple fil rouge du chapitre : nous le retrouverons dans les parties 2 et 3 pour calculer l'espérance puis la variance. On lance deux dés équilibrés et on note X la somme des deux faces. Construisons sa loi de probabilité, méthodiquement.

1

L'univers est l'ensemble des couples (d₁ ; d₂) : il contient 6 × 6 = 36 issues équiprobables, chacune de probabilité 1/36.

2

Les valeurs possibles de X vont de 1 + 1 = 2 à 6 + 6 = 12 : onze valeurs au total.

3

On compte les issues de somme 7 : {(1 ; 6) ; (2 ; 5) ; (3 ; 4) ; (4 ; 3) ; (5 ; 2) ; (6 ; 1)} — 6 issues, donc P(X = 7) = 6/36.

4

On fait le même comptage pour chaque valeur : les effectifs sont 1 ; 2 ; 3 ; 4 ; 5 ; 6 ; 5 ; 4 ; 3 ; 2 ; 1 (la répartition est symétrique autour de 7). Chaque probabilité est l'effectif divisé par 36.

5

D'où le tableau complet de la loi de X :

Valeur xᵢ23456789101112
Effectif12345654321
Probabilité pᵢ1/362/363/364/365/366/365/364/363/362/361/36
✅ Vérification systématique

Σpᵢ = (1 + 2 + 3 + 4 + 5 + 6 + 5 + 4 + 3 + 2 + 1)/36 = 36/36 = 1 ✓ — les onze probabilités se regroupent en 2 × (1 + 2 + 3 + 4 + 5) + 6 = 30 + 6 = 36. La loi est complète et cohérente.

Le tableau se lit comme une mine d'informations : la valeur la plus probable est 7 (avec 6/36 = 1/6), les valeurs extrêmes 2 et 12 sont les plus rares (1/36 chacune). On peut aussi calculer des probabilités d'événements composés en additionnant des colonnes :

🧮 Exemple — Lire le tableau de loi
1

P(X = 7) = 6/36 = 1/6 : c'est la probabilité maximale, lue directement dans le tableau.

2

P(X ≥ 10) = P(X = 10) + P(X = 11) + P(X = 12) = 3/36 + 2/36 + 1/36 = 6/36 = 1/6.

3

P(5 ≤ X ≤ 6) = 4/36 + 5/36 = 9/36 = 1/4 : un événement « par plage » se calcule en additionnant les colonnes concernées.

Notion 2 · loi_probabilite

Deux autres lois : piles et tombola de tontine

Construire une loi, c'est toujours le même ballet : lister les valeurs, compter ou pondérer les issues, dresser le tableau, vérifier Σpᵢ = 1. Deux exemples pour ancrer le réflexe.

A. Nombre de piles sur deux lancers d'une pièce

🧮 Exemple complet — Construire la loi de N (nombre de piles)
1

On lance deux fois une pièce équilibrée : Ω = {PP ; PF ; FP ; FF}, quatre issues équiprobables de probabilité 1/4.

2

L'événement (N = 0) ne contient que FF : P(N = 0) = 1/4.

3

L'événement (N = 1) contient PF et FP : P(N = 1) = 2/4 = 1/2. Et (N = 2) ne contient que PP : P(N = 2) = 1/4.

4

Vérification : 1/4 + 1/2 + 1/4 = 1 ✓ — la loi est cohérente.

Valeur xᵢ012
Probabilité pᵢ1/41/21/4

B. La tombola de la tontine « Solidarité »

Une tontine de Niamey organise sa tombola de fin d'année : 20 billets vendus, un seul lot de 5000 francs, trois lots de 1000 francs, les seize autres billets ne gagnent rien. On note G le gain brut d'un billet (avant déduction du prix d'achat). C'est une variable aléatoire — construisons sa loi :

1

Un billet sur 20 remporte le grand lot : P(G = 5000) = 1/20 = 0,05.

2

Trois billets remportent 1000 F : P(G = 1000) = 3/20 = 0,15.

3

Les seize billets restants ne gagnent rien : P(G = 0) = 16/20 = 0,80.

4

Vérification : 0,80 + 0,15 + 0,05 = 1 ✓ — d'où le tableau :

Gain brut xᵢ (F)010005000
Probabilité pᵢ0,800,150,05
✅ Vérification croisée par l'argent total

Les lots totalisent 5000 + 3 × 1000 = 8000 F pour 20 billets : 8000/20 = 400 F de gain brut moyen par billet. Ce nombre, c'est l'espérance de G — nous le recalculerons en partie 2, où l'on verra aussi ce que devient ce gain une fois déduite la mise (le gain net).

⚠️ Brut ou net : une différence qui change tout

Le tableau ci-dessus décrit le gain brut. Si le billet coûte 400 F, le gain net d'un billet est la nouvelle variable G − 400, qui prend les valeurs −400 ; 600 ; 4600 avec les mêmes probabilités (0,80 ; 0,15 ; 0,05). Bien préciser ce que représente la variable avant de dresser le tableau : c'est une question classique en sujet d'examen.

Notion 3 · fonction_repartition

La fonction de répartition F(x)

Le tableau donne les probabilités « par valeur ». Il existe une seconde description, cumulée : pour chaque réel x, on regarde la probabilité que X prenne une valeur au plus x. C'est la fonction de répartition — brève ici, mais tu la retrouveras plus tard avec les lois continues.

📗 Définition officielle — Fonction de répartition

La fonction de répartition d'une variable aléatoire X est la fonction F définie sur ℝ par : pour tout réel x, F(x) = P(X ≤ x). C'est la probabilité cumulée de toutes les valeurs de X inférieures ou égales à x.

F(x) = P(X ≤ x)
F est une fonction en escalier, croissante, de 0 (avant la plus petite valeur) à 1 (après la plus grande). Chaque valeur possible xᵢ fait « monter » F d'un palier de hauteur pᵢ.
🧮 Exemple complet — F pour la loi du nombre de piles

Reprenons la loi de N : P(N = 0) = 1/4, P(N = 1) = 1/2, P(N = 2) = 1/4. Calculons F en plusieurs points :

1

F(0,5) = P(N ≤ 0,5) : seule la valeur 0 convient, donc F(0,5) = P(N = 0) = 1/4.

2

F(1) = P(N ≤ 1) = P(N = 0) + P(N = 1) = 1/4 + 1/2 = 3/4 : on cumule.

3

F(1,5) = P(N ≤ 1,5) = 3/4 : aucune valeur possible entre 1 et 2, la fonction reste sur son palier.

4

F(2) = 1/4 + 1/2 + 1/4 = 1 : après la dernière valeur, toute la probabilité est cumulée. Et pour x < 0 : F(x) = 0.

Position du réel xx < 00 ≤ x < 11 ≤ x < 2x ≥ 2
F(x)01/43/41
⚠️ Cumuler, pas seulement lire

L'erreur classique : prendre F(x) pour « la probabilité de la valeur juste en dessous de x ». Non : F additionne toutes les probabilités des valeurs ≤ x. De plus, attention aux bornes : F(1) = P(N ≤ 1) inclut la valeur 1 (le signe est ≤, pas <).

Bilan

L'essentiel de la partie

Tu sais désormais transformer une expérience aléatoire en nombres et décrire ces nombres par un tableau vérifié. C'est ce tableau qui alimentera toute la suite du chapitre : l'espérance (partie 2), la variance (partie 3), puis les lois usuelles (partie 4).

La carte d'identité d'une variable aléatoire
X : Ω → ℝ  ·  loi : tableau des xᵢ et pᵢ  ·  Σpᵢ = 1  ·  F(x) = P(X ≤ x)
Définition, tableau de loi avec sa vérification, et fonction de répartition : les trois objets à connaître sur le bouton des doigts.
  • Une variable aléatoire est une application X : Ω → ℝ : à chaque issue du hasard, elle associe un nombre. On ne dit jamais « X = 2 » tout seul, mais « l'événement (X = 2) ».
  • Les événements se traduisent issue par issue : (X = k) regroupe toutes les issues dont l'image est k ; (X ≤ k) et (X > k) sont contraires.
  • La loi de probabilité est la liste complète des couples (xᵢ ; pᵢ), présentée en tableau. Les valeurs ne sont pas équiprobables en général : on compte les issues.
  • Vérification obligatoire sous chaque tableau : Σpᵢ = 1. Une case manquante se complète par 1 moins la somme des autres.
  • La fonction de répartition F(x) = P(X ≤ x) cumule les probabilités : fonction en escalier croissante de 0 à 1.
  • Fil rouge du chapitre : la loi de la somme de deux dés (2 à 12, effectifs 1 ; 2 ; 3 ; 4 ; 5 ; 6 ; 5 ; 4 ; 3 ; 2 ; 1 sur 36) — nous nous en resservirons en partie 2 !
⚠️ Réflexe rédaction pour l'examen

Toute question du type « donner la loi de X » exige trois ingrédients : la liste des valeurs possibles, une probabilité par valeur (justifiée par un comptage d'issues), et la vérification Σpᵢ = 1 écrite. Un tableau sans vérification, ou des probabilités non justifiées, perd des points.

Q1 — Deux dés équilibrés, X la somme. Que vaut P(X = 7) ?

A) 1/36B) 1/11C) 1/9D) 1/6
Voir la réponse
D) 1/6. La somme 7 est réalisée par 6 couples sur 36 : P(X = 7) = 6/36 = 1/6. (B est le piège classique : les 11 valeurs possibles ne sont pas équiprobables — on compte les ISSUES, pas les valeurs.)

Q2 — Une variable X prend les valeurs 0 ; 1 ; 2 avec P(X = 0) = 0,2 et P(X = 1) = 0,5. Que vaut P(X = 2) ?

A) 0,2B) 0,3C) 0,5D) 0,7
Voir la réponse
B) 0,3. Toute loi vérifie Σpᵢ = 1 : P(X = 2) = 1 − (0,2 + 0,5) = 1 − 0,7 = 0,3. Vérification : 0,2 + 0,5 + 0,3 = 1 ✓.

Q3 — Pour la loi du nombre de piles (pᵢ = 1/4 ; 1/2 ; 1/4 sur 0 ; 1 ; 2), que vaut F(1,5) ?

A) 0B) 1/4C) 3/4D) 1
Voir la réponse
C) 3/4. F(1,5) = P(N ≤ 1,5) = P(N = 0) + P(N = 1) = 1/4 + 1/2 = 3/4. La fonction de répartition cumule : elle reste sur son palier tant qu'aucune valeur possible n'est rencontrée.

  • [loi_probabilite] Vérification systématique : Σpᵢ = 1 ; une probabilité manquante vaut 1 moins la somme des autres
