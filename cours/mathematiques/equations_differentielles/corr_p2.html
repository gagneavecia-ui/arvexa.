Corrigés — Conditions initiales et second ordre (exercices 7 à 9)

✏️ Exercice 7 — Une condition suffit (★★)

Données : solution de y' = 3y avec y(0) = 2 ; solution de y' + y = 6 avec y(0) = 5.

1

Les solutions de y' = 3y sont y(x) = C·e^(3x). La condition donne y(0) = C·e⁰ = C = 2, donc y(x) = 2·e^(3x). Vérification : y'(x) = 6·e^(3x) = 3·y(x) ✓ et y(0) = 2 ✓.

2

y' + y = 6 s'écrit y' = −y + 6 : solutions y(x) = C·e^(−x) + 6. La condition donne y(0) = C + 6 = 5, donc C = −1 et y(x) = 6 − e^(−x).

3

Vérification : y'(x) = e^(−x) et −y(x) + 6 = −6 + e^(−x) + 6 = e^(−x) ✓ ; y(0) = 6 − 1 = 5 ✓.

y = 2·e^(3x)
y = 6 − e^(−x)
Deux équations, deux conditions initiales, deux solutions uniques.
⚠️ Piège — C peut être négatif (ici C = −1) : une condition initiale ne choisit jamais un coefficient « joli ».
✏️ Exercice 8 — Second ordre avec ω = 2 (★★)

Données : (E) : y'' + 4·y = 0, solutions proposées y(x) = A·cos(2x) + B·sin(2x), conditions y(0) = 3 et y'(0) = 4.

1

On dérive deux fois : y'(x) = −2A·sin(2x) + 2B·cos(2x) puis y''(x) = −4A·cos(2x) − 4B·sin(2x). Donc y''(x) + 4·y(x) = (−4A·cos(2x) − 4B·sin(2x)) + (4A·cos(2x) + 4B·sin(2x)) = 0 ✓ pour tous A, B.

2

y(0) = A·cos(0) + B·sin(0) = A = 3. Et y'(0) = −2A·sin(0) + 2B·cos(0) = 2B = 4, donc B = 2.

3

Solution unique : y(x) = 3·cos(2x) + 2·sin(2x). Revérification : y(0) = 3 ✓ ; y'(x) = −6·sin(2x) + 4·cos(2x) donc y'(0) = 4 ✓.

y(x) = 3·cos(2x) + 2·sin(2x)
Équation caractéristique r² + 4 = 0 : pas de racine réelle, d'où cosinus et sinus.
⚠️ Piège — Dériver sin(2x) fait sortir le facteur ω = 2 : (sin(2x))' = 2·cos(2x). C'est lui qui donne B = 2.
✏️ Exercice 9 — Second ordre, deux cas (★★★)

Données : y'' + 9·y = 0 avec y(0) = 1, y'(0) = 0 ; puis y'' + y = 0 avec y(0) = 2, y'(0) = −1.

1

Ici ω = 3 : y(x) = A·cos(3x) + B·sin(3x). y(0) = A = 1 ; y'(x) = −3A·sin(3x) + 3B·cos(3x) donc y'(0) = 3B = 0 et B = 0. Solution : y(x) = cos(3x). Vérification : y''(x) = −9·cos(3x) = −9·y(x) ✓, y(0) = 1 ✓, y'(0) = 0 ✓.

2

Ici ω = 1 : y(x) = A·cos(x) + B·sin(x). y(0) = A = 2 ; y'(0) = B = −1. Solution : y(x) = 2·cos(x) − sin(x). Vérification : y''(x) = −2·cos(x) + sin(x) = −y(x) ✓, y(0) = 2 ✓, y'(0) = −1 ✓.

y = cos(3x)
y = 2·cos(x) − sin(x)
Deux conditions initiales : l'une fixe A, l'autre fixe B.
⚠️ Piège — y'' + ω²·y = 0 ne donne jamais d'exponentielle : si un e^(3x) apparaît pour y'' + 9·y = 0, tout est à revoir.

✏️ Exercice 10 — Désintégration radioactive (★★★)

Données : N'(t) = −λ·N(t), N en milliers de noyaux, t en jours, N(8) = 108, courbe de exo_p2.html.

1

N'(t) = −λ·N(t) est de la forme y' = a·y avec a = −λ : les solutions sont N(t) = C·e^(−λ·t). Comme N(0) = N₀ > 0, on a C = N₀ > 0.

2

Lecture graphique : la courbe part du point (0 ; 800), donc N₀ = 800 (milliers de noyaux).

3

N(8) = 108 donne 800·e^(−8λ) = 108, soit e^(−8λ) = 108/800 = 0,135. Donc −8·λ = ln(0,135) ≈ −2,002 et λ ≈ 2,002/8 ≈ 0,25 par jour.

4

D'où N(t) = 800·e^(−0,25·t). Alors N(4) = 800·e^(−1) ≈ 800 × 0,3679 ≈ 294 (milliers de noyaux). Contrôle graphique : à t = 4, la courbe passe bien près de 294 ✓.

5

Demi-vie : 800·e^(−0,25·t₁/₂) = 400 donne e^(−0,25·t₁/₂) = 0,5, puis −0,25·t₁/₂ = ln(0,5) ≈ −0,693 et t₁/₂ ≈ 0,693/0,25 ≈ 2,8 jours.

N₀ = 800 · λ ≈ 0,25 j⁻¹ · N(4) ≈ 294 · t₁/₂ ≈ 2,8 jours
Modèle complet : N(t) = 800·e^(−0,25·t).
⚠️ Piège — ln(0,135) est négatif : le signe de −8·λ l'absorbe. Et la demi-vie ne dépend pas de N₀ : c'est une propriété du noyau, pas de l'échantillon.
✏️ Exercice 11 — Refroidissement d'une boisson (★★★)

Données : θ'(t) = −k·(θ(t) − 20), θ(0) = 90, θ(30) = 60, θ en °C, t en minutes.

1

Avec θ(t) = C·e^(−k·t) + 20 : θ'(t) = −k·C·e^(−k·t) et −k·(θ(t) − 20) = −k·C·e^(−k·t) ✓. C'est une équation y' = a·y + b avec a = −k, b = 20·k : la solution constante vaut −b/a = 20, la température ambiante.

2

θ(0) = C·e⁰ + 20 = C + 20 = 90, donc C = 70 et θ(t) = 70·e^(−k·t) + 20.

3

θ(30) = 70·e^(−30·k) + 20 = 60 donne e^(−30·k) = 40/70 = 4/7, puis −30·k = ln(4/7) et k = ln(7/4)/30 ≈ 0,5596/30 ≈ 0,0187 min⁻¹.

4

Avec la valeur exacte k = ln(7/4)/30 : 60·k = 2·ln(7/4) ≈ 1,119, donc θ(60) = 20 + 70·e^(−1,119) ≈ 20 + 70 × 0,3266 ≈ 20 + 22,9 ≈ 42,9 °C.

5

θ(t) = 25 donne 70·e^(−k·t) = 5, soit e^(−k·t) = 1/14, puis t = ln(14)/k ≈ 2,639/0,0187 ≈ 141 minutes, soit environ 2 h 21 min.

θ(t) = 70·e^(−k·t) + 20 · k ≈ 0,0187 min⁻¹ · θ(60) ≈ 42,9 °C · t ≈ 141 min
La température tend vers 20 °C sans jamais descendre en dessous.
⚠️ Piège — Utilisez la valeur exacte k = ln(7/4)/30 pour les questions 4 et 5 ; l'arrondi 0,0187 ne sert qu'à la fin. Arrondir trop tôt décale tous les résultats.
✏️ Exercice 12 — Second membre non constant (★★★)

Données : (E) : y' = 2·y − e^x, solution particulière proposée p(x) = e^x, condition y(0) = 3.

1

p'(x) = e^x et 2·p(x) − e^x = 2·e^x − e^x = e^x : donc p' = 2·p − e^x ✓, p est solution particulière de (E).

2

Les solutions de y' = 2·y sont y₀(x) = C·e^(2x). En ajoutant la solution particulière : y(x) = C·e^(2x) + e^x. Vérification : y'(x) = 2C·e^(2x) + e^x et 2·y(x) − e^x = 2C·e^(2x) + 2·e^x − e^x = 2C·e^(2x) + e^x = y'(x) ✓.

3

y(0) = C·e⁰ + e⁰ = C + 1 = 3, donc C = 2 et y(x) = 2·e^(2x) + e^x.

4

Vérification complète : y'(x) = 4·e^(2x) + e^x et 2·y(x) − e^x = 4·e^(2x) + 2·e^x − e^x = 4·e^(2x) + e^x = y'(x) ✓ ; y(0) = 2 + 1 = 3 ✓.

y(x) = 2·e^(2x) + e^x
Solution générale = solutions de l'équation homogène + solution particulière.
⚠️ Piège — Oublier la solution particulière e^x fausse tout : la solution générale est la somme de C·e^(2x) et de e^x. On teste toujours une solution particulière proposée par dérivation.
