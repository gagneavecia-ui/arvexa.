Accroche

Le pacte ln–exp, enfin démontré

Depuis quatre parties, tu les emploies sans relâche : résoudre e^x = 8 ? On applique ln. Simplifier e^(ln 5) ? Les fonctions s'annulent. Cette partie fait le travail inverse : elle démontre ces identités, proprement, sans cercle vicieux — puis les pousse dans leurs conséquences : équations, inéquations, duels de limites, primitives, et le monde réel de la croissance. Une seule idée porte tout : ln et exp se défont l'une l'autre.

Les deux identités du chapitre — avec leurs conditions
ln(e^x) = x  pour tout x ∈ ℝ
e^(ln x) = x  pour x > 0 seulement
Dans la première, l'entrée de ln est e^x, strictement positif pour tout réel : aucun filtre. Dans la seconde, c'est ln x qu'on veut calculer : il exige x > 0, sinon rien n'existe. Une même amitié, deux portes d'entrée.
💡 La carte mentale de la partie

La réciproque fait tout : elle démontre les identités (section 01), transfère chaque équation et inéquation d'un monde dans l'autre (section 02), tranche le duel des infinis par l'étude d'une fonction bien choisie (section 03), et chaque problème concret n'est qu'une équation où l'inconnue s'appelle t (section 05).

01
Notion 1 · ln_exp

Les deux identités, démontrées

Démonstration n°1 — ln(e^x) = x pour tout réel x, par la dérivée de la composée. On étudie la fonction auxiliaire h(x) = ln(e^x) :

1

Bien définie : e^x > 0 pour tout x, donc ln peut le recevoir : h est définie sur ℝ tout entier.

2

On dérive (composée, avec (ln u)' = u'/u et (e^x)' = e^x) :

h'(x) = (1/e^x) × e^x = 1

3

Dérivée constante 1 ⇒ h(x) = x + c pour une constante c à identifier.

4

En x = 0 : h(0) = ln(e^0) = ln 1 = 0, donc 0 = 0 + c : c = 0. Conclusion :

ln(e^x) = x pour tout x ∈ ℝ ■

Démonstration n°2 — e^(ln x) = x pour x > 0, par l'injectivité de ln. Posons y = e^(ln x) : par la démonstration n°1, ln(y) = ln x. Or x vérifie aussi ln(x) = ln x : deux nombres strictement positifs de même logarithme. Comme ln est strictement croissante (donc injective), ils sont égaux : y = x, c'est-à-dire e^(ln x) = x ■

Le raisonnement circulaire — piège de question de cours

Pour « démontrer » e^(ln x) = x, dériver la composée est un cercle vicieux : remplacer e^(ln x) par x en route, c'est utiliser l'identité qu'on prouve. Le partage des rôles : dérivée pour ln(e^x), injectivité pour e^(ln x).

🧮 Exemple — Simplifier grâce aux identités
1

A = ln(e^(−3)) + e^(ln 5)

A = −3 + 5 = 2 (ln(e^x) = x pour tout réel ; e^(ln x) = x car 5 > 0)

2

B = e^(ln 2 + 1)

B = e^(ln 2) × e^1 = 2e ≈ 5,437 (propriété maîtresse, puis identité)

3

C = 3·ln(e²) − 2·ln e

C = 3 × 2 − 2 × 1 = 4

🧮 Exemple — Les équations de référence s'ensuivent
1

Résoudre ln x = −2 : on applique exp aux deux membres :

e^(ln x) = e^(−2), donc x = e^(−2) = 1/e² ≈ 0,135 — bien strictement positif, attendu.

2

Résoudre e^x = 8 : le second membre est > 0, on applique ln :

x = ln 8 = ln 2³ = 3·ln 2 ≈ 2,079

Contrôle : e^(3·ln 2) = (e^(ln 2))³ = 2³ = 8 : vérifié.

02
Notion 2 · equations

Équations et inéquations avec exp

A. La boîte de référence des équations

e^x = a  ⇔  x = ln a  (si a > 0) ; aucune solution si a ≤ 0
e^x = e^b  ⇔  x = b  (injectivité de exp)
ln x = b  ⇔  x = e^b  (toujours : e^b > 0)
e^(kx) = a  ⇔  x = (ln a)/k  (a > 0, k ≠ 0)
e^(u(x)) = e^(v(x))  ⇔  u(x) = v(x)
Le filtre du signe d'abord : e^x > 0 toujours, donc e^x = −4 n'a aucune solution (S = ∅) avant tout calcul. Injectivité : exp ne prend jamais deux fois la même valeur, on peut égaler les exposants.
🧮 Exemple vedette — Résoudre e^(2x) − 3e^x + 2 = 0
1

Repérer le carré : e^(2x) = (e^x)². On pose X = e^x, donc X > 0 pour tout réel x — cette phrase s'écrit dès le départ.

2

Substituer : l'équation devient X² − 3X + 2 = 0.

3

Discriminant : Δ = (−3)² − 4 × 1 × 2 = 9 − 8 = 1 > 0

X₁ = (3 − 1)/2 = 1  et  X₂ = (3 + 1)/2 = 2

4

LE CONTRÔLE (celui qui rapporte les points) : X₁ = 1 > 0 et X₂ = 2 > 0 — aucune racine à rejeter ici.

5

Revenir à x (e^x = a ⇔ x = ln a car a > 0) :

e^x = 1 ⇔ x = 0  et  e^x = 2 ⇔ x = ln 2

6

Vérification par substitution : e^(2·ln 2) − 3·e^(ln 2) + 2 = 4 − 6 + 2 = 0 : vérifié.

S = {0 ; ln 2}

🧮 Exemple — Une racine rejetée : e^(2x) − e^x − 6 = 0

Avec X = e^x > 0 : X² − X − 6 = 0, discriminant Δ = 1 + 24 = 25, racines X₁ = (1 − 5)/2 = −2 et X₂ = (1 + 5)/2 = 3. Le filtre tranche : X₁ = −2 < 0 est impossible (aucun x n'a une exponentielle négative) — il n'existe aucun x tel que e^x = −2. Il reste e^x = 3 ⇔ x = ln 3 : S = {ln 3}.

🧮 Exemple — Équation-produit : e^(2x) = 3·e^x
1

Tout à gauche, factoriser :

e^(2x) − 3e^x = e^x(e^x − 3) = 0

2

Produit nul : e^x = 0 ? Jamais (e^x > 0). Donc e^x = 3 ⇔ x = ln 3 : S = {ln 3}.

Variante courte : comme e^x ≠ 0, diviser par e^x est légal et réversible : e^(2x) = 3e^x ⇔ e^x = 3.

Deux fautes qui annulent la question

(1) Garder une racine X ≤ 0 : toute racine négative ou nulle du trinôme est rejetée sans exception — « X = −2 donc x = ln(−2) » est doublement faux, ln(−2) n'existe pas. (2) Diviser par (e^x − 3) : illégal — ce facteur peut s'annuler (c'est même la solution !). On divise par e^x seul, ou on factorise.

B. Les inéquations : l'ordre est conservé

e^x > a  ⇔  x > ln a  (a > 0, sens conservé)
a ≤ 0 :  e^x > a vraie pour tout x (S = ℝ) ; e^x ≤ a jamais vraie (S = ∅)
e^x ≥ e^b  ⇔  x ≥ b
ln et exp sont strictement croissantes : appliquer l'une conserve le sens de l'inégalité, dans les deux cas. Seul retournement possible : une division par un nombre négatif en route.
🧮 Exemple — Coefficient négatif : e^(−2x) ≤ 9
1

9 > 0 : on applique ln, sens conservé :

e^(−2x) ≤ 9 ⇔ −2x ≤ ln 9

2

LE piège — division par −2, qui est négatif : le sens se retourne :

x ≥ −(ln 9)/2

3

Simplifier : ln 9 = 2·ln 3, donc x ≥ −ln 3 : S = [−ln 3 ; +∞[.

Contrôle : pour x = 0 : e^0 = 1 ≤ 9 ; pour x = −2 : e⁴ ≈ 54,6 > 9 — hors de S, cohérent.

🧮 Exemple — Exponentielles des deux côtés : e^x ≥ e^(1−2x)

L'injectivité s'applique même quand l'exposant est une expression : on égale les exposants, l'ordre étant conservé :

e^x ≥ e^(1−2x) ⇔ x ≥ 1 − 2x ⇔ 3x ≥ 1 ⇔ x ≥ 1/3

Donc S = [1/3 ; +∞[. Contrôle : pour x = 0 < 1/3 : e^0 = 1 < e¹ ≈ 2,718 — cohérent.

⚠️ Les deux réflexes d'inéquation

Avant toute application du ln : regarde le signe du second membre (e^x > −1 est vraie pour tout réel, S = ℝ ; e^x ≤ −1 pour aucun, S = ∅). Et à chaque division par un négatif : le sens se retourne — vérifie-le deux fois. On conclut par un intervalle, jamais par des valeurs isolées.

Notion 3 · etudes

Le duel e^x/x et les fonctions vedettes

« e^x → +∞ » et « x → +∞ » se disputent le quotient e^x/x : forme indéterminée « +∞/+∞ » que les quatre opérations ne lèvent pas. La stratégie : figer le duel dans une fonction, l'étudier complètement, et lire le verdict sur son tableau.

🧮 Étude complète — f(x) = e^x/x sur ℝ*
1

Domaine : le dénominateur s'annule en 0 : f est définie sur ℝ* (les réels non nuls).

2

Dérivée (quotient : (u/v)' = (u'v − uv')/v² avec u = e^x, v = x) :

f'(x) = (e^x·x − e^x·1)/x² = (e^x(x − 1))/x²

3

Signe : e^x > 0 et x² > 0 sur ℝ* : le signe de f' est celui de (x − 1). f décroît sur ]0 ; 1[, croît sur ]1 ; +∞[.

4

Minimum sur ]0 ; +∞[ : atteint en x = 1, valant f(1) = e ≈ 2,718.

5

Limites : en 0⁺ : f → +∞ (asymptote verticale x = 0) ; en 0⁻ : f → −∞ ; en −∞ : forme « 0/(−∞) », direct : f → 0 par valeurs négatives.

6

Contrôles du minimum : f(0,5) ≈ 3,30, f(2) ≈ 3,69, f(5) ≈ 29,7 — toujours ≥ e. Et f(10) ≈ 2202,6 : après x = 1, la fonction ne redescend jamais sous e.

x−∞ … 0⁻0⁺ … 111 … +∞
f'(x)< 0< 00> 0
f(x)0 → −∞+∞ ↘e (min)↗ +∞

La démonstration tient en trois coups : (1) le minimum dit que e^x ≥ e·x pour tout x ≥ 1 ; (2) le levier — l'inégalité appliquée à x/2 puis élevée au carré — donne e^x ≥ (e²/4)·x² pour x ≥ 2 ; (3) en divisant par x, e^x/x ≥ (e²/4)·x → +∞ par comparaison.

lim(x→+∞) e^x/xⁿ = +∞  (n ≥ 1) — « l'exponentielle l'emporte »
lim(x→+∞) xⁿ·e^(−x) = 0  (n ≥ 1) — « l'exponentielle absorbe »
lim(x→−∞) x·e^x = 0   ;  lim(x→−∞) e^x = 0
Rédaction attendue : nommer l'outil — « d'après les croissances comparées, … ». Le résultat seul, sans le nom, perd la moitié des points de méthode. Et respecte la direction : e^x/x → +∞ en +∞ seulement (en −∞, c'est 0/(−∞) = 0, direct).

A. Étude vedette n°1 : f(x) = x·e^x

🧮 Étude complète — f(x) = x·e^x
1

Dérivée factorisée : f'(x) = 1·e^x + x·e^x = (x + 1)·e^x

2

Signe : e^x > 0 toujours ⇒ signe de (x + 1) : négatif avant −1, positif après.

3

Minimum en x = −1 : f(−1) = −1/e ≈ −0,368.

4

Limites : en +∞ : +∞ (produit de deux +∞) ; en −∞ : forme « −∞ × 0 » → d'après les croissances comparées, x·e^x → 0⁻ : asymptote y = 0 rejointe par valeurs négatives.

5

Zéro et signe : f(x) = 0 ⇔ x = 0 (car e^x ≠ 0) ; f < 0 sur ]−∞ ; 0[, f > 0 après. Bonus : tangente horizontale y = −1/e au minimum.

B. Étude vedette n°2 : g(x) = x²·e^x

🧮 Étude complète — g(x) = x²·e^x (le zéro double)
1

Dérivée factorisée : g'(x) = 2x·e^x + x²·e^x = x(x + 2)·e^x

2

Signe : racines −2 et 0 : g' > 0 sur ]−∞ ; −2[, g' < 0 sur ]−2 ; 0[, g' > 0 sur ]0 ; +∞[.

3

Extremums : maximum local g(−2) = 4/e² ≈ 0,541 ; minimum g(0) = 0 — global, car x² ≥ 0 et e^x > 0 donnent g(x) ≥ 0 pour tout x.

4

Le zéro double : g(x) = 0 ⇔ x² = 0 : zéro double en 0 — tangente horizontale, la courbe rebondit sur l'axe sans jamais passer dessous. Limites : 0 (par valeurs positives) en −∞, +∞ en +∞.

Erreur fréquente au Bac

Le minimum de x·e^x vaut −1/e ≈ −0,37, atteint en l'abscisse x = −1. Trois confusions sanctionnées : écrire « le minimum est −e ≈ −2,718 » (−1/e est l'inverse de e, pas son opposé), « le minimum est −1 » (c'est l'abscisse), ou le placer en x = 1. Rédaction saine : « minimum en x = −1, il vaut −1/e ».

Notion 4 · primitives

Primitives u'·e^u en profondeur

La règle (e^u)' = u'·e^u, lue de droite à gauche, intègre d'un trait toute expression dont le facteur devant l'exponentielle est la dérivée de l'exposant. La table de reconnaissance :

u'·e^u (forme exacte)  →  e^u + c
λ·u'·e^u (facteur constant)  →  λ·e^u + c
e^(kx+b) (exposant affine)  →  (1/k)·e^(kx+b) + c  (k ≠ 0)
Dans tous les cas, la vérification finale est la même : dériver la primitive proposée et retrouver l'intégrande — la ligne « on vérifie : F'(x) = … = f(x) » est notée par le correcteur.
🧮 Exemple 1 — Facteur constant à ajuster : 4x·e^(x²+3)
1

Exposant et sa dérivée : u(x) = x² + 3, donc u'(x) = 2x.

2

Comparer : le facteur présent est 4x = 2 × (2x) : le double de u'.

4x·e^(x²+3) = 2·u'(x)·e^(u(x))

3

Primitive : F(x) = 2·e^(x²+3). Vérification : F'(x) = 2 × 2x·e^(x²+3) = 4x·e^(x²+3) : vérifié.

🧮 Exemple 2 — Forme composée : e^x·(e^x + 1)²

Ici l'exposant à considérer est toute une expression : la dérivée de (e^x + 1)³ vaut 3·e^x·(e^x + 1)². Le facteur présent vaut donc un tiers de cette dérivée, et une primitive est :

F(x) = (1/3)·(e^x + 1)³

Vérification : F'(x) = (1/3) × 3(e^x + 1)² × e^x = e^x(e^x + 1)² : vérifié.

Formule reine — la forme x·e^x déborde du cadre u'·e^u
une primitive de x·e^x est (x − 1)·e^x
Dans x·e^x, l'exposant est u = x donc u' = 1 : aucun ajustement constant ne marchera. On isole x·e^x dans la dérivée du produit (x·e^x)' = e^x + x·e^x, puis on intègre : x·e^x = (x·e^x)' − e^x → primitive (x − 1)·e^x. C'est l'intégration par parties, annoncée.
🧮 Exemple 3 — Par identification : une primitive de x·e^(2x)
1

Forme candidate : la dérivée de (ax + b)·e^(2x) vaut (2ax + a + 2b)·e^(2x).

2

Identifier avec x·e^(2x) : 2a = 1 et a + 2b = 0, donc a = 1/2, b = −1/4.

3

Conclure : F(x) = (x/2 − 1/4)·e^(2x).

Vérification : F'(x) = (1/2 + x − 1/2)·e^(2x) = x·e^(2x) : vérifié.

une primitive de x·e^(ax) est (x/a − 1/a²)·e^(ax)
Cas a = 1 : (x − 1)·e^x. Cas a = −1 : −(x + 1)·e^(x). Le signe de a compte : pour x·e^(−x), oublier le moins donnerait la primitive de −x·e^(−x).
Erreur fréquente au Bac

(1/2)·e^(x²) est la primitive de x·e^(x²), pas celle de x·e^x : les deux intégrandes diffèrent d'un seul exposant, mais la dérivée de contrôle le crie — ((1/2)e^(x²))' = x·e^(x²) ≠ x·e^x. L'exposant de la primitive candidate doit être exactement celui de l'intégrande.

Notion 5 · applications

Modèles de croissance et grande table de synthèse

Intérêts composés, démographie, radioactivité : un unique modèle — une quantité multipliée par un facteur constant par unité de temps, qui en continu donne l'exponentielle. La réciproque ln transforme chaque question concrète (« quand double-t-il ? », « quand ne reste-t-il que 10 % ? ») en équation résoluble.

Le modèle de croissance exponentielle
N(t) = N₀·e^(kt)
N₀ = N(0) est la valeur initiale ; le taux k décide de tout : k > 0 → croissance, k < 0 → décroissance (on écrit alors k = −λ avec λ > 0). Modèle discret parallèle : Cₙ = C₀·(1 + t)ⁿ par périodes, C(t) = C₀·e^(rt) en continu.
temps de doublement = ln 2 / k   (croissance, k > 0)
demi-vie = ln 2 / λ   (décroissance, λ > 0)
lecture inverse : λ = ln 2 / (demi-vie)
Démonstration : N₀·e^(kt) = 2N₀ ⇔ e^(kt) = 2 ⇔ kt = ln 2 ⇔ t = ln 2/k. Le résultat ne dépend pas de N₀ : une population de 1 million et une de 50 millions doublent en même temps — la signature des phénomènes exponentiels. Le même ln 2 ≈ 0,693 des deux côtés : doubler et moitier sont le même événement vu dans deux sens.
🧮 Application 1 — Intérêts composés : 10 000 F à 5 % par an
1

Mettre en équation : Cₙ = C₀·1,05ⁿ ; doubler : 1,05ⁿ ≥ 2.

2

Appliquer ln (croissante, 2 > 0, sens conservé) :

n·ln 1,05 ≥ ln 2, donc n ≥ ln 2 / ln 1,05 ≈ 14,2

3

Arrondir à l'entier supérieur (des années entières) : contrôles 1,05¹⁴ ≈ 1,98 < 2 mais 1,05¹⁵ ≈ 2,08 ≥ 2.

Le capital double au bout de 15 années — pas 14.

🧮 Application 2 — Population : N₀ = 2 millions, k = 0,03 par an

N(10) = 2·e^(0,03×10) = 2·e^0,3 ≈ 2 × 1,3499 ≈ 2,70 millions : environ +35 % en 10 ans. Et le doublement : t = ln 2 / 0,03 ≈ 23,1 ans — le rythme s'accélère, c'est l'exponentielle.

🧮 Application 3 — Demi-vie du césium 137 : 30 ans

Lecture inverse : λ = ln 2 / 30 ≈ 0,0231 par an. Pour qu'il ne reste que 10 % : e^(−λt) = 0,1 ⇔ t = ln 10 / λ ≈ 2,303 / 0,0231 ≈ 99,7 ans — environ 100 ans. Contrôle par les demi-vies : ln 10 / ln 2 ≈ 3,32 demi-vies, et (1/2)^3,32 ≈ 0,1 : vérifié.

C. Réflexes Bac de la partie

  • Compter les exponentielles d'une équation : une seule → isoler, filtrer le signe, appliquer ln ; plusieurs → factoriser par e^x ou poser X = e^x.
  • Tout changement de variable porte sa condition : « X = e^x, donc X > 0 », et le contrôle ligne par ligne des racines.
  • Toute levée d'indétermination est nommée : « d'après les croissances comparées… » — le nom vaut la moitié des points.
  • Toute primitive est vérifiée en dérivant : « on vérifie : F'(x) = … = f(x) ».
  • Toute application de ln est précédée de son hypothèse : « comme a > 0, on applique ln, strictement croissante ».
  • Tout problème concret se termine par une phrase : unité, arrondi correct (entier supérieur si l'on atteint un seuil par pas entiers), interprétation.

Une seule idée porte le chapitre entier : la réciproque. ln et exp se défont l'une l'autre (section 01, démontré), donc toute équation se transfère d'un monde dans l'autre (section 02), toute inéquation suit en gardant l'ordre, le duel des infinis se tranche par l'étude d'une fonction bien choisie (section 03), les primitives en découlent (section 04), et les applications ne sont que ces équations où l'inconnue s'appelle t (cette section).

1. Que vaut e^(ln 3) + ln(e²) ?

A) 5B) 3e²C) ln 5D) e⁵
Voir la réponse

A) e^(ln 3) = 3 (car 3 > 0) et ln(e²) = 2 : total 3 + 2 = 5. Les deux identités s'appliquent chacune dans son domaine.

2. Le minimum de f(x) = x·e^x est :

A) −e, atteint en −1B) −1/e, atteint en −1C) 0D) −1/e, atteint en 1
Voir la réponse

B) f'(x) = (x + 1)·e^x, nul en −1 ; f décroît puis croît : minimum f(−1) = −1/e ≈ −0,37. Attention aux deux pièges : la valeur est −1/e (pas −e), l'abscisse est −1 (pas 1).

3. lim(x→+∞) x³·e^(−x) = ?

A) +∞B) 1C) 0D) forme indéterminée sans outil
Voir la réponse

C) x³·e^(−x) = x³/e^x : d'après les croissances comparées, l'exponentielle absorbe toute puissance — la limite vaut 0. Et on nomme l'outil sur la copie !

📌 Ce qu'il faut retenir
  • [ln_exp] ln(e^x) = x pour tout réel x (démontrée par la dérivée) ; e^(ln x) = x pour x > 0 (démontrée par l'injectivité — jamais par dérivation : cercle vicieux)
  • [equations] e^x = a ⇔ x = ln a si a > 0, S = ∅ si a ≤ 0 ; e^(2x) et e^x ensemble → X = e^x, contrôle X > 0, retour x = ln X
  • [equations] Diviser par e^x est légal (e^x ≠ 0) ; par (e^x − a), jamais sans discussion
  • [equations] Inéquations : e^x > a ⇔ x > ln a (a > 0), sens conservé — sauf division par un négatif ; a ≤ 0 : S = ℝ ou ∅ avant tout calcul
  • [etudes] Le duel : e^x/x → +∞ en +∞, démontré par le minimum e en x = 1 et le levier e^x ≥ (e²/4)·x² ; xⁿ·e^(−x) → 0 — toujours nommer les croissances comparées
  • [etudes] x·e^x : min −1/e en −1 ; x²·e^x : max 4/e² en −2, zéro double en 0 (rebond)
  • [primitives] u'·e^u → e^u + c ; e^(kx+b) → (1/k)e^(kx+b) + c ; x·e^(ax) → (x/a − 1/a²)·e^(ax) — et toujours vérifier en dérivant
  • [applications] N(t) = N₀·e^(kt) ; temps de doublement ln 2/k, demi-vie ln 2/λ, lecture inverse λ = ln 2/(demi-vie) — indépendants de N₀
  • [applications] Intérêts composés : Cₙ = C₀(1 + t)ⁿ par périodes, C₀·e^(rt) en continu ; arrondir au seuil atteint (15 ans, pas 14,2)
