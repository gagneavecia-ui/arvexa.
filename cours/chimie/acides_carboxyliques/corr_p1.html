Masses molaires, solutions et dosage

✏️ Exercice 1 — L'acide du vinaigre (★)

Données : CH₃—COOH ; m = 12,0 g ; H = 1, C = 12, O = 16 g·mol⁻¹.

1

Compter les atomes : 2 C, 4 H (3 dans CH₃ et 1 dans OH), 2 O. Donc M = 2×12 + 4×1 + 2×16 = 24 + 4 + 32 = 60 g·mol⁻¹.

2

Masses des éléments dans une mole : m(C) = 24 g, m(H) = 4 g, m(O) = 32 g. D'où %C = 24/60 × 100 = 40 % ; %H = 4/60 × 100 ≈ 6,7 % ; %O = 32/60 × 100 ≈ 53,3 %. Somme : 40 + 6,7 + 53,3 = 100 % ✓.

3

Quantité de matière : n = m/M = 12,0/60 = 0,20 mol.

M(CH₃—COOH) = 60 g·mol⁻¹ ; n = 0,20 mol

Composition massique : 40 % de carbone, ≈ 6,7 % d'hydrogène, ≈ 53,3 % d'oxygène.

⚠️ Piège : l'acide éthanoïque contient 4 hydrogènes et non 3 : n'oublie pas celui du groupe —OH.
✏️ Exercice 2 — La série des acides saturés (★)

Données : formule brute CₙH₂ₙO₂ ; l'acide cherché a M = 88 g·mol⁻¹.

1

Acide méthanoïque : 1 C, 2 H, 2 O → M = 1×12 + 2×1 + 2×16 = 12 + 2 + 32 = 46 g·mol⁻¹.

2

Acide propanoïque : 3 C, 6 H, 2 O → M = 3×12 + 6×1 + 2×16 = 36 + 6 + 32 = 74 g·mol⁻¹.

3

Masse molaire de la série : M = 12n + 2n + 32 = 14n + 32. Donc 14n + 32 = 88, soit 14n = 56 et n = 4. Formule brute C₄H₈O₂ ; vérification : 48 + 8 + 32 = 88 g·mol⁻¹ ✓.

C₄H₈O₂ : CH₃—CH₂—CH₂—COOH, acide butanoïque

C'est l'acide du beurre rance : M = 88 g·mol⁻¹.

⚠️ Piège : dans CₙH₂ₙO₂, n compte tous les carbones (4 ici) ; dans CₙH₂ₙ₊₁—COOH, il ne compte que ceux du groupe alkyle (3 ici). Ne mélange pas les deux écritures.
✏️ Exercice 3 — Dosage du vinaigre (★★)

Données : VA = 20,0 mL ; CB = 0,50 mol·L⁻¹ ; VE = 16,0 mL ; M = 60 g·mol⁻¹.

1

Réaction de dosage (totale) : CH₃—COOH + OH⁻ → CH₃—COO⁻ + H₂O, soit avec la soude : CH₃—COOH + NaOH → CH₃—COO⁻Na⁺ + H₂O.

2

À l'équivalence, les réactifs ont été mélangés dans les proportions stœchiométriques : n(acide) = n(OH⁻) versé = CB × VE = 0,50 × 16,0×10⁻³ = 8,0×10⁻³ mol.

3

Concentration du vinaigre : CA = n/VA = 8,0×10⁻³ / 20,0×10⁻³ = 0,40 mol·L⁻¹.

4

Concentration massique : Cm = CA × M = 0,40 × 60 = 24 g·L⁻¹.

CA = 0,40 mol·L⁻¹ soit Cm = 24 g·L⁻¹ d'acide éthanoïque

Ordre de grandeur réaliste pour un vinaigre commercial.

⚠️ Piège : convertis les volumes en litres AVANT tout calcul : 16,0 mL = 16,0×10⁻³ L.

Estérification et sels de sodium

✏️ Exercice 4 — Quatre esters à l'atelier (★★)

Données : schéma général R—COOH + R′—OH ⇌ R—COO—R′ + H₂O ; le groupe alkyle R′ vient de l'alcool.

1

Acide éthanoïque + éthanol : CH₃—COOH + C₂H₅—OH ⇌ CH₃—COO—C₂H₅ + H₂O → éthanoate d'éthyle.

2

Acide méthanoïque + méthanol : H—COOH + CH₃—OH ⇌ H—COO—CH₃ + H₂O → méthanoate de méthyle.

3

Acide propanoïque + éthanol : CH₃—CH₂—COOH + C₂H₅—OH ⇌ CH₃—CH₂—COO—C₂H₅ + H₂O → propanoate d'éthyle. Acide butanoïque + méthanol : CH₃—CH₂—CH₂—COOH + CH₃—OH ⇌ CH₃—CH₂—CH₂—COO—CH₃ + H₂O → butanoate de méthyle.

4

Vérification atome par atome (équation 1) : C : 2 + 2 = 4 de part et d'autre ✓ ; H : 4 + 6 = 10 à gauche, 8 + 2 = 10 à droite ✓ ; O : 2 + 1 = 3 à gauche, 2 + 1 = 3 à droite ✓.

Nom d'un ester : « …oate de …yle »

La partie « …oate » vient de l'acide (éthanoate, méthanoate, propanoate, butanoate) ; la partie « …yle » vient de l'alcool (méthyle, éthyle).

⚠️ Piège : ne retourne jamais le nom : c'est « éthanoate d'éthyle », pas « éthyle d'éthanoate ». L'ordre acide → alcool est imposé.
✏️ Exercice 5 — Contrôle de cohérence : l'éthanoate d'éthyle (★★)

Données : M(acide) = 60, M(alcool) = 46, M(eau) = 18 g·mol⁻¹ ; mélange de 6,0 g d'acide et 4,6 g d'alcool.

1

L'ester CH₃—COO—C₂H₅ a pour formule brute C₄H₈O₂ : M = 4×12 + 8×1 + 2×16 = 48 + 8 + 32 = 88 g·mol⁻¹.

2

Cohérence : M(acide) + M(alcool) = 60 + 46 = 106 g·mol⁻¹ et M(ester) + M(eau) = 88 + 18 = 106 g·mol⁻¹. L'égalité traduit la conservation de la matière : 1 mole d'acide et 1 mole d'alcool donnent 1 mole d'ester et 1 mole d'eau, sans perte d'atomes.

3

Quantités initiales : n(acide) = 6,0/60 = 0,10 mol et n(alcool) = 4,6/46 = 0,10 mol : mélange équimolaire. Si la réaction était totale : n(ester) = 0,10 mol, soit m = 0,10 × 88 = 8,8 g.

M(ester) = 88 g·mol⁻¹ ; masse maximale théorique : 8,8 g

La vérification 60 + 46 = 88 + 18 doit devenir un réflexe de contrôle.

Figure — L'éthanoate d'éthyle : la partie gauche (rouge) vient de l'acide, la partie droite de l'alcool.
⚠️ Piège : en réalité la réaction est limitée : avec le rendement r ≈ 67 % du cours, la masse réelle d'ester serait 0,67 × 8,8 ≈ 5,9 g. La partie 2 détaille ce calcul.
✏️ Exercice 6 — Lire une formule développée (★★★)

Données : figure de l'acide éthanoïque (2 C, 4 H, 2 O) ; soude NaOH.

1

Le carbone fonctionnel porte une double liaison C=O et un groupe OH : c'est le groupe carboxyle, de formule générale —COOH, caractéristique des acides carboxyliques R—COOH.

2

Comptage sur la figure : 2 C, 4 H (3 sur le premier C, 1 sur l'oxygène), 2 O → formule brute C₂H₄O₂. Masse molaire : M = 2×12 + 4×1 + 2×16 = 60 g·mol⁻¹, conforme à l'exercice 1.

3

Réaction avec la soude : CH₃—COOH + NaOH → CH₃—COO⁻Na⁺ + H₂O. Vérification : C : 2 = 2 ✓ ; H : 4 + 1 = 5 à gauche, 3 + 2 = 5 à droite ✓ ; O : 2 + 1 = 3 de part et d'autre ✓ ; Na : 1 = 1 ✓. Le produit organique est l'éthanoate de sodium, sel de sodium de l'acide : il a bien la forme R—COO⁻Na⁺ avec R = CH₃.

CH₃—COOH + NaOH → CH₃—COO⁻Na⁺ + H₂O

L'éthanoate de sodium est le « savon modèle » ; les savons véritables ont une longue chaîne R.

⚠️ Piège : écrire « CH₃—COONa » est toléré, mais la forme ionique CH₃—COO⁻Na⁺ montre mieux la structure : c'est elle qu'il faut savoir dessiner pour le savon.
