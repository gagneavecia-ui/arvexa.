Études type Bac du régime transitoire

✏️ Exercice 1 — Étude complète d'un circuit R-L (★★)

Données : E = 6,0 V ; R = 20 Ω ; L = 0,40 H ; i(τ) ≈ 0,63·Iₘₐₓ ; i(3τ) ≈ 0,95·Iₘₐₓ.

1

Constante de temps : τ = L/R = 0,40/20 = 0,020 s = 20 ms. Le régime permanent est atteint vers 5τ = 0,10 s.

2

Intensité maximale : Iₘₐₓ = E/R = 6,0/20 = 0,30 A.

3

Intensités : i(τ) = 0,63×0,30 = 0,19 A ; i(3τ) = 0,95×0,30 = 0,29 A.

4

Tension aux bornes de R à t = τ : u_R(τ) = R·i(τ) = 20×0,19 = 3,8 V.

5

Loi des mailles : u_b = E − u_R. À t = 0, i(0) = 0 donc u_R(0) = 0 et u_b(0) = E = 6,0 V ; en régime permanent, di/dt = 0 (r négligeable) donc u_b = 0 V.

6

Énergie stockée : Eₘ = ½·L·Iₘₐₓ² = 0,5×0,40×(0,30)² = 0,5×0,40×0,090 = 1,8×10⁻² J = 18 mJ.

τ = 20 ms ; Iₘₐₓ = 0,30 A ; u_R(τ) = 3,8 V ; u_b(0) = 6,0 V ; Eₘ = 18 mJ

La tension de la bobine chute de E à 0 pendant que i monte de 0 à Iₘₐₓ.

⚠️ Piège : u_R(τ) se calcule avec i(τ) = 0,19 A, et non avec Iₘₐₓ. Et à t = 0, c'est la bobine qui prend TOUTE la tension du générateur.

✏️ Exercice 2 — Décharge de la bobine (★★)

Données : I₀ = 2,0 A ; L = 0,50 H ; R' = 5,0 Ω ; i(τ') ≈ 0,37·I₀.

1

La bobine s'oppose à la disparition du courant (auto-induction) : elle produit une f.é.m. qui entretient le courant pendant qu'il décroît → i passe continûment de I₀ à 0, sans discontinuité.

2

Nouvelle constante de temps : τ' = L/R' = 0,50/5,0 = 0,10 s.

3

À t = τ' : i(τ') = 0,37×I₀ = 0,37×2,0 = 0,74 A.

4

Énergie initiale : Eₘ = ½·L·I₀² = 0,5×0,50×(2,0)² = 0,5×0,50×4,0 = 1,0 J : elle est entièrement dissipée par effet Joule dans R' pendant la décharge.

τ' = 0,10 s ; i(τ') = 0,74 A ; Eₘ = 1,0 J dissipée dans R'

À la décharge, le courant a perdu 63 % de sa valeur au bout de τ'.

⚠️ Piège : à la décharge, i(τ') = 0,37·I₀ (et non 0,63) : la courbe DÉCROÎT, il ne reste que 37 % du courant initial après une durée τ'.

✏️ Exercice 3 — Exploiter un enregistrement u_R(t) (★★★)

Données : R = 15 Ω ; U_Rmax = 7,5 V ; τ = 2,0 ms ; i(τ) ≈ 0,63·Iₘₐₓ ; i(3τ) ≈ 0,95·Iₘₐₓ.

1

D'après la loi d'Ohm, u_R = R·i : la tension enregistrée a exactement la même évolution que i. On lit donc Iₘₐₓ = U_Rmax/R = 7,5/15 = 0,50 A.

2

En régime permanent, la bobine (r négligeable) est un fil : E = U_Rmax = 7,5 V.

3

Inductance : L = τ·R = 2,0×10⁻³×15 = 3,0×10⁻² H = 30 mH.

4

Tensions : u_R(τ) = 0,63×7,5 = 4,7 V ; u_R(3τ) = 0,95×7,5 = 7,1 V.

5

Énergie stockée : Eₘ = ½·L·Iₘₐₓ² = 0,5×3,0×10⁻²×(0,50)² = 0,5×3,0×10⁻²×0,25 = 3,8×10⁻³ J = 3,8 mJ.

Iₘₐₓ = 0,50 A ; E = 7,5 V ; L = 30 mH ; u_R(τ) = 4,7 V ; Eₘ = 3,8 mJ

u_R est l'image fidèle de i : on lit tout sur son enregistrement.

⚠️ Piège : τ = 2,0 ms doit être converti en 2,0×10⁻³ s AVANT L = τ·R. Justifier chaque lecture : « l'asymptote donne U_Rmax », « la tangente à l'origine coupe l'asymptote à t = τ ».

Bobine réelle, décharge et bilans d'énergie

✏️ Exercice 4 — Bobine réelle : étude type Bac (★★★)

Données : L = 0,10 H ; r = 2,0 Ω ; R = 8,0 Ω ; E = 4,0 V ; u_b = r·i + L·di/dt.

1

Résistance totale : R + r = 8,0 + 2,0 = 10 Ω ; constante de temps : τ = L/(R + r) = 0,10/10 = 0,010 s = 10 ms.

2

En régime permanent, di/dt = 0 : Iₘₐₓ = E/(R + r) = 4,0/10 = 0,40 A.

3

À t = 0 : i(0) = 0 donc r·i = 0, mais le courant va croître → L·di/dt = E, d'où u_b(0) = E = 4,0 V. En régime permanent : di/dt = 0, donc u_b(∞) = r·Iₘₐₓ = 2,0×0,40 = 0,80 V.

4

Énergie stockée : Eₘ = ½·L·Iₘₐₓ² = 0,5×0,10×(0,40)² = 0,5×0,10×0,16 = 8,0×10⁻³ J = 8,0 mJ.

τ = 10 ms ; Iₘₐₓ = 0,40 A ; u_b(0) = 4,0 V ; u_b(∞) = 0,80 V ; Eₘ = 8,0 mJ

La tension de la bobine réelle ne s'annule pas : il reste r·Iₘₐₓ.

⚠️ Piège : en régime permanent, une bobine réelle se comporte comme un simple résistor de résistance r — sa tension ne vaut PAS zéro (0,80 V ici).

✏️ Exercice 5 — Étincelle et sécurité (★★)

Données : L = 0,30 H ; I₀ = 0,50 A ; ouverture en 0,10 ms.

1

Énergie stockée : Eₘ = ½·L·I₀² = 0,5×0,30×(0,50)² = 0,5×0,30×0,25 = 3,75×10⁻² ≈ 3,8×10⁻² J.

2

Vitesse moyenne de variation : |Δi/Δt| ≈ I₀/Δt = 0,50/1,0×10⁻⁴ = 5,0×10³ A·s⁻¹.

3

Surtension : e ≈ L·|Δi/Δt| = 0,30×5,0×10³ = 1,5×10³ V : ces quelques milliers de volts ionisent l'air entre les contacts → l'énergie stockée part dans l'arc : c'est l'étincelle.

4

Puissance moyenne : P = Eₘ/Δt = 3,75×10⁻²/1,0×10⁻⁴ = 375 W. Protections possibles : diode de roue libre en parallèle de la bobine, condensateur aux contacts, ouverture lente du circuit.

e ≈ 1,5×10³ V ; P ≈ 375 W pendant 0,10 ms

Une ouverture rapide transforme la bobine en générateur de surtension.

⚠️ Piège : la surtension se calcule avec la DURÉE D'OUVERTURE (0,10 ms), pas avec la constante de temps. Convertir 0,10 ms = 1,0×10⁻⁴ s.

✏️ Exercice 6 — Synthèse générale : bilan d'énergie (★★★)

Données : E = 10 V ; R = 4,0 Ω ; L = 0,25 H ; r = 1,0 Ω ; i(τ) ≈ 0,63·Iₘₐₓ ; Q = Iₘₐₓ·τ.

1

Résistance totale : R + r = 4,0 + 1,0 = 5,0 Ω ; constante de temps : τ = L/(R + r) = 0,25/5,0 = 0,050 s.

2

Intensités : Iₘₐₓ = E/(R + r) = 10/5,0 = 2,0 A ; i(τ) = 0,63×2,0 = 1,26 ≈ 1,3 A.

3

À t = τ : u_R(τ) = R·i(τ) = 4,0×1,26 = 5,0 V ; loi des mailles : u_b(τ) = E − u_R(τ) = 10 − 5,0 = 5,0 V.

4

Bornes de la variation : u_b(0) = E = 10 V (car i(0) = 0 et L·di/dt(0) = E) ; u_b(∞) = r·Iₘₐₓ = 1,0×2,0 = 2,0 V.

5

Énergie stockée : Eₘ = ½·L·Iₘₐₓ² = 0,5×0,25×(2,0)² = 0,5×0,25×4,0 = 0,50 J.

6

Charge circulant pendant l'établissement : Q = Iₘₐₓ·τ = 2,0×0,050 = 0,10 C ; énergie fournie : W = E·Q = 10×0,10 = 1,0 J. Bilan : 0,50 J stockés dans la bobine + 0,50 J dissipés par effet Joule dans R et r : exactement la moitié de chaque.

τ = 0,050 s ; Iₘₐₓ = 2,0 A ; Eₘ = 0,50 J ; W = 1,0 J = 2×Eₘ

Résultat classique : la moitié de l'énergie fournie part en chaleur pendant l'établissement.

⚠️ Piège : Q = Iₘₐₓ·τ est un résultat admis — ne pas le recalculer avec i(τ). Et le bilan porte sur l'énergie fournie W = E·Q, avec E en volts et Q en coulombs.
