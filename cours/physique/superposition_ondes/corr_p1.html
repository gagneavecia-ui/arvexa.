Superposition et battements

✏️ Exercice 1 — Deux ondes se croisent (★)

Données : principe de superposition y = y₁ + y₂ ; tableau de l'énoncé.

1

M₁ : y = y₁ + y₂ = 2,0 + 3,0 = +5,0 mm.

2

M₂ : y = 2,0 + (−3,0) = −1,0 mm.

3

M₃ : y = −1,5 + (−2,5) = −4,0 mm.

4

M₄ : y = 0 impose y₂ = −y₁ = −4,0 mm.

Pointy₁ (mm)y₂ (mm)y (mm)
M₁+2,0+3,0+5,0
M₂+2,0−3,0−1,0
M₃−1,5−2,5−4,0
M₄+4,0−4,00
5

M₄ est immobile : les deux élongations se compensent à chaque instant (interférence destructive en ce point).

6

Après le croisement, chaque onde se propage comme si l'autre n'avait jamais existé : elles se croisent sans se déformer.

y = y₁ + y₂
M₁ : +5,0 mm ; M₂ : −1,0 mm ; M₃ : −4,0 mm ; M₄ : y₂ = −4,0 mm.

⚠️ Piège : l'élongation est une grandeur algébrique : compte les signes, sinon M₂ et M₃ deviennent faux.

✏️ Exercice 2 — Deux diapasons et les battements (★)

Données : f₁ = 440 Hz ; f₂ = 443 Hz.

1

Fréquence des battements : f_b = |f₂ − f₁| = |443 − 440| = 3 Hz.

2

Période des battements : T_b = 1/f_b = 1/3 ≈ 0,33 s.

3

En 2,0 s, l'oreille perçoit N = f_b × 2,0 = 3 × 2,0 = 6 maxima d'intensité.

4

Si f₂ = 440 Hz : f_b = 0 → plus de battements : le son garde une intensité constante.

f_b = 3 Hz ; T_b ≈ 0,33 s ; 6 maxima en 2,0 s
Son d'intensité constante si f₂ = f₁.

⚠️ Piège : on n'additionne jamais les fréquences : la fréquence du son perçu reste voisine de 440 Hz (ici 441,5 Hz), seule son intensité oscille 3 fois par seconde.

✏️ Exercice 3 — Accorder un piano (★★)

Données : corde : 436 Hz ; diapason : 440 Hz ; 4 battements par seconde.

1

Vérification : f_b = |440 − 436| = 4 Hz : cohérent avec les 4 battements entendus par seconde.

2

436 < 440 : la corde est trop basse (sa note est plus grave que celle du diapason, il manque 4 Hz).

3

Tendre la corde augmente sa fréquence : f monte de 436 vers 440 Hz et f_b s'annule à l'accord. Il faut donc TENDRE la corde.

4

Corde inconnue : f_b = |512 − f| = 5 Hz donne deux solutions : f = 512 − 5 = 507 Hz ou f = 512 + 5 = 517 Hz.

f_b = 4 Hz ; corde trop basse → tendre
Corde inconnue : 507 Hz ou 517 Hz.

⚠️ Piège : la valeur absolue donne DEUX solutions ; sans test supplémentaire (variation des battements quand on modifie la tension), on ne peut pas trancher.

Interférences à la cuve à ondes

✏️ Exercice 4 — Cuve à ondes : constructive ou destructive ? (★★)

Données : f = 10 Hz ; λ = 2,0 cm ; S₁M = 12,0 cm ; S₂M = 16,0 cm ; S₁N = 9,0 cm ; S₂N = 12,0 cm.

1

En M : δ = |S₂M − S₁M| = |16,0 − 12,0| = 4,0 cm.

2

δ/λ = 4,0/2,0 = 2, donc δ = 2λ = k·λ avec k = 2 : interférence CONSTRUCTIVE, l'amplitude est maximale.

3

En N : δ = |12,0 − 9,0| = 3,0 cm ; δ/λ = 1,5, donc δ = (1 + ½)·λ : interférence DESTRUCTIVE, amplitude minimale (nulle si les deux ondes ont la même amplitude).

4

Célérité : v = λ·f = 2,0 × 10 = 20 cm·s⁻¹ = 0,20 m·s⁻¹.

M : constructive (k = 2) ; N : destructive ; v = 0,20 m·s⁻¹
δ/λ entier → constructif ; δ/λ demi-entier → destructif.

⚠️ Piège : δ est une différence de DISTANCES (valeur absolue), pas une somme ; et on compare δ à λ, jamais δ à f.

Ondes stationnaires

✏️ Exercice 5 — Vrai ou faux ? (★★)

Données : les cinq affirmations de l'énoncé, à valider une par une.

1

a) FAUX — après le croisement, chaque onde se propage sans modification : elles se sont seulement superposées pendant la rencontre.

2

b) VRAI — par définition f_b = |f₂ − f₁|.

3

c) FAUX — δ = k·λ est la condition CONSTRUCTIVE : l'amplitude résultante est maximale ; c'est δ = (k + ½)·λ qui la minimise.

4

d) VRAI — deux nœuds consécutifs (comme deux ventres consécutifs) sont distants de λ/2.

5

e) FAUX — un ventre est un point d'amplitude MAXIMALE ; le point d'amplitude nulle s'appelle un nœud.

a) FAUX ; b) VRAI ; c) FAUX ; d) VRAI ; e) FAUX
À savoir justifier sans hésiter le jour du Bac.

⚠️ Piège : ne te contente pas de VRAI/FAUX : la justification rapporte les points. Cite la condition (δ = k·λ ou (k + ½)·λ) ou le vocabulaire (nœud, ventre).

✏️ Exercice 6 — Corde de Melde : cinq fuseaux (★★★)

Données : L = 0,90 m ; n = 5 fuseaux ; f = 100 Hz ; puis f′ = 150 Hz à célérité inchangée.

1

Un fuseau mesure λ/2, donc L = n·λ/2 : λ = 2L/n = 2 × 0,90/5 = 0,36 m.

2

Distance entre deux nœuds consécutifs : d = λ/2 = 0,36/2 = 0,18 m.

3

Sur la figure : n + 1 = 6 nœuds (les deux extrémités comprises) et 5 ventres.

4

Célérité : v = λ·f = 0,36 × 100 = 36 m·s⁻¹.

5

À f′ = 150 Hz : λ′ = v/f′ = 36/150 = 0,24 m, donc n′ = 2L/λ′ = 1,80/0,24 = 7,5.

6

n′ = 7,5 n'est pas un entier : PAS de régime stationnaire à 150 Hz (les fréquences propres valent f_n = n·v/2L = 20·n Hz : 20, 40, 60, 80, 100, 120, 140 Hz… et 150 Hz n'en fait pas partie).

λ = 0,36 m ; d = 0,18 m ; v = 36 m·s⁻¹
À 150 Hz : n′ = 7,5 → régime stationnaire impossible.

⚠️ Piège : nœuds = n + 1 (les extrémités comptent !) ; et vérifie toujours que n est un entier avant d'annoncer un régime stationnaire — n'arrondis jamais 7,5 à 7 ou 8.

📌 Mémo : y = y₁ + y₂ ; f_b = |f₂ − f₁| ; constructif : δ = k·λ ; destructif : δ = (k + ½)·λ ; corde de Melde : L = n·λ/2, nœuds distants de λ/2, v = λ·f.
