Croisements simples et échiquiers

✏️ Exercice 1 — L'échiquier à compléter : Aa × Aa (★)

Données de l'énoncé. Pois, A pourpre dominant sur a blanc ; union Aa × Aa.

1

Chaque parent Aa forme deux types de gamètes, A et a, chacun à 1/2 (une moitié des gamètes porte A, l'autre porte a).

2

Échiquier complété : chaque case réunit un gamète ♀ et un gamète ♂.

3

Génotypes : AA 1/4 · Aa 1/2 (deux cases sur quatre) · aa 1/4.

4

Phénotypes : fleurs pourpres 1/4 + 1/2 = 3/4 (75 %) ; fleurs blanches 1/4 (25 %).

×A (1/2)a (1/2)
A (1/2)AA — 1/4Aa — 1/4
a (1/2)Aa — 1/4aa — 1/4

Aa × Aa → 3/4 + 1/4 = 1 (3:1)

Vérification : 1/4 + 1/4 + 1/4 + 1/4 = 4/4 = 1 et 75 % + 25 % = 100 % ✔

✏️ Exercice 2 — Le croisement test du pois (★)

Données de l'énoncé. Parent pourpre inconnu × parent blanc (aa) ; 62 descendants : 30 pourpres, 32 blancs.

1

Le parent blanc (aa) ne forme qu'un type de gamète : a. Le parent pourpre, s'il est Aa, forme A et a à 1/2 chacun.

2

Échiquier : A × a → Aa (1/2) et a × a → aa (1/2) : moitié pourpres, moitié blancs.

3

Observé : 30/62 ≈ 0,48 de pourpres et 32/62 ≈ 0,52 de blancs : très proches de 1/2 - 1/2 (l'écart vient du hasard de l'échantillon). Vérification : 0,48 + 0,52 = 1 ✔

4

Le parent pourpre est donc Aa. Croiser un individu avec un double récessif pour révéler son génotype s'appelle un croisement test.

Aa × aa → 1/2 + 1/2 = 1 (1:1)

Proportions 1:1 : signature d'un croisement test avec individu hétérozygote.

Compter les gamètes et lire un pedigree

✏️ Exercice 3 — Combien de gamètes différents ? 2ⁿ (★★)

Données de l'énoncé. Drosophile 4 paires ; maïs 10 paires ; humain 23 paires ; formule 2ⁿ.

1

Drosophile : 2⁴ = 16 types de gamètes ; maïs : 2¹⁰ = 1 024 ; humain : 2²³ = 8 388 608.

2

Vérification avec une seule paire : deux orientations possibles des homologues → 2¹ = 2 types de gamètes ✔

3

Le crossing-over, en échangeant des fragments entre chromatides non sœurs, crée des chromosomes recombinés : la diversité dépasse largement les 2ⁿ combinaisons de l'orientation seule.

Formule du comptage

2ⁿ types de gamètes

n = nombre de paires d'homologues ; les bivalents s'orientent indépendamment en métaphase I.

✏️ Exercice 4 — Dihybride : l'échiquier 16 cases (★★)

Données de l'énoncé. Drosophile BbVv × BbVv ; B gris, b ébène, V longues, v vestigiales ; gènes sur deux paires différentes.

1

La F1 porte deux paires hétérozygotes : 2² = 4 types de gamètes, AB, Ab, aB, ab, chacun à 1/4.

2

Échiquier complet : seize cases, chaque case à 1/16.

3

Regroupement par phénotype : gris longues 9/16 (AABB, 2 AABb, 2 AaBB, 4 AaBb) ; gris vestigiales 3/16 (AAbb, 2 Aabb) ; ébène longues 3/16 (aaBB, 2 aaBb) ; ébène vestigiales 1/16 (aabb).

4

Vérification : 9 + 3 + 3 + 1 = 16 cases, soit 16/16 = 1 ; en pourcentages : 56,25 % + 18,75 % + 18,75 % + 6,25 % = 100 % ✔

×ABAbaBab
ABAABBAABbAaBBAaBb
AbAABbAAbbAaBbAabb
aBAaBBAaBbaaBBaaBb
abAaBbAabbaaBbaabb

BbVv × BbVv → 9:3:3:1

Lecture : 9/16 = 56,25 % ; 3/16 = 18,75 % ; 3/16 = 18,75 % ; 1/16 = 6,25 % ; somme = 100 % ✔

⚠️ Piège. Regroupe les cases par phénotype (A– B–), pas par génotype : AaBb occupe quatre cases à lui tout seul.
✏️ Exercice 5 — Lire un pedigree (★★)

Données de l'énoncé. Parents I1 et I2 sains ; fille II3 atteinte ; trois autres enfants sains.

1

Deux parents sains ont une enfant atteinte : l'allèle malade était présent chez les parents sans se voir : il est récessif (il saute une génération).

2

II3 est une fille atteinte alors que son père I1 est sain. Si le gène était récessif lié au chromosome X, une fille atteinte devrait recevoir un X malade de son père, qui serait donc atteint : impossible. Le gène est porté par un autosome : transmission autosomique récessive.

3

Génotypes : I1 Aa, I2 Aa (sains mais obligatoirement porteurs), II3 aa (atteinte).

4

Prochain enfant du couple : Aa × Aa → 1/4 d'enfants atteints, soit 25 %.

PersonnePhénotypeGénotype
I1 (père)sainAa
I2 (mère)sainAa
II3 (fille)atteinteaa

Aa × Aa → 1/4 atteints (25 %)

Vérification : 3/4 + 1/4 = 1 ✔

⚠️ Piège. « Sain » ne veut pas dire AA : dans un pedigree récessif, les parents sains d'un enfant atteint sont des hétérozygotes obligatoires.
✏️ Exercice 6 — Croisement test dihydride chez le maïs (★★★)

Données de l'énoncé. Maïs, F1 RrJj × double récessif rrjj ; R lisse, r ridé, J jaune, j pâle.

1

Gamètes de la F1 : RJ, Rj, rJ, rj, chacun à 1/4 (deux paires hétérozygotes, 2² = 4). Gamètes du testeur rrjj : rj uniquement.

2

Échiquier : chaque gamète de la F1 rencontre le gamète rj.

3

Quatre phénotypes égaux : lisses jaunes (RrJj), lisses pâles (Rrjj), ridés jaunes (rrJj), ridés pâles (rrjj), chacun 1/4 = 25 %. Vérification : 4 × 25 % = 100 % ✔

4

Les deux gènes sont indépendants : ils sont portés par deux paires différentes, orientées au hasard en métaphase I (brassage interchromosomien).

×rj
RJ (1/4)RrJj — lisses jaunes — 1/4
Rj (1/4)Rrjj — lisses pâles — 1/4
rJ (1/4)rrJj — ridés jaunes — 1/4
rj (1/4)rrjj — ridés pâles — 1/4

RrJj × rrjj → 1:1:1:1

Signature d'un croisement test dihydrique à gènes indépendants.

⚠️ Si les gènes étaient liés. Portés par le même chromosome, ils se transmettraient ensemble : le croisement test donnerait surtout les deux combinaisons parentales (lisses jaunes et ridés pâles), en proportions proches de 1:1, avec de rares recombinants dus au crossing-over.
📌 À retenir après ces corrigés
  • 2ⁿ : nombre de types de gamètes pour n paires d'homologues (métaphase I).
  • Aa × Aa → 3/4 + 1/4 (3:1) ; Aa × aa → 1:1 (croisement test).
  • BbVv × BbVv → 9:3:3:1 ; BbVv × bbvv → 1:1:1:1.
  • La somme des proportions d'un échiquier vaut toujours 1 (100 %) : vérifie-la systématiquement.
