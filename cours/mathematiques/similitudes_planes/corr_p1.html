Méthode permanente : pour toute similitude z' = az + b, on retient k = |a|, θ = arg(a) [2π] et, si a ≠ 1, un unique invariant d'affixe ω = b/(1 − a), si bien que z' − ω = a(z − ω).

Reconnaître et lire une similitude

✏️ Exercice 1 — Quatre écritures à décoder (★)

Données : S₁ : z' = 2iz + 4 − 2i ; S₂ : z' = (1 + i)z + 2 − i ; S₃ : z' = 3z − 6 ; S₄ : z' = −z + 2.

1

Rapports et angles : |2i| = 2 et arg(2i) = π/2 ; |1 + i| = √(1 + 1) = √2 et arg(1 + i) = π/4 ; |3| = 3 et arg(3) = 0 ; |−1| = 1 et arg(−1) = π.

2

Pour S₁ : ω = (4 − 2i)/(1 − 2i). On multiplie par le conjugué 1 + 2i : (4 − 2i)(1 + 2i) = 4 + 8i − 2i − 4i² = 8 + 6i et (1 − 2i)(1 + 2i) = 1 + 4 = 5, donc ω = (8 + 6i)/5 = 1,6 + 1,2i : Ω(1,6 ; 1,2).

3

De même : S₂ : ω = (2 − i)/(−i) = i(2 − i) = 1 + 2i ; S₃ : ω = −6/(1 − 3) = 3 ; S₄ : ω = 2/(1 + 1) = 1.

4

Natures : k = 1 et θ = π donnent une rotation (symétrie centrale) ; θ = 0 avec k ≠ 1 donne une homothétie ; sinon, similitude quelconque.

✏️ Exercice 2 — Images, antécédent et vecteurs (★)

Données : S : z' = (1 − i)z + 2 + i ; A(2 ; 1), B(0 ; 1), C'(4 ; 2).

1

(1 − i)(1 − 2i) + 2 + i = 1 − 2i − i + 2i² + 2 + i = −1 − 3i + 2 + i = 1 − 2i : Ω(1 ; −2) est bien invariant. De plus k = |1 − i| = √2 et θ = −π/4 [2π].

2

z_A' = (1 − i)(2 + i) + 2 + i = 3 − i + 2 + i = 5 : A'(5 ; 0). z_B' = (1 − i)i + 2 + i = 1 + i + 2 + i = 3 + 2i : B'(3 ; 2).

3

Antécédent : z = (z' − b)/a = (4 + 2i − 2 − i)/(1 − i) = (2 + i)/(1 − i). Avec (1 − i)(1 + i) = 2 : z = (2 + i)(1 + i)/2 = (1 + 3i)/2 = 0,5 + 1,5i : C(0,5 ; 1,5).

4

→AB = z_B − z_A = i − (2 + i) = −2 et →A'B' = (3 + 2i) − 5 = −2 + 2i. Or a·→AB = (1 − i)(−2) = −2 + 2i : égalité vérifiée ✓. Enfin AB = 2, A'B' = |−2 + 2i| = 2√2, donc A'B'/AB = √2 = k ✓.

S : z' = (1 − i)z + 2 + i ; Ω(1 ; −2) ; k = √2 ; θ = −π/4 ; A'(5 ; 0), B'(3 ; 2), C(0,5 ; 1,5)
Résultats de l'exercice 2 — l'antécédent s'obtient par z = (z' − b)/a.
⚠️ Piège : ne retourne pas l'écriture à la hâte pour un antécédent ; isole z dans z' = az + b.

✏️ Exercice 3 — Éléments caractéristiques (★★)

Données : S : z' = (1 + i√3)z + √3 − i√3.

1

Pour z = 1 + i : (1 + i√3)(1 + i) + √3 − i√3 = 1 + i + i√3 + i²√3 + √3 − i√3 = 1 + i : Ω(1 ; 1) est invariant ✓.

2

k = |1 + i√3| = √(1 + 3) = 2 ; θ = π/3 car cos(θ) = 1/2 et sin(θ) = √3/2.

3

z_A' = √3 − i√3 : A'(√3 ; −√3). z_B' = 1 + i√3 + √3 − i√3 = 1 + √3 : B'(1 + √3 ; 0).

4

→ΩB = z_B − ω = 1 − (1 + i) = −i ; a·→ΩB = (1 + i√3)(−i) = −i − i²√3 = √3 − i ; or →ΩB' = (1 + √3) − (1 + i) = √3 − i : égalité vérifiée ✓.

5

Comme k = 2 ≠ 1, S n'est pas une rotation ; comme θ = π/3 ≠ 0, ce n'est pas une homothétie : S est une similitude de rapport 2 et d'angle π/3, composée d'une homothétie et d'une rotation de même centre Ω.

Ω(1 ; 1) ; k = 2 ; θ = π/3 ; A'(√3 ; −√3) ; B'(1 + √3 ; 0)
Résultats de l'exercice 3 — S transforme →ΩB en a·→ΩB.
✏️ Exercice 4 — Rapport et longueurs (★★)

Données : S : z' = (2 + 2i)z + 2 − 4i ; A(1 ; 1), B(2 ; 0), C(2 ; 2).

1

ω = (2 − 4i)/(−1 − 2i) = (2 − 4i)(−1 + 2i)/((−1)² + 2²) = (−2 + 4i + 4i − 8i²)/5 = (6 + 8i)/5 = 1,2 + 1,6i : Ω(1,2 ; 1,6). k = |2 + 2i| = √(4 + 4) = 2√2 ; θ = π/4.

2

z_A' = (2 + 2i)(1 + i) + 2 − 4i = 4i + 2 − 4i = 2 : A'(2 ; 0). z_B' = 4 + 4i + 2 − 4i = 6 : B'(6 ; 0). z_C' = (2 + 2i)(2 + 2i) + 2 − 4i = 8i + 2 − 4i = 2 + 4i : C'(2 ; 4).

3

AB = |z_B − z_A| = |1 − i| = √2 et A'B' = |6 − 2| = 4. Donc A'B'/AB = 4/√2 = 2√2 = k ✓ : la similitude multiplie bien les longueurs par k.

4

→AB = (1 ; −1) et →AC = (1 ; 1) : produit scalaire 1 − 1 = 0 et AB = AC = √2 : ABC est rectangle isocèle en A. →A'B' = (4 ; 0) et →A'C' = (0 ; 4) : produit scalaire nul et longueurs 4 = 4 : A'B'C' est rectangle isocèle en A' ✓.

Ω(1,2 ; 1,6) ; k = 2√2 ; θ = π/4 ; A'(2 ; 0), B'(6 ; 0), C'(2 ; 4)
Résultats de l'exercice 4 — A'B' = k·AB = 4.
⚠️ Piège : |2 + 2i| = √8 = 2√2, pas 4 : ne développe jamais le radical d'un module.
✏️ Exercice 5 — Une rotation transforme un carré (★★)

Données : S : z' = iz + 2 ; carré A(3 ; 1), B(3 ; 3), C(1 ; 3), D(1 ; 1).

1

k = |i| = 1 et θ = arg(i) = π/2 : S est une rotation. Son centre vérifie ω = 2/(1 − i) = 2(1 + i)/((1 − i)(1 + i)) = (2 + 2i)/2 = 1 + i : rotation de centre Ω(1 ; 1) et d'angle π/2.

2

z_A' = i(3 + i) + 2 = 3i − 1 + 2 = 1 + 3i : A'(1 ; 3). z_B' = i(3 + 3i) + 2 = 3i − 3 + 2 = −1 + 3i : B'(−1 ; 3). z_C' = i(1 + 3i) + 2 = i − 3 + 2 = −1 + i : C'(−1 ; 1).

3

z_D' = i(1 + i) + 2 = i − 1 + 2 = 1 + i : D' = D. Le point D coïncide avec le centre Ω(1 ; 1) de la rotation, et le centre d'une rotation est invariant.

4

→A'B' = −2 et →A'D' = (1 + i) − (1 + 3i) = −2i : longueurs 2 et 2, produit scalaire (−2)(0) + (0)(−2) = 0. De même →B'C' = −2i et →C'D' = 2 : quatre côtés égaux et des angles droits, donc A'B'C'D' est un carré ✓.

Rotation de centre Ω(1 ; 1) et d'angle π/2 ; A'(1 ; 3), B'(−1 ; 3), C'(−1 ; 1), D' = D
Résultats de l'exercice 5 — le carré ABCD est envoyé sur le carré A'B'C'D'.

✏️ Exercice 6 — Composée de deux applications usuelles (★★★)

Données : S₁ : z' = iz ; S₂ : z'' = 2z' ; S = S₂ ∘ S₁.

1

S₁ : k = 1, θ = π/2, centre O(0 ; 0) : rotation r(O ; π/2). S₂ : k = 2, θ = 0, centre O : homothétie h(O ; 2).

2

z'' = 2z' = 2(iz) = 2iz : S a pour écriture z' = 2iz. Ainsi a = 2i, b = 0 : k = 2, θ = π/2 et ω = 0/(1 − 2i) = 0 : S est la similitude de centre O, de rapport 2 et d'angle π/2.

3

z_A' = 2i·2 = 4i : A'(0 ; 4). z_B' = 2i·i = 2i² = −2 : B'(−2 ; 0). z_M' = 2i(1 + 0,5i) = 2i + i² = −1 + 2i : M'(−1 ; 2).

4

→AM = (−1 ; 0,5) et →AB = (−2 ; 1) : comme →AM = 0,5·→AB, le point M appartient à (AB). →A'M' = (−1 ; −2) et →A'B' = (−2 ; −4) : comme →A'M' = 0,5·→A'B', le point M' appartient à (A'B').

5

Conclusion : tout point de (AB) a son image sur (A'B') : la similitude S transforme la droite (AB) en la droite (A'B') — une similitude transforme une droite en une droite.

S : z' = 2iz ; centre O, rapport 2, angle π/2 ; A'(0 ; 4), B'(−2 ; 0), M'(−1 ; 2)
